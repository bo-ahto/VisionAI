## 2. 한국 갤러리 가격 책정의 실제 구조

### 2.1 호당 가격제 (한국 고유)

한국 미술 시장의 전통적 가격 산정 방식. 경매(2차)가 아닌 **갤러리(1차) 시장에서 주로 사용**.

```
갤러리 판매가 = 호수 × 호당 가격

  호수: 캔버스 크기 단위 (1호 = 22.7 × 15.8cm)
  호당 가격: 작가의 "시세"를 나타내는 단가
```

**호당 가격의 일반적 기준 (업계 관행):**

| 작가 경력 | 나이대 | 호당 가격 | 10호 기준 |
|-----------|--------|----------|----------|
| 신진 | 20대 | 5~8만원 | 50~80만원 |
| 신진 후기 | 30대 | 10~15만원 | 100~150만원 |
| 중견 초기 | 40대 | 15~20만원 | 150~200만원 |
| 중견 | 50대 | 25~30만원 | 250~300만원 |
| 원로 | 60대+ | 40~50만원+ | 400~500만원+ |
| 블루칩 | - | 100만원+ | 1,000만원+ |

> **출처**: 울산매일, 월간 ANDA, 브런치 미술시장 칼럼 등 국내 미술 매체 종합

**핵심 인사이트**: 한국 갤러리 가격의 기본 구조는 `작가의 호당 가격 × 크기(호수)`이며,
호당 가격은 작가의 경력/명성에 의해 결정됨.
단, 실측 결과 크기-가격 관계는 완전 선형이 아닌 **비선형(β=0.74)**: 큰 작품일수록 호당가 할인.
따라서 정확한 공식은 `Price = α × Ho^0.74` (Shin 2010 참조).

### 2.2 호당 가격을 결정하는 요인 (갤러리 관점)

갤러리에서 작가의 호당 가격을 산정하는 기준 (Beckert & Rössel, 2013; 국내 관행 종합):

```
호당가격 ∝ f(
    경력 단계,           ← 신진/중견/원로
    학력,               ← 미대 출신, 대학원 (한국 특수)
    전시 이력,           ← 개인전 횟수, 미술관 전시
    소속 갤러리 등급,     ← 메이저 갤러리 소속 = 높은 호당가
    수상 이력,           ← 비엔날레, 공모전
    소장처,             ← 국립현대미술관, 기업 컬렉션
    경매 실적,           ← 2차 시장에서의 검증
    시장 트렌드           ← 현재 인기도
)
```

### 2.3 학술 근거

| 연구 | 핵심 공식/발견 | 적용 |
|------|--------------|------|
| **Rengers & Velthuis (2002)** | `ln(P) = β₀ + β₁·size + β₂·material + β₃·artist_age + β₄·gallery_location + β₅·institutional_recognition + ε` | 1차 시장 hedonic의 원형 |
| **Beckert & Rössel (2013)** | 가격은 작품 내재적 속성이 아닌 **상호주관적 명성 인정 과정**에서 결정 | 정량화 어려운 "명성" 피처의 학술적 근거 |
| **Schönfeld & Reinstaller (2007)** | `ln(P) = f(artist_reputation, gallery_reputation)`, 가격과 작가명성 양의 상관, **갤러리명성과 음의 상관** (갤러리가 유명할수록 가격 할인 = 투자적 관점) | gallery_tier 피처의 방향성 |
| **Park et al. (2024)** | Popularity(인기) + Ability(실력) 통합 모델. 기존 hedonic의 시간 불변 명성 한계 극복 | 시간 변화하는 명성 지표 필요성 |
| **한국 호당가격 연구 (Shin, 2010)** | `P = α × Ho_number^β`, β < 1 (호수에 대한 체감 효과). 한국 시장 고유의 비선형 크기-가격 관계 | 호수 기반 가격 모델의 학술적 지지 |

## 3. 1차 시장 가격 예측 접근법 — 3가지 옵션

### 3.1 Option A: 호당 가격 역산 모델 (규칙 기반, 즉시 적용 가능)

**핵심 아이디어**: 갤러리가 실제로 가격을 정하는 방식 그대로 모방

```
Step 1. 작가별 호당 가격 역산 (선형 근사)
    호당가격_실측 = 판매가 / 호수

Step 2. 작가의 호당 가격 통계 구축
    작가별 호당가격 = median(호당가격_실측 across works)

Step 3. 신규 작품 가격 예측
    기본: 예측가 = 작가_호당가격 × 호수 × 매체_보정계수
    개선: 예측가 = α × Ho^0.74 × 매체_보정 (비선형, 파일럿 실측 β=0.74)

※ Step 1~3의 선형식(호당가 × 호수)은 업계 관행을 따른 1차 근사.
  실측 결과 β=0.74로 비선형이므로, 정밀 예측에는 비선형 공식 사용 권장.
```

**장점**: 실제 업계 관행과 동일, 해석 가능, 데이터 적어도 작동
**단점**: 신규 작가의 호당가격을 알 수 없음, 작가 내 가격 변동 설명 안 됨

**현재 94건으로 실행 가능 여부**: 가능 (11명 작가 각각 호당가격 계산)

### 3.2 Option B: 작가 명성 점수 기반 회귀 (데이터 수집 후)

**핵심 아이디어**: 호당 가격 자체를 작가 속성으로 예측

```
ln(호당가격) = β₀ 
             + β₁ × career_stage          ← 신진(1) ~ 원로(4) 
             + β₂ × ln(exhibition_count)   ← 전시 횟수 (로그)
             + β₃ × museum_shows           ← 미술관 전시 유무/횟수
             + β₄ × gallery_tier           ← 소속 갤러리 등급
             + β₅ × has_auction_record     ← 경매 이력 유무
             + β₆ × ln(auction_avg_price)  ← 경매 평균가 (있으면)
             + β₇ × collection_count       ← 소장처 수
             + β₈ × award_count            ← 수상 이력
             + ε

예측가 = exp(ln(호당가격_예측)) × 호수 × 매체_보정
```

**이 모델의 수학적 의미**:
- Rengers & Velthuis (2002)의 hedonic 공식을 한국 시장에 적응
- 종속변수를 `ln(가격)`이 아닌 `ln(호당가격)`으로 → 크기 효과를 분리
- 작가 속성이 호당가격을 결정, 크기는 단순 곱셈 → 업계 구조 반영

**필요 데이터**:
- 작가 프로필 (경력, 전시, 수상, 소장처) → 웹 크롤링/수동 수집
- 최소 50~100명 작가 × 각 3~5건 = 150~500건
- 주의: 독립변수가 대부분 작가-수준이므로 유효 표본은 작가 수(50~100)에 가까움.
  작품-수준 변동(크기, 매체)만이 작가 내 변동을 설명하므로, mixed-effects 또는 hierarchical 모델 고려 필요.

### 3.3 Option C: 2단계 앵커 + 업리프트 모델 (중장기)

**핵심 아이디어**: 경매 모델(이미 있음) → 갤러리 프리미엄/디스카운트 모델

```
Step 1. Auction Anchor (기존 모델)
    auction_estimate = existing_model.predict(artist, medium, size)
    → 이 작가의 비슷한 작품이 경매에 나오면 얼마?

Step 2. Gallery Uplift Model (신규)
    ln(gallery_price / auction_anchor) = f(
        gallery_tier,         ← 갤러리 등급
        exhibition_type,      ← 개인전/그룹전/아트페어
        artist_career_stage,  ← 경력 단계
        is_new_work,          ← 신작 여부
        market_momentum       ← 시장 분위기
    )

Step 3. Final Estimate
    gallery_price = auction_anchor × exp(uplift)
```

**학술 근거**: Schönfeld & Reinstaller (2007)의 이중 명성 모델을 실용화.
경매가 = 작가 명성, 갤러리 가격 = 작가 명성 + 갤러리 명성 + 컨텍스트.

**필요 데이터**: 
- 동일 작가의 경매 + 갤러리 가격 페어 → 한국 경매 이력 있는 작가의 갤러리 데이터

### 4.1 호당 가격 역산 분석

```python
# 실제 계산 가능
for 작가 in 11명:
    works = 작가의 작품들
    for work in works:
        ho = area_to_ho(width_cm * height_cm)     # 면적 → 가장 가까운 F호 변환
        price_per_ho = price / ho                  # 호당 가격 역산
    
    작가_호당가 = median(price_per_ho across works)  # 작가의 호당 가격
    
    # 예측: 새 작품의 가격 = 작가_호당가 × 호수

# 주의: 호수 변환은 F형 기준 면적 매칭. P형/M형/S형은 같은 호수라도 면적이 다르므로
# 작품 비율(aspect_ratio)에 따라 실제 호수가 달라질 수 있음.
# 현재 파일럿에서는 F형 기준 단순 변환 사용 — 편향 가능성 있음.
```

### 5.3 작가 경력 단계 자동 분류 규칙

```python
def classify_career_stage(birth_year, solo_count, museum_count, auction_record):
    age = 2026 - birth_year
    
    # 원로 판정을 먼저 (이전 분기에 흡수되지 않도록)
    if age >= 60 and solo_count >= 20:
        return 4  # 원로
    elif solo_count >= 10 or museum_count >= 3 or auction_record:
        return 3  # 중견
    elif age >= 30 or (solo_count >= 3):
        return 2  # 신진 후기
    else:
        return 1  # 신진
```

```
각 작가의 호당가격 CV (변동계수) 계산:
  CV < 0.3 → 호당 가격 일정 (모델 유효)
  CV > 0.5 → 호당 가격 불안정 (작가 내 다른 요인 필요)
```

### 7.2 가설 2: 크기-가격 관계가 선형인가?

```
한국 연구 (Shin, 2010): P = α × Ho^β,  β ≈ 0.8~0.9 (체감)
  β = 1.0 → 완전 선형 (호수 비례)
  β < 1.0 → 대형 작품 호당가격 할인 (일반적)
  β > 1.0 → 대형 프리미엄 (드묾)
```

### 7.3 가설 3: 전시 유형이 가격에 영향을 주는가?

```
같은 작가의 개인전 vs 그룹전 가격 비교:
  개인전 프리미엄 예상 (갤러리가 주력 작가에 높은 가격 책정)
```

## 7-A. Option A 검증 결과 (실제 94건 분석)

### 호당 가격 역산 결과

> **CV (Coefficient of Variation, 변동계수)** = 표준편차 / 평균.
> 같은 작가의 여러 작품에서 역산한 호당 가격이 얼마나 **일관적인지** 측정.
> - CV < 0.3 = **안정** (호당가 모델이 잘 맞음)
> - CV 0.3~0.5 = **보통**
> - CV > 0.5 = **불안정** (호당가만으로 부족, 크기/매체/전시유형 추가 필요)
>
> CV가 높은 주원인: **크기 체감 효과** — 작은 작품(1호)은 호당가가 높고, 큰 작품(30호+)은 낮아지는 경향.

| 작가 | 건수 | 호당가 중앙 | CV | 판정 |
|------|:----:|----------:|:---:|------|
| 김윤신 | 3 | 215만 | 0.14 | 안정 |
| 김주리 | 5 | 17만 | 0.10 | 안정 |
| 이진주 | 3 | 117만 | 0.33 | 보통 |
| 임노식 | 4 | 9만 | 0.35 | 보통 |
| 남석우 | 8 | 12만 | 0.44 | 보통 |
| 주연수 | 12 | 33만 | 0.52 | 불안정 |
| 정수정 | 8 | 56만 | 0.58 | 불안정 |
| 이시현 | 10 | 6만 | 0.64 | 불안정 |
| 조이솝 | 4 | 15만 | 0.78 | 불안정 |
| 이동혁 | 3 | 30만 | 1.00 | 불안정 |
| 순이지 | 34 | 12만 | 0.55 | 불안정 |

- **안정(CV<0.3)**: 2명 — 호당 가격 모델이 잘 맞는 작가
- **보통(0.3~0.5)**: 3명
- **불안정(CV>0.5)**: 6명 — **같은 작가 내에서도 가격 변동이 커서 호당가만으로 부족**

> 순이지 34건 중 idx 112 (10x10cm) 1건이 0호 매핑 → price/0 = inf 발생. 해당 1건 제외 후 CV=0.55 산출.
> 1호 작품(22.7x15.8cm) 12건의 호당가 50만원 vs 30호 이상 작품의 호당가 10만원 → 크기 체감 효과가 CV를 높이는 주원인.

### 가설 검증 결과

**가설 1 (호당가 일정성)**: PARTIAL — 11명 중 5명 안정/보통, 6명 불안정.

**가설 2 (크기-가격 비선형)**:
```
ln(Price) = 12.94 + 0.74 × ln(Ho)
→ β = 0.74 (한국 연구 Shin 2010의 0.8~0.9보다 낮음)
→ 큰 작품일수록 호당가 할인이 더 큼 (체감 효과)
```

**가설 3 (전시 유형 영향)**: PARTIAL (주의 필요)
```
아트페어: 호당 215만원 (3건, 김윤신 1명 — 작가 효과와 혼동 가능)
개인전:   호당  27만원 (54건)
단체전:   호당  35만원 (10건)
그룹전:   호당   9만원 (27건)
→ 개인전 > 그룹전은 유의미하나, 아트페어는 김윤신 단독이라 전시 유형 효과로 단정 불가
```

**해석**: 호당가격만으로도 MdAPE 28% — 경매 모델(40.87%)보다 오히려 좋음.
단, 이는 같은 작가의 다른 작품에서 호당가를 참조하는 것이므로 비교매출 접근과 유사.
11명 밖에 없어서 과적합 위험이 있으나, **호당가 모델의 유효성은 확인됨**.

### Option A 개선 방향

호당가만으로 MdAPE 28%이지만, CV가 높은 작가(5명)의 오차가 큼. 개선을 위해:

1. **전시 유형 보정**: 개인전 vs 그룹전에 따라 호당가 조정
2. **크기 체감 효과 적용**: `Price = α × Ho^0.74` (선형 아닌 비선형)

### 10.6 수집 우선순위 로드맵 (검증 반영 수정)

```
[Phase 0: 즉시 (0원, 1주)] ────────────────────────────────
  ✅ 공공데이터포털 전시정보 API → 작가별 전시 횟수 (작가 필드 구조 사전 확인 필요)
  ✅ 네이버 뉴스 API → 미디어 언급 빈도 (25,000건/일)
  ✅ K-ARTMARKET KADA → 작가 프로필 (학력/전시/소장처) ← 검증 완료
  → 11명 작가에 대해 KADA + 네이버로 프로필 보강

[Phase 1: 단기 (1~2주)] ──────────────────────────────────
  ▶ K-ARTMARKET 경매 데이터 크롤링 → 경매 거래 이력
  ▶ K-ARTMARKET KADA 확장 → 50~100명 작가 프로필
  ▶ Artsy API → 글로벌 전시/경매 (retirement 경고 주의, 빠른 수집 권장)
  ✗ Korean Artist Project → 사이트 불안정, 사용 불가
  → 50~100명 작가 프로필 구축

[Phase 2: 중기 (1~2개월)] ─────────────────────────────────
  ▶ 아이옥션(insaauction.com) 등 크롤링 가능 경매사 → 경매 데이터 확장
  ※ 서울옥션은 크롤링 금지 → K-ARTMARKET 경매 데이터로 대체
  ▶ MutualArt 구독 → 글로벌 경매 앵커
  ▶ Instagram 작가 계정 매핑 → 소셜 시그널
  → 거래 데이터 +30,000건, 프로필 +500명

[Phase 3: 장기 (3~6개월)] ─────────────────────────────────
  ▶ 갤러리 파트너십 → 실거래 데이터
  ▶ ArtFacts 구독 → 작가 랭킹
  ▶ Artnet 라이선스 → 글로벌 경매 완전 데이터
  → 종합 1차+2차 시장 모델 학습 가능
```
