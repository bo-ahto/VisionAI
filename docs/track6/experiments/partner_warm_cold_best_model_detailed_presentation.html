1. 발표 목표와 진행 방식

목표

Warm, Warm-lite, Cold를 성능 숫자만으로 소개하지 않고, 실제 가격 예측이 만들어지는 계산 흐름으로 설명한다.

설명할 질문 발표에서 답하는 방식
어떤 작품이 어느 경로로 가는가 작가 매칭 신뢰도와 같은 작가 가격 이력 수로 설명
각 경로는 어떤 피처를 쓰는가 모델별 피처 지도와 단계별 사용처로 설명
최종 가격은 어떻게 계산되는가 로그가격 계산식, 후보 선택, 보정, exp() 변환으로 설명
왜 Warm과 Warm-lite를 나누는가 1~4건, 5건 이상 반례 실험 근거로 설명
Cold는 왜 구조가 다른가 같은 작가 가격 이력이 없는 조건에서 검색 피처와 불확실성 방어가 필요한 이유로 설명

권장 흐름

공통 라우팅과 용어를 먼저 설명한 뒤, Warm -> Warm-lite -> Cold 순서로 같은 구조를 반복한다.

2. 현재 0.1v API 라우팅 기준

[작품 입력]
  - 작가명 / artist_key
  - 작품 크기
  - 매체 / 지지체
  - 작가 메타 / 검색 문맥
        |
        v
[라우팅 판단]
  - 작가매칭신뢰도점수 >= 0.80 ?
  - 같은작가_사용가능가격이력수는 몇 건인가?
        |
        +-- 0.80 이상 AND 5건 이상  -> Warm
        |
        +-- 0.80 이상 AND 1~4건     -> Warm-lite
        |
        +-- 그 외                    -> Cold 또는 검수대기
경로 현재 0.1v API 입력 조건 가격 판단의 중심
Warm 작가 매칭 신뢰도 0.80 이상 + 같은 작가 이력 5건 이상 같은 작가 가격 이력과 정밀 유사작품 비교군
Warm-lite 작가 매칭 신뢰도 0.80 이상 + 같은 작가 이력 1~4건 적은 작가 이력 통계와 작품 기본 피처
Cold 이력 0건, 작가 매칭 불확실, 입력 부족, 동명이인 위험 작품 피처, 작가 메타, 검색 문맥, 불확실성 방어

3. 라우팅 값 1: 작가매칭신뢰도점수

목적

입력 작가가 학습 데이터의 특정 작가와 같은 사람인지 0~1 사이 점수로 판단한다.

작가키 직접 일치:
  작가매칭신뢰도점수 = 1.00

작가키가 없거나 신뢰하기 어려운 경우:
  작가매칭신뢰도점수 =
    clip(
        0.70 * 이름일치점수
      + 0.20 * 보조정보일치점수
      + 0.10 * 학습작가등록점수
      - 0.15 * 동명이인위험점수
      - 0.20 * 핵심정보충돌점수,
      0.00,
      0.95
    )
요소 의미 예측 경로 영향
이름일치점수 정규화 작가명 또는 문자열 유사도 기반 점수 높을수록 Warm/Warm-lite 가능성 증가
보조정보일치점수 생년, 국적, 외부 작가 ID 등 일치 여부 동명이인 위험을 줄임
학습작가등록점수 학습 데이터에 해당 작가가 존재하는지 같은 작가 이력 사용 가능성 확인
동명이인위험점수 같은 이름 후보가 여러 명인지 높으면 Cold 또는 검수대기
핵심정보충돌점수 생년/국적/외부 ID 충돌 여부 충돌 시 상위 경로 금지

4. 라우팅 값 2: 같은작가_사용가능가격이력수

이 값은 단순 작가 등장 횟수가 아니다.

가격 예측에 실제로 사용할 수 있는 같은 작가의 학습 가격 이력 수다.

포함 조건 제외 조건
같은 작가로 확정된 학습 데이터 작품 가격이 없거나 0 이하인 행
실제 가격값이 있고 로그가격 계산 가능 동일 작품/동일 거래 중복
예측 대상 작품과 중복되지 않음 평가 대상의 정답 가격
자기 fold 제외 후 남은 학습 이력 작가 매칭이 불확실한 후보 
작가매칭신뢰도점수 >= 0.80 AND 이력 >= 5       -> Warm
작가매칭신뢰도점수 >= 0.80 AND 이력 1~4건      -> Warm-lite
그 외                                          -> Cold 또는 검수대기

주의

Warm 내부의 최소 표본 1은 Warm 진입 조건을 1건으로 낮춘다는 뜻이 아니다. 이미 Warm에 들어온 5건 이상 작가 안에서 더 좁은 하위 유사작품 비교군을 1건부터 인정한다는 뜻이다.

5. 공통 계산 단위

표현 의미 사용 위치
로그가격 가격에 자연로그를 적용한 값 세 경로의 내부 계산 단위
exp() 로그가격을 원화 가격으로 되돌리는 함수 최종 가격 변환
잔차 실제_로그가격 - 예측_로그가격 학습/검증에서 보정 모델 target 또는 평가에 사용
clip(x, a, b) 값을 a~b 범위로 제한 Warm 잔차 보정, Cold 구간 보정

최종_원화가격 = exp(최종_로그가격)

APE =
  abs(최종_원화가격 - 실제_원화가격)
  / 실제_원화가격

7. Warm과 Warm-lite를 분리한 실험 근거

질문 확인 결과 근거
1~4건 이력을 Cold로 보내도 되는가 안 된다. Warm-lite가 동일 행 Cold보다 크게 우세 PP-WCUT4: Warm-lite 0.1092 / 0.2866 / 0.8765, Cold 0.5429 / 0.9946 / 2.5358
1~4건 전체를 Warm 계열로 통일해도 되는가 현재 근거로는 지지되지 않음 PP-WMIN9C: Warm-lite 0.1092 / 0.2866 / 0.8765, WMIN8 svc-core proxy 0.1291 / 0.2932 / 0.9163
5건 이상에 Warm-lite를 강제 적용하면 어떤가 WMIN8 Warm이 전 지표 우세 PP-WMIN9D: WMIN8 0.104326 / 0.235814 / 0.739416, 강제 Warm-lite 0.108722 / 0.248054 / 0.837824

해석

1~4건은 Cold로 보내기에는 작가 이력 신호가 강하고, 5건 이상 Warm 본체를 그대로 쓰기에는 저표본 구조가 다르다. 그래서 현재 0.1v API는 5건 이상 Warm, 1~4건 Warm-lite로 분리한다.

11. Warm 유사작품 비교군 기준가격

비교군 매칭 사다리

우선순위 비교군 그룹 최소 표본 의미
1 작가 + 재료/지지체 + 크기 구간 1 같은 작가의 가장 가까운 시장 조건
2 작가 + 크기 구간 1 매체/지지체가 부족할 때 크기 중심
3 작가 전체 이력 1 같은 작가 가격대 유지
4 재료/지지체 + 크기, 작가 무관 30 작가 비교군이 비면 쓰는 일반 비교군
5~7 재료/크기 일반 그룹, 전체 학습 데이터 30~50 / 제한 없음 최종 fallback 
같은작가_유사작품기준로그가격
  = 선택된 비교군의 로그가격 통계 기반 기준가격

중요

자기 fold를 제외한 뒤 비교군이 0건이면 다음 단계로 fallback한다. 평가 대상 작품의 정답 가격이 자기 피처에 들어가지 않게 하기 위한 누수 차단이다.

12. Warm 보조안정 예측값

보조안정_Warm예측로그가격은 단순 평균이나 임시값이 아니라, 이미 학습·동결된 두 예측 축을 로그가격에서 섞은 보조 기준이다.

보조안정_Warm예측로그가격
  = 0.75 * 큰오차방어_Warm예측로그가격
    + 0.25 * 버킷순차보정_Warm예측로그가격
축 생성 방식 Warm에서의 역할
큰오차방어 Warm 예측값 여러 Warm 후보 예측값, 후보 간 평균/분산/범위, 불확실성 폭을 입력으로 한 Huber meta-model 큰 오차 가능성이 있는 작품에서 안정적인 보조 기준 제공
버킷순차보정 Warm 예측값 생성 bucket -> CatBoost Quantile -> Huber 중심선 -> CatBoost 잔차 보정 작품 크기/형태/매체 조건을 반영한 보조 예측 축

해석

14. 버킷순차보정의 학습 단계와 예측 단계

구분 실제 가격 사용 여부 처리
학습 단계 사용함 실제 로그가격으로 Quantile/Huber/CatBoost 잔차 모델을 학습
OOF 잔차 생성 사용함 실제_로그가격 - Huber_OOF_중심선_로그가격을 CatBoost 잔차 target으로 생성
운영 예측 단계 사용하지 않음 새 작품 피처만으로 q10/q50/q90, Huber 중심선, 잔차 보정값을 예측 
학습 때:
  잔차 target = 실제_로그가격 - Huber_OOF_중심선_로그가격

예측 때:
  버킷순차보정_Warm예측로그가격

      + 동결 CatBoost 잔차모델 예측값

해석

Huber 중심선은 먼저 안정적인 중심 가격을 잡는 기준선이고, CatBoost 잔차 모델은 그 뒤에 반복적으로 남는 오차만 보정한다.

15. Warm 기준가격 후보 생성

기본후보_기준가 =
  0.70 * 같은작가_유사작품기준로그가격
  + 0.30 * 보조안정_Warm예측로그가격

대안후보_기준가 =
  0.85 * 같은작가_유사작품기준로그가격
  + 0.15 * 보조안정_Warm예측로그가격
후보 의미 언제 중요해지는가
기본 후보 일반적으로 유지하는 기준가격 대부분의 Warm 작품
대안 후보 같은 작가 유사작품 신호를 더 강하게 반영한 후보 위험도 0.2534 이상이고 대안 후보가 기본 후보보다 0.005 log 이상 낮을 때

논리

기준가격의 중심은 같은 작가 유사작품이다. 다만 비교군이 작거나 가격 분산이 클 수 있으므로 보조안정 값을 일부 섞어 기준가격의 급격한 흔들림을 줄인다.

16. Warm Huber 잔차 보정

잔차예측 = Huber잔차모델(10개 피처)

후보_보정로그가격 =
  후보_기준가 + clip(0.50 * 잔차예측, -0.05, +0.05)
장치 의미 이유
Huber loss 큰 오차 작품의 영향을 완만하게 처리하는 강건 회귀 이상치가 회귀계수를 과하게 흔드는 것을 줄임
0.50 배율 잔차 예측값의 절반만 반영 보정 모델이 기준가격을 뒤집지 못하게 함
clip(-0.05, +0.05) 보정 폭을 로그가격 ±0.05로 제한 Warm의 주 신호인 같은 작가 기준가격을 보호

Huber는 학습된다

Huber 자체는 손실 함수지만, 여기서의 Huber 잔차 모델은 Huber loss를 기준으로 회귀계수와 절편을 적합한 예측기다.

17. Warm 위험도 조건부 라우터

작품단위위험도 =
  clip(
      0.38 * clip((Quantile예측구간폭 - 1.20) / 0.95, 0, 1)
    + 0.22 * clip(후보예측분산 / 0.18, 0, 1)
    + 0.14 * clip(현재-안정기준차이 / 0.06, 0, 1)
    + 0.16 * (신뢰도구간 == 저신뢰)
    + 0.10 * (안정기준가격대 == 초고가),
      0,
      1
    )

35. Cold 대표 로그가격 안정화

Quantile예측구간폭_구간 = bucket(Quantile예측구간폭)

구간별_잔차중앙값 =
  median(
    실제_로그가격 - 검색피처포함_기초Quantile후보_로그가격
  )
  within same Quantile예측구간폭_구간

구간별_보정값 =
  clip(구간별_잔차중앙값, -0.25, +0.25)

검색포함_대표로그가격 =
  검색피처포함_기초Quantile후보_로그가격
  + 구간별_보정값

운영 예측에서의 실제 가격 사용 여부

구간별 잔차중앙값은 학습/검증 단계에서 미리 계산해 동결한다. 운영 예측 시점에는 실제 가격을 새로 쓰지 않고, Quantile 폭 구간에 맞는 동결 보정값만 조회한다.

36. Cold 과대예측 방어 guard

방어조건 =
  Quantile예측구간폭 >= 1.4612207078910142
  AND 검색포함_대표로그가격 - 낮은쪽40퍼센트기준_로그가격 >= 0.07715547281151025
  AND 낮은쪽40퍼센트기준_로그가격 < 검색포함_대표로그가격

if 방어조건:
  과대예측방어_로그가격 =
    0.50 * 검색포함_대표로그가격
    + 0.50 * 낮은쪽40퍼센트기준_로그가격
else:
  과대예측방어_로그가격 = 검색포함_대표로그가격

논리

Cold의 주요 운영 리스크는 신규/무이력 작가의 큰 과대예측이다. 그래서 불확실성이 크고 대표가격이 낮은쪽 40% 기준보다 충분히 높을 때만 하향 방어한다.

37. Cold 작가 검색 보정 lookup

작가검색보정_로그값 =
  search_delta_lookup[artist_key]

최종_Cold_로그가격 =
  과대예측방어_로그가격
  + clip(작가검색보정_로그값, -0.20, +0.20)
경우 처리
lookup에 작가가 있음 작가별 검색 보정값을 최종 로그가격에 더함
lookup에 작가가 없음 보정값 0, guard only
Quantile 폭이 넓음 검수 플래그 또는 낮은 신뢰도 표시
lookup 없음 + 폭 넓음 검색 보정 근거 부족과 높은 불확실성을 함께 표시

lookup 의미

실시간 검색이나 즉석 학습이 아니다. 검증된 검색 스냅샷에서 만든 고정 작가별 검색 보정값 조회표다.

44. 발표 결론

한 문장 요약

현재 0.1v 가격 예측은 작가 매칭 신뢰도와 같은 작가 가격 이력 수를 기준으로 Warm, Warm-lite, Cold를 나누고, 각 경로는 서로 다른 정보 조건에 맞는 피처와 방어 로직으로 최종 로그가격을 만든다.

결론 설명
Warm 5건 이상 같은 작가 이력을 중심으로 정밀 유사작품 기준가격을 만들고, 잔차 보정과 위험도 라우터로 방어
Warm-lite 1~4건 작가 이력을 Cold로 버리지 않고, 저이력 통계와 작품 피처를 Huber ensemble로 결합
Cold 같은 작가 이력이 없거나 불확실하므로 작품/작가/검색 피처와 Quantile 기반 과대예측 방어를 사용

마무리 메시지

이 모델의 핵심은 단순히 어떤 알고리즘을 썼는지가 아니라, 입력 작품이 가진 근거의 양과 신뢰도에 맞춰 계산 경로를 다르게 설계했다는 점이다.
