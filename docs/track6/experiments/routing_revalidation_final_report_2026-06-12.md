# Warm/Cold 라우팅 재검증 최종 보고서

- 작성일: 2026-06-12 / 범위: 라우팅 기준(이력 임계·매칭 임계) 전면 재검증 — 실험 7건(WCUT1/2, WMATCH1, WCUT4, MCAL1, RMAP1, E2E1, RHO1) + 정책 동결 2건(warm_lite_v0.1, routing_policy_v0.1)
- 방식: 신규 수집 0 — 기존 데이터 재구성(실존 저이력 작가 leave-one-out, 합성 캘리브레이션, 원천 universe proxy)으로 원안 9~16주를 **3일**에 완료. 전 실험 체크포인트 재개 구조 + 전용 폴더 재현.

## 1. 결론 (변경 전 → 후)

| 항목 | 재검증 전 | 재검증 후 |
|---|---|---|
| 이력 5건 기준 | 암묵적 성능 임계값 취급 | **구조 제약으로 판명** — 1~4건 고신뢰 작가는 Warm-lite 경로가 압도적 우위 |
| 라우팅 구조 | 2-경로 (Warm/Cold) | **3-경로** (Warm 5+ / Warm-lite 1~4 / Cold) — `warm_lite_v0.1` 동결 |
| 매칭 임계 | 0.90 (보수 설계안) | **0.80 하향 권고 확정**(proxy 기준) — 0.90은 자격 작가 64~73%를 Cold로 누수(기대 MAPE all-Cold 수준), 0.80이면 누수 6%/기대 MAPE -13% |
| k별 차등 매칭 임계 | 미검토 | 불필요 확인 (전 k 요구 정확도 0.70~0.72 동일) |

## 2. 핵심 실증 수치

- **실존 저이력 작가 검증 (PP-WCUT4, 게이트 1.0/1.0/1.0)**: train 실존 2~5건 작가 649명 leave-one-out ×3 seed — Warm-lite MdAPE k=1~4 `0.1195/0.1194/0.1049/0.0948` vs Cold `0.51~0.56`, p95 0.88 vs 2.54. **절단 시뮬레이션(0.146~0.218)은 비관적이었음** — 전환 가치가 추정보다 큼.
- **오매칭 비용 (PP-WMATCH1)**: 오매칭 Warm은 MAPE 2.69/p95 9.3~9.7 — 같은 장르 오매칭도 동일하게 파괴적 → 매칭 정확도 ~85%+가 우위 조건.
- **임계 비용 (PP-E2E1, 4,355행 replay)**: 0.90의 안전(Cold 오유입 0%)은 자격 누수 64~73%의 대가. 0.80: 누수 6.1%(clean), Cold 오유입 0~0.5%. **부동소수점 경계 버그(0.7+0.1<0.80) 실증 — 운영 구현 시 tolerance 필수.**
- **사전 밖 동명이인율 (PP-RHO1)**: 원천 universe 3,033작가 중 사전 밖 1,260명 → 이름 충돌 63명 = **ρ proxy 5.0%** (생년 충돌 차단 제외 시 ≤4.4%) ≪ 허용 한계 30%(PP-RMAP1) → 0.80 권고 확정.
- **매칭 산식 구조 (PP-MCAL1)**: 사전 내 위험(동명이인 117key·유사이름)은 점수 ≤0.65로 차단 — [0.6,0.7) 혼합 구간(정확도 0.42)은 절대 상위 경로 금지 구간.

## 3. 동결 산출물

- `models/track6/warm_lite_v0.1/` — 1~4건 경로 (Huber 6구성 + 작가 이력 실시간 통계 + k=1 차등 등급, 동결 모델이 WCUT2 수치 재현)
- `models/track6/routing_policy_v0.1/` — 3-경로 규칙 + 임계 0.80 권고(근거·채택 조건·구현 함정) + 잔여 과제
- `scripts/track6/monitor_warm_lite_routing.py` — 운영 모니터링 하니스 (R1 규칙 위반 / R2 트래픽·k 분포 / R3 보조정보 무 구간 검수율 / R4 k별 MdAPE 경보 한계(WCUT4×1.5) / R5 ρ 실측 누적)
- 파트너 문서(md+html) 반영 완료: 5건 기준의 성격, 매칭 임계 정량 근거, 0.80 하향 권고

## 4. 기대 효과 (운영 반영 시)

자격 작가 트래픽(이름 일치+사전 등록) 기준: 현행(0.90, 2-경로) 기대 MAPE **0.92 → 0.80**(임계 하향) → Warm-lite 반영 시 저이력 세그먼트 MdAPE **0.51~0.56 → 0.095~0.120**. 작가 수 기준 저이력(2~5건) 작가는 사전의 37%.

## 5. 잔여 운영 과제 (오프라인 한계 — 명시적 이관)

1. **ρ 최종 추인**: proxy(5%)는 같은 수집 파이프라인 내 universe 기준 — 완전 외부 신규 작가의 ρ는 운영 매칭 로그로 확인 (모니터링 하니스 R5).
2. **Warm-lite 실트래픽 모니터링**: 하니스 준비 완료 — 로그 스키마(ts, artist_key, match_score, history_n, route, pred[, actual])로 연동만 남음.
3. 운영 매칭 구현 시 경계 비교 tolerance(1e-6) 적용 (E2E1 실증 버그).

## 6. 실험 색인

WCUT1(절단, 5건=구조 제약) → WCUT2(게이트 12조합) → WMATCH1(오매칭 비용) → WLITE-ARTIFACT1(동결) → WCUT4(실존 검증 통과) → MCAL1(캘리브레이션) → RMAP1(2D 맵) → E2E1(replay, 0.80 권고) → RHO1(ρ=5%) → routing_policy_v0.1. 상세는 각 `experiments/track6/PP-*/`와 matrix.
