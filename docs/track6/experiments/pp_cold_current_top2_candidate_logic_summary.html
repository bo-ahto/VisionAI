Cold 모델 후보 1, 2위 정리

현재 Cold 모델 후보를 운영 관점에서 정리한 문서다. 핵심은 k160_alpha45를 성능 균형형 1위 후보로 두되, 극단 오차 안정성 기준에서는 user_meta_core_bucket을 2위 보수 후보로 유지하는 것이다.

1. 현재 후보 순위

순위 후보 성격 MdAPE MAPE p95 APE RMSE log APE > 5
1 k160_alpha45 균형형 개선 후보 0.471031 0.999148 2.569218 0.880774 74
2 user_meta_core_bucket 보수형 안정 후보 0.473483 1.100452 2.942330 0.887405 72
참고 k160_alpha50 공격적 성능 후보 0.467623 1.068718 2.920315 0.876089 76

k160_alpha45는 기존 후보보다 MdAPE, MAPE, p95 APE, RMSE log를 모두 개선한다. 다만 APE > 5는 기존보다 2건 증가한다. 따라서 평균 성능과 tail 안정성 사이의 선택이 필요하다.

2. 후보 1: k160_alpha45

Cold 입력에서 같은 작가의 가격 이력을 직접 쓰지 못하는 문제를 보완하기 위해, 입력 작품과 비슷한 과거 작품 160건의 가격 분포를 모델 피처로 추가한 후보다. 같은 작가를 찾는 방식이 아니며, artist_key는 사용하지 않는다.

k160_alpha45 학습 단계 순서도
1. 학습 데이터 준비 가격 라벨이 있는 과거 작품 사용. artist_key, 같은 작가 가격 이력, lookup, search/live 검색 제외.
2. 작품 피처 생성 가로/세로/깊이 cm, 면적, 로그 면적, 종횡비, 매체, 지지체, 크기 bucket, 입체 여부, 극단 비율 여부.
3. 유사작품 비교군 생성 train 내부는 KFold out-of-fold로 자기 가격 누수를 차단하고, 작품 조건이 가까운 비교군을 만든다.
4. k160 통계 생성 가장 가까운 160건의 로그가격 중앙값, q25/q75, IQR, 평균, 표준편차, 면적당 가격, 유사도 통계 생성.
5. LightGBM Quantile q45 학습 목표값은 실제 로그가격. q50보다 약간 보수적인 q45를 학습해 과대평가 tail을 완화한다.
k160_alpha45 사용 단계 순서도
1. 작품 정보 입력 cm 기준 크기, 매체, 지지체, 깊이/입체 여부를 입력한다.
2. 작가 메타 입력 출생연도, 작품 수, 팔로워/인지도성 지표, 경력 단계, 국적/활동권 등 입력 가능한 메타를 받는다.
3. 유사작품 160건 검색 artist_key가 아니라 작품 조건 기준으로 학습 작품 중 가까운 160건을 찾는다.
4. 유사작품 통계 계산 로그가격 중앙값, q25/q75, IQR, 면적당 가격, 유사도 평균/최대/최소를 만든다.
5. q45 모델 예측 작품 피처 + 작가 메타 + 유사작품 통계를 LightGBM Quantile q45 모델에 넣는다.
6. 가격 변환 최종 가격 = exp(예측 로그가격).

3. 후보 2: user_meta_core_bucket

현재 가장 보수적인 Cold 후보다. 유사작품 비교군을 쓰지 않고, 작품 정보와 사용자가 입력 가능한 작가 메타 bucket만 사용한다. 평균 성능은 q45보다 낮지만 APE > 5가 더 적어 극단오차 안정성 기준으로 중요하다.

user_meta_core_bucket 학습 단계 순서도
1. 학습 데이터 준비 가격 라벨이 있는 과거 작품 사용. artist_key, 같은 작가 가격 이력, artist-key lookup 제외.
2. 작품 피처 생성 가로/세로/깊이 cm, 면적, 로그 면적, 종횡비, 매체, 지지체, 매체-지지체 조합, 크기 bucket.
3. 작가 메타 피처 생성 출생연도, 총 작품 수, 팔로워/인지도성 지표, 경력 단계, P1/국제 활동 여부, 국적, missing flag.
4. 메타 bucket 생성 출생연대, 작품 수, 팔로워, 경력 단계, 메타 완성도, 매체 x 출생연대, 지지체 x 메타 완성도, 경력 x 크기.
5. LightGBM Quantile q50 학습 실제 로그가격을 목표값으로 중앙값 예측 모델을 학습한다.
user_meta_core_bucket 사용 단계 순서도
1. 작품 정보 입력 cm 기준 크기, 면적, 매체, 지지체 등 작품 피처를 만든다.
2. 작가 메타 입력 출생연도, 작품 수, 팔로워, 경력 단계, 국적 등 사용자가 입력 가능한 메타를 받는다.
3. 메타 bucket 생성 작가 메타를 안정적인 구간형 피처로 변환한다.
4. q50 모델 예측 작품 피처와 작가 메타 bucket을 LightGBM Quantile q50 모델에 넣는다.
5. 가격 변환 최종 가격 = exp(예측 로그가격).

선택 근거

  • APE > 5가 72건으로 현재 후보군 중 가장 낮다.
  • k160_alpha45보다 평균 성능은 낮지만, 극단오차 최소화 기준에서는 안정적이다.
  • 유사작품 통계를 만들지 않아 구조가 단순하고 운영 구현 난이도가 낮다.

4. APE > 5를 더 줄이는 방향

이미 시도한 방법

  • 유사작품 기준가격 + residual clip
    MdAPE와 p95가 악화되어 운영 후보로 부적합.
  • 유사작품 가격 상단 기준 output cap
    MdAPE/MAPE는 소폭 개선했지만 APE > 5는 줄이지 못함.
  • 저가 가중치 + 낮은 quantile
    APE > 5는 줄었지만 MdAPE 손실이 커짐.

다음 실험 우선순위

  • q45 + 약한 저가 가중치 세밀 grid
    low_weight=1.2~1.8, alpha=0.43~0.47.
  • 과대평가 전용 asymmetric loss
    전체 예측을 낮추지 않고 과대평가 오차만 더 강하게 벌점.
  • APE > 5 위험 검수 모델
    가격을 바꾸지 않고 저신뢰/검수 필요 표시.

5. 현재 권장안

운영 선택지 권장 후보 이유 주의점
기본 개선 후보 k160_alpha45 MAPE/p95 개선이 명확하고 전체 균형이 가장 좋다. APE > 5가 2건 증가하므로 검수/신뢰도 표시 필요.
보수 후보 user_meta_core_bucket 극단오차가 가장 낮고 구조가 단순하다. 평균 성능과 p95는 q45보다 낮다.

최종 결정 전에는 q45 + 약한 저가 가중치 세밀 grid, APE > 5 발생 행의 원인 분석, 저가 구간 검수 표시 기준, 작가 메타 필수/권장 입력 정책을 추가로 확인하는 것이 좋다.
