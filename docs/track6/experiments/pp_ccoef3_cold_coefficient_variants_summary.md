# PP-CCOEF3 — 나라별 관행 계수 변형 (둘레 기반 / 이산 등급) 요약

- 날짜: 2026-06-22
- 트랙: Track6 / Cold
- 실험 폴더: `experiments/track6/PP-CCOEF3_cold_coefficient_variants/`
- 선행: PP-CCOEF1(A, 면적 재매개화)·PP-CCOEF2(B, 메타→연속 계수) 모두 기각
- 상태: **종료 — 둘 다 기각**

## 1. 목적

PP-CCOEF1/2는 사실상 미국·한국식(면적당 단가 = 연속 계수) 하나의 형태였다. 리서치가 말한
나머지 관행을 **다른 방식으로** 적용해 미시도 영역을 닫는다.

- **C1 (독일 Factor, 둘레 기반)**: 타깃 `log(price / (width+height))`, 복원 `exp(pred)×(w+h)`.
  크기항이 면적(제곱 증폭)이 아니라 둘레(선형) → A의 대형작 노이즈 증폭 완화 가설.
- **C2 (독일·이탈리아 이산 등급)**: 메타 5신호(전시·팔로워·작품수·갤러리등급·경력)로 작가를
  5개 등급(quantile)에 넣고 **등급 median 계수**(ln(price/area)) 배정. B의 연속 회귀와 달리
  계수를 밴드 안에 묶음 → B의 MAPE 폭증을 막는지 검증.

## 2. 고정 test 기록 (선택용 아님, n=3,099)

| | MdAPE | MAPE | p95_APE |
|---|---|---|---|
| v0.2 base | 0.4823 | 1.242 | 4.380 |
| **C1 둘레** | 0.48242 | 1.2328 | 3.9651 |
| **C2 등급** | 0.52198 | 1.2372 | 3.7430 |

- C1: 중앙값 base와 사실상 동일, MAPE/p95 미세 개선.
- C2: 중앙값 악화(+0.040), MAPE는 base 동급(**B의 1.777 폭증을 1.237로 해소** = 이산화 가설 입증),
  p95는 변형 중 최고(3.743).

## 3. 게이트 — artist 80/70% holdout 200회 paired (변형 vs 직접 ln_price 타깃)

| 변형 | improve_prob MdAPE | MAPE | p95 | pass(≥0.90) |
|---|---|---|---|---|
| C1 둘레 | 0.565 | 0.605 | 0.51 | ✗ |
| C2 등급 | **0.05** | 0.75 | **0.855** | ✗ |

- **C1**: 세 지표 ≈ 0.5~0.6 = 동전던지기. A(면적)와 동일 — 트리가 크기를 정규화 방식과 무관하게
  이미 처리. 둘레로 바꿔도 추가신호 없음.
- **C2**: 중앙값 개선확률 0.05 = held-out에서 **거의 항상 median 악화**. 그러나 p95 0.855는
  **콜드 변형 중 0.90 게이트에 가장 근접한 꼬리 방어**. MAPE 0.75. → 이산 등급은 **꼬리/MAPE
  안전장치**(극단 계수 차단)이지 median 정확도 수단이 아님. all-metric 게이트는 미통과.

## 4. 결론 — 둘 다 기각

- **C1 (둘레)**: 면적과 동일한 wash. 정규화 분모 형태는 콜드에서 무의미(트리가 크기 학습).
- **C2 (이산 등급)**: 보승님 질문의 핵심을 입증 — **"계수를 어떻게 적용하느냐"는 분명히 영향**.
  연속 회귀(B)의 극단 계수가 MAPE를 폭증시켰고, 등급 median으로 묶으니 MAPE/p95가 안정화.
  그러나 거친 5등급은 median 정확도를 잃어(MdAPE 0.522, win-prob 0.05) all-metric으로는 base를
  못 이김. **꼬리 방어 목적 후보로서의 가치는 있으나 점 예측 교체 불가.**

## 5. PP-CCOEF1/2/3 종합 — 작가계수 재구조화 전수 종결

| 경로 | 형태 | 결과 |
|---|---|---|
| A (CCOEF1) | 면적 재매개화 (행 단위, 연속) | 기각 (동전던지기, 면적노이즈) |
| B (CCOEF2) | 메타→계수 (작가 단위, 연속 회귀) | 기각 (MAPE +43% 폭증) |
| C1 (CCOEF3) | 둘레 재매개화 (행 단위, 연속) | 기각 (동전던지기) |
| C2 (CCOEF3) | 메타→등급→median (작가 단위, 이산) | 기각 (median 붕괴, 꼬리만 방어) |

**미국·한국·독일·이탈리아식 작가계수 형태를 연속/이산·면적/둘레·행/작가 단위로 전수 시험.
어느 것도 v0.2 base를 all-metric으로 이기지 못함.** 일관된 원인: (1) 트리 base가 크기↔가격을
이미 학습 → 정규화 재매개화 무익, (2) 콜드 작가 계수는 메타로만 추정 가능한데 그 신호가 약하고
연속 추정은 극단값, 이산 추정은 median 손실. **종결 재확인 — 콜드 점예측 개선 레버는 Warm
커버리지 확대.** 단 C2의 꼬리 방어(p95 0.855)는 향후 콜드 범위/검수 정책의 보조 신호로 재활용
여지(점 예측 아닌 범위 표시 축).
