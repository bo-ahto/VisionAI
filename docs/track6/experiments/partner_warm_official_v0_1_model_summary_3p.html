Warm 가격 예측 모델 핵심 설명

이 문서는 partner_warm_cold_official_v0_1_unified_model_report.html에서 Warm 모델만 따로 설명하기 위한 3페이지 요약본이다. 현재 Warm 모델이 언제 쓰이고, 기존 WMIN8 대비 성능이 어떻게 달라졌으며, 가격이 어떤 순서로 계산되는지만 정리한다.

Warm의 의미
Warm은 입력 작가가 기존 작가로 신뢰 가능하게 매칭되고, 같은 작가의 가격 이력을 1건 이상 사용할 수 있는 경우의 가격 예측 경로다. 현재 official 0.1v 기본 Warm은 예전처럼 1~4건과 5건 이상을 서로 다른 모델로 나누지 않고, 같은 작가 이력이 1건 이상이면 통합 Warm current 후보를 사용한다.

Warm은 기준가격을 만들고, 모델 보정으로 다듬는다

Warm current는 단일 산식 하나가 아니라, 같은 작가의 가격 이력 통계와 작품 피처를 함께 사용하는 예측 파이프라인이다. 학습 단계에서는 과거 작품의 실제 로그가격을 정답으로 두고 두 q50 평균 기준가격과 잔차 보정 구조를 학습한다. 사용 단계에서는 입력 작품의 같은 작가 이력과 작품 정보를 같은 방식으로 피처화해 최종 로그가격을 만든다.

3. 가격 계산 예제

같은 작가 가격 이력이 있는 작품 1점이 사용 단계 순서대로 가격이 나오는 과정이다. 로그가격은 자연로그 기준이다. (고정값)은 학습·검증 때 정해져 운영 입력마다 바뀌지 않는 값이고, 표시가 없는 값은 입력 작품마다 모델이 예측하거나 계산하는 값이다. 

[1] LightGBM Quantile 기준가격 계산
    두 방식으로 '한가운데 예상가'를 각각 내고 평균 내 기준가격을 만든다.

    전체 피처 기반 q50 = 14.22
    안정 피처 기반 q50 = 14.08
    기준 로그가격 = 평균(14.22, 14.08) = 14.15
        |
        v
[2] LightGBM Huber residual 보정값 계산
    기준가격에서 남은 오차를 모델이 예측하고, 절반만 제한된 폭 안에서 반영한다.

    Huber residual 예측값 = +0.30
    0.50 (고정값: residual 보정 강도) * 0.30 = +0.15
    clip(+0.15, -0.10, +0.10) = +0.10
      - -0.10, +0.10은 고정값: 보정 폭 하한/상한
      - +0.15는 상한 +0.10을 넘으므로 +0.10으로 잘림

    보정 후 로그가격 = 14.15 + 0.10 = 14.25
        |
        v
[3] 최종 Warm 가격 변환
    최종 Warm 로그가격 = 14.25
    최종 Warm 가격 = exp(14.25) ≈ 1,544,000원

clip은 보정값이 하한보다 작으면 하한으로, 상한보다 크면 상한으로 잘라내는 함수다. 위 예제에서는 모델이 +0.15 보정을 만들었지만 상한 +0.10으로 잘려, 운영 가격이 한 번에 과도하게 움직이지 않는다.

4. 왜 이렇게 계산하는가

같은 작가 가격 이력 Warm의 가장 강한 근거다. 같은 작가의 실제 과거 가격 분포를 기준가격으로 사용하므로, 작가별 가격 수준을 직접적으로 잡을 수 있다.
작품 피처 같은 작가라도 크기, 매체, 지지체, 입체 여부에 따라 가격이 달라진다. 작품 피처는 같은 작가 기준가격을 작품 단위로 조정하는 역할을 한다.
Quantile 기준가격 전체 피처 q50과 안정 피처 q50의 평균은 대표 예측값이고, q10/q90은 가격 범위와 불확실성 폭을 보여준다. 단일 가격만 내는 것보다 위험도를 설명하기 쉽다.
LightGBM Huber residual 보정 기준가격이 놓친 반복 오차를 LightGBM Huber residual 모델로 보정한다. Huber objective는 큰 이상치에 덜 민감하고, clip은 보정이 과도하게 튀는 것을 막는다.

Warm current를 운영 기본 후보로 보는 이유

1. 사용 피처

구분피처역할
작품 크기 width_cm, height_cm, depth_cm, area_cm2, log_area, aspect_ratio 작품 단위 가격 차이를 설명한다. 면적과 로그 면적은 가격 분포가 한쪽으로 치우치는 현상을 완화한다.
작품 형태 has_depth, is_3d_candidate, 크기 bucket 2D/3D 여부와 크기 구간 차이를 반영한다.
재료/지지체 medium_category, support_category, 조합 bucket 캔버스, 종이, 패널, 혼합재료처럼 가격 차이를 만드는 매체 조건을 반영한다.
같은 작가 가격 통계 가격 중앙값, q25/q75, IQR, 면적단가, 표본 수, 매칭 단계 Warm의 핵심 근거다. 같은 작가의 실제 가격 이력을 작품 조건과 결합해 기준가격을 만든다.
모델 파생값 전체 피처 q10/q50/q90, 안정 피처 q50, 예측 불확실성 폭, residual 보정값 대표 가격, 가격 범위, 남은 오차 보정을 계산한다.

3. 학습 데이터 증가 효과

별도 learning curve 실험에서는 fixed test split을 고정하고 Warm train split만 25%, 50%, 75%, 100%로 늘렸다. 모든 비율에서 Warm 처리가 가능한 동일 test cohort 기준으로 비교했기 때문에, 단순히 평가 대상이 바뀌어서 좋아진 것이 아니라 학습 데이터 증가 효과를 본 실험이다.

train 비율 n 평균 MdAPE 평균 MAPE 평균 p95 APE 평균 RMSE log 평균
25% 550 0.153252 0.363610 0.990130 0.487094
50% 550 0.114222 0.256292 0.908345 0.425109
75% 550 0.102419 0.234519 0.815625 0.404022
100% 550 0.088637 0.229596 0.806068 0.379168
25%에서 100%로 늘렸을 때 fixed cohort 평균 변화는 MdAPE -0.064615, MAPE -0.134014, p95 APE -0.184062, RMSE log -0.107926이다. 따라서 품질 관리된 학습 데이터가 늘면 Warm 정확도가 좋아질 근거가 있다. 다만 신규 운영 데이터도 가격 라벨, 작가 매칭, 작품 피처 품질 검수를 통과해야 같은 개선을 기대할 수 있다. 이 학습곡선 100% 행은 학습곡선 전용으로 재학습한 별도 실험이므로, Page 1의 배포 Warm current 수치와 셋업이 정확히 같지는 않다. 핵심은 절대 수치가 아니라 데이터가 늘수록 좋아지는 추세다.

4. 운영 설명 문장

Official 0.1v Warm 가격 예측은 먼저 작가가 기존 작가로 신뢰 가능하게 매칭되는지 확인한다.
같은 작가 가격 이력이 1건 이상 있으면 Warm current 모델을 사용한다.

Warm current는 같은 작가의 과거 가격 통계와 입력 작품의 크기·매체·지지체 피처를 함께 사용한다.
먼저 LightGBM Quantile이 전체 피처 q10/q50/q90과 안정 피처 q50 로그가격을 만든다.
두 q50 평균을 대표 기준가격으로 두고,
그 다음 LightGBM Huber residual 모델이 기준가격에서 남은 오차를 제한된 폭으로 보정한다.

같은 607개 Stable Warm fixed test 기준에서 Warm current는 기존 WMIN8보다
MdAPE와 MAPE가 개선됐다. 다만 p95 APE는 기존 WMIN8보다 높으므로,
큰 오차 구간은 운영 모니터링과 검수 표시를 유지한다.

5. 최종 해석

  • Warm current는 같은 작가 가격 이력을 쓸 수 있는 입력의 official 0.1v 기본 Warm 후보다.
  • 기존 WMIN8과 같은 607개 fixed test에서 비교했을 때 중앙 오차와 평균 오차가 개선됐다.
  • p95는 악화됐으므로 “모든 지표에서 완전 우세”가 아니라 “대표 정확도 중심 기본 후보”로 설명해야 한다.
  • 운영에서는 가격만 반환하지 않고 q10/q90 범위, 불확실성 폭, 신뢰도/검수 표시를 함께 유지하는 것이 안전하다.
