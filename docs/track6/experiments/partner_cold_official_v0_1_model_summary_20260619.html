Cold 모델 단독 정리 - official 0.1v 후보

이 문서는 Warm과 분리해서 Cold 모델만 설명한다. Cold는 같은 작가의 가격 이력을 직접 쓸 수 없거나, 작가 식별이 충분히 신뢰되지 않을 때 쓰는 경로다. 따라서 artist_key나 같은 작가 과거 거래가는 예측 피처로 쓰지 않고, 작품 정보와 사용자가 입력 가능한 작가 메타, 그리고 비슷한 작품 그룹의 가격 분포를 사용한다.

Cold q35 k160 기본 후보와 k320 규칙 라우터 후보

1. 결론 요약

현재 Cold 기본 후보는 base_k160이다. 구조는 단순하고 중앙 오차가 가장 낮다. 극단 오차 방어를 더 중시하면 pred_or_ref_lt_800w_gap0p0 규칙 라우터를 후보로 둘 수 있다. 이 라우터는 일부 입력에서 k160 대신 k320 후보를 선택해 MAPE, p95 APE, APE > 5를 줄인다.

  • base_k160은 MdAPE가 더 낮아 일반적인 중앙 오차 기준에서 설명하기 쉽다.
  • pred_or_ref_lt_800w_gap0p0은 MAPE, p95 APE, APE > 5가 더 낮아 큰 오차 방어에 유리하다.
  • 둘 다 같은 strict Cold 조건에서 검증했으며, test 가격 라벨을 보고 선택하지 않는다.

2. Cold 입력과 사용 피처

사용하는 정보

  • 작품 크기: 가로 cm, 세로 cm, 깊이 cm, 면적, 로그 면적, 종횡비
  • 작품 속성: 매체, 지지체, 매체-지지체 조합, 크기 구간, 입체 여부
  • 사용자 입력 작가 메타: 출생연도, 경력 단계, 국적/활동권 등 입력 가능한 정보
  • 메타 bucket: 출생연대, 경력 단계, 매체 x 출생연대, 경력 단계 x 크기 구간
  • 유사작품 통계: 비슷한 작품 k160 또는 k320의 가격 분포 요약값

쓰지 않는 정보

  • artist_key로 같은 작가를 직접 찾지 않는다.
  • 같은 작가의 과거 가격 이력을 직접 쓰지 않는다.
  • 작가 이름 lookup 후처리로 가격을 보정하지 않는다.
  • search_* 피처와 외부 live 검색 결과를 쓰지 않는다.
  • 검증/테스트 행의 실제 가격은 라우터 선택에 쓰지 않는다.

3. 학습 단계

Cold q35 k160 기본 후보 학습 흐름
1. strict Cold 학습 데이터 구성 실제 가격 라벨이 있는 과거 작품을 사용하되, 같은 작가 식별자와 같은 작가 가격 이력은 제거한다.
목적: 운영에서 작가 가격 이력을 모르는 Cold 상황을 재현한다.
2. 작품 피처와 사용자 입력 가능 작가 메타 생성 크기, 면적, 매체, 지지체, 크기 구간, 출생연도, 경력 단계, 국적/활동권, 메타 bucket을 만든다.
목적: 운영 사용자가 입력할 수 있는 정보만 모델에 남긴다.
3. 유사작품 k160 통계 생성 각 학습 작품과 작품 조건이 비슷한 과거 작품 160건을 찾고, 그 그룹의 로그가격 중앙값, q25, q75, IQR, 평균, 표준편차, 면적당 가격 통계를 만든다.
목적: 같은 작가 이력 대신 비슷한 작품들의 시장 가격 분포를 기준 정보로 제공한다.
4. 자기 가격 누수 차단 학습 행의 유사작품 통계를 만들 때 자기 자신이 비교군에 들어가지 않도록 fold/out-of-fold 방식으로 만든다.
목적: 학습 중 자기 가격을 본 통계로 자기 가격을 맞히는 누수를 막는다.
5. LightGBM Quantile alpha=0.35 학습 작품 피처, 작가 메타, 메타 bucket, 유사작품 k160 통계를 입력으로 넣고 실제 로그가격을 맞히도록 학습한다.
목적: 중앙값보다 약간 낮은 q35 기준으로 학습해 Cold에서 자주 발생하는 과대예측 tail을 줄인다.
k320 규칙 라우터 후보 학습/검증 흐름
1. base k160 후보 학습 k160 비가중 유사작품 통계와 LightGBM Quantile alpha=0.35 모델을 학습한다.
2. k320 후보 학습 k320 비가중 통계와 거리 가중 통계를 함께 사용해 더 넓은 비교군 기반 후보를 학습한다.
3. 사용 가능한 신호만으로 라우터 규칙 탐색 k160 예측가, k320 예측가, k160 유사작품 기준가만 사용해 k320을 선택할 조건을 validation에서 고른다.
4. 선택 규칙 동결 후 test 확인 선택된 규칙은 k160 예측가 또는 유사작품 기준가가 800만원 미만이고, k320 후보가 k160 후보보다 낮으면 k320이다.

4. 사용 단계

base_k160 사용 흐름
1. 입력값 수집 사용자가 작품 크기, 매체, 지지체, 입체 여부, 입력 가능한 작가 메타를 넣는다.
2. 작품 피처와 메타 bucket 생성 cm 기준 크기에서 면적, 로그 면적, 종횡비, 크기 구간을 만들고, 작가 메타를 구간화한다.
3. 유사작품 160건 찾기 같은 작가가 아니라, 작품 크기/형태/매체/지지체 조건이 유사한 학습 작품 160건을 찾는다. 작가 메타는 유사작품 검색 조건이 아니라 이후 LightGBM 예측 모델의 입력 피처로 사용한다.
4. 유사작품 가격 통계 계산 160건의 로그가격 중앙값, q25, q75, IQR, 평균, 표준편차, 면적당 가격 통계를 만든다.
5. LightGBM Quantile q35 예측 작품 피처, 작가 메타, 유사작품 통계를 학습된 모델에 넣어 q35 로그가격을 출력한다.
6. 원화 가격 변환 최종 가격은 exp(예측 로그가격)으로 변환한다.
규칙 라우터 사용 흐름
1. base k160 예측값 계산 먼저 기본 Cold 후보의 로그가격과 원화 가격을 계산한다.
2. k320 후보 예측값 계산 같은 입력으로 k320 비교군 기반 후보 가격도 계산한다.
3. 라우터 조건 판단 k160 예측가 또는 k160 유사작품 기준가가 800만원 미만이고, k320 예측 로그가격이 k160 예측 로그가격보다 낮으면 k320을 선택한다.
4. 조건 미충족 시 base 유지 위 조건을 만족하지 않으면 base k160 예측값을 그대로 사용한다.

5. 계산 예제

아래 숫자는 계산 흐름을 설명하기 위한 예시다. LightGBM Quantile 예측값은 고정 산식으로 사람이 직접 계산하는 값이 아니라, 학습된 모델에 입력 피처를 넣었을 때 나오는 출력값이다.

[입력 작품] 가로 80cm, 세로 100cm, 면적 8,000cm2 매체 oil, 지지체 canvas, 크기 구간 large 작가 메타: 1980년대 출생, mid-career, 한국 활동권 [유사작품 k160 통계] 비슷한 작품 160건의 로그가격 중앙값 = 17.90 q25 = 17.30 q75 = 18.45 IQR = 1.15 면적당 로그가격 중앙값 = 9.05 [base_k160 LightGBM Quantile q35 출력] 예측 로그가격 = 18.10 예측 가격 = exp(18.10) = 약 72,500,000원 [k320 후보 출력] k320 예측 로그가격 = 18.02 k320 예측 가격 = exp(18.02) = 약 66,900,000원 [라우터 판단] k160 예측가 72,500,000원: 800만원 이상 k160 유사작품 기준가 exp(17.90) = 약 59,400,000원: 800만원 이상 조건 미충족 → base_k160 유지 [최종 Cold 가격] 약 72,500,000원

저가 후보에서 라우터가 작동하는 예

[입력 작품] 작은 크기, paper 계열, 작가 메타가 낮은 가격대와 가까운 입력 [base_k160 출력] k160 예측 로그가격 = 15.70 k160 예측 가격 = exp(15.70) = 약 6,590,000원 k160 유사작품 기준가 = 약 5,800,000원 [k320 후보 출력] k320 예측 로그가격 = 15.55 k320 예측 가격 = exp(15.55) = 약 5,680,000원 [라우터 판단] k160 예측가 또는 유사작품 기준가가 800만원 미만: 예 k320 로그가격이 k160 로그가격보다 낮음: 15.55 < 15.70, 예 조건 충족 → k320 후보 선택 [최종 Cold 가격] 약 5,680,000원

6. 해석과 운영 선택

운영 기준 권장 후보 이유
구조 단순성, 중앙 오차, 설명 용이성 base_k160 MdAPE가 낮고 라우터 없이 한 모델 출력만 사용한다.
큰 오차 방어, p95, APE > 5 감소 pred_or_ref_lt_800w_gap0p0 MdAPE는 약간 나빠지지만 MAPE, p95 APE, APE > 5가 개선된다.
엄격한 출시 안정성 base 우선, 라우터는 후속 후보 라우터는 투명하지만 운영 로직이 하나 늘어나므로 모니터링과 parity 검증이 추가로 필요하다.
