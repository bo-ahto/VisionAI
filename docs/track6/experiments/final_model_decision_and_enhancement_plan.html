  • MdAPE: 0.1566
  • Within_30: 0.7315
  • 작가명만보다 크기 결합이 안정적
  • 실제 크기 묶음 유지
작가 학습 작품 수 확인
  • artist_works_log 추가 후 MdAPE: 0.1562
  • Within_30: 0.7364
  • WM1 종합 점수 1위
  • 직접 가격 영향은 작음
  • 신뢰도/안정성 보조 피처로 유지
모델군 비교
  • WM1 종합 점수 1~5위 모두 Huber
  • Linear/Ridge보다 MdAPE와 Within_30 균형 우수
  • Warm 1차 모델은 Huber

Warm Huber가 피처를 쓰는 방식

  • Huber는 선형 회귀 계열 모델
  • 예측 구조: 기준값 + 피처별 계수의 합
  • 일반 선형 회귀보다 큰 이상치에 덜 흔들리도록 학습
  • 미술품처럼 가격 이상치가 많은 데이터에 적합

Cold CatBoost가 피처를 쓰는 방식

  • CatBoost는 트리 부스팅 계열 모델
  • 여러 개의 작은 의사결정 트리를 쌓아 오차를 줄임
  • 범주형 피처와 비선형 관계 처리에 강점
  • Cold처럼 작가명 없이 작품 정보와 작가 메타를 함께 써야 하는 상황에 적합
