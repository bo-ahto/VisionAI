# 피처·모델 선정 중간 리포트

- 작성일: 2026-06-04
- 목적: 현재까지의 가격 예측 실험을 기준으로 Warm/Cold 모델과 피처 선정의 중간 판단을 정리
- 작성 범위: 모델 선택, 핵심 피처, 주요 실험 결과, 현재 판단
- 제외 범위: 운영 API, 서비스 화면 구성, DB 구축, 외부 데이터 운영 정책
- 표기 원칙: 본문은 실험 설명 중심으로 작성하고, 상세 결과표와 실행 로그는 요청 시 별도 제공

## 1. 핵심 결론

### 1.1 v0.1 기준 모델 정의

v0.1은 최종 배포 모델이 아니라, 현재까지의 실험 결과를 기준으로 신규 테스트와 서비스 적용 검토에 사용할 중간 기준 버전이다.

| 구분 | v0.1 기준 | 구체 구성 | 사용 방식 |
|---|---|---|---|
| Warm | Huber 기반 결합 후보 | 유사 작품 기반 가격 피처 70% + 오차 안정화 후보 30%, 내부 실험명 `blend_svcnum_ppv8_wsvc_0.70` | 같은 작가의 학습 이력이 있는 작품에 적용 |
| Cold | LightGBM Quantile 기반 기준 후보 | q10/q50/q90 예측 + qwidth 구간 보정, 내부 실험명 `qwidth_bin_oof_min30_cap0.25` | 학습 이력이 없거나 부족한 작가에 참고 예측가와 가격 범위 중심으로 적용 |
| CatBoost/순차 조합 | 보조 후보 | CatBoost Quantile -> Huber -> CatBoost 잔차 보정 순차 실험은 진행했지만 v0.1 기준에는 미포함 | v0.1 대표 모델은 아니며 Warm/Cold 추가 개선 후보로 관리 |

Warm v0.1의 가격 예측 구조:

```text
warm_pred_log
= 0.70 * 유사_작품_기반_가격_피처_후보
+ 0.30 * 오차_안정화_후보

warm_pred_price = exp(warm_pred_log)
```

Cold v0.1의 가격 예측 구조:

```text
cold_q50_log = LightGBM Quantile 중앙 예측값
cold_q10_log, cold_q90_log = 낮은/높은 가격 분위 예측값
quantile_width = cold_q90_log - cold_q10_log

cold_pred_price = exp(cold_q50_log + qwidth_based_correction)
```

Cold v0.1에서 CatBoost 보정은 적용하지 않는다.

- CatBoost Quantile -> Huber -> CatBoost 잔차 보정 순차 실험은 진행했음
- Warm에서는 기존 Warm Huber 대비 MdAPE, MAPE, p95_APE가 함께 개선됐음
- Cold에서는 MdAPE와 MAPE는 개선됐지만 p95_APE가 악화되어 큰 오차 위험이 남았음
- 따라서 v0.1 기준은 LightGBM Quantile 후 qwidth 보정으로 고정
- CatBoost는 현재 기준 모델이 아니라 추가 개선 후보로 관리

해석:

- Warm은 같은 작가의 과거 거래가 있으므로 가격 기준선을 더 직접적으로 잡을 수 있음
- Cold는 같은 작가 기준선이 약하므로 단일 가격보다 예측 범위와 신뢰도 차이를 함께 표시해야 함
- CatBoost는 대칭 트리 구조상 조건 조합 해석에 장점이 있으나, 현재 v0.1에서는 대표 모델이 아니라 보조 개선 후보
- 기존 저장 artifact의 Warm Huber, Cold LightGBM/CatBoost 파일은 baseline과 smoke test 용도이며, v0.1 현재 기준 후보 자체로 해석하지 않음

| 구분 | 현재 판단 | 근거 | 판단 메모 |
|---|---|---|---|
| Warm 모델 | Huber 유지 | 같은 작가 이력이 있어 작가 기준선과 크기 효과를 선형 계수로 설명 가능 | Warm CatBoost/LightGBM 대체는 현 단계 대표 후보로 두지 않음 |
| Warm 피처 | 작가, 크기, 재료/지지체, 유사 작품 기반 가격 피처 유지 | 작가/크기가 핵심이고 유사 작품 기반 가격 피처 추가 후 성능이 크게 개선 | 재료/지지체는 원본 피처와 조합 피처를 함께 쓰는 현재 구조 유지 |
| Warm 현재 후보 | 유사 작품 기반 가격 피처 70% + 오차 안정화 후보 30% 결합 | MdAPE, MAPE, p95_APE가 함께 개선 | 직접 비교군 가격값만 쓰는 방식은 단독 적용하지 않음 |
| Cold 모델 | LightGBM Quantile 중심 | q10/q50/q90과 qwidth로 예측 불확실성을 함께 해석 가능 | Cold는 단일 가격보다 범위와 신뢰도 중심으로 사용 |
| Cold 보조 모델 | CatBoost 보조 유지 | 조합 bucket과 조건 분리에 강점 | 단독 1순위보다 구간 해석, 잔차 보정, 보조 후보로 활용 |

핵심 수치:

| 구분 | 실험 내용 | MdAPE | MAPE | p95_APE | 판단 |
|---|---|---:|---:|---:|---|
| Warm 기준선 | 유사 작품 기반 가격 피처를 넣기 전 Huber 기준 모델 | 0.2274 | 0.4952 | 2.0130 | 개선 전 기준 |
| Warm 피처 추가 | 유사 작품 기반 숫자 가격 피처를 Huber 입력에 추가 | 0.1528 | 0.2956 | 0.9694 | 핵심 개선 신호 |
| Warm 현재 후보 | 유사 작품 기반 가격 피처 70% + 오차 안정화 30% 결합 | 0.1405 | 0.2748 | 0.8331 | 현재 Warm 1순위 |
| Cold 기준선 | 작품 조건 중심 LightGBM 기준 모델 | 0.4909 | 1.4131 | 4.8212 | 작품 조건만으로는 한계 |
| Cold 피처 통합 | 작가 메타, 전시/갤러리, 검색 피처를 통합한 LightGBM Quantile | 0.4421 | 1.0484 | 3.3537 | Cold 보수적 기준선 |

| Cold 추가 개선 | qwidth 상위 구간 + LightGBM q40 + 예측 gap 기준 제한 보정 | 0.4178 | 0.9640 | 2.5377 | 추가 개선 후보, v0.1 기준에는 미반영 |

## 2. 평가 기준

평가 우선순위는 후보를 기계적으로 고르는 절대 순위가 아니다.

- MdAPE를 1차로 확인
- MAPE, p95_APE, RMSE_log로 평균 오차와 큰 오차 위험 확인
- holdout, bootstrap, OOF 결과로 한 번의 우연인지 확인
- 한 지표만 좋아진 후보보다 여러 지표가 함께 안정적인 후보를 우선 검토

| 지표 | 의미 | 사용 이유 |
|---|---|---|
| MdAPE | 절대 비율 오차의 중앙값 | 일반적인 작품에서 대표 정확도 확인 |
| MAPE | 절대 비율 오차의 평균 | 큰 오차가 평균을 흔드는지 확인 |
| p95_APE | 절대 비율 오차 상위 5% 지점 | 크게 틀리는 끝단 위험 확인 |
| RMSE_log | 로그 가격 공간의 평균 제곱 오차 | 모델이 학습한 로그 가격 구조가 안정적인지 확인 |
| holdout/bootstrap/OOF | 데이터를 다시 나누거나 자기 자신을 직접 맞히지 않는 예측값 사용 | 후보가 과적합인지 확인 |

선정 원칙:

- Warm은 대표 정확도와 큰 오차 완화를 함께 봄
- Cold는 대표 정확도가 좋아도 p95 위험이 크면 단독 1순위로 보지 않음
- test에서만 좋아 보이고 반복 검증 안정성이 낮으면 기준 후보를 교체하지 않음

## 3. Warm 모델과 피처 판단

### 3.1 Huber를 유지하는 이유

- Warm 데이터 특성: 같은 작가의 과거 거래가 있어 작가별 가격 기준선을 직접 학습 가능
- Huber 모델 특성: 선형 모델이라 작가, 크기, 재료/지지체가 가격에 어떤 방향으로 작용하는지 설명 가능

Huber 예측식:

```text
pred_log_price = intercept + Σ(coefficient_j * transformed_feature_j)
pred_price = exp(pred_log_price)
```

Huber 손실의 의미:

```text
residual = actual_log_price - pred_log_price

if abs(residual) <= delta:
    loss = 0.5 * residual^2
else:
    loss = delta * (abs(residual) - 0.5 * delta)
```

해석:

- 작은 오차는 정밀하게 학습
- 큰 오차는 영향력을 완만하게 제한
- 고가/저가 특이 작품이 전체 계수를 과도하게 흔드는 문제 완화

### 3.2 Warm 기준 피처

| 피처 그룹 | 주요 피처 | 역할 | 현재 판단 |
|---|---|---|---|
| 작가 기준선 | `artist_key` | 같은 작가의 과거 가격 수준 반영 | 핵심 유지 |
| 크기 | `width_cm`, `height_cm`, `area_cm2`, `log_area` | 작품 규모에 따른 가격 중심선 조정 | 핵심 유지 |
| 깊이/입체 | `depth_cm`, `has_depth`, `is_3d_candidate` | 입체/깊이 조건 보조 | 특이 작품 설명용 유지 |
| 형태 | `aspect_ratio`, `is_extreme_aspect_ratio` | 극단적 가로세로 비율 보조 | 보조 유지 |
| 재료/지지체 | `medium_category`, `support_category`, `medium_support_bucket` | 재료와 바탕 조합 차이 보조 | 현재 구조 유지, 희소 조합 안정화 효과 확인 |

재료/지지체 피처 정리:

- `medium_support_bucket`: 재료 대분류와 지지체 대분류를 결합한 조합 피처
- 생성 기준: `medium_category + support_category`
- 효과: 재료 또는 지지체를 따로 볼 때보다 “아크릴+캔버스”, “혼합재료+종이”처럼 실제 가격 차이가 생기는 조합을 직접 반영
- 희소 조합 처리: Warm Huber의 one-hot 처리에서 10건 미만 조합은 자동으로 희소 범주로 묶여 과도하게 세분화되는 위험을 줄임
- 원본만, 조합만, 현재 구조, 전체 제거 조건을 비교한 결과 현재 구조는 validation에서 MdAPE 1위는 아니지만 MAPE, p95_APE, RMSE_log 균형이 가장 안정적
- 조합 피처 단독은 validation MdAPE만 소폭 좋았지만 MAPE, p95_APE, RMSE_log가 악화되어 즉시 교체하지 않음

### 3.3 Warm 개선 흐름

| 단계 | 내용 | 결과 | 판단 |
|---|---|---|---|
| 기준 모델 | Huber에 작가, 크기, 재료/지지체, 형태 피처 사용 | MdAPE 0.2274 | 개선 전 기준 |
| 유사 작품 기반 가격 피처 추가 | 같은 작가/크기/재료 조건의 과거 가격 통계를 입력 피처로 추가 | MdAPE 0.1528 | 큰 폭 개선 |
| 유사 작품 기반 가격 피처와 오차 안정화 후보 결합 | 로그 가격에서 70:30으로 결합 | MdAPE 0.1405, MAPE 0.2748, p95 0.8331 | 현재 Warm 1순위 |

유사 작품 기반 가격 피처의 의미:

- 비슷한 작품의 과거 거래 가격을 요약한 값
- 예측값을 직접 대체하는 값이 아니라 Huber가 함께 학습하는 보조 피처
- 사람이 “비슷한 작품은 과거에 얼마였는가”를 참고하는 방식과 유사

Warm 현재 판단:

- Huber 유지
- 기존 Warm 기준 피처셋 유지
- 유사 작품 기반 숫자 가격 피처를 핵심 보강 피처로 유지
- 유사 작품 기반 가격 피처 70% + 오차 안정화 30% 결합을 현재 Warm 1순위로 유지

## 4. Cold 모델과 피처 판단

### 4.1 Cold의 기본 문제

Cold는 같은 작가의 학습 이력이 없거나 부족하다. Warm처럼 `artist_key`를 가격 기준선으로 직접 쓰기 어렵기 때문에 작품 조건, 작가 메타, 전시/갤러리, 검색 피처, 예측 불확실성을 함께 봐야 한다.

### 4.2 Cold 핵심 피처

| 피처 그룹 | 주요 피처 | 역할 |
|---|---|---|
| 작품 조건 | 크기, 재료, 지지체, 형태, 깊이 | 작품 자체의 물리적 가격 기준 |
| bucket 피처 | `size_bucket`, `medium_shape_bucket`, `support_size_bucket` 등 | 트리 모델이 조건 구간을 더 쉽게 나누도록 보조 |
| 작가 메타 | 작품 수, 팔로워, 출생연도, 국적, 판매 작품 수 | 작가 시장 지위 간접 보완 |
| 전시/갤러리 | 개인전, 단체전, 아트페어, 갤러리 tier | 활동성/시장 노출 보완 |
| 검색 피처 | 검색 결과 수, 미술 문맥 count, 검색 품질 | 외부 인지도와 정보 가용성 보완 |
| 불확실성 | `quantile_width`, `price_range_ratio` | 예측 위험 구간 판단 |

트리 모델에서 bucket 피처가 유리한 이유:

| 모델 특성 | bucket 피처가 돕는 부분 |
|---|---|
| 트리 모델은 조건 분기로 데이터를 나눔 | 크기 구간, 재료+형태, 지지체+크기처럼 의미 있는 조건을 미리 만들어주면 split 후보가 명확해짐 |
| LightGBM은 오차를 줄이는 leaf를 세밀하게 확장 | 연속값만 넣었을 때보다 특정 구간의 반복 오차를 더 쉽게 분리 |
| CatBoost는 대칭 트리 구조로 같은 깊이의 조건 조합을 반복 적용 | 조합 bucket이 있으면 규칙적인 경로에서 작품 유형을 나누기 쉬움 |
| Cold는 작가 기준선이 약함 | 작가 정보가 부족한 대신 작품 조건 조합으로 가격 구간을 보완 |
| 주의점 | bucket이 너무 많거나 원본 피처와 과하게 겹치면 과적합 또는 중복 위험이 있어 안정성 확인 필요 |

### 4.3 Cold 검색 피처

- 현재 성능표에 반영된 검색 피처: 저장된 운영형 검색/외부 피처 snapshot을 작가 단위로 집계한 값
- 성능표 기준: 특정 실시간 검색 API 호출 결과가 아니라 실험 당시 저장된 snapshot 기준으로 해석
- 현재 운영형 수집 구조: Python DuckDuckGo 계열 provider를 기본으로 사용하고, Naver 블로그/뉴스/웹문서 공식 API는 인증값이 있을 때 병합/검증 가능한 provider로 관리
- 처리 방식: provider별 검색 결과를 표준화한 뒤 결과 수, 미술 문맥 수, source 다양성, 동명이인 위험을 작가별 피처로 변환

| 항목 | 기준 |
|---|---|
| 검색어 | 한글 작가명은 `{작가명} 작가 미술 전시`, 영문명은 `{artist_name} artist art exhibition` |
| 검색 결과 수 | 포털 전체 검색 결과 수가 아니라 수집 스크립트가 가져온 제한된 상위 결과 row 수 |
| 미술 문맥 count | 제목, snippet, URL에 미술/작가/전시/갤러리 관련 키워드가 포함된 결과 수 |
| source 수 | 검색 결과 URL의 고유 도메인 수 |
| 검색 품질 | 미술 문맥, source 다양성, 동명이인 위험을 함께 반영 |

검색 품질 등급:

| 등급 | 기준 | 의미 |
|---|---|---|
| high | 미술 문맥 결과가 충분하고 동명이인 위험이 낮음 | 비교적 안정적인 검색 신호 |
| medium | 일부 미술 문맥 신호가 있음 | 제한적으로 사용 가능 |
| low | 결과가 부족하거나 동명이인/비미술 문맥 위험 존재 | 보수적으로 사용 |
| missing | 검색 결과 없음 | 검색 신호 없음 |

### 4.4 Cold 모델 판단

LightGBM Quantile은 q10, q50, q90을 예측한다.

```text
quantile_width = q90_log - q10_log
price_range_ratio = exp(q90_log) / exp(q10_log)
```

해석:

- q50은 중앙 가격 예측
- q10~q90 폭은 가격 불확실성
- `quantile_width`가 클수록 모델이 해당 작품을 불확실하게 본다는 의미
- Cold는 작가 기준선이 약하기 때문에 단일 가격보다 가격 범위와 위험 구간을 함께 보는 방식이 적합

Cold 개선 흐름:

| 단계 | 내용 | MdAPE | MAPE | p95_APE | 판단 |
|---|---|---:|---:|---:|---|
| 작품 조건 중심 LightGBM | 작품 조건만 사용 | 0.4909 | 1.4131 | 4.8212 | 한계 확인 |
| 외부 피처 통합 LightGBM Quantile | 작가 메타, 전시/갤러리, 검색 피처 추가 | 0.4421 | 1.0484 | 3.3537 | Cold 보수적 기준선 |
| qwidth 기반 반복 오차 보정 | q90-q10 폭이 큰 구간을 보정 | 0.4247 | 0.9910 | 3.3053 | 안정성 확인 후보 |
| qwidth 상위 구간 + LightGBM q40 + 예측 gap 기준 제한 보정 | 과대 예측 위험 구간을 제한적으로 보정 | 0.4178 | 0.9640 | 2.5377 | 추가 개선 후보, v0.1 기준에는 미반영 |

Cold 현재 판단:

- LightGBM Quantile을 중심 모델로 유지
- CatBoost는 단독 대표 모델보다 조합 구간 해석, residual 보정, segment 보정 후보로 유지
- qwidth 상위 구간, q40 예측, 예측 gap을 함께 쓰는 보정은 성능 개선 신호가 있으나, v0.1 기준은 반복 안정성이 확인된 qwidth 기반 보정으로 유지

### 4.5 순차 조합 실험 확인

CatBoost Quantile -> Huber -> CatBoost 잔차 보정 순차 실험 해석:

- 실험 구조: CatBoost Quantile로 q10/q50/q90과 불확실성 폭을 먼저 만들고, 해당 값을 Huber 입력 피처로 추가한 뒤, 남은 Huber 예측 오차를 CatBoost로 한 번 더 보정
- 해석 포인트: Quantile은 가격 범위와 위험 폭을 만들고, Huber는 안정적인 중심 가격을 잡고, CatBoost는 Huber가 놓친 비선형 잔차를 조정하는 구조
- 적용 결과: Warm에서는 기준 Huber보다 분명한 개선 신호가 있었지만, Cold에서는 큰 오차 위험이 커져 v0.1 기준으로 채택하지 않음

| 실험 내용 | test MdAPE | test MAPE | test p95_APE | 판단 |
|---|---:|---:|---:|---|
| Warm Huber 기준 | 0.2274 | 0.4952 | 2.0130 | Warm 순차 실험 비교 기준 |
| Warm CatBoost Quantile -> Huber -> CatBoost 잔차 보정 | 0.1777 | 0.3383 | 1.1047 | 기준 Huber 대비 개선, 다만 현재 Warm 1순위인 유사 작품 기반 결합 후보보다는 낮음 |
| Cold CatBoost 기준 | 0.5001 | 1.4341 | 4.1815 | Cold 순차 실험 비교 기준 |
| Cold CatBoost Quantile -> Huber -> CatBoost 잔차 보정 | 0.4682 | 1.3310 | 5.3208 | MdAPE/MAPE는 개선됐지만 p95_APE가 악화되어 v0.1 미채택 |
