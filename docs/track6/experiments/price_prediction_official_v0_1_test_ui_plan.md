# 가격 예측 서비스 공식 테스트 v0.1 화면 설계서

- 작성일: 2026-06-12
- 공식 버전: `price_prediction_v0.1`
- 테스트 화면: `/test/v0.1`
- 기준 API: `/api/v1`
- 문서 목적: 공식 테스트 v0.1에서 사용자가 입력값을 넣고, 보고서 기준 Warm/Cold 모델의 계산 흐름을 실제 서비스 관점에서 확인할 수 있는 화면 구조 정의

## 1. 화면 목표

- 사용자가 작가명과 작품 정보를 입력해 예상 가격을 확인할 수 있게 한다
- 사용자는 내부 용어인 `Warm`, `Cold`, `artist_key`, 실험 번호를 몰라도 된다
- 작가명이 여러 후보로 매칭될 때 후보 정보를 보고 선택할 수 있어야 한다
- 예측 결과는 가격만 보여주지 않고 가격 근거, 신뢰도, 유사작품, 계산 과정을 함께 보여준다
- 참고 예측의 경우 정확도가 낮을 수 있음을 과도하게 숨기지 않는다
- 예측이 지연될 때 로딩 상태를 명확히 보여준다
- 실제 판매가 피드백 입력까지 한 화면에서 확인할 수 있게 한다

## 2. 화면 전체 구조

```text
[상단]
  - 서비스명
  - 공식 테스트 v0.1 배지
  - 모델 상태 요약

[본문 2열]
  왼쪽: 입력 영역
    - 작가 확인
    - 작품 기본 정보
    - 크기/재료 정보
    - 고급 입력
    - 실행 버튼

  오른쪽: 결과 영역
    - 예측 결과 카드
    - 작가 확인 상태
    - 가격 근거 요약
    - 유사작품/유사작가
    - 계산 과정
    - 정보 보완 안내
    - 실제 판매가 피드백
```

모바일에서는 1열로 쌓는다.

## 3. 사용자 화면 표현

| 내부 표현 | 화면 표현 | 비고 |
|---|---|---|
| Warm | 이력 기반 예측 | 같은 작가 가격 이력이 충분한 경우 |
| Cold | 참고 예측 | 같은 작가 이력이 부족한 경우 |
| artist_key | 표시하지 않음 | 내부 식별자 |
| Quantile | 가격 범위 예측 | 설명 tooltip에서만 사용 가능 |
| Huber | 이상치에 강한 보정 | 계산 과정 상세에서 설명 |
| guard | 과대예측 방어 | 참고 예측 상세에서 설명 |
| search delta | 작가 검색 정보 보정 | 참고 예측 상세에서 설명 |

## 4. 입력 영역

### 4.1 작가 확인

입력 필드:

| 항목 | 필수 | 설명 |
|---|---:|---|
| 한글 작가명 | 조건부 | 한글 또는 영문 중 하나 필수 |
| 영문 작가명 | 조건부 | 한글 또는 영문 중 하나 필수 |
| 생년 | 선택 | 동명이인 구분에 도움 |

동작:

```text
1. 사용자가 작가명을 입력
2. 자동 또는 버튼 클릭으로 /api/v1/artists/resolve 호출
3. 후보가 1명이고 신뢰도가 충분하면 자동 선택
4. 후보가 여러 명이면 후보 카드 표시
5. 사용자가 후보를 선택하면 선택 상태 고정
```

작가 후보 카드 표시 항목:

- 작가명
- 생년
- 국적
- 학습 가격 이력 수
- 대표 작품 1~3개
- 매칭 신뢰도
- 동명이인 위험 안내

### 4.2 작품 기본 정보

| 항목 | 필수 | 역할 |
|---|---:|---|
| 작품명 | 권장 | 결과 저장, 중복 검수 |
| 제작연도 | 권장 | 작품 시기와 작가 경력 단계 |
| 작품 유형 | 권장 | Painting, Sculpture 등 |

### 4.3 크기/재료 정보

| 항목 | 필수 | 역할 |
|---|---:|---|
| 가로 cm | 필수 | 면적, 호수, 크기 구간 |
| 세로 cm | 필수 | 면적, 호수, 크기 구간 |
| 깊이 cm | 조건부 | 입체 작품 판단 |
| 매체 | 필수 | 재료별 가격 차이 |
| 지지체 | 필수 | canvas/paper/panel 등 |

크기 입력 즉시 표시:

```text
예측 대상 작품 크기
- 72.7 x 60.6cm
- 약 20호
- 면적 4,405.62cm2
```

### 4.4 고급 입력

초기에는 접어둔다.

| 항목 | 설명 |
|---|---|
| 작품 URL | 검수와 중복 확인 |
| 이미지 URL | 이미지 피처 후속 실험 후보 |
| 판매/전시 문맥 메모 | 검수용 |

## 5. 실행 버튼과 로딩

버튼 상태:

| 상태 | 화면 |
|---|---|
| 입력 부족 | 비활성 또는 `필수 정보 입력 필요` |
| 작가 후보 선택 필요 | `작가를 먼저 확인하세요` |
| 실행 가능 | `가격 예측 실행` |
| 실행 중 | spinner + `계산 중` |
| 완료 | 결과 카드 표시 |
| 실패 | 오류 안내와 재시도 |

로딩 표시:

```text
작가 확인 중
유사작품 통계 조회 중
검색 피처 확인 중
가격 예측 계산 중
계산 과정 저장 중
```

## 6. 결과 영역

### 6.1 예측 결과 카드

카드 우선순위:

1. route 표시
2. 예측 가격
3. 가격 범위
4. 신뢰도
5. 한 줄 가격 해석

이력 기반 예측 예시:

```text
이력 기반 예측
예상 가격 1,328만원
참고 범위 436만원 - 1,582만원
신뢰도 보통

같은 작가의 가격 이력과 유사작품 통계를 기반으로 기준가격을 만들고,
불확실성이 낮은 방향으로만 미세 보정했습니다.
```

참고 예측 예시:

```text
참고 예측
예상 가격 420만원
참고 범위 180만원 - 910만원
신뢰도 낮음

같은 작가 가격 이력이 부족해 작품 조건, 작가 메타, 검색 피처를 함께 사용한 참고 가격입니다.
실제 판매가와 차이가 클 수 있습니다.
```

### 6.2 가격 해석 카드

목적: 호당 참고가와 최종 예측가격의 차이를 설명한다.

표시 항목:

| 항목 | 설명 |
|---|---|
| 1차 시장 호당 참고가격 | 조건 유사 표본의 호당 중앙값 |
| 입력 작품 환산 총액 | 호당 참고가격 x 입력 작품 호수 |
| 모델 보정 후 예상가격 | 작가 이력, 유사작품, 보정값 반영 결과 |
| 예상가격 기준 호당가 | 최종 예상가격 / 입력 작품 호수 |

tooltip 문구:

```text
호당 참고가격은 유사 조건 작품들의 단순 시장 기준입니다.
최종 예상가격은 작가 이력, 유사작품 통계, 예측 모델 보정, 불확실성 방어를 반영한 값이라
호당 참고 총액과 다를 수 있습니다.
```

### 6.3 작가 확인 상태

표시 항목:

- 확인됨 / 확인 필요
- 매칭 신뢰도
- 동명이인 위험
- 같은 작가 가격 이력 수
- 선택된 작가 간략 정보

표현 예시:

```text
작가 확인: 확인됨
매칭 신뢰도: 1.00
동명이인 위험: 낮음
같은 작가 가격 이력: 21건
```

### 6.4 가격 근거 요약

표시 항목:

| 항목 | 설명 |
|---|---|
| 예측 방식 | 이력 기반 예측 또는 참고 예측 |
| 판단 기준 | route 결정 조건 |
| 사용 근거 | 같은 작가 가격 이력, 유사작품 통계, 검색 피처 등 |
| 부족 정보 | 제작연도, 지지체, 검색 피처 등 |

## 7. 유사작품/유사작가 영역

### 7.1 유사작품

표시 원칙:

- 같은 작가 + 재료/지지체 + 크기 유사 사례를 최우선 표시
- 제목이 있으면 반드시 제목 표시
- 제목이 없으면 `제목 정보 없음`으로 표시하되 원천 ID/URL을 내부 디버그에서 확인 가능하게 함
- 타 작가 사례는 `유사작품`이 아니라 `비슷한 조건의 참고 사례`로 표시

tooltip:

```text
유사작품은 같은 작가를 우선하고, 재료/지지체와 크기가 가까운 작품을 먼저 보여줍니다.
표본이 부족하면 조건을 넓혀 참고 사례를 표시합니다.
```

### 7.2 유사작가

표시 원칙:

- 같은 작가는 제외
- 가격 이력 5건 이상 작가 우선
- 생년대, 국적, 활동 단계, 주 사용 재료, 가격대가 가까운 후보 표시
- 가격 보정에 직접 사용했는지와 단순 참고인지 구분

tooltip:

```text
유사작가는 생년대, 국적, 활동 단계, 주 사용 재료, 가격대가 가까운 작가를 기준으로 선정합니다.
현재 화면에서는 주로 작가 비교와 참고 근거로 사용합니다.
```

## 8. 계산 과정 영역

초기에는 접어둔다. 사용자가 펼치면 단계별 계산을 보여준다.

이력 기반 예측 단계:

```text
1. 입력 피처 생성
2. 같은 작가 가격 이력 조회
3. 유사작품 통계 조회
4. 기준가격 생성
5. 방향 확률 계산
6. Huber 잔차 보정 계산
7. 위험도 기반 보정 상한 적용
8. 최종 가격 변환
```

참고 예측 단계:

```text
1. 입력 피처 생성
2. 작가 메타 조회
3. 검색 피처 snapshot 조회
4. LightGBM Quantile 가격 범위 예측
5. 과대예측 방어 적용
6. 작가 검색 보정 적용
7. 최종 가격 변환
```

표시 형식:

| 단계 | 역할 | 식 | 결과 |
|---|---|---|---|
| 기준가격 생성 | 기준 로그가격 계산 | `기준가격 = ...` | `1,327만원` |
| 미세보정 | 보정값 계산 | `보정값 = ...` | `+1만원` |

## 9. 정보 보완 안내

입력 부족 또는 신뢰도 하향 사유를 사용자에게 설명한다.

예시:

```text
정확도를 높이는 방법
- 제작연도를 입력하면 작가 경력 단계와 작품 시기 판단에 도움이 됩니다.
- 지지체를 정확히 입력하면 재료/지지체 유사작품 기준이 개선됩니다.
- 실제 판매가를 나중에 입력하면 검수 후 모델 개선 후보로 활용할 수 있습니다.
```

## 10. 실제 판매가 피드백

예측 결과 하단에 표시한다.

필드:

| 항목 | 설명 |
|---|---|
| 실제 판매가 | 원화 기준 |
| 판매일 | 선택 |
| 판매 채널 | gallery/auction/direct/online 등 |
| 증빙 상태 | none/partial/verified |
| 학습 활용 동의 | 기본 true |
| 메모 | 검수자/사용자 메모 |

저장 후 표시:

```text
실제 판매가 피드백을 저장했습니다.
검수 승인 후 학습 후보로 승격할 수 있습니다.
```

## 11. 상태별 화면 정책

| 상태 | 가격 표시 | 안내 |
|---|---|---|
| 이력 기반 예측 성공 | 표시 | 기준가격과 미세보정 설명 |
| 참고 예측 성공 | 표시 | 참고 가격이며 정확도 낮을 수 있음 |
| 작가 후보 다수 | 숨김 | 후보 선택 요청 |
| 최소 입력 부족 | 숨김 | 부족 입력 표시 |
| 검색 피처 없음 | 표시 가능 | 낮은 신뢰도와 fallback 안내 |
| DB/cache 오류 | 숨김 | 시스템 상태 확인 요청 |
| 저장 실패 | 표시 가능 | 저장 실패 warning |
