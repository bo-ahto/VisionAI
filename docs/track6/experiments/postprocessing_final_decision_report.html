Cold는 점 예측 개선과 큰 오차 방어가 같은 방향으로 움직이지 않았다. 따라서 점 예측 모델과 위험 표시 모델을 분리하는 편이 낫다.

5. 모델별 예측 로직과 보정 의미

Warm Huber

pred_log_price = intercept + sum(beta_j * transformed_feature_j)
pred_price = exp(pred_log_price)
  • Huber는 선형 모델이므로 피처가 로그 가격에 더해지는 방향과 크기를 계수로 해석할 수 있다.
  • 큰 오차는 일정 기준 이후 영향력을 줄이기 때문에 고가 이상치가 많은 미술품 데이터에 적합하다.
  • Warm에서는 작가 기준선, 작품 크기, 재료/지지체가 주요 설명 축이다.
residual_log = actual_log_price - pred_log_price
corrected_pred_log = pred_log_price + correction_value
corrected_pred_price = exp(corrected_pred_log)

Cold CatBoost

pred_log_price = base_value + sum(each_tree_leaf_value)
pred_price = exp(pred_log_price)
  • CatBoost는 대칭 트리 구조라 피처 하나보다 피처 조합이 같은 leaf로 묶이는 방식이 중요하다.
  • Cold에서는 작가명 기준선이 없으므로 크기, 2D/3D, 재료/지지체 조합이 가격 구간을 만든다.
  • 그래서 전체 평균 보정보다 leaf 또는 segment별 residual 중앙값 보정이 더 자연스럽다.
segment_residual = actual_log_price - pred_log_price
segment_correction = median(segment_residual values in same leaf_or_segment)
corrected_pred_log = pred_log_price + segment_correction

Cold LightGBM

  • LightGBM은 leaf-wise 방식으로 손실을 크게 줄이는 leaf를 우선 확장한다.
  • 이번 split에서는 Cold 원 모델 기준 test 점 예측이 CatBoost보다 안정적이었다.
  • 따라서 Cold의 주 예측값은 LightGBM, 보조 위험 판단은 CatBoost/segment 보정으로 분리한다.
