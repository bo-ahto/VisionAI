Warm/Cold 가격 예측 모델 핵심 설명

이 문서는 상세 리포트 partner_warm_cold_official_v0_1_unified_model_report.html의 운영 설명용 축약본이다. 목표는 모델을 처음 보는 사람도 “어떤 입력이 어떤 경로로 가고, 어떤 피처를 쓰며, 가격이 어떤 계산으로 나오고, 검증 근거가 무엇인지”를 5장 안에서 이해하게 하는 것이다.

1. 운영 라우팅

입력 조건사용 경로의미
작가 매칭이 신뢰 가능하고, 같은 작가 가격 이력이 1건 이상 있음 Warm-lite current 작가의 실제 과거 거래/판매 가격 정보를 기준가격으로 직접 활용한다.
같은 작가 가격 이력이 없거나, 작가 매칭 신뢰가 부족함 Cold 보수 후보 적용 + 검색 보정 같은 작가 가격 이력을 직접 쓰지 못하므로 작품 정보, 작가 메타, 검색 기반 피처로 예측한다.
현재 기본 운영은 1건 이상 같은 작가 가격 이력을 하나의 Warm-lite current 계산 흐름으로 처리한다. 예전처럼 1~4건과 5건 이상을 서로 다른 Warm 모델로 나누지 않는다.

2. Warm과 Cold를 나누는 이유

Warm 같은 작가의 가격 이력을 쓸 수 있는 경우다. 과거 가격의 중앙값, 분위값, 면적 단가, 표본 수 같은 직접적인 가격 근거가 있으므로 예측 난이도가 낮다.
Cold 같은 작가 가격 이력을 직접 쓸 수 없는 경우다. 작품 크기, 재료, 지지체, 작가 메타, 검색 피처를 통해 간접적으로 가격을 추정하므로 난이도가 높다.

Page 2 · Warm 모델

Warm: 같은 작가 가격 이력을 쓰는 예측

Warm은 작가가 신뢰도 높게 매칭되고 같은 작가 가격 이력이 1건 이상 있을 때 사용한다. 핵심은 “같은 작가의 유사 작품 가격 통계로 기준가격을 만들고, 작품 조건과 모델 보정으로 과도한 오차를 줄이는 것”이다. 사용하는 모델은 두 개다. ① 기준가격을 만드는 LightGBM Quantile 회귀, ② 그 위에 남은 오차를 작게 보정하는 LightGBM Huber residual 회귀다.

Page 3 · 사용 피처

가격 예측에 사용하는 피처

피처는 모델에 넣는 입력 정보다. Warm과 Cold는 같은 작품 기본 정보를 쓰지만, Warm은 같은 작가의 과거 가격 이력을 직접 쓰고, Cold는 같은 작가 가격 이력을 쓰지 못해 작가 메타와 검색 기반 정보를 더 많이 사용한다.

1. Warm 사용 피처

피처 묶음구체 항목가격 계산에서 하는 역할
작품 크기 가로, 세로, 깊이, 면적, 로그 면적, 가로세로 비율, 입체 여부 같은 작가라도 크기와 형태가 다르면 가격 수준이 달라지므로 기준가격과 보정값에 반영한다.
재료/지지체 매체 분류, 지지체 분류, 매체+지지체 조합 캔버스, 종이, 혼합재료 등 제작 조건 차이를 반영한다.
크기/형태 구간 크기 구간, 형태 구간, 매체+형태 조합, 지지체+크기 조합 연속 숫자인 크기 정보를 모델이 더 안정적으로 해석하도록 구간화한다.
같은 작가 가격 이력 로그가격 중앙값, q25, q75, IQR, 면적단가 중앙값, 면적단가 IQR, 표본 수, 매칭 단계 Warm의 핵심 근거다. 같은 작가의 과거 가격 분포를 기준가격 생성에 직접 사용한다.
Quantile 예측값 낮은값 q10, 중앙값 q50, 높은값 q90, 전체 피처 q50, 안정 피처 q50 가격의 중심과 예측 불확실성을 만든다. 기본 Warm 가격은 두 q50의 평균을 중심으로 삼는다.
잔차 보정 입력 작품 피처, 작가 이력 피처, Quantile 예측값, 예측 불확실성 폭 기준가격에서 남은 오차를 LightGBM Huber residual 모델이 작게 보정한다.

2. Cold 사용 피처

피처 묶음구체 항목가격 계산에서 하는 역할
작품 조건 가로, 세로, 깊이, 면적, 비율, 매체, 지지체, 크기/형태 구간 같은 작가 이력이 없을 때 작품 자체 조건으로 기본 가격대를 추정한다.
작가 메타 작가 등록 여부, 작가 식별 상태, 작가 관련 외부/내부 메타 가용성 작가 정보가 충분한지, 신뢰 가능한 예측인지 판단하는 데 사용한다.
검색 기반 피처 작가명 검색 커버 여부, 검색 기반 가격 신호, 검색 결과 품질 상태 같은 작가 가격 이력을 직접 쓰지 못할 때 시장 기준가격을 보완한다.
Cold Quantile 예측값 q10, q40, q50, q90, q90 - q10 대표 가격과 보수 가격 후보, 예측 불확실성 폭을 만든다.
검수/신뢰도 피처 예측 불확실성 폭, 모델 간 차이, 검색 커버 여부 high/low/review 표시와 보수 후보 적용 여부를 결정한다.

3. 피처 해석에서 주의할 점

  • Warm의 같은 작가 가격 이력은 입력 작품 자기 가격을 직접 참조하지 않도록 fold/hold-out으로 누수를 차단해 만든다.
  • Cold는 같은 작가 가격 이력을 직접 쓰지 않으므로 Warm보다 불확실성이 크고, 검색/메타/검수 피처의 역할이 커진다.
  • Quantile의 q90 - q10은 모델이 보는 가격 범위의 폭이며, 폭이 클수록 예측이 더 불확실하다는 뜻이다.

Page 4 · Cold 모델

Cold: 같은 작가 가격 이력이 없을 때의 예측

Cold는 같은 작가 가격 이력을 직접 기준가격으로 쓸 수 없는 입력을 처리한다. Warm보다 불확실성이 크기 때문에 점예측만 만들지 않고, 검색 기반 기준가격, Quantile 불확실성, 보수 후보 적용 조건, 신뢰도 표시를 함께 사용한다. 학습되는 모델은 하나다 — 작품·작가 메타·검색 피처로 가격 분포를 예측하는 LightGBM Quantile 회귀(q10/q40/q50/q90). 그 위에 ① 구간별 잔차 보정, ② 과대예측 방어, ③ 작가 검색 보정 세 후처리 층을 얹는데, 이 셋은 별도 학습 모델이 아니라 검증 단계에서 고정한 보정표(lookup)와 규칙이다.

1. Cold 학습 단계

[Cold 학습 데이터 구성]
같은 작가 가격 이력을 직접 쓰지 않는 조건으로 학습/검증 데이터 구성
        |
        v
[피처 생성]
작품 크기/면적/형태, 매체, 지지체, 작가 메타, 작가명 검색 결과,
검색 커버 여부, 검색 기반 가격 신호
        |
        v
[모델 — LightGBM Quantile 회귀 학습]
  - 작품/작가 메타/검색 피처로 q10/q40/q50/q90 가격 분포 예측
  - q90 - q10으로 예측의 불확실성 폭 계산
  - 학습되는 모델은 이 하나뿐
        |
        v
[구간별 잔차 보정표 산출 (lookup, 모델 아님)]

  - 새 모델이 아니라 구간별 고정 보정값 표
        |
        v

        |
        v
[작가 검색 보정표 동결 (lookup, 모델 아님)]
  - 작가별 검색 문맥 보정값(±0.2)을 검증 스냅샷에서 고정

3. 핵심 산식

Quantile 예측의 불확실성 폭 = q90 - q10

대표로그가격 =
    검색_q50
  + clip(qwidth_bucket별_OOF_median_residual, -0.25, +0.25)

보수 후보 적용 조건 =
    불확실성폭 >= 1.4612207078910142
    AND 대표로그가격 - LGBM_q40 >= 0.07715547281151025
    AND LGBM_q40 < 대표로그가격

보수후보적용_로그가격 =
    0.50 * 대표로그가격 + 0.50 * LGBM_q40, if 보수 후보 적용 조건 통과
    대표로그가격, otherwise

최종 Cold 로그가격 =
    보수후보적용_로그가격 + 검색delta_lookup

4. 보수 후보 적용 조건의 성능 효과

이 조건은 Cold가 만든 대표 가격을 항상 낮추는 규칙이 아니다. 예측 불확실성이 크고, q40 보수 후보가 대표 가격보다 충분히 낮은 경우에만 대표 가격과 q40을 섞는다. 조건을 쓰지 않으면 검색 보정은 유지하되 대표 가격을 그대로 사용한다.

비교 기준MdAPEMAPEp95 APE해석
보수 후보 적용 없음 + 검색 보정 0.412921 0.875749 2.937449 검색 보정만 적용한 기준
보수 후보 적용 + 검색 보정 0.409820 0.849260 2.346465 현재 Cold 최종 기준
  • 보수 후보 적용 조건을 쓰면 MdAPE는 0.003101, MAPE는 0.026489, p95 APE는 0.590984 낮아진다.
  • 개선 폭은 특히 p95 APE에서 크다. 즉 이 조건은 일반적인 중앙 오차보다 큰 오차 방어에 더 큰 역할을 한다.

5. 신뢰도와 검수 표시

2. 학습 데이터가 늘면 Warm이 좋아지는가

별도 learning curve 실험에서 fixed test split은 고정하고 Warm train split만 25%, 50%, 75%, 100%로 늘렸다. 모든 비율에서 Warm 처리가 가능한 동일 test cohort 기준으로 비교했기 때문에, 단순히 평가 대상이 바뀌어서 좋아진 것이 아니라 학습 데이터 증가 효과를 본 실험이다.

3. 운영 설명 문장

현재 official 0.1v 가격 예측은 먼저 같은 작가 가격 이력을 쓸 수 있는지 판단한다.
작가 매칭이 신뢰 가능하고 같은 작가 가격 이력이 1건 이상이면 Warm-lite current 모델을 사용한다.
Warm은 같은 작가 가격 통계와 작품 피처로 Quantile 기준가격을 만들고, Huber residual 보정을 더해 최종 가격을 정한다.

같은 작가 가격 이력을 직접 쓰기 어렵거나 작가 매칭이 불확실하면 Cold 경로를 사용한다.
Cold는 작품 조건, 작가 메타, 검색 피처로 가격 분포를 예측하고, 불확실성이 큰 경우 보수 후보를 조건부로 섞으며, 신뢰도와 검수 필요 여부를 함께 표시한다.

두 경로 모두 운영 반영 전 동결 산출물 재현성 검증과 official 0.1v API parity 검증을 통과해야 한다.

4. 주의할 해석

  • Warm 성능과 Cold 성능은 같은 문제를 푼 결과가 아니므로 직접 우열 비교하지 않는다.
  • Cold는 같은 작가 가격 이력을 직접 쓰지 못해 본질적으로 불확실성이 더 크다.
  • 임계값과 보정 폭은 운영 중 매 요청마다 다시 최적화하지 않고, 검증 실험에서 선택한 값을 동결해 재현성을 확보한다.
  • 새 학습 데이터 추가는 자동 승격이 아니라 재학습, hold-out 검증, parity 검증을 통과한 뒤 운영 반영한다.

5. 보조 운영 모드

현재 기본 Warm은 Warm-lite current다. 다만 큰 오차 방어를 우선해야 하는 상황에 대비해, 같은 Warm-lite 모델 산출물 안에서 더 강한 잔차 보정 후보를 조건부로 선택하는 보조 운영 모드를 남겨 둔다. 이 보조 모드는 기본 설명 흐름에는 포함하지 않으며, 운영자가 환경변수로 명시했을 때만 사용한다.
