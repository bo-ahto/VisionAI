# 유사 작품/유사 작가 서비스 기준 정리

- 작성일: 2026-06-11
- 기준 실험: `PP-SA1_similar_artist_artwork_grouping`
- 목적: 가격 예측 화면에서 유사 작품, 유사 작가, 유사 작가의 유사 작품을 어떤 기준으로 계산하고 노출할지 정의한다.

## 1. 실험 결론

- 유사 작품 기준은 이미 Warm에서 성능 개선 신호가 강하게 확인됐다.
- 유사 작가+작품 기준가는 단독 예측값으로 쓰기에는 부족했다.
- Warm direct 기준에서는 기존 유사 작품 기준가에 유사 작가 기준가를 10~20%만 섞을 때 MdAPE와 MAPE가 함께 개선됐다.
- Cold에서는 유사 작가+작품 기준가가 단독으로 악화됐다.
- 따라서 현재 서비스 적용 방향은 다음과 같다.

| 구분 | 운영 적용 |
|---|---|
| 유사 작품 | 가격 근거와 참고 작품 노출에 적극 사용 |
| 유사 작가 | 작가 확인/비교 설명에 사용 |
| 유사 작가의 유사 작품 | Cold 또는 이력 부족 작가의 참고 사례로 사용 |
| 유사 작가 기준가 | 최종 예측가격 대체 금지, Warm에서 제한적 보정 후보로만 후속 검증 |

## 2. 유사 작품 기준

유사 작품은 기본적으로 같은 작가의 과거 거래 작품을 우선한다.

| 등급 | 기준 | 최소 표본 | 화면 표현 |
|---|---|---:|---|
| 강한 유사 작품 | 같은 작가 + 같은 재료/지지체 + 비슷한 크기 | 5건 | 유사도가 높은 참고 작품 |
| 중간 유사 작품 | 같은 작가 + 비슷한 크기 | 5건 | 크기가 비슷한 같은 작가 작품 |
| 넓은 작가 이력 | 같은 작가 전체 | 5건 | 같은 작가의 가격 이력 |
| 작품 조건 참고 | 같은 재료/지지체 + 비슷한 크기 | 30건 | 작가 무관 작품 조건 참고 |

크기 기준은 `log_area`를 학습 데이터 기준 분위 구간으로 나눈 `size_bucket`을 사용한다.

```text
작품면적_cm2 = 가로_cm * 세로_cm
로그면적 = log(작품면적_cm2)
크기구간 = 학습 데이터의 로그면적 분위 기준으로 q1~q5 구간화
```

재료/지지체 기준은 정규화된 `medium_category`, `support_category`, `medium_support_bucket`을 사용한다.

```text
재료_지지체_구간 = 정규화재료 + "__" + 정규화지지체
```

## 3. 유사 작가 기준

유사 작가는 같은 작가가 아닌 작가 중에서 작가 프로필과 시장 특성이 가까운 작가를 의미한다.

후보군 조건:

- 학습 데이터에 낙찰 이력이 5건 이상 있는 작가
- 입력 작가와 동일한 작가는 제외
- 유사도 점수 0.45 이상인 후보 중 상위 5명까지 표시
- 0.45 이상 후보가 없으면 전체 후보 중 상위 5명을 넓은 참고 후보로 사용

이력이 있는 작가의 유사도:

```text
유사도점수
  = 0.55 * 숫자형_유사도
  + 0.45 * 범주형_유사도
```

이력이 부족한 신규 작가의 유사도:

```text
유사도점수
  = 0.30 * 숫자형_유사도
  + 0.70 * 범주형_유사도
```

숫자형 유사도는 가격대, 면적당 가격, 작가 이력 수, 작가 메타 수치를 표준화 거리로 비교한다.

```text
표준화거리 = sqrt(mean(((후보값 - 대상값) / 표준편차)^2))
숫자형_유사도 = 1 / (1 + 표준화거리)
```

범주형 유사도는 아래 조건의 일치 여부를 가중합으로 계산한다.

| 조건 | 가중치 |
|---|---:|
| 생년대 | 0.20 |
| 국적 | 0.18 |
| 활동 단계 | 0.16 |
| 작가 가격대 등급 | 0.14 |
| 주 사용 재료 | 0.16 |
| 주 사용 지지체 | 0.10 |
| P1 작가 여부 | 0.04 |
| 해외 활동 여부 | 0.02 |

신규 또는 이력 부족 작가의 경우에는 대상 작가의 과거 가격대가 없기 때문에 입력 작품의 재료, 지지체, 크기와 후보 작가의 주 사용 재료, 주 사용 지지체, 일반적인 작품 크기를 중심으로 계산한다.

```text
입력작품면적_cm2 = 가로_cm * 세로_cm
입력작품_로그면적 = log(입력작품면적_cm2)
후보작가_일반크기 = 후보 작가 과거 작품의 log(면적_cm2) 중앙값
```

## 4. 유사 작가의 유사 작품 기준

유사 작가가 정해지면, 그 작가들의 작품 중 입력 작품과 조건이 가까운 작품을 다시 고른다.

| 등급 | 기준 | 최소 표본 | 화면 표현 |
|---|---|---:|---|
| 강한 참고 | 유사 작가 + 같은 재료/지지체 + 비슷한 크기 | 8건 | 유사 작가의 유사 작품 |
| 중간 참고 | 유사 작가 + 같은 재료 대분류 + 비슷한 크기 | 10건 | 재료와 크기가 가까운 유사 작가 작품 |
| 넓은 참고 | 유사 작가 + 비슷한 크기 | 15건 | 크기가 가까운 유사 작가 작품 |
| 작가군 참고 | 유사 작가 전체 | 20건 | 유사 작가군 가격 이력 |

## 5. 성능 결과

| 기준 | scope | MdAPE | MAPE | p95_APE | 해석 |
|---|---|---:|---:|---:|---|
| 유사 작품 direct 기준가 | Warm | 0.3100 | 0.7193 | 2.2352 | 단독 예측은 부족하지만 기존 SVC 피처로는 효과 확인 |
| 유사 작가+작품 direct 기준가 | Warm | 0.4035 | 0.6921 | 2.0382 | 중앙 오차는 악화, 평균/꼬리 오차는 소폭 개선 |
| 유사 작품 direct 기준가 | Cold | 0.5223 | 1.1957 | 3.8200 | Cold 참고 기준으로는 기존 작품 조건 기준이 더 적합 |
| 유사 작가+작품 direct 기준가 | Cold | 0.5780 | 1.4876 | 5.7293 | 가격 보정에는 부적합, 설명용 참고로 제한 |

| 후보 | MdAPE | MAPE | p95_APE | 해석 |

| 유사 작품 85% + 유사 작가+작품 15% | 0.2991 | 0.6718 | 2.0796 | direct 기준 내 최선 균형 |
| 유사 작품 80% + 유사 작가+작품 20% | 0.3074 | 0.6601 | 2.0350 | 평균/꼬리 방어 강화 |

## 6. 서비스 표시 정책

- 예측가격 산출에 직접 사용한 기준과 참고용 기준을 화면에서 구분한다.
- 같은 작가 + 재료/지지체 + 크기가 모두 맞는 경우만 `유사도가 높은 참고 작품`으로 표시한다.
- 유사 작가 기준은 `작가 비교 근거`로 표시하고, 가격을 직접 보정했다는 표현은 쓰지 않는다.
- Cold 또는 신규 작가 화면에서는 `비슷한 조건의 타 작가 거래 사례`로 표시한다.
- 표본 수가 부족하거나 조건이 넓어진 경우에는 `참고 범위가 넓음` 또는 `정확도 보완 필요`를 함께 표시한다.
- `1차 시장 가격` 카드는 입력 작품과 가까운 재료/지지체/크기의 호당가 중앙값, 사분위 범위, 매체별 분포, 표본 수를 표시한다.

```text
호수 = 면적_cm2 기반 환산값
호당가 = 거래가격_원화 / 호수
호당가_중앙값 = 조건 유사 표본의 median(호당가)
범위 = 조건 유사 표본의 25% 분위 호당가 ~ 75% 분위 호당가
```

## 7. 후속 실험

- `PP-SA2`에서 Warm 운영 후보 위에 유사 작가 기준가를 작은 보정값으로 붙여 검증했다.
- 공격적 validation 선택 후보는 test에서 MAPE와 RMSE는 소폭 개선했지만 MdAPE와 p95가 악화되어 채택하지 않는다.
- 보수적 서비스 후보는 test에서 MdAPE를 유지하면서 MAPE와 p95를 아주 작게 개선했다.

| 후보 | MdAPE | MAPE | p95_APE | 평균 보정폭 | 판단 |
|---|---:|---:|---:|---:|---|
| 기존 Warm 운영 후보 | 0.140976 | 0.269888 | 0.807325 | 0.000000 | 현재 기준 |
| 유사 작가 보수 보정 후보 | 0.140976 | 0.269835 | 0.807218 | 0.000467 | 반복 검증 후보 |

보수 보정 후보의 계산식:

```text
보정예측로그가격
  = 기존_Warm_운영예측로그가격
  + 0.08 * clip(
      유사작가_유사작품_기준로그가격 - 같은작가_유사작품_기준로그가격,
      -0.01,
      +0.01
    )
```

적용 gate:

- 유사 작가의 유사 작품 기준이 `유사 작가 + 같은 재료/지지체 + 비슷한 크기`일 때만 적용
- test 기준 적용 row: 358건 / 607건
- 평균 로그 보정폭: 0.000467

운영 판단:

- 현재 단계에서 최종 예측가격 계산 로직에 바로 편입하지 않는다.
- 서비스 화면에는 유사 작가와 유사 작가의 유사 작품을 참고 근거로 노출한다.
- 다음 검증에서 반복 split 또는 다른 기간 테스트에서도 같은 방향이면 제한적 보정 후보로 승격한다.
- Cold는 가격 보정은 보류하고 참고 사례 노출 품질만 우선 적용한다.
