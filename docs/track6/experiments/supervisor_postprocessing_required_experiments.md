# 후처리 진행 전/중 작성이 필요한 핵심 실험 정리

목적은 후처리 보정 실험을 무작정 적용하는 것이 아니라, 모델별 특성과 현재 예측 오차 구조에 맞게 어떤 보정을 해야 하는지 확인하는 것이다.

이번 후처리 실험은 크게 다음 순서로 진행한다.

```text
1. 후처리에 쓸 피처/구간이 타당한지 확인
2. Warm/Cold 기준 모델을 다시 확인
3. CatBoost 구분 학습이 보정값을 줄이는지 확인
4. 모델별/구간별 보정값을 상세하게 산출
5. 기본 보정과 모델별 커스텀 보정을 비교
6. 필요 시 남은 오차 모델, 모델 결합, 조건별 모델 선택으로 확장
7. 추천 보조 조합이 MAPE와 큰 오차를 줄이는지 확인
8. Huber/Quantile/CatBoost 순차 학습으로 MAPE 최적화 가능성을 확인
9. 최종적으로 가격 범위와 신뢰도 정책까지 연결
```

---

## 1. [PRE-PP-W / PRE-PP-CB / PRE-PP-LGB] 모델별 피처/구간 근거 검증 실험

후처리에서 사용할 구간이 실제로 모델 성능에 필요한지 먼저 확인한다.

### 실험 대상

1. Warm Huber
   - 기준 모델: `Huber(base_existing_combo)`
   - 확인 그룹:
     - 작가 정보
     - 작품 크기
     - 재료/지지체
     - 깊이/3D 여부
     - 형태/aspect 정보

2. Cold CatBoost
   - 기준 모델: `CatBoost(base_medium_shape)`
   - 확인 그룹:
     - 작품 크기
     - 깊이/3D 여부
     - 형태 구간
     - 재료 x 형태 구간

3. Cold LightGBM
   - 기준 모델: `LightGBM(base_support_size)`
   - 확인 그룹:
     - 작품 크기
     - 크기 구간
     - 지지체 x 크기 구간
     - 깊이/3D 여부

### 진행 방식

1. 기존 기준 피처셋으로 모델을 학습한다.
2. 특정 피처 그룹을 하나씩 제거하고 같은 데이터 분할 기준으로 다시 학습한다.
3. 제거 전/후 성능을 비교한다.
4. 제거했을 때 성능이 나빠지는 피처 그룹을 후처리 보정 기준 후보로 둔다.

### 확인할 결과

- 특정 피처 그룹 제거 후 MdAPE가 악화되는지 확인한다.
- 특정 피처 그룹 제거 후 p95_APE가 악화되는지 확인한다.
- 성능이 악화되는 그룹은 후처리 구간으로 사용할 근거가 된다.
- 성능 변화가 없는 그룹은 후처리 우선순위를 낮춘다.

### 후속 작업

- Warm은 크기/작가 학습량/예측 가격대 중심으로 보정할지 판단한다.
- Cold CatBoost는 leaf, 재료 x 형태, 2D/3D x 크기 중심으로 보정할지 판단한다.
- Cold LightGBM은 예측 가격대, 크기 구간, 지지체 x 크기 구간 중심으로 보정할지 판단한다.

## 2. [PRE-MODEL-WCB / PRE-MODEL-CCB] Warm/Cold CatBoost 적합성 검증 실험

현재 Warm 기준 모델은 Huber지만, CatBoost가 작가별 크기/재료 조합을 더 잘 나눌 가능성이 있어 추가 검증한다.

### 실험 대상

1. Warm 모델 비교
   - 기존 방식: `Huber(base_existing_combo)`
   - 추가 후보: Warm CatBoost
   - 후보 피처:
     - `base_existing_combo`
     - `artist_key + size`
     - `artist_key + size + material/support`

2. Cold 모델 비교
   - 기존 1순위: `CatBoost(base_medium_shape)`
   - 비교 후보: `LightGBM(base_support_size)`

### 진행 방식

1. 같은 고정 데이터 분할 기준을 사용한다.
2. 보정은 적용하지 않고 모델 원 예측 성능만 비교한다.
3. Warm에서는 Huber와 CatBoost의 성능 차이를 본다.
4. Cold에서는 CatBoost와 LightGBM의 성능 차이를 다시 확인한다.

### 확인할 결과

- Warm CatBoost가 Warm Huber보다 MdAPE 또는 p95_APE를 개선하는지 확인한다.
- Warm CatBoost가 특정 구간에서만 좋은지, 전체적으로도 좋은지 구분한다.
- Cold CatBoost가 Cold LightGBM보다 여전히 기본 모델로 적합한지 확인한다.

### 후속 작업

- Warm CatBoost가 유효하면 Warm 기준 모델 재선정 후보로 올린다.
- Warm CatBoost가 일부 구간에서만 좋으면 전체 교체가 아니라 조건부 적용 또는 보정 후보로 둔다.
- Cold CatBoost가 유지되면 CatBoost 중심 후처리를 계속 진행한다.
- Cold LightGBM이 특정 tail 구간에서 강하면 보조 모델 또는 신뢰도 정책에 연결한다.

## 3. [PRE-SPLIT-WCB / PRE-SPLIT-CCB] Warm/Cold CatBoost 구분 학습 보정 실험

전체 모델 하나로 학습하는 방식보다 조건별로 나누어 구분 학습하는 방식이 예측 오차와 보정값을 더 안정적으로 줄일 수 있는지 확인한다.

### 1. 전체 CatBoost 모델

- Warm 전체 또는 Cold 전체 데이터를 하나의 CatBoost 모델로 학습한다.
- 이후 구간별 보정값을 계산한다.

### 2. 구분 학습 CatBoost 모델

- 데이터를 조건별로 나눈다.
- 각 구간별 CatBoost 모델을 따로 학습한다.
- 이후 각 구간별 보정값을 계산한다.

### Warm CatBoost 구분 기준

- 작품 크기 구간별 CatBoost
- 작가 학습 작품 수 구간별 CatBoost
- 작가 x 작품 크기 구간별 CatBoost

### Cold CatBoost 구분 기준

- 작품 크기 구간별 CatBoost
- 2D/3D 후보 구간별 CatBoost
- 재료 x 형태 조합 구간별 CatBoost

### 진행 방식

동일한 고정 데이터 분할 기준으로 진행한다.

1. 학습 데이터를 구분 기준별로 나눈다.
2. 각 구간별 CatBoost 모델을 따로 학습한다.
3. 검증 데이터도 같은 기준으로 나눈다.
4. 각 검증 샘플은 자기 구간에 맞는 CatBoost 모델로 예측한다.
5. 실제 로그 가격과 예측 로그 가격의 차이를 계산한다.
6. 구간별 예측 오차 중앙값을 보정값으로 계산한다.
7. 전체 모델 방식과 구분 학습 방식의 성능 및 보정값 크기를 비교한다.

### 확인할 결과

- 구분 학습 CatBoost가 전체 CatBoost보다 MdAPE를 개선하는지 확인한다.
- 구분 학습 CatBoost가 p95_APE를 줄이는지 확인한다.
- 구분 학습 후 필요한 보정값의 절대 크기가 줄어드는지 확인한다.
- 특정 구간에서만 개선되는지, 전체적으로 개선되는지 구분한다.

### 후속 작업

- 구분 학습이 전체적으로 좋으면 모델 구조 자체를 구분 학습 방식으로 검토한다.
- 일부 구간에서만 좋으면 조건별 모델 선택 정책으로 연결한다.
- 성능 개선은 작지만 보정값이 줄어들면 후처리 안정성 후보로 둔다.
- 표본 수가 부족한 구간은 전체 모델 또는 상위 구간 보정값으로 대체한다.

## 4. [PRE-CAL-W / PRE-CAL-WCB / PRE-CAL-CB / PRE-CAL-LGB] 모델별 상세 보정값 산출 실험

후처리 적용 전에 모델별/구간별로 예측이 어느 방향으로 얼마나 치우치는지 먼저 확인한다.

### 기본 계산 방식

```text
pred_log = 모델이 예측한 로그 가격
residual_log = 실제 로그 가격 - 예측 로그 가격
segment_correction = 같은 구간 residual_log의 중앙값
corrected_pred_log = pred_log + segment_correction
```

### 산출 대상

1. Warm Huber
   - 전체 보정값
   - 예측 가격대별 보정값
   - 작품 크기 구간별 보정값
   - 작가 학습량 구간별 보정값

2. Warm CatBoost 후보
   - 예측 가격대별 보정값
   - 작품 크기 구간별 보정값
   - 작가 x 크기 구간별 보정값
   - CatBoost leaf 구간별 보정값

3. Cold CatBoost
   - CatBoost leaf 구간별 보정값
   - 재료 x 형태 구간별 보정값
   - 형태 구간별 보정값
   - 전체 보정값

4. Cold LightGBM
   - 예측 가격대별 보정값
   - 크기 구간별 보정값
   - 지지체 x 크기 구간별 보정값
   - 큰 오차 위험 구간별 보정값

### 확인할 결과

- 어떤 구간에서 반복적으로 높게 예측하는지 확인한다.
- 어떤 구간에서 반복적으로 낮게 예측하는지 확인한다.
- 구간별 표본 수가 충분한지 확인한다.
- 보정값이 지나치게 큰 구간은 과보정 위험 구간으로 표시한다.

### 후속 작업

- 표본 수가 충분한 구간만 실제 보정 후보로 둔다.
- 표본 수가 부족하면 상위 구간 보정값으로 대체한다.
- 보정값이 크고 불안정한 구간은 낮은 신뢰도 후보로 둔다.

## 5. [PP-A1~PP-A8] 기본 residual 보정 실험

상세 보정값을 바탕으로 가장 단순한 보정부터 먼저 적용한다.

### 실험 대상

1. 전체 예측 오차 보정
   - 전체 validation residual 중앙값을 한 번 더한다.

2. 예측 가격대별 보정
   - 예측 가격을 저가/중가/고가 구간으로 나누고 구간별 보정값을 적용한다.

3. 작품 크기 구간별 보정
   - 크기 구간별 반복 오차를 보정한다.

4. 재료/지지체 구간별 보정
   - 특정 재료/지지체에서 반복되는 오차를 보정한다.

5. Warm 작가 학습량 구간 보정
   - 학습 작품 수가 적은 Warm 작가의 반복 오차를 보정한다.

6. Cold 메타 정보량 구간 보정
   - 메타 정보가 부족한 Cold 작품의 반복 오차를 보정한다.

### 확인할 결과

- 단순 보정만으로 MdAPE가 개선되는지 확인한다.
- p95_APE가 악화되지 않는지 확인한다.
- 특정 구간의 성능 개선이 전체 성능 악화로 이어지지 않는지 확인한다.

### 후속 작업

- 단순 보정이 충분하면 복잡한 커스텀 보정은 보류한다.
- 단순 보정 후에도 특정 모델/구간 문제가 남으면 모델별 커스텀 보정으로 넘어간다.

## 6. [PP-J1~PP-J6] 모델별 커스텀 보정 실험

기본 보정으로 해결되지 않는 문제 구간에 대해서만 모델 구조에 맞춘 보정을 적용한다.

### Warm Huber 커스텀 보정

- 큰 오차 구간 보정
- 피처별 계수 기여도 구간 보정
- 크기 기여도, 작가 기여도, 재료/지지체 기여도가 큰 구간을 따로 확인한다.

### Warm CatBoost 커스텀 보정

- CatBoost leaf 구간 보정
- 작가 x 크기 구간 보정
- 표본 수가 부족한 leaf는 크기 구간 또는 전체 보정으로 대체한다.

### Cold CatBoost 커스텀 보정

- CatBoost leaf별 보정
- 재료 x 형태 구간 보정
- 2D/3D x 크기 구간 보정
- leaf 표본 수를 기준으로 보정 가능 여부와 신뢰도를 함께 판단한다.

### Cold LightGBM 커스텀 보정

- 고가 예측 구간 보정
- 작은 leaf 위험 구간 보정
- 지지체 x 크기 구간 보정
- p95_APE가 큰 tail 구간을 우선 확인한다.

### 확인할 결과

- 기본 보정보다 모델별 커스텀 보정이 더 안정적인지 확인한다.
- p95_APE가 줄어드는지 확인한다.
- 보정값이 너무 커져 과보정되지 않는지 확인한다.

### 후속 작업

- 효과가 있으면 해당 모델의 후처리 정책 후보로 둔다.
- 효과가 특정 구간에만 있으면 전체 적용이 아니라 조건부 적용으로 둔다.
- 효과가 없으면 기본 residual 보정 또는 가격 범위/신뢰도 정책으로 대체한다.

## 7. [PP-B1~PP-B5] 남은 오차 보정 모델 실험

기본 보정과 커스텀 보정으로도 남는 오차가 별도 모델로 학습 가능한지 확인한다.

### 진행 방식

1. 학습 데이터를 내부 교차 방식으로 나눈다.
2. 각 fold에서 자기 자신을 학습하지 않은 모델로 예측값을 만든다.
3. 이 예측값을 OOF 예측값으로 사용한다.
4. OOF 예측값과 실제값의 차이를 남은 오차로 계산한다.
5. Ridge, Huber, LightGBM 보정 모델이 남은 오차를 학습할 수 있는지 확인한다.

### 확인할 결과

- 남은 오차 모델이 validation에서만 좋아지는지 확인한다.
- test에서 재현되는지 최종 후보만 확인한다.
- 복잡한 오차 모델이 과적합되는지 확인한다.

### 후속 작업

- 단순 Ridge 보정이 충분하면 복잡한 LightGBM 오차 모델은 보류한다.
- validation만 좋아지고 test에서 무너지면 채택하지 않는다.

## 8. [PP-D1~PP-D5 / PP-E1~PP-E5] 모델 결합 및 조건별 모델 선택 실험

단일 모델보다 여러 모델의 예측값을 결합하거나 조건별로 모델을 선택하는 방식이 안정적인지 확인한다.

### 모델 결합 실험

- Warm Huber와 Warm CatBoost 후보의 예측값 결합
- Cold CatBoost와 Cold LightGBM의 예측값 결합
- 단순 평균과 가중 평균을 비교한다.
- 1차 비교는 보정 전 `pred_log` 기준으로 진행한다.

### 조건별 모델 선택 실험

- Warm 저이력 작가 구간에서 Warm 방식과 Cold 방식을 비교한다.
- Cold 메타 부족 구간에서 CatBoost와 LightGBM/보수 모델을 비교한다.
- 극단 크기 구간에서 기본 모델과 크기 보정 모델을 비교한다.
- 재료/지지체 미분류 구간에서 fallback 기준을 확인한다.

### 확인할 결과

- 단일 모델보다 결합 모델이 p95_APE를 줄이는지 확인한다.
- 특정 조건에서만 다른 모델이 더 좋은지 확인한다.
- 전체 적용보다 조건부 적용이 더 안정적인지 확인한다.

### 후속 작업

- 결합이 전체적으로 좋으면 평균/가중 평균 후보로 둔다.
- 특정 조건에서만 좋으면 조건별 모델 선택 정책으로 둔다.

## 9. [PP-K1~PP-K10] 추천 보조 조합 검증 실험

기본 모델과 일반 보정만으로 MAPE나 큰 오차가 충분히 줄지 않을 경우, 모델 특성이 다른 후보를 조합해서 추가 개선 가능성을 확인한다.

이 실험은 모델을 무작정 늘리는 것이 아니라, 각각의 역할을 명확히 나누어 검증한다.

### PP-K1. Quantile 가격 범위 보조 모델

- 목적:
  - 단일 예측 가격만으로 불안정한 작품에 대해 하한/상한 가격 범위를 함께 만들 수 있는지 확인한다.
- 진행 방식:
  - Warm/Cold 기준 피처셋으로 중앙 예측 모델과 하위/상위 분위 예측 모델을 만든다.
  - 실제 가격이 예측 범위 안에 들어오는 비율과 범위 폭을 함께 확인한다.
- 확인할 결과:
  - 가격 범위가 실제 가격을 충분히 포함하는지 확인한다.
  - 범위가 너무 넓어 실무적으로 의미가 없어지는지 확인한다.
- 후속 작업:
  - 정확도 개선용보다는 가격 범위와 신뢰도 표시 정책에 연결한다.

### PP-K2. Ridge/ElasticNet 선형 기준선 비교

- 목적:
  - Warm Huber가 현재 선형 기준 모델로 적합한지 다시 확인한다.
  - Huber가 아닌 단순 규제 선형 모델이 더 안정적인 구간이 있는지 확인한다.
- 진행 방식:
  - Warm `base_existing_combo` 피처를 그대로 고정한다.
  - Huber, Ridge, ElasticNet을 같은 데이터 분할과 같은 평가 기준으로 비교한다.
- 확인할 결과:
  - Huber가 MdAPE와 p95_APE에서 유지할 만한 근거가 있는지 확인한다.
  - Ridge/ElasticNet이 더 안정적이면 Warm 기준 모델 재선정 후보로 둔다.
- 후속 작업:
  - Huber 유지 근거가 명확하면 후처리 설명 문서에 반영한다.
  - 다른 선형 모델이 더 좋으면 Warm 기준 모델 재선정 실험으로 연결한다.

### PP-K3. 유사 작품 fallback 예측

- 목적:
  - 모델 예측이 불안정한 작품에서 유사 작품 가격 중앙값을 보조 기준으로 쓸 수 있는지 확인한다.
- 진행 방식:
  - 작가, 작품 크기, 재료/지지체, 형태가 비슷한 과거 작품을 찾는다.
  - 유사 작품 로그 가격 중앙값과 모델 예측값을 비교한다.
  - 유사 작품 수가 충분한 경우와 부족한 경우를 나누어 본다.
- 확인할 결과:
  - 유사 작품이 충분한 구간에서 MAPE 또는 p95_APE가 줄어드는지 확인한다.
  - 유사 작품이 부족한 구간은 fallback을 쓰면 안 되는지 확인한다.
- 후속 작업:
  - 효과가 있으면 조건별 모델 선택 또는 낮은 신뢰도 작품의 보조 가격 기준으로 사용한다.

### PP-K4. Huber 선행 + CatBoost residual 보정

- 목적:
  - Huber가 안정적인 기본 가격선을 만들고, CatBoost가 Huber가 남긴 조건 조합 오차를 보정할 수 있는지 확인한다.
- 진행 방식:
  - 먼저 Warm Huber로 예측값을 만든다.
  - 실제 로그 가격과 Huber 예측 로그 가격의 차이를 남은 오차로 계산한다.
  - CatBoost가 이 남은 오차를 학습할 수 있는지 확인한다.
  - 학습 데이터 내부 교차 예측값을 사용해 검증 데이터에 맞춘 과적합 위험을 줄인다.
- 확인할 결과:
  - Huber 단독보다 MdAPE 또는 p95_APE가 개선되는지 확인한다.
  - validation에서만 좋아지고 test에서 무너지는지 확인한다.
- 후속 작업:
  - 효과가 있으면 Warm의 2단계 보정 모델 후보로 둔다.
  - 효과가 없으면 더 단순한 Huber 구간 보정으로 유지한다.

### PP-K5. Huber 선행 + CatBoost segment 규칙 보정

- 목적:
  - Huber 모델을 완전히 바꾸지 않고, CatBoost가 잘 나누는 작가 x 크기 조건 구간만 보정에 활용할 수 있는지 확인한다.
- 진행 방식:
  - Huber 예측값을 기준으로 residual을 계산한다.
  - CatBoost가 나눈 leaf 구간, 작가 x 크기 구간, 크기 구간별 residual 중앙값을 계산한다.
  - 구간별 표본 수가 충분한 경우에만 보정값을 적용한다.
- 확인할 결과:
  - 전체 Huber 보정보다 특정 구간 보정이 p95_APE를 더 줄이는지 확인한다.
  - 표본 수가 적은 구간에서 과보정이 생기는지 확인한다.
- 후속 작업:
  - 효과가 있으면 Warm Huber의 조건부 보정 규칙으로 둔다.
  - 표본 수가 부족하면 전체 보정 또는 상위 구간 보정으로 대체한다.

### PP-K6. OOF stacking 조합

- 목적:
  - Huber, CatBoost, LightGBM, Quantile, 유사 작품 예측값을 함께 사용했을 때 단일 모델보다 안정적인지 확인한다.
- 진행 방식:
  - 각 모델의 학습 데이터 내부 교차 예측값을 만든다.
  - 이 예측값들을 입력으로 두고 단순한 2단계 모델을 학습한다.
  - 2단계 모델은 Ridge 또는 Huber처럼 복잡도가 낮은 모델부터 사용한다.
- 확인할 결과:
  - 단일 모델보다 MdAPE 또는 p95_APE가 개선되는지 확인한다.
  - 여러 모델을 섞었을 때 과적합이 생기는지 확인한다.
- 후속 작업:
  - 개선폭이 크고 재현되면 최종 후보로 검토한다.
  - 개선폭이 작거나 불안정하면 PP-D의 단순 평균/가중 평균까지만 사용한다.

### PP-K7. Huber + Quantile 위험 구간 보정

- 목적:
  - Huber는 안정적인 중심 가격선을 만들고, Quantile은 예측이 불안정한 구간을 찾는 역할로 나누어 MAPE를 낮출 수 있는지 확인한다.
- 진행 방식:
  - Huber로 기본 예측 로그 가격을 만든다.
  - Quantile 모델로 낮은 예측값, 중앙 예측값, 높은 예측값을 함께 만든다.
  - 높은 예측값과 낮은 예측값의 차이가 큰 작품을 위험 구간으로 분류한다.
  - 위험 구간에만 예측 오차 중앙값 보정을 적용한다.
- 확인할 결과:
  - 위험 구간 보정 후 MAPE가 줄어드는지 확인한다.
  - p95_APE가 줄어드는지 확인한다.
  - 일반 구간까지 불필요하게 보정해서 MdAPE가 나빠지는지 확인한다.
- 후속 작업:
  - 효과가 있으면 Quantile width를 신뢰도와 보정 기준으로 사용한다.
  - 효과가 없으면 Quantile은 가격 범위 표시용으로만 사용한다.

### PP-K8. Huber + Quantile 중앙 예측 가중 평균

- 목적:
  - Huber 예측값과 Quantile 중앙 예측값을 섞었을 때 MAPE가 낮아지는지 확인한다.
- 진행 방식:
  - Huber 예측 로그 가격을 만든다.
  - Quantile 중앙 예측 로그 가격을 만든다.
  - 두 예측값을 여러 비율로 섞어 비교한다.
  - 가중치는 검증 데이터에서만 선택한다.
- 계산 방식:
  - `최종 예측 로그 가격 = w * Huber 예측 로그 가격 + (1 - w) * Quantile 중앙 예측 로그 가격`
  - `w` 후보는 `0.2`, `0.4`, `0.5`, `0.6`, `0.8`로 둔다.
- 확인할 결과:
  - Huber 단독보다 MAPE가 줄어드는지 확인한다.
  - Quantile 단독보다 p95_APE가 안정적인지 확인한다.
- 후속 작업:
  - 단순 가중 평균만으로 개선되면 복잡한 라우팅 실험보다 우선 적용한다.
  - 개선이 특정 구간에만 있으면 PP-K10의 조건부 선택으로 넘긴다.

### PP-K9. Huber residual Quantile 보정

- 목적:
  - Huber가 예측한 뒤 남은 오차를 Quantile 방식으로 다시 보정할 수 있는지 확인한다.
- 진행 방식:
  - Huber 예측값을 먼저 만든다.
  - 실제 로그 가격과 Huber 예측 로그 가격의 차이를 남은 오차로 계산한다.
  - Quantile 모델이 이 남은 오차를 학습하게 한다.
  - 중앙 residual 예측값을 Huber 예측값에 더해 최종 예측값을 만든다.
- 계산 방식:
  - `Huber 남은 오차 = 실제 로그 가격 - Huber 예측 로그 가격`
  - `최종 예측 로그 가격 = Huber 예측 로그 가격 + Quantile이 예측한 남은 오차`
- 확인할 결과:
  - Huber 단독보다 MAPE가 줄어드는지 확인한다.
  - 과대 예측 구간과 과소 예측 구간이 따로 줄어드는지 확인한다.
  - 학습 데이터에만 맞는 보정이 아닌지 확인한다.
- 후속 작업:
  - 효과가 있으면 남은 오차 보정 모델의 Quantile 버전으로 관리한다.
  - 효과가 없으면 Huber의 단순 구간 보정으로 유지한다.

### PP-K10. Huber + Quantile 위험도 기반 CatBoost 라우팅

- 목적:
  - 안정적인 작품은 Huber 예측을 유지하고, 위험한 작품만 CatBoost 보정 또는 대체 예측으로 넘겨 MAPE를 낮출 수 있는지 확인한다.
- 진행 방식:
  - Huber로 기본 예측값을 만든다.
  - Quantile width로 예측 불확실성이 큰 작품을 찾는다.
  - CatBoost 보정 예측 또는 CatBoost 대체 예측을 함께 만든다.
  - Quantile width가 낮은 구간은 Huber를 유지하고, 높은 구간에서만 CatBoost 적용 여부를 비교한다.
- 확인할 결과:
  - 전체를 CatBoost로 바꾸는 것보다 위험 구간만 CatBoost를 쓰는 방식이 안정적인지 확인한다.
  - MAPE와 p95_APE가 동시에 줄어드는지 확인한다.
  - 라우팅 기준이 너무 복잡하지 않은지 확인한다.
- 후속 작업:
  - 효과가 있으면 조건별 모델 선택 정책으로 연결한다.
  - 효과가 없으면 Huber+Quantile 단순 조합까지만 유지한다.

## 10. [PP-L1~PP-L9] Huber / Quantile / CatBoost MAPE 최적화 실험

별도 상세 문서: `docs/track6/experiments/huber_quantile_catboost_mape_optimization_plan.md`

이 실험은 Huber, Quantile, CatBoost를 단순 평균하는 것이 아니라, 각 모델의 장점을 순서대로 사용해 MdAPE를 유지하면서 MAPE와 p95_APE를 낮출 수 있는지 확인한다.

PP-K는 간단한 추천 보조 조합을 탐색하는 실험이고, PP-L은 MAPE 최적화를 목표로 한 정식 순차 학습 실험이다. 따라서 PP-L은 PP-K 결과에서 가능성이 보인 조합을 더 엄격한 OOF/validation 기준으로 검증하는 단계로 본다.

### 핵심 목표

- Huber는 안정적인 중심 가격선을 만든다.
- Quantile은 `q10_log`, `q50_log`, `q90_log`를 통해 예측 범위 폭을 계산한다.
- CatBoost는 Huber가 남긴 작가, 크기, 재료, 형태 조합 오차를 보정한다.
- 최종 목표는 MAPE 감소이지만, MdAPE가 악화되면 채택하지 않는다.

### 주요 실험

1. `PP-L1~PP-L2`
   - CatBoost 자체를 MAPE 목표에 맞게 조정한다.
   - CatBoost 옵션이 MAPE와 p95_APE에 미치는 영향을 확인한다.

2. `PP-L3~PP-L6`
   - Huber + CatBoost residual 보정
   - Huber + Quantile 위험 구간 보정
   - Huber + Quantile + CatBoost 라우팅
   - Huber / Quantile / CatBoost 가중 앙상블을 비교한다.

3. `PP-L7`
   - Quantile 구간을 먼저 정의한다.
   - `PP-L7-0`: Quantile width와 price_range_ratio가 실제 오차 위험을 구분하는지 검증한다.
   - `PP-L7-H`: Quantile 구간별 Huber 재학습을 검증한다.
   - `PP-L7-CB`: Quantile 구간별 CatBoost 재학습을 검증한다.
   - `PP-L7-HCB`: Quantile 구간별 Huber+CatBoost 결합을 검증한다.

4. `PP-L8`
   - Quantile → Huber → CatBoost 순차 구조를 검증한다.
   - Quantile은 선행 진단, Huber는 중심 가격선, CatBoost는 residual 보정 역할로 사용한다.
   - 이때 ratio는 가격 예측 범위인 `price_range_ratio`로 해석한다.

5. `PP-L9`
   - Huber → Quantile residual → CatBoost remaining residual 순차 구조를 검증한다.
   - Quantile은 가격 자체가 아니라 Huber residual 범위를 추정한다.
   - 이때 ratio는 Huber residual 범위인 `residual_range_ratio`로 해석한다.

### 확인할 결과

- 전체 MdAPE가 유지 또는 개선되는지 확인한다.
- 전체 MAPE가 줄어드는지 확인한다.
- p95_APE가 악화되지 않는지 확인한다.
- Warm/Cold별로 어떤 순차 구조가 더 적합한지 확인한다.
- stable / caution / risk 구간별로 Huber와 CatBoost의 역할이 다르게 나타나는지 확인한다.
- PP-L8의 가격 범위 ratio와 PP-L9의 residual 범위 ratio가 서로 다른 의미로 해석되는지 확인한다.

### 논문 수준 검증 기준

- 각 PP-L 후보는 Huber 단독, CatBoost 단독, Quantile q50 단독, 전체 median 보정, Huber+CatBoost residual, Huber+Quantile residual, 단순 가중 앙상블과 비교한다.
- Quantile 구간 기준은 33/66, 50/80, 70/90, price_range_ratio 1.5/2.5배를 비교한다.
- 최종 후보는 paired bootstrap 95% 신뢰구간과 Wilcoxon signed-rank test를 기록한다.
- CatBoost/Quantile처럼 seed 영향을 받을 수 있는 모델은 seed 반복 평균과 표준편차를 기록한다.
- 모델 수, 학습 단계 수, 구간 수, fallback 수, 추론 비용을 함께 기록해 복잡도 대비 개선폭을 판단한다.
- 개선된 후보뿐 아니라 보류/실패한 후보와 실패 사유도 남긴다.

### 후속 작업

- PP-L 실험이 효과가 있으면 최종 후보정/라우팅 정책에 반영한다.
- 효과가 특정 구간에만 있으면 전체 적용이 아니라 조건부 적용으로 둔다.
- 단순 Huber, CatBoost, PP-K 조합보다 개선이 명확하지 않으면 PP-L은 보류한다.
- Huber/CatBoost residual 학습은 OOF 예측 기반 residual을 사용하지 않으면 실행하지 않는다.

## 11. [PP-F1~PP-F4] 가격 범위 및 신뢰도 정책 실험

정확도 개선과 별개로, 서비스에서 예측 가격을 어떻게 보여줄지 결정한다.

### 진행 방식

1. Warm/Cold별 로그 오차 분포를 계산한다.
2. 70%, 80%, 90% 포함률 기준의 가격 범위를 계산한다.
3. 구간별 오차가 큰 경우 더 넓은 범위를 적용한다.
4. 신뢰도 등급을 저위험/보통/고위험으로 나눈다.

### 확인할 결과

- 단일 예측가만 보여도 되는 구간을 확인한다.
- 가격 범위를 함께 보여야 하는 구간을 확인한다.
- 낮은 신뢰도 문구가 필요한 구간을 확인한다.

### 후속 작업

- Warm은 단일 가격 또는 좁은 범위 제공 가능성을 검토한다.
- Cold는 단일 가격보다 범위/신뢰도 표시가 필요한지 판단한다.

## 12. [PP-G1~PP-G5 / PP-H1~PP-H6] 외부 데이터 및 검색/소셜 지표 검증 실험

기존 피처와 후처리만으로 해결되지 않는 Cold 문제를 외부 데이터로 개선할 수 있는지 확인한다.

### 검증 후보

- 작가 전시 이력
- 수상/기관 이력
- 갤러리 소속 여부
- 네이버 검색 결과 수
- 구글 검색 결과 수
- Google Trends 관심도
- SNS/소셜 언급량
- 검색 품질/동명이인 위험 정보

### 진행 방식

1. 신규 수집 가능 여부를 먼저 확인한다.
2. 기존 데이터에 이미 있는 피처와 중복되지 않는지 확인한다.
3. 수집 성공률과 결측률을 확인한다.
4. 기본 Cold 모델에 추가했을 때 성능이 개선되는지 확인한다.

### 확인할 결과

- 신규 외부 데이터가 Cold 성능을 실제로 개선하는지 확인한다.
- 수집 가능률이 실무적으로 충분한지 확인한다.
- 동명이인/검색 오염 위험이 낮은지 확인한다.

### 후속 작업

- 성능 개선과 수집 가능성이 모두 있으면 다음 버전 피처 후보로 둔다.
- 수집 비용이 크거나 오염 위험이 높으면 후순위로 둔다.

## 최종 보고 기준

각 실험은 다음 형식으로 결과를 정리한다.

```text
1. 왜 이 실험을 했는가
2. 어떤 모델과 피처를 사용했는가
3. 어떤 방식으로 보정하거나 비교했는가
4. 기대한 결과는 무엇인가
5. 실제 결과는 어땠는가
6. 채택/보류/중단 판단은 무엇인가
7. 다음 실험 또는 후속 작업은 무엇인가
```

최종적으로는 아래 의사결정을 할 수 있어야 한다.

- Warm 기준 모델을 Huber로 유지할지, CatBoost 후보를 추가로 볼지 결정한다.
- Cold 기준 모델을 CatBoost 중심으로 유지할지, LightGBM을 보조로 쓸지 결정한다.
- 전체 보정, 구간 보정, 모델별 커스텀 보정 중 어떤 방식을 채택할지 결정한다.
- Quantile, 유사 작품 fallback, Huber+CatBoost 조합, OOF stacking 중 추가 실험 가치가 있는 조합을 결정한다.
- 가격 범위와 신뢰도 표시가 필요한 구간을 결정한다.
- 외부 데이터 수집이 필요한지, 필요하다면 어떤 항목부터 수집할지 결정한다.
