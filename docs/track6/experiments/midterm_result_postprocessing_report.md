# Track6 중간 실험 결과 요약 및 후처리 계획

## 1. 문서 목적

- 작품 가격 예측 실험의 중간 결과를 상사 보고용으로 정리한다.
- A~J 그룹 실험과 후속 모델 비교 실험을 바탕으로 어떤 피처가 중요한지 설명한다.
- 현재 결과만 보고도 Warm / Cold 모델 방향을 이해할 수 있게 한다.
- 후처리로 가격 예측을 더 안정적으로 만드는 계획을 정리한다.

## 2. 현재까지의 실험 기준

- 입력 단위: 작품 1건
- 예측 대상: 작품 가격
- 평가 구분:
  - Warm: 학습 데이터에 같은 작가가 있는 작품을 예측하는 상황
  - Cold: 학습 데이터에 없는 신규 작가의 작품을 예측하는 상황
- 핵심 평가 지표:
  - MdAPE: 예측 가격이 실제 가격과 얼마나 차이 나는지 보는 대표 오차
  - p95_APE: 오차가 큰 상위 5% 작품에서 얼마나 크게 틀리는지 보는 위험 지표
  - Within_30: 실제 가격 대비 30% 이내로 맞춘 비율
  - RMSE_log / R2: 로그 가격 기준으로 모델이 얼마나 안정적인지 보는 보조 지표
- 해석 원칙:
  - Warm과 Cold는 난이도가 다르므로 합쳐서 판단하지 않는다.
  - 최종 판단은 MdAPE를 먼저 보고, p95_APE와 Within_30으로 안정성을 확인한다.
  - 성능이 좋아도 운영에서 입력하거나 수집할 수 없는 피처는 최종 후보에서 제외하거나 보류한다.

## 3. 전체 결론

- Warm은 작가명이 가장 큰 영향을 준다.
- Warm에서는 작가명만 쓰는 것보다 실제 크기 정보를 함께 쓰는 것이 크게 좋았다.
- Warm 후보 모델은 현재 `Huber`가 가장 안정적이다.
- Cold는 작가명을 직접 쓸 수 없으므로 작품 자체 정보와 작가 메타 정보가 중요하다.
- Cold에서는 `CatBoost`가 현재 가장 좋은 후보로 확인됐다.
- Cold에서 가장 유효한 피처 조합은 `작품 기본 피처 + 활동량/인지도 정보`다.
- 재료, 지지체, 제작연도, 작품 유형, 깊이, 에디션은 단독으로 강하지 않았다.
- 단독 피처보다 여러 피처를 묶었을 때 의미가 있는 경우가 많았다.
- 후처리는 특히 Cold에서 중요하다. Cold는 단일 예측값만으로는 위험한 구간이 남아 있다.

## 4. 결론과 실험 근거 요약

| 결론 | 근거가 된 실험 | 확인한 내용 | 현재 판단 |
|---|---|---|---|
| Warm은 작가명이 중요하다 | B1, C1, C6, WM1 | 작가명 단독보다 작가명 + 작품 정보가 크게 개선됨 | Warm 핵심 피처로 유지 |
| Warm은 실제 크기 정보가 중요하다 | A1, A8-1, C1, WM1 | 호수만보다 가로/세로/면적/비율을 함께 쓸 때 성능이 좋아짐 | Warm 기본 피처에 실제 크기 포함 |
| Warm 모델은 Huber가 유리하다 | WM1 모델 비교 | 같은 피처 조합에서 Huber가 상위권 반복 | 1차 Warm 후보 모델로 유지 |
| Cold는 작가명을 직접 쓰기 어렵다 | B1, C계열, Cold split 기준 | 신규 작가에는 학습된 작가명이 없으므로 작가명 효과를 그대로 쓰기 어려움 | Cold는 작가명 제외 |
| Cold는 작품 기본 피처만으로 한계가 있다 | A9, G6, CM1 | 작품 기본 피처에 활동량/인지도 정보가 붙으면 성능 개선 | 작가 메타 수집 필요 |
| Cold 모델은 CatBoost가 유력하다 | CM1 | Cold 상위 피처 조합에서 CatBoost가 MdAPE 기준 1위 | Cold 1차 후보 모델 |
| 단독 피처는 대부분 약하다 | A2~A7, E계열 | 재료, 지지체, 제작연도, 유형, 깊이, 에디션 단독 효과 제한적 | 단독보다 조합/후처리 후보 |
| 후처리가 필요하다 | Cold p95_APE, Within_30 | Cold는 대표 오차가 줄어도 큰 오차 위험이 남음 | 가격 범위와 신뢰도 표시 필요 |

## 5. 실험군별 역할

| 실험군 | 목적 | 이번 보고에서 활용한 방식 |
|---|---|---|
| Group A | 작품 자체 변수 영향 확인 | 크기, 재료, 지지체, 제작연도, 유형, 깊이, 에디션의 단독/조합 효과 확인 |
| Group B | 작가명 효과 확인 | Warm에서 작가명이 가격대 설명에 얼마나 중요한지 확인 |
| Group C | 작가명 + 작품 변수 확인 | 작가명을 넣은 뒤에도 작품 정보가 추가 설명력을 가지는지 확인 |
| Group D | 작가명/작품 변수 교차 효과 확인 | 작가별 대형작 프리미엄, 작가별 재료/지지체 차이 확인 |
| Group E | 작가 메타 단독 효과 확인 | 생년, 경력, 국적, 활동량, 인지도 단독 효과 확인 |
| Group F | 작가 메타 조합 효과 확인 | 여러 작가 메타를 묶었을 때 가격대 설명력이 생기는지 확인 |
| Group G | 작품 기본 피처 + 작가 메타 확인 | 작품 조건을 통제한 뒤 작가 메타가 추가로 도움이 되는지 확인 |
| Group H~J | 교차항/확장 조합 확인 | 활동량/인지도와 호수/면적 같은 조합이 Cold에 도움이 되는지 확인 |
| WM1 | Warm 상위 피처의 모델 비교 | Warm에서 Huber가 적합한지 확인 |
| CM1 | Cold 상위 피처의 모델 비교 | Cold에서 CatBoost가 적합한지 확인 |

## 6. Warm 결과 상세

### 4.1 Warm에서 영향이 큰 피처

| 피처/효과 | 확인 결과 | 해석 |
|---|---:|---|
| 작가명 + 전체 크기 | MdAPE 약 64% 개선 | Warm에서 가장 강한 개선 축 |
| 작가명 + 호수/작품 기본 피처 | MdAPE 약 59% 개선 | 작가명 단독보다 작품 정보 추가가 필요 |
| 작가명 단독 | MdAPE 약 14% 개선 | 작가명만으로도 가격대 일부 설명 가능 |
| 재료 + 크기 | MdAPE 약 6% 개선 | 재료는 단독보다 크기와 묶을 때 효과 있음 |
| 지지체 + 크기/재료 | MdAPE 약 3.5% 개선 | 지지체는 조합 피처로 의미 있음 |
| 제작연도/작품 연한 | 약 1% 개선 | 단독 핵심은 아니고 보조 후보 |
| 깊이/3D, 에디션 | 단독으로는 악화 | 최종 핵심 피처보다는 후처리/위험 구간 판단 후보 |

### 4.2 Warm 상위 후보

| 후보 | 사용 피처 | 모델 | MdAPE | p95_APE | Within_30 | 해석 |
|---|---|---|---:|---:|---:|---|
| Warm 1순위 성능 후보 | 작가명 + 가로 + 세로 + 로그 면적 + 가로세로 비율 + 작가명 x 면적 | Huber | 0.1545 | 1.0181 | 0.7232 | 대표 오차가 가장 낮은 후보 |
| Warm 안정 후보 | 작가명 + 가로 + 세로 + 로그 면적 + 가로세로 비율 + 작가 학습 작품 수 | Huber | 0.1562 | 1.0548 | 0.7364 | Within_30이 높아 안정성 후보 |
| Warm 단순 후보 | 작가명 + 가로 + 세로 + 로그 면적 + 가로세로 비율 | Huber | 0.1566 | 1.0434 | 0.7315 | 실무 적용이 가장 단순한 후보 |

### 4.3 Warm 모델 해석

- Huber는 선형 회귀 계열 모델이다.
- 일반 선형 회귀보다 큰 이상치에 덜 흔들린다.
- 미술품 가격은 일부 고가 작품이 평균을 크게 흔들 수 있으므로 Huber가 유리하다.
- Warm에서는 작가명 피처가 강하게 작동한다.
- 작가명만으로도 기본 가격대가 잡히고, 크기 정보가 붙으면 작품별 차이를 더 잘 설명한다.
- 작가명 x 면적 같은 조합 피처는 일부 개선을 만들었지만, 구조가 복잡해진다.
- 따라서 운영 1차 후보는 `작가명 + 전체 크기 + Huber`가 가장 현실적이다.
- 추가 정확도가 필요하면 `작가명 x 면적` 또는 `작가 학습 작품 수`를 보조 후보로 둔다.

## 7. Cold 결과 상세

### 5.1 Cold에서 영향이 큰 피처

| 피처/효과 | 확인 결과 | 해석 |
|---|---:|---|
| 활동량/인지도 + CatBoost | MdAPE 약 6.4% 개선 | 현재 Cold 1순위 후보 |
| 활동량/판매 노출 | MdAPE 약 4.6% 개선 | 신규 작가 예측에서 의미 있음 |
| 전체 작가 메타 | MdAPE 약 2.3% 개선 | 일부 개선은 있으나 피처 수 대비 추가 검증 필요 |
| 작가 생년/세대 | MdAPE 약 1.6% 개선 | 수집 품질이 좋아지면 보조 후보 |
| 활동량/인지도 x 면적 | MdAPE 약 1.3% 개선 | 대형작과 시장 노출 조합 후보 |
| 면적 x 지지체 | MdAPE 약 1.0% 개선 | 일부 조합 효과 있음 |
| 국적 / 전시 횟수 / 인지도 단독 | 악화 또는 제한적 | 단독 사용보다 묶음 또는 후처리 후보 |

### 5.2 Cold 상위 후보

| 후보 | 사용 피처 | 모델 | MdAPE | p95_APE | Within_30 | 해석 |
|---|---|---|---:|---:|---:|---|
| Cold 1순위 후보 | 호수 + 난트 재료 + 난트 도구 + 난트 지지체 + 총 작품 수 + 판매 중 작품 수 + 팔로워 수 + 주요 작가 여부 | CatBoost | 0.4488 | 2.9885 | 0.3304 | 현재 가장 좋은 Cold 후보 |
| Cold 보조 후보 1 | 활동량/인지도 + 면적 교차 피처 | LightGBM | 0.4516 | 3.1609 | 0.3153 | 성능은 좋지만 p95 위험 확인 필요 |
| Cold 보조 후보 2 | 활동량/인지도 + 호수 교차 피처 | LightGBM | 0.4544 | 3.1807 | 0.3211 | 후처리 후보 |
| Cold 안정 후보 | 작품 기본 피처 + 활동량 + 결측 정보 | LightGBM | 0.4577 | 2.9056 | 0.3246 | p95가 상대적으로 안정적 |

### 5.3 Cold 모델 해석

- Cold는 작가명을 직접 쓸 수 없다.
- 신규 작가이므로 작가명 피처는 학습에서 본 적 없는 이름이 많아진다.
- 따라서 Cold는 작품 자체 정보와 작가 메타 정보로 가격대를 추정해야 한다.
- CatBoost는 범주형 피처와 숫자 피처를 함께 다루는 데 유리하다.
- 재료, 지지체, 작가 활동량, 인지도처럼 값의 종류가 많은 피처를 처리하기 좋다.
- 현재 Cold 결과에서는 CatBoost가 MdAPE 기준 1위였다.
- 다만 p95_APE가 여전히 높다.
- 즉, 대표적인 작품은 어느 정도 맞추지만 크게 틀리는 작품이 아직 남아 있다.
- Cold는 모델 선택만으로 끝내기보다 후처리와 위험 구간 관리가 필요하다.

## 8. 피처별 결론

### 6.1 최종 후보로 유지할 피처

- Warm 공통 후보:
  - 작가명
  - 가로
  - 세로
  - 로그 면적
  - 가로세로 비율
- Warm 보조 후보:
  - 작가 학습 작품 수
  - 작가명 x 면적
  - 작가명 x 호수
- Cold 공통 후보:
  - 로그 호수
  - 난트 재료 번호
  - 난트 도구
  - 난트 지지체
  - 작가 총 작품 수
  - 판매 중 작품 수
  - 팔로워 수
  - 주요 작가 여부
- Cold 보조 후보:
  - 정보량 점수
  - 결측 여부
  - 활동량/인지도 x 면적
  - 활동량/인지도 x 호수

### 6.2 보류하거나 후처리용으로만 볼 피처

- 제작연도:
  - 단독 효과가 약하다.
  - 입력 가능하면 보조 피처로 유지할 수 있다.
- 작품 유형:
  - Cold 일부 조합에서 보조 효과가 있다.
  - 단독 핵심 피처는 아니다.
- 깊이/3D:
  - 단독 효과는 약하다.
  - 3D 작품이나 입체 작품 위험 구간 판단에 쓸 수 있다.
- 에디션:
  - 단독 효과는 약하다.
  - 에디션 작품만 따로 위험 구간 분석할 수 있다.
- 국적:
  - 현재는 효과가 제한적이다.
  - 데이터 표준화 후 재검토한다.
- 전시/경력 횟수:
  - 현재는 강한 개선 근거가 부족하다.
  - 수집 품질 개선 후 다시 본다.

## 9. 현재 모델 후보

### 7.1 Warm 모델 후보

- 1차 후보:
  - 모델: Huber
  - 피처: 작가명 + 가로 + 세로 + 로그 면적 + 가로세로 비율
- 이유:
  - 작가명 효과가 크다.
  - 크기 정보 추가 시 성능이 크게 좋아졌다.
  - Huber는 고가 작품 같은 이상치에 덜 흔들린다.
  - 모델 구조가 단순해서 설명하기 쉽다.
- 확장 후보:
  - 작가 학습 작품 수 추가
  - 작가명 x 면적 추가
  - 작가명 x 호수 추가
- 주의:
  - 교차 피처는 성능이 조금 좋아지지만 설명이 복잡해진다.
  - 운영 후보는 단순 모델과 확장 모델을 나란히 검증해야 한다.

### 7.2 Cold 모델 후보

- 1차 후보:
  - 모델: CatBoost
  - 피처: 작품 기본 피처 + 활동량/인지도 메타
- 작품 기본 피처:
  - 로그 호수
  - 난트 재료
  - 난트 도구
  - 난트 지지체
- 활동량/인지도 메타:
  - 총 작품 수
  - 판매 중 작품 수
  - 팔로워 수
  - 주요 작가 여부
- 이유:
  - Cold는 작가명을 쓰기 어렵다.
  - 작품 자체 정보만으로는 한계가 있다.
  - 활동량/인지도 정보가 붙었을 때 성능이 좋아졌다.
  - CatBoost가 범주형 값과 비선형 관계를 잘 처리했다.
- 보조 후보:
  - LightGBM
  - Quantile-LAD
- 주의:
  - Cold는 대표 오차가 줄어도 큰 오차 위험이 여전히 남는다.
  - 후처리와 신뢰도 표시가 필수다.

## 10. 후처리가 필요한 이유

- 모델이 예측한 단일 가격은 항상 오차를 가진다.
- 특히 Cold는 처음 보는 작가를 예측하므로 Warm보다 불확실성이 크다.
- 현재 Cold의 p95_APE가 높다는 것은 일부 작품에서 크게 빗나가는 경우가 있다는 뜻이다.
- 따라서 모델 결과를 그대로 서비스에 노출하기보다 아래 처리가 필요하다.
  - 예측값 보정
  - 위험 구간 표시
  - 가격 범위 제공
  - 신뢰도 표시
  - Warm/Cold 또는 저이력 작가 라우팅

## 11. 후처리 계획

### 9.1 가격대별 보정

- 목적:
  - 특정 가격대에서 반복적으로 높게 또는 낮게 예측하는 문제를 줄인다.
- 방법:
  - 예측 가격을 구간으로 나눈다.
  - 예: 50만원 이하, 50~100만원, 100~300만원, 300~1000만원, 1000만원 이상
  - 각 구간에서 평균적으로 얼마나 높게/낮게 예측하는지 계산한다.
  - 반복적으로 과대 예측되는 구간은 예측값을 낮춘다.
  - 반복적으로 과소 예측되는 구간은 예측값을 올린다.
- 검증:
  - 보정 전/후 MdAPE 비교
  - 보정 전/후 p95_APE 비교
  - 보정 후 Within_30이 올라가는지 확인
- 기대 효과:
  - 단일 가격 예측의 대표 오차를 줄일 수 있다.

### 9.2 피처 구간별 보정

- 목적:
  - 특정 조건에서 반복적으로 틀리는 문제를 줄인다.
- 우선 볼 구간:
  - 대형 작품
  - 초대형 호수
  - 3D/깊이 있는 작품
  - 특정 재료
  - 특정 지지체
  - 활동량이 낮은 작가
  - 정보가 부족한 작가
- 방법:
  - 각 구간별 오차를 따로 계산한다.
  - 특정 구간에서 계속 높게 예측되면 보정값을 적용한다.
  - 특정 구간에서 계속 낮게 예측되면 보정값을 적용한다.
- 검증:
  - 전체 성능이 나빠지지 않는지 확인한다.
  - 해당 구간의 p95_APE가 줄어드는지 본다.
- 기대 효과:
  - 큰 오차가 나는 위험 구간을 줄일 수 있다.

### 9.3 신뢰도 표시

- 목적:
  - 예측값을 그대로 믿어도 되는지 사용자에게 알려준다.
- 신뢰도에 사용할 후보:
  - Warm / Cold 여부
  - 작가 학습 작품 수
  - 작가 메타 정보 보유량
  - 활동량/인지도 정보 존재 여부
  - 3D/대형/초대형 여부
  - 모델별 예측값 차이
- 표시 예시:
  - 높음: 학습된 작가이고, 작가 작품 수가 충분하며, 작품 정보가 많음
  - 보통: 작품 정보는 충분하지만 작가 메타가 일부 부족함
  - 낮음: Cold이고, 작가 메타가 부족하거나 대형/특수 작품임
- 검증:
  - 신뢰도 높음 구간의 MdAPE가 실제로 낮은지 확인한다.
  - 신뢰도 낮음 구간의 p95_APE가 실제로 높은지 확인한다.
- 기대 효과:
  - 모델의 한계를 서비스에서 설명할 수 있다.

### 9.4 가격 범위 제공

- 목적:
  - 단일 가격 하나만 보여줄 때 생기는 위험을 줄인다.
- 방법:
  - 예측 가격과 함께 예상 범위를 제공한다.
  - 예: 예측가 100만원, 예상 범위 70만~140만원
  - Warm과 Cold의 범위 폭을 다르게 둔다.
  - Cold는 불확실성이 크므로 범위를 더 넓게 둔다.
- 검증:
  - 실제 가격이 제시한 범위 안에 들어오는 비율을 확인한다.
  - 범위가 너무 넓어 실무적으로 의미가 없어지지 않는지 확인한다.
- 기대 효과:
  - Cold 예측의 불확실성을 줄여 보이기보다 명확히 표현할 수 있다.

### 9.5 Warm / Cold / 저이력 작가 라우팅

- 목적:
  - 모든 작품에 같은 모델을 쓰지 않고 상황별로 더 적합한 모델을 선택한다.
- 기준 후보:
  - 학습 데이터에 작가가 있으면 Warm
  - 학습 데이터에 작가가 없으면 Cold
  - 학습 데이터에 작가가 있어도 작품 수가 너무 적으면 저이력 Warm
- 방법:
  - 저이력 Warm 작가를 별도 구간으로 본다.
  - Warm 모델과 Cold 모델 중 어떤 쪽이 더 안정적인지 비교한다.
  - 작가 작품 수 기준을 1개, 3개, 5개, 10개 등으로 바꿔 실험한다.
- 검증:
  - 저이력 작가 구간에서 MdAPE와 p95_APE가 개선되는지 확인한다.
  - 전체 Warm 성능이 나빠지지 않는지 확인한다.
- 기대 효과:
  - 작가명이 있더라도 데이터가 부족한 경우의 과신을 줄일 수 있다.

### 9.6 모델 결과 섞기

- 목적:
  - 한 모델의 약점을 다른 모델로 보완한다.
- 후보:
  - Warm: Huber + Ridge
  - Cold: CatBoost + LightGBM
- 방법:
  - 두 모델의 예측값을 일정 비율로 섞는다.
  - 예: CatBoost 70%, LightGBM 30%
  - 비율을 여러 개 실험한다.
- 검증:
  - MdAPE가 줄어드는지 확인한다.
  - p95_APE가 줄어드는지 확인한다.
  - 모델이 너무 복잡해지는지 확인한다.
- 기대 효과:
  - 단일 모델보다 안정적인 예측값을 만들 수 있다.

## 12. 추가 데이터 수집 계획

### 10.1 우선 수집할 데이터

- 작가 총 작품 수
- 판매 중 작품 수
- 팔로워 수
- 주요 작가 여부
- 작가 생년
- 작가 국적
- 개인전 수
- 단체전 수
- 아트페어 수
- 수상 이력 수
- 소장 이력 수

### 10.2 검색/소셜 기반 데이터

- 목적:
  - 작가 인지도와 시장 노출 정도를 더 잘 반영한다.
- 후보:
  - 네이버 검색 결과 수
  - 구글 검색 결과 수
  - 뉴스 검색 결과 수
  - 전시 페이지 검색 결과 수
  - SNS 팔로워 수
  - 갤러리/기관 페이지 언급 여부
- 주의:
  - 검색 결과 수는 시점에 따라 변할 수 있다.
  - 동명이인 문제가 생길 수 있다.
  - 작가명만으로 검색하면 노이즈가 많을 수 있다.
- 보완:
  - 작가명 + 미술
  - 작가명 + artist
  - 작가명 + gallery
  - 작가명 + exhibition
  - 작가명 + 소속 갤러리
  - 위 조합으로 검색 결과를 나눠 수집한다.

### 10.3 데이터 수집 후 검증

- 수집한 데이터가 결측이 많으면 바로 모델에 넣지 않는다.
- 먼저 아래를 확인한다.
  - 값이 너무 한쪽으로 몰려 있지 않은지
  - 동명이인으로 잘못 매칭된 값이 없는지
  - Warm / Cold 모두에서 만들 수 있는지
  - 운영 시점에도 다시 만들 수 있는지
- 그다음 피처 추가 실험을 진행한다.

## 13. 후처리 실험 우선순위

### 1순위: Cold 가격대별 보정

- 이유:
  - Cold는 현재 단일 예측값의 큰 오차 위험이 남아 있다.
  - 가격대별 과대/과소 예측을 줄이면 바로 서비스 품질에 도움이 된다.

### 2순위: Cold 신뢰도 구간 만들기

- 이유:
  - Cold 예측은 모든 작품에 같은 신뢰도를 줄 수 없다.
  - 정보가 부족한 작가와 정보가 많은 작가를 나눠야 한다.

### 3순위: Cold CatBoost + LightGBM 혼합

- 이유:
  - CatBoost는 현재 1위 후보지만, LightGBM도 안정 후보로 반복 등장했다.
  - 두 모델의 예측을 섞으면 큰 오차가 줄어드는지 확인할 수 있다.

### 4순위: Warm 저이력 작가 라우팅

- 이유:
  - 작가명이 있어도 학습 작품 수가 적으면 Warm 모델을 과신할 수 있다.
  - 저이력 작가에게 Cold 방식 또는 보정 방식을 적용할지 확인해야 한다.

### 5순위: 검색/소셜 인지도 피처 추가

- 이유:
  - Cold에서 활동량/인지도 정보가 성능 개선에 도움을 줬다.
  - 검색/소셜 데이터가 추가되면 Cold 성능 개선 가능성이 있다.

## 14. 후처리 실험 계획

### 14.1 후처리 실험의 목표

- 모델을 새로 많이 늘리는 것이 1차 목표가 아니다.
- 현재 선정된 Warm / Cold 후보 모델의 예측값을 더 안정적으로 만드는 것이 목표다.
- 특히 Cold에서 큰 오차가 나는 작품을 줄이는 것이 중요하다.
- 후처리 실험은 아래 질문에 답해야 한다.
  - 예측값을 보정하면 실제 가격에 더 가까워지는가?
  - 어떤 조건에서 예측 신뢰도가 낮아지는가?
  - 가격 범위를 함께 보여주면 서비스에서 더 안전한가?
  - 추가 데이터를 수집하면 Cold 예측력이 실제로 좋아지는가?

### 14.2 후처리 실험 목록

### 14.3 후처리 실험 기록 방식

- 각 후처리 실험은 기존 실험과 같은 방식으로 폴더를 분리한다.
- 각 실험 폴더에는 아래 내용을 남긴다.
  - 실험 목적
  - 사용한 원본 예측 결과
  - 사용한 보정 방법
  - 사용한 피처
  - 보정 전 성능
  - 보정 후 성능
  - 개선 여부
  - 운영 적용 가능 여부
- 결과 표에는 반드시 아래 지표를 포함한다.
  - MdAPE
  - p95_APE
  - Within_30
  - Within_50
  - RMSE_log
  - 가격 범위 포함률
  - 가격 범위 폭

### 14.4 후처리 실험 판단 기준

- 보정 후 MdAPE가 좋아져도 p95_APE가 크게 나빠지면 채택하지 않는다.
- 보정 후 전체 성능은 그대로라도 위험 구간 p95_APE가 줄면 부분 채택할 수 있다.
- 가격 범위는 실제 가격을 많이 포함해야 하지만, 너무 넓으면 서비스 가치가 떨어진다.
- 신뢰도 등급은 실제 오차와 연결되어야 한다.
- 추가 수집 데이터는 운영에서도 다시 만들 수 있어야 한다.

## 15. 상사 보고용 요약

- 이번 실험의 목적은 어떤 피처가 가격 예측에 도움이 되는지 확인하는 것이었다.
- Warm에서는 작가명이 가장 중요했고, 작가명에 실제 크기를 붙였을 때 성능이 크게 좋아졌다.
- Warm 모델은 Huber가 현재 가장 안정적이다.
- Cold에서는 작가명을 쓸 수 없으므로 작품 기본 정보와 작가 메타 정보가 중요했다.
- Cold 모델은 CatBoost가 현재 가장 좋은 후보로 확인됐다.
- Cold에서 활동량/인지도 정보가 붙었을 때 성능이 개선됐다.
- 단독 피처만으로 강한 효과를 낸 것은 많지 않았다.
- 재료, 지지체, 제작연도, 작품 유형, 깊이, 에디션은 조합이나 후처리용으로 보는 것이 맞다.
- 다음 단계는 모델을 새로 많이 늘리는 것보다, 현재 후보 모델의 예측값을 보정하고 위험 구간을 줄이는 것이다.
- 후처리의 핵심은 가격대별 보정, 위험 구간 표시, 가격 범위 제공, 저이력 작가 라우팅이다.
- 추가 데이터 수집은 Cold 성능 개선을 목표로 해야 하며, 특히 작가 활동량, 시장 노출, 검색/소셜 인지도 정보가 우선이다.
