- 날짜: 2026-06-22

## 1. 목적

세계 미술시장의 작가 단가 구조(`작품가격 = 크기 × 작가계수`)를 모델 학습 구조로 옮긴다.
콜드 모델이 `log(가격)`을 직접 예측하는 대신 **`log(가격 / 면적)` = 단위면적당 작가계수**를
타깃으로 학습하고, 추론 시 `가격 = exp(예측) × 면적`으로 복원한다. 면적은 콜드 작가도 정확히
아는 값이므로, 알려진 잡음 축을 타깃에서 제거하고 모델이 계수에만 집중하게 만든다는 가설.

- 모델/피처: v0.2 운영 LightGBM Quantile(q10/q40/q50/q90), 운영 12 피처 동일.
- 비교 base: 검색 없는 운영 base v0.2 q50 = **0.4823 / 1.242 / 4.380** (MdAPE/MAPE/p95).

## 2. 고정 test q50 (기록 전용, 선택 금지)

| 지표 | v0.2 base | PP-CCOEF1 (coef 타깃) | Δ |
|---|---|---|---|
| MdAPE | 0.4823 | **0.48835** | +0.0061 (악화) |
| MAPE | 1.242 | **1.25253** | +0.0105 (악화) |
| p95_APE | 4.380 | **3.91684** | **−0.4632 (개선)** |

- 중앙값은 거의 동일~소폭 악화, p95(꼬리)만 −10.6% 개선. 단 이 수치는 **기록 전용**이며
  후보 선택 근거로 쓰지 않음(게이트로만 판정).

## 3. 게이트 — artist 80/70% holdout 200회 paired (coef vs 직접 타깃)

각 부트스트랩 run에서 동일 held-in 작가로 coef 타깃 모델과 직접 `ln_price` 타깃 모델을 함께
학습, 동일 held-out 작가에서 평가해 coef가 이기는 비율을 셈.

| 개선확률 | 값 | 게이트(≥0.90) |
|---|---|---|
| MAPE | 0.54 | ✗ |
| p95_APE | 0.555 | ✗ |
| MdAPE | 0.52 | ✗ |
| **pass** | **false** | |

- 세 지표 모두 ≈0.5 = **직접 타깃과 동전던지기**. 고정 test의 p95 개선은 held-out 작가로
  일반화되지 않음(robust하지 않음). 게이트 로직은 코드리뷰로 정합성 확인(페어링·승패방향·
  복원·누수 무결).

## 4. 면적 노이즈 민감도 (정직한 실패 모드 확인)

`가격 = exp(계수) × 면적` 복원은 면적 측정오차를 예측에 직접 곱한다. 고정 test를 면적 분위로
슬라이스:

| 슬라이스 | n | MdAPE | MAPE | p95_APE |
|---|---|---|---|---|
| overall | 3,099 | 0.488 | 1.253 | 3.917 |
| area_bottom_1% | 32 | 0.354 | 0.420 | 0.821 |
| **area_top_1%** | 31 | **0.685** | **1.567** | **8.217** |
| area_mid | 3,036 | 0.488 | 1.258 | 3.917 |

- **대형작(top 1%)에서 오차 급증**(MdAPE 0.685 vs mid 0.488, p95 8.2 vs 0.82). 면적 노이즈
  증폭 리스크가 실제로 관측됨 → 만약 채택했다면 면적 클립/대형작 fallback 가드가 필요했을 것.

## 5. 결론 — 기각

**크기 정규화 타깃 단독은 무익.** held-out 작가 기준 직접 타깃 대비 개선이 동전던지기(≈0.5)이고,
고정 test의 p95 이득은 일반화되지 않으며, 대형작에서 면적 노이즈가 직접 증폭된다. 트리 base가
크기↔가격 관계를 이미 충분히 학습하므로 타깃에서 면적을 떼는 재매개화의 추가 이득이 없음.

## 6. B(PP-CCOEF2)로의 인계

- A의 신호: **행 단위 크기 재매개화는 held-out 작가 분산을 robust하게 줄이지 못함.**
- B(PP-CCOEF2)는 행 단위가 아니라 **작가 단위 계수 집계(EB 수축) + 메타 회귀**라는 다른
  메커니즘이므로 별개로 검증할 가치는 있다. 다만 A 결과는 "계수 재매개화 자체의 추가 신호가
  작다"는 것을 시사하므로 **B의 천장도 낮을 가능성**을 정직히 전제하고 진행한다.
- 면적 노이즈 민감도는 B에도 동일 적용(B도 `exp(coef)×area` 복원) → B 평가에서 면적 극단
  슬라이스 재확인 필요.
