# Track6 모델 후보 종합 점수 기준

- 목적: 여러 평가 지표를 하나의 보조 점수로 묶어 모델 후보를 비교한다.
- 적용 대상: `WM1`, `CM1`처럼 여러 모델과 피처 조합을 한 번에 비교하는 실험
- 주의: 종합 점수는 최종 판단을 돕는 기준이다. 원본 지표인 `MdAPE`, `p95_APE`, `Within_30`, `RMSE_log`, `R2`도 함께 확인한다.

## 점수 계산 방식

- 각 지표를 실험 후보 안에서 `0~100점`으로 변환한다.
- 좋은 값일수록 `100점`에 가깝게 만든다.
- 변환된 지표 점수에 가중치를 곱해 합산한다.
- 최종 `composite_score`는 높을수록 좋다.

## 지표별 방향

| 지표 | 의미 | 방향 |
|---|---|---|
| `MdAPE` | 대표 비율 오차 | 낮을수록 좋음 |
| `p95_APE` | 큰 오차 구간의 위험도 | 낮을수록 좋음 |
| `Within_30` | 실제 가격의 30% 이내로 맞춘 비율 | 높을수록 좋음 |
| `RMSE_log` | 로그 가격 기준 오차 | 낮을수록 좋음 |
| `R2` | 가격 변동 설명력 | 높을수록 좋음 |

## 변환식

- 낮을수록 좋은 지표:
  - `지표점수 = (최댓값 - 현재값) / (최댓값 - 최솟값) * 100`
- 높을수록 좋은 지표:
  - `지표점수 = (현재값 - 최솟값) / (최댓값 - 최솟값) * 100`
- 후보 간 값이 모두 같으면:
  - 해당 지표는 후보를 구분하지 못하므로 모두 `100점`으로 처리한다.

## Warm 가중치

| 지표 | 비중 | 이유 |
|---|---:|---|
| `MdAPE` | 45% | Warm은 대표 예측 정확도가 가장 중요함 |
| `Within_30` | 20% | 실무적으로 꽤 근접하게 맞춘 비율 확인 |
| `p95_APE` | 20% | 큰 오차가 과도하게 늘어나는 후보 제외 |
| `RMSE_log` | 10% | 로그 가격 기준 안정성 확인 |
| `R2` | 5% | 설명력은 보조 기준으로 사용 |

## Cold 가중치

| 지표 | 비중 | 이유 |
|---|---:|---|
| `MdAPE` | 35% | 대표 예측 정확도는 여전히 중요함 |
| `p95_APE` | 30% | Cold는 신규 작가라 큰 오차 위험을 더 중요하게 봄 |
| `Within_30` | 20% | 실무적으로 근접하게 맞춘 비율 확인 |
| `RMSE_log` | 10% | 로그 가격 기준 안정성 확인 |
| `R2` | 5% | 설명력은 보조 기준으로 사용 |

## 결과 파일

- `metrics_scored.csv`: 원본 지표 + 지표별 점수 + 종합 점수
- `result_sheet_scored.csv`: 보기용 점수 결과
- `result_sheet.html`: 종합 점수 기준 HTML 리포트
