# Warm/Cold 가격 예측 서비스 운영 적용 계획

- 작성일: 2026-06-11
- 문서 목적: 최종 Warm/Cold 리포트 모델을 실제 서비스에 적용하기 위한 운영 기준, 입력 정책, 계산 설명, 사용자 피드백 수집 방식을 정리
- 버전 표기 원칙: 기존 구현은 `이전 버전(v0.1)`, 이번 적용 대상은 `다음 버전(v0.2)`으로 표기
- 기준 리포트: `partner_warm_cold_best_model_report.md`

## 1. 결론

- 이전 버전(v0.1)은 작가명 기반 artist_key 매칭 흐름을 이미 갖고 있음
- 다음 버전(v0.2)은 이전 버전(v0.1)의 작가 확인 흐름을 재사용하고, 최종 리포트의 Warm/Cold 모델 기준으로 라우팅과 예측 설명을 확장
- 사용자는 artist_key를 직접 입력하지 않음
- 사용자는 한글 작가명 또는 영문 작가명을 입력하고, 서비스가 내부 artist_key 후보를 찾아줌
- Cold는 정확도 보장 모델이 아니라 입력 정보 기반 예상 가격 안내 모델로 제공
- Cold라도 최소 입력 정보가 부족하면 단일 예상 가격을 보여주지 않음
- Cold 결과 화면에는 가격뿐 아니라 어떤 정보가 예측에 쓰였고 어떤 정보가 부족한지 함께 표시
- 실제 판매가를 나중에 입력할 수 있게 하여 모델 재학습 후보 데이터로 누적

## 2. 버전 구분

| 구분 | 이전 버전(v0.1) | 다음 버전(v0.2) |
|---|---|---|
| 서비스 기준 | `price_prediction_v0.1` 운영 구현 | `price_prediction_v0.2` 운영 적용안 |
| 작가 입력 | 한글명/영문명 입력 후 artist_key 후보 확인 | 동일하게 유지 |
| artist_key 입력 | 내부 테스트 옵션으로만 존재 | 일반 사용자 화면에서는 숨김 유지 |
| 작가 매칭 | alias/direct/fuzzy 후보 검색 | 매칭 점수와 Warm 가능 기준을 더 명확히 적용 |
| Warm 기준 | 유효 학습 가격 이력 1건 이상이면 Warm 가능 처리 | `작가매칭신뢰도점수 >= 0.90` AND `같은작가_사용가능가격이력수 >= 5` |
| Warm 모델 | v0.1 Warm operational blend | v0.2 최종 Warm 미세 보정 모델 |

| Cold 계산 설명 | 제한적 | 입력값, Quantile, 낮은쪽 40% 지점 가격, 과대예측 방어 설명 제공 |
| 사용자 보완 입력 | 제한적 | 부족 정보 표시, 추가 입력, 실제 판매가 입력 흐름 제공 |
| 학습 개선 루프 | 별도 운영 필요 | 예측 결과와 실제 판매가를 연결해 재학습 후보 데이터로 축적 |

### 4.2 Cold 최소 입력 정책

Cold라도 단일 예상 가격을 표시하려면 최소 입력 기준을 만족해야 함.

```text
Cold 예상 가격 표시 가능 =
  (한글 작가명 또는 영문 작가명 존재)
  AND (가로 cm 존재)
  AND (세로 cm 존재)
  AND (매체 존재)
  AND (지지체 존재)
```

| 입력 상태 | 서비스 처리 | 화면 표시 |
|---|---|---|
| 작가명 + 가로/세로 + 매체 + 지지체 존재 | Cold 예상 가격 표시 가능 | 예상 가격, 가격 범위, 낮은 신뢰도/중간 신뢰도 안내 |
| 작가명은 있으나 크기/매체/지지체 중 일부 누락 | 참고 범위만 표시 | 단일 예상 가격 숨김, 부족 정보 요청 |
| 작가명 없음 | 예측 보류 | 작가명 입력 요청 |
| 가로/세로 모두 없음 | 예측 보류 | 작품 크기 입력 요청 |
| 매체와 지지체 모두 없음 | 예측 보류 | 재료/지지체 입력 요청 |
| 동명이인 후보가 여러 명 | 예측 보류 | 후보 선택 또는 운영 검수 요청 |

### 4.3 신뢰도 하향 조건

| 조건 | 처리 |
|---|---|
| 제작연도 없음 | 예측 가능하나 신뢰도 하향 |
| 작가 생년/국적 없음 | Cold 신뢰도 하향 |
| 검색 피처 없음 | Cold 신뢰도 하향 |
| 동명이인 위험 있음 | 후보 선택 또는 검수 요청 |
| 입체 작품인데 depth 없음 | 예측 가능하나 신뢰도 하향 |
| Quantile예측구간폭이 넓음 | 가격 범위 넓게 표시, 과대예측 방어 적용 가능 |

## 5. 작가명 기반 artist_key 매칭

### 5.1 운영 원칙

- 사용자는 artist_key를 입력하지 않음
- artist_key는 모델 내부에서 사용하는 작가 식별자
- 사용자는 한글 작가명 또는 영문 작가명을 입력
- 서비스는 입력 작가명을 정규화하고 학습 작가 사전에서 후보 artist_key를 찾음
- 후보가 1명이고 매칭 신뢰도가 충분하면 자동 확정
- 후보가 여러 명이면 사용자 선택 또는 운영 검수로 이동

### 5.2 작가 확인 흐름

```text
[입력 작가명]
  - name_ko
  - name_en
        |
        v
[정규화]
  - 소문자 변환
  - 앞뒤 공백 제거
  - 연속 공백 축소
  - 하이픈/기호 완화
  - 한글명 공백 제거 후보 생성
  - 영문명 First Last / Last First 후보 생성
        |
        v
[artist alias 조회]
  - artist_key 직접 일치
  - 한글명 alias 일치
  - 영문명 alias 일치
  - 영문 slug 일치
  - fuzzy 후보 조회
        |
        v
[후보 검증]
  - 후보 수
  - 생년
  - 국적
  - 외부 작가 식별자
  - 동명이인 위험
        |
        v
[artist_key 확정 또는 후보 선택]
```

### 5.3 작가매칭신뢰도점수

```text
작가키가 직접 일치하면:
작가매칭신뢰도점수 = 1.00

작가키가 없거나 신뢰할 수 없으면:
작가매칭신뢰도점수 =
  clip(
      0.70 * 이름일치점수
    + 0.20 * 보조정보일치점수
    + 0.10 * 학습작가등록점수
    - 0.15 * 동명이인위험점수
    - 0.20 * 핵심정보충돌점수,
    0.00,
    0.95
  )
```

| 점수 예시 | 의미 | 처리 |
|---:|---|---|
| 1.00 | artist_key 직접 일치 | 가격 이력 수 확인 후 Warm 가능 |
| 0.95 | 이름 일치 + 생년 또는 외부 식별자 일치 | 가격 이력 수 확인 후 Warm 가능 |
| 0.80 | 이름은 일치하지만 보조 정보 부족 | Cold 또는 검수 |
| 0.60 | 검색/텍스트 기반 추정 | Cold |
| 0.00 | 같은 작가 근거 없음 | Cold 또는 예측 보류 |

## 6. Warm/Cold 라우팅 정책

### 6.1 다음 버전(v0.2) 라우팅 공식

```text
Warm 적용 여부 =
  (작가매칭신뢰도점수 >= 0.90)
  AND
  (같은작가_사용가능가격이력수 >= 5)

위 조건을 하나라도 만족하지 못하면 Cold
```

### 6.2 라우팅 처리표

| 조건 | route | 설명 |
|---|---|---|
| 작가매칭신뢰도점수 0.90 이상 + 같은 작가 가격 이력 5건 이상 | Warm | 같은 작가 가격 이력을 기준가격에 반영 가능 |
| 작가매칭신뢰도점수 0.90 이상 + 같은 작가 가격 이력 1~4건 | Cold | 표본이 적어 Warm 기준가격 불안정 |
| 작가매칭신뢰도점수 0.90 미만 | Cold | 작가 오매칭 위험 |
| 후보가 여러 명 | 예측 보류 | 사용자 선택 또는 검수 필요 |
| 작가명 없음 | 예측 보류 | 최소 입력 불충족 |

## 8. Cold 예상 가격 화면과 계산 설명

### 8.1 Cold 서비스 표시 원칙

- Cold는 정확 감정가가 아님
- Cold는 입력 정보 기반 예상 가격
- Cold는 신뢰도와 가격 범위를 함께 표시
- Cold는 어떤 정보가 예측에 쓰였는지 보여줘야 함
- Cold는 어떤 정보가 부족한지 보여줘야 함
- Cold는 실제 판매가 입력을 통해 모델 개선에 참여할 수 있게 해야 함

권장 화면 문구:

```text
입력 정보 기반 예상 가격입니다.
동일 작가의 충분한 가격 이력이 없거나 작가 매칭이 불확실한 경우,
작품 정보와 작가 정보, 검색 문맥을 함께 사용해 참고용 가격을 계산합니다.
정확 감정가 또는 판매 보장 가격은 아닙니다.
```

### 8.2 Cold 사용자용 계산식

```text
Cold 예상 가격 =
  작품 정보 기반 기준 가격
+ 작가 정보 보정
+ 검색 문맥 보정
- 과대예측 방어 보정
```

사용자 설명:

| 구성요소 | 쉬운 설명 |
|---|---|
| 작품 정보 기반 기준 가격 | 크기, 매체, 지지체, 제작연도, 작품 유형을 바탕으로 기본 가격대를 계산 |
| 작가 정보 보정 | 작가 생년, 국적, 활동량, 작품 수, 팔로워 수 등으로 가격대를 보정 |
| 검색 문맥 보정 | 작가명이 미술/전시/갤러리/시장 문맥에서 얼마나 확인되는지 반영 |
| 과대예측 방어 보정 | 예측 범위가 넓고 가격이 높게 잡힐 위험이 있으면 낮은쪽 40% 지점 가격 기준으로 일부 낮춤 |

### 8.3 Cold 운영 계산식

```text
검색피처포함_기초Quantile후보_로그가격
  = LightGBM_Quantile_회귀(
      작품피처
      + 작가메타피처
      + 검색피처
      + 검색상호작용피처
    )

Quantile예측구간폭 = 저장된_Quantile예측폭

낮은쪽40퍼센트기준_로그가격
  = LightGBM_40퍼센트_Quantile로그가격
```

```text
Quantile예측구간폭_구간 = bucket(Quantile예측구간폭)

구간별_잔차중앙값
  = median(실제_로그가격 - 검색피처포함_기초Quantile후보_로그가격)
    within same Quantile예측구간폭_구간

구간별_보정값
  = clip(구간별_잔차중앙값, -0.25, +0.25)

검색포함_대표로그가격
  = 검색피처포함_기초Quantile후보_로그가격 + 구간별_보정값
```

```text
방어조건 =
  (Quantile예측구간폭 >= 1.4612207078910142)
  AND (검색포함_대표로그가격 - 낮은쪽40퍼센트기준_로그가격 >= 0.07715547281151025)
  AND (낮은쪽40퍼센트기준_로그가격 < 검색포함_대표로그가격)
```

방어조건이 켜진 경우:

```text
과대예측방어_로그가격
  = 0.50 * 검색포함_대표로그가격
  + 0.50 * 낮은쪽40퍼센트기준_로그가격
```

방어조건이 꺼진 경우:

```text
과대예측방어_로그가격 = 검색포함_대표로그가격
```

최종 Cold 가격:

```text
최종_Cold_로그가격
  = 과대예측방어_로그가격 + 작가검색보정_로그값

최종_Cold_가격_KRW
  = exp(최종_Cold_로그가격)
```

### 8.4 낮은쪽 40% 지점 가격 설명

```text
낮은쪽 40% 지점 가격 =
모델이 예상한 가격들을 낮은 가격부터 높은 가격까지 줄 세웠을 때
40% 지점에 해당하는 가격
```

- 40% 할인이라는 뜻이 아님
- 가격을 40% 낮춘다는 뜻이 아님
- 과대예측 위험이 있을 때 대표 가격을 조금 더 낮은 기준으로 당겨오는 방어 기준

## 9. 입력값별 예측 역할

| 입력값 | Warm 역할 | Cold 역할 | 사용자에게 보여줄 설명 |
|---|---|---|---|
| 작가명 | artist_key 매칭, 같은 작가 가격 이력 확인 | 작가 메타와 검색 피처 연결 | 작가명은 예측 경로와 작가 정보 연결에 사용됩니다 |
| 작품 크기 | 유사작품 기준가격과 크기 효과 반영 | 기준가격 후보 생성의 핵심 피처 | 작품 크기는 가격대 계산에 큰 영향을 줍니다 |
| 매체 | 유사작품 비교 조건 | 재료별 가격 차이 반영 | 재료에 따라 가격 패턴이 달라집니다 |
| 지지체 | 유사작품 비교 조건 | canvas/paper/panel 등 가격 차이 반영 | 지지체는 매체와 함께 가격대에 영향을 줍니다 |
| 제작연도 | 작품 시기 보조 | 작가 경력 단계와 작품 시기 반영 | 제작연도가 없으면 신뢰도가 낮아질 수 있습니다 |
| 작가 생년/국적 | 작가 매칭 검증 보조 | 작가 세대/시장권역 신호 | 동명이인 구분과 가격 보정에 도움이 됩니다 |
| 검색 문맥 | 최종 Warm 미세 보정층에는 직접 사용하지 않음 | 작가 인지도, 전시/갤러리/시장 문맥 반영 | 검색 결과가 미술 문맥에 가까울수록 Cold 판단에 도움됩니다 |
| 실제 판매가 | 재학습 후보 데이터 | 재학습 후보 데이터 | 실제 판매가는 향후 모델 개선에 가장 직접적으로 도움이 됩니다 |
