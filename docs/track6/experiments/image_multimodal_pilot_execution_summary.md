# Track6 이미지 멀티모달 파일럿 실행 요약

- 목적: 작품 이미지 임베딩을 Cold 가격 예측에 추가했을 때 성능 개선 가능성이 있는지 확인.
- 참고 방법론: 작품 이미지를 CNN/CLIP 같은 이미지 모델로 수치 벡터화한 뒤, 기존 정형 피처와 결합해 가격을 예측하는 방식.
- 현재 결론: 이미지 단독 모델은 약하고, 정형 피처 + CLIP PCA 단순 결합은 기본 모델 채택 근거가 부족함. 다만 test MAPE/p95_APE 개선이 반복되어 tail 오차 방어 또는 residual 보정 후보로 유지함.

## 1. 준비 결과

| 항목 | 결과 |
|---|---|
| Track6 전체 행 수 | 33,892 |
| 이미지 URL 보유 행 수 | 30,946 |
| 전체 이미지 URL 보유율 | 약 91.3% |
| Cold test 이미지 URL 보유율 | 약 93.2% |
| URL 샘플 검증 | Saatchi/Artsy 20/20 성공 |
| 기존 임베딩 재사용 | 불가. 기존 인덱스는 `idx` 기준이고 Track6 기준 키는 `_track6_row_id` |
| Track6 전용 임베딩 방식 | `_track6_row_id` 기준으로 새로 생성 |

## 2. IMG-P1 결과

- 임베딩 규모:
  - train 200건
  - validation 200건
  - test 200건
- CLIP 임베딩:
  - 600건 대상
  - 600건 성공
  - 실패 0건

| 비교 | validation MdAPE | validation MAPE | validation p95_APE | test MdAPE | test MAPE | test p95_APE |
|---|---:|---:|---:|---:|---:|---:|
| 샘플 정형 LightGBM | 0.6736 | 1.4706 | 6.6115 | 0.6032 | 2.5680 | 14.0070 |
| 정형 + CLIP PCA32 | 0.5375 | 1.0038 | 4.5947 | 0.5682 | 1.4511 | 4.2944 |

해석:

- train 200건만 사용했는데도 정형+이미지 결합이 샘플 정형 기준보다 개선됨.
- 이미지 단독은 MdAPE 기준으로 약함.
- 이미지는 단독 예측 모델보다 정형 피처를 보완하는 보조 피처로 쓰는 방식이 더 적합함.

## 3. IMG-P2 결과

- 임베딩 규모:
  - train 992건
  - validation 200건
  - test 200건
- CLIP 임베딩:
  - 1,400건 대상
  - 1,392건 성공
  - 실패 8건
  - 실패 사유는 모두 Saatchi 이미지 URL 404

| 비교 | validation MdAPE | validation MAPE | validation p95_APE | test MdAPE | test MAPE | test p95_APE |
|---|---:|---:|---:|---:|---:|---:|
| 샘플 정형 LightGBM | 0.5630 | 0.8800 | 2.1251 | 0.5343 | 1.6339 | 8.7697 |
| 정형 + CLIP PCA16 | 0.5122 | 0.7842 | 2.0644 | 0.4980 | 1.2153 | 3.9720 |
| 정형 + CLIP PCA32 | 0.5473 | 0.8645 | 2.7690 | 0.4894 | 1.2190 | 3.4606 |

해석:

- train을 늘려도 이미지 결합 개선이 유지됨.
- PCA16은 validation에서 가장 안정적.
- PCA32는 test에서 MdAPE와 p95_APE가 가장 좋음.
- PCA64는 일부 tail 지표는 개선하지만 MdAPE가 불안정해 우선순위가 낮음.

## 4. IMG-P3 결과

- 임베딩 규모:
  - train 1,988건
  - validation 400건
  - test 400건
- CLIP 임베딩:
  - 2,800건 대상
  - 2,788건 성공
  - 실패 12건
  - 실패 사유는 모두 Saatchi 이미지 URL 404

| 비교 | validation MdAPE | validation MAPE | validation p95_APE | test MdAPE | test MAPE | test p95_APE |
|---|---:|---:|---:|---:|---:|---:|
| 샘플 정형 LightGBM | 0.4579 | 0.8243 | 2.6638 | 0.5031 | 1.5804 | 6.3018 |
| 정형 + CLIP PCA16 | 0.5059 | 0.9189 | 3.5725 | 0.5100 | 1.1849 | 4.1869 |
| 정형 + CLIP PCA32 | 0.5018 | 0.9582 | 3.6688 | 0.4884 | 1.1941 | 3.7407 |
| 정형 + CLIP PCA64 | 0.5214 | 0.8519 | 2.8125 | 0.5095 | 1.1954 | 3.7983 |

해석:

- test에서는 정형+CLIP PCA32가 샘플 정형 기준보다 MdAPE, MAPE, p95_APE를 모두 낮춤.
- 특히 test p95_APE는 6.3018에서 3.7407로 줄어 큰 오차 방어 효과가 있음.
- validation에서는 정형+CLIP 후보가 샘플 정형 기준보다 MdAPE가 악화됨.
- 따라서 IMG-P3는 이미지 결합 가능성을 강화하지만, 현재 단계에서 최종 채택 근거로 보기는 부족함.
- 다음 단계는 test 결과만 보고 후보를 고르지 않고, 고정 validation 기준으로 PCA16/PCA32를 중심으로 더 큰 Cold 이미지 가능 표본에서 재검증하는 것임.

## 5. IMG-P4 결과

- 임베딩 규모:
  - train 24,367건
  - validation 2,535건
  - test 2,886건
- CLIP 임베딩:
  - 29,970건 대상
  - 29,788건 성공
  - 실패 182건
  - 성공률 0.9939
  - 실패는 모두 Saatchi HTTPError

| 비교 | validation MdAPE | validation MAPE | validation p95_APE | test MdAPE | test MAPE | test p95_APE |
|---|---:|---:|---:|---:|---:|---:|
| 샘플 정형 LightGBM | 0.4076 | 0.6961 | 2.2053 | 0.4726 | 1.3468 | 4.5763 |
| 정형 + CLIP PCA16 | 0.4455 | 0.8045 | 2.9688 | 0.4787 | 1.2711 | 4.4706 |
| 정형 + CLIP PCA32 | 0.4427 | 0.8172 | 3.0099 | 0.4723 | 1.2371 | 4.4606 |
| 정형 + CLIP PCA64 | 0.4403 | 0.7260 | 2.3487 | 0.4841 | 1.2757 | 4.2776 |

해석:

- 전체 이미지 가능 표본으로 확장해도 이미지 단독 모델은 정형 기준보다 약함.
- test에서는 정형+CLIP PCA32가 MAPE와 p95_APE를 낮춤.
- test MdAPE 개선은 0.4726에서 0.4723으로 매우 작음.
- validation에서는 정형+CLIP PCA16/32/64가 모두 샘플 정형 LightGBM보다 악화됨.
- 따라서 CLIP 결합을 Cold 기본 모델로 바로 채택하기는 어려움.
- 다만 test에서 반복적으로 MAPE/p95_APE가 낮아지는 경향은 있으므로, 이미지는 기본 예측 모델보다 tail 오차 방어용 보조 피처 또는 residual 보정 후보로 남김.

## 6. 기존 전체 정형 모델 참고 기준과 비교

| 후보 | test MdAPE | test MAPE | test p95_APE |
|---|---:|---:|---:|
| 전체 Cold CatBoost 참고 기준 | 0.4908 | 2.1338 | 5.0367 |
| 전체 Cold LightGBM 참고 기준 | 0.5204 | 1.7956 | 8.1969 |
| IMG-P2 정형 + CLIP PCA32 | 0.4894 | 1.2190 | 3.4606 |
| IMG-P3 정형 + CLIP PCA32 | 0.4884 | 1.1941 | 3.7407 |
| IMG-P4 정형 + CLIP PCA32 | 0.4723 | 1.2371 | 4.4606 |

해석:

- IMG-P2 정형+CLIP PCA32는 같은 200건 test 샘플에서 전체 Cold CatBoost 참고 기준과 MdAPE가 거의 같음.
- MAPE와 p95_APE는 더 낮음.
- 이는 이미지 임베딩이 큰 오차를 줄이는 보조 신호로 유효할 가능성을 보여줌.
- IMG-P3에서도 test 기준으로 MAPE와 p95_APE 개선 신호가 유지됨.
- 단, IMG-P3 validation에서는 전체 Cold LightGBM 참고 기준과 샘플 정형 기준이 더 좋았으므로 최종 채택은 전체 이미지 가능 샘플에서 재검증해야 함.
- IMG-P4 전체 확장에서도 test MAPE/p95 개선은 유지되지만 validation 악화가 확인됨.

## 7. 현재 판단

- 이미지 실험은 계속 진행할 가치가 있음.
- Cold에서 우선순위가 높음.
- Warm은 Cold에서 기본 모델 채택이 아니라 보조 피처 성격이 확인된 뒤 확장하는 것이 적절함.
- 다음 후보는 PCA32와 PCA64를 tail 방어/잔차 보정 관점에서 재설계.
- 이미지 단독 모델은 우선순위를 낮춤.
- 현재까지의 가장 현실적인 가설은 "이미지 임베딩이 가격 중심값을 단독으로 맞히기보다, 정형 모델의 큰 오차를 줄이는 보조 신호로 작동한다"는 것임.
- 전체 표본 기준으로는 CLIP을 정형 피처에 단순 결합하는 방식은 기본 모델 채택 근거가 부족함.

- validation 기준으로 개선되는 조건부 적용 구간 탐색.
