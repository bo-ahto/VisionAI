# Track6 A~J 피처별 영향도 분석

## 분석 기준
- 영향도는 모델 내부 계수만이 아니라, 실험 결과의 성능 변화로 판단한다.
- 기준 지표는 `MdAPE`다. 낮을수록 대표 예측 오차가 작다.
- 개선율 계산식: `(기준 MdAPE - 비교 MdAPE) / 기준 MdAPE * 100`.
- Warm과 Cold는 다른 예측 상황이므로 분리해서 해석한다.
- 이 분석은 인과관계 증명이 아니라, 현재 split과 실험 조건에서의 예측 기여도 판단이다.

## 판정 기준
- `강한 개선`: MdAPE 10% 이상 개선
- `의미 있는 개선`: MdAPE 3% 이상 개선
- `소폭 개선`: MdAPE 1% 이상 개선
- `거의 변화 없음`: -1% 초과 ~ 1% 미만
- `악화`: MdAPE가 1% 이상 나빠짐
