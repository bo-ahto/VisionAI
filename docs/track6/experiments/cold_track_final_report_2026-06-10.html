3. 최고 성능 모델 — v0.3 체인 (피처·로직·계산식)

단일 모델이 아니라 상류 Quantile 모델 + 3단 보정 체인. 각 층이 서로 다른 오차 원인을 직교 방어(가산성 검증: redundancy gap ≈ 0).

3.1 상류 — LightGBM Quantile (PP-Y18 계열)

  • 분위수 4개 학습: q10 / q40 / q50 / q90 — 대표 점 예측 = q50, 불확실성 = quantile_width = q90 − q10
  • 피처 3축:
    • ① 작품 기본: width_cm, height_cm, depth_cm, area_cm2, log_area, aspect_ratio, has_depth, is_3d_candidate, medium_category, support_category, size_bucket, support_size_bucket
    • ② 작가 메타(외부 출처 — cold 작가도 보유 가능): 생년, 팔로워, 총작품수 등
    • ③ 검색 피처(search_all) + 외부 상호작용: 작가 검색 결과수, 소스군 비율(gallery_museum/market/news/social…), 미술 맥락 카운트와 상호작용
  • 검색 피처의 가치: search-free 변형(v0.2) MdAPE 0.4852 vs 검색 포함 체인 0.4098 — Cold 최대 단일 신호

3.2 ① qwidth 구간 OOF median 보정 (qwidth_bin_oof_min30_cap0.25)

보정값(행) = clip( median( validation OOF 잔차 | 행의 qwidth bin ), −0.25, +0.25 )   # bin 표본 ≥ 30
대표' = q50 + 보정값
  • 로직: 불확실성 폭이 큰 구간은 잔차가 계통적으로 치우침(주로 과소예측) → 구간 중앙값만 OOF로 학습해 가산(행 단위가 아니라 구간 단위 = 과적합에 강함)
  • 효과: 0.4421/1.048/3.354 → 0.4247/0.991/3.305 · artist holdout 반복검증 통과(PP-Y21)

3.3 ② guard — 과대예측 하향 블렌드 (PP-QR4)

발동: qwidth ≥ 1.4612 (val q67)  AND  (대표' − q40) ≥ 0.0772 (val q50)  AND  q40 < 대표'
발동 시: 대표'' = 0.5 × 대표' + 0.5 × q40        # 미발동 행은 그대로
  • 로직: "불확실성 크고 + 하위 분위수(q40)와 괴리가 큰" 행 = 과대예측 위험 → 그 행만 q40 방향으로 절반 이동(위쪽 꼬리 절단)
  • 임계값은 전부 validation의 정답 미사용 분위수 → 운영 재현 가능
  • 효과: → 0.4178/0.964/2.538 (p95 −23%) · row/artist 반복검증 양쪽 통과한 Cold 최초의 견고 방어층

3.4 ③ 작가단위 검색 delta (PP-H23/H28, frozen lookup 372작가)

작가 세그먼트(검색결과 중 gallery_museum 소스 비율):
  ratio = 0        → none → delta = −0.0313     # 전역 하향 bias 보정
  0 < ratio ≤ 임계 → low  → delta = −0.20       # 검색되지만 기관 노출 없음 = 과대예측 보정
  ratio > 임계     → high → delta = +0.20       # 기관 노출 많음 = 과소예측 보정
  (delta = validation 잔차의 세그먼트별 중앙값, cap ±0.2 — 작가 상수로 동결)

최종 로그가격 = 대표'' + delta(작가)
미커버 작가 → 상수 −0.0313 (v0.4 활성, 2026-06-10 결정)
최종 가격(KRW) = exp(최종 로그가격)
  • 로직: 검색층의 본질 = 전역 bias 보정 + 미술기관 노출 신호의 양방향 가격대 보정 (PP-CSRCH1 분해로 확인)
  • guard와 가산적(중복 없음) · 효과: → 0.4098/0.8493/2.3465 (base 대비 누적 p95 −29%)

3.5 정책층 v0.4 (점 예측 불변)

  • 신뢰도 tier(정답 미사용, 경계는 validation 분위수 동결):
    • low: qwidth ≥ val q90(2.157) OR 모델 gap |y18−v0.2| ≥ val q90(0.425)
    • high: qwidth ≤ q33(0.735) AND gap ≤ q50(0.153) AND 검색 커버 (low 아님)
    • 나머지 medium · test p95 분리: high(8.2%) 0.99 vs low(29.2%) 2.99
  • 표시: high = 점 예측+좁은 범위 / medium = q10~q90 범위(적중 ~74%) / low = 넓은 범위+우선 검수
  • 2단 검수: review_v03(qwidth≥1.4612 OR 미커버) OR priority(low tier)
  • 금지 동결: v0.2 단독 tier 표시(test 과신 역전) · tier 확장(test p95 0.99→4.4 붕괴)

4. raw-input 환경 — v0.5 이종 blend (피처·로직·계산식)

B = LightGBM Quantile(12 운영 피처, n_est 900) × 5-seed 예측 평균   # q10/q40/q50/q90
C = 선형 HuberRegressor 6구성 평균                                   # α∈{1e-4,1e-3} × ε∈{1.2,1.35,1.5} × 피처셋
    C 피처 = 크기 8종 + 비교군 사다리 통계 8종 + grp_price_proxy

최종 대표 = 0.7 × B_q50 + 0.3 × C
guard: width=B_q90−B_q10 기준, (대표−B_q40) gap 조건 충족 시 0.5×대표+0.5×B_q40  # 임계값은 blend 전 B 기준 val 분위수

비교군 사다리 (작가 미사용) — 첫 매칭 그룹 사용

  • L1: medium_support_bucket × size_bucket (표본 ≥ 30) → L2: medium + support + size (≥30) → L3: medium × size (≥50) → L4: 전체 train fallback
  • 그룹 통계 피처: 로그가격 중앙값/Q25/Q75/IQR, 면적단가(ln_price − log_area) 중앙값/IQR, 표본수 log, 매칭레벨
  • grp_price_proxy = 면적단가 중앙값 + log_area = 비교군 기반 직접 가격 추정치 (MdAPE 비악화의 열쇠)

leakage 차단

  • C 학습: train 행의 그룹 통계는 5-fold 자기 fold 제외로 계산 (자기 가격이 자기 피처에 새지 않음)
  • 추론: full-train 동결 사다리 테이블(JSON) — 신규 행 raw-input 추론 가능

작동 원리와 한계

  • 17개 실험 중 유일하게 재현된 레버 = 계열 다양성: 트리(전역 분할) vs 선형(전역 계수+명시 비교군 통계)의 오차 구조가 다름 → 30% 블렌드로 test MAPE −3.5% / p95 −13%
  • 같은 통계를 트리 피처로 넣으면 무가치(트리는 categorical 분기로 기학습, PP-CGRP1) — 별도 선형 모델의 본체일 때만 가치
  • 한계(정직): MdAPE 반복 비악화 확률 0.12~0.28 (구조적 center-vs-tail) → all-metric 아님, p95 방어 목적별 채택(사용자 결정)
  • 재현 검증: 동결 예측기 ≡ PP-CBOOST3 fixed test, diff ≤ 4.4e-16

6. 확립된 원칙 (재실험 방지)

  • val→test 작가 구성 이동이 최대 리스크 — validation 내부 검증(artist holdout 포함)으로 감지 불가, fixed test 최종 1회가 과신 후보 3건을 거름
  • 콘텐츠 신호(이미지·텍스트)는 Cold 점 예측에 닫힘 — 가격 신호가 작가 내 유사성을 탐
  • 조합의 유일한 레버 = 계열 다양성 (동계열 meta/routing/kNN 전멸, 트리+선형만 작동)
  • 명시 그룹 통계: 트리 피처로는 무가치, 선형 모델 본체로는 유효
  • 검색층 = 전역 bias 보정 + 기관 노출 양방향 보정 — 현 공식의 delta는 신규 작가에 미전이(재적합엔 실제 cold 트래픽 잔차 필요)
  • 금지 3건: 0604 사용 / v0.2 단독 tier 표시 / tier 확장
