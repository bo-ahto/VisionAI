# PP-WMIN1 Warm 사다리 최소 표본 완화 검증 요약 — 게이트 통과 (강한 신호)

- 실행일: 2026-06-12 / 스크립트: `scripts/track6/run_pp_wmin1_warm_ladder_min_relaxation.py` / 폴더: `experiments/track6/PP-WMIN1_warm_ladder_min_relaxation/` (변형별 체크포인트)
- 배경: warm test 행의 41.2%가 최정밀 비교군(작가+재료/지지체+크기) 1~4건을 보유하나 현행 min5에 걸려 거친 레벨로 fallback (PP-SVC8의 40.7% 정밀 매칭률과 일치).
- 설계: 작가 사다리 min_n {5(현행)/2/1} proxy(Huber 6구성, fold-제외 통계) 비교 — **validation 선택 + artist-cluster bootstrap 게이트, test는 확인 1회** (test 선택 금지 원칙 준수).

## 결과

| 변형 | 정밀 매칭률(test) | validation MdAPE/MAPE/p95 | test (확인 1회) | 게이트 (vs min5) |
|---|---:|---|---|---|
| min5 (현행) | 40.7% | 0.1316 / 0.2336 / 0.7421 | 0.1533 / 0.2829 / 1.0552 | — |
| min2 | 67.9% | 0.1052 / 0.2085 / 0.6322 | 0.1182 / 0.2604 / 0.9265 | **통과** 1.0/1.0/0.97 |
| **min1** | **81.9%** | **0.0932 / 0.1895 / 0.6322** | **0.1087 / 0.2481 / 0.8378** | **통과** 1.0/1.0/0.98 |

- **min1이 전 지표 압도**: test MdAPE -29%, MAPE -12%, p95 -21% (vs min5 proxy). 소표본(1~4건) 정밀 그룹의 분산 우려는 기각 — "정밀 비교군 1건 > 거친 그룹 5건+"가 5+ 작가에서도 성립 (Warm-lite 발견과 일관된 원리).
- 단조성: min5 → min2 → min1 개선이 단조 — 임계 자체를 제거(min1)하는 것이 최적.

## 의미와 한계

- proxy min1의 test MdAPE 0.1087은 **운영 Warm(0.141)보다 낮음** — 단 이는 선형 proxy 기준 방향 신호이며, 운영 svc 파이프라인(10-seed + PPV8 + 보정 스택)에 min1을 반영하면 **그 위의 Codex 보정 스택(PP258 계열) 전체 재검증이 필요**.
- 권고: Warm 트랙(Codex 라인)의 차기 최우선 후보로 이관 — "svc 매칭 사다리 작가 레벨 min5→min1 + 전체 체인 재검증". 기대값은 현재까지 발견된 미수확 개선분 중 최대(41% 행의 비교군 정밀도 상승).

## 파트너 문서 함의

- "5건 = 그룹 통계 안정성을 위한 설계값" 서술은 유지하되, "완화 검증에서 정밀 매칭 우위 확인 — 본체 반영 검토 중"으로 갱신 가능 (운영 반영 결정 후).
