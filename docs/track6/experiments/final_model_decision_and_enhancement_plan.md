# Track6 Warm / Cold 모델 후보 확정 근거와 고도화 계획

- 목적: Track6 실험 결과를 바탕으로 Warm / Cold 예측 모델 후보를 정하고, 선택 근거와 후처리 고도화 방향을 명확히 정리한다.
- 기준 데이터: Track6 고정 split
- 기준 지표: `MdAPE`, `p95_APE`, `Within_30`, `RMSE_log`, `R2`, `composite_score`
- 현재 결론의 성격: 최종 운영 모델 배포 확정이 아니라, 후처리와 추가 검증을 진행할 `운영 1차 후보` 선정

## 1. Warm / Cold 적용 기준

- Warm:
  - 학습 데이터에 같은 작가가 존재하는 경우
  - 작가명 기반 가격대 학습이 가능함
  - 작가명, 작품 크기, 작가 학습 작품 수를 활용할 수 있음

- Cold:
  - 학습 데이터에 한 번도 등장하지 않은 작가의 경우
  - 작가명 효과를 학습할 수 없음
  - 작가명은 사용하지 않고, 작품 정보와 작가 메타 정보 중심으로 예측함

- 운영 라우팅 기준:
  - 입력 작가명이 학습 작가 목록에 매칭되면 Warm 모델 사용
  - 입력 작가명이 학습 작가 목록에 없으면 Cold 모델 사용
  - 작가명이 불확실하거나 동명이인 가능성이 있으면 Cold 또는 저신뢰 Warm으로 처리

## 2. Warm 모델 후보

### 선택 후보

- 모델: `Huber`
- 피처 조합:
  - `artist_name_ko`
  - `width_cm`
  - `height_cm`
  - `log_area`
  - `aspect_ratio`
  - `artist_works_log`

### 선택 근거

- `WM1` 종합 점수 기준 1위:
  - 피처 조합: `WM1-F3: F1 + 작가 학습 작품 수`
  - 모델: `Huber`
  - 종합 점수: `98.2730`
  - MdAPE: `0.1562`
  - p95_APE: `1.0548`
  - Within_30: `0.7364`
  - RMSE_log: `0.4128`
  - R2: `0.9081`

- 해석:
  - Warm에서는 작가명이 가장 강한 기준 정보로 작동한다.
  - 작가명만으로 부족하고, 실제 크기 정보가 함께 들어가야 예측력이 안정된다.
  - `artist_works_log`는 해당 작가의 학습 데이터가 얼마나 있는지를 반영하므로, 예측 신뢰도와 안정성에 도움이 된다.
  - `Huber`는 이상치가 많은 미술품 가격 데이터에서 선형 모델의 해석 가능성과 이상치 방어력을 함께 가진다.

### 보류 후보

- `artist_name_ko x log_area`
- `artist_name_ko x ln_estimated_ho`

- 이유:
  - MdAPE 단일 기준으로는 매우 좋은 결과가 나왔다.
  - 다만 작가별 교차항은 특정 작가에 과적합될 수 있다.
  - 운영에서는 신규 작품이나 학습 작품 수가 적은 작가에서 흔들릴 가능성이 있다.
  - 따라서 1차 운영 후보에는 넣지 않고, 고도화 실험 후보로 유지한다.

## 3. Cold 모델 후보

### 선택 후보

- 모델: `CatBoost`
- 피처 조합:
  - `ln_estimated_ho`
  - `nant_material_idx`
  - `nant_tool`
  - `nant_support`
  - `artist_meta_total_works`
  - `artist_meta_for_sale_works`
  - `artist_meta_followers`
  - `artist_meta_is_p1`

### 선택 근거

- `CM1` 종합 점수 기준 1위:
  - 피처 조합: `CM1-F2: 작품 기본 피처 + 활동량/인지도`
  - 모델: `CatBoost`
  - 종합 점수: `94.0240`
  - MdAPE: `0.4488`
  - p95_APE: `2.9885`
  - Within_30: `0.3304`
  - RMSE_log: `0.8797`
  - R2: `0.5519`

- 해석:
  - Cold는 작가명을 사용할 수 없기 때문에 Warm보다 예측 난이도가 높다.
  - 작품 자체 정보만으로는 가격대 설명에 한계가 있다.
  - 작가의 활동량, 판매 노출량, 플랫폼 인지도 정보가 추가될 때 Cold 예측력이 개선된다.
  - CatBoost는 범주형 피처와 비선형 관계를 다루는 데 강점이 있어 Cold 후보군에서 가장 균형이 좋았다.

### 안정성 보조 후보

- 모델: `HistGradientBoosting` 또는 `LightGBM`
- 피처 조합:
  - 활동량/인지도와 호수 또는 면적의 교차 효과 포함

- 이유:
  - 일부 실험에서 p95_APE가 더 낮아 큰 오차 방어에 유리했다.
  - 다만 MdAPE와 Within_30이 항상 가장 좋지는 않았다.
  - Cold는 단일 모델만 고정하기보다, 고위험 구간 후처리 또는 fallback 후보로 관리하는 것이 적절하다.

## 4. Warm / Cold 결론 비교

| 구분 | 1차 후보 모델 | 핵심 피처 | 대표 성능 | 해석 |
|---|---|---|---|---|
| Warm | Huber | 작가명 + 실제 크기 + 작가 학습 작품 수 | MdAPE 약 `15.6%` | 서비스 적용 가능성이 높음 |
| Cold | CatBoost | 작품 기본 피처 + 작가 활동량/인지도 | MdAPE 약 `44.9%` | 단일 가격만 제공하기에는 위험이 큼 |

- Warm은 예측 정확도가 비교적 안정적이다.
- Cold는 대표 오차와 큰 오차 위험이 모두 크다.
- 따라서 Warm과 Cold는 같은 방식으로 보여주면 안 된다.
- Warm은 단일 예측 가격 중심으로 제공 가능하다.
- Cold는 예측 가격과 함께 가격 범위, 신뢰도, 경고 문구를 같이 제공해야 한다.

## 5. 선택 근거 상세

### 5.1 Warm 후보를 고른 과정

| 단계 | 확인한 질문 | 확인한 결과 | 결론 |
|---|---|---|---|
| 작품 변수 확인 | 작가명을 빼고 작품 크기만으로 가격을 어느 정도 설명할 수 있는가 | A1 크기 단독 최고 Warm MdAPE는 `0.5052`, Within_30은 `0.3278`, R2는 `0.4930`이었다. 최종 Warm 후보 MdAPE `0.1562`, Within_30 `0.7364`, R2 `0.9081`과 비교하면 대표 오차가 약 3.2배 크고 30% 이내 적중률은 절반 이하이다. | 크기는 가격대 설명의 기본 신호지만 Warm 최종 예측에는 작가명과 결합해야 함 |
| 작가명 효과 확인 | 작가명을 넣으면 가격대 설명력이 크게 좋아지는가 | WM1 상위 조합은 모두 `artist_name_ko`를 포함했다. 작가명 + 전체 크기 Huber는 MdAPE `0.1566`, R2 `0.9080`으로 크기 단독보다 크게 개선됐다. | Warm에는 `artist_name_ko` 유지 |
| 작가명 + 작품 변수 확인 | 작가명을 넣은 뒤에도 크기 정보가 추가 설명력을 가지는가 | `artist_name_ko + width_cm + height_cm + log_area + aspect_ratio` 조합이 WM1 4위였고 MdAPE `0.1566`, Within_30 `0.7315`였다. 작가명만으로 가격대를 잡는 것보다 실제 작품 크기를 같이 넣는 쪽이 안정적이다. | 실제 크기 묶음 유지 |
| 작가 학습 작품 수 확인 | 학습 데이터에 해당 작가 작품이 많은지 여부가 예측 안정성에 도움이 되는가 | `artist_works_log` 추가 조합이 WM1 종합 점수 1위였다. 작가명 + 전체 크기 대비 MdAPE는 `0.1566`에서 `0.1562`로 소폭 개선, Within_30은 `0.7315`에서 `0.7364`로 개선됐다. | `artist_works_log` 유지 |
| 모델군 비교 | 같은 피처 조합에서 어떤 모델이 가장 안정적인가 | WM1에서 Huber가 종합 점수 1~5위를 모두 차지했다. 같은 상위 피처에서 Linear/Ridge보다 MdAPE와 Within_30 균형이 좋았다. | Warm 1차 모델은 Huber |

### 5.2 Warm 후보 성능 근거

- `WM1-F3: F1 + 작가 학습 작품 수` + `Huber`
  - 종합 점수: `98.2730`
  - MdAPE: `0.1562`
  - p95_APE: `1.0548`
  - Within_30: `0.7364`
  - RMSE_log: `0.4128`
  - R2: `0.9081`

- 이 조합을 고른 이유:
  - MdAPE 단일 최저 후보는 아니지만, Within_30과 RMSE_log까지 포함한 균형이 가장 좋았다.
  - 작가명과 실제 크기만 쓰는 후보보다 학습 데이터 내 작가 작품 수를 추가했을 때 종합 점수가 가장 높았다.
  - 작가명 교차항 후보는 MdAPE는 좋았지만 과적합 가능성이 있어 1차 운영 후보에서는 보류했다.

| 상호작용 확인 | 활동량/인지도와 크기 조합이 큰 오차를 줄이는가 | CM1-F5 일부 모델은 p95_APE `2.9012`로 CM1-F2 CatBoost의 `2.9885`보다 낮았지만 MdAPE는 `0.4666`으로 더 나빴다. 큰 오차 방어에는 가능성이 있으나 대표 오차 기준 1위는 아니다. | 안정성 보조 후보로 유지 |

- `CM1-F2: 작품 기본 피처 + 활동량/인지도` + `CatBoost`
  - 종합 점수: `94.0240`
  - MdAPE: `0.4488`
  - p95_APE: `2.9885`
  - Within_30: `0.3304`
  - RMSE_log: `0.8797`
  - R2: `0.5519`

- 이 조합을 고른 이유:

## 6. 모델이 피처를 활용하는 방식

### 6.1 Warm Huber 모델

- Huber는 선형 회귀 계열 모델이다.
- 기본 구조는 `가격 = 기준값 + 피처별 영향도 합`으로 이해할 수 있다.
- 일반 선형 회귀와 다른 점은 큰 이상치에 덜 흔들리도록 학습한다는 점이다.
- 미술품 가격은 일부 작품 가격이 매우 높거나 낮은 경우가 많기 때문에, Huber가 일반 선형 회귀보다 안정적으로 작동할 수 있다.

#### Warm 피처가 가격 예측에 쓰이는 방식

| 피처 | 모델에서의 역할 | 해석 |
|---|---|---|
| `artist_name_ko` | 작가별 기본 가격대 반영 | 같은 크기와 재료라도 작가에 따라 가격대가 달라지는 효과를 반영 |
| `width_cm`, `height_cm` | 실제 가로/세로 크기 반영 | 작품이 실제로 얼마나 큰지 반영 |
| `log_area` | 면적 효과 반영 | 면적이 커질수록 가격이 증가하는 경향을 완만하게 반영 |
| `aspect_ratio` | 형태 비율 반영 | 같은 면적이라도 가로형/세로형/정방형 차이를 반영 |
| `artist_works_log` | 학습 데이터 내 작가 작품 수 반영 | 해당 작가를 모델이 얼마나 많이 학습했는지 반영 |

#### Warm 피처 선택 근거

- A~D 실험에서 작품 크기, 면적, 작가명, 작가명과 작품 변수 조합을 순차적으로 비교했다.
- C/D 계열 실험에서 작가명을 포함한 뒤에도 실제 크기 정보가 성능 개선에 기여하는지 확인했다.
- WM1 실험에서 Warm 상위 피처 조합을 고정하고 여러 모델을 비교했다.
- 결과적으로 `artist_name_ko + 실제 크기 + artist_works_log` 조합이 종합 점수 기준 가장 균형적이었다.
- Huber는 해당 피처 조합에서 MdAPE, p95_APE, Within_30, RMSE_log, R2의 균형이 가장 좋았다.

#### Warm 모델 해석 방법

- Huber는 선형 계수를 확인해 각 피처가 예측 가격을 올리는 방향인지 내리는 방향인지 볼 수 있다.
- 작가명은 one-hot 처리되므로, 특정 작가명이 기준 가격대에 어느 정도 영향을 주는지 비교할 수 있다.
- 단, 작가명 계수는 해당 작가의 과거 학습 데이터에 의존하므로 학습 작품 수가 적은 작가는 해석을 조심해야 한다.

#### Huber 계수 확인 절차

- 모델 학습 후 `coef_` 값을 확인한다.
- 숫자형 피처는 `StandardScaler`로 표준화된 상태에서 계수를 비교한다.
- 범주형 작가명은 one-hot 피처로 변환된 뒤 계수를 확인한다.
- 이때 각 작가명 계수는 “그 작가일 때 기준 가격대가 얼마나 위/아래로 이동하는지”를 뜻한다.
- 계수가 `+`이면 해당 피처 값이 커질수록 예측 로그가격을 올리는 방향으로 작동한다.
- 계수가 `-`이면 해당 피처 값이 커질수록 예측 로그가격을 낮추는 방향으로 작동한다.
- 절대값이 클수록 해당 피처가 예측값에 더 크게 반영된 것으로 해석한다.
- 예를 들어 `log_area` 계수가 양수이면 면적이 큰 작품일수록 가격 예측값이 높아지는 방향이다.
- `artist_name_ko`는 작가별 더미 변수로 변환되므로, 특정 작가 계수가 양수이면 기준 작가군보다 높은 가격대로 학습됐다는 뜻이다.
- 단, 작가명 계수는 학습 작품 수가 적은 작가에서는 불안정할 수 있으므로 `artist_works_log`와 함께 해석한다.
- 이번 해석 산출물 생성 시 Huber 수렴 경고가 발생했다. 성능값은 WM1 결과와 동일하게 재현됐지만, 계수는 정식 설명용 확정값이 아니라 방향성 점검용으로 우선 사용한다. 최종 설명 모델로 쓰려면 `max_iter` 상향 또는 Ridge 계수와 교차 확인이 필요하다.

#### Huber 계수 확인 결과

| 구분 | 피처 | 계수 | 해석 |
|---|---:|---:|---|
| 숫자형 | `log_area` | `+0.7385` | 면적이 커질수록 예측 로그가격을 올리는 방향이다. Warm에서 실제 크기 정보 중 가장 강하게 작동했다. |
| 숫자형 | `width_cm` | `+0.1119` | 가로 크기가 커질수록 예측 가격을 올리는 방향이다. |
| 숫자형 | `height_cm` | `+0.0808` | 세로 크기가 커질수록 예측 가격을 올리는 방향이다. |
| 숫자형 | `aspect_ratio` | `+0.0260` | 형태 비율 효과는 있으나 면적보다 영향이 작다. |
| 숫자형 | `artist_works_log` | `+0.0003` | 방향은 양수지만 계수 크기는 작다. 직접 가격을 크게 올리는 피처라기보다 예측 안정성 보조 피처로 해석한다. |

| 작가명 계수 확인 | 확인 내용 | 해석 |
|---|---|---|
| 큰 양수 계수 작가 | 일부 작가명 one-hot 계수가 `+3` 이상으로 나타남 | 해당 작가의 학습 가격대가 기준 작가군보다 높게 학습됐다는 뜻이다. |
| 큰 음수 계수 작가 | 일부 작가명 one-hot 계수가 `-3` 이하로 나타남 | 해당 작가의 학습 가격대가 기준 작가군보다 낮게 학습됐다는 뜻이다. |

#### Huber 해석 산출물

- 전체 계수 표:
  - 피처명
  - 계수값
  - 방향
  - 절대 영향도 순위
- 숫자형 피처 계수 표:
  - `width_cm`, `height_cm`, `log_area`, `aspect_ratio`, `artist_works_log`
- 작가명 계수 표:
  - 상위 양수 작가
  - 상위 음수 작가
  - 작가별 학습 작품 수

### 6.2 Cold CatBoost 모델

- CatBoost는 트리 부스팅 계열 모델이다.
- 여러 개의 작은 의사결정 트리를 순차적으로 쌓아 예측 오차를 줄인다.
- 선형 모델처럼 피처 영향이 항상 직선 형태라고 가정하지 않는다.
- 재료, 지지체, 호수, 작가 메타 정보처럼 범주형/숫자형이 섞인 데이터에서 비선형 관계를 잡는 데 유리하다.

#### Cold 피처가 가격 예측에 쓰이는 방식

| 피처 | 모델에서의 역할 | 해석 |
|---|---|---|
| `ln_estimated_ho` | 작품 크기 대표값 | 호수가 커질수록 가격대가 달라지는 효과 반영 |
| `nant_material_idx` | 표준화된 재료 번호 | 유화, 아크릴, 혼합재료 등 재료별 가격 차이 반영 |
| `nant_tool` | 제작 도구/기법 정보 | 재료만으로 설명되지 않는 제작 방식 차이 반영 |
| `nant_support` | 표준화된 지지체 | 캔버스, 종이, 패널 등 바탕 차이 반영 |
| `artist_meta_total_works` | 작가 등록 작품 수 | 작가 활동량 또는 데이터상 노출량 반영 |
| `artist_meta_for_sale_works` | 판매 중 작품 수 | 시장에 현재 노출된 작품량 반영 |
| `artist_meta_followers` | 플랫폼 팔로워 수 | 플랫폼 내 인지도 반영 |
| `artist_meta_is_p1` | 주요 작가 여부 | 플랫폼이 표시한 주요 작가 신호 반영 |

#### Cold 피처 선택 근거

- Cold는 작가명을 사용할 수 없으므로 작품 기본 피처와 작가 메타 피처를 중심으로 실험했다.
- A 그룹 실험에서 호수, 재료, 지지체 등 작품 기본 피처의 효과를 확인했다.
- E~G 그룹 실험에서 작가 메타 정보가 작가명 없이도 가격 설명에 도움이 되는지 확인했다.
- I/J 그룹 실험에서 작품 기본 피처와 작가 메타 조합, 상호작용 효과를 검토했다.
- CM1 실험에서 Cold 상위 피처 조합을 여러 모델에 적용해 비교했다.
- 결과적으로 `작품 기본 피처 + 활동량/인지도` 조합과 CatBoost가 종합 점수 기준 가장 균형적이었다.

#### Cold 모델 해석 방법

- CatBoost는 선형 계수 대신 피처 중요도와 SHAP 값으로 해석하는 것이 적절하다.
- 피처 중요도는 전체 예측에서 어떤 피처가 많이 쓰였는지 보여준다.
- SHAP 값은 개별 작품 예측에서 어떤 피처가 가격을 올리거나 내렸는지 설명할 수 있다.
- 예를 들어 특정 작품의 예측가가 높게 나온 경우, `ln_estimated_ho`, `nant_material_idx`, `artist_meta_followers` 중 어떤 값이 상승 요인인지 확인할 수 있다.

#### CatBoost 영향도 확인 절차

- 모델 학습 후 `feature_importances_` 또는 CatBoost의 feature importance를 확인한다.
- 전체 예측에서 어떤 피처가 많이 사용됐는지 순위를 만든다.
- SHAP 값을 계산해 각 작품별 예측에서 어떤 피처가 가격을 올렸는지, 낮췄는지 확인한다.
- 전체 평균 SHAP 절대값을 계산해 전역 중요도를 확인한다.
- 개별 작품 SHAP 값을 확인해 특정 예측 결과의 설명 문구를 만들 수 있다.
- 예를 들어 어떤 Cold 작품에서 `artist_meta_followers` SHAP 값이 양수이면, 플랫폼 인지도가 예측 가격을 올린 요인으로 해석할 수 있다.
- `nant_material_idx`나 `nant_support`의 SHAP 값이 특정 작품에서 크게 작동하면, 재료/지지체 조합이 가격 판단에 크게 반영된 것이다.

### 6.3 피처와 모델을 고른 방식

- 피처는 한 번에 모두 넣어서 고른 것이 아니다.
- 실험군별로 피처를 분리해 영향도를 확인했다.
- 기본 흐름은 아래와 같다.
  - 작품 변수만 사용
  - 작가명만 사용
  - 작가명 + 작품 변수 사용
  - 작품 변수끼리 조합
  - 작가 메타 변수 추가
  - 작가 메타 + 작품 변수 조합
  - 상위 피처 조합에서 모델군 비교

- 모델 선택은 단일 지표 1위만 보지 않았다.
- `MdAPE`, `p95_APE`, `Within_30`, `RMSE_log`, `R2`를 종합 점수로 변환해 비교했다.
- Warm은 대표 오차와 안정성이 모두 좋은 Huber를 선택했다.
- Cold는 대표 오차, 큰 오차 위험, 범주형/비선형 처리력을 함께 고려해 CatBoost를 선택했다.

## 7. 후처리 고도화 계획

### 7.1 가격 범위 제공

- 목적:
  - 단일 예측 가격이 틀릴 수 있는 범위를 사용자에게 함께 제공한다.

- 방법:
  - validation 결과에서 실제 오차 분포를 계산한다.
  - Warm / Cold를 따로 계산한다.
  - 예측 가격 주변에 `보수적 가격 범위`를 붙인다.

- 예시:
  - 예측 가격: `100만 원`
  - Warm 가격 범위: `약 80만~125만 원`
  - Cold 가격 범위: `약 50만~200만 원`

- 주의:
  - Cold 범위는 넓게 나올 가능성이 높다.
  - 범위가 너무 넓으면 단일 가격 예측 서비스보다 참고용 추정 서비스에 가깝게 안내해야 한다.

### 7.2 신뢰도 점수 생성

- 목적:
  - 예측값을 그대로 믿어도 되는지 판단할 수 있게 한다.

- 후보 신뢰도 피처:
  - Warm:
    - `artist_works_log`
    - 해당 작가의 학습 작품 수
    - 예측 대상 작품 크기가 학습 범위 안에 있는지
  - Cold:
    - 작가 메타 정보 보유량
    - `artist_meta_completeness_score`
    - 활동량/인지도 정보 존재 여부
    - 작품 크기가 극단값인지 여부

- 출력 방식:
  - `높음`
  - `보통`
  - `낮음`

### 7.3 위험 구간 경고

- 목적:
  - 큰 오차가 자주 발생하는 조건을 사전에 표시한다.

- Warm 위험 후보:
  - 학습 작품 수가 적은 작가
  - 작가명은 있지만 가격대가 넓게 분포한 작가
  - 극단적으로 큰 작품
  - 작가명 매칭 신뢰도가 낮은 경우

- Cold 위험 후보:
  - 작가 메타 정보가 거의 없는 경우
  - 활동량/인지도 정보가 없는 경우
  - 대형 작품 또는 특수 지지체
  - NANT 재료/지지체 분류가 불명확한 경우

### 7.4 예측값 보정

- 목적:
  - 모델이 특정 구간에서 반복적으로 높게 또는 낮게 예측하는 문제를 줄인다.

- 보정 후보:
  - 가격대별 보정
  - 작가 학습 작품 수 구간별 보정
  - Warm / Cold 별도 보정
  - 작품 크기 구간별 보정

- 적용 순서:
  - 먼저 validation에서 편향을 확인한다.
  - 같은 방향의 오차가 반복되는 구간만 보정한다.
  - test에는 마지막에 한 번만 적용한다.

  - 단체전 수
  - 아트페어 참여 수
  - 주요 기관 전시 여부
  - 수상 이력
  - 레지던시 이력

- 기대 효과:
  - Cold에서 작가명 없이도 작가의 시장 위치를 설명할 수 있다.
  - Warm에서도 저이력 작가의 신뢰도 판단에 사용할 수 있다.

### 8.2 시장 노출 정보

- 수집 후보:
  - 플랫폼 등록 작품 수
  - 판매 중 작품 수
  - 팔로워 수
  - 검색량
  - 언론/비평 기사 수
  - 갤러리 소속 여부

- 기대 효과:
  - Cold 예측 성능 개선 가능성이 높다.
  - 특히 현재 Cold 1위 후보가 활동량/인지도 피처를 포함하고 있으므로 우선 수집 가치가 있다.

### 8.3 갤러리/거래 맥락 정보

- 수집 후보:
  - 갤러리명
  - 갤러리 티어
  - 전속 여부
  - 출품 플랫폼
  - 전시 이력과 판매 이력의 연결

- 주의:
  - 실제 운영 입력 단계에서 사용자가 알 수 없는 정보는 모델 입력 피처로 직접 쓰지 않는다.
  - 다만 내부 작가 DB에서 자동 매칭 가능한 정보라면 후보 피처로 검토할 수 있다.

## 9. 다음 실험 계획

- 상세 계획 문서: `followup_experiment_plan.md`

### E1. Warm 가격 범위 보정 실험

- 대상: Warm Huber 1차 후보
- 목적: 단일 예측 가격 주변의 실무용 가격 범위를 계산한다.
- 확인 지표:
  - coverage
  - interval width
  - MdAPE 변화

### E2. Cold 가격 범위 보정 실험

- 대상: Cold CatBoost 1차 후보
- 목적: Cold 예측값을 서비스에 쓸 수 있는 범위로 제공 가능한지 확인한다.
- 확인 지표:
  - coverage
  - interval width
  - 고위험 구간별 coverage

### E3. Cold 신뢰도 라우팅 실험

- 목적:
  - Cold 전체를 하나로 보지 않고, 저위험/고위험 구간을 나눠 다른 안내 방식을 적용한다.

- 후보 기준:
  - 작가 메타 정보 보유량
  - 활동량/인지도 정보 존재 여부
  - 작품 크기 극단값 여부
  - NANT 분류 성공 여부

### E4. 외부 작가 DB 추가 후 재실험

- 목적:
  - 작가 경력/인지도/시장 노출 정보가 Cold 성능을 얼마나 개선하는지 검증한다.

- 우선 수집 순서:
  - 개인전/단체전/아트페어 수
  - 주요 기관 전시 여부
  - 수상 이력
  - 언론/검색량
  - 갤러리 소속/전속 여부

### E5. Warm 저이력 작가 fallback 실험

- 목적:
  - 학습 데이터에 작가가 있어도 작품 수가 적으면 Warm보다 Cold 방식이 안정적인지 확인한다.

- 확인 방식:
  - 작가별 학습 작품 수 구간을 나눈다.
  - Warm Huber와 Cold CatBoost 결과를 같은 작품에서 비교한다.
  - 특정 작품 수 이하에서는 Cold 또는 보수적 가격 범위를 적용할지 판단한다.

## 10. 운영 적용 방향

- 1차 운영안:
  - Warm: `Huber`
  - Cold: `CatBoost`
  - Warm / Cold 모델 분리
  - Cold는 가격 범위와 신뢰도 문구 필수

- 모델 입력 원칙:
  - 운영에서 입력 가능하거나 내부 DB로 자동 생성 가능한 피처만 사용한다.
  - 출처 자체는 모델 입력으로 쓰지 않는다.
  - 가격 정보와 직접 연결되는 피처는 사용하지 않는다.

- 최종 확정 전 필요한 작업:
  - Warm / Cold 가격 범위 보정
  - 신뢰도 점수 기준 설정
  - 위험 구간 문구 정의
  - 외부 작가 DB 보강 후 Cold 재검증
  - 최종 test 기준 재평가
