# PP-CCOEF2 — 콜드 2단계 작가계수 임퓨테이션(메타→Artist Coefficient) 요약

- 날짜: 2026-06-22
- 트랙: Track6 / Cold
- 실험 폴더: `experiments/track6/PP-CCOEF2_cold_artist_coefficient_imputation/`
- 계획: `docs/track6/experiments/PP-CCOEF1_2_cold_artist_coefficient_impl_plan.md`
- 선행: PP-CCOEF1(A) = 기각. 본 실험은 다른 메커니즘으로 종결 재도전.
- 상태: **종료 — 기각**

## 1. 목적

독일·이탈리아식 "작가 이력서 → 작가 Factor" 구조의 문자 그대로 구현.
- **1단계**: Warm(train) 작가별 계수 `coef_a = shrunk_median(ln(price/area))`, EB 수축 k=5
  (작은/거친 작가는 전역 중앙값으로 수축). 작가 1명 = 1행 (1,773명).
- **2단계**: `shrunk_coef ~ 메타 6피처`(생년·총작품수log·팔로워log·경력단계·전시총수log·갤러리등급)
  LightGBM 회귀, Warm 작가만 학습. OOF(KFold5)로 누수 점검.
- **콜드 추론**: 콜드 작가 메타 → `coef_hat` → `price = exp(coef_hat) × area`.
  메타 미보유 작가는 A(PP-CCOEF1)로 fallback.

행 단위 `log(가격)` 학습이던 기존 메타 실험(PP-CDATA1/2)과 달리 **작가 단위 집계 계수**를
타깃으로 둔 점이 신규.

## 2. 결과 (고정 cold test, n=3,099)

| | MdAPE | MAPE | p95_APE |
|---|---|---|---|
| v0.2 base | 0.4823 | 1.242 | 4.380 |
| A (PP-CCOEF1 size-norm) | 0.48835 | 1.2525 | 3.9168 |
| **B (메타→계수)** | **0.48870** | **1.7772** | **3.8278** |

- **coverage_rate = 1.0**: 콜드 test 전 작가가 메타 6필드 중 최소 1개 보유(플랫폼 메타 DB 100%
  커버와 정합). → A fallback은 실제로 발동하지 않음(B_blend = B). 즉 **메타가 실재하는 가장
  유리한 조건**에서의 평가.
- B의 중앙값(MdAPE)은 A·base와 사실상 동일(~0.488 vs base 0.482, 소폭 악화).
- **B의 MAPE는 1.777로 base(1.242) 대비 +43% 악화.** 작가당 단일 상수 계수 × 면적은 작가 내부
  크기 변동을 트리보다 거칠게 처리 → 일부 예측이 크게 빗나가 평균오차 폭증.
- p95는 A와 유사(계수×면적 복원의 꼬리 효과), base보다는 개선이나 이는 A에서도 동일.

## 3. 결론 — 기각

**메타→작가계수 임퓨테이션은 콜드 점예측을 개선하지 못함.** 메타가 모든 작가에 실재하는
최선 조건에서도 중앙값은 base와 동급, 평균오차(MAPE)는 크게 악화. 작가 단위로 집계한 계수를
메타로 예측해도, 그 계수를 면적에 곱하는 복원은 트리 base가 이미 하는 일보다 정보가 적다.

이는 트랙의 기존 진단([[track6-cold-search-meta-diagnosis]])과 정합:
- 메타의 관측 이득은 대부분 선택편향이며 운영 신규 작가로 전이되지 않음.
- 콜드 개선 레버는 새 모델 구조가 아니라 **Warm 커버리지 확대**(가격 이력 매칭으로 Cold→Warm).

## 4. PP-CCOEF1+2 종합 — "종결 재도전" 결과

리서치의 핵심 통찰(작품가격 = 크기 × 작가계수)은 옳지만, **그 계수는 작가 본인의 거래 이력이
있어야 의미가 있고(=Warm), Track6 Warm은 이미 이를 소진(pp_hcoef)**한다. 콜드 작가(이력 0)에게
계수를 부여하는 두 경로를 모두 시험:

| 경로 | 메커니즘 | 결과 |
|---|---|---|
| A (PP-CCOEF1) | 타깃을 `ln(price/area)`로 재매개화 (행 단위) | 기각 — held-out 작가 동전던지기, 면적 노이즈 증폭 |
| B (PP-CCOEF2) | 메타→작가계수 회귀 후 면적 곱 (작가 단위) | 기각 — base 동급 MdAPE, MAPE +43% 악화 |

**결론: 수집 없는 콜드 점예측은 데이터 프런티어에 있다는 기존 종결을 재확인.** 작가계수
재구조화(재매개화/임퓨테이션) 어느 쪽도 v0.2 base를 이기지 못함. 다음 레버는 변함없이
Warm 커버리지 확대.

## 5. 정직한 한계

- coverage가 1.0이라 "운영 희소 메타" 조건의 층화 마스킹은 발동하지 못함. 단 B는 **완전 메타
  조건에서도** 기각이므로, 더 희소한 메타에서는 더 나빠질 뿐 — 결론은 a fortiori 유지.
- 면적 노이즈 민감도(PP-CCOEF1 §4)는 B에도 동일 적용(B도 `exp(coef)×area` 복원).
- Task 7은 API 장애로 컨트롤러가 인라인 실행(OOF 누수 테스트는 통과). 독립 서브에이전트
  리뷰는 최종 whole-branch 리뷰에서 보강 대상으로 표시됨.
