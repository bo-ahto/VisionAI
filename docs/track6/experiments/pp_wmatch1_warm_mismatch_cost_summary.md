# PP-WMATCH1 작가 오매칭 비용 실측 요약 — "고신뢰 매칭" 기준의 정량 근거

- 실행일: 2026-06-12 / 스크립트: `scripts/track6/run_pp_wmatch1_warm_mismatch_cost.py` / 폴더: `experiments/track6/PP-WMATCH1_warm_mismatch_cost/`
- 질문: Warm(-lite) 라우팅의 전제인 "고신뢰 매칭(점수 ≥0.90)" 기준은 어떤 근거를 가져야 하는가?
- 설계: Warm proxy(작가 사다리 min1 + 선형 Huber, full train 학습)를 warm test 607행에 적용하되, 추론 시 작가 key를 ① 정매칭 ② 무작위 타작가 ③ 같은 장르(매체·지지체 버킷) 타작가로 바꿔 오매칭 비용을 실측. 0604 미사용.

## 임계값 함의 — 기대손실 비대칭 (근사 계산)

매칭 정확도 p일 때 `E[Warm] = p×정매칭 + (1−p)×오매칭`이 Cold보다 좋으려면:

- MAPE 기준: p > (2.69−0.675)/(2.69−0.249) ≈ **0.83**
- p95 기준: p > (9.54−2.17)/(9.54−0.82) ≈ **0.85**

즉 **매칭 실제 정확도가 ~85% 이상**이어야 Warm 라우팅이 Cold 대비 기대 우위 — 임계값 0.90은 이 최소선 위에 마진을 둔 보수 설정으로 정당화된다. (근사의 한계: 행 동일 p 가정, median 비선형 — 방향 근거로 사용)

## 결론

1. "장르가 비슷한 작가로 잘못 매칭되는 것"도 안전하지 않음(p95 9.35) — 이름 유사 혼동의 실위험 입증.
2. **임계값이 보장해야 할 것 = 오매칭률 ≤ ~15%.** 단 매칭 점수→실제 정확도 대응(캘리브레이션)은 라벨이 필요하므로 **운영 매칭 로그 수집·검수로 보정하는 과제**를 파트너 문서에 명시해야 함.
3. 동명이인(6.6%)·생년 결측(59%)이 실재하므로 "보조 정보 확인 전 Warm 금지" 보수 원칙은 데이터로 지지됨.
