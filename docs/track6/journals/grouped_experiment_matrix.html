작가 중심 신규 실험 가설 리스트

상사 예시를 참고해 새로 만드는 Track6 작가 중심 실험 설계안입니다. 작품 변수만 보는 A 그룹은 참조 정의로 상단에 두고, 작가 중심 검증을 B1부터 시작합니다. C와 D의 피처 구성은 C1 = B1 + A1, D3 = B1 x A8처럼 실험 번호를 조합해 표기합니다. 작가명 한글화와 동명이인 처리는 이미 정제 단계에서 반영된 전제 조건으로 두고 신규 실험 번호에서는 제외합니다. only 단일 변수 실험은 Group B에서만 관리하고, Group E/F는 단일 변수를 반복하지 않고 묶음과 결합 효과만 확인합니다. Group G는 Group D와 겹치지 않도록 작가명 자체가 아니라 작가 메타 묶음과 작품 변수의 교차항만 다룹니다.

Group C: 작품 기본 피처 묶음 + 작가 변수

기본 비교 방식은 작품 기본 피처 묶음과 작품 기본 피처 묶음 + 작가 변수입니다.

작품 기본 피처 묶음은 ln_estimated_ho + nant_material_idx + nant_tool + nant_support입니다. support_category는 nant_support와 중복되므로 기준선에서 제외하고 참고용 하위 실험에서만 봅니다.
