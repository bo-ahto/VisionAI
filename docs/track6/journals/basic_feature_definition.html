현재 기본 피처 후보 해석

  • Warm 기본 후보: artist_name_ko, ln_estimated_ho, 크기 파생 일부
  • Cold 기본 후보: ln_estimated_ho, medium_category/nant_material, depth/3D 후보
  • 재료와 3D/depth는 Cold 개선 신호가 있으므로 기본 피처 후보에 남기고 후속 검증 필요
  • 지지체는 개선폭이 작지만 Warm/Cold 모두 방향은 나쁘지 않아 보류 후보
  • 크기 파생은 Warm 개선이 뚜렷하고 Cold 개선은 제한적이므로 Warm 우선 후보
