## 3. 핵심 발견 정리

### 3.1 효과 있었던 것
1. **무효 피처 제거** — 노이즈 감소 → MdAPE -0.5%p
2. **global_median_price 보간** — 87.6% 결측 해소 → Warm 개선
3. **auction_house_tier** — 경매사 등급 정보 반영
4. **LightGBM 복원** — 3-모델 앙상블 다양성 확보
5. **시계열 피처** — Gap 3.43%p으로 감소
6. **가격대별 세그먼트 모델** — 참고용으로 유용하나 Blend보다는 열위

### 3.2 효과 없었던 것
1. **이미지 피처 (전체 적용)** — R² < 0, 성능 악화
2. **이미지 피처 (Cold 전용)** — Cold에서도 효과 없음
3. **이상치 클리핑** — 효과 미미 (+0.03%p)
4. **가격대별 모델 단독** — Ensemble보다 열위

### 3.3 Cold Start 문제의 본질
- Cold MdAPE 60% → **데이터 부족이 아닌 "작가 브랜드" 부재**
- 이미지로 보상 불가 → 소셜/경력 데이터가 해법
- `is_new_artist` 복원 시에도 Cold 개선 안 됨
- 근본 한계: Cold 작가는 과거 거래 없이 가격 예측이 본질적으로 어려움
