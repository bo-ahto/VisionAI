# 1차 시장 가격 예측 실험 결과 보고서

> **실험일**: 2026-04-13
> **데이터**: Artsy 한국 작가 5개 카테고리 9,975건 / 930명 작가
> **카테고리**: Painting, Mixed Media, Drawing/Collage/Paper, Photography, Print
> **모델**: XGBoost (기존 작가, MdAPE 9.7%) + CatBoost v2 (Cold Start, MdAPE 31.0%)

---

## 1. 호당 가격제 검증

한국 갤러리 가격 체계의 핵심 구조 `Price = α × Ho^β`를 Artsy 데이터로 검증했다.

### 검증 조건

Painting 중 Canvas/Linen + Unique + ho > 0인 작품 **5,276건**으로 검증.

### 가설 검증 결과

| 가설 | 기준 | 결과 | 판정 |
|------|------|------|:----:|
| **H1**: β ∈ [0.6, 0.9] | OLS β 추정 | **β = 0.817** (CI: 0.799~0.836) | 성립 |
| **H2**: KRW β가 0.74에 가까움 | KRW vs USD 비교 | KRW **β=0.749**, USD β=0.840 | 성립 |
| **H3**: CV<0.3 작가 50%+ | 303명 중 안정 비율 | **71%** (217명 안정) | 성립 |

### 핵심 발견

- **β = 0.817**: 작품 크기가 커질수록 가격이 체감 증가 (크기 2배 → 가격 1.76배)
- **KRW(국내) β = 0.749**: Shin(2010)의 0.74와 거의 일치. 국내 갤러리에서 호당 가격제가 실제로 작동
- **USD(국제) β = 0.840**: 국제 갤러리는 크기 프리미엄이 국내보다 더 강함
- **71% 안정**: 대부분의 작가가 호당가 기준으로 일관된 가격 책정

### 시나리오 판정: **A (호당 성립)**

→ 호당 이론 피처를 모델에 포함하는 Hybrid 접근이 유효함을 데이터로 확인.

## 2. 모델 성능

### 2.1 평가 방법

| 방법 | 설명 | 의미 |
|------|------|------|
| **GroupKFold** | 같은 작가가 train/val에 섞이지 않음 | Cold Start (새 작가 예측) |
| **KFold** | 같은 작가가 train/val에 섞일 수 있음 | 기존 작가 예측 (실서비스) |

### 2.2 모델 비교 (CatBoost vs XGBoost vs LightGBM)

동일 피처·동일 조건에서 3개 모델을 비교한 결과:

| 모델 | 기존 작가 MdAPE | 기존 작가 R² | Cold Start MdAPE | Cold Start R² |
|------|:--------------:|:----------:|:----------------:|:------------:|
| **XGBoost** | **9.7%** | **0.930** | 31.2% | 0.805 |
| LightGBM | 11.2% | 0.927 | 33.1% | 0.794 |
| CatBoost | 15.7% | 0.910 | **31.0%** | **0.810** |

기존 작가에서는 XGBoost가 압도적. Cold Start에서는 CatBoost가 범주형 피처 직접 처리 강점으로 근소하게 우위.

### 2.3 최종 성능 (상황별 모델 분기)

### 2.4 목표 달성 현황

| 지표 | 기존 작가 (XGBoost) | Cold Start (CatBoost) |
|------|:------------------:|:--------------------:|

| MAPE < 35% | **달성** (21.4%) | 미달 (49.5%) |

### 3.2 피처 그룹별 기여도

| 그룹 | v5 (기존 작가) | v4 (Cold Start) |
|------|:-----------:|:-----------:|
| **유사 작가 가격 (K-NN)** | **31.2%** | — |

### 3.3 핵심 인사이트

1. **K-NN 유사 작가 가격**(31.2%): 기존 작가 예측에서 압도적. "비슷한 경력의 작가가 얼마에 파는가"가 가장 강력한 예측 변수. 단, Cold Start에서는 작동하지 않음
2. **크기(호당) 피처**(21.6%): 두 모델 모두 핵심. 호당 가격제가 데이터에서 확인됨
3. **cat_ho_power**(4.1%): 카테고리별 크기-가격 관계 차이를 반영. Photography와 Print는 크기 프리미엄이 Painting보다 작음
4. **ho_x_career 인터랙션**(10.2%): 같은 크기라도 경력 단계에 따라 가격이 다름

### 3.4 K-NN 최적화 결과

| k값 | 거리 함수 | GroupKFold MdAPE |
|:---:|----------|:----------------:|
| 3 | euclidean | 41.4% |
| 5 | euclidean | 38.7% |
| 7 | euclidean | 38.3% |
| 10 | euclidean | 37.8% |
| 3 | cosine | 41.9% |
| 10 | cosine | 38.3% |

**결론**: K-NN은 k값/거리함수 변경으로도 GroupKFold(Cold Start) 개선 불가. K-NN 기반 Cold Start 개선 한계 확인.

**최종 선택: 상황별 모델 분기**
- 기존 작가 → XGBoost 단독 (MdAPE 9.7%) — 앙상블(11.9%)보다 단독이 더 우수
- Cold Start → CatBoost 단독 (MdAPE 31.0%) — 범주형 피처 처리 강점

### 5.3 핵심 개선 기여

- **v1→v3**: career_stage 분류 개선 (중견 0명→1,999명)
- **v3→v4**: 작가 내 가격 이상치 제거 + 하이퍼파라미터 튜닝
- **v4→v5**: K-NN 유사 작가 가격 (기존 작가 CatBoost MdAPE 15.5%→13.6%)
- **Painting→5cat**: 카테고리 확장 + cat_ho_power 인터랙션
- **모델 비교**: XGBoost가 기존 작가에서 CatBoost 대비 6%p 우수 (15.7%→9.7%)

### 5.4 실패한 시도

- **fold-safe artist 통계** (v2): GroupKFold Cold Start에서 global fallback만 적용되어 MdAPE 48.8%로 급락
- **K-NN Cold Start 개선**: k값(3~10), 거리함수(euclidean/cosine) 전수 탐색했으나 GroupKFold 개선 불가
- **3모델 앙상블**: 균등(11.9%) 및 가중(11.1%) 모두 XGBoost 단독(9.7%)보다 낮은 성능. CatBoost가 앙상블 평균을 끌어내림

## 7. 한계와 향후 과제

### 7.1 Cold Start 한계

MdAPE 32.5%는 새 작가 예측의 구조적 한계. K-NN 최적화(k=3~10, euclidean/cosine)로도 개선되지 않음. 작가 2~3건 학습 후 MdAPE가 13.6%로 급격히 향상.

### 7.2 Artsy 가격 = 호가 (Listing Price)

Artsy 가격은 실거래가가 아닌 갤러리 호가. Sold 작품(6,891건)의 가격이 비공개라 실거래가 검증 불가.

### 7.3 가격 비공개 편향

"Price on request" 7,027건은 고가 작품일 가능성 높음. 고가(1억+) 작품의 과소 예측 경향(85%)이 이를 반영.

## 8. 모델 선택 근거

### 8.1 왜 트리 모델인가 — 헤도닉 회귀와의 비교

헤도닉 회귀(`ln(Price) = β₀ + β₁×ln(Ho) + β₂×birth_year + ...`)는 공식이 명확하지만, 동일 데이터에서 실측 비교한 결과 트리 모델과 큰 격차가 있다:

| 모델 | 기존 작가 MdAPE | Cold Start MdAPE | R² |
|------|:--------------:|:----------------:|:--:|
| 단순 헤도닉 | 40.5% | 44.5% | 0.732 |
| 헤도닉 + 인터랙션 | 30.5% | 34.3% | 0.812 |
| 헤도닉 + Spline(비선형) | 30.5% | 35.6% | 0.817 |
| **XGBoost** | **9.7%** | **31.5%** | **0.931** |

헤도닉을 인터랙션, 비선형 항으로 강화해도 XGBoost와 **20.7%p 격차**. 이는 가중치 튜닝으로 해결할 수 없는 구조적 한계이다:

- **비선형**: 호수 5→10의 가격 증가폭 ≠ 호수 50→100의 증가폭
- **조건부 인터랙션**: 원로 작가의 대형 캔버스 vs 신진 작가의 소형 종이는 크기-가격 관계가 완전히 다름
- **갤러리 개별 효과**: 66개 갤러리 각각의 가격 수준을 트리는 자동 학습하지만, 헤도닉은 데이터 부족으로 학습 불가

### 8.2 XGBoost / CatBoost / LightGBM 비교 (실측)

| 모델 | 기존 작가 MdAPE | Cold Start MdAPE | 범주형 처리 | 선택 |
|------|:--------------:|:----------------:|:----------:|:----:|
| **XGBoost** | **9.7%** | 31.2% | 인코딩 필요 | 기존 작가용 |
| LightGBM | 11.2% | 33.1% | 인코딩 필요 | — |
| **CatBoost** | 15.7% | **31.0%** | 직접 처리 | Cold Start용 |
| 3모델 앙상블 | 11.9% | 31.4% | — | 단독보다 낮음 |

앙상블(3모델 평균)은 XGBoost 단독보다 성능이 낮아 채택하지 않았다.

### 8.3 트리 모델의 설명: SHAP

트리 모델은 하나의 공식이 없지만, **SHAP(SHapley Additive exPlanations)**으로 개별 예측을 피처별 기여도로 분해할 수 있다.

**전체 피처 기여도 (SHAP 기반)**:

| 요인 | 비중 | 설명 |
|------|:----:|------|
| 작가 세대 | 15.4% | 나이/세대가 가격의 가장 큰 단일 결정 요인 |
| 작품 크기 | 34.4% | 면적, 호수, 크기 곡선 등 합산 |
| 갤러리 | 8.8% | 어떤 갤러리에서 판매하는가 |
| 아트페어 | 3.8% | 국제 전시 참여 이력 |
| 시장 관심도 | 3.4% | Artsy 팔로워 수 |
| 경력 단계 | 3.3% | 신진/중견/원로 |
| 지지체 | 3.6% | 캔버스/종이/패널 |

**개별 작품 SHAP 분해 예시**:


### 8.4 딥러닝을 쓰지 않는 이유

9,975건은 딥러닝에 부족한 데이터이며, 예측 근거 설명이 불가능하다. 향후 이미지 피처(작품 스타일, 색감)를 추가할 때는 딥러닝으로 이미지 embedding을 추출한 뒤, 트리 모델의 피처로 투입하는 **하이브리드 방식**이 현실적이다.

## 9. 용어 설명

### K-NN (K-Nearest Neighbors) 유사 작가 가격 추정

"이 작가와 경력이 비슷한 작가 K명을 찾아서, 그 작가들의 평균 가격을 참고값으로 쓴다"는 방법.

```
예시: 새 작가 A의 프로필
  생년 1985, 팔로워 500, 개인전 3회, 그룹전 5회, 아트페어 2회

→ 데이터에서 프로필이 가장 비슷한 작가 7명을 탐색:
  작가 B (생년 1983, 팔로워 450, 개인전 4회) → 평균 가격 500만원
  작가 C (생년 1987, 팔로워 600, 개인전 2회) → 평균 가격 400만원
  작가 D (생년 1984, 팔로워 520, 개인전 3회) → 평균 가격 480만원
  ...

→ 7명의 가중 평균 = 460만원
→ 이 값이 "knn_artist_price" 피처로 모델에 입력됨
```

이 피처가 기존 작가 예측에서 **중요도 31.2%로 1위**인 이유는, 미술품 가격이 결국 **"비슷한 급의 작가가 얼마에 파는가"**에 가장 크게 좌우되기 때문이다.

단, Cold Start(새 작가)에서는 학습에 없는 작가라 "비슷한 작가"를 찾아도 정확도가 떨어져 효과가 제한적이다.

### 호당 가격제 (Ho-based Pricing)

한국 갤러리의 가격 책정 관행. 캔버스 면적을 "호(號)" 단위로 환산하고, 작가별 "호당 단가(α)"를 곱해 가격을 산출한다.

```
Price = α × Ho^β
  α: 작가별 호당 기준가 (작가의 명성/경력에 따라 다름)
  Ho: 작품의 호수 (면적 기반)
  β: 체감 계수 (크기가 커질수록 단위당 가격이 줄어드는 효과)
```

본 실험에서 β = 0.817로 추정됨. 크기가 2배이면 가격은 2^0.817 ≈ 1.76배 (2배가 아님).

### Cold Start (콜드 스타트)

모델이 학습 시 한번도 본 적 없는 새 작가의 가격을 예측하는 상황. 작가 개인의 가격 이력이 없으므로 프로필(나이, 경력, 팔로워)만으로 예측해야 하며, 정확도가 제한적이다. GroupKFold로 평가.

### SHAP (SHapley Additive exPlanations)

게임 이론의 Shapley Value를 머신러닝에 적용한 설명 방법. 기준가(전체 평균)에서 출발하여 각 피처가 가격을 얼마나 올리고 내리는지 %로 분해한다. 트리 모델에서 "공식" 대신 사용하는 설명 방법.

### 헤도닉 회귀 (Hedonic Regression)

`ln(Price) = β₀ + β₁×ln(크기) + β₂×생년 + ...` 형태의 선형 모델. 공식이 명확하지만, 비선형 관계와 조건부 인터랙션을 학습할 수 없어 정확도가 트리 모델 대비 20%p+ 낮다.

### CatBoost / XGBoost

Gradient Boosted Tree 계열 머신러닝 모델. 수백~수천 개의 결정 트리가 순차적으로 오차를 보정하며 학습한다. XGBoost는 기존 작가 예측(MdAPE 9.7%)에서, CatBoost는 Cold Start(MdAPE 31.0%)에서 더 정확.

### MdAPE (Median Absolute Percentage Error)

예측 오차의 중앙값. 전체 작품 중 절반은 이 오차보다 정확하고, 절반은 이보다 부정확하다는 의미. 평균(MAPE)보다 극단 이상치에 강건한 지표.

### R² (결정 계수)

모델이 가격 변동의 몇 %를 설명하는지를 나타내는 지표. R²=0.938이면 가격 변동의 93.8%를 모델이 설명한다는 의미. 1.0에 가까울수록 좋다.

### W30, W50

예측 오차가 30% 이내(W30), 50% 이내(W50)인 작품의 비율. W30=78.5%이면 전체 작품 중 78.5%가 실제 가격 대비 30% 오차 이내로 예측되었다는 의미.
