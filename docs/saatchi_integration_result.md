## 4. 모델 고도화 (v3~v6)

Saatchi 통합 후 Cold Start MdAPE 43.8%에서 더 개선하기 위해 4단계 고도화를 진행했다.

### 4.1 고도화 과정

#### v3: 피처 보강 + source 피처

- `source` 컬럼을 categorical 피처로 추가 (소스별 가격 수준 직접 학습)
- `ln_area`, `support_factor`, `ho_x_support` 파생 피처
- `has_birth_year`: 생년 결측 자체가 가격 신호 (결측 = Saatchi 작가 = 저가 경향)
- `profile_completeness`: bio/education/exhibitions 텍스트 존재 여부 (0~3)
- CatBoost + XGBoost 앙상블

**결과**: 전체 MdAPE 43.8% → **38.7%** (-5.1%p)

#### v4: 피처 확장 + 가격대별 샘플 가중치

- 작가별 데이터셋 내 작품수, 호수 다양성, 매체 다양성 등 14개 피처 추가
- 고가(1천만+) 샘플 가중치 1.5~2.0배, 저가(~100만) 가중치 0.7배

**결과**: 피처 과잉으로 과적합, 38.7% → 40.4% (악화). **피처 수가 아니라 피처 질이 중요.**

#### v5: 하이퍼파라미터 탐색

- CatBoost 4종 (depth 6/8/10, lr 0.01~0.03)
- XGBoost 3종 (depth 6/8, regularization 강도)
- 7개 단일 모델 + 전체 2-모델/3-모델 앙상블 조합 탐색

**결과**: 단일 최고 XGB-d6-lr03 (MdAPE 39.5%), 앙상블 최고 CB-d10+XGB-d8 (39.0%). v3과 거의 동일 — **하이퍼파라미터 튜닝의 한계**.

#### v6: 구조적 접근 (ratio 보정, stacking, source 분리)

- **A1: source별 median ratio 보정** — 예측 후 Saatchi 과대 경향(1.078x)을 log scale에서 차감
- **A2: 가격대+source별 세분화 보정**
- **B: 2-레벨 Stacking** — CatBoost+XGBoost OOF를 입력으로 Ridge 메타 모델
- **C: source별 별도 모델** — Artsy 전용/Saatchi 전용 각각 학습

### 4.2 고도화 전체 비교 (GroupKFold)

| 버전 | 접근법 | 전체 MdAPE | Artsy | Saatchi | 비율 | W30 |
|------|--------|:---------:|:-----:|:-------:|:----:|:---:|
| v2 | 단순 통합 CatBoost | 43.8% | 38.4% | 46.3% | 1.04x | 35.7% |

### 4.5 가격이 튀는 원인과 조정 메커니즘

#### 학습 전 과대 예측(2.08x)의 원인

동일 호수+매체에서도 소스별 가격 차이가 존재한다:

| 조건 | Artsy | Saatchi | Artsy/Saatchi |
|------|------:|--------:|:---:|
| 10호 oil | 276만 | 173만 | 1.6x |
| 15호 oil | 374만 | 257만 | 1.5x |
| 30호 oil | 607만 | 404만 | 1.5x |
| 50호 oil | 945만 | 657만 | 1.4x |

기존 모델은 Artsy 가격만 학습했으므로, Saatchi 작품도 Artsy 가격 수준으로 예측 → 1.1~1.6x 과대.

여기에 **팔로워(피처 중요도 1위, 24%)** 효과가 중첩. Saatchi 작가는 팔로워 평균 3.61 (Artsy 2.34 대비 높음). 팔로워가 높으면 모델이 더 비싸게 예측 → 과대 폭이 **2.08x까지 증폭**.

#### 학습 후 조정 메커니즘

1. **gallery_name = "Saatchi Art" 학습**: 통합 모델은 "Saatchi Art" 갤러리의 가격 수준을 별도로 학습. 동일 작품이라도 Saatchi Art이면 Gallery Hyundai 대비 **0.80x** (25% 저렴하게 예측)

2. **artist_total_works 피처**: 통합 모델에서 중요도 1위(37%). Saatchi 작가는 평균 201건(Artsy 55건의 3.6배). 작품 많은 작가 = Saatchi 패턴 = 저가 → 모델이 학습

3. **source ratio 보정(v6)**: 예측 후 Saatchi의 중앙 ratio(1.078x)를 log scale에서 차감 → **비율 1.00x로 편향 완전 해소**

## 5. 분석

### 5.1 Saatchi 가격의 특성

Saatchi Art는 작가가 직접 가격을 설정하는 온라인 플랫폼이다. 갤러리 중개 없이 직거래하므로:

- 동일 작가라도 Artsy/Artue 대비 **30~50% 저렴**
- 가격 분포가 **100~300만원에 집중** (31.6%)
- 고가(3천만+) 작품은 전체의 4.9%에 불과

### 5.2 고도화에서 배운 것

| 시도 | 효과 | 교훈 |
|------|------|------|
| source 피처 추가 (v3) | **-5.1%p** | 소스별 가격 수준 차이는 핵심 신호 |
| has_birth_year (v3) | 중요도 2.2% | 결측 자체가 정보 (Saatchi 작가 식별) |
| profile_completeness (v3) | 중요도 8.4% | 프로필 충실도가 가격과 상관 |
| 피처 과잉 (v4) | **악화** | 37→46 피처로 GroupKFold 과적합 |
| 하이퍼파라미터 탐색 (v5) | **변화 없음** | 모델 구조보다 데이터/피처가 중요 |
| source ratio 보정 (v6) | **비율 1.00x** | 사후 보정이 편향 해소에 효과적 |
| source 분리 (v6-C) | 악화 | 통합 모델이 분리보다 나음 (데이터 공유 효과) |

### 5.3 Cold Start 한계 (~39%)

GroupKFold MdAPE가 38.7~39.0% 근처에서 수렴한다. 이유:

1. **생년 결측 72%**: 핵심 피처인데 Saatchi에서 9.1%만 유효
2. **career_age 결측 80%**: 경력 연수를 추정할 수 없음
3. **고가 데이터 부족**: 3천만+ 1,678건(5.7%)으로 극과소 예측 지속
4. **구조적 한계**: 작가 이력 없이 크기/매체/프로필만으로는 40% 이하가 어려움
