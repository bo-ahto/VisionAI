1. 모델 수식 정의 (Hedonic + Mixed-Effects)

1.1 선형 Hedonic 회귀 (운영 채택 모델)

가격 (KRW) 의 자연로그를 종속변수로 두고, 작품/작가 특성의 선형 결합 + log_area 의 spline 항으로 모형화:

$$\log P_i = \beta_0 + \beta_1 \cdot \log A_i + \beta_2 \cdot (B_i - \bar{B}) + \beta_3 \cdot \log(1 + W_i) + \beta_4 \cdot s_1(\log A_i) + \varepsilon_i$$

$P_i$: 작품 $i$ 의 가격 (KRW) · $A_i$: 작품 $i$ 의 면적 (cm²) · $B_i$: 작품 $i$ 의 작가 출생년 · $\bar{B}$: 출생년 평균 (centering 기준) · $W_i$: 작가 총 작품수 · $s_1(\log A_i)$: log_area 의 3-knot restricted cubic spline basis (1개 항 추가) · $\varepsilon_i$: 잔차 (분포 가정 X — Huber loss 사용)

운영 채택 손실함수: Huber loss (eps=1.35) $$\mathcal{L}_\delta(r) = \begin{cases} \frac{1}{2} r^2 & |r| \leq \delta \\ \delta(|r| - \frac{1}{2}\delta) & |r| > \delta \end{cases}$$

$r = \log P - \mathbf{x}^\top \boldsymbol{\beta}$, $\delta = 1.35$ (sklearn default). 큰 잔차의 영향을 quadratic → linear 로 down-weighting → 이상치/heavy-tail 영향 감소. 특히 양 끝단 (저가/고가) segment 정확도 개선에 효과적.

1.2 Mixed-Effects Random Intercept 확장 (참고용)

warm-start 시나리오 검토용 확장 모델 — 운영 채택 X (cold-start LAO 에서 무력화):

$$\log P_{ij} = \beta_0 + \beta_1 \cdot \log A_{ij} + \beta_2 \cdot (B_j - \bar{B}) + \beta_3 \cdot \log(1 + W_j) + u_j + \varepsilon_{ij}$$

$j$: 작가 인덱스 · $i$: 작가 $j$ 의 작품 인덱스 · $u_j \sim \mathcal{N}(0, \tau^2)$ : 작가별 고유 효과 (random intercept) · $\varepsilon_{ij} \sim \mathcal{N}(0, \sigma^2)$ : 잔차

1.3 분산 분해

$$\text{Var}(\log P_{ij}) = \tau^2 + \sigma^2$$ $$\text{ICC} = \frac{\tau^2}{\tau^2 + \sigma^2}$$

ICC (Intra-class Correlation): 가격 분산 중 작가 단위 변동 비중. 본 데이터에서 ICC = 0.541.

2. 변수 정의 + 변환

2.1 종속 변수

변수정의변환
$\log P$ (log_price) 작품 가격 (KRW) 의 자연로그 $\log P = \ln(\max(P, 1))$

2.2 독립 변수 (3개)

변수원본변환식
$\log A$ (log_area) area_cm2 (cm²) $\log A = \ln(\max(A, 1))$
$B - \bar{B}$ (birth_year_centered) artist_birth_year $B - \bar{B}$ (mean centering)
$\log(1+W)$ (log_artist_total_works) artist_total_works $\log(1 + W)$ (log1p)

2.3 변환 근거

  • $\log P$, $\log A$: 가격/면적은 양의 right-skewed 분포 → log 변환으로 정규성 ↑ + size elasticity 해석 가능
  • $B - \bar{B}$: 절대 출생년 (1936~1997) 의 절편 영향 제거 → 계수 해석 명확
  • $\log(1+W)$: 작품수 0 인 케이스 처리 ($\log 0$ 방지) + diminishing return 표현

3. OLS 추정 (수식 + 매트릭스 형식)

3.1 매트릭스 표기

$$\mathbf{y} = \mathbf{X}\boldsymbol{\beta} + \boldsymbol{\varepsilon}$$

$\mathbf{y} \in \mathbb{R}^n$ : log_price 벡터 · $\mathbf{X} \in \mathbb{R}^{n \times 4}$ : design matrix (상수항 1열 + 3개 독립변수) · $\boldsymbol{\beta} \in \mathbb{R}^4$ : 계수 벡터 · $\boldsymbol{\varepsilon} \sim \mathcal{N}(0, \sigma^2 \mathbf{I})$

3.2 OLS 추정량

$$\hat{\boldsymbol{\beta}} = (\mathbf{X}^\top \mathbf{X})^{-1} \mathbf{X}^\top \mathbf{y}$$

3.3 잔차 / 분산 추정

$$\hat{\boldsymbol{\varepsilon}} = \mathbf{y} - \mathbf{X}\hat{\boldsymbol{\beta}}$$ $$\hat{\sigma}^2 = \frac{1}{n - k} \sum_{i=1}^n \hat{\varepsilon}_i^2 \quad (k = 4)$$

3.4 표준오차 / t-statistic / p-value

$$\text{SE}(\hat{\beta}_j) = \sqrt{\hat{\sigma}^2 \cdot [(\mathbf{X}^\top \mathbf{X})^{-1}]_{jj}}$$ $$t_j = \frac{\hat{\beta}_j}{\text{SE}(\hat{\beta}_j)}$$ $$p_j = 2 \cdot P(T_{n-k} \geq |t_j|) \quad (\text{양측 검정})$$

3.5 모델 적합도 ($R^2$)

$$R^2 = 1 - \frac{\sum_i \hat{\varepsilon}_i^2}{\sum_i (y_i - \bar{y})^2}$$ $$R^2_{\text{adj}} = 1 - (1 - R^2) \cdot \frac{n - 1}{n - k}$$

4. Mixed-Effects Random Intercept 추정

4.1 모델 형태

$$\mathbf{y} = \mathbf{X}\boldsymbol{\beta} + \mathbf{Z}\mathbf{u} + \boldsymbol{\varepsilon}$$

$\mathbf{Z} \in \{0,1\}^{n \times J}$ : 작가 indicator matrix · $\mathbf{u} \sim \mathcal{N}(0, \tau^2 \mathbf{I}_J)$ : random intercept 벡터 · $\boldsymbol{\varepsilon} \sim \mathcal{N}(0, \sigma^2 \mathbf{I}_n)$

4.2 반복 추정 알고리즘 (간이 구현)

주의 — 본 구현은 정식 Mixed-Effects 추정 (BLUP / REML / lme4) 이 아닙니다.
  • 정식 ME 의 핵심인 shrinkage (작가별 작품 수에 따른 $u_j$ 가중 축소) 가 빠져 있음
  • $\hat{u}_j$ 를 단순 잔차 평균으로 추정 → 작은 그룹은 over-fit 위험
  • 분산 추정 $\hat{\tau}^2$ 도 단순 표본 분산 (REML 비편향 X)
  • 정식 ME 가 필요한 경우 statsmodels.MixedLM 또는 pymer4 (R lme4) 사용 권장

현재는 Python 3.14 + statsmodels 호환 이슈로 numpy 직접 구현. 본 구현의 ICC 0.541 은 정식 ME 추정과 ±0.05 이내 근사로 검증.

1 초기 OLS 적합 $$\hat{\boldsymbol{\beta}}^{(0)} = (\mathbf{X}^\top \mathbf{X})^{-1} \mathbf{X}^\top \mathbf{y}$$ $$\hat{\boldsymbol{\varepsilon}}^{(0)} = \mathbf{y} - \mathbf{X}\hat{\boldsymbol{\beta}}^{(0)}$$
2 작가별 잔차 평균 = random intercept 추정 $$\hat{u}_j^{(t)} = \frac{1}{n_j} \sum_{i \in j} \hat{\varepsilon}_i^{(t)}$$

$n_j$: 작가 $j$ 의 train 작품 수

3 $\mathbf{u}$ 보정 후 OLS 재적합 $$\mathbf{y}_{\text{adj}} = \mathbf{y} - \mathbf{Z}\hat{\mathbf{u}}^{(t)}$$ $$\hat{\boldsymbol{\beta}}^{(t+1)} = (\mathbf{X}^\top \mathbf{X})^{-1} \mathbf{X}^\top \mathbf{y}_{\text{adj}}$$
4 수렴 조건 $$\max_j |\hat{\beta}_j^{(t+1)} - \hat{\beta}_j^{(t)}| < 10^{-5}$$ 최대 20회 반복.

4.3 분산 추정 (variance components)

$$\hat{\tau}^2 = \frac{1}{J} \sum_{j=1}^J \hat{u}_j^2$$ $$\hat{\sigma}^2 = \frac{1}{n} \sum_{i=1}^n (y_i - x_i^\top \hat{\boldsymbol{\beta}} - \hat{u}_{j(i)})^2$$ $$\widehat{\text{ICC}} = \frac{\hat{\tau}^2}{\hat{\tau}^2 + \hat{\sigma}^2}$$

6. 예측 프로세스 (단계별)

1 입력 변수 변환 (학습 시와 동일) 
log_area_new = log(max(area_cm2_new, 1))
birth_year_centered_new = artist_birth_year_new - mean_train  # 학습 시 평균 사용
log_works_new = log(1 + artist_total_works_new)
2 설계 벡터 구축 $$\mathbf{x}_{\text{new}} = [1, \log A_{\text{new}}, (B_{\text{new}} - \bar{B}), \log(1+W_{\text{new}})]^\top$$
3 로그 가격 예측

OLS:

$$\widehat{\log P}_{\text{new}} = \mathbf{x}_{\text{new}}^\top \hat{\boldsymbol{\beta}}$$

Mixed-Effects: 작가가 학습 데이터에 있으면 random intercept 추가

$$\widehat{\log P}_{\text{new}} = \mathbf{x}_{\text{new}}^\top \hat{\boldsymbol{\beta}} + \mathbb{1}[\text{작가} \in \text{train}] \cdot \hat{u}_j$$

신규 작가 (cold-start): $\hat{u}_j = 0$ (population mean)

4 역변환 (KRW)

Median 예측 (기본):

$$\hat{P}_{\text{new}}^{\text{median}} = \exp(\widehat{\log P}_{\text{new}})$$

$\exp(\widehat{\log P})$ 는 가격 분포의 median 추정치. 본 모델 운영 권고치.

Mean 예측 (선택, smearing 보정):

$$\hat{P}_{\text{new}}^{\text{mean}} = \exp(\widehat{\log P}_{\text{new}}) \cdot \exp\left(\frac{\hat{\sigma}^2}{2}\right)$$

log-normal 가정 시 mean 추정용 보정. 현재 운영 권고는 median 기반 (MdAPE metric 과 일치).

7. 평가 protocol (LAO holdout + 지표)

7.1 Leave-Artist-Out (LAO) Split

작가 단위로 train/test 분할. 같은 작가가 train/test 에 동시 등장 금지 (cold-start 평가):

1 GroupShuffleSplit(test_size=0.20, random_state=seed) 로 작가 인덱스를 train/test 분할.
2 Hard gate 검증: $$\text{train\_artists} \cap \text{test\_artists} = \emptyset$$
3 30 seeds (42, 43, ..., 71) 반복으로 평균 + 표준편차 산출.

7.2 평가 지표

MdAPE (Median Absolute Percentage Error) $$\text{MdAPE} = \text{median}_i \left( \frac{|\hat{P}_i - P_i|}{P_i} \right) \times 100\%$$
$W_{30}$ / $W_{50}$ (Within-X% Hit Rate) $$W_{30} = \frac{1}{n} \sum_i \mathbb{1}\left[ \frac{|\hat{P}_i - P_i|}{P_i} \leq 0.30 \right] \times 100\%$$ $$W_{50} = \frac{1}{n} \sum_i \mathbb{1}\left[ \frac{|\hat{P}_i - P_i|}{P_i} \leq 0.50 \right] \times 100\%$$

7.3 Bootstrap 95% CI

$$\text{CI}_{95\%} = \left[ Q_{2.5\%}(\text{boot}), Q_{97.5\%}(\text{boot}) \right]$$

30 seeds 결과에 대해 $B = 500$ resampling → $B$ 개의 median MdAPE 분포 형성 → 2.5% / 97.5% 분위수.

7.4 Time-Split CV (시간 안정성 + 이원 전략 근거)

이원 전략 (warm = ME / cold = OLS) 의 실제 운영 근거는 LAO 가 아닌 time-split:

1 시간 기준 train/test 분할

예: $\text{train} = \{i : Y_i \leq 2023\}$, $\text{test} = \{i : Y_i > 2023\}$

2 warm/cold 분류 $$\text{warm}(j) = \mathbb{1}\left[ n_j^{\text{train}} \geq T \right]$$

$T$ = warm threshold (운영 기본 10, 성능 showcase 3)

3 각 segment 별 metric 측정
  • warm test: ME 예측 (작가 $u_j$ 사용 가능)
  • cold test: OLS 예측 (population $\bar{u} = 0$)
  • combined: 양쪽 합쳐서 통합 MdAPE

8. Calibration (후처리 보정)

8.1 보정 테이블 생성

1 예측가 quantile bin 정의 $$Q = \{q_{0.20}, q_{0.40}, q_{0.60}, q_{0.80}\} \;\text{ (예측가 분위수)}$$ $$B = \{(-\infty, q_{0.20}], (q_{0.20}, q_{0.40}], \ldots, (q_{0.80}, +\infty)\}$$
2 각 bin 의 잔차 중앙값 계산 $$\delta_b = \text{median}_{i \in b}\left[ \log P_i - \widehat{\log P}_i \right]$$

$\delta_b$ : bin $b$ 의 log-scale 평균 편향

8.2 보정 적용

$$\widehat{\log P}_i^{\text{cal}} = \widehat{\log P}_i + \delta_{b(i)}$$ $$\hat{P}_i^{\text{cal}} = \hat{P}_i \cdot \exp(\delta_{b(i)})$$

$\exp(\delta_b)$ = 보정 배수 (예: 1.229 = +22.9% 보정).

9. 이원 전략 운영 절차

9.1 라우팅 규칙

$$\text{Route}(j) = \begin{cases} \text{V3 (warm)} & \text{if } n_j^{\text{train}} \geq 10 \\ \text{Track 2 OLS} & \text{otherwise (cold)} \end{cases}$$

$n_j^{\text{train}}$ : 학습 데이터에서 작가 $j$ 의 작품 수

9.2 운영 예측 함수 (의사 코드)

def predict_price(artwork):
    artist = artwork.artist_slug
    n_train = train_artist_counts.get(artist, 0)

    if n_train >= 10:
        # Warm path: V3 운영 모델
        return v3_predict(artwork)

    else:
        # Cold path: Track 2 (F4 + log_area spline, Huber 학습)
        log_area = log(max(artwork.area_cm2, 1))
        birth_centered = artwork.birth_year - BIRTH_MEAN
        log_works = log(1 + artwork.artist_total_works)
        spline_term = restricted_cubic_spline(log_area, KNOTS_LOG_AREA)

        x = [1, log_area, birth_centered, log_works, spline_term]
        log_price = sum(beta_track2[k] * x[k] for k in range(5))
        # beta_track2 는 HuberRegressor (eps=1.35) 로 학습된 계수

        # 후처리 calibration
        bin_idx = find_bin(exp(log_price))
        log_price += calibration_table[bin_idx].delta

        # 가드레일 적용
        if needs_human_review(artwork):
            return PriceBand(low=exp(log_price)*0.7, high=exp(log_price)*1.3, flag="human_review")

        return exp(log_price)

10. 모델 검증 (VIF / 부호 일관성 / Bootstrap)

10.1 VIF (Variance Inflation Factor)

$$\text{VIF}_j = \frac{1}{1 - R_j^2}$$

$R_j^2$ = 변수 $j$ 를 다른 모든 변수로 회귀한 결정계수. VIF > 5 = 다중공선성 의심 / VIF > 10 = 심각.

본 모델 VIF (max VIF = 1.2): 다중공선성 없음.

10.2 30-seed 부호 일관성

$$\text{Consistency}_j = \max\left( \frac{\#\{s : \hat{\beta}_j^{(s)} > 0\}}{S}, \frac{\#\{s : \hat{\beta}_j^{(s)} < 0\}}{S} \right) \times 100\%$$

$S = 30$ seeds. 100% = 모든 seed 에서 같은 부호.

본 모델 부호 일관성: log_area (100%), birth_year_centered (100%), log_artist_total_works (100%) — 완벽 일관.
