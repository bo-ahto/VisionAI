# v3 모델 보강 계획 (요약본)

**작성일**: 2026-04-30
**대상**: 콜론30 협력자
**관련**: `model_technical_report_v2.html` (v2 기술 보고서)

---

## 한 문단 요약

본 문서는 현 v2 모델(integrated_v3_filtered_tuned + cell calibration)에 이어 진행될 **v3 보강 작업의 공식 계획**을 정리한다. v2 산출물의 5-fold CV 측정값은 warm Artsy MdAPE 8.3% (앙상블 8.7%)로 1차년도 A 등급 목표 밴드(warm Artsy slice 8.0~9.0%) 내에 진입했으며, v3에서 ① v1 vs v2 paired statistical test로 v2 개선의 통계적 유의성을 추가 검증하고, ② **방법론적 엄밀성 강화** (Bootstrap CI, leave-one-X-out CV 등), ③ **모델 구조 정직화** (nested CV, calibration 재검토), ④ **학술적 차별성 정량 입증**, ⑤ **데이터 클렌징 파이프라인 고도화** 다섯 축에서 점진적 보강을 수행한다. 작업은 5개 Group으로 분해되어 기존 Phase 1B/2A/2B/3A/3B 로드맵과 정렬되며, 각 마일스톤에 산출물 + 정량 임계값 형태의 acceptance gate를 둔다.

## 1. v3 보강 목표

| 축 | 보강 내용 | 기대 효과 |
|---|---|---|
| **방법론적 엄밀성** | Bootstrap CI, paired statistical test, leave-one-gallery-out / leave-one-medium-out CV, residual analysis 추가. 1차 시장 모델의 시간축 부재 한계는 정직 명시 | 학술 평가 기준에 부합하는 정직 메트릭 보고 |
| **모델 구조 정직화** | Nested cross-validation 도입, Optuna 탐색 확장, cold path 모델 채택 규칙 정량 명시화, calibration·신뢰 구간 방식 재검토 | post-hoc bias 제거, 채택 결정의 객관성 확보 |
| **학술적 차별성** | 출처 라벨 통제 실험 표본 확장 (n=30 → 90+), 선행 연구 정량 benchmark, drift 진단 procedure 일반화 | 본 연구의 학술 기여 정량 입증 |
| **데이터 클렌징 잔여 정밀화** | 4건 잔여 영역: 실험데이터분류 시트(6,050행) reader 추가 + 미매칭 unique 재료(약 980개) 분포 분석, gallery_name 표준화(콜론30 매핑 적용), A 모델용 duplicate detection 신규, 시점별·다국적 통화 환율 정규화 (매체/지지체 분류·입체 4규칙은 이미 구현 완료) | cold-start 데이터 측 한계 완화, Phase 2B 데이터 강화의 정량 backbone |

## 3. 단계별 정량 기준 (Acceptance Gate 요약)

각 v3 마일스톤에는 **산출물 + 정량 임계값** 형태의 acceptance gate를 둔다.

| 마일스톤 | Warm Artsy MdAPE | Warm 전체 | Cold 전체 | 핵심 검증 항목 |
|---|---|---|---|---|
| v2 (현재) | 8.3% | 9.7% | 38.3% | KFold + GroupKFold 기반 |
| **v3.0** (Group 1) | 8.3% (95% CI 추가) | 9.7% (CI) | 38.3% (CI) | Bootstrap CI / paired test / leave-one-X-out CV / 시간축 부재 정직 명시 |
| **v3.1** (Group 2) | 변동 추적 | 변동 추적 | 변동 추적 | 출처 플립 n=90+ / cold path 채택 결정 / quantile coverage |
| **v3.2** (Group 3) | 변동 추적 (nested CV 기반) | 변동 추적 | 변동 추적 | nested CV 기반 정직 메트릭 / source 처리 재설계 결과 |
| **v3 final** (Group 4) | 운영 환경 측정값 | 동일 | 동일 | A/B 테스트 / 선행 연구 benchmark |

> **주의 (정합 명시)**: ① v2 기준 수치는 5-fold CV에 기반한 **추정치**이며, v3.2의 nested CV에서 정직 메트릭으로 갱신될 수 있다. 변동 시 "방법론 엄밀화의 결과"로 보고한다. ② cold MdAPE의 v3.2 추가 개선(35~37% 추정 범위)은 모델 구조 변경만으로는 달성 어려우며, **Phase 2B 데이터 강화 완료를 가정한 추정치**다. master plan §6 acceptance gate에서는 정량 임계값으로 사용하지 않으며, 본 표의 v3.2 수치도 acceptance 기준이 아닌 **dependency 충족 시 도달 가능 추정치**다.

## 4. v2 발표 시점 진행 상황 (2026-05 기준)

본 v3 plan은 **v2 중간평가 발표와 병행**하여 다음과 같이 진행된다.

- **발표 시점 (2026-05)**: Group 1의 우선 작업 5건 (Bootstrap CI, 통계 검정, baseline 비교, learning curve, paired test)이 완료 또는 진행 중. v2 발표 자료에 통계적 신뢰도 정보 일부 반영.
- **발표 직후 (2026-05~06)**: Group 1 완료 → v3.0 산출물.
- **2차년도**: Group 2 / Group 3 본격 진행. Phase 1B / 2A / 2B와 정합.

## 6. 정직성 명시 — v3 plan의 한계

본 v3 plan에는 다음과 같은 한계가 있으며, 사내 master plan에 더 자세히 기술되어 있다.

- **1차 시장 모델의 시간축 부재**: 현재 학습 데이터에는 거래 시점 정보가 없어 워크포워드 백테스트 같은 시간 기반 일반화 평가가 불가능. v3 plan에서는 leave-one-gallery-out / leave-one-medium-out CV로 OOD 일반화를 측정하고, 시간축 평가는 후속 Phase에서 거래 시점 메타데이터 수집 협력을 통해 보강 예정
- **Cold MdAPE 추가 개선의 데이터 의존성**: v3.2 단계에서 cold MdAPE의 추가 개선(35~37% 추정 범위)은 모델 구조 변경만으로는 도달 어려우며, Phase 2B 데이터 강화 완료를 전제로 함. master plan §6 acceptance gate에서는 정량 임계값으로 사용하지 않음
- **자원 가정**: 모델 개발자 1인 풀타임 + 데이터 엔지니어 1인 (Group 5) + 약 1,613~1,935 compute-hours 기준. 자원 부족 시 Group 1 우선 진행

## 7. 한 문장 결론

> v2 모델의 5-fold CV 측정값 (warm Artsy MdAPE 8.3%, 앙상블 8.7%)은 정부 R&D 1차년도 A 등급 목표 밴드 (warm Artsy 8.0~9.0%) 내에 진입했으며 (v3에서 v1 vs v2 paired statistical test로 개선의 통계적 유의성 추가 검증 예정), v3는 **방법론적 엄밀성과 학술적 차별성**을 점진적으로 보강하여 2~3차년도까지 **최종평가 통과 + 논문화 가능 수준**으로 격상한다. 모든 보강 작업은 acceptance gate 기반으로 진행되며, 기존 Phase 로드맵과 정렬되어 후속 단계에서 통합된다.
