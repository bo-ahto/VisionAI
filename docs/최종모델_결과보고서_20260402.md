## 4. 핵심 발견 사항

### 4.1 효과가 있었던 것
1. **잔차 보정 (Bias Correction)**: MdAPE -1.5%p, W30 +1.5%p — **가장 큰 단일 개선**
2. **무효 피처 제거**: 노이즈 감소 → Warm -0.5%p
3. **has_global_price 지표**: NaN 보존 + 바이너리 지표로 Cold 정보 보존
4. **3-모델 앙상블 (CB+LGB+XGB)**: 다양성 확보 → MdAPE -0.3%p
5. **시간 가중치 (반감기 2년)**: 최근 시장 반영 → Warm -0.5%p
6. **인터랙션 피처**: artist×medium 가격비, 매체 전문화도
7. **Cold newness_score**: binary→연속값 전환

### 4.2 효과가 없었던 것
1. **이미지 피처 (ResNet50/CLIP)**: 전체 적용 시 악화, Cold 전용도 무효
2. **global_median_price 전체 보간**: Cold 정보 파괴 → Cold +3%p 악화
3. **이상치 클리핑 (1%-99%)**: 효과 미미
4. **가격대별 세그먼트 모델 (단독)**: Ensemble보다 열위

### 4.3 이미지 피처 실험 결론
> **미술품 가격은 이미지 내용과 무상관** (R² < 0)
> - ResNet50 (ImageNet): 전체 R²=-0.017, Cold R²=-0.005
> - CLIP (OpenAI): 유사한 결과
> - 한국 미술 시장에서 가격은 **작가 브랜드**가 지배적
> - Mei-Moses(2025)의 Cold 이미지 효과는 한국 시장에서 재현 안 됨

## 5. 한계 및 향후 과제

### 5.1 현실적 한계
- **MdAPE 32% 달성**: 현재 데이터로는 불가. 38~40%가 실질적 바닥
- **Cold Start**: 외부 소셜/경력 데이터 없이 근본 해결 불가
- **저가 세그먼트**: 구조적 과대예측 (bias correction으로 부분 해결)
- **수확체감**: 10회 실험 후반부는 실험당 0.2~0.5%p 개선

### 5.2 추가 개선을 위해 필요한 것
| 필요 사항 | 예상 효과 | 확보 난이도 |
|----------|----------|-----------|
| 작가 전시/수상 이력 데이터 | -2~4%p | 높음 (웹 스크래핑) |
| 갤러리 소속/등급 데이터 | -1~2%p | 중간 |
| 추가 경매 데이터 (최신) | -0.5~1%p | 낮음 |
| 작품 상태/보존도 정보 | -1~2%p | 높음 (도록에서 추출) |

### 5.3 프로덕션 전환 권장 사항
1. **현재 모델을 프로덕션 배포** — MdAPE 40.83%는 "가격 참고용"으로 충분
2. **신뢰도 등급 표시**: Warm(High) / Cold(Low) 구분
3. **유사 거래 사례 제시**: comp_artist_avg, comp_medium_avg 기반
4. **재학습 자동화**: 새 경매 데이터 수집 시 주기적 재학습
5. **사용자 피드백 수집**: 실제가 vs 예측가 비교 데이터 축적
