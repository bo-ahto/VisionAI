📖 모델 작동 방식 — 비전공자용 풀이

1. 모델이 어떤 정보를 보는가? (사용 피처 10가지)

작품 한 점의 가격을 예측하려면 그 작품의 "특징"을 숫자로 정리해야 합니다. 현재 모델은 다음 10가지 정보를 봅니다.

#피처 이름무엇인가?왜 중요한가?
1작가명 (한글)이 작품을 누가 그렸는가같은 작품이라도 거장이 그리면 100배 비쌈. 가격을 결정하는 가장 중요한 정보. 신규 작가일 땐 이 정보 없음 → Cold 모델 사용
2매체유화/아크릴/수채화 등 9종유화가 일반적으로 비싸고, 연필화는 저렴함
3바탕캔버스/종이/패널 등 7종캔버스 작품이 종이보다 평균 비쌈
4면적 (로그)가로×세로 (로그 변환)크기가 클수록 비쌈. 로그를 씌우는 이유는 "10배 큰 작품 = 가격도 약 10배"라는 비례 관계를 더 잘 학습하기 위함
5한국 호수1호, 10호, 50호 등 캔버스 표준 크기한국 시장에선 "20호 = 약 70×60 cm" 같은 표준 단위로 가격을 매김. 면적과 비슷하지만 한국 시장 관행 반영
6가로세로 비율가로 ÷ 세로 (로그 변환)긴 그림(panorama)인지 정사각형인지 구분. 같은 면적이라도 비율에 따라 가격 다름
7방향가로형/세로형/정사각형가로세로 비율의 단순 카테고리. 트리 모델에 도움
8깊이 여부 + 깊이입체 작품 여부 (depth_cm > 0)설치미술/조각은 평면 회화보다 가격 다름
9출처 (source)Artsy/Saatchi/Artue 어디서 가져왔나매우 중요: 같은 작품도 Artsy(갤러리)는 Saatchi(직거래)보다 평균 45.5% 비쌈. 이 차이를 모델이 학습
10매체×호수 결합"유화_20호" 같은 조합"유화의 20호 가격대"가 "수채화의 20호 가격대"와 다름. 두 특징의 상호작용을 따로 학습
11작가 작품 수 (로그)이 작가의 학습 데이터 작품 수작품이 많은 작가일수록 신호가 강함. Warm 모델에서만 효과 있음 (Cold에선 오히려 악화)
📌 피처 중요도: 작가명 >> 출처 > 면적/호수 > 매체 > 나머지. 작가가 같으면 가격이 비슷한 게 가장 큰 신호.

2. 예측은 어떻게 진행되는가? (단계별 프로세스)

새 작품 한 점이 들어오면 다음 순서로 가격이 예측됩니다.

단계이름설명
1️⃣입력 검증필수 정보 (작가명, 매체, 바탕, 크기, 호수, 방향, 출처) 다 있는지 확인. 빠지면 예측 거절.
2️⃣피처 가공가로×세로 → 면적 → 로그 면적, "유화" + "20호" → "유화_5-20", 작가의 학습 작품 수 찾기 등
3️⃣라우팅 결정이 작가가 학습 데이터에 있나? → 1번 이상 있으면 Warm 모델, 없으면 Cold 모델
4️⃣예측 (Warm 또는 Cold)선택된 모델이 "이 작품의 로그 가격은 X" 형태로 예측
5️⃣가격 복원로그 가격을 일반 가격으로 환산 (exp 함수). 예: log 가격 14.8 → 약 270만 원
6️⃣신뢰도 + 경고거장 작품(>1억) Cold 예측은 "신뢰 불가" 경고. 신규 작가는 "±115% 오차 가능" 경고.

3. 두 모델은 어떻게 작동하는가?

🌱 Cold 모델 — LAD (선형 회귀의 한 종류)

한 줄로: "각 피처가 가격에 더하거나 빼는 정도를 학습한 단순 공식."

예시 형태: 예측 로그 가격 = (상수) + (매체별 가중치) + (호수별 가중치) + (출처별 가중치) + ...

왜 LAD? 가격은 한쪽으로 치우친 분포(대부분은 100만원대인데 일부 거장은 100억원). LAD는 "예측과 실제의 차이를 절반은 위, 절반은 아래로 균등하게 두는" 방식이라 극단값(거장 작품)에 흔들리지 않습니다. 단순하지만 신규 작가 예측에 가장 안정적.

🌳 Warm 모델 — LightGBM (트리 부스팅)

한 줄로: "수많은 작은 질문(if/else)을 차곡차곡 쌓아 정답을 찾는 모델."

예시 트리:

질문 1: 작가가 "황선태"인가?
├─ 예 → 질문 2: 작품 면적이 3000cm² 이상?
│       ├─ 예 → 예측: log 가격 16.0 (약 900만원)
│       └─ 아니오 → 예측: log 가격 14.5 (약 200만원)
└─ 아니오 → 질문 3: 출처가 Artsy?
            ├─ 예 → ...
            └─ 아니오 → ...

이런 트리를 수백 개 순차적으로 만들어, 각 트리가 이전 트리의 실수를 보정. 작가별 가격 패턴, 매체×크기 조합 등 비선형 관계를 잘 잡아냄.

4. 왜 작가가 있을 땐 트리(LightGBM), 없을 땐 선형(LAD)?

  • 작가 정보 있음 (Warm): 2,132명 작가 각자 다른 가격 패턴 → 트리가 "작가별 분기"로 효과적 학습. LightGBM이 압승 (med_APE 0.10 vs LAD 0.31).
  • 작가 정보 없음 (Cold): 일반 피처 6개만 → 트리는 데이터가 부족해서 과적합 위험. 단순 선형이 오히려 안정적. LAD가 LightGBM보다 4pp 우수.

5. 예측 정확도 의미 (Warm 기준 W30 = 78%)

"학습된 작가의 신규 작품 10개를 예측하면, 약 8개는 실제 가격의 ±30% 안에 들어간다"는 의미.
예: 실제 100만 원 작품 → 모델 예측 70만~130만 원 사이에 들어갈 확률 78%.

다만 다음 경우는 정확도 떨어짐:

  • 신규 작가: ±30% 안 들어갈 확률 63% (Cold W30 = 37%)
  • 1억 이상 작품 + 신규 작가: 사실상 예측 불가 (med_APE 98%, 거의 무작위)
  • 출처 정보 없음: ±20~45% 추가 오차

🎓 학습 내용 (Lessons Learned)

1. 단일 강모델 > 조건부 분리

  • Cold: LAD (linear, outlier robust)가 LightGBM (default + Optuna 둘 다) 능가
  • 6 features만 쓰는 cold-start에서 선형 모델이 충분
  • Tree model은 squared loss로 long-tail에 sensitive

2. Feature Engineering이 가장 안전한 향상 수단

  • PR7 ALL: Cold -3.8pp / Warm -1.2pp 유일한 성공
  • Source feature 추가가 가장 큰 효과 (Cold -0.016)
  • Popularity는 cold-start에 악화 (unseen 작가에 정보 없음)

3. Conditional/Segmentation은 데이터 부족 시 위험

  • PR8 모든 variant negative result (표본 부족)
  • 40K rows / 12 cells = 평균 3K/cell — LAD 학습에 불충분
  • 초기 우려와 일치

4. Heteroscedastic 처리는 trade-off

  • PR9 Quantile + reweight: B4 -7pp, 일반 +3-5pp
  • 거장 작품 정확도 ↑ vs 일반 작품 정확도 ↓
  • 완화된 모델 선택 규칙 가능성 있으나 추가 noise 위험

5. Source bias 정량화의 가치

  • PR5에서 Artsy +45.5% 발견 → PR7에서 -0.016 흡수
  • Source 정보 입력 운영 필수
  • 가격 데이터 정책 차이 (갤러리 마크업) 명시 필요
