> **납품일**: 2026-03-27
> **개발**: Claude Opus 4.6 + Codex GPT-5.4 듀얼 검증 체계
> **데이터**: K-Auction 경매 낙찰 데이터 43,866건 / 3,286명 작가

## 1. 프로젝트 개요

### 1.1 목적

K-Auction 경매에 출품되는 미술 작품의 **낙찰가를 사전에 예측**하는 AI 엔진을 구축하였습니다.

작가명, 작품 크기, 재료, 추정가 등의 정보를 입력하면 예측 낙찰가, 가격 범위, 신뢰도 등급을 반환합니다.

### 1.2 활용 시나리오

| 시나리오 | 설명 |
|---------|------|
| **경매 전 가격 가이드** | 출품 예정 작품의 예상 낙찰가를 사전에 파악 |
| **작가별 시세 분석** | 특정 작가의 호수별 가격대 형성 현황 확인 |
| **투자 참고 자료** | 과거 낙찰 데이터 기반의 가격 트렌드 분석 |
| **추정가 검증** | 경매사 추정가 대비 모델 예측가 비교 |

### 1.3 참고 사항

본 예측 엔진은 **참고용 가격 가이드**이며, 개별 작품의 적정가를 확정하는 도구가 아닙니다. 실제 거래가는 작품 상태, 시기, 시장 분위기 등에 따라 달라질 수 있습니다.

## 2. 성능 요약

### 2.1 예측 정확도

| 지표 | 수치 | 의미 |
|------|------|------|
| **평균 오차율 (MAPE)** | **27.0%** | 예측이 실제 낙찰가에서 평균 27% 벗어남 |
| **중앙값 오차율 (MdAPE)** | **18.2%** | 예측의 절반 이상이 18% 이내 |
| **±20% 적중률** | **53.3%** | 10건 중 5건이 실제가의 ±20% 범위 안에 적중 |
| **설명력 (R²)** | **0.936** | 가격 변동의 93.6%를 설명 |

### 2.2 경매 타입별 정확도

| 경매 타입 | 평균 오차율 | ±20% 적중률 | 건수 비중 |
|----------|-----------|-----------|----------|
| **메이저** | **19.2%** | 높음 | 15.6% |
| **프리미엄** | **27.6%** | 중간 | 19.3% |
| **위클리** | **35.3%** | 보통 | 65.1% |

→ 고가 작품(메이저 경매)일수록 예측이 정확합니다.

### 2.3 가격대별 정확도

| 가격대 | 평균 오차율 | 특징 |
|--------|-----------|------|
| 3,000만~1억 원 | **~16%** | **가장 정확** |
| 1억 원 이상 | **~20%** | 우수 |
| 500만~3,000만 원 | **~28%** | 양호 |
| 100만~500만 원 | **~35%** | 보통 |
| 100만 원 미만 | **~50%+** | 참고용 |

### 2.4 신뢰도 등급

예측마다 A~D 등급이 함께 제공되어, 예측을 **얼마나 믿을 수 있는지** 알려줍니다.

| 등급 | ±20% 적중률 | 설명 | 표시 방식 |
|------|-----------|------|----------|
| **A** | **71.6%** | 높은 신뢰 — 거래 풍부한 고가 작가 | 예측가 + 좁은 범위 |
| **B** | **50.4%** | 보통 신뢰 | 예측가 + 범위 |
| **C** | **42.6%** | 낮은 신뢰 — 거래 이력 희소 | 넓은 범위 + "참고용" |
| **D** | — | 데이터 부족 — 예측 불가 | **"데이터 부족"** 표시 |

## 3. 주요 기능

### 3.1 예측 API

웹 서비스 형태로 예측을 호출할 수 있습니다.

```
요청 (POST /api/v1/predict_price):
{
  "artist_name": "김환기",
  "auction_type": "메이저",
  "width_cm": 72.7,
  "height_cm": 60.6,
  "medium": "캔버스에 유채",
  "estimate_low": 50000000,
  "estimate_high": 80000000
}

응답:
{
  "predicted_price": 62000000,        ← 예측 낙찰가
  "price_range": [49600000, 74400000], ← 가격 범위
  "confidence_grade": "A",             ← 신뢰도 등급
  "estimate_vs_prediction": 95.4       ← 추정가 대비 비율(%)
}
```

### 3.2 정적 예측 데이터

1,177명의 주요 작가에 대해 호수별(10호, 20호, 30호, 50호, 100호) 예측가가 사전 계산되어 있습니다.

파일: `frontend/data/predictions.json`

### 3.3 엔진 테스트 페이지

브라우저에서 직접 예측을 테스트할 수 있는 독립 페이지입니다.

파일: `frontend/engine_test.html` → 브라우저에서 열기

기능:
- 작가/크기/재료/추정가 입력 → 예측 결과 즉시 확인
- 피처 기여도 차트
- 디버그 정보 (피처 벡터, 파이프라인 로그)
- 모델 정보 탭 (성능 요약, Ablation 결과)

### 3.4 모델 품질 모니터링

운영 중 예측 품질 변화를 자동으로 감지합니다.

| 모니터링 항목 | 감지 내용 | 임계치 |
|-------------|----------|--------|
| PSI | 입력 데이터 분포 변화 | > 0.2 경고 |
| KS | 분포 통계적 차이 | p < 0.01 |
| Rolling MAPE | 예측 성능 추이 | 기준 대비 +5%p |

### 3.5 Shadow Mode

실제 경매 데이터를 받아 예측만 기록하고, 낙찰 결과 확정 후 사후 검증하는 모드입니다.

```bash
# 예측 기록
python scripts/run_shadow.py record --limit 100

# 결과 확정 후 검증
python scripts/run_shadow.py score
```

## 4. 기술 구성

### 4.1 예측 방식

```
작품 정보 입력
  ↓
전처리 (크기 파싱, 재료 분류, 작가 통계)
  ↓
CatBoost 모델 — "추정가 대비 할인/프리미엄율" 예측
  ↓
세그먼트 보정 (가격대별 보정 계수 적용)
  ↓
예측 낙찰가 + 신뢰도 등급
```

**핵심 특징**: 절대 가격이 아닌 "추정가 대비 얼마에 낙찰될 것인가?"를 예측합니다. K-Auction의 특성(추정가의 약 60% 수준에서 낙찰)에 맞춘 설계입니다.

### 4.2 학습 데이터

| 항목 | 수치 |
|------|------|
| 총 낙찰 데이터 | 43,866건 |
| 작가 수 | 3,286명 |
| 경매 타입 | 위클리 / 프리미엄 / 메이저 |
| 데이터 기간 | K-Auction 전 회차 |

### 4.3 입력 피처 (모델이 사용하는 정보)

| 카테고리 | 피처 | 예측 기여도 |
|---------|------|-----------|
| **추정가** | 추정가 최저/최고, 중앙값, 범위 | **68%** — 가장 중요 |
| **작가** | 작가명, 과거 낙찰 건수/평균가/최고가 | 14% |
| **경매** | 경매 타입, 회차, LOT 번호 | 10% |
| **작품** | 매체, 지지체, 크기, 종횡비, 3D 여부 | 4% |
| **기타** | 제목(무제 여부), 결측 플래그 | 4% |

## 5. 사용 방법

### 5.1 환경 설정

```bash

pip install -e ".[price-engine-core,price-engine-api]"
```

## 6. 한계 및 주의사항

### 6.1 예측이 어려운 경우

| 상황 | 원인 | 대응 |
|------|------|------|
| **신규 작가** (D등급) | 과거 거래 데이터 없음 | "데이터 부족" 표시, 추정가 범위만 참고 |
| **100만 원 미만 저가** | 가격 변동성이 큼 | 오차율 50%+ — 참고용으로만 사용 |
| **초고가 이벤트** | 추정가를 크게 초과하는 "서프라이즈" 낙찰 | 현재 모델이 포착하기 어려움 |
| **시장 급변** | 경기 충격, 작가 사망 등 갑작스러운 변화 | 월 1회 재학습으로 대응 |

### 6.2 데이터 제약

| 제약 | 영향 | 대응 |
|------|------|------|
| **전량 낙찰 데이터** | 유찰 정보 없음 → 선택 편향 | "낙찰 기준" 명시 |
| **정확한 경매 날짜 미확보** | 시즌성 피처 사용 불가 | 회차 번호로 시간 근사 |
| **출처/전시 이력 없음** | 작품 이력 프리미엄 반영 불가 | 추정가에 일부 내포됨 |

### 6.3 운영 권장사항

| 항목 | 권장 |
|------|------|
| **재학습 주기** | 월 1회 (새 경매 결과 누적 후) |
| **모니터링** | 주간 rolling MAPE + PSI 확인 |
| **배포 방식** | Shadow → Canary → 전면 전환 (단계적) |
| **D등급 처리** | 예측값 비노출, 추정가 범위만 표시 |

## 7. 모델 개선 이력

### 7.1 실험 경과

| 모델 | MAPE | 판정 |
|------|------|------|
| Baseline (log 가격 예측) | 34.87% | 출발점 |
| **Target Transform (할인율 예측)** | **30.87%** | **-4%p 개선** |
| **+ Segment Calibration** | **27.01%** | **-3.9%p 추가** |
| 분리 모델 (타입별) | 32.40% | +5.4%p 악화 → 기각 |
| Two-Step (분류→회귀) | 28.87% | +1.9%p 악화 → 기각 |

### 7.2 품질 검증 체계

- **Codex (GPT-5.4) 리뷰**: 기획서 12회 + 개발 코드 다수회 → 총 20회+ 리뷰
- **자동 테스트**: 138개 테스트 케이스 전체 통과
- **전환 게이트**: 9개 품질 조건 전체 충족
- **Shadow 검증**: 실 데이터 기반 사후 검증 파이프라인 구축
