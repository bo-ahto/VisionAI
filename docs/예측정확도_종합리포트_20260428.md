## 0. TL;DR — 결국 예측 정확도가 얼마나 좋아졌나

| 지표 | 시작 (4/27) | 현재 (4/28) | 개선 폭 |
|---|---:|---:|---:|
| **Cold MdAPE** (CatBoost, 신규 작가) | 40.6% | **38.3%** | **-2.3%p** |
| **Warm MdAPE** (XGBoost, 학습 작가) | 10.3% | **9.7%** | **-0.6%p** |
| **Warm Artsy MdAPE** | 미측정 | **8.1%** | A 등급 목표 8% 도달 |
| **Cold Artsy MdAPE** | 미측정 | **35.5%** | 큰 폭 개선 |

**핵심 메시지**:
- A 등급 (warm Artsy) 정확도가 액션 플랜 목표인 **8%에 도달**
- Cold 전체 -2.3%p 개선 — 신규 작가 예측이 실질적으로 좋아짐
- 단, Cold 신규 작가 (특히 Saatchi 41%) 여전히 큰 폭 — Cold-start 데이터 보강 필요

## 2. 어떻게 개선했나 — PR 별 정확도 기여

### PR #19: 갤러리 티어 v3 매핑 분석 (Phase 1A)
- **정확도 영향**: 0 (분석 only)
- **기여**: Phase 1B 진행 가능 여부 판정 자료. 결론: 매칭 13.2%만 → 협력자 검수 후 재판정.

### PR #20: career_stage v2 + 5개 drifted features 제거
- **Cold**: 40.6 → 39.4 (-1.2%p)
- **Warm**: 10.3 → 9.8 (-0.5%p)
- **변경**:
  - `career_stage`: 4단계 int (Stage 3=0건, 죽은 피처) → 0~8 multi-factor 연속 점수
  - 5개 drift features 제거: career_age, work_age, vintage_premium, freshness_discount, gallery_name
    - 학습 데이터에는 값 있음, 서빙에서는 0 하드코딩 → 모델이 학습한 신호를 서빙에서 활용 불가
  - warm 라우팅 정합 (warm_artist_slugs JSON로 학습/서빙 동일 set 사용)
- **놀라운 발견**: drift features 제거가 metric을 **개선**시킴. 학습한 신호가 노이즈에 가까웠음.
- 코덱스 리뷰: **15차** 끝에 GO

### PR #21: source × target_market calibration
- **Cold**: 39.4 → 38.3 (-1.1%p, 특히 Saatchi cold 큰 개선)
- **Warm**: 9.8 → 9.7 (변화 없음 — calibration 효과 noise 수준)
- **변경**:
  - cold path 후처리 보정. 4개 cell:
    - artsy_gallery: 1.0 (회귀 cell, skip)
    - artsy_online: 0.943
    - saatchi_online: 0.957
  - cross-fit 5-fold + per-cell guard (회귀 cell은 factor=1.0)
- 코덱스 리뷰: **8차** 끝에 GO

### PR #22: source 정규화 + m 값 재캘리브레이션
- **정확도 영향**: 0 (정합 정리 + 측정 only)
- **기여**:
  - source 정규화: predict cell lookup이 모델 입력 정규화와 일관 (None/'nan'/'None'/'' → 'unknown')
  - m 값 재측정 (production-time): 등급별 권장치 산출
  - calibrate_grade_margins.py가 production XGB train slice + cold calibration 정합
- 코덱스 리뷰: **8차** 끝에 GO

### PR #23: 협력자/운영/정책 협조 필요 사항 문서화
- **정확도 영향**: 0 (문서 only)
- **기여**: 후속 작업 진행 전 사람 협조 가시화 (12건)

## 3. 정확도 측면에서 무엇이 남았나

### 3.1 즉시 가능한 추가 개선 (작은 폭)

| 작업 | 예상 Cold 개선 | 예상 Warm 개선 | 작업량 | 의존 |
|---|---:|---:|---:|---|
| m 값 업데이트 (PR #22 권장치) | 0 | 0 | 1시간 | 정책 결정 |
| Bootstrap CI 추가 | 0 | 0 | 1일 | 정책 결정 |
| Optuna search 확장 (50→100) | -0.3%p | -0.3%p | 1일 | 없음 |

→ 정확도 직접 개선은 거의 한계. 신뢰도/측정 정합 작업.

### 3.2 큰 폭 개선 가능 (협력자/운영 협조 필요)

| 작업 | 예상 Cold 개선 | 예상 Warm 개선 | 의존 |
|---|---:|---:|---|
| **갤러리 티어 v3 Phase 1B** (협력자 검수 후) | -1~2%p | -1~1.5%p | 협력자 |
| **Cold-start 데이터 보강** (갤러리 입력 UX) | C/D **-5~10%p** | 0 | 운영 + 갤러리 |
| **DB schema career_age 추가** | -0.5~1%p | -0.5%p | 운영 |
| **PredictRequest gallery_name** | -0.5%p | -0.5%p | 운영 |

→ 진짜 큰 개선은 **데이터/인프라 협조** 필요. 모델 코드는 거의 한계.

### 3.3 시도하지 말 것 (이미 검증된 한계)

| 작업 | 결과 |
|---|---|
| 직접 피처 추가 (solo/group/fair) | Cold 악화, Warm 미미 (코덱스 검증) |
| source-split-models | 코덱스 risky 평가 — split 후 sample 반감 |
| 5 카테고리 확장 | 계약 변경 위험 큼 |

## 4. 정직성 관점 — 메트릭이 "진짜"인가

### 학습/서빙 contract 정합 (PR #20+#21+#22 효과)
- ✅ feature drift 제거 (career_age, work_age, vintage, freshness, gallery_name)
- ✅ warm 라우팅 학습/서빙 동일 (warm_artist_slugs JSON)
- ✅ source calibration 학습 시점 fit, 서빙 적용 일관
- ✅ categorical 정규화 학습/서빙 동일

### 정직한 평가 (post-hoc bias 잔존, 코덱스 검증)
- ⚠️ Cross-fit calibration: factor 추정은 OOF지만 guard cell selection은 동일 OOF 결과 보고 결정 → post-hoc selection bias 잔존
- ⚠️ Production-time MdAPE: 모델 OOF + full-data routing/calibration artifact → 순수 OOF 아님
- 결론: **38.3% / 9.7%는 보수적 추정치**. 실제 production 정확도는 그 이상일 수도.
- 추가 검증 필요시: nested CV (outer fold guard 결정, inner fold factor 추정) — 미시행

### 알려진 train/serve drift (사전 존재, 미해소)
- DB schema: `career_stage` INT (1..4) → float (0..8) 마이그레이션 필요
- DB `training_count`: filtered count로 동기화 필요 (32명 미스라우팅 우회 중)
- `gallery_name`: artist_matcher 하드코딩 → PredictRequest 필드 추가 필요

## 7. 실용적 의사결정 가이드

### "지금 production에 사용해도 되나?"
- **A 등급 (warm Artsy)**: ✅ MdAPE 8.1% — 매우 좋음. 사용 권장.
- **A 등급 (warm Saatchi)**: ✅ MdAPE 10.3% — 양호. 사용 권장.
- **B 등급**: ⚠️ MdAPE 29.7% — 사용 가능하나 m=0.30이 좁음 (coverage 50%). 권장 m=0.609로 업데이트 시 더 안전.
- **C/D 등급**: ❌ MdAPE 39~44% — Cold-start 데이터 보강 전까지 신뢰도 낮음. 가격 범위 표시 정책 검토 필요.

### "정확도 더 올리려면?"
1. **갤러리 티어 v3 협력자 검수** — Top 30 검수만으로 Artsy의 81% 재평가 가능 (-1~2%p 가능성)
2. **DB career_age 추가** — 학습/서빙 drift 해소, 신호 회복
3. **갤러리 입력 UX** — Cold-start C/D 큰 폭 개선 가능
4. **PredictRequest gallery_name** — 작은 신호지만 정합

### "정확도 개선이 끝나는 지점은?"
- 1차 시장 가격은 본질적으로 거래 데이터 부족 + 비정형 가격 결정 (큐레이션·협상)
- A 등급 8% 정도가 데이터로 도달 가능한 합리적 한계 추정
- 그 이상은 모델 자체보다 **새 데이터 소스 확보**가 핵심
