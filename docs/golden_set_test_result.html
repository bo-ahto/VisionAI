4. 분석

4.1 Cold Start 성능 평가

골든셋 130명 중 129명이 학습에 없는 작가. Cold Start 모델(CatBoost v2)만으로 예측한 결과:

  • 전체 MdAPE 39.5%: Artsy 학습 데이터 기준 Cold Start MdAPE(33.0%)보다 높음
  • 원인: 골든셋 작가의 가격대가 학습 데이터보다 더 넓음 (14만~1.38억 vs 학습 중앙 360만)
  • 비율 0.88x: 약간의 과소 경향이지만 체계적 편향은 크지 않음

4.3 이력 추출의 한계

이력 텍스트에서 자동 추출된 개인전/단체전 횟수가 career_stage를 결정하는데, 일부 작가에서 오분류:

  • 진희원: 개인전 50회 → 원로(stage 4)로 분류됐지만, 실제 가격은 200만원 (신진 수준)
  • 김재이: 개인전 20회 + 단체전 60회 → 중견으로 분류됐지만, 실제 가격은 225만원

전시 횟수가 많다고 가격이 높은 것은 아님. 전시의 질(기관 급)이 중요한데, 현재 모델은 횟수만 반영.

6. 용어 설명

MdAPE

예측 오차의 중앙값. 39.5%는 절반의 작품이 이 오차보다 정확하다는 의미.

W30

오차 30% 이내 비율. 36.0%이면 150건 중 54건이 정답 대비 30% 이내.

비율 (예측/실제)

1.0x = 정확. 0.88x = 12% 과소 예측. 1.73x = 73% 과대 예측.

Cold Start

학습에 없는 작가의 예측. 작가 가격 이력 없이 크기+매체+생년+이력으로만 예측하므로 정확도에 한계.
