1. 한 줄 요약 + 본 페이지의 결정 범위

현재 증거 기준으로는 신규 작가 영역에 Track 2 모델을 운영 적용할 근거가 부족합니다. 운영 main 모델 (Track 1 v3_filtered_tuned) 을 그대로 유지하는 것이 안전한 방안이며, 다음 의사결정에 필요한 추가 검증 (운영 모델 직접 평가 cycle) 은 별도 승인이 필요합니다.

직접 비교 가 어려운 사유 (3 항목):
  1. 모집단 다름: 운영 Track 1 = 28K Artsy + Saatchi 통합 / 본 비교 = 8,495 Artsy only
  2. Split protocol 다름: 운영 Track 1 = GroupKFold + calibration / 본 비교 = Random LAO + Time-split (calibration 미적용)
  3. Metric 문맥 다름: 운영 reported = 운영 학습/calibration 결과 / 본 비교 = offline cold validation

4. 의사결정 옵션 + 권고

옵션무엇을 하는가기대 효과주요 리스크작업량권고
A. 운영 유지 운영 main 모델 (Track 1 32 features) 그대로 유지 / Track 2 cold 적용 X 현재 증거 와 정합 / 안전 / 즉시 실행 가능 Cold 영역 정확도 개선 X 없음 기본 안전 방안 · 지금 운영 판단 에 가장 적합
B. 운영 모델 직접 평가 cycle 운영 Track 1 (32 features) 을 같은 dataset / 같은 split 으로 직접 평가 (입력 feature 정합성 보강 + Saatchi 통합 등 선행) 승인 가능 한 다음 결정 의 근거 확보 입력 feature 정합성 보강 작업량 ↑ / 평가 환경 의무 중-상 필수 후속 검증 · 다음 결론 만드는 핵심
C. 데이터 확장 cycle Saatchi 모집단 통합 (year_made enrichment) + Track 2 재학습 + broader 재평가 외부 일반화 evidence / Track 2 재기 가능성 B 없이 단독 시 평가 구속력 약함 중 B 또는 D 와 결합 권고
D. 외부 협력 영역 외부 데이터 source 의 license / acquisition / 운영 입력 정합성 확장 Cold 영역 정확도 개선 의 근본 path / 리드타임 길어 조기 착수 유리 외부 의존 / 일정 불확실 중-상 병행 권고 · 조기 착수 가치 높음
E. Track 2 spec 변형 Feature 추가 / loss 변경 / nested CV 등 추가 실험 탐색 / 미세 개선 가능성 현재 미충족 사유 가 spec tuning 부족 인지 불명확 저-중 탐색 후순위 · 결정 병목 해소력 낮음
권고 안 (조합):
  • 보수적 기본: A + B (운영 유지 + 운영 모델 직접 평가 cycle 승인)
  • 현실적 확장: A + B + D (외부 협력 영역 동시 진행 — 리드타임 고려)
  • 공격적 재도전: A + B + D 후 C (데이터 확장 cycle, B/D 정합 후)
  • E 는 어느 안에서도 탐색 후순위

5. 본 페이지에서 결정 해 주실 항목

결정 항목옵션승인 / 보류
① 운영 main 모델 즉시 변경 여부 A (그대로 유지) 또는 다른 안 (승인 / 보류 / 다른 안)
② 내부 검증 cycle 승인 여부 B (운영 모델 직접 평가 — 필수) / C (데이터 확장) / E (spec 변형) (B 단독 / B+C / B+E / 보류)
③ 외부 협력 영역 (D) 진입 여부 D 의 license / data source / API contract 협조 (승인 / 보류 / 단계적)
각 옵션 승인 시 필요한 추가 입력:
  • B 승인: 입력 feature 정합성 보강 우선순위 (Saatchi 통합 vs feature 재구성) + 운영 모델 평가 환경 확보
  • C 승인: B 또는 D 의 선행 결정 / Saatchi year_made provenance 봉인
  • D 승인: 외부 협력 우선순위 + license / acquisition 협조 영역 결정 (외부 협력자 영역)
