5. 권고 안 (조합)

보수적 기본 안: A + B
  • A: 즉시 운영 유지 (안전 default)
  • B: 동시에 Lane 1 cycle 승인 — 다음 결정 의 근거 확보
현실적 확장 안: A + B + D 병행
  • D 의 외부 협력 영역 (license / data source / API contract) = 리드타임 길어 조기 착수 유리
  • B 와 D 가 서로 독립 — 동시 진행 가능
공격적 재도전 안: A + B + D 후 C
  • C (Saatchi 통합) 는 B 의 schema 보강 + D 의 외부 협력 정합 후 진행 가치 ↑

E: 어느 안에서도 탐색 후순위 — 현재 결정 병목 해소력 낮음.
