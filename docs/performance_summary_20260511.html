4. Cycle별 시도 axis 종합

본 세션 시도된 axes (총 8개):
  1. HP retune (CB+XGB unified) — D1.X / D1.Y / D1-extended (cold 모두 fail / warm B 성공)
  2. Architecture change (CB→LGBM) — D1.Arch / D1.Arch.tuned (insufficient)
  3. Source-conditional split — D1.SC (fail)
  4. Blend ratio (50/50 → other) — D3 / D3.B (fail)
  5. Per-source calibration — Reprod / OOS (artsy_online ADOPT_with_caveat)
  6. Feature N=15 migration — N15.A/B/C (종결)
  7. Validation framework reform — VFR (현행 winner)
  8. Threshold/aggregation alternative — D1.Z+alt (non-binding finding)
→ 8 axes 중 1 axis 만 ADOPT 가능 (warm-only HP retune = B winner).
→ Cold path는 4 axes 시도 모두 fail (HP retune / architecture / source-split / threshold relax).
