# Artsy + Artue 통합 모델 실험 결과

> **실험일**: 2026-04-13
> **학습 데이터**: Artsy 7,551건 + Artue 2,756건 = 10,307건 / 1,078명 작가
> **모델**: XGBoost (기존 작가) + CatBoost (Cold Start) 분기

---

## 1. 실험 목적

Artsy 데이터만으로 학습한 모델은 Artue 작품을 예측할 때 **저가 구간 과대 예측**(MdAPE 41.6%)이 발생했다. Artue의 실제 가격 데이터를 학습에 포함하여 이 갭을 해소하고, Artue 작가/작품에 최적화된 모델을 구축한다.

---

## 2. 데이터 구성

| 소스 | 건수 | 작가 | 가격 중앙값 | 특성 |
|------|:----:|:----:|:---------:|------|
| Artsy | 7,551 | 757 | 414만원 | 국제 갤러리, USD 중심 |
| Artue | 2,756 | 363 | 279만원 | 신진 작가, KRW 중심 |
| **통합** | **10,307** | **1,078** | — | 가격대 커버리지 확대 |

통합으로 Artsy에 부족했던 **저가(~100만원) 구간**이 보강되었다.

## 3. 모델 성능

### 3.1 전체 성능

| 모델 | KFold MdAPE | KFold R² | GroupKFold MdAPE | GroupKFold R² |
|------|:-----------:|:--------:|:----------------:|:------------:|
| **XGBoost** | **11.6%** | **0.917** | 33.0% | 0.774 |
| CatBoost | 18.5% | 0.887 | 33.2% | 0.775 |

### 3.2 Artue 서브셋 성능

| 모델 | MdAPE | W30 | 예측/실제 비율 |
|------|:-----:|:---:|:----------:|
| **XGBoost** | **14.2%** | **69.7%** | **1.00x** |
| CatBoost | 24.3% | 57.2% | 1.02x |

### 3.3 Artsy only 대비 개선

| 지표 | Artsy only | 통합 (Artsy+Artue) | 개선 |
|------|:---------:|:-----------------:|:----:|
| Artue MdAPE | 41.6% | **14.2%** | **-27.4%p** |
| Artue W30 | 38.3% | **69.7%** | **+31.4%p** |
| Artue 비율 | 1.12x | **1.00x** | 정확 |
| 전체 KFold MdAPE | 9.7% | 11.6% | +1.9%p |
| 전체 KFold R² | 0.930 | 0.917 | -0.013 |

**Artue 예측이 41.6% → 14.2%로 극적 개선**. 전체 성능은 소폭 하락(9.7%→11.6%)했지만, Artue 가격대를 학습한 효과가 압도적.

## 4. 핵심 발견

### 4.1 저가 구간 과대 예측 해소

Artsy only 모델의 가장 큰 문제였던 저가(~100만원) 과대 예측이 해소되었다. Artue 2,756건 중 상당수가 100만~300만원 구간이라, 이 가격대를 모델이 학습할 수 있게 되었다.

### 4.2 비율 1.00x

Artue 서브셋의 예측/실제 비율이 **정확히 1.00x**. Artsy only(1.12x, 12% 과대)에서 완전히 보정.

### 4.3 Cold Start 한계 유지

GroupKFold(새 작가) MdAPE 33.0%는 Artsy only(31.0%)와 비슷. Cold Start는 데이터를 늘려도 구조적 한계가 존재. 작가의 가격 이력이 없으면 정확도에 한계.

## 5. 실서비스 권장 구조

```
작가의 가격 데이터가 학습에 포함됨?
  ├─ Yes → XGBoost — MdAPE 14.2%, 비율 1.00x
  └─ No  → CatBoost — MdAPE 33.0% (Cold Start)

신규 작가 최소 입력:
  필수: 작품 크기 (가로×세로), 매체
  권장: 작가 생년 (+11.8%p 개선)
```

## 6. 모델 운영

### 6.1 데이터 갱신

| 소스 | 주기 | 방법 |
|------|------|------|
| Artsy | 월 1회 | GraphQL API 자동 수집 |
| Artue | 수시 | 판매 데이터 추가 학습 |

### 6.2 학습 재실행

Artue 신규 판매 데이터가 누적될수록 모델 정확도가 향상된다. 특히 Cold Start 작가가 1~2건만 판매되어도 XGBoost 경로로 전환되어 정확도가 급격히 올라간다.

---

## 7. 용어 설명

### MdAPE (Median Absolute Percentage Error)
예측 오차의 중앙값. MdAPE 14.2%는 전체 작품 중 절반이 이 오차보다 정확하다는 의미.

### W30
예측 오차가 30% 이내인 작품의 비율. W30=69.7%이면 10건 중 7건이 실제 가격 대비 30% 이내.

### 예측/실제 비율
1.0x = 정확, 1.5x = 50% 과대 예측. 통합 모델의 1.00x는 체계적 편향이 없다는 의미.

### Cold Start
학습 시 본 적 없는 작가의 가격을 예측하는 상황. GroupKFold로 평가.
