## ❓ Q1. "기획과 운영 정책에 반영" — `profile_completeness` 8.41% (2026-04-26 17:30)

> 8.41%는 기획과 운영 정책에 반영되어야 하는 부분이네요

### 답변

`profile_completeness` 피처는 다음과 같이 정의됩니다 (`docs/model_technical_report.md:206-208`):

- **Artsy**: $\mathbb{1}[\text{birth\_year} \neq \emptyset] + \mathbb{1}[\text{shows} > 0] + \mathbb{1}[\text{bio} \neq \emptyset]$
- **Saatchi**: $\mathbb{1}[\text{bio} \neq \emptyset] + \mathbb{1}[\text{education} \neq \emptyset] + \mathbb{1}[\text{exhibitions} \neq \emptyset]$

**의미**: "프로필을 성실히 작성한 작가일수록 가격이 높다" — 8.41% 중요도는 **프로필 충실도가 작가 전문성·시장 참여도의 프록시**로 작동함을 시사.

**정책 반영 권장사항**:
1. **작가 등록 가이드 강화**: bio / 학력 / 전시 이력을 모두 입력하도록 안내. 누락 시 가격 예측 신뢰도 하락 명시.
2. **운영 검수**: 신규 등록 시 3개 모두 채워졌는지 확인. 누락 항목 자동 표시.
3. **Cold Start 가격 가이드**: 프로필 충실도 0~3 단계별 예상 가격 영향 제시 (각 단계당 SHAP 기준 평균 5~10% 가격 차이).

**즉시 액션**: 이 피드백은 **운영 정책 영역**이므로 본 모델 개발 외 별 트랙. 운영 매뉴얼 작성 시 본 답변 인용.

## ❓ Q3. "0.00%" 원작/에디션 중요도 (2026-04-26 17:22)

이는 모델이 "원작/에디션이 가격에 무관"하다고 학습한 게 아니라, **데이터에 차이가 없어서 학습 불가**한 상태.

**판화·복제 작품(에디션)은 수집되지 않았거나 학습에서 빠짐**:

- Saatchi: 100% Unique (Saatchi는 원작 전용 플랫폼이라 자연스러움)
- Artsy의 Limited edition 34건도 너무 적어 학습 불가

### 보고서 정정 필요

`docs/model_technical_report.md:255-256` 표 수정:

```
| `is_unique` | 0.00% | 원작 여부 (분산 부족: 학습 데이터 99.9% Unique) |
```

```python
    if career_age >= 30: score += 2
    elif career_age >= 15: score += 1
    if solo_count >= 5: score += 2
    elif solo_count >= 1: score += 1
    if fair_count >= 3: score += 2
    elif fair_count >= 1: score += 1
    if awards >= 3: score += 1
    if has_market_entry: score += 1
    
    if score >= 7: return 4  # 정상위

    if score >= 2: return 2  # 중하위
    return 1                  # 신진
```
