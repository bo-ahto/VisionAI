# 협조 응답 — source 라벨 룰 정의 여부

> **수신**: 콜론30
> **회신일**: 2026-05-06
> **참조 문서**: `docs/model_technical_report_v2.html`

## 질문

> Production 에서 새로 들어오는 데이터(갤러리 직접 입력, 컬렉터 입력 등)에 source 라벨을 어떻게 부여하는지 룰이 정의돼 있나요?

## 답변 (간략)

**현재 별도 룰은 정의되어 있지 않습니다.** 학습 단계에서 사용된 source 라벨은 데이터 출처(`artsy`, `saatchi`) 만 구분합니다.

### 1. 현재 source 라벨 정의

| 값 | 의미 | 비고 |
|---|---|---|
| `artsy` | Artsy primary market dataset | 갤러리 등록 작품 |
| `saatchi` | Saatchi cleaned dataset | 글로벌 platform 작품 |

### 2. Production 새 데이터 처리 — 권고 방안

| 입력 채널 | source 라벨 (권고) | 처리 방안 |
|---|---|---|
| 갤러리 직접 입력 | `gallery_direct` | 신규 카테고리, 학습 분포에 없음 |
| 컬렉터 입력 | `collector_input` | 신규 카테고리, 학습 분포에 없음 |
| 기타 외부 채널 | `external_other` | 통합 처리 |

### 3. 트랙별 영향

**트랙 2 (Hedonic / 해석력)** — source 는 Core 5 에서 **제외**
- 새 source 라벨이 들어와도 핵심 변수에 영향 없음
- 즉시 도입 가능

**트랙 1 (Predictive / V3 기반)** — source 가 입력 변수
- 신규 라벨은 `unknown` / `out-of-distribution` 으로 mapping 필요
- mapping 룰 사전 정의 필요 → **별도 협의 항목**

### 4. 권고 처리 흐름

```
새 데이터 도착
  ↓
source 라벨 부여 (입력 채널 기반)
  ↓
학습 분포에 있는 라벨? — 그대로 사용
  ↓ (없으면)
unknown / external 로 mapping
  ↓
미매칭 분포 모니터링 (drift 감지)
```

### 5. 다음 작업 (협의 필요)

- [ ] Production 입력 채널별 source 라벨 명명 규칙 확정
- [ ] 학습 데이터에 없는 신규 source 의 fallback 룰 정의
- [ ] Source 별 가격 분포 차이 monitoring (입력 채널 별 calibration)
- [ ] 트랙 1 (V3) 의 source feature 처리 (unknown 옵션 도입 여부)

## 요약

- **현재**: source = `artsy` / `saatchi` 만 (학습 출처 기반)
- **Production 새 라벨**: 룰 미정의 → 입력 채널 기반 명명 규칙 협의 필요
- **트랙 2 (해석)**: source 미사용 → 영향 없음
- **트랙 1 (예측)**: 신규 라벨 fallback 룰 정의 필요
