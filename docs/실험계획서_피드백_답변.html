실험계획서 피드백 답변 정리

Q1. 경력 자동 분류 — Career Age 추가 제안

"신진, 중견, 원로 기준에 나이+개인전 횟수 외에 '첫 개인전 이후 경과 연수(Career Age)'를 추가하면 어떨지. 중견 이후 핵심은 시장의 지속성이기 때문에 얼마나 오래 살아남았는가가 핵심."

답변: 매우 타당한 지적. 현재 분류 로직에 career_age = 현재연도 - 첫 개인전 연도를 추가하는 것이 합리적.

반영 방안:

def classify_career_stage(birth_year, solo_count, museum_count, auction_record, first_solo_year):
    age = 2026 - birth_year
    career_age = 2026 - first_solo_year if first_solo_year else 0

    if age >= 60 and solo_count >= 20 and career_age >= 25:
        return 4  # 원로 (25년 이상 지속)
    elif career_age >= 15 and (solo_count >= 10 or museum_count >= 3):
        return 3  # 중견 (15년 이상 + 실적)
    elif career_age >= 5 or solo_count >= 3:
        return 2  # 신진 후기
    else:
        return 1  # 신진

근거: Fraiberger et al.(2018)도 커리어 초기 5년이 이후 궤적을 결정한다고 밝힘. 단순 전시 횟수보다 "얼마나 오래 활동하면서 시장에서 살아남았는가"가 중견/원로 구분에 더 적합.

데이터 확보: KADA 아카이브에서 첫 전시 연도 수집 가능 (VERIFIED).

Q2. 개인/그룹전 — 갤러리/뮤지엄 티어 반영 여부

"전시를 진행한 갤러리, 뮤지엄의 티어도 들어가나요? 제주도 카페 갤러리 개인전과 국제갤러리 개인전의 차이가 반영되는 것인지."

답변: 현재 계획서에서는 단순 횟수만 집계하고 있어 티어 가중치는 미반영. 지적대로 카페 갤러리 개인전 10회와 국제갤러리 개인전 1회는 가치가 전혀 다름.

반영 방안: 전시 횟수를 기관 위신 가중 합산으로 변경

# 단순 횟수 (현재)
exhibition_count = count(전시)

# 가중 합산 (개선)
weighted_exhibition_score = Σ (기관_위신_가중치 × 전시)

기관 위신 가중치 (안):
  국제갤러리/학고재/PKM 급 = 5.0
  중견 갤러리 (갤러리기체 등) = 3.0
  소형 갤러리 = 1.0
  카페/대안공간 = 0.5
  국립현대미술관/서울시립 = 10.0
  해외 미술관 = 8.0
  비엔날레 = 10.0
  아트페어 부스 = 갤러리 등급에 따름

학술 근거: ArtFacts.net의 랭킹 알고리즘도 동일한 원리 — MoMA 전시 1회 > 지역 갤러리 10회.

현실적 방안: 당장은 "미술관 전시 횟수"와 "갤러리 전시 횟수"를 분리하는 것만으로도 상당한 개선. 기관별 가중치 DB는 Phase 1~2에서 점진적으로 구축.

Q3. 순이지 1호 작품 — "점당 가격" 구조

"1호 작품을 호당가로 계산한 것이 아님. '작은 그림 한 점에 최소 50~60만원'이라는 점당 가격 기준이 적용되었기 때문."

답변: 정확한 지적. 실제 데이터를 확인한 결과:

순이지 1호 작품 (15.8×22.7cm, 종이 수채): 50만원 × 12건 (전부 동일가)
순이지 5호 작품 (31.8×31.8cm, 캔버스 아크릴): 60만원 × 7건 (전부 동일가)

1호 50만원은 "호당 50만원"이 아니라 "작은 그림 한 점의 최소 가격 = 50만원"이라는 점당 가격 관행이 적용된 것. 호당가로 역산하면 50만/호로 과대 산출됨.

반영 방안: 3호 이하 소품은 호당가 모델에서 분리

if ho <= 3:
    price = 점당_고정가  # 작가별 소품 최소가 (데이터에서 추출)
else:
    price = α × Ho^0.74  # 비선형 호당가 모델

현재 데이터 기준 소품 가격:

  • 순이지 1호 종이 수채 = 50만원 (점당)
  • 순이지 5호 캔버스 = 60만원 (≒ 12만/호)
  • 이시현 2호 캔버스 = 40만원 (점당)
  • 이동혁 3호 이하 = 120만원 (점당)

Q4. 3호 미만 소품 — 점당 가격 고정 제안

"관행적으로 3호 미만의 소품은 호당 가격이 적용되지 않고 점당 가격으로 책정. 1~3호 작품에 대해 10호 가격의 50~60% 수준을 '점당 가격'으로 고정하는 것은 어떨지."

답변: 업계 관행에 정확히 부합하는 제안. 데이터로도 확인됨:

순이지: 10호 기준 추정 = 120만원 × 10^0.74 ≈ 660만원? → 실제는 아님
         5호(60만) vs 12호(125만) → 10호 추정 ≈ 100만원
         1호(50만) = 10호의 50% → 제안 비율과 일치

이시현: 10호 기준 추정 ≈ 90만원
        2호(40만) = 10호의 44% → 50~60% 범위 내

반영 방안:

소품 가격 규칙:
  1호 이하: 10호 가격 × 0.50  (최소 점당가)
  2호:     10호 가격 × 0.55
  3호:     10호 가격 × 0.60
  4호 이상: α × Ho^0.74 (비선형 모델)

이 규칙은 업계 관행과 데이터 모두에서 지지되므로 계획서에 반영 필요.

Q5. F/P/M/S형 호수 변환

"캔버스 규격이 F,P,M,S에 따라 면적 차이가 상당한데 면적을 호수로 단순 변환해도 괜찮은지?"

답변: 엄밀히는 안 됨. 같은 10호라도:

  • F형 (Figure): 53.0 × 45.5 = 2,412cm²
  • P형 (Paysage): 53.0 × 40.9 = 2,168cm²
  • M형 (Marine): 53.0 × 33.4 = 1,770cm²
  • S형 (Square): 53.0 × 53.0 = 2,809cm²

면적 차이 최대 58% (M vs S). 그러나 현실적으로:

  1. 현재 데이터에 호수 타입 정보가 없음 — size_raw에 "80.3 x 130.3 cm"만 기록
  2. aspect_ratio로 타입 추정 가능: F형(≈1.17), P형(≈1.30), M형(≈1.59), S형(≈1.00)
  3. 업계에서도 호당가는 F형 기준이 표준 — P/M은 동일 호수로 취급하는 것이 관행

반영 방안:

# 현실적 접근: aspect_ratio 기반 타입 추정
if aspect_ratio ≈ 1.0:  type = "S"
elif aspect_ratio < 1.2: type = "F"
elif aspect_ratio < 1.4: type = "P"
else: type = "M"

# 면적 → 해당 타입 테이블에서 호수 매칭
ho = match_ho_by_type(area, type)

단, 94건 파일럿에서는 F형 단순 변환의 영향이 크지 않을 것으로 판단 (대부분 F형 비율 작품). Phase 1에서 타입별 변환 적용.

Q6. 매체 보정 — 지지체 + 에디션/유니크 구분 필요

"종이와 캔버스/에디션과 유니크 구분이 꼭 필요. 순이지 34건 중 저가 작품(30만원)이 종이 드로잉이라면 캔버스 호당가 모델에 넣으면 통계적 왜곡. 호당가는 보통 캔버스, 원화(유니크) 기준."

답변: 데이터로 확인한 결과 정확히 지적한 문제가 존재:

순이지 34건 분석:
  종이 수채 (Watercolor on paper panel): 13건, 중앙 50만원
  캔버스 아크릴 (Acrylic on canvas):    20건, 중앙 160만원
  목재 아크릴 (Acrylic on wood):         1건, 300만원

한국 작가 전체 지지체별:
  캔버스: 69건, 중앙 330만원
  종이:   17건, 중앙 50만원  ← 캔버스의 15%
  면:     3건, 중앙 1,400만원
  기타:   7건, 중앙 1,600만원

종이 작업이 캔버스 대비 약 85% 저렴 (330만 vs 50만). 이를 구분 없이 호당가에 넣으면 혼합 편향 발생.

반영 방안: 호당가 모델에 2단계 필터 적용

Step 0. 1차 분류 필터:
  지지체: 캔버스(canvas/linen) vs 종이(paper) vs 기타
  복제성: 유니크(원화) vs 에디션(판화/프린트)

Step 1. 호당가는 "캔버스 + 유니크" 기준으로만 산출
Step 2. 종이 작업 = 캔버스 호당가 × 0.30~0.50 (보정 계수)
Step 3. 에디션 = 별도 가격 체계 (에디션 넘버, 총 부수에 따라)

Q8. 갤러리 명성 ↔ 가격(-) 해석

"메이저 갤러리는 높은 운영비를 반영하고 작가의 권위를 보증하기 때문에 가격이 훨씬 높게 형성됨. 메이저 갤러리 = 가격 프리미엄(+) 가중치가 필요."

답변: 피드백이 한국 시장의 현실을 정확히 반영하고 있음. 계획서의 Schönfeld(2007) 인용이 오해를 유발함.

원 논문의 맥락: Schönfeld(2007)의 "갤러리 명성 ↔ 가격 음의 상관"은 유럽 시장에서 메이저 갤러리가 유망 신진 작가에게 투자 목적으로 낮은 진입 가격을 제공하는 현상을 설명. 즉, 유명 갤러리가 신진 작가를 일부러 싸게 팔아 시장을 만드는 전략.

한국 시장 현실: 한국에서는 반대로 메이저 갤러리(국제, 학고재, PKM) 소속 = 가격 프리미엄(+)이 일반적.

반영 방안: 계획서에서 갤러리 명성 효과의 방향성을 한국 시장 맥락으로 수정:

한국 시장: gallery_tier가 높을수록(메이저) → 가격 프리미엄 (+)
  이유: 갤러리 브랜드가 작가 가치를 보증 + 높은 운영비 반영
  Schönfeld(2007)의 음의 상관은 유럽 투자형 갤러리 맥락이므로
  한국 적용 시 방향성 재검증 필요

Q11. 미디어 언급 vs 전문가 비평 정량화

"미디어 언급량과 별개로 비평(전문가 평가) 정량화도 가능할까요?"

답변: 이론적으로 가능하나 정량화 난이도가 높음.

가능한 접근:

1. 비평 존재 여부 (binary): 주요 미술 매체에 리뷰 있음/없음
2. 비평 매체 등급: 월간미술(5점) > 아트인컬처(4점) > 블로그(1점)
3. 비평 감성 분석: NLP로 긍정/부정 분류 (고난이도)
4. 비평가 등급: 유명 비평가의 리뷰 = 높은 가중치 (최고 난이도)

현실적 방안: Phase 0~1에서는 네이버 뉴스 API로 언급 빈도만 측정. 비평 정량화는 Phase 2 이후 수동 태깅으로 파일럿 검증 후 자동화 여부 결정.

Q12. 김윤신 1명 — 작가 편향 제거

"이런 작가 편향은 제거되는 것인가요?"

답변: 현재 파일럿에서 아트페어 호당가 215만원이 김윤신 1명에서만 나온 것은 전시 유형 효과가 아닌 작가 효과일 가능성이 높음. 이미 계획서에 "PARTIAL — 작가 혼동 주의"로 표기됨.

제거 방법:

1. 전시 유형 효과 측정 시 "작가 고정효과(fixed effect)"를 통제
   → 같은 작가 내에서 개인전 vs 그룹전 가격 차이만 측정
2. 현재 11명 중 아트페어 출품이 김윤신뿐이므로
   아트페어 효과는 데이터 확대 전까지 측정 불가
3. 개인전 vs 그룹전 비교는 여러 작가에서 관측되므로 유효

Q13. 작품 연식(제작연도) 변수 추가

"중견 이상은 전성기 작품이 더 비싸고, 신진은 최신작일수록 가격이 상승. 신진에게 작년 그림은 재고, 원로에게 70년대 그림은 보물."

답변: 매우 중요한 피처 제안. 작품 연식의 가격 효과가 경력 단계에 따라 방향이 반대라는 통찰이 핵심.

반영 방안:

work_age = 현재연도 - 제작연도

# 경력 단계별 연식 효과 (인터랙션)
if career_stage >= 3:  # 중견/원로
    vintage_premium = f(work_age)  # 오래될수록 프리미엄 가능
else:  # 신진
    freshness_discount = f(work_age)  # 오래될수록 할인 (재고)

# 또는 단순화:
work_age_effect = work_age × career_direction
  career_direction = +1 (원로: 빈티지 프리미엄)
  career_direction = -1 (신진: 신선도 감소)

현재 데이터: 연도 컬럼 존재 (제작연도). 즉시 피처화 가능.

Q14. 레지던시 선정 횟수 추가

"수상과 별개로 국공립 레지던시 선정 횟수도 추가할 수 있을까요? 레지던시 선정 여부는 작가 커리어의 중요한 지표."

답변: 한국 미술계에서 레지던시는 신진→중견 전환의 핵심 게이트웨이. 매우 유효한 피처.

주요 국공립 레지던시:

Tier 1 (국립):
  국립현대미술관 창동/고양 레지던시
  서울시립미술관 난지 레지던시

Tier 2 (공립):
  경기도미술관 레지던시
