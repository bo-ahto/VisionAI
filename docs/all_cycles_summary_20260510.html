7.2 Search-time CV scheme bug pattern (KFold vs GroupKFold)

N15.B run #1 KFold cold (artist sharing) → search-time scale ~10-12 / validation GroupShuffleSplit ~38-40 / 3-4× scale gap. Constraint screening이 잘못된 객체에서 동작. Codex R4 P0 fix → GroupKFold 정정 후 spurious "warm improvement" 부호 반전 (-2.64 → +3.76pp).

7.4 Frozen feature contract vs fold-adaptive search

Sweep amendment의 N=15 winner는 fold마다 다른 top-15 → 1-SE band winner. Frozen feature set으로 freeze 시 재현 X (N15.A에서 sweep 시그널 부분 재현 / warm signal은 reverse). Operational deployment는 frozen contract 필요 — sweep "winner"가 deployable이 아닐 수 있음을 본 세션이 입증.
