## 1. 피처 선별 방법론

### 1.1 작가 내 상관 분석 (Within-Artist Correlation)

미술품 가격은 **작가 브랜드**가 지배적. 따라서 단순 "피처↔가격" 상관은 대부분 작가 효과를 반영할 뿐, 실질적 가격 신호가 아닐 수 있음.

**방법**: 작가별 평균 가격을 빼서 "작가 내 잔차"를 구하고, 각 피처와 잔차의 상관을 계산.

```
잔차 = ln_price - artist_group_mean(ln_price)
작가내_상관 = corr(피처, 잔차)
```

작가내 상관 > 0.1이면 **실질 신호** (A등급), ~0이면 **작가 대리지표** (B/C등급).

### 1.2 등급 분류

| 등급 | 기준 | 의미 | 수 |
|------|------|------|-----|
| **A** | 작가내 상관 > 0.1 | 같은 작가의 다른 작품 간 가격 차이 설명 | 9개 |
| **B** | 작가 간 신호 (CatBoost 기여 > 1%) | 작가 브랜드를 수치화하는 핵심 피처 | 10개 |
| **C** | CatBoost 비선형 기여 | 단독 선형 상관 약하나 트리 분기에서 활용 | 12개 |

## 4. 추가 최적화 실험 결과

### comp_to_avg_ratio 실험

**정의**: `ln(comp_artist_avg) - ln(artist_avg_price)` — 비교 거래가 작가 평균 대비 높은/낮은 정도

**작가내 상관**: r=0.71 — 현존 모든 피처 중 가장 강력

| 구성 | MdAPE | Warm | Cold | Gates |
|------|-------|------|------|-------|
| 31개 (기준) | 40.87% | 38.61% | 57.90% | **4/7** |
| 33개 (+comp_to_avg_ratio, comp_match_level) | **40.35%** | **38.09%** | 59.98% | 3/7 |

**결과**: Warm -0.52%p 개선하지만 Cold +2.08%p 악화.
**원인**: Cold 작가는 comp_artist_avg가 NaN → comp_to_avg_ratio도 NaN → 모델 혼란.
**판단**: Cold 데이터 보강 또는 Cold 전용 모델 도입 시 재투입 가치 있음.

### comp_weighted 가중치 실험

**변경**: 레벨별 감쇠 가중치 (L1=1.0, L2=0.8, L3=0.5, L4=0.3)

| 구성 | MdAPE | Cold | Gates |
|------|-------|------|-------|

**판단**: 가중치 적용 시 Cold 보정 로직 필요.

## 5. 핵심 발견

### 5.1 comp_artist_avg와 comp_weighted의 실체

**코드 분석 결과**: `compute_comparable_sales()`에서 comp_weighted는 comp_artist_avg와 **동일한 값**을 반환.

```
L1/L2: comp_weighted = comp_artist_avg (작가 기반)
L3/L4: comp_weighted = comp_medium_avg (매체 기반, 작가 미매칭)
```

comp_weighted의 12.6% 기여도의 실체:
- comp_artist_avg가 NaN인 16,705건에서 comp_medium_avg 값을 제공
- 실질적으로 **폴백 가격**의 역할

### 5.2 Warm vs Cold 트레이드오프

모든 피처 최적화에서 공통된 패턴:
- **Warm 개선 ↔ Cold 악화** 가 상충
- 추가 피처는 Warm에서 정보를 더 추출하지만 Cold에서 노이즈로 작용
- **31개가 Warm/Cold 균형의 최적점**

### 5.3 가격 예측의 본질

작가내 상관 분석으로 밝혀진 가격 결정 구조:

```
총 가격 분산 = 작가 효과 (75~80%) + 작품 효과 (15~20%) + 노이즈 (5%)

작가 효과: artist_clean, artist_avg/median/max, nationality
작품 효과: 크기(surface, sides), 매체×크기, 비교거래, 경매사
노이즈:   시장 변동, 당일 경매 분위기, 상태 등 (미관측)
```

현재 모델은 작가 효과를 잘 캡처하고 작품 효과도 부분적으로 캡처.
**노이즈 5%가 이론적 MdAPE 하한(~35%)의 원인.**
