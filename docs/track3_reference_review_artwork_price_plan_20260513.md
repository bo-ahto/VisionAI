## 1. 참고 문서에서 좋은 점

- `작가 이름만 외우는 모델`의 위험을 명확히 짚고 있음
- 실제 운영에서는 정보가 일부 빠진 작품도 예측해야 한다는 점을 잘 설명함
- `Warm / Cold`와 유사한 다중 모델 구조 필요성을 직관적으로 설명함
- `미래 정보 사용 금지`를 강하게 강조함
- `가격 하나`가 아니라 `가격 범위 + 신뢰도`로 보여줘야 한다는 관점이 있음

## 2. 현재 Track 3와 잘 맞는 부분

- 작가 정보를 활용하는 모델과 활용하지 않는 모델을 분리하자는 방향
- 작가명 없이도 작품 구조 정보만으로 예측 가능한지 확인해야 한다는 방향
- 미래 정보 사용 금지
- 정보가 적을수록 예측 범위를 넓게 보고 신뢰도를 낮게 봐야 한다는 방향
- 일부 정보를 의도적으로 가린 상태에서도 모델이 버티는지 확인해야 한다는 방향

## 3. 바로 반영하면 안 되는 부분

- `source_platform`
- 현재 Track 3 운영 입력 제약과 충돌
- 분석용 참고는 가능하지만 최종 운영 입력 변수로는 바로 반영하기 어려움
- `작가의 최근 평균 거래가 / 최고가 / 상승률`
- 매우 유용할 수 있지만 거래일 이전 정보만 사용해야 해서 누수 관리가 필수임
- `작가 평균 가격대를 뺀 모델`
- 아이디어 자체는 좋지만 현재 Track 3에서는 아직 별도 가설로 검증되지 않았음
- `이미지 스타일`
- 현재 Track 3 핵심 실험선에는 아직 포함되지 않음

## 4. 현재 체계에 반영한 신규 가설

- `H9`
- 일부 정보를 의도적으로 가리고 학습한 모델이 결측 상황에서 더 잘 버틸 것이다
- `H10`
- 작가명 자체보다 거래 이력 기반 구조화 피처가 Warm에서 더 설명 가능하고 안정적일 것이다
- `H11`
- 정보량에 따라 단일 가격보다 가격 범위와 신뢰도를 함께 주는 방식이 더 실용적일 것이다
- `H12`
- 작가 기본 가격대를 먼저 추정하고, 작품별 편차를 따로 예측하는 2단계 구조가 일부 Warm 상황에서 더 설명력 있을 것이다
