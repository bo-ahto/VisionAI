## 1. 프로젝트 개요

**목표**: 한국 미술품 경매 낙찰가 예측 AI 시스템 구축

**입력**: 작가명, 매체(재료), 크기, 경매일시, 경매사
**출력**: 예상 낙찰가 (하한/중앙/상한 구간)

**방법론**: Hedonic Pricing Model (Rosen 1974)
- 작품의 물리적 속성(크기, 매체), 작가 이력(과거 거래, 경력), 시장 지표를 피처로 사용
- 로그 가격 회귀 → 분위수 예측 → Conformal Calibration

## 5. 모델 아키텍처

### 5.1 3-모델 비교 체계

#### Model-A: CatBoost MultiQuantile
- **구조**: CatBoost 단일 모델, 3-분위수 동시 예측 (q25/q50/q75)
- **하이퍼파라미터**: iterations=2500, depth=9, lr=0.03, l2_leaf_reg=4.0
- **Test MdAPE**: 44.64%

#### TwoStep: 5-Bin Classifier + Per-Bin Regressor
- **구조**: 가격대 5분류 (budget/low/mid/high/premium) → 각 bin별 CatBoost
- **가격대**: [0, 100만, 500만, 2000만, 1억, ∞]
- **Test MdAPE**: 47.14%

#### Ensemble: CatBoost + LightGBM + XGBoost → RidgeCV (최종 선택)
- **Level 0**: CatBoost MQ + LightGBM (q25/q50/q75) + XGBoost (q25/q50/q75)
- **Level 1**: RidgeCV 메타러너 (분위수별 독립, alpha CV)
- **CatBoost**: iterations=2000, depth=8, lr=0.05
- **LightGBM**: n_estimators=2000, depth=8, lr=0.03, num_leaves=63
- **XGBoost**: n_estimators=2000, depth=8, lr=0.03, quantile regression
- **시간 가중치**: 반감기 2년, 최소 가중치 0.5
- **Test MdAPE**: **42.81%** (최적)

### 5.2 CQR (Conformalized Quantile Regression)
- alpha=0.38 → 62% 목표 커버리지
- 각 모델별 독립 CQR 캘리브레이터
- Calibration set(5%)으로 학습

### 5.3 Cold Start 처리
- **정의**: artist_total_sold < 5
- **유사작가 피처**: K-NN 5명의 가격 통계 (warm에도 감쇠 적용)
- **newness_score**: max(0, 1 - total_sold/5) 연속값 (기존 binary → 연속)
- **매체×크기 폴백**: 작가 데이터 부족 시 매체+크기 조합 평균

### 8.5 결론
> **미술품 가격은 이미지의 시각적 내용과 무상관.**
> 가격은 **작가 브랜드 + 크기 + 매체 + 시장 상황**으로 결정되며,
> Pre-trained CNN/CLIP 임베딩은 가격 신호를 캡처하지 못함.
> 미술품 전용 fine-tuned 모델이나 "상태/보존도" 등
> 더 세밀한 시각 정보가 필요할 수 있음.

### 10.2 실현 가능한 개선 방향

**단기 (이미지 없이, 목표 ~40%)**
| 과제 | 예상 효과 | 비고 |
|------|----------|------|
| 가격대별 전문 모델 | -1~2%p | 고가/저가 패턴 차이 활용 |
| Rolling window CV | Gap -1%p | 시계열 안정성 |
| 작가 프로필 추가 수집 (유료 DB) | -0.5~1%p | 커버리지 9.7%→30%+ |

**중장기 (근본적 접근 변경 필요)**
| 과제 | 예상 효과 | 비고 |
|------|----------|------|
| 미술품 전용 이미지 모델 fine-tuning | 미지수 | ImageNet/CLIP pre-trained는 효과 없음 확인 |
| 작가미상 전용 모델 | 커버리지↑ | 29,614건 활용 가능 |
| 텍스트 임베딩 (KoBERT) | -0.5~1%p | 규칙 기반 NLP 대체 |
| GNN 작가 관계 학습 | -1~2%p | 작가-작가 유사성 그래프 |

### 10.3 핵심 인사이트

> **미술품 가격의 본질적 불확실성**
> - 같은 작가/같은 크기 유화도 주제/상태에 따라 10배 차이 가능
> - 경매는 당일 분위기/경쟁 입찰에 크게 좌우
> - 학술 문헌에서 hedonic 모델 R²는 0.4~0.6 (현재 0.48)
> - **이미지 피처 없이 40% 근처가 실질적 한계**로 확인
>
> **이미지 피처의 한계**
> - ResNet50/CLIP 모두 가격 예측에 기여하지 못함 (R² < 0)
> - 미술품 가격은 시각적 품질이 아닌 **작가 브랜드**가 지배
> - "이 그림이 예뻐서 비싼 것"이 아니라 "이 작가가 유명해서 비싼 것"
>
> **서비스 관점**
> - MdAPE 42.81%는 "가격 참고용"으로 충분한 수준
> - Coverage 57.78% → 절반 이상의 작품에서 실제가가 구간 안에 들어옴
> - Warm artist MdAPE 40.76% → 기존 거래 이력 있으면 비교적 정확

### 12.2 주요 발견

1. **작가 프로필**: 510명(9.7%)이지만 레코드 41% 커버 → MdAPE -0.63%p
2. **인터랙션 피처**: artist×medium 조합이 효과적 → Cold -2.09%p
3. **newness_score**: binary→연속값 전환이 cold/warm 경계 부드럽게 처리
4. **시간 가중치**: 반감기 1년은 cold 악화, 2년이 최적 균형

6. **이미지 피처**: ResNet50/CLIP 모두 가격과 무상관 (R² < 0)
7. **이상치 클리핑**: 1%-99% 범위 클리핑은 효과 미미
