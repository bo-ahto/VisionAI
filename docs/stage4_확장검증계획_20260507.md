## 4. 분할 / 평가 protocol (v3 — 변경 없음)

### 4.1 Split 정책 — 3-way

| Split | 정의 | 용도 | 실제 (Artsy clean) |
|---|---|---|---|
| **Train** | year_made ≤ 2023 | 모델 fit | 4,207 작품 / 555 작가 |
| **Val** | year_made == 2024 | hyperparameter / model selection | 1,953 / 376 |
| **Test** | year_made == 2025 | 최종 평가 (primary hypothesis) | 2,335 / 402 |
| **Rolling sensitivity** | cutoff 2022 / 2023 / 2024 | 강건성 (test 와 별도) | (참고) |

- **Warm threshold**: `WARM_ROUTING_MIN_WORKS = 10` (변경 없음)
- **Test set freeze**: Phase 1 Stage 3 종료 시점에 test (year 2025) 분리, 변경 X

### 4.2 Bootstrap 정책 (변경 없음)
- 기본 단위: artist cluster
- 반복: n_boot = 2000 (champion)
- 평가 모델: baseline / **FE only (leading candidate)** / Combined (참고) / Combined-shrunk (참고)
- 분리 리포트: 신규 warm (Stage 3 학습에 없던 작가) vs 기존 warm
- Seed 안정성: 10 seed × n_boot = 500 std ≤ 0.5%p

### 4.2.1 본실험 제외 모델 (변경 없음)
- gallery_tier dummy / interaction / fe + tier / fe + interaction (Stage 3 재탐색 결과 기준)
- medium_category, 다중 interaction, Core 5 조합 (선형 모델 권고 검증 결과)

### 4.3 Composition-shift 리포트 (필수)
- Test 작가 분포 (신규 warm vs Stage 3 100 작가 중 warm)
- 가격 분포 (median / IQR) Stage 3 vs Stage 4 비교
- depth 분포 비교

### 4.4 Sample Size Justification

| 항목 | Stage 3 (실측) | Stage 4 (실제 가용) |
|---|---|---|
| Detectable minimum effect | ~3.4%p | 2.5%p (목표) |
| Required artist cluster (test) | 13 | **40** (확보) |
| Required test rows (warm) | 44 | **450** (확보) |
| α | 0.05 (1-sided) | 0.05 (1-sided) |
| Target power | — | 0.80 |
| Bootstrap iterations | 500 | 2,000 (champion) |

### 4.4.1 Power simulation 결과 (v2 — 실제 풀 기반)

> v1 (`stage4_power_simulation.py`): Stage 3 cutoff 2023 의 10 artist effect 분포 → 25 clusters @ 81.8% power (**outlier 영향 과대평가**).
> **v2 (`stage4_power_simulation_v2.py`)**: Artsy 전체 cleansed → train ≤2023 / test 2025 split → 40 test-eligible warm artist 의 실제 effect 분포 (mean -13.49%p, median -5.01%p, std 50.83%p).

| n_clusters | Power (v2) | 판정 |
|---|---|---|
| 13 (Stage 3 baseline) | 24.3% | ✗ |
| 25 | 32.3% | ✗ |
| **40 (Stage 4 가용)** | **44.9%** | **✗ < 0.8** |
| 50 | 52.4% | ✗ |
| 80 | 71.0% | △ |
| 100 | 82.5% | ✓ |
| 200 | 97.9% | ✓ |

> ⚠️ **40 clusters 만으로는 0.8 power 미달**. 표본 자체가 모집단 100% (Artsy 가용 풀) 라 외부 source 없이는 더 확장 불가.

해석 (코덱스 권고):
- **Power 자체보다 effect stability 우선** — heterogeneity / outlier / 2025 test sparsity / bin imbalance 가 진짜 위험
- "유의성 보장" 표현 회피 — Stage 4 합격 기준 (CI 상한 ≤ 0) 통과는 매우 어려울 수 있음
- 본 cycle 의 정직한 기대: **effect 방향성 + segment harm 검증** (통계적 유의성보다)
- 합격 기준 (§6.1) 미달 시 보류 / 폐기 결정 = Phase 2 진입 또는 외부 source 보강 cycle

### 6.0 Pre-registered Analysis Plan (Stage 4 시작 전 freeze)

| 항목 | 사전 고정 값 |
|---|---|
| **Primary hypothesis** | H₀: MdAPE(FE only) ≥ MdAPE(baseline) / H₁: MdAPE(FE only) < MdAPE(baseline) |
| **Primary metric** | warm-only MdAPE (artist-cluster bootstrap, n=2000) |
| **Primary test** | **1-sided 95% CI, 단일 비교 (unadjusted)** — 채택 결정의 유일한 통계 게이트 |
| **Practical significance** | MdAPE 차이 ≤ -0.8%p (상한, 코덱스 권고) |
| **Secondary hypotheses** (Holm m=5, primary 와 별도 family) | Combined / Combined-shrunk / FE only @ depth bin 10-14 / 15-24 / 25+ |
| **Sample 분할** | Train ≤ 2023 / Val == 2024 / Test == 2025 (3-way) + rolling sensitivity cutoff (2022 / 2023 / 2024, 3개) |
| **Stratification** | warm artist depth bin (10-14 / 15-24 / 25+) |
| **Bootstrap unit** | artist cluster |
| **Seed 안정성** | 10 seed 평균 + std (std ≤ 0.5%p 요구) |
| **본실험 제외 모델** | + gallery_tier / + interaction / + medium_category / Core 5 (Stage 3 재탐색 결과 기준) |
| **Baseline model hash** | `track2_v1_20260507` (F4 + log_area spline + Huber eps=1.35 alpha=1e-4) — cold rollout shadow 와 동일 |
| **Feature pipeline version** | `f4_spline_v1_20260506` (artist_slug 정규화 / area_cm2 / birth_year_centered offset / log1p artist_total_works) |
| **Train data hash** | `data/curated/stage4_*.parquet` SHA (Week 1 종료 시 freeze) |
| **Data source (v3 추가)** | **Artsy only** — Saatchi 제외 (year_made 결측) |
| **Cluster pool size (v3 추가)** | 40 test-eligible warm artists (모집단 = 표본) |

### 6.1 합격 (Stage 4 leading candidate 검증 통과)
- **Primary**: FE only vs baseline 단일 비교
  - cluster bootstrap CI 상한 ≤ 0 (또는 P<0 ≥ 95%)
  - **MdAPE 차이 점추정 ≤ -0.8%p** (practical significance)
- **Secondary** (Holm m=5 별도 family, descriptive):
  - depth bin 3 개 + Combined / Combined-shrunk = 5개 비교, family-wise α=0.05 Holm
  - depth bin 별 모두 baseline 대비 개선 권장 (악화 bin 0건이 이상적, primary 통과 여부와 독립)
  - 신규 warm vs 기존 warm 모두 개선 또는 동등 (별도 분석)
- **Segment harm budget** (어느 하나도 초과 X):
  - 가격 저가/중가/고가: +1.0 / +0.5 / +1.0%p
  - source: Artsy only (sensitivity 항목 X)
  - depth bin 10-14 / 15-24 / 25+: +1.5 / +1.0 / +0.5%p
- → Phase 2 (Artsy-only full confirmatory) 진입 자격
- → spec §17 W-S 진입은 Phase 2 합격 후 (즉시 X)

### 6.2 보류 (Stage 5 재검토)
- Primary CI 상한 ∈ (0, +1%p] (부분 유의)
- Practical significance 미달 (점추정 ∈ (-0.8, 0]%p)
- Segment harm 1-2 개 임계 초과
- depth bin 1개 악화

### 6.3 폐기 (warm-only path 후보 제거)
- Primary 점추정 양수 또는 ±0%p 근처
- depth bin 2개 이상 악화
- Segment harm 3개 이상 임계 초과
- 신규 warm 일관 악화

### 6.4 Deviation Rule
- 사전등록 vs 실제 차이 발생 시 별도 deviation log (`docs/methodology_deviation_log.md`) 기록
- Major deviation (가설 / metric / 임계 변경) → 새 exploratory cycle 분리, 본 결과는 폐기
