# VisionAI 가격예측 모델 운영 방향 임원 메모

> **작성일**: 2026-05-05
> **대상**: CTO / 운영 책임자
> **분량**: A4 1페이지
> **출처**: 코덱스 11차 자문 (V4 cycle 종결 + V5 PoC 결과 + 학술 비교 종합)
> **관련 자료**: PR #26, `docs/v4_운영도입_의사결정_20260504.md`, `docs/v5_cycle_plan_20260504.md`

## 1. 한 문장 결론

현재 `integrated_v3_filtered_tuned` 모델은 **기존 거래 이력이 있는 작가(warm-known-artist)** 영역에서는 운영 활용이 가능하지만, **신규 작가(cold-start)** 영역에서는 아직 독립 의사결정 엔진이 아니라 **보조 판단 도구로 제한 운용**하는 것이 타당합니다. 따라서 **V4는 도입 보류를 유지**하고, **V3를 warm 중심으로 운영하면서 V5에서 cold-start 성능 개선에 집중**하는 방향을 권고드립니다.

## 2. 현재 운영 가능성

운영 관점에서 모델의 활용 가능성은 warm과 cold를 구분해서 봐야 합니다. Warm 구간에서는 예측 오차가 실무적으로 수용 가능한 수준이며, 내부 가격 검토·우선순위 선별·운영자 판단 보조에 적극 활용할 수 있습니다. 반면 cold-start는 작가 이력과 시장 맥락이 부족한 특성상 오차 변동성이 크므로, 현재 단계에서는 **자동 의사결정**보다 **confidence-gated 보조 도구**로 쓰는 것이 적절합니다.

즉, 지금 시점의 권고는 **"warm 적극 활용, cold 제한 활용"** 입니다.

## 3. 객관적 성능 핵심

V4 cycle 검증 기준으로 warm KFold MdAPE는 **12~18%** 로, 운영상 "좋은 시나리오"에 해당합니다. 반면 cold-start holdout MdAPE는 **28~48%** 로 높고, warm 대비 **약 23%p 격차**가 확인됩니다. 정확도 측면에서도 **W30(예측이 실제값 ±30% 이내)** 는 warm이 **50% 이상**, cold는 **38%** 수준입니다. Cold의 **W50(±50%)도 60%** 에 머물러, 상당수 예측이 넓은 허용구간 밖으로 벗어납니다.

외부 학술 결과와 비교하면, 당사 모델은 **warm에서는 공개 literature 대비 경쟁력이 높고**, cold-start도 "비정상적으로 나쁜 수준"은 아닙니다. 다만 미술 시장의 본질적 불확실성을 감안해도, **cold를 현재 바로 확장 운영하기엔 신뢰도가 부족**합니다.

## 4. 리스크 및 한계

핵심 리스크는 **cold-start 일반화 성능 부족**입니다. 이는 모델 문제이기도 하지만, 미술품 가격 자체가 작가 맥락·시장 심리·희소성에 크게 좌우되는 구조적 한계도 포함합니다. 또한 V4에서 시도한 `gallery_tier_v4`는 repeated holdout 기준 **재현 가능한 개선을 입증하지 못했습니다** (CB Overall **+0.45 ± 1.54**). 반면 CatBoost에서 **Saatchi 채널 일관 악화**는 반복 확인되어, **Saatchi 제외를 기본 정책으로 두는 현재 판단은 타당**합니다.

## 5. 다음 단계 (3~6개월)

향후 3~6개월의 초점은 V5 cycle입니다. 방향은 명확합니다. 첫째, **image embedding(DINOv2)** 은 가격 일반화에 실질 가치가 없다는 점이 확인되었으므로 우선순위를 낮춥니다. 둘째, **structured retrieval(매체·사이즈 기반 NN)** 신호를 중심으로 cold-start gap 축소를 노려야 합니다. 현재 PoC 기준 V5의 cold-start 개선 기대치는 **-2~4%p**, stretch goal은 **-5%p (예: 31→25)**, worst case는 **개선 없음** 입니다. 셋째, repeated holdout·fairness·사전등록 기반의 검증 체계를 유지해, "좋아 보이는 실험"이 아니라 **재현 가능한 개선만 채택**해야 합니다.

## 6. 장기 방향

장기적으로는 단일 가격(point estimate) 제시보다 **예측 범위(range estimate)와 confidence score를 함께 제공하는 시스템**으로 전환해야 합니다. 시장 특성상 모든 작품을 한 숫자로 맞히는 접근에는 한계가 있으며, 운영적으로도 **"얼마나 맞는가"보다 "어디까지 신뢰할 수 있는가"** 가 더 중요합니다. 따라서 제품 방향은 **range estimate + confidence gating** 이 되어야 합니다.

## 7. 결정 요청

임원진께 요청드리는 결정은 세 가지입니다.

1. **V4 도입 보류 유지**
2. **V3를 warm 중심으로 계속 운영하되, cold는 제한적·보조적으로만 사용**
3. **V5에 3~6개월 집중 투자하여 cold-start 개선 여부를 검증하고, 개선 폭이 미미할 경우 cold 자동화 확대는 보류**

현재 시점의 합리적 결론은 **no-go가 아니라 selective continue** 입니다. Warm에서는 운영 가치가 있고, cold는 아직 확장 운영의 기준에 도달하지 않았습니다.

## 부록 — 메모 작성 배경 (참고용)

### 학술 비교 reference
- Scientific Reports 2024 (contemporary art auction): metadata-only XGBoost R² ~73%, 전문가 추정 ~90%
- Applied Sciences 2024 (print/multiples auction): XGBoost 최고 sMAPE ~55%
- 결론: 우리 warm 성능은 공개 literature 대비 강한 편, cold-start는 비정상적으로 나쁘지 않음

### V5 cycle 핵심 plan (`docs/v5_cycle_plan_20260504.md` 참조)
- 1순위: C-lite (GPBoost mixed-effects) — seen-artist 개선 + uncertainty
- 2순위: R (composite retrieval prior) — image incremental gate 검증
- 백업 후보: S (structured-only retrieval) — image cut 시 fallback
- 검증: artist-level 80/20 holdout × 3 seeds + 사전등록 protocol

### V4 cycle 학습 (`docs/v4_운영도입_의사결정_20260504.md` 참조)
1. Selection bias (탐색+평가 같은 fold) → holdout 분리
2. Capacity vs feature effect 혼재 → budget-matched 비교
3. KFold artist leakage → LAO split 표준
4. Single split 비재현 → repeated 3-seed
5. Cherry-picking 위험 → 사전등록 의무

### 코덱스 자문 11차 trajectory
| 회차 | 주제 |
|---|---|
| 1-5차 | V4 cycle (선정 → 진단 → 보류 결정) |
| 6-9차 | V5 cycle (방향 → plan → PILOT → 재조정) |
| 10차 | 모델 종합 평가 (warm/cold 분리, 학술 비교) |
| 11차 | 본 임원 메모 작성 |
