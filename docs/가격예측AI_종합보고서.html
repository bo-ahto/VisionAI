2. 모델 아키텍처

모델 유형 명시: 본 시스템은 "헤도닉 피처 기반 Gradient Boosted Tree 앙상블"이며, 전통적 헤도닉 회귀 모델(OLS: ln(P) = β₀ + ΣβᵢXᵢ)과는 다릅니다.
헤도닉 가격 이론에서 피처 설계(작가, 매체, 크기 등 속성 분해)를 차용하되, 피처 → 가격 매핑은 선형 회귀 대신 트리 모델을 사용하여 비선형 인터랙션과 범주형(5,269명 작가)을 처리합니다.

참고 비교: 수치형 23개 피처만으로 전통 헤도닉 회귀(OLS)를 돌리면 MdAPE 67.0%. 현재 트리 모델은 범주형 포함 31개로 MdAPE 40.87% (최종 앙상블 기준).
단, 이는 피처 세트와 모델 구조가 다른 비교이므로 순수 모델 차이라고 볼 수 없음. OLS에 CatBoost 단독(31개)을 대응시키면 MdAPE 58.2%. 전통 회귀 공식은 섹션 4.3에서 참고용으로 제시합니다.

3. 31개 피처 상세 + 중요도

피처 설계 배경: 헤도닉 가격 이론(Rosen, 1974)에서 속성 분해 방식을 차용 — 가격 ≈ f(작가, 매체, 크기, 경매사 등).
여기에 비교매출, 시장 지수 등 추가 엔지니어링 피처를 결합. 모델은 OLS 회귀가 아닌 Gradient Boosted Tree 사용.
상위 4개 피처 = 전체 중요도의 43%

피처 등급 기준

A등급: 작가 내에서도 가격 설명력 있음 (같은 작가의 다른 작품 간 가격 차이 설명)
B등급: 작가 간 차이를 설명 (작가 브랜드 수치화)
C등급: CatBoost 비선형 효과로 기여 (단독 선형 상관 약하나 트리 분기에서 활용)

4. 예측 공식

4.1 전체 예측 흐름

Step 1. 피처 생성 (31개) — cutoff 시점 기준, 미래 정보 차단
Step 2. Base Learner 예측 (9개)
           CB_q25/q50/q75, LGB_q25/q50/q75, XGB_q25/q50/q75
Step 3. Meta-Learner (RidgeCV) — 분위수별 독립 학습
           q_i = w₁·CB_qi + w₂·LGB_qi + w₃·XGB_qi + b
Step 4. CQR 보정 — Conformal Quantile Regression
           low = q25 - Q̂,  high = q75 + Q̂
Step 5. 분위수 순서 보장 (PAV pooling)
           q25 ≤ q50 ≤ q75  (분위수 교차 방지, G8 크기-가격 단조 상관과는 별개)
Step 6. exp 변환 → 원화
Step 7. Bias 보정: 저가 /1.079, 고가 /1.075
Step 8. 시장 단위 라운딩 (100만~5000만 단위)

4.2 피처 생성 공식 — 31개 피처가 만들어지는 과정

A. Bayesian Shrinkage (공통 기법)

여러 피처에 공통 적용되는 수축 추정. 거래가 적은 그룹(작가·매체)의 극단값을 전체 평균 쪽으로 당겨 안정화. 
shrunk_ln = (n × group_mean_ln + m × global_mean_ln) / (n + m)
                                        m = 10 (수축 강도)

n=0  → 100% 전체평균  (데이터 없는 작가)
n=10 → 50:50 혼합
n=50 → 83% 작가 고유값

적용 대상: artist_median_price, cold_start 계층별 폴백
(제거된 medium_avg_price에도 적용됐으나 현재 모델에선 미사용)

B. 비교매출 (comp_artist_avg, comp_weighted, comp_match_count) — 비중 26.6%

가장 중요한 피처 그룹. "이 작가의 비슷한 작품이 최근 얼마에 팔렸는가"를 4단계로 매칭. 
■ Level 1 (match_level=1.0): 작가 + 매체 + 크기(면적 ±20%)
   조건: 매칭 ≥3건
   comp_artist_avg = mean(최근 3건의 낙찰가)
   comp_weighted   = comp_artist_avg와 동일 값 (현재 구현에서 별도 가중 없음)

■ Level 2 (match_level=2.0): 작가 + 매체 (크기 무시)
   조건: 매칭 ≥3건
   comp_artist_avg = mean(최근 3건)

■ Level 3 (match_level=3.0): 매체 + 크기 (작가 무시)
   조건: 매칭 ≥10건
   comp_medium_avg = mean(최근 10건)  ← comp_artist_avg는 채워지지 않음
   comp_weighted   = comp_medium_avg와 동일

■ Level 4 (match_level=4.0): 매체 전체 (글로벌 폴백)
   조건: 매칭 ≥5건
   comp_medium_avg = mean(해당 매체 전체)
   comp_weighted   = comp_medium_avg와 동일
   ※ L3/L4에서 comp_artist_avg는 NaN으로 남음 (코드에서 미할당)

comp_match_count = 매칭된 거래 건수
                   0건이면 비교 불가 → 높은 불확실성

C. 작가 통계 (artist_avg_price, artist_median_price, artist_max_price) — 비중 15.9%

■ artist_avg_price = round(mean(prices_before_cutoff))
   cutoff 이전 해당 작가의 모든 낙찰가 단순 평균

■ artist_median_price (Bayesian Shrinkage 적용):
   IF count ≥ 3:
       artist_median_price = median(prices)
   ELSE:
       ln_shrunk = (count × ln(median) + 10 × ln(global_median)) / (count + 10)
       artist_median_price = exp(ln_shrunk)

■ artist_max_price = max(prices_before_cutoff)
   작가의 역대 최고 낙찰가 → "천장 가격" 참조점

D. 작가 파생 통계 (변동성·추세·모멘텀·빈도) — 비중 6.3%

■ artist_price_volatility = std(ln(prices))
   최소 3건 이상 (미만 → NaN)
   높으면 예측 불확실성 큼

■ artist_price_trend = (최근 5개월 평균 / 이전 전체 평균) - 1.0
   ※ date mode: _subtract_periods(cutoff, 5) = 5개월 전 날짜
   최소 5건 이상 (미만 → NaN),  양수 = 상승세

■ artist_price_momentum = (최근 3개월 평균 / 전체 평균) - 1.0
   ※ date mode: 3개월 창
   최소 3건 (미만 → NaN),  >0 = 상승,  <0 = 하락

■ artist_last_hammer_price = 가장 최근 세션의 낙찰가 중앙값

■ artist_auctions_since_last
   date mode: cutoff 날짜 - 마지막 거래 날짜 = 일수 (days)
   session mode: cutoff 세션 - 마지막 세션 = 세션 수

■ artist_total_sold = count(price > 0 before cutoff)
   Cold Start 기준: <5건 = Cold

E. 크기 피처 (short/long_side_cm, ln_surface_area, aspect_ratio, size_bucket, orientation) — 비중 15.2%

■ short_side_cm = min(height_cm, width_cm)
  long_side_cm  = max(height_cm, width_cm)
  → 회전 무관하게 크기 표현 (세로/가로 혼동 방지)

■ ln_surface_area = ln(height_cm × width_cm)
  → 로그 스케일에서 가격과 더 선형적 관계

■ aspect_ratio = height_cm / width_cm
  → 정방(~1.0) vs 세로 긴 형태 vs 가로 긴 형태

■ size_bucket = 면적 기준 이산 구간 (pd.cut)
  소형(<2,720cm²) / 중형(2,720~7,320) / 대형(7,320~22,000) / 초대형(>22,000)

■ orientation = {landscape, portrait, square}
  ratio > 1.2 → portrait,  ratio < 0.83 → landscape,  그 외 → square

F. 인터랙션 피처 (artist_medium_price_ratio, medium_size_avg_price, price_segment_median) — 비중 7.1%

■ artist_medium_price_ratio
  = mean(prices | 작가, 매체) / mean(prices | 작가)
  "이 작가의 유화는 전체 평균 대비 몇 배인가?"
  예: 김환기 유화 = 1.8 (전체보다 80% 비쌈)
      김환기 판화 = 0.3 (전체보다 70% 저렴)

■ medium_size_avg_price (3단계 폴백)
  IF count(매체 × size_bucket) ≥ 5:
      = mean(prices | 매체, size_bucket)      ← "중형 유화 시세"
  ELIF count(매체) ≥ 5:
      = mean(prices | 매체)                   ← "유화 시세"
  ELSE:
      = global_mean(prices)                   ← 전체 시세

■ price_segment_median = ln(median(prices | medium_category))
  "유화 시장의 기준 가격" = ln(280만) ≈ 14.8
  "판화 시장의 기준 가격" = ln(35만) ≈ 12.8
  ※ 주의: 현재 구현은 split 전 전체 데이터에서 계산 (cutoff 무관).
    엄밀히는 미래 정보 누수이나, 매체별 중앙가는 시간에 따라
    큰 변동이 없어 실질적 영향은 제한적. 향후 cutoff 기반으로 개선 권장.

G. 시장·출처 피처 (market_price_index, auction_house_tier, source_count) — 비중 5.8%

■ market_price_index (시장 평균가, 엄밀한 지수는 아님)
  = date mode: 최근 3개월 전체 낙찰가 단순 평균
    session mode: 최근 3세션 평균
  → 시장 전체 호황/불황 시그널 (유일한 시계열 피처)
  ※ 구성 효과(composition effect)에 취약한 단순 평균

■ auction_house_tier = {1, 2, 3}
  1 = 메이저 (서울옥션, 케이옥션, 에이옥션)  중앙가 145만 (데이터 실측)
  2 = 중견 (아이옥션 등)                     중앙가 42만
  3 = 소형                                   중앙가 80만

■ source_count = 작가가 출품한 고유 경매사 수
  1개 = 지역 작가,  4+ = 전국구

H. 범주형 피처 (artist_clean, medium_category, support_category, artist_nationality) — 비중 18.1%

■ artist_clean: 정규화 작가명 (5,269명)
  CatBoost native categorical → 작가별 leaf 분기 직접 학습
  빈 값/작가미상 → "__UNKNOWN__" 통합, 그 외 원본 작가명 그대로 사용
  ※ 이명 통합(예: 이우환↔Lee Ufan) 로직은 미구현 — 향후 과제

■ medium_category: 17개 범주
  유화, 아크릴, 수묵, 수채, 판화, 조각, 사진, 혼합매체, ...
  → CatBoost가 매체별 기본 가격대를 학습

■ support_category: 8개 범주
  캔버스, 종이, 비단, 판, 금속, 섬유, 없음, 기타
  → 캔버스 유화 vs 종이 수묵 = 가격 계층 분리

■ artist_nationality: {KR, WS, JP, UN}
  KR=한국, WS=Western(서양 및 기타 해외 통합), JP=일본, UN=미상
  한국 vs 해외 작가의 가격 결정 패턴 차이

I-2. 제목 주제 (title_subject) — 비중 1.3% (별도 카테고리)

■ title_subject: 제목에서 NLP 추출한 주제
  추상, 풍경, 인물, 꽃, 정물, 서예 등
  → 같은 작가 내 풍경(+12.5%), 추상(-9.9%) 가격 차이 (데이터 실측, 서예는 66건으로 +2.8%)
  범주형이지만 카테고리 분류상 "범주형 (ID/매체)"와 별도로 분리

I. 프로필 피처 (artist_age_at_sale, is_deceased) — 비중 3.6%

■ artist_age_at_sale = 경매년도 - 작가 생년
  프로필 확보된 510명/5,269명 (9.7%)에서만 유효
  미확보 → NaN (CatBoost가 결측 자체를 패턴으로 학습)

■ is_deceased = True/False
  작고 작가: 더 이상 신작 없음 → 희소성 프리미엄
  작고 중앙가 150만 vs 생존 100만 (데이터 실측)

4.3 전통 헤도닉 회귀 공식 vs 현재 트리 모델

본 시스템은 헤도닉 가격 이론에서 피처 설계를 차용하되, 모델은 전통 OLS 회귀 대신 Gradient Boosted Tree를 사용합니다. 아래에 두 접근의 차이를 명시합니다.

A. 전통 헤도닉 회귀 (참고용 — 닫힌 공식 있음)

ln(Price) = 4.616                                  ← 절편 (모든 피처=0일 때 수학적 값, 시장 의미 없음)
  + 0.655 × artist_price_volatility               ← 변동성 큰 작가 → 고가 편향
  + 0.521 × price_segment_median                  ← 매체별 기준가 (ln scale)
  - 0.238 × auction_house_tier                    ← tier +1단계 → 가격 -21%
  + 0.219 × artist_medium_price_ratio             ← 작가×매체 비율 +0.1 → 가격 +2.2%
  + 0.064 × artist_price_momentum                 ← 모멘텀 +0.1 → +0.6%
  + 0.051 × source_count                          ← 경매사 +1곳 → +5.3%
  + 0.051 × ln_surface_area                       ← 면적 1%↑ → 가격 0.05%↑ (탄력성)
  + 0.013 × short_side_cm                         ← +10cm → 가격 +13.7%
  + 0.001 × artist_total_sold                     ← +10건 → 가격 +1.0%
  + ...  (나머지 피처는 계수 < 0.001)

  Test R² = 0.525  |  MdAPE = 67.0%
  (수치형 23개 피처만 사용, 범주형 8개 미포함)
  ※ 절편 4.616은 모든 피처가 0일 때의 수학적 값이며 시장의 "기본가"가 아님
계수 해석 예시:
auction_house_tier의 β = -0.238이므로, tier가 1(메이저)에서 2(중견)로 바뀌면:
   가격 변화 = exp(-0.238) = 0.788, 즉 -21.2% 하락.
short_side_cm의 β = 0.013이므로, 단변이 50cm에서 60cm로 +10cm 커지면:
   가격 변화 = exp(0.013 × 10) = 1.137, 즉 +13.7% 상승.

B. 현재 시스템: 트리 모델 (닫힌 공식 없음)

핵심: 트리 모델에는 y = w₁×comp + w₂×size + ... 같은 닫힌 공식이 존재하지 않습니다.
대신 983개 트리 × 256개 leaf = 25만개 경로 중 피처 조합에 맞는 하나를 선택하여 비선형적으로 가격을 결정합니다.

가격 결정 순서 (모델이 학습한 패턴):
1. 비교매출이 가격의 출발점 설정 (comp_artist_avg/comp_weighted 등 = 26.6%)
2. 작가 브랜드가 기준선 확립 (작가통계 15.9% + 범주형 ID/매체/국적 18.1% = 34.0%)
3. 크기가 기준선에서 상하 조정 (크기 6개 피처 = 15.2%)
4. 나머지가 미세 보정 (인터랙션 7.1% + 작가 파생 통계 6.3% + 출처+시장 5.8% + 프로필 3.6% + 제목 1.3% = 24.1%)

4.4 앙상블 예측 공식

Level-0: Base Learner 3개 × 3분위수 = 9개 예측

■ CatBoost MultiQuantile
  loss = "MultiQuantile:alpha=0.25,0.5,0.75"
  iterations=2000, depth=8, lr=0.05, l2_leaf_reg=4.0
  → CB_q25, CB_q50, CB_q75  (한 모델에서 3개 동시 출력)
  범주형: native categorical (cat_features 지정)

■ LightGBM × 3 (분위수별 독립 모델)
  objective="quantile", alpha={0.25, 0.50, 0.75}
  n_estimators=1500, max_depth=7, lr=0.03, num_leaves=63
  → LGB_q25, LGB_q50, LGB_q75
  범주형: pandas Categorical dtype 자동 인식

■ XGBoost × 3 (분위수별 독립 모델)
  objective="reg:quantileerror", quantile_alpha={0.25, 0.50, 0.75}
  n_estimators=1500, max_depth=7, lr=0.03
  → XGB_q25, XGB_q50, XGB_q75
  범주형: 정수 코드 변환 (.cat.codes) 후 입력

■ 결측 처리: 3개 모델 모두 NaN을 별도 분기로 처리 (결측 = 정보 신호)

Level-1: RidgeCV Meta-Learner (앙상블 결합)

분위수별 독립 학습 (Calib 데이터 2,723건 사용):

FOR qi in {q25, q50, q75}:
    X_meta = [ CB_qi,  LGB_qi,  XGB_qi ]   ← 3개 base 예측값
    y_meta = actual_ln_price

    RidgeCV(alphas=[0.01, 0.1, 0.5, 1.0, 5.0, 10.0]).fit(X_meta, y_meta)

    final_qi = w₁·CB_qi + w₂·LGB_qi + w₃·XGB_qi + b

단조성 강제: q25 ≤ q50 ≤ q75 (위반 시 PAV pooling)

CQR (Conformal Quantile Regression)

Calib 데이터에서 비순응 점수 계산:
    E_i = max(q25_i - y_i,  y_i - q75_i)

Q̂ = quantile(E, 1-α)    여기서 α = 0.38

최종 구간:
    price_low  = exp(q25 - Q̂)     하한
    price_mid  = exp(q50)          중앙 예측
    price_high = exp(q75 + Q̂)     상한

목표 커버리지 62%, 실측 57.5%
→ -4.5%p undercoverage 원인:
   1) Calib→Test 간 concept drift (시장 변화)
   2) 비정상성: Calib 기간의 Q̂가 Test 기간에 과소 추정
   3) Cold 작가의 높은 분산이 구간 이탈률을 높임

Bias Correction (가격대별 과대예측 보정)

Valid 데이터에서 가격대별 median(pred/actual) 비율을 동적으로 계산:

  구간 정의:
    저가: pred < 200만
    중가: 200만 ≤ pred < 2000만
    고가: pred ≥ 2000만

  bias_factor[seg] = median(pred[seg] / actual[seg])   ← 학습 시 계산
  corrected = pred / bias_factor

  최근 학습 결과: 저가 1.079, 중가 1.003, 고가 1.075
  ※ 이 값은 하드코딩이 아니라 학습 시마다 Valid에서 재계산됨

적용 범위: q50(중앙 예측)에만 적용. q25/q75 구간은 CQR이 이미 보정.
가격대 판정: 보정 전 exp(q50) 기준으로 구간 결정.
원인: 트리 모델이 극값을 평균 쪽으로 당기는 경향 (regression to mean)

시장 라운딩

최종 원화 변환 후 시장 관행에 맞게 라운딩:
  <100만      → 10만 단위    (예: 47만 → 50만)
  100~500만   → 50만 단위    (예: 320만 → 300만)
  500~1000만  → 100만 단위   (예: 780만 → 800만)
  1000~5000만 → 500만 단위   (예: 2,300만 → 2,500만)
  5000만~1억  → 1000만 단위
  1억 이상    → 5000만 단위

round_half_up: floor(price / unit + 0.5) × unit

4.5 Cold Start 예측 (거래 <5건 작가)

■ Tier 0: 기존 거래 ≥5건 → 정상 모델 사용 (Warm)

■ Tier 1: 외부 데이터 (Artsy 등) ≥3건
    cold_estimate = external_stats["avg_ln_price"]

■ Tier 2: K-NN 유사 작가 (5명) ≥3명
    cold_estimate = weighted_avg(similar_artists.ln_price)
    유사 피처: sim_avg_price_ln, sim_weighted_price_ln, sim_count, sim_avg_distance

■ Tier 3: 매체 × 경매유형 (Bayesian Shrinkage)
    조건: count ≥ 30
    shrunk = (n × group_ln + 10 × global_ln) / (n + 10)  ← 실제 n 사용

■ Tier 4a: 매체만 (Bayesian Shrinkage)
    조건: count ≥ 50
    shrunk = (n × group_ln + 10 × global_ln) / (n + 10)

■ Tier 4b: 경매유형만 (최종 폴백, tier=4로 반환)
    cold_estimate = mean(ln(prices)) by auction_type (shrinkage 미적용)

■ 최후 수단: 전체 평균 (tier=4)
    cold_estimate = global_mean_ln

신뢰도 등급:
  A: total_sold ≥ 20 AND tier=0
  B: 5 ≤ total_sold < 20
  C: total_sold < 5 OR unsold_rate > 50%
  D: 신규 작가 OR tier ≥ 2

4.6 시간 가중치

sample_weight = max(0.5,  2^(-(days_ago / 730)))

  반감기 = 730일 (2년),  최소 가중치 = 0.5

  예시:
    오늘 경매      → weight = 1.00
    1년 전         → weight = 0.71
    2년 전         → weight = 0.50 (반감)
    5년 전         → weight = 0.50 (바닥)
