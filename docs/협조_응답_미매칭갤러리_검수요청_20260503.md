## 0. 요청 요약

PR #19 의 학습 데이터 분석 결과, Artsy 갤러리 **66개 중 11개 (17%) 만** 협력자 리스트와 매칭되어 있습니다. 미매칭 Top 30 갤러리가 Artsy 데이터의 **81.5%** 를 차지하므로, 이들의 한글명·tier 확정만으로 모델의 gallery_tier_v3 피처 도입 가능 여부가 결정됩니다.

**ROI**: Top 30 검수 → Artsy 작품 5,937 건 (전체의 81.5%) 재평가 가능.

## 3. 검수 요청 항목 (각 갤러리당)

협력자 리스트 (`data/art_gallery_tier_list_v3.xlsx - 전체 리스트.csv`) 의 schema (`티어 / 분류 / 명칭`) 와 정합:

| 필드 | 형식 | 비고 |
|---|---|---|
| 명칭 (한글, 확정) | 텍스트 | 추정명 검증 또는 미상 갤러리 한글명 추가 |
| 티어 | Tier A / B / C / D / E | 협력자 리스트 의 `티어` 컬럼 정합 |
| 분류 | 갤러리 / 기관 / 기타 | 협력자 리스트 의 `분류` 컬럼 정합 |
| 리스트 추가 여부 | yes / no | yes = 협력자 리스트 v3 에 신규 row 로 추가 |
| 비고 | (선택) | 한국 갤러리 / 해외 / 폐업 / 온라인 전용 등 |

**회신 형식**: CSV 에 4 컬럼 추가 (협력자 리스트 schema 와 동일 명):
- `명칭_한글` (확정)
- `티어` (Tier A / B / C / D / E)
- `분류` (갤러리 / 기관 / 기타)
- `리스트_추가_여부` (yes / no)
- `비고` (선택)

→ 회신 받으면 운영 측에서 `art_gallery_tier_list_v3.xlsx` 의 "전체 리스트" 시트에 신규 row 로 직접 추가 가능 (schema 일치).

## 4. 검수 후 후속 작업 (backend)

협력자 회신 받은 후:

1. **협력자 리스트 v3 갱신**: 운영 측 `data/art_gallery_tier_list_v3.xlsx`
   ("전체 리스트" 시트) 에 회신 row 추가 (schema 정합 — 4 컬럼 그대로)
2. `analyze_gallery_tier_coverage.py` 의 `gallery_name_to_korean` 매핑
   (현재 11건 hardcode) 에 신규 영문→한글 매칭 추가
3. 모델 retraining (별도 PR — Phase 1B 진입 가능 여부 재판정)
4. Tier B vs E 가격 분리도 (현재 2.04x, n=114) 재측정 — 검수로 표본 늘리면 통계적 유의성 확보 가능
