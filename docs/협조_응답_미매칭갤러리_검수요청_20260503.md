## 0. 요청 요약

PR #19 의 학습 데이터 분석 결과, Artsy 갤러리 **66개 중 11개 (17%) 만** 협력자 리스트와 매칭되어 있습니다. 미매칭 Top 30 갤러리가 Artsy 데이터의 **81.5%** 를 차지하므로, 이들의 한글명·tier 확정만으로 모델의 gallery_tier_v3 피처 도입 가능 여부가 결정됩니다.

**ROI**: Top 30 검수 → Artsy 작품 5,937 건 (전체의 81.5%) 재평가 가능.

## 3. 검수 요청 항목 — CSV 직접 작성

### 작업 방식

`docs/unmatched_galleries_top30.csv` 를 Excel / Google Sheets 에서 열면
**12 컬럼 중 마지막 5 컬럼이 빈칸**입니다. 그 5 컬럼만 채워서 회신해 주세요.

### CSV 컬럼 구조 (12 컬럼)

| # | 컬럼명 | 작성 여부 | 설명 |
|---|---|---|---|
| 1 | `순위` | (참고) | 작품 수 기준 1-30위 |
| 2 | `영문명` | (참고) | Artsy 데이터의 원본 영문명 — **수정 X** |
| 3 | `정규화_영문명` | (참고) | 매칭 알고리즘용 — **수정 X** |
| 4 | `작품_수` | (참고) | 학습 데이터 안의 작품 수 |
| 5 | `Artsy_점유율_pct` | (참고) | 미매칭 중 비중 |
| 6 | `분석_메모_참고용` | (참고) | 저희 측 메모 ("한글명 미상 — 검수 필요" 등) |
| 7 | `추정_한글명_참고용` | (참고) | 저희 측 추정 — 검수 시 참고만 |
| **8** | **`명칭_한글_확정`** | **✏️ 작성 필요** | 협력자 측 확정 한글명 |
| **9** | **`티어`** | **✏️ 작성 필요** | Tier A / B / C / D / E |
| **10** | **`분류`** | **✏️ 작성 필요** | 갤러리 / 기관 / 기타 |
| **11** | **`리스트_추가_여부`** | **✏️ 작성 필요** | yes / no |
| **12** | **`비고`** | (선택) | 자유 메모 |

### 컬럼별 허용 값 (5개 작성 컬럼)

#### 8. `명칭_한글_확정` (필수)

- 7번 `추정_한글명_참고용` 이 **맞으면 그대로** 8번에 입력
- **틀리면 정정**해서 입력
- **빈칸 (한글명 미상 5건 — Genuine Global Company / CDA / AVO / SPACE SO / oaoa)**: 검수 후 정확한 한글명 또는 음역 입력
- 한글이 없는 해외 갤러리는 영문명 그대로 또는 음역 (예: "유아트스페이스", "브루노 마사")

#### 9. `티어` (필수, 5 값 중 1개)

| 값 | 의미 |
|---|---|
| `Tier A` | 국공립 + 주요 사립 미술관 / Frieze·Art Basel 메인 섹션 3회+ |
| `Tier B` | 한국 메인 갤러리 (KIAF / Frieze 참가 + 작가 개인전) |
| `Tier C` | 하이엔드 라이징 / 이머징 / 신생 |
| `Tier D` | 한국화랑협회 회원 / 지역 중소 |
| `Tier E` | 미분류 / 신생 / 기타 |

→ 결정 어려운 경우 비고에 "?" 또는 "이중 분류 가능" 메모.

#### 10. `분류` (필수, 3 값 중 1개)

| 값 | 의미 |
|---|---|
| `갤러리` | 일반 상업 갤러리 |
| `기관` | 미술관 / 비영리 기관 / 재단 |
| `기타` | 온라인 플랫폼 / 아트페어 / 기타 |

#### 11. `리스트_추가_여부` (필수, yes / no)

- `yes` = 협력자 리스트 v3 (`art_gallery_tier_list_v3.xlsx`) 에 신규 row 로 추가
- `no` = 추가 안 함 (모델에서 Tier E 기본값 처리)
- 결정 기준: 한국 미술 시장에서 의미 있는 갤러리/기관이면 `yes`

#### 12. `비고` (선택)

- 한국 갤러리 / 해외 / 폐업 / 온라인 전용 / 신생 / 이중 분류 등 자유 메모
- 검수가 어려운 갤러리 ("?" 표시) 도 여기에

### 작성 형식 예시 (가상의 갤러리 — 권장 분류 아님, **형식 참고용**)

⚠️ 아래는 **형식 이해용 가상 예시** 입니다. 실제 30 갤러리 (rank 1-30) 의 권장
티어/분류는 협력자 검수 결과로 결정해 주세요. 아래 값은 검수 input 으로
사용하지 마세요.

```csv
순위,...,추정_한글명_참고용,명칭_한글_확정,티어,분류,리스트_추가_여부,비고
99,...,(가상예시1) 추정명,확정 한글명,Tier B,갤러리,yes,
99,...,(가상예시2) (빈칸),확정 한글명,Tier E,기타,no,분류 모호
99,...,(가상예시3) 추정명,(추정명 동일),Tier C,갤러리,yes,온라인 전용
```

각 컬럼 채움 패턴만 참고:
- 추정명 그대로 / 정정 / 빈칸에서 새로 채움 — 3 패턴 모두 가능
- `리스트_추가_여부=no` 인 row 도 5 컬럼 모두 채움 (yes/no 결정만)

### 운영 측 후속 절차 (협력자 작업과 무관 — 참고용)

회신 받은 후 운영팀이 자동 변환:
- `리스트_추가_여부 = yes` row 만 filter
- `명칭_한글_확정` → `명칭` 컬럼으로 rename
- `티어 / 분류 / 명칭` 3 컬럼만 추출 → `art_gallery_tier_list_v3.xlsx` 의 "전체 리스트" 시트에 append
- `비고` 는 별도 메모 (시트에 없음)

## 4. 검수 후 후속 작업 (backend)

협력자 회신 받은 후:

1. **협력자 리스트 v3 갱신**: 운영 측 `data/art_gallery_tier_list_v3.xlsx`
   ("전체 리스트" 시트) 에 회신 row 추가 — §3 의 변환 절차 (5 컬럼 회신
   → filter `리스트_추가_여부=yes` + rename `명칭_한글_확정 → 명칭` +
   drop `비고` → 3 컬럼 시트 schema) 적용
2. `analyze_gallery_tier_coverage.py` 의 `gallery_name_to_korean` 매핑
   (현재 11건 hardcode) 에 신규 영문→한글 매칭 추가
3. 모델 retraining (별도 PR — Phase 1B 진입 가능 여부 재판정)
4. Tier B vs E 가격 분리도 (현재 2.04x, n=114) 재측정 — 검수로 표본 늘리면 통계적 유의성 확보 가능
