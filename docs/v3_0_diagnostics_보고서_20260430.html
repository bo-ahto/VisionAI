3. 1.2 v1 vs v2 proxy 비교

3.1 한계 — 정직 명시

v1 OOF raw 예측이 산출물에 보존되지 않아 엄밀 paired Wilcoxon signed-rank test 불가능. 정확한 paired test는 v3.1에서 v1을 28,376건 동일 데이터로 재학습한 뒤 진행 예정. 본 라운드에서는 대체로 v1 점추정이 v2 OOF Bootstrap 95% CI 내부에 들어가는지 proxy 비교만 수행.

학습 데이터도 다름: v1 n=29,361 (입체 포함), v2 n=28,376 (입체 985건 제외). v1 OOF가 985건 입체 작품에서 어떻게 동작하는지 알 수 없으므로 conservative bound.

6. 1.5 Learning Curve (slice-split SOFT PASS)

6.1 방법

  • 5개 fraction (0.10 / 0.25 / 0.50 / 0.75 / 1.00)
  • Nested cumulative subsampling: 각 fold에서 작가/행 permutation 1회 → fraction은 prefix 슬라이스 (10% ⊂ 25% ⊂ 50% ⊂ 75% ⊂ 100% 강제 → Monte Carlo noise 최소화)
  • Paired bootstrap CI on Δ50→100:
    • Cold: artist-cluster bootstrap (n_clusters=1551) — GroupKFold 일반화 질문에 정렬
    • Warm: row-level bootstrap — KFold 작품 단위 분할에 정렬

12.1 인사이트 1 — 1차년도 정량 목표 통계적 입증

12.2 인사이트 2 — D10 saatchi_online 구조적 과대예측 (1.7 발견)

최고가 예측 decile (D10, n=2,838) 의 saatchi_online (n=1,499) 가 broad cell saturation: log(pred/actual) median +1.359 (3.9× 과대), SDD01-SDD08 (D10 안의 actual 하위 80%) 모두 강한 음수. 단일 cold cell factor 0.9569로는 부족 — D10 (예측가 ≥ 13.7M KRW) 전용 calibration layer 신설이 v3.1 최우선 모델 변경 항목. v2 보고서의 "saatchi MdAPE 41.7%" 일부는 이 segment에 집중된 비대칭이며, 일반 cold path 보정만으로는 한계.

12.3 인사이트 3 — Cold path 데이터/피처 bottleneck (1.4 + 1.5 + 1.9 결합)

1.4 baseline 비교에서 RF cold 38.95% [38.40, 39.62] vs v2 ensemble cold 38.66% [38.03, 39.19] CI 겹침 — cold path GBDT 우위 약함. 1.5 learning curve cold cluster CI [-0.81, +7.92] 0 포함 — 데이터 추가의 통계적 효용 불명확. 1.9 LOO medium 에서 oil/mixed cold가 baseline 보다 better — 매체 신호가 다른 피처에 분산된 흔적. 결론: cold path 개선은 단순 모델 변경 / 데이터 양 증가보다 피처 강화 / segment 전용 calibration / 라벨 정제가 효과적. (warm은 RF 24.80% vs XGB 9.70% 명확한 GBDT 우위 — 반대 결론)

12.4 인사이트 4 — Cold path 모델 채택 재검토 근거 (Group 2.2 정량 backbone)

현재 production은 cold path에 CatBoost + cell calibration (cross-fit guarded 38.29%) 사용. 그러나 raw OOF 기준 ensemble이 38.66%로 CatBoost 39.38% 보다 우수. 즉 cold ensemble + cell calibration 조합 검토 가치 있음. v3.1 Group 2.2에서 정량 채택 규칙(MdAPE 차이 ≥ 0.5%p / CI 비겹침 / latency / 운영 단순성 4단계 tie-break)으로 결정 예정. (참고: 1.5 인사이트 3과 통합 — 모델 변경 효과 ≤ peak)

12.5 인사이트 5 — v1 vs v2 개선의 통계적 명확성 부족 + 라벨 정제 기회

v2 보고서 §1의 "−2.0%p (XGB warm)" / "−0.6%p (cold)" 점추정 변화는 1.2 proxy 비교에서 통계적으로 명확하지 않음. v3.1에서 v1 재학습 + 정식 paired Wilcoxon으로 power 보강 필수. 또한 1.7 'other' medium 1,144건 중 ~140건 한국 전통 회화 (silk / korean paper / gofun / stone powder) 식별 → korean_traditional 카테고리 신설로 라벨 정제가 가능 (Group 5 데이터 클렌징 backlog).
