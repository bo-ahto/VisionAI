2. 1.1 Bootstrap CI for MdAPE

2.1 방법

  • OOF 산출: scripts/v3_extract_oof.py가 tune_primary_market_v3_filtered.py의 _final_cv_groupkfold_5 / _final_cv_kfold_5와 동일 로직으로 production tuned best_params (CB iterations=1000, lr=0.0953, depth=8 / XGB num_boost_round=3000, eta=0.0401, max_depth=7) 사용해 OOF 예측 산출
  • Bootstrap: scripts/v3_bootstrap_ci.py에서 비파라매트릭 percentile bootstrap, 10,000 resample, seed=42, row-level (artist-cluster bootstrap 아님)
  • 두 cold path 분리 보고: raw OOF + calibrated (cell factor 적용 후 production path)

3. 1.2 v1 vs v2 proxy 비교

3.1 한계 — 정직 명시

v1 OOF raw 예측이 산출물에 보존되지 않아 엄밀 paired Wilcoxon signed-rank test 불가능. 정확한 paired test는 v3.1에서 v1을 28,376건 동일 데이터로 재학습한 뒤 진행 예정. 본 라운드에서는 대체로 v1 점추정이 v2 OOF Bootstrap 95% CI 내부에 들어가는지 proxy 비교만 수행.

학습 데이터도 다름: v1 n=29,361 (입체 포함), v2 n=28,376 (입체 985건 제외). v1 OOF가 985건 입체 작품에서 어떻게 동작하는지 알 수 없으므로 conservative bound.

해석: v1 점추정이 모두 v2 95% CI 내부 ⇒ 이 proxy 비교에서는 v1 vs v2 cold path 차이가 통계적으로 명확하지 않음. 이는 (1) v2 개선이 noise 수준일 수 있거나, (2) proxy 비교가 정식 paired test보다 power가 약함을 의미. 정식 paired Wilcoxon은 v3.1에서 power 강화 예정.

다만 warm slice는 v1과 v2의 slice 정의가 다름 (v1 KFold는 전체 29,361건 / v2 KFold는 warm 27,062건만) — 직접 비교 부적절.

4. 1.3 출처 플립 통계 검정

4.1 방법

  • 표본: warm 30명 (3 코호트 × 10명) — source_flip_results_warm.json
  • 검정: paired Wilcoxon signed-rank (비정규 대응), paired t-test (보조), Cohen's d_z (paired effect size), Bootstrap 10,000 95% CI
  • 비교 단위: log-price 비율 (= ln(price_saatchi) − ln(price_artsy)) — paired difference

4.3 해석

  • 출처 라벨 효과의 크기가 작음: |Cohen's d_z| < 0.6 (small ~ medium)
  • Pooled 95% CI [−0.368, −0.017] 은 0을 포함하지 않으나 Wilcoxon p=0.068 ⇒ α=0.05 기준 경계선 비유의
  • "큰 영향 없음"은 데이터로 입증되나 "사실상 영향 없음"이라고 단언하기엔 표본(n=30)이 부족
  • v2 §5.6의 "사실상 영향 없음" 표현을 "효과 크기가 작음 + 경계선 비유의"로 톤다운 (이미 §5.6 갱신 완료)
  • v3.1 Group 2.1에서 표본 90+ 확장 + 작가별 다중 작품으로 power 보강 예정

5. 핵심 인사이트 3가지

5.1 인사이트 1 — 1차년도 정량 목표 통계적 입증

warm Artsy XGB MdAPE 95% CI [7.97, 8.68] ⊂ A 등급 목표 밴드 [8.0, 9.0]. CI 상한 8.68 < 9.0이라 목표 도달이 점추정 + 통계적 신뢰 구간 모두에서 입증됨.

5.2 인사이트 2 — Cold path 모델 채택 재검토 근거 (Group 2.2 정량 backbone)

현재 production은 cold path에 CatBoost + cell calibration 38.15% 사용. 그러나 raw OOF 기준 ensemble이 38.66%로 CatBoost 39.38% 보다 우수. 즉 cold ensemble + cell calibration 조합 검토 가치 있음. v3.1 Group 2.2에서 정량 채택 규칙(MdAPE 차이 ≥ 0.5%p / CI 비겹침 / latency / 운영 단순성 4단계 tie-break)으로 결정 예정.

5.3 인사이트 3 — v1 vs v2 개선의 통계적 명확성 부족

v2 보고서 §1의 "−2.0%p (XGB warm)" / "−0.6%p (cold)" 점추정 변화는 본 proxy 비교에서 통계적으로 명확하지 않음. v3.1에서 v1 재학습 + 정식 paired Wilcoxon으로 power 보강 필수. v2 개선이 noise 수준일 가능성을 정직하게 인지.
