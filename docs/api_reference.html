VisionAI 1차 시장 가격 예측 API 레퍼런스

API 버전: 1.0.0

모델 버전: v3 (CatBoost + XGBoost 라우팅)

베이스 URL: https://visionai-api.ahto.city

최종 업데이트: 2026-04-17

이 API는 무엇인가

그림 한 점의 작가 이름 · 가로세로 크기 · 재료를 주면, 그 작품의 갤러리 적정 판매가(원/달러)와 신뢰도 등급(A/B/C/D)을 돌려주는 REST API입니다. 학습된 작가는 평균 오차 11.7%, 처음 보는 작가는 약 38.7% 수준입니다. 처음 보는 작가의 경우 Artsy/Saatchi/웹검색으로 작가 프로필을 실시간 자동 수집하여 예측에 반영합니다. 모든 응답은 JSON, 인증 없음(공개 데모 단계).

1. 개요와 기본 정보

1.1 API가 해결하는 문제

한국 미술 1차 시장(작가 → 갤러리 → 첫 구매자)은 가격 공개성이 매우 낮습니다. 갤러리가 신인 작품에 가격을 매길 때, 컬렉터가 구매 전 "이 값이 맞냐"를 따질 때, 모두 비교 기준이 부족합니다. 본 API는 29,361건의 실제 거래 데이터로 학습된 모델에 작품 정보만 넣으면 적정 가격과 신뢰도를 즉시 돌려줍니다.

1.2 베이스 URL과 인증

항목값
Production URLhttps://visionai-api.ahto.city
Content-Type (요청)application/json
Content-Type (응답)application/json
인증없음 (현재 공개 데모 단계)
CORS모든 Origin 허용 (*)

1.3 Rate Limit / Quota

현재는 명시적 제한이 없습니다. 배치 엔드포인트는 요청당 최대 50건으로 제한됩니다. 운영 단계로 이행하면서 API 키·쿼터가 추가될 예정입니다.

1.4 응답 시간 참고치

시나리오평균 소요
학습 작가(DB 매칭, 외부 수집 없음)~100~200ms
처음 보는 작가(외부 수집 포함)~2~5초
skip_external_lookup=true로 외부 수집 스킵~100~200ms

외부 수집은 Artsy GraphQL + Saatchi HTML 파싱 + 웹검색을 포함하므로 초기 비용이 큽니다. 대량 호출 시엔 배치 엔드포인트를 권장합니다(동일 작가 반복은 1회만 수집).

2. 엔드포인트 요약표

MethodPath용도인증
GET/health서비스 생존 확인, DB 연결 상태없음
GET/api/v1/model/info모델 메타(버전, 학습 규모, 성능)없음
GET/api/v1/monitor인메모리 카운터(예측 횟수, 등급 분포 등)없음
POST/api/v1/predict단일 작품 가격 예측없음
POST/api/v1/predict/batch배치 예측(최대 50건)없음
GET/demo브라우저 데모 페이지(HTML)없음

3. GET/health

서비스가 살아있는지 모니터링, CI/CD의 배포 확인 훅, 로드 밸런서 헬스체크.

  "status": "ok",
  "model_version": "v3",
  "artists_loaded": 1589,
  "uptime_seconds": 3281.5,
  "db_status": "connected"

필드타입의미

필드의미
total_predictions서버 가동 후 총 예측 건수
by_grade신뢰도 등급별 건수 (A/B/C/D)
by_model내부 라우팅된 모델별 건수 (variant 별 — 예: xgboost_v3_filtered_tuned, catboost_v3_5_v_year_saatchi_warm). v3.6 PR7 이후 model_type 이 variant prefix 포함.
avg_ms총 처리시간 평균(ms). 단건 + batch 모두 합산 (v3.6 PR9b).

server_instancedeploy pipeline 주입 (env SERVER_INSTANCE). 미주입 시 "unknown".
worker_instance_idv3.6 PR12: process-local uuid4 hex 32자. multi-worker 환경에서 worker 별 식별 — uvicorn --workers spawn 모델 안전. gunicorn preload+fork 시 startup 훅 별도 갱신 필요.

6. POST/api/v1/predict — 핵심 엔드포인트

작가·크기·재료를 주고 단일 작품의 예상 가격을 받고 싶을 때. 제목까지 함께 넘기면 학습 데이터 내 동일/유사 작품의 실제 가격도 매칭해서 돌려줍니다.

6.1 요청 본문 (Request Body)

필드타입필수제약설명
artist_namestring필수길이 ≥ 1작가명 (한국어/영어 모두 가능, 자동 정규화)
width_cmfloat필수0 < x ≤ 500가로 길이 (cm)
height_cmfloat필수0 < x ≤ 500세로 길이 (cm)
mediumstring필수길이 ≥ 1재료 (예: acrylic on canvas, oil on canvas, mixed media on paper)
titlestring선택길이 ≤ 200작품 제목 (같은 작품/유사 제목의 실제 거래가 매칭에 사용)
target_marketstring선택gallery / online유통 경로. 기본 gallery. online 선택 시 Saatchi 기반 보정(-7.5%) 적용
skip_external_lookupbool선택—외부 수집 스킵 여부. 기본 false. 대량 호출/빠른 응답이 필요할 때 true
artist_birth_yearint선택1900~2010작가 출생 연도 수동 입력 (DB/외부 수집값을 덮어씀)
artist_total_worksint선택≥ 0작가 총 작품 수 수동 입력
solo_countint선택≥ 0개인전 횟수 수동 입력
group_countint선택≥ 0단체전 횟수 수동 입력
followersint선택≥ 0플랫폼 팔로워 수 수동 입력

prediction 객체 — 핵심 결과

필드타입의미
price_krwint예측 가격(원)
price_usdint달러 환산(참고용, 환율 1,380원/$)
price_range.lowint신뢰구간 하한(원) = price_krw × (1 − margin)
price_range.highint신뢰구간 상한(원) = price_krw × (1 + margin)
confidence_gradestringA/B/C/D — 아래 표 참조
marginfloat등급별 가격 범위 비율 (A=0.20, B=0.30, C=0.50, D=0.70)

신뢰도 등급 결정 규칙

등급조건가격 범위해석
A학습 데이터에 해당 작가 5건 이상±20%높은 신뢰도 — 패턴을 충분히 학습함
B학습 데이터에 1~4건±30%보통 — 표본 부족, 참고 수준
C학습 데이터엔 없지만 생년 또는 수동 프로필 확보±50%참고용 — 외부 수집 기반 추정
D크기·매체 외 정보 없음±70%단순 추정치 — 구매 의사결정에 단독 사용 비권장

model_info 객체 — 내부 라우팅 정보

필드타입의미
model_typestringxgboost_v3(학습 작가 경로) 또는 catboost_v3(Cold Start 경로)
is_known_artistboolDB 매칭 성공 여부
training_countint학습 데이터 내 이 작가의 작품 수 (미매칭 시 0)

processing 객체

필드타입의미
total_msint요청 전체 처리 시간(ms)
external_fetch_msint외부 수집에 쓴 시간(ms), 없으면 0

external_sources_used 배열

외부 수집이 실제로 사용한 소스명 리스트. 예: ["artsy"], ["saatchi", "web_search"]. 빈 배열이면 DB 매칭만 사용.

feature_contributions 배열 — SHAP 기반 가격 근거

CatBoost 경로(Cold Start)에서만 제공됩니다. 각 피처가 예측 가격에 몇 % 기여했는지를 풀어줍니다.

필드타입의미
featurestring피처 이름 (예: artist_total_works)
valuestring해당 요청의 피처 값
contributionstring기여도 퍼센트 (예: +24.1%, -12.5%)

matched_artworks 배열 — 학습 데이터 내 유사 작품

최대 5건. 매칭 우선순위(품질 좋은 순):

match_type의미
exact_title_size같은 제목 + 같은 호수 (거의 동일 작품)
same_title_diff_size같은 제목 + 다른 호수 (시리즈)
title_only_global제목만 일치 (작가 미매칭 시)
same_size_medium같은 호수 + 같은 매체 (참고용)
similar_size인접 호수 + 같은 매체 (보조 참고)

artist_price_history 객체 — 해당 작가의 학습 데이터 내 가격 이력 요약

매칭된 작가에 한해 제공. 미매칭이면 null.

필드의미
total_works_in_data학습 데이터 내 이 작가 작품 수
price_min / price_max / price_median가격 최저/최고/중앙값 (원)
ho_range호수 범위 (예: 10~150호)
mediums사용된 매체 목록 (최대 5종)
galleries거래 갤러리 목록 (최대 5개)
data_collected_date데이터 수집 시점 (예: Artsy 2026-04-13)
samples대표 작품 샘플 최대 5건 (고가순)

7. POST/api/v1/predict/batch

여러 작품을 한 번에 예측하고 싶을 때. 같은 작가가 여러 번 포함되어 있으면 외부 수집을 작가당 1회만 수행해서 비용을 절약합니다.

7.1 요청 본문

필드타입필수제약설명
artworksarray of BatchItem필수최대 50건예측할 작품 리스트
skip_external_lookupbool선택—전체 요청에 대해 외부 수집 스킵

BatchItem 스키마 — /api/v1/predict와 유사, 단 title 필드 없음

artist_name, width_cm, height_cm, medium은 필수. 나머지 옵션(출생연도·작품수 등)은 동일하게 선택 입력 가능. 단 target_market은 패턴 검증(^(gallery|online)$)이 걸려 있어 그 외 값은 422 오류입니다.

요청 예시

{
  "artworks": [
    {
      "artist_name": "김창열",
      "width_cm": 73, "height_cm": 60,
      "medium": "oil on canvas"
    },
    {
      "artist_name": "김창열",
      "width_cm": 116, "height_cm": 91,
      "medium": "oil on canvas"
    },
    {
      "artist_name": "홍길동",
      "width_cm": 60, "height_cm": 60,
      "medium": "acrylic on canvas",
      "target_market": "online"
    }
  ],
  "skip_external_lookup": false
}

8. GET/demo

브라우저에서 직접 작동 확인하거나 영업·시연 용도로. 페이지가 HTML로 반환되어 별도 프론트엔드 없이 바로 사용 가능.

브라우저에서 https://visionai-api.ahto.city/demo에 접속하면 입력 폼 UI가 뜹니다. 작가명·크기·재료를 입력하면 내부적으로 /api/v1/predict를 호출하여 결과를 카드 형태로 보여줍니다.

응답은 HTML. 이 엔드포인트는 외부 통합용이 아니라 사용자 체험용입니다.

9. 데이터 스키마 상세

9.1 medium(재료) 입력 규칙

자유 문자열이지만 모델이 잘 이해하는 표준 패턴을 권장합니다. 내부적으로 정규화되어 medium_category와 support_type으로 변환됩니다.

표준 패턴예시medium_categorysupport_type
{paint} on {support}oil on canvasoilcanvas
acrylic on canvasacryliccanvas
watercolor on paperwatercolorpaper
mixed media on papermixedpaper
ink on paperinkpaper
gouache on panelgouachepanel

인식 가능한 paint: oil, acrylic, watercolor, gouache, ink, mixed, pastel, tempera. support: canvas, paper, panel, linen, board. 알 수 없는 값은 unknown 카테고리로 폴백.

9.2 작가명 매칭 규칙

  • 한글/영문/혼합 모두 허용 (예: 김창열, Kim Tschang-Yeul, Kim, Tschang-Yeul)
  • 내부적으로 공백/특수문자 제거 및 소문자화 후 퍼지 매칭(rapidfuzz)
  • 매칭 점수가 임계값 이상이면 is_known_artist=true, 아니면 외부 수집 시도
  • 동명이인 방지: 외부 수집 시 2개 이상 독립 소스에서 동일 생년 확인된 경우만 채택

9.3 호수 변환 참조

사용자는 cm로 입력하지만 내부에선 F형 표준 캔버스 호수로 변환합니다. 대표 매핑:

호수대략 크기면적(cm²)

10호53×46cm2,412
20호73×61cm4,304
50호117×91cm9,128

9.4 target_market 값별 차이

값의미내부 보정
gallery(기본)오프라인 갤러리 리스팅가보정 없음

10. 오류 처리

10.1 HTTP 상태 코드

코드의미언제
200 OK성공예측 응답 정상 반환
400 Bad Request잘못된 요청target_market이 gallery/online이 아닐 때
422 Unprocessable Entity스키마 검증 실패필수 필드 누락, 타입 불일치, 범위 초과 (FastAPI 기본)
500 Internal Server Error서버 오류모델 로드 실패, 의존 서비스 장애
503 Service Unavailable서비스 사용 불가헬스체크 degraded 상태 (참고용, 현재 500으로 통일되어 나올 수 있음)

10.2 오류 응답 예시

{
  "detail": "target_market must be 'gallery' or 'online'"
}

FastAPI 422 (Pydantic validation error)는 좀 더 구조적입니다.

{
  "detail": [
    {
      "type": "greater_than",
      "loc": ["body", "width_cm"],
      "msg": "Input should be greater than 0",
      "input": -10,
      "ctx": {"gt": 0}
    }
  ]
}

10.3 알아둘 실패 케이스

  • 작가명이 완전 가상이거나 오타: DB 미매칭 + 외부 수집 실패 → D등급으로 반환. 에러 아님.
  • 크기 500cm 초과: 422 오류. 한국 표준 호수 테이블 범위를 넘으면 모델이 신뢰할 수 없음.
  • 재료 파싱 실패: medium_category=unknown으로 폴백, 예측은 여전히 반환되지만 정확도 저하.
  • 외부 수집 타임아웃: 외부 수집이 실패해도 전체 요청은 성공. external_sources_used가 비어 돌아옴.

11.3 Python — 배치로 10건 처리

import requests

artworks = [
    {"artist_name": "김창열", "width_cm": 73, "height_cm": 60, "medium": "oil on canvas"},
    {"artist_name": "박서보", "width_cm": 162, "height_cm": 130, "medium": "mixed media on canvas"},
    # ... 추가
]

r = requests.post(
    "https://visionai-api.ahto.city/api/v1/predict/batch",
    json={"artworks": artworks, "skip_external_lookup": False},
    timeout=120,
)
data = r.json()
for res in data["results"]:
    if res["status"] == "success":
        p = res["prediction"]
        print(f"[{res['index']}] {p['price_krw']:,}원 ({p['confidence_grade']})")
    else:
        print(f"[{res['index']}] 실패: {res['error']}")

11.4 Python — 수동 프로필 강제 주입

r = requests.post(

        "artist_total_works": 30,
        "solo_count": 2,
        "group_count": 8,
        "followers": 250,
        "skip_external_lookup": true
    }
)
