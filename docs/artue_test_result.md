```
작가가 Artsy에 가격 데이터가 있음?
  ├─ Yes (579건, 46명) → XGBoost — 유사 작가 가격 기반 (전시 피처 포함)
```

## 4. 분석

### 4.1 정확한 구간

- **Artsy 매칭 작가**: 비율 1.05x, MdAPE 22.4% — 실서비스 수준
- **100~300만원 구간**: 모델 학습 데이터(Artsy 중앙값 414만원)와 가장 겹치는 구간
- **500만~1천만원**: 비율 1.02x — 거의 완벽한 추정

### 4.2 부정확한 구간과 원인

| 구간 | 문제 | 원인 |
|------|------|------|
| ~100만원 (648건) | 2~4배 과대 예측 | Artsy 학습 데이터에 저가 작품 부족 |
| 1천만원+ (430건) | 0.63x 과소 예측 | 블루칩 작가 데이터 부족 |
| Cold Start BY 없음 (727건) | 1.19x 과대 | 작가 정보 없이 크기만으로 예측 |

### 4.3 전시 피처 제거가 효과적인 이유

Cold Start 작가는 Artsy에 전시 데이터가 없어 solo_count=0, group_count=0, fair_count=0이 입력된다. 모델이 이 "0"을 "전시 이력이 전혀 없는 신진 작가"로 해석하여 가격을 과소 추정하거나, 노이즈로 작용한다. 전시 피처를 제거하면 모델이 크기, 생년, 팔로워 등 실제 유효한 정보에 집중하여 정확도가 올라간다.

학습 데이터(Artsy) 기준 Cold Start 시뮬레이션에서도 동일한 패턴:

| 추가 정보 | MdAPE | 개선 효과 |
|----------|:-----:|:--------:|
| 크기만 | 48.1% | — |
| +매체 | 47.8% | +0.3%p |
| **+Birth Year** | **31.8%** | **+16.0%p** |
| +전시 횟수 | 33.1% | **-1.3%p (악화)** |
| +갤러리 | 31.3% | +1.8%p |

Birth Year가 MdAPE를 16%p 낮추는 반면, 전시 횟수는 오히려 1.3%p 악화시킨다.

### 4.4 Birth Year의 영향

미술 시장에서 **작가의 나이/세대가 가격 수준의 가장 큰 결정 요인**이다. 1960년대생과 1990년대생의 가격대가 근본적으로 다르다. 크기만으로는 "큰 그림 = 비싼 그림"만 학습하지만, 생년을 알면 "이 세대의 이 크기 = 이 가격대"로 좁혀진다.

## 6. 용어 설명

### MdAPE (Median Absolute Percentage Error)
예측 오차의 중앙값. MdAPE 22.4%는 전체 작품 중 절반이 이 오차보다 정확하다는 의미.

### W30
예측 오차가 30% 이내인 작품의 비율. W30=60.4%이면 10건 중 6건이 실제 가격 대비 30% 이내.

### 예측/실제 비율
1.0x = 정확, 1.5x = 50% 과대 예측, 0.5x = 50% 과소 예측.

### Cold Start
학습 시 본 적 없는 작가의 가격을 예측하는 상황. 작가 개인 가격 이력이 없으므로 프로필(생년, 크기, 매체)만으로 예측.

### XGBoost / CatBoost
Gradient Boosted Tree 계열 머신러닝 모델. XGBoost는 기존 작가 예측에서, CatBoost는 Cold Start에서 더 정확. Cold Start용 CatBoost v2는 전시 피처를 제거한 최적화 버전.
