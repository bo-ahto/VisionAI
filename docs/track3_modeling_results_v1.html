⚠️ 주요 한계 (외부 보고 시 명시)

  • 🔴 본 모델은 "listing-price prediction"이지 "시장가치 예측" 아님 (절대가격 해석 보수적으로)
  • 🔴 Warm med_APE 0.123은 "학습된 작가의 신규 작품" 기준. 실 운영에서 신규 작가가 섞이면 평균 정확도는 더 낮음 (cold mix 비율에 따라 0.15-0.30 사이 추정).
  • 🔴 >100M 고가 작품 Cold-start는 사실상 예측 불가 (med_APE 0.889). 운영 시 가격 가이드 비공개 또는 "문의" 처리 제안. Warm 모델 (학습 작가)은 정상 (med_APE 0.042).
  • ⚠️ Phase 2 비선형 모델은 default hyperparameter 사용. Optuna tuning한 LightGBM이 후속 PR에서 LAD를 추월할 가능성 — Cold 모델 final 결정은 tuning 후 재검토.
  • 시간 split 없음 — 시간 기준 검증 불가 (가격 트렌드 변화 평가 X)
  • Singleton artist 299명 / ≤2건 516명 — 운영은 rare artist 보조 방식 규칙. blend 비율은 Phase 5에서 정성적 제안만, grid search는 후속 PR.
  • Cold LAD 5-fold OOF (0.429) vs outer 검증용 분리 데이터 (0.389) 차이는 작가 sampling variance로 추정. 두 추정치 모두 합리적 범위 (단정 X).
  • Warm 95% CI [0.120, 0.126]는 같은 dev pool random split correlation 큼 → "분포 폭"이 아니라 "split sensitivity" 추정치로 해석.

🔄 후속 실험 제안

  1. LightGBM Optuna tuning (Cold + Warm) — default → tuned 비교
  2. Rare artist blend 비율 grid search (1건/2건 가중치 결정)
  3. Conformal prediction 도입 — 점추정 외 신뢰구간 (Plan v2.1 §4.6 미실행)
  4. Multi-seed Cold LAD (GroupShuffleSplit) — split variance 측정
  5. 가격 데이터 source bias audit — Artsy 갤러리 마크업 vs Saatchi 직거래 등 listing price 차이 정량화
