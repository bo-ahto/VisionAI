## 3. 보류 항목 판단

### H15

- 보류 이유:
- 현재 release split에는 핵심 입력 변수 결측이 없음
- 결측 패턴 피처를 만들어도 값이 모두 같아 학습 신호가 없음
- 추가 실험 가능 조건:
- 운영 입력 데이터에서 실제 결측 사례 확보

### H16

- 보류 이유:
- 현재 release split에는 거래일, 판매일, 등록일 역할을 하는 날짜 컬럼이 없음
- 작가 이력 피처를 예측 시점 이전 정보만으로 계산했는지 검증 불가
- 추가 실험 가능 조건:
- `sale_date`, `transaction_date`, `auction_date`, `registered_at` 등 날짜 컬럼 확보

## 5. 현재 결론

- 현재 문서 기준으로 실행 가능한 미검증 실험은 남아 있지 않음
- H15와 H16은 실험 미진행이 아니라 데이터 조건 부족으로 인한 보류임
- 다음 실험을 진행하려면 먼저 아래 데이터가 필요함
- 운영 결측 사례
- 거래일 또는 등록일 컬럼
- 현재 모델 방향은 아래처럼 정리함
- Warm: H17 기준 작가 이력 피처 조합이 가장 강한 후보
- Cold: 기존 robust 선형 계열 유지
- 가격 범위: H18 기준 Warm 80% 보조 구간만 후속 후보
