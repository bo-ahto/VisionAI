## 0. 한 문단 요약

코덱스가 v2 산출물을 "엔지니어링 완성도는 인상적이나 학술적 엄밀성은 부족 — 중간평가 조건부 통과 가능"으로 평가했다. 치명적 P1 5건이 식별됐으며, 본 문서는 v3에서 이를 어떻게 보강할지 작업 단위로 분해하고 기존 Phase 1B/2A/2B/3A/3B 로드맵과 정렬한다. **v2는 현 상태로 중간평가에 진행하고 v3에서 점진 보강**한다는 결정에 따라, 즉시 가능한 분석 보강(Group 1)부터 모델 구조 변경(Group 3) + 운영·재현성(Group 4) + 데이터 클렌징 고도화(Group 5)까지 5개 Group으로 분해한다. 각 작업에는 acceptance gate, dependency, resource 가정을 명시하며, 1차 시장 모델의 시간축 부재 같은 평가 설계 한계도 정직하게 인정한다.

## 2. v3 보강 목표

본 v3 작업의 목표는 다음 3가지다.

1. **학술적 엄밀성 확보**: 통계 검정·CI·진단 분석·leave-one-X-out CV를 추가하여 심사위원 학술 기준을 통과
2. **모델 구조 정직화**: post-hoc bias·튜닝 leakage 위험을 nested CV·확장 search로 제거. cold path 채택 규칙을 정량 기준으로 명시화
3. **차별성 입증**: 선행 연구 benchmark, drift 진단 procedure 일반화로 학술 기여를 정량화

성공 시 v3는 **"중간평가 조건부 통과" → "최종평가 통과 + 논문화 가능"** 수준으로 격상.

### 2.1 1차 시장 모델의 평가 설계 한계 (정직 명시)

1차 시장 모델 데이터(Artsy + Saatchi 학습 28,376건)는 **시간축 정보가 부재**하다. 작품의 `year_made`(제작 연도)는 있으나 **거래 시점(listing/sale 시점)** 은 없으며, 데이터 수집 자체도 한 차례 크롤링으로 모인다. 따라서:

- **워크포워드 백테스트 불가**: 코드베이스에 `src/visionai/price_engine/validation/backtest.py`로 walk-forward 백테스트 인프라가 있으나, 이는 **경매 모델(회차/낙찰가 시계열)** 전용이며 1차 시장 모델에는 적용 불가
- **시간 기반 train/test split도 의미 약함**: `year_made` 기반 분할은 "신작 vs 구작" 일반화 평가에 불과 (시간 일반화 ≠ 신·구작 일반화)
- **대안 평가**: leave-one-gallery-out / leave-one-medium-out / leave-one-tier-out CV로 OOD 일반화 측정. 작가 단위 GroupKFold(현재 평가)는 OOD 개념이 약하므로 보강

이 한계는 v3 보고서에서 정직하게 기술하며, 후속 Phase에서 거래 시점(listing 일자) 메타데이터 수집을 검토한다 (Phase 2B 협력 영역).

## 3. 작업 분해 — 5개 Group

### Group 1: 분석·통계 보강 (대부분 재학습 불필요, 일부 재학습 필요)

> **예상 일정**: 10~14 실작업일 (1인 풀타임) + 보고서 반영 1~2일
> **인력 가정**: 모델 개발자 1인 풀타임
> **해소 P#**: #2 (CI/통계 검정/leave-one-X-out), #3 일부 (통계 검정), #4 일부 (learning curve, baseline)

| # | 작업 | 입력 | 산출물 | 재학습 | 해소 P# |
|---|---|---|---|:---:|---|
| 1.1 | **Bootstrap CI for MdAPE** — 1,000회 resample로 warm/cold 메트릭 95% CI | 기존 OOF 예측 결과 | 메트릭 표 + CI 컬럼 | × | P1 #2 (CI) |
| 1.2 | **v1 vs v2 paired statistical test** — Wilcoxon signed-rank, McNemar (W30 비율) | v1·v2 동일 sample 예측 | 통계적 유의성 표기된 비교 표 | × | P1 #2 (검정) |
| 1.3 | **출처 플립 통계 검정** — paired t-test, Wilcoxon, Cohen's d, 95% CI | source_flip_results_warm.json | 코호트별 검정 결과 | × | P1 #3 |
| 1.4 | **Baseline 비교** — global median / mean per (medium/source/tier) / **Random Forest baseline** 학습·평가 | 학습 데이터 | "모델 가치" 정량 표 | **○ (RF)** | P1 #4 |
| 1.5 | **Learning curve** — 학습 데이터 10/25/50/75/100% 비율로 **재학습 5회**, MdAPE 그래프 | 학습 데이터 + 학습 스크립트 | plateau 근거 그래프 | **○ (5회)** | P1 #4 |
| 1.6 | **Calibration plot** — 예측 분위수 vs 실제 분위수 reliability diagram (warm/cold) | OOF 예측 | reliability plot 2종 | × | P1 #2 |
| 1.7 | **Residual analysis** — 가격대별·재료별·갤러리별·source별 오차 분해 | OOF 예측 + 메타 | 진단 표 + 그림 6~8개 | × | P1 #2 |
| 1.8 | **Leave-one-gallery-out CV** — Artsy 갤러리 66개 중 K개 갤러리를 fold 단위로 holdout (실제 OOD 갤러리 시뮬레이션) | 학습 데이터 + gallery_name | gallery-OOD MdAPE 보고 | **○ (~10회)** | P1 #2 (OOD) |
| 1.9 | **Leave-one-medium-out CV** — `medium_category` (acrylic/oil/watercolor 등) 단위 holdout (재료 OOD 시뮬레이션) | 학습 데이터 + medium | medium-OOD MdAPE 보고 | **○ (5~7회)** | P1 #2 (OOD) |
| 1.10 | **시간축 부재 명시 + 데이터 수집 시점 cutoff 평가** (가능한 경우만) — `crawl_date` 필드가 일부 행에 있으면 cutoff 분할 시도. 불가 시 §2.1 한계 정직 기술 | 학습 데이터 메타 | 시도 결과 또는 한계 명시 문서 | 조건부 | P1 #2 (time, 정직 한계) |

**일정 재산정**: 1.1/1.2/1.3/1.6/1.7 = 분석만 (각 0.5~1일, 합 4~6일). 1.4/1.5/1.8/1.9 = 재학습 필요 (1.4 RF 1일, 1.5 학습 5회 약 2~3일, 1.8 약 3~4일, 1.9 약 2일). 1.10은 데이터 메타 확인 (반나절). **합계 10~14 실작업일**.

**산출물**: `model_test_results/v3_diagnostics/` 디렉토리 (JSON + PNG/SVG), 보고서 §6/§7 보강

## 6. 성공 기준 (Acceptance Gate — 산출물 + 정량 임계값)

각 v3 마일스톤의 acceptance gate는 **산출물 완비 + 정량 임계값 모두 충족**해야 통과로 간주. 임계값 미달 시 통과 보류.

각 임계값 항목은 두 종류로 분류된다:
- **HARD gate**: 미충족 시 통과 보류. 임계값을 만족해야 다음 단계 진행
- **SOFT gate**: 관찰·정직 보고 항목. 결과에 무관하게 통과 (해석은 별도 보고)

### v3.0 Acceptance Gate (Group 1 완료)

| 항목 | 산출물 | 종류 | 정량 임계값 |
|---|---|---|---|
| 1.1 Bootstrap CI | warm/cold MdAPE 95% CI 표 | SOFT | CI 너비 보고 (임계값 없음, 관찰만) |
| 1.2 v1 vs v2 paired test | 통계 검정 결과 | SOFT | Wilcoxon p-value 보고 + 95% CI 비겹침 여부 보고 (관찰만 — 통계적 유의성 결과를 그대로 정직 보고) |
| 1.3 출처 플립 통계 검정 | 코호트별 paired test + Cohen's d | SOFT | 검정 결과 보고 (임계값 없음, 관찰만) |
| 1.4 Baseline 비교 | RF + 카테고리별 mean baseline | **HARD** | v2 MdAPE이 Global median baseline 대비 ≥ 30%p 우수 (실측 71.9 → 38.3 = 33.6%p) |
| 1.5 Learning curve | 데이터 양 vs MdAPE 그래프 | SOFT | 50% → 100% 구간 개선 폭 보고. < 1.0%p면 plateau 시사, 이상이면 추가 개선 여지 시사 (해석은 별도) |
| 1.6 Calibration plot | reliability diagram 2종 | SOFT | 산출물 완비 |
| 1.7 Residual analysis | 진단 표 + 그림 | SOFT | 산출물 완비 |
| 1.8 Leave-one-gallery-out | gallery-OOD MdAPE | SOFT | OOD MdAPE 보고. 일반 cold MdAPE와 차이 보고 |
| 1.9 Leave-one-medium-out | medium-OOD MdAPE | SOFT | 동일 |
| 1.10 시간축 평가 시도 | 결과 또는 한계 문서 | SOFT | 산출물 완비 (정직성 평가) |

**v3.0 통과 기준**: HARD gate (1.4) 임계값 충족 + 모든 SOFT gate 산출물 완비 + 보고서 §6/§7 갱신. SOFT gate의 결과는 해석을 별도 보고하나 통과 자체에 영향 없음.

### v3.1 Acceptance Gate (Group 2 완료)

| 항목 | 산출물 | 종류 | 정량 임계값 |
|---|---|---|---|
| 2.1 출처 플립 n=90+ | warm/cold 분리, 검정 + 95% CI | **HARD** | warm 코호트 평균 |delta|% 95% CI 상한 < 2.0% |
| 2.2 Cold path 채택 결정 | 사전 규칙 적용 결과 | **HARD** | CB 유지 / XGB 전환 / ensemble 채택 셋 중 명시 + 근거 표 (결정 산출 자체가 통과 조건) |
| 2.3 Drift ablation | 5개 피처 단독 영향 표 + procedure 초안 | SOFT | 산출물 완비 |
| 2.4 Quantile / conformal coverage | coverage + sharpness 비교 | **HARD** | coverage 80% ± 5% 달성 + median width가 등급별 단일 m 대비 동등 이하 |

**v3.1 통과 기준**: HARD gate 3건 (2.1, 2.2, 2.4) 모두 충족 + 모든 산출물 완비.

### v3.2 Acceptance Gate (Group 3 완료)

| 항목 | 산출물 | 종류 | 정량 임계값 |
|---|---|---|---|
| 3.1 Nested CV MdAPE | outer-fold MdAPE + 95% CI | **HARD** | v2 대비 악화 폭 < 2.0%p 또는 v2 CI와 겹침 (둘 중 하나) |
| 3.2 Optuna 100+ 확장 | 새 best_params + 정확도 | **HARD** | 채택 결정 산출 (변동 < 0.5%p ⇒ v2 유지 / ≥ 0.5%p 개선 ⇒ production 갱신) |
| 3.3 Cell key 재설계 | 대안 셀 비교 표 | **HARD** | 최우수 cell 채택 결정 (cold MdAPE 차이 ≥ 0.3%p이면 변경) |
| 3.4 Source ablation | source 제거 시 cold MdAPE 변동 | **HARD** | 채택 결정 산출 (변동 < 1.0%p ⇒ source 제거 / ≥ 1.0%p ⇒ source 유지 + 잔존 편향 별도 보고) |

**v3.2 통과 기준**: HARD gate 4건 모두 충족 + 새 production artifact 5종 산출.

> **Dependency note**: cold MdAPE의 "v3.2에서 35~37%"는 §5에 명시한 대로 **Phase 2B 데이터 강화 완료 가정 시 도달 가능 추정치**이며, Group 3 단독으로는 도달 어려움. v3.2 acceptance gate에서는 정량 임계값으로 사용하지 않음.

### v3 Final Acceptance Gate (Group 4 완료)

| 항목 | 산출물 | 종류 | 정량 임계값 |
|---|---|---|---|
| 4.1 Production A/B | v2 vs v3 user-facing 메트릭 | **HARD** | A/B 평균 MdAPE 차이 < 1.0%p (v2 호환) 또는 영향 분석 보고서 산출 |
| 4.2 선행 연구 benchmark | 5~10편 literature 비교 표 | **HARD** | 비교 대상 5편 중 ≥ 3편보다 우수하거나 동등 (정량 입증) |
| 4.3 Drift procedure | 다른 도메인 적용 사례 1건 | SOFT | 산출물 완비 |
| 4.4 재현성 패키지 | Docker + sample + README | SOFT | 외부 1건 재현 시도 결과 보고 (성공 또는 실패 원인) |

| Risk | 영향 | 대응 |
|---|---|---|

| **외부·운영 risk** | | |
| 콜론30 갤러리 티어 검수 지연 | Phase 1B 일정 지연 | Group 1 전체, 2.2/2.3, 4.2는 콜론30 의존 없이 진행 |
| **외부·비공개 갤러리 정보 확보 실패** | Phase 2B 데이터 강화 불가 → cold 30%대 목표 미달 | "현 데이터 제약 하에서 모델 측 한계"로 메시지 전환 + cold 36~37%대로 목표 하향 |
