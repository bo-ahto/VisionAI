1. 모델 아키텍처

1.1 Two-path Routing

┌─────────────────────┐ │ predict 요청 │ └──────────┬──────────┘ │ ┌────────────┴────────────┐ │ artist_slug ∈ warm_set? │ │ (artist 작품수 ≥ 5) │ └────┬─────────────────┬──┘ │ Yes (warm) │ No (cold) ▼ ▼ ┌───────────┐ ┌───────────┐ │ XGBoost │ │ CatBoost │ │ (warm) │ │ (cold) │ └─────┬─────┘ └─────┬─────┘ │ │ │ per-source calibration │ (cold_factors 적용) ▼ ▼ ┌─────────────────────────────┐ │ ln_price → exp → KRW │ └─────────────────────────────┘
핵심: ensemble blend (CB+XGB)/2가 아님. 운영 routing은 artist의 warm 여부에 따라 단일 모델 호출. warm artist는 XGB만 / cold artist는 CB만 사용.
(CB+XGB ensemble은 학습 시 CV evaluation에만 등장 / 운영 inference X — primary_predictor.py:464-497)

매칭 단계 (primary_predictor.py):

4.3 Cold path scale 차이 해석

왜 cold MdAPE가 warm보다 4배 높은가:
- Cold = 신규 작가 / 작품수 <5 / 작가 정보 부족 / 가격 분산 큼 (heavy-tailed)
- Warm = 기존 작가 / 작품수 ≥5 / 같은 작가 다른 작품 / 가격 분포 학습됨
→ structural difference이지 모델 성능 차이 X. 비즈니스 측면 cold price 추정은 본질적으로 어려움 (artist 자체가 신호인데 작가 정보 sparse).

5. Per-source Calibration (e3367ed Phase 2 shipped)

5.1 적용 방식

cell = (source, target_market) / 운영 적용:

  1. 모델 prediction 산출 (CB or XGB)
  2. 해당 작품의 cell 결정: is_krw==1 → 'gallery' / else 'online'
  3. cold_factors[cell] 곱하기 (cold path만 적용 / warm은 미적용)
  4. price_krw = exp(ln_price * factor)
