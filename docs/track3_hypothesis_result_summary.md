## 1. 보는 방법

- `관련 실험`
- 이 가설을 직접 또는 간접으로 검증한 실행 실험
- `사용 변수`
- 해당 가설 검증에서 핵심이 된 변수 축
- `Warm / Cold 결과 요약`
- 핵심 지표 또는 방향성
- `핵심 결과`
- 현재 결론을 만드는 데 가장 중요했던 수치 또는 비교 결과
- `현재 결론`
- 지금 시점에서 이 가설을 어떻게 해석하는지
- `남은 액션`
- 아직 더 확인할 가치가 있는 후속 실험
