## 2. 피처 매핑: 보유 ✅ vs 부족 ❌

### 2.1 작가(Artist) 피처

| 리서치 피처 | 보유 여부 | 매핑 가능 필드 | 비고 |
|------------|----------|---------------|------|
| 작가 정체성(ID) | ✅ 있음 | 작가명 | 고유 ID로 인코딩 필요 |
| 작가 명성(Reputation) | ⚠️ 간접 | 낙찰 횟수, 총 낙찰액, 최고 낙찰가, 평균 낙찰가 | 작가 통계 DB에서 파생 가능 |
| 생존 여부 | ❌ 없음 | - | 외부 데이터 보강 필요 |
| 작가 나이/제작 시점 나이 | ❌ 없음 | - | 생몰년 데이터 필요 |
| 과거 경매 이력 | ✅ 있음 | 작가별 낙찰 횟수, 평균가 | 작가 통계에서 직접 활용 |
| 경력 단계 | ❌ 없음 | - | 생몰년 + 제작연도로 계산 가능 |

### 2.2 작품(Artwork) 물리적 특성

| 리서치 피처 | 보유 여부 | 매핑 가능 필드 | 비고 |
|------------|----------|---------------|------|
| 크기(Dimensions) | ✅ 있음 | 크기 (예: 81×116cm, 高48) | 파싱 필요 — 높이/너비/면적으로 분리 |
| 매체/재료(Medium) | ✅ 있음 | 재질/재료 (예: 캔버스에 유채, Bronze 등) | 텍스트 정규화 및 카테고리화 필요 |
| 지지체(Support) | ⚠️ 부분 | 재료 필드에 혼합 포함 | 재료에서 분리 추출 가능 (캔버스, 종이보드 등) |
| 장르/주제(Genre) | ❌ 없음 | - | 이미지 분류 또는 제목 기반 추출 가능 |
| 서명 여부 | ❌ 없음 | - | 경매 카탈로그에서 추출 가능 |
| 제작 연도 | ❌ 직접 없음 | 제목에 일부 포함 (예: "22-X-73 #325") | 별도 필드로 수집 필요 |
| 제목 | ✅ 있음 | 작품명/제목(한/영) | Untitled 여부 등 파생 피처 생성 가능 |

### 2.3 출처/이력(Provenance) 피처

| 리서치 피처 | 보유 여부 | 매핑 가능 필드 | 비고 |
|------------|----------|---------------|------|
| 소장 이력 | ❌ 없음 | - | 경매 카탈로그 크롤링으로 보강 가능 |
| 전시 이력 | ❌ 없음 | - | 장기적으로 수집 필요 |
| 문헌 수록 | ❌ 없음 | - | 장기적으로 수집 필요 |
| 인증/감정서 | ❌ 없음 | - | 경매 카탈로그에서 일부 추출 가능 |

### 2.4 거래/시장(Transaction) 피처

| 리서치 피처 | 보유 여부 | 매핑 가능 필드 | 비고 |
|------------|----------|---------------|------|
| 경매소 | ✅ 있음 | 소스 (offline_artwork 등), 타입(메이저) | 경매소명으로 매핑 필요 |
| 경매 일시 | ✅ 있음 | 일자 | 시즌, 월, 요일 등 파생 피처 생성 |
| 경매 위치 | ❌ 직접 없음 | - | 경매소 정보에서 추론 가능 |
| 출품 순서(LOT) | ✅ 있음 | LOT 번호 | 직접 활용 가능 |
| 추정가(Estimate) | ✅ 있음 | 추정가(최저), 추정가(최고) | ★ 가장 강력한 피처 — 보유 확인 |
| 낙찰가(Target) | ✅ 있음 | 낙찰가 | 예측 타겟 변수 |
| 입찰 수 | ✅ 있음 | 입찰수 | 사전 예측에는 못 쓰지만 분석용으로 유용 |
| 낙찰률 | ✅ 있음 | 낙찰률 | 경매 회차 수준 피처 |
| 거시경제 지표 | ❌ 없음 | - | 공개 API로 보강 가능 (한국은행, S&P500 등) |

### 2.5 비전(Visual) 피처

| 리서치 피처 | 보유 여부 | 매핑 가능 필드 | 비고 |
|------------|----------|---------------|------|
| 작품 이미지 | ⚠️ 부분 | 이미지 (일부 작품) | VisionAI 인수 범위에서 이미지 임베딩 활용 예정 |

## 3. 종합 평가: 충분한가?

### 3.1 결론: ✅ 현재 데이터만으로 베이스라인 모델 구현 가능

현재 보유 데이터에서 **가장 강력한 예측 피처 3가지를 모두 확보**하고 있다:

1. **추정가(Estimate Low/High)** — 논문에서 가장 강력한 단일 피처로 보고됨
2. **작가 정체성 + 과거 경매 통계** — 예측력의 핵심
3. **작품 물리적 특성(크기, 재료)** — 헤도닉 모델의 기본 변수

### 3.2 현재 데이터로 즉시 구성 가능한 피처 목록 (Phase 1)

```
즉시 사용 가능한 피처 (정규화/파싱 후):
─────────────────────────────────────
[타겟]  ln(낙찰가)

[작가 피처]
  - artist_id              ← 작가명 인코딩
  - artist_total_sales     ← 작가 통계: 낙찰 횟수
  - artist_total_amount    ← 작가 통계: 총 낙찰액
  - artist_max_price       ← 작가 통계: 최고 낙찰가
  - artist_avg_price       ← 작가 통계: 평균 낙찰가

[작품 피처]
  - height_cm              ← 크기 파싱
  - width_cm               ← 크기 파싱
  - surface_area           ← height × width
  - medium_category        ← 재질 → 카테고리 (유화/아크릴/판화/조각 등)
  - support_category       ← 재질 → 지지체 분리 (캔버스/종이/패널 등)
  - is_untitled            ← 제목이 "Untitled"인지 여부
  - title_length           ← 제목 길이 (구체성 proxy)

[거래 피처]
  - estimate_low           ← 추정가(최저)
  - estimate_high          ← 추정가(최고)
  - estimate_mid           ← (최저 + 최고) / 2
  - estimate_range         ← 최고 - 최저 (불확실성 proxy)
  - auction_house          ← 소스/경매소
  - auction_type           ← 타입 (메이저/온라인)
  - lot_number             ← LOT 번호
  - sale_month             ← 일자 → 월
  - sale_year              ← 일자 → 연도
  - sale_season            ← 봄(3-5)/가을(9-11)/기타
  - auction_sell_rate      ← 해당 경매 회차 낙찰률
  - auction_total_lots     ← 해당 경매 총 LOT 수
```

### 3.3 파생 피처 (Phase 2에서 추가)

```
작가 경력 파생 피처:
  - artist_price_trend     ← 최근 N건 낙찰가 추세 (상승/하락)
  - artist_price_volatility← 낙찰가 표준편차
  - artist_days_since_last ← 마지막 경매로부터 경과 일수
  - artist_auction_frequency ← 연간 출품 빈도

시장 컨텍스트 파생 피처:
  - market_heat_index      ← 동일 시기 전체 낙찰률
  - same_artist_recent_ratio ← 최근 추정가 대비 낙찰가 비율

크기 관련 파생 피처:
  - size_category          ← 소형/중형/대형 구간화
  - is_standard_size       ← 표준 캔버스 규격 여부 (F/P/M호)
```

## 4. 데이터 갭 및 보강 우선순위

| 우선순위 | 부족 피처 | 보강 방법 | 난이도 | 예측력 기여도 |
|---------|-----------|-----------|--------|-------------|
| 🔴 높음 | **제작 연도** | 경매 카탈로그 크롤링 또는 DB 필드 추가 | 중 | ★★★★ |
| 🔴 높음 | **작가 생몰년/국적** | 공개 DB (한국미술정보센터, Artnet 등) 매핑 | 중 | ★★★★ |
| 🟡 중간 | **장르/주제** | Vision AI 이미지 분류 또는 제목 NLP | 중 | ★★★ |
| 🟡 중간 | **거시경제 지표** | 한국은행 API, KOSPI 데이터 | 하 | ★★★ |
| 🟢 낮음 | **출처(Provenance)** | 경매 카탈로그 상세 크롤링 | 상 | ★★★★★ (장기) |
| 🟢 낮음 | **전시/문헌 이력** | 미술관/갤러리 DB 연동 | 상 | ★★★★ (장기) |

## 5. 실행 로드맵 제안

### Phase 1: 베이스라인 (현재 데이터로 즉시 시작)

```
기간: 2026-03-02 ~ 2026-03-13 (로드맵의 베이스라인 기간)
목표 MAPE: < 40%

작업:
1. 크기 필드 파싱 (정규식으로 높이/너비 추출)
2. 재질 → 매체 카테고리 + 지지체 카테고리 분리
3. 작가 통계 조인 (평균가, 낙찰 횟수 등)
4. 추정가 기반 파생 피처 생성
5. CatBoost baseline 학습 (log price 타겟)
6. MAPE 기준선 확보
```

### Phase 2: 피처 고도화 (데이터 보강 + 파생 피처)

```
기간: 2026-03-09 ~ 2026-04-10
목표 MAPE: < 30%

작업:
1. 제작 연도, 작가 생몰년 데이터 보강
2. 작가 경력 파생 피처 추가
3. 시장 컨텍스트 피처 추가
4. 시계열 split 적용 (미래 누수 방지)
5. CatBoost + LightGBM + XGBoost 앙상블
```

### Phase 3: 멀티모달 (Vision AI 연동)

```
기간: 로드맵 후반기
목표 MAPE: < 25%

작업:
1. 이미지 임베딩 피처 통합
2. 장르 자동 분류 피처 추가
3. 최종 모델 확정 및 API 구축
```
