2. 검증 protocol — 2단계 paired

모든 F1-F5 실험은 동일 protocol 따름:

1. mini hold-out (5 seeds 또는 frozen benchmark) → 후보 선별
2. 후보 발견 시 고정 평가 데이터 test 1회 paired confirm
3. 동일 row 위에서 V0 vs 후보 paired 비교
4. 판정: median Δ + WinRate + 큰 오차 위험 (p95/p99/max/10x errors) 동시 통과
후속 검토 핵심: heavy-tail cold APE 환경에서 mean / Cohen's d는 outlier 1건에 좌우됨. median Δ + WR + 작품 단위 tail percentile 중심으로 판단해야 false positive 차단.

검증 protocol 가치: F2 (medium_support_combo)와 F5-B (KNN blend) 두 번 mini 신호 → 고정 평가 데이터 반전. 2단계 protocol이 false positive를 정확히 차단.

11. 종합 진단 — v1.2가 강한 plateau

사전 진단 (F3 후 시점, F4/F5/F6 결과로 다시 확인):
"현재 가설 공간 안에서는 이미 강한 plateau에 올라와 있다. 근접 변형으론 이득이 안 나고, 나와도 고정 평가 데이터에서 뒤집히거나 Warm tail에서 비용을 치르는 상태."

왜 plateau인가

  1. 모든 단순 변형 reject: 크기 redundancy / 새 파생 / 모델 가족 / 라우팅 변경 / KNN 후처리 모두
  2. v1.2 비교 기준 자체가 이미 dataset 정제 + leakage 방지 + feature ablation 거친 결과 (PR1-PR16e)
  3. 알고리즘이 아니라 데이터 커버리지가 병목 — 진단 결과처럼 시간 split / 추가 작가 / source 안정화가 다음 ROI

검증 protocol 가치 입증

  • F2 (medium_support_combo): mini 4/5 seeds 일관 → 고정 평가 데이터 반전
  • F5-B (KNN blend): frozen benchmark 신호 → 고정 평가 데이터 반전
  • 둘 다 2단계 confirm protocol이 false positive를 정확히 차단
  • 이 protocol 가치는 향후 어떤 Track 실험에도 적용 가능
