4. Cycle 2 — Reprod cycle d0f8b88

목표: e3367ed의 cell factor가 cross-fit OOF에 들어가지 않은 fresh 20% holdout에서 baseline 대비 개선되는지 확인.

4.1 Method 핵심

  • Holdout split: cold = GroupShuffleSplit(0.20, seed=31337, groups=artist_slug) / warm = train_test_split(0.20, seed=31337, shuffle)
  • Refit: 80% pool 위에서 e3367ed 동일 절차로 cross-fit OOF + per-cell guard → refit factor
  • Holdout 평가 (Dual-track): PR1 artifact 그대로 holdout prediction × original (e3367ed) factor → primary endpoint / refit factor → secondary
  • Paired bootstrap (small cell n_holdout < 500): 1000-iter / 90% CI
  • 핵심 가정 (R1 합의): PR1 artifact 재학습 X (artifact variance를 confound 시키지 않기 위함)

4.3 Verdict + R4 caveat

per prereg §3.3: 전 load_bearing FAIL → 채택 보류.
R4 사후 검수 verdict (LGTM-with-caveat / View B):
  • Implementation prereg-faithful / 결정 logic 정합.
  • BUT 본 cycle = "deployment value의 clean test가 아님". holdout prediction = artifact 기준 in-sample (PR1이 holdout 행 학습 시 본 데이터). In-sample baseline (3.21/7.17) << OOF baseline (~33) → OOF로 학습된 factor가 in-sample에 over-correction → FAIL이 구조적으로 강제됨.
  • FAIL = "이 cycle 한정 운영 binding"이지 "calibration deployment value 없음" 강한 증거 X.
  • 후속 cycle 권고: retrained-artifact + multi-seed (= OOS cycle).

6. Reprod vs OOS 비교 (R4 caveat 해소 입증)

같은 seed=31337 / 같은 split / 다른 evaluation method:

Overall verdict FAIL (채택 보류) NEEDS_MORE_DATA —
해석: 두 sample이 완전히 동일 (seed=31337의 holdout indices가 두 cycle 사이 같은 artist set). 차이는 holdout prediction 방법뿐:
  • Reprod cycle: PR1 artifact (full data 학습 / holdout 행 포함) → in-sample 예측 → baseline MdAPE 매우 낮음 → OOF로 학습된 factor가 in-sample에 over-correction → 거의 항상 FAIL.
  • OOS cycle: 80% pool 재학습 artifact (holdout 행 미학습) → true OOS 예측 → baseline MdAPE 정상 OOF 수준 → factor가 baseline 대비 개선 효과 발현.
→ R4 in-sample bias 가설 강하게 지지. Reprod FAIL은 method artifact였음.
