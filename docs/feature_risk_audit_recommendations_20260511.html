5. ⚠️ Layer 0: Target/Source bias audit (Update: 2026-05-11)

핵심 발견 (user 지적): 기존 risk 분석은 feature contamination만 다룸. 그런데 더 본질적인 차원이 빠져 있음 —

target 자체 (y=price)가 source별로 체계적으로 다르다면, feature audit는 잘못된 y에 fit하는 feature를 평가하는 셈. 즉 Layer 0 = target/source bias가 모든 feature audit보다 먼저 와야 함.

5.2. 현 model의 source bias 처리 상태

  • source (#32 categorical) → feature로 들어감 → model이 source=price level proxy로 직접 학습
  • source_conditional_v1 variant 시도 (D1.SC cycle) → FAIL (각 source 별 sample 부족 + warm/cold imbalance)
  • source_router_mode (off/shadow/canary/on) infra는 있지만 source-conditional model이 fail해서 활용 불가
  • 결과: 현재는 source bias가 model에 직접 새겨져 있고, 분리 메커니즘 없음

5.3.1. T1 threshold 가이드 (codex)

"median ratio 하나로 확정하지 말고 effect size + stability 같이 본다"
  • 중심값: within-artist median log(price_artsy / price_saatchi)
  • Dispersion: artist별 ratio IQR 또는 25-75% band
Ratio range해석Action
1.0-1.2x미미현 학습 유지
1.2-1.5x경계composition control (T2/T4) 후 재평가
1.5-2.0x유의한 source effectcohort 분리 또는 target normalization 검토
2.0x+강한 bias 의심즉시 대응 — global model 사용 위험
3-5x+(확정 아닌) 심각한 mixing 상태그 전에 이미 대응했어야 함

median + IQR 둘 다 안정적으로 벌어져 있을 때 source bias로 판정. median만 큰데 IQR도 크면 sampling noise일 수 있음.

5.4. 본 세션 결과 재해석 (Codex 동의)

Codex: "B winner = saatchi warm 단일 cohort retune이라면, 성능 개선 일부가 모델 개선이라기보다 source/target heterogeneity 제거 효과일 가능성이 높다.

한 줄 요약: B는 운영상 쓸 수는 있지만, 조직적으로는 '모델이 좋아졌다'보다 '혼합 target을 덜 맞췄다'에 더 가까울 수 있다."
  • 18 cycle 중 17 FAIL → 일부는 source bias가 underlying target heterogeneity로 발현된 결과
  • Cold path FAIL이 많은 이유 → cold split이 source-conditional하게 갈리는 경우 target distribution이 mixed
  • B winner 성공의 본질 → 단일 cohort (saatchi warm) 내 retune → source bias가 자연스럽게 통제된 결과
  • B를 "global winner"가 아닌 "cohort-local winner"로 라벨링해야 함 (codex 권고)

5.5. 운영 / future cycle 영향 (Codex 권고)

  • 현재 Stage 3-5에서 B가 동일 cohort(saatchi warm)에만 적용되면 즉시 위험은 낮음 → 배포 계획 변경 불요
  • 다만 B를 "일반적 개선"으로 해석하면 안 됨
  • Future cycle부터 global winner와 cohort-local winner 분리 평가 필수
  • "source-cohort locked eval"을 기본 리포트에 추가 권고
  • Warm 성공을 전체 Track1 성공 신호로 사용하지 말고 "heterogeneity-controlled local success"로 라벨링

8. 운영 측면 시사 (B winner deploy 결정)

본 세션 B winner (warm path retune)는 32 features 그대로 사용:
  • 위 risk 검토 결과가 B winner 효과에는 영향 X — 동일 feature set에서 retune 효과만 측정
  • B는 cycle별 std=0.137 (warm path / population-level robust)
  • Cold path는 위 risky features (artist_total_works / career_stage 등) 가 cold split variance 본질에 기여 가능성 있음 (D1 cycles fail 정합)

운영 Stage 3 활성화 (B deploy)는 정합. Feature reform 작업은 별도 axis / 향후 cycle.
