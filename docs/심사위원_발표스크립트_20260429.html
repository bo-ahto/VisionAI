1. 여는 말 — 연구 배경과 목적3분

📌 발표자 노트

인사 후 곧바로 "이 연구가 왜 필요한지"를 명확히 합니다. 한국 미술 시장의 정보 비대칭 문제 → 본 연구가 그 해결책 → 정량 목표(MdAPE 8% 이내) 순으로.

1.1 연구 배경 — 한국 미술 시장의 정보 비대칭

한국 미술 시장에서 작품 가격은 작가 인지도, 작품 크기, 재료, 갤러리 판매처, 제작 연도 등 다수 요인이 복합적으로 결정합니다. 그러나 시장 호가는 일반에 공개되지 않거나 거래마다 큰 분산을 보이며, 신진 작가의 적정 가격 산정 자체가 어렵다는 구조적 문제가 있습니다.

이는 갤러리·작가·구매자 사이 정보 비대칭을 야기하며, 미술 시장의 투명성과 거래 활성화를 저해합니다.

1.2 연구 목적

본 연구는 이러한 정보 비대칭을 줄이기 위해 작품 정보 입력만으로 1차 시장 가격을 추정하는 기계학습 모델을 구축합니다. 4가지 정량 목표를 설정하였습니다.

  1. 한국 작가의 1차 시장 작품을 오차 중앙값(MdAPE) 8% 이내로 예측 (warm Artsy slice 기준)
  2. 학습량 부족 작가(cold-start)의 정확도를 40% 이내로 안정화 + 보정 메커니즘
  3. 예측 신뢰도를 등급별로 분류(A/B/C/D)하여 사용자가 결과를 적절히 활용할 수 있도록 함
  4. 학습 데이터 출처(Artsy/Saatchi) 편향을 정량 분석·통제
💡 현재 달성도 (한 줄)

warm Artsy 8.3% (목표 도달), warm 전체 9.7%, cold 전체 38.3%. 등급별 신뢰도 시스템 production 적용 완료. 출처 편향은 셀별 보정으로 통제하고 통제 실험으로 정량 검증 (warm 30명 ±1.5% 이내).

4. 핵심 수식 — 학습 목표·라우팅·보정·등급5분

📌 발표자 노트

심사위원이 학술적 검증을 할 수 있도록 수식 명시가 핵심. 4가지 핵심 수식을 차근차근. 가능하면 화이트보드에 함께 적으면서 설명.

4.1 학습 목표

가격은 right-skewed (대수정규) 분포이므로 자연로그 변환 후 회귀합니다.

학습 Loss — squared-error on log-price (MSE)
$$ \mathcal{L} = \frac{1}{N}\sum_{i=1}^{N}\left( \ln(P_{i, \text{actual}}) - \hat{f}(\mathbf{x}_i) \right)^2 $$

4.2 모델 라우팅

라우팅 함수
$$ \text{model}(\mathbf{x}) = \begin{cases} \text{XGBoost} & \text{if } s(\mathbf{x}) \in \mathcal{W} \\ \text{CatBoost} & \text{otherwise} \end{cases} $$

$s(\mathbf{x})$: 작가 식별자 (artist_slug) · $\mathcal{W}$: warm artist set (≥5건, 930명, JSON으로 동결)

4.3 GBDT 예측

두 모델 모두 K개의 회귀 트리 ensemble로 표현됩니다.

$$ \hat{f}(\mathbf{x}) = \sum_{k=1}^{K} \eta \cdot t_k(\mathbf{x}) $$

$t_k(\mathbf{x})$: $k$번째 회귀 트리 출력 · $\eta$: learning rate (CatBoost 0.0953, XGBoost 0.0401) · $K$: 트리 수 (CatBoost 1,000, XGBoost 3,000, Optuna 튜닝)

4.4 후처리 — 셀 보정 (cold path)

cold 영역에 학습 데이터 출처별 분포 편향을 후처리로 보정합니다.

셀 정의 및 factor 산출
$$ \text{cell}(\mathbf{x}) = (\text{source}(\mathbf{x}), \text{target\_market}(\mathbf{x})) $$ $$ \text{factor}[c] = \text{median}_{i \in c}\left( \frac{P_{i, \text{actual}}}{\hat{P}_{i, \text{predicted}}} \right) $$

factor < 1 ⇒ 모델 과대예측 → 곱셈 깎음 (현재 artsy_online 0.9426, saatchi_online 0.9569).
target_market 도출: 학습/오프라인 평가는 is_krw로 도출, 서빙은 caller가 직접 전달 (predictor는 받은 값을 셀 키 산출에만 사용).

4.5 후처리 — 신뢰도 등급·마진

등급 함수와 가격 범위
$$ G(\mathbf{x}) = \begin{cases} A & \text{if matched} \land s(\mathbf{x}) \in \mathcal{W} \\ B & \text{if matched} \land s(\mathbf{x}) \notin \mathcal{W} \land n_{\text{train}} \geq 1 \\ C & \text{if has\_birth\_year} \lor \text{has\_manual\_profile} \\ D & \text{otherwise} \end{cases} $$ $$ P_{\text{low}} = \hat{P}(1 - m_G), \quad P_{\text{high}} = \hat{P}(1 + m_G) $$

$m_G$: 등급별 마진 (production-time 80% coverage 산출). $m_A=0.286$, $m_B=0.609$, $m_C=0.896$, $m_D=0.827$

6. 평가 방법 — 교차검증과 지표3분

📌 발표자 노트

학술적 정당성 확보용 섹션. 두 가지 CV 방식과 두 가지 지표를 짧게 정의.

6.1 교차 검증

방식분할 단위평가 시나리오적용 영역

6.2 평가 지표

MdAPE (Median Absolute Percentage Error)
$$ \text{MdAPE} = \text{median}_i\left( \frac{|P_{i, \text{actual}} - \hat{P}_i|}{P_{i, \text{actual}}} \right) \times 100 $$

오차 비율의 중앙값. right-skewed 분포에서 평균(MAPE) 대비 robust.

W30 (Within 30% Error Rate)
$$ W_{30} = \frac{1}{N}\sum_{i=1}^{N}\mathbb{1}\left[\frac{|P_{i, \text{actual}} - \hat{P}_i|}{P_{i, \text{actual}}} \leq 0.3\right] \times 100 $$

예측이 실제값의 ±30% 안에 들어간 비율.

한국 미술 시장 가격 분포의 right-skewed 특성을 고려해 평균보다 중앙값 지표를 우선 채택했습니다.

8. 연구 과정에서 발견한 핵심 인사이트5분

📌 발표자 노트

이 섹션이 학술적 기여 부분. 3가지 인사이트를 명확히 분리해 설명. 각각이 별도 학술 가치가 있음을 강조.

8.1 인사이트 1 — Train/Serve Drift가 정확도보다 큰 병목

v1 분석 시 발견한 5개 drift 피처(career_age 등)를 제거하니 cold MdAPE가 40.6 → 39.4로 오히려 개선됨을 정량 입증. 학습 시 신호가 서빙에서 silent noise로 변질되는 현상이 production에서 침묵으로 작동함을 발견하고 진단·제거 방법론을 제시했습니다.

8.2 인사이트 2 — 출처별 편향과 셀 단위 보정

v1의 단일 상수 보정 ($c = -0.075$)이 두 출처에 동일 적용되는 한계를 분석하고, (source × target_market) 셀별 multiplicative factor로 교체. 5-fold cross-fit (per-fold factor 재추정): 각 held-out fold에 대해 다른 4개 fold로 모델·factor를 모두 재추정 → self-reference leakage 차단. per-cell guard: 보정이 OOF MdAPE를 악화시키는 셀은 자동 ×1.0 fallback (실제 artsy_gallery 셀이 가드로 skip). 결과: cold path MdAPE 39.4 → 38.3 (−1.1%p) 개선.

8.3 인사이트 3 — 출처 라벨 효과의 통제 실험

모델이 출처 라벨에 얼마나 의존하는지 측정하기 위해 n=30 통제 실험을 설계했습니다. 동일 작품의 모든 입력을 그대로 두고 source 라벨만 플립하여 두 번 예측한 후 차이를 측정.

warm 작가 30명 모두 변화율 ±1.5% 이내, 80%(24명)가 ±0.5% 이내. 학습량 충분 작가에게는 출처 라벨 효과가 사실상 없음을 정량 입증. cold 작가에 대한 별도 보조 실험에서는 일부 사례에서 −8 ~ −17% 차이가 관찰되며, 이는 categorical embedding 자체의 학습 분포 편향임을 분석 (model_test_results/source_flip_results.json, warm-only=False).

8.4 인사이트 4 — Cold-start의 plateau

Cold MdAPE 38.3%는 현재 데이터 제약 하에서 모델 구조 변경만으로는 더 줄이기 어려운 plateau에 가깝다고 분석됩니다. 근거:

  • 생년 결측 72%
  • 고가 작품 1,678건(5.7%)이 분포 꼬리
  • 외부 정보 수집 정확도 한계

해결책은 모델 구조 변경이 아닌 데이터 측 강화에 의존함을 정량 분석. §9 후속 계획에서 구체화.

📌 발표자 노트

심사위원이 던질 가능성이 높은 질문들. 발표하지 않아도 되고, 질문 시 참조하세요.

Q. Warm 작가 5건 임계값의 학술적 근거는?
학습 데이터 작가별 작품 수 분포 분석 결과 5건이 안정성 변곡점이었습니다. 4건 이하는 분산 추정 신뢰도가 낮고, 5건 이상은 작가별 평균·분산이 안정화됩니다. warm_artist_slugs.json의 min_count 필드에 명시되며 학습/서빙 모두 동일 set 사용으로 정합 보장.
Q. CatBoost와 XGBoost를 ensemble 하지 않고 분리 라우팅하는 이유는?
두 모델의 강점이 영역별로 명확히 다르기 때문입니다. warm에선 XGB가 2.2%p 우수(9.7% vs 11.9%), cold에선 CatBoost가 ordered target stats로 안정. ensemble 실험은 PR #20 이전 v6에서 시도했으나 stacking 효과가 없었고, 분리 라우팅이 단순성·해석가능성·서빙 성능 면에서 우수했습니다.
Q. MdAPE 외에 RMSLE, R² 등도 보고하나?
학습 Loss는 log-price 공간의 squared-error (MSE). 이는 원본 가격 공간으로 변환하면 RMSLE(Root Mean Squared Log Error)에 해당하며, 학습 단계에서 자동으로 함께 보고됩니다. R²는 가격 분포 right-skewness 때문에 미술품 도메인에서 해석이 까다로워 보조 지표로만 참조합니다. 메인 보고 지표는 MdAPE + W30 (실용 해석성).
Q. Cold-start 38% 오차가 너무 큰데 사용성에 문제 없나?
cold 영역은 모델이 신뢰도 등급 C/D로 분류해 사용자에게 가격 범위(±50~70%)를 함께 제시합니다. 즉 사용자는 "이 추정은 불확실하다"는 정보를 함께 받으며, 추가 검증이 필요한 케이스로 분류합니다. 또한 §9 후속 계획의 Phase 2B에서 데이터 측 강화로 30%대까지 개선 계획.
Q. 출처(Artsy/Saatchi) 라벨이 결과를 흔든다는 건 모델 편향 아닌가?
통제 실험으로 정량 측정한 결과 warm 작가에서는 ±1.5% 이내(80%가 ±0.5% 이내)로 사실상 영향 없음을 확인. cold 작가에서만 −8 ~ −17% 영향이 나타나며 이는 학습 데이터의 출처별 가격 분포 차이를 모델이 학습한 결과입니다. 셀별 보정으로 분포 차이 평균은 잡았으나 categorical embedding 잔존 편향은 남아있어 source ablation 실험을 후속 Phase에서 검토 중.
Q. 학습 데이터 28,376건이 충분한가?
한국 미술 1차 시장의 비공개 거래 특성상 이 규모가 현실적 한계에 가깝습니다. warm 영역은 충분(95.4% 작품, 27,062건)하나 cold 영역은 본질적 한계가 있습니다. 후속 Phase 2B에서 한국 갤러리 사이트 추가 크롤링 + 외부 작가 정보 수집 정확도 향상으로 보강 예정.
Q. 모델 산출물의 production 안전성 보장은?
5종 artifact(model + label_maps + warm_artists + calibration)가 모두 fail-closed로 로딩됩니다. 1개라도 누락·schema 불일치 시 서버 시작 시점에 RuntimeError. v1은 partial load 후 잘못된 예측을 silent하게 반환할 수 있었으나 v2에서 차단되었습니다. Schema validation으로 calibration factor 범위 [0.1, 10.0] 외 시 즉시 에러.
Q. 본 모델의 차별성은? (기존 미술품 가격 예측 연구 대비)
기존 연구는 주로 2차 시장(경매)을 대상으로 하거나 글로벌 데이터를 사용했습니다. 본 연구는 ① 한국 1차 시장 전용으로 신진·중견 작가의 갤러리 호가 영역을 다루며, ② train/serve drift 진단 방법론과 ③ 출처별 cell calibration with cross-fit guard를 제시한 점에서 차별성이 있습니다.

Q1. "코덱스 round 1-3 비판은 어떻게 다뤘는가?"

답변: P1 5건 비판 모두 v3.0 Group 1 (분석·통계 보강) 작업으로 보강 완료. 10개 acceptance gate 전체 PASS — HARD 1건 (1.4 baseline 비교, gap 33.25%p) + SOFT 9건. 1.2 v1 vs v2 정식 paired test는 v1 OOF 부재로 proxy 처리, v3.1 v1 재학습 후 정식 검정.

Q2. "1차년도 정량 목표는 통계적으로 어떻게 입증되는가?"

답변: warm Artsy XGB MdAPE 95% CI [7.97%, 8.68%]가 A등급 목표 밴드 [8.0%, 9.0%] 내부 (CI 상한 8.68 < 9.0). Bootstrap 10,000 resample 산출. 점추정 + 통계적 신뢰 구간 둘 다에서 목표 도달.

Q3. "Cold path MdAPE 38.3%의 한계는?"

답변: 1.4 baseline 비교에서 RandomForest cold 38.95%와 v2 ensemble 38.66%의 95% CI가 겹침 → cold slice GBDT 모델 우위가 통계적으로 명확하지 않음. 1.5 learning curve cold cluster bootstrap CI [-0.81, +7.92]도 0 포함 → 데이터 추가의 통계적 효용 불명확. cold path 개선은 모델 변경 / 데이터 양 증가보다 segment 전용 calibration / 라벨 정제 / 피처 강화가 효과적이라는 신호. 1.7 잔차 분석에서 D10 saatchi_online (n=1499)에서 log(pred/actual) median +1.359 (3.9× 과대) — saatchi 최고가 segment broad cell saturation 확인. v3.1 우선 액션: D10 (예측가 ≥ 13.7M KRW) 전용 calibration layer 신설.

Q4. "1차 시장 모델의 시간축 평가가 부재한 이유는?"

답변: 학습 데이터 28,376건 중 Saatchi 21,087건 (74%)에 year_made / 게시일 / 거래일 컬럼이 없음. Artsy (26%, 7,289건)는 year_made 99.2% 가용하나 작품 제작연도 (cohort/age proxy)이며 listing/sale time과 무관. 본 분석은 1.10에서 cohort stratification 한정 (market-time stability 평가 아님)을 정직 명시. v3.1 후속: listing_date / sold_date / first_seen_date 신규 수집 (콜론30 협력 영역) → 정식 temporal holdout 평가.

Q5. "출처 라벨 효과 실험은 power가 충분한가?"

답변: warm 30명 통제군 기준 Pooled Δ% = −0.183 (95% CI [−0.368, −0.017]), Wilcoxon p = 0.068 (α=0.05 기준 경계선 비유의), Cohen's d_z = −0.366 (small effect). "출처 라벨 효과는 크지 않다"는 데이터로 뒷받침되나, "사실상 영향 없음"이라 단언하기엔 표본 부족. v3.1 Group 2.1에서 표본 90+ 확장 + 작가별 다중 작품으로 power 보강 예정.

Q6. "v1 vs v2 개선의 통계적 유의성은?"

답변: v1 OOF 예측 raw 데이터가 보존되지 않아 정식 paired Wilcoxon 불가. v1 점추정 vs v2 95% CI proxy 비교에서는 v1 cold 점추정이 모두 v2 CI 내부 → 차이가 통계적으로 명확하지 않음 (proxy 한계). v3.1에서 v1 재학습 후 정식 검정 예정. v2 개선이 noise 수준일 가능성을 정직하게 인지.

Q7. "재현성 / 감사 가능성은?"

답변: 별도 코덱스 하네스 review 결과 P1 5건 (provenance / 학습 코드 무테스트 / CI 부재 / lock file 부재 / lineage 추적) 식별 → 3 phase 보강으로 close. 모든 학습/진단 산출물에 git SHA + 데이터 해시 + 의존성 버전 + 파서 룰 버전 자동 stamping. uv.lock 124 packages 잠금. 공통 helper 모듈 추출 + 61 unit tests 100% 커버.
