## 1. 무엇을 만들었나

K-Auction 경매 작품의 **예상 낙찰가를 미리 알려주는 AI 엔진**입니다.

작가명, 작품 크기, 재료, 추정가를 넣으면 → 예측 낙찰가 + 가격 범위 + 신뢰도가 나옵니다.

### 제공 형태

| 형태 | 설명 | 파일 |
|------|------|------|
| **API 서버** | 웹에서 호출하여 실시간 예측 | `uvicorn` 실행 후 `localhost:8000` |
| **정적 데이터** | 1,177명 작가의 호수별 예측 | `frontend/data/predictions.json` |
| **테스트 페이지** | 브라우저에서 직접 예측 확인 | `frontend/engine_test.html` |
| **품질 모니터링** | 예측 정확도 자동 추적 | `scripts/check_gate.py` |

## 2. 얼마나 정확한가

> 테스트 데이터: 각 경매 타입의 최근 회차 작품 (학습에 사용하지 않은 데이터)
> 학습 데이터 기준: K-Auction 2026-03-25 수집 CSV 기준

### 전체 성능

| | 수치 | 쉬운 설명 |
|---|------|----------|
| 평균 오차 | **27.0%** | 1억 원짜리 작품이면 예측이 7,300만~1억 2,700만 원 사이 |
| 절반 이상 정확도 | **18.1%** | 예측의 반 이상은 실제가와 18% 이내 차이 |
| ±20% 적중 | **53.4%** | 10건 중 5건은 실제가의 80~120% 범위에 적중 |

### 경매 타입별

| 타입 | 평균 오차 | 한 줄 요약 |
|------|----------|-----------|
| **메이저** (고가 경매) | **19.1%** | 가장 정확 — 5건 중 3건이 ±20% 이내 |
| **프리미엄** (중가 경매) | **27.6%** | 보통 수준 |
| **위클리** (일반 경매) | **35.2%** | 저가 작품이 많아 변동이 큼 |

### 가격대별

| 가격대 | 평균 오차 | 판단 |
|--------|----------|------|
| 3,000만~1억 원 | **~16%** | 매우 정확 |
| 1억 원 이상 | **~20%** | 정확 |
| 500만~3,000만 원 | **~28%** | 양호 |
| 100만~500만 원 | **~35%** | 보통 |
| 100만 원 미만 | **~50%** | 참고용 |

→ **고가 작품일수록 정확하고, 저가 작품은 변동이 큽니다.**

### 신뢰도 등급

예측마다 A~D 등급이 함께 나와서, **이 예측을 얼마나 믿을 수 있는지** 바로 알 수 있습니다.

| 등급 | 정확도 | 뜻 | 사용 권장 |
|------|--------|-----|----------|
| **A** | 72% 적중 | 거래 많은 고가 작가 | 예측가 신뢰 가능 |
| **B** | 50% 적중 | 거래 보통 | 범위로 참고 |
| **C** | 43% 적중 | 거래 이력 적음 | 넓은 범위로 참고 |
| **D** | — | 데이터 부족 | 화면에 "데이터 부족" 또는 "참고용"으로 표시 권장 |

## 3. 어떻게 동작하나

```
① 작품 정보 입력 (작가, 크기, 재료, 추정가)
     ↓
② AI가 "추정가 대비 얼마에 낙찰될지" 예측
     ↓
③ 가격대별 보정 적용 (고가/저가 편차 조정)
     ↓
④ 예측 낙찰가 + 가격 범위 + 신뢰도 등급 반환
```

**핵심**: "이 작품이 얼마다"가 아니라 "추정가 대비 몇 %에 낙찰될 것인가?"를 예측합니다.

K-Auction은 평균적으로 추정가의 약 60% 수준에서 낙찰되는 특성이 있고, 이 패턴을 AI가 학습했습니다.

## 7. 한계와 주의사항

### 이런 경우 조심하세요

| 상황 | 왜 | 어떻게 |
|------|-----|--------|
| 처음 보는 작가 | 과거 거래 없음 | D등급으로 표시, 추정가 범위 참고 |
| 100만 원 미만 저가 | 가격 변동이 큼 | 오차 50%+ — 참고용으로만 |
| 추정가를 크게 넘는 낙찰 | "서프라이즈" 패턴 | 현재 모델이 포착 어려움 |
| 시장 급변 (경기 충격 등) | 학습 데이터에 미반영 | 월 1회 재학습으로 대응 |

### 이 엔진은 이런 것이 아닙니다

- 개별 작품의 적정가를 확정하는 감정 도구가 **아닙니다**
- 투자 판단의 근거로 사용하기에는 **부적합합니다**
- 모든 작품에 동일한 정확도를 보장하지 **않습니다**
- 유찰(안 팔린) 작품 데이터는 포함되지 않았으며, 낙찰된 작품만을 기준으로 학습했습니다
- 현재 운영 배포는 되어 있지 않으며, 배포 전 실 데이터 기반 Shadow 검증을 권장합니다

## 8. 실행 방법

### 가장 간단한 방법 (테스트 페이지)

`frontend/engine_test.html` 파일을 **브라우저에서 열기**만 하면 됩니다.
→ 작가/크기/추정가 입력 → 예측 결과 즉시 확인

### API 서버 실행

```bash
# 1. 패키지 설치 (최초 1회)
pip install -e ".[price-engine-core,price-engine-api]"

# 2. 데이터 전처리 (최초 1회, 약 10초)
python scripts/run_pipeline.py

# 3. 서버 시작
uvicorn visionai.price_engine.api.server:app --reload

# 4. 브라우저에서 확인
#    http://localhost:8000/docs → API 문서 (Swagger)
```

### API 호출 예시

```
POST http://localhost:8000/api/v1/predict_price

요청:
{
  "artist_name": "김환기",
  "auction_type": "메이저",
  "width_cm": 72.7,
  "height_cm": 60.6,
  "medium": "캔버스에 유채",
  "estimate_low": 50000000,
  "estimate_high": 80000000
}

응답:
{
  "predicted_price": 62000000,         ← 예측 낙찰가
  "price_range": [49600000, 74400000], ← 가격 범위
  "confidence_grade": "A",              ← 신뢰도 (A=높음)
  "estimate_vs_prediction": 95.4        ← 추정가의 95.4%
}
```
