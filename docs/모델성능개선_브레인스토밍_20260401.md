## 2. 학술 리서치 결과

### 2.1 핵심 논문 요약

#### [1] Kim & Kim (2024) — 한국 미술 경매 2단계 모델
> *Two-step model based on XGBoost for Korean art auction data*
> — 한국 경매 데이터에서 가격대별 분류 후 개별 회귀 모델 적용
> — **가격 결정 요인이 가격대마다 다름**: 저가=크기/매체, 고가=작가 브랜드

- 예상 효과: **-3~5%p MdAPE**
- 구현 복잡도: 중간
- 데이터 요구: 현재 데이터로 충분
- 근거 강도: **강함** (한국 데이터 직접 검증)

#### [2] Mei, Moses et al. (2025) — 딥러닝 멀티모달 가치 평가
> *Deep Learning for Art Market Valuation*
> — Mei-Moses 팀 (미술시장 지수 창시자)
> — 이미지 피처는 **Cold Start 작가에만 효과** (R² +14%p)
> — Warm 작가에서는 이미지 추가 효과 없음

| 시나리오 | Tabular R² | Multimodal R² | 차이 |
|---------|-----------|---------------|------|
| Warm (반복 거래) | 0.79 | 0.79 | 0 |
| **Cold (신규)** | **0.53** | **0.67** | **+0.14** |

- 예상 효과: Cold MdAPE -10~12%p → 전체 -2~3%p
- 구현 복잡도: 높음
- **핵심**: 이미지를 전체 적용하면 안 되고 Cold 전용으로만 사용
- 근거 강도: **매우 강함** (Mei-Moses 팀, 53K 거래, 2025년)

#### [3] Nature Scientific Reports (2024) — 소셜/경력 신호
> *Social signals predict contemporary art prices better than visual features*
> — XGBoost + 30개 소셜/경력 피처 → R² = 0.73
> — 시각적 피처만으로는 R² = 0.055
> — **신흥 시장(한국 포함)에서 소셜 신호가 더 강력** (R²=0.75 vs 선진시장 0.67)

**가장 예측력 높은 소셜 피처:**
- 최근 5/10건 거래 가격 (이미 있음)
- **전시 횟수 및 격** (비엔날레 참여, 미술관 소장)
- **경매사 등급/명성**
- **작가 나이, 성별, 교육 배경**
- 시장 레벨: 국가별 가격 통계, 시장 성장률

- 예상 효과: **-2~4%p** (전시/갤러리 데이터 확보 시)
- 구현 복잡도: 중간 (데이터 수집이 관건)
- 근거 강도: **강함** (Nature 저널, 한국 시장 명시)

#### [4] Applied Sciences (2024) — 딥러닝 vs GBDT 비교
> *Tabular Data Models for Predicting Art Auction Results*
> — 13개 모델 벤치마크: GBDT가 딥러닝(SAINT, VIME) 일관 우위
> — CatBoost/LightGBM/XGBoost가 최적

- **결론**: 모델 아키텍처 교체 불필요. 현재 앙상블이 이미 최적 구조.

#### [5] 한국 LSTM 연구 — 시계열 가격 예측
> — 작가별 가격 궤적을 시계열로 모델링
> — RMSE 0.064 보고

- 예상 효과: -1~3%p (시계열 피처 추가)
- 구현 복잡도: 낮음 (rolling stat) ~ 높음 (per-artist LSTM)

#### [6] Hedonic + RSR 하이브리드 (중국 회화 연구)
> — Repeat-Sales Regression과 Hedonic 결합이 단독보다 우수
> — RSR이 시장 수준 가격 지수 보정 제공

- 예상 효과: -1~2%p
- 구현 복잡도: 낮음 (RSR 지수를 피처로 추가)

## 3. 에러 분석 + 리서치 종합: 개선 전략

### 3.1 전략 1: 가격대별 전문 모델 (예상 -3~5%p)

**근거**: Kim & Kim (2024) + 에러 분석에서 저가(<50만) MdAPE 90%

**방법**:
1. 1단계: 가격대 3분류 (저가/중가/고가) Classifier
2. 2단계: 각 세그먼트별 독립 CatBoost+LightGBM+XGBoost 앙상블
3. 3단계: 세그먼트별 CQR 캘리브레이션

**세그먼트 설계**:
| 세그먼트 | 범위 | Train 건수 | 특성 |
|---------|------|-----------|------|
| 저가 | <200만원 | ~28,000 | 크기/매체 중심, 작가 브랜드 약함 |
| 중가 | 200만~2000만 | ~12,000 | 균형 |
| 고가 | 2000만+ | ~6,000 | 작가 브랜드 지배적 |

**기대 효과**:
- 저가 세그먼트 MdAPE: 90% → 50~60% (전체 -5~8%p)
- 고가 세그먼트는 현재도 양호하므로 유지

### 3.2 전략 2: Cold Start 전용 이미지 모델 (예상 -2~3%p)

**근거**: Mei-Moses (2025) — Cold 전용 이미지 R² +0.14

**방법**:
1. Cold 작가 (거래 <5건) 대상으로만 이미지 모델 학습
2. CLIP 임베딩 512d (이미 추출 완료) 사용
3. Cold 전용 CatBoost: hedonic 57 + CLIP 32d = 89 피처
4. Warm 작가는 기존 모델 유지
5. 예측 시 artist_total_sold < 5이면 Cold 모델 사용

**기존 실패 원인과 차이**:
- 이전: 전체 적용 → Warm에서 노이즈로 작용
- 이번: Cold 전용 → 히스토리 없는 작가에서만 이미지가 보조 신호

### 3.3 전략 3: 무효 피처 제거 + 소셜 피처 대체 (예상 -1~2%p)

**제거 대상 (7개)**:
`is_3d`, `bbox_volume`, `depth_cm`, `artist_career_length`,
`artist_lot_count_trend`, `artist_sale_frequency`, `is_new_artist`

**추가 가능 소셜/시장 피처**:
| 피처 | 설명 | 데이터 확보 |
|------|------|-----------|
| `auction_house_tier` | 경매사 등급 (1=메이저, 2=중견, 3=소형) | 즉시 가능 |
| `artist_auction_house_count` | 작가가 출품한 경매사 수 | 즉시 가능 |
| `price_segment_median` | 해당 가격대의 중앙 가격 | 즉시 가능 |
| `medium_quarterly_trend` | 매체별 분기 가격 추세 | 즉시 가능 |
| `artist_exhibition_count` | 전시 횟수 | 외부 수집 필요 |
| `gallery_tier` | 소속 갤러리 등급 | 외부 수집 필요 |

### 3.4 전략 4: 시계열 피처 강화 (예상 -1~2%p)

**추가 피처**:
| 피처 | 설명 |
|------|------|
| `market_3m_trend` | 최근 3개월 시장 가격 추세 (상승/하락) |
| `market_6m_trend` | 최근 6개월 시장 가격 추세 |

| `days_since_last_artist_sale` | 마지막 거래 후 경과일 |

### 3.5 전략 5: RSR 하이브리드 지수 (예상 -1~2%p)

**방법**:
1. 반복 거래 쌍 식별 (동일 작품이 다른 시점에 거래)
2. 작가/매체별 RSR 가격 지수 산출
3. 지수를 hedonic 모델의 피처로 추가

### 3.6 전략 6: global_median_price 결측 해결 (예상 -1~2%p)

**현황**: 테스트셋 87.6% 결측 → 피처가 거의 무용

**해결 방안**:
1. 매체 × 국적 × 가격대 버킷의 중앙 가격으로 대체
2. 학습 데이터의 해당 조합 평균 사용
3. 결측 시 전체 매체 평균으로 폴백

## 5. 핵심 인사이트 요약

### 5.1 확인된 사실
1. **이미지는 전체 적용 시 무효**, Cold 전용 시에만 효과 (Mei-Moses 2025)
2. **GBDT 앙상블이 딥러닝보다 우수** — 모델 교체 불필요 (Applied Sciences 2024)
3. **가격대마다 결정 요인이 다름** — 단일 모델의 한계 (Kim & Kim 2024)
4. **소셜/경력 신호 > 시각적 신호** — 한국 시장에서 특히 강력 (Nature 2024)
5. **저가 세그먼트가 전체 오차의 주범** — 에러 분석에서 MdAPE 90%

### 5.2 가장 효과 대비 비용이 좋은 3가지
1. **가격대별 전문 모델** — 코드 변경만으로 -3~5%p (데이터 추가 불필요)
2. **무효 피처 제거 + 결측 보간** — 30분 작업으로 -1~2%p
3. **경매사 등급 피처** — 이미 있는 데이터로 -0.5~1%p

### 5.3 학술적 천장
- Hedonic 단독: **~35~40%** (현재 42.81%)
- Hedonic + 가격대별 분리: **~32~37%**
- Hedonic + 소셜/경력 + 이미지(Cold): **~28~34%**
- 이론적 하한 (미술품 고유 불확실성): **~20~25%**
