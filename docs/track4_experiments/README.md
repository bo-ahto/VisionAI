# Track 4 개별 실험 기록

- 목적: Track 4에서 실행한 실험을 1건씩 기록하는 폴더
- 원칙
- 실험 1건당 기록 파일 1개를 작성함
- 파일명은 `YYYY-MM-DD_T4-E번호_실험명.md` 형식을 사용함
- 예시: `2026-05-15_T4-E001_temporal_safe_warm_features.md`

## 기록 방식

- 모든 실험은 아래 항목을 포함함
- 실험 ID
- 연결 가설
- 실험 목적
- 사용 데이터
- 사용 피처
- 사용 모델
- 비교 기준
- 실행 명령
- 결과 파일
- Warm 결과
- Cold 결과
- 해석
- 결론
- 후속 작업
