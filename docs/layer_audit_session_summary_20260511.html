4. Layer-by-Layer audit 결과

Layer 0: Target/Source bias audit (T0-T6)

핵심 발견: artist_slug overlap = 0 — Artsy slug ("yujin-ju") vs Saatchi slug ("1889924") 완전히 분리된 universe
  • T0 (price type): 두 source 모두 list/asking price (sold 아님) — consistent
  • T1 (within-artist median ratio): name-match 37명 / median log-ratio -0.05 (≈0.95x) / IQR 1.16 (큰 dispersion)
    → systematic source bias 미미, within-artist composition variation 큼 (Simpson's paradox)
  • T2-T6 (codex 추가 권고): seller/time/inventory 분리 — 본 세션 미진행 (운영 데이터 의존)
의미: GroupKFold(artist_slug)가 자동으로 source-split → cold task는 "new artist + source/domain shift" 결합. D1.SC fail의 evaluation design 문제.

9. 결론

  1. 운영 fidelity 정리: 32 → 28 features 통해 train-only signals 3종 (ho_price_level, medium_price_level, source, for_sale_ratio, gallery_tier) 제거. 운영에서 inference 변별력 없는 features 정리.
  2. Train/serve consistency 개선: source 입력 불가능한 user 환경 정합. has_followers flag로 missingness explicit.
  3. Performance 거의 동일: 모든 PASS cycle warm path 영향 0 (2σ noise 내). Cold path 미세 손실 (within 0.5σ).
  4. Variant infrastructure 확장: 5 base × 2 = 10 variants 운영 가능. VARIANT_SHADOW로 비교 가능.
  5. 실제 효과는 production에서: isolated cycle은 학습 분포 내 측정. unmatched 신규 작가 / train-serve drift 실제 효과는 운영 monitoring에서만.

본 문서는 본 세션 audit + 4 PR 결과 종합. 실제 운영 deploy 결정은 별도 prereg 필요 (Stage 3-5 패턴).
