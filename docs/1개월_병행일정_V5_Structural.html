1개월 두 가지 트랙 병행 진행
  • 트랙 1 (운영 모델 개선·배포, Day 1-28)
    • 매주 수요일 갱신 마이그레이션 데이터 기준
    • 신규 작가 예측 약점 직접 개선
    • 한 달 후 실서비스 단계적 배포 완료 (필수)
  • 트랙 2 (해석 가능 비교 기준 모델, Day 1-28)

공통 검증: 동일 LAO holdout (artist-level 80/20) + 3 seeds 반복 (재현성 점검)

4주 후 산출물:

본인 결정/관리 사항: 마이그레이션 데이터 사용 가능일 / 배포 권한 / rollout 진행 방식 / rollback owner (§9 타임라인 참조)

2. 배경 — 현재 모델 상태

운영 모델 성능

측정 조건 오차 (MdAPE) 의미 활용 가능성
기존 작가 (학습에 작품이 있는 작가) 12-18% 예측이 실제값의 12-18% 범위 (median) ✅ 운영 활용 가능
신규 작가 (학습에 등장하지 않은 작가) 28-48% 예측 변동성 큼 ⚠️ 보조 도구로만 사용 권장
격차 23%p 기존/신규 작가 본질적 difficulty 차이 핵심 개선 영역 (트랙 1 목표)

두 트랙 병행 필요 이유

  • 트랙 1: 신규 작가 예측 영역 직접 개선 → 실서비스 staged rollout
    • 협력자 갤러리 검수 데이터 활용
    • 새로운 가격 anchor feature 도입
  • 트랙 2: 운영 모델 해석 한계 보완
    • Core 5 고정 + Main 7 1차 확장만 사용
    • 변수별 가격 영향 설명 가능 모델 구축
    • 운영 도입 X, 설명 자료 + 비교 기준 역할
주요 용어 풀이:
  • MdAPE: 예측 오차의 대표값 (중앙값 기준 % 오차)
  • holdout: 학습에 사용하지 않은 별도 검증 셋
  • 3 seeds: 랜덤 분할을 3회 반복한 재현성 점검
  • shadow / canary / staged rollout: 신모델을 단계적으로 (1% → 5% → 25% → 50% → 100%) 도입하여 운영 위험 최소화

3. 트랙 정의

트랙 1 — 운영 모델 개선 + Staged Rollout (28일)

항목내용
최종 목표 한 달 후 실제 서비스 반영 (배포 완료 + 4-5일 초기 안정화)
도입 후보 ① 작가별 차이 보정 (mixed-effects 잔차 모델)
② 매체 + 크기 기반 가격 anchor (유사 작품 NN retrieval)
③ 매체 + 크기만 사용 (image 효과 부족 시 fallback)
전제조건 매주 수요일 마이그레이션 데이터 갱신 + 추가 미매칭 갤러리 일괄 검수 완료 (Day 1-2)
평가 방법 같은 작가가 학습·평가에 동시에 섞이지 않도록 분리 (artist-level holdout 80/20), 3회 반복 (재현성 점검)
도입 후보 선정 기준 가장 robust 한 후보 선택 (cherry-pick X)
  • 3회 반복 모두 같은 방향
  • 평균 오차 개선 ≥ 0.8%p 또는 ≥ 3% 상대 개선
  • 작가 식별 의존도 ≤ 50%
미충족 시: 가장 안전한 후보 (변동성 낮음) 도입 + monitoring 강화
배포 단계 (staged rollout) Shadow Week 3 초 (검증)
1% 5% Week 3 (canary)
25% 50% Week 4 초 (확장)
100% 5/29 (금) full rollout + 4-5일 초기 안정화 (~6/2)
운영 monitoring 지표
  • 응답 속도 (latency)
  • Fallback 빈도
  • 입력 누락률 (feature missingness)
  • 예측가 / 등급 분포 변화 (drift)
  • Source 별 output shift
  • Rollback 즉시 가능 여부
산출물
  • 도입 후보 메모
  • 배포 PR
  • Monitoring dashboard
  • Rollback runbook
  • 4-5일 초기 안정화 리포트

트랙 2 — 해석 가능 비교 기준 모델 (28일)

항목내용
목적
  • 운영 모델과 별도, 가격 결정 요인 설명 가능한 간결 모델 구축
  • 핵심 5-7개 피처 한정 (parsimony)
  • 운영 모델 비교 기준 + 설명 자료 활용
모델 형태
  • 변수별 가격 기여 분해 회귀 모델
  • 작가/갤러리별 차이 분리 (mixed-effects 구조)
  • "왜 이 가격이 나왔는가" 를 5-7개 변수로 설명
핵심 5개 피처 (core) 가장 robust 하고 인과적으로 해석 가능한 5개:
① 작품 크기 (log_area)
② 매체 (oil/acrylic/paper/other 4분류)
③ 제작 연도 (year_made_centered)
④ 작가 경력 단계 (career_stage)
⑤ 데이터 소스 (Artsy / Saatchi)
main 7개 피처 (보조 추가) Core 5 + 갤러리 티어 (gallery_tier) + 정보 누락 control 1개 (has_year_made / has_birth_year 중)
sensitivity 8-10개 (한계 검증용) Main 7 + 작가 활동 지표 (log_followers, reverse causality 우려) + 한국시장 dummy 등
피처 선정 원칙 (parsimony)
  • 한 개념당 한 변수 (size / medium / year / career / source 각 1개)
  • DAG 상 직접 특성·사전결정 변수 우선
  • Reverse causality 강한 변수 (followers 등) core 제외 → sensitivity 만
  • 자동 변수 선택 (LASSO 등) 은 보조 진단으로만 사용 (해석 가능성 우선)
인과 framing
  • 변수 간 인과 구조 (DAG) 명시
  • 신뢰 가능한 효과 (예: 크기 → 가격) vs 단순 상관관계 (예: 갤러리 티어 → 가격) 분리 보고
산출물
  • 변수별 가격 기여 표 (5-7 변수 한정)
  • 작가/갤러리 효과 분해
  • 인과 신뢰도 등급표
  • 운영 모델 비교 표
  • 최종 보고서 (10-15페이지)
