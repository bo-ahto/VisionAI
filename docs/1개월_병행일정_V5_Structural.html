4. 핵심 의존성 / 위험 (코덱스 13차 자문 반영)

⚠️ Hard dependencies
  • Dependency stop: V5 Day 1 시작 조건 = 본 마이그레이션 데이터 도착. 미도착 시 Structural Week 1 만 먼저 진행.
  • V5 Day 2 A re-check: V4 PILOT 결과 (image FAIL) 가 본 데이터에서도 재현된다는 가정. 의외 PASS 시 deviation log + scope 재검토.
  • Structural Week 1 데이터 spec: V5 LAO split 과 동일 framework. Variable spec confirmed by Day 5.
🛑 Burn-rate Stop / Branch Rules (코덱스 13차 신규)
  • Burn-rate stop: 어느 주든 계획 대비 +30% 시간 초과 시 다음 stretch 항목 자동 제거 (Quantile / Bayesian / V6 brainstorm 등).
  • V5 Week 1 negative branch: Week 1 종료 시 R/S 둘 다 불명확 → Week 2 = integration branch 취소, C-lite only + final go/no-go.
  • V5 Day 14 no-go 시 Week 3-4 = deploy prep 대신 retro 중심 전환.
  • Structural OLS 실패 처리 (Week 2 종료):
    • spec failure (변수 미확정 / 수치 불안정) → ME 진행 보류
    • performance disappointment (성능 낮음) → ME 진행 가능
    • diagnostic weakness (잔차 부적합 등) → caveat 달고 진행
  • Day 10 기준 OLS/ME instability 시 → Week 4 Quantile scope 축소.
⚠️ Soft risks (mitigation 가능)
  • 시간 over-allocation: 일 4-6h 부담. Burn-rate stop +30% 적용으로 자동 controlled.
  • 병행 cognitive load: Morning V5 / Afternoon Structural time-block 으로 mitigation. Day-by-day interleave 보다 피로 적음.
  • R fail 시 S fallback: V5 Week 1 plan 의 변형 진행 (코덱스 9차 자문 권고).
  • Structural Mixed-effects convergence: statsmodels MixedLM 실패 시 pymer4 (R lme4) 또는 GPBoost 으로 fallback.
  • Bayesian stretch: 시간 부족 시 자동 폐기 (Burn-rate stop).

5. 성공 기준 (Day 28 종료 시)

V5 Cycle

  • R/S 또는 C-lite 도입 결정 완료 (pass/cut 명확)
  • R Pass: cold-start ΔMdAPE ≤ -max(0.8pp, baseline 3%) + memorization retention ≥ 50%
  • C-lite Pass: seen-artist ΔMdAPE ≤ -max(0.5pp, 2%) + cold-start 악화 ≤ +0.5pp
  • 통합 Pass: gain retention ≥ 80%
  • 의사결정 memo + PR review 완료

Structural Pricing Track (≥ 2/3)

  • 학술 baseline 확립: OLS / ME / Quantile coefficient + V3 비교
  • Cold-start regime baseline: Within-artist 식별 결과
  • 이론적 방어 가능 문서: 5+ paper reference + 식별 등급표

병행 성공 기준

  • 두 트랙 모두 timeline 내 완료 (지연 없음)
  • V5 결과와 Structural 결과의 비교 표 (홀드아웃 동일 protocol)
  • 코덱스 자문 적정 빈도 활용 (≥ 2회 추가 자문)
