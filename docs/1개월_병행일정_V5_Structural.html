1개월 가격예측 모델 실험 계획

작성일: 2026-05-05 · 대상 기간: 28일 (4주) · 주제: 운영 모델 개선 (V5) + 신규 해석 가능 모델 (Structural Pricing) 병행 진행

1. 핵심 요약 (TL;DR)

향후 1개월 동안 두 가지 트랙을 병행 진행하겠습니다.
  1. 트랙 1 (운영 모델 개선): 협력자 갤러리 검수 데이터를 활용해 현재 모델의 신규 작가 예측 약점을 직접 개선하겠습니다 (14일).
  2. 트랙 2 (해석 가능 비교 기준 모델): 변수별 가격 영향을 설명할 수 있는 별도 모델을 구축해 운영 모델의 비교 기준이자 설명 자료로 활용하겠습니다 (28일).
두 트랙은 동일한 검증 방식으로 비교하겠습니다. 같은 작가가 학습·평가에 동시에 섞이지 않도록 분리하고, 이를 3회 반복해 재현성을 확인합니다.

4주 후 남는 것: ① 신규 작가 예측 개선 도입 결정 (도입 또는 보류 명확) + ② 변수별 가격 기여 설명서 (10-15페이지 보고서) + ③ 두 모델 비교 표.
승인 요청: 본 4주 plan 진행 + 마이그레이션 데이터 사용 가능일 확정 + 추가 갤러리 검수 지원.

2. 배경 — 현재 모델 상태

운영 모델 (V3) 성능

측정 조건 MdAPE 의미 활용 가능성
Warm (기존 거래 작가) 12-18% 예측이 실제값의 12-18% 범위 (median) ✅ 운영 활용 가능
Cold-start (신규 작가) 28-48% 예측 변동성 큼 ⚠️ 보조 도구로만 사용 권장
격차 23%p warm 과 cold-start 의 본질적 difficulty 차이 핵심 개선 영역

두 트랙 병행이 필요한 이유

  • 트랙 1 (운영 모델 개선): 신규 작가 예측 영역의 직접 개선 — 협력자 갤러리 검수 데이터 + 새로운 가격 anchor feature 도입.
    → 1개월 내 운영 가능 여부 검증 + 도입 결정.
  • 트랙 2 (해석 가능 비교 기준 모델): 현 운영 모델의 해석 한계를 보완하기 위해, 변수별 가격 영향이 설명 가능한 비교 기준 모델을 별도 구축하겠습니다.
    → 운영 도입 X, 운영 모델의 설명 자료 + 학술적 비교 기준.
주요 용어 (본문 첫 등장 시 풀이):
  • MdAPE: 예측 오차의 대표값 (중앙값 기준 % 오차)
  • holdout: 학습에 사용하지 않은 별도 검증 셋
  • 3 seeds: 랜덤 분할을 3회 반복한 재현성 점검
  • cold-start / 신규 작가: 학습에 등장하지 않은 새 작가 예측
  • warm / 기존 작가: 학습 데이터에 작품이 있는 작가

3. 트랙 정의

트랙 1 — 운영 모델 개선 (V5 Cycle, 14일)

항목내용
목적 V3 의 cold-start MdAPE 를 stretch -5%p / 현실 -2~4%p 개선
도입 후보 ① 작가별 차이 보정 (mixed-effects 잔차 모델)
② 매체 + 크기 기반 가격 anchor (유사 작품 NN retrieval)
③ 매체 + 크기만 사용 (image 효과 부족 시 fallback)
전제조건 본 마이그레이션 데이터 도착 + 추가 미매칭 갤러리 일괄 검수 완료
평가 방법 같은 작가가 학습·평가에 동시에 섞이지 않도록 분리 (artist-level holdout 80/20), 3회 반복 (재현성 점검)
도입 결정 기준 ① 3회 반복 모두 같은 방향 + ② 평균 오차 개선 ≥ 0.8%p 또는 ≥ 3% 상대 개선 + ③ 작가 식별 의존도 ≤ 50% (단순 작가 매칭으로만 개선되는 경우 제외)
산출물 의사결정 메모 + 모델 PR + 운영 monitoring checklist

트랙 2 — 해석 가능 비교 기준 모델 (Structural Pricing, 28일)

항목내용
목적 운영 모델과 별도로, 가격 결정 요인을 설명할 수 있는 해석 가능 기준 모델을 구축하겠습니다. 이 모델은 운영 모델의 비교 기준이자 설명 자료로 활용합니다.
모델 형태 변수별 가격 기여를 분해해 보여주는 회귀 모델 + 작가/갤러리별 차이를 별도로 분리하는 mixed-effects 구조.
→ "왜 이 가격이 나왔는가" 를 변수 단위로 설명 가능
주요 변수 (15-25개) 작품 크기 / 매체 (oil, acrylic 등) / 제작 연도 / 작가 경력 단계 / 작가 활동 지표 / 갤러리 티어 / 데이터 소스 등
인과 framing 변수 간 인과 구조 (DAG) 명시 → 신뢰 가능한 효과 (예: 크기 → 가격) vs 단순 상관관계 (예: 갤러리 티어와 가격) 를 분리해 보고하겠습니다.
→ 약한 근거를 강한 근거처럼 포장하지 않음
설계 원칙 1차 시장 데이터에 맞는 변수 체계를 사용하고, 작가/갤러리 효과를 분리해 해석 가능한 결과를 만들겠습니다. 변수 정의 / 인과 가정 / 모델 한계를 모두 문서화합니다.
산출물 변수별 가격 기여 표 · 작가/갤러리 효과 분해 · 인과 신뢰도 등급표 · 운영 모델과 비교 표 · 최종 보고서 (10-15페이지)
