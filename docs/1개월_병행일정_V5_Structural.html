1개월 가격예측 모델 실험 + 운영 도입 계획

작성일: 2026-05-05 · 대상 기간: 2026-05-06 (수) ~ 2026-06-02 (4주) · 구조: Champion-Challenger (두 트랙 동시 검증, 단일 endpoint 배포)

1. 핵심 요약 (TL;DR)

두 가지 모델 트랙을 동시 검증 후, 운영 endpoint 에는 winner 1개 배포
  • 트랙 1 (Predictive Challenger): 예측력 우선 — 매주 수요일 갱신 데이터 + V5 후보 (mixed-effects / retrieval) 도입 검증
  • 트랙 2 (Interpretable Challenger): 해석력 강점 — Core 5 고정 hedonic mixed-effects 모델, 변수별 가격 영향 설명 가능
운영 원칙
  • Week 1-2: 동일 protocol 로 두 트랙 offline 검증
  • Week 3 초: 두 트랙 모두 shadow 환경에서 동시 검증
  • Week 3 말: 복합 scorecard 기반 champion 1개 선정
  • Week 4: champion 만 canary → full rollout + 안정화
  • 비선정 모델은 shadow challenger 또는 설명/의사결정 보조 모델로 유지
4주 후 산출물
  • 운영 endpoint 에 champion 모델 배포 완료 + 4-5일 초기 안정화
  • Champion 선정 근거 + 비선정 모델 활용 방안 메모
  • Core 5 기반 해석 가능 모델 보고서 (10-15페이지)
  • 두 트랙 비교 표 (정확도 + 안정성 + 운영성 + 해석성)
외부 협업 요청: 협력자 콜론30 — 추가 미매칭 갤러리 검수 (Week 1)
본인 결정/관리 사항: 마이그레이션 데이터 사용 가능일, champion 선정, 배포 방식, rollback owner — §9 타임라인 참조

2. 배경 — 현재 운영 모델 상태

측정 조건 오차 (MdAPE) 의미 활용 가능성
기존 작가 (학습에 작품이 있는 작가) 12-18% 예측이 실제값의 12-18% 범위 (median) ✅ 운영 활용 가능
신규 작가 (학습에 등장하지 않은 작가) 28-48% 예측 변동성 큼 ⚠️ 보조 도구로만 사용 권장
격차 23%p 기존/신규 작가 본질적 difficulty 차이 핵심 개선 영역
주요 용어 풀이
  • MdAPE: 예측 오차의 대표값 (중앙값 기준 % 오차)
  • holdout: 학습에 사용하지 않은 별도 검증 셋
  • 3 seeds: 랜덤 분할을 3회 반복한 재현성 점검
  • Champion-Challenger: 동일 protocol 검증, winner (champion) 만 운영 배포 / 비선정은 challenger 로 shadow 유지
  • shadow → canary → full rollout: 신모델 단계적 배포 (트래픽 0% → 1% → 5% → 25% → 50% → 100%)

3. 트랙 정의

트랙 1 — Predictive Challenger (예측력 우선)

항목내용
목표 실서비스 endpoint 의 예측력 (특히 신규 작가 예측) 직접 개선
모델 형태
  • 현 운영 모델 (V3, 32 features, GBM ensemble) baseline
  • 도입 후보:
    • 작가별 차이 보정 (mixed-effects 잔차 모델)
    • 매체 + 크기 기반 가격 anchor (유사 작품 NN retrieval)
    • 매체 + 크기만 사용 (image 효과 부족 시 fallback)
피처 설계
  • Week 1 에 V3 32 features 의 기여/누수/운영 리스크 검증 (feature validation gate)
  • 새 candidate features 도입 후 검증
  • source 유지 (예측력 + calibration 검증됨)
강점 예측 정확도 / cold-start 일반화 / 운영 안정성

트랙 2 — Interpretable Challenger (해석력 강점)

항목내용
목표 변수별 가격 영향이 설명 가능한 간결 모델 — 동일 protocol 검증 후 champion 후보
모델 형태
  • Hedonic mixed-effects 회귀
  • 변수별 가격 기여 분해
  • 작가/갤러리별 차이 분리 (random effects)
  • "왜 이 가격이 나왔는가" 를 5-7개 변수로 설명
Core 5 (고정)
  • log_area — structural / 인과 가능
  • medium_family (oil/acrylic/paper/other) — structural / 인과 가능
  • year_made_centered — structural / vintage 효과
  • career_stage — structural / Galenson curve
  • gallery_tier — associational / 시장 포지셔닝 proxy (caveat)
Main 7 (1차 확장) Core 5 + log_artist_total_works (productivity proxy) + missingness control 1개
Sensitivity (한계 검증용) Main 7 + source [control only] + log_followers [predictive only] + is_krw or has_seoul
강점 변수 해석성 / 인과 framing / 운영 의사결정 설명력

두 트랙의 설계 철학 차이

차원트랙 1 (Predictive)트랙 2 (Interpretable)
피처 수 32 + α (V3 기반) 5-7 (parsimony)
source 처리 유지 (예측 기여) Core 제외 (control only)
모델 유형 GBM ensemble + retrieval / mixed-effects Linear hedonic + mixed-effects
최우선 metric MdAPE / W30 변수별 elasticity / 인과 신뢰도
champion 선정 시 강점 예측 정확도 설명 + 운영 안정성

📝 설계 원칙: 두 트랙은 서로 다른 trade-off 를 보여주는 challenger. winner 는 복합 scorecard 로 결정.

4. Champion 선정 기준 (복합 Scorecard)

축 (Dimension) 측정 지표 가중치
정확도 Holdout MdAPE (전체 + 신규 작가) / W30 / W50 높음
안정성 3-seed 재현성 / cold-start 변동성 / 분포 drift 높음
운영성 Latency / Fallback 빈도 / 입력 누락 robustness / 모델 수렴 안정성 중간
해석성 변수별 가격 기여 설명 가능 여부 / 인과 신뢰도 등급 중간
📌 Champion 선정 규칙
  • 정확도 ≥ baseline 인 후보 중에서 안정성 + 운영성 + 해석성 종합 평가
  • 정확도 차이 ≤ 1%p 인 경우 → 해석성 / 운영성 우위 후보 우선
  • 정확도 차이 > 1%p 인 경우 → 정확도 우위 후보 우선 (단 안정성 통과 조건)
  • 비선정 모델 = shadow challenger 또는 설명용 보조 모델로 유지
