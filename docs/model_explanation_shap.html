1차 시장 가격 예측 모델 설명 방법

작성일: 2026-04-13 모델: XGBoost (기존 작가) + CatBoost v2 (Cold Start) 분기 설명 방법: SHAP (SHapley Additive exPlanations)

1. 왜 트리 모델인가

1.1 헤도닉 회귀 vs 트리 모델 비교

동일 데이터(9,975건)에서 실측 비교한 결과:

모델 기존 작가 MdAPE Cold Start MdAPE R²
단순 헤도닉 (Ridge) 40.5% 44.5% 0.732
헤도닉 + 인터랙션 30.5% 34.3% 0.812
헤도닉 + Spline 30.5% 35.6% 0.817
XGBoost 9.8% 31.5% 0.931
20.7%p Gap

헤도닉을 인터랙션, 비선형 항(Spline), 2차 다항식으로 강화해도 XGBoost와 20.7%p 격차가 존재한다. 이 격차는 가중치 튜닝으로 해결할 수 없는 구조적 한계이다.

1.2 트리가 더 정확한 이유

헤도닉은 모든 관계가 선형이라 가정하지만, 실제 미술 시장은:

  • 비선형: 호수 5→10의 가격 증가폭 ≠ 호수 50→100의 증가폭
  • 조건부 인터랙션: 원로 작가의 대형 캔버스 vs 신진 작가의 소형 종이는 크기-가격 관계가 완전히 다름
  • 갤러리 개별 효과: 66개 갤러리 각각의 가격 수준이 다르며, 트리는 이를 자동으로 학습

트리 모델은 수천 개의 결정 트리가 순차적으로 오차를 보정하며 이런 복잡한 패턴을 자동으로 학습한다. 하나의 공식으로 표현할 수 없지만, SHAP으로 개별 예측을 분해하여 설명할 수 있다.

2. SHAP 기반 설명

2.1 SHAP이란

모델의 예측을 각 피처의 기여도로 분해하는 방법. 기준가(전체 평균)에서 출발하여, 각 피처가 가격을 얼마나 올리고 내리는지를 %로 계산한다.

기준가 (전체 평균): 450만원
  + 작가 세대 (1944년생): +105%  →  923만원
  + 경력 단계 (원로):      +17%  → 1,081만원
  + 아트페어 참여:         +9%   → 1,294만원
  + 크기 (40호):          +9%   → 1,523만원
  - 총 작품수 (많음):      -4%   → 1,460만원
  ...
  = 예측가: 1,757만원

2.2 전체 피처 기여도

모델이 가격을 결정할 때 각 요인이 차지하는 비중:

요인 비중 설명
작품 크기 34.4% 면적, 호수, 크기 곡선 등 합산
작가 세대 15.4% 나이/세대가 가격의 가장 큰 단일 결정 요인
갤러리 8.8% 어떤 갤러리에서 판매하는가
아트페어 3.8% 국제 전시 참여 이력
지지체 3.6% 캔버스/종이/패널
시장 관심도 3.4% Artsy 팔로워 수
경력 단계 3.3% 신진/중견/원로

2.3 개별 작품 설명 예시

예시 1: Somin Kim — 범_Tiger (50호)

기준가 4,504,000원
↑ 작가 세대 +28.1% → 5,769,000원
↑ 크기(로그) +18.6% → 6,840,000원
↑ 면적 +18.2% → 8,084,000원
↑ 크기 곡선 +13.0% → 8,978,000원
↓ 총 작품수 -13.3% → 7,012,000원
예측가: 8,308,000원 실제가: 7,590,000원 (오차 9.5%)

예시 2: Suk Chuljoo — New-Scenery-in-Dream (40호, 원로)

기준가 4,504,000원
↑ 작가 세대 ← 1944년생 원로 +105.2% → 9,240,000원
↑ 경력 단계 +17.0% → 10,812,000원
↑ 그룹전 +10.1% → 11,901,000원
↑ 갤러리 +8.7% → 12,941,000원
↑ 아트페어 +8.5% → 14,044,000원
예측가: 17,574,000원 실제가: 16,560,000원 (오차 6.1%)

사용자에게 보여줄 형태:

40호 | 캔버스 유화
예측 가격: 17,574,000원
가격을 올린 요인
작가 세대 (원로) +105%

헤도닉 공식은 없지만, "이 가격이 왜 이 수준인지"를 %로 명확하게 설명할 수 있다.

4. 모델 운영 전략

4.1 데이터 주기적 학습

항목현재목표
Artsy 데이터 9,975건 (1회 수집) 월 1회 자동 갱신
작가 커버리지 Artue 362명 중 46명 매칭 (13%) 50%+
XGBoost 경로 비율 20% 50%+

작가 데이터가 많을수록 XGBoost 경로(MdAPE 9.8%)로 처리되는 비율이 올라간다. 현재 Artue 기준 20%만 XGBoost를 사용하지만, Artsy 매칭을 50%까지 올리면 전체 MdAPE가 크게 개선된다.

4.2 Cold Start 최소 입력

작가 정보가 없는 경우에도 예측은 가능하지만, 정보량에 따라 정확도가 달라진다:

보유 정보MdAPE비율
크기+매체만 55.9% 1.19x
+Birth Year 44.1% 1.13x
+Artsy 프로필 22.4% 1.05x

Birth Year 하나만 추가해도 11.8%p 개선. 사용자 입력 시 생년을 최우선으로 요청해야 한다.

4.3 SHAP 설명의 활용

  • 갤러리/작가 설득: "이 가격은 비슷한 세대 작가의 비슷한 크기 작품 기준입니다"
  • 가격 조정 근거: "갤러리 등급이 올라가면 가격이 +9% 상승합니다"
  • 모델 디버깅: 예측이 이상할 때 어떤 피처가 원인인지 즉시 파악

5. 용어 설명

SHAP (SHapley Additive exPlanations)
게임 이론의 Shapley Value를 머신러닝에 적용한 설명 방법. 각 피처가 예측에 기여한 정도를 공정하게 분배한다. 트리 모델에서는 TreeExplainer로 빠르게 계산 가능.
기준가 (Base Value)
전체 학습 데이터의 평균 예측값. SHAP은 이 기준가에서 출발하여 각 피처가 가격을 올리거나 내리는 형태로 분해한다. 현재 기준가는 약 450만원.
피처 기여도 (Feature Contribution)
개별 작품에서 특정 피처가 가격에 미치는 영향. "+105%"는 기준가 대비 2배 이상 올린다는 의미.
헤도닉 회귀 (Hedonic Regression)
ln(Price) = β&sub0; + β&sub1;×ln(크기) + β&sub2;×생년 + ... 형태의 선형 모델. 공식이 명확하지만, 비선형 관계와 조건부 인터랙션을 학습할 수 없어 정확도가 트리 모델 대비 20%p+ 낮다.
