## 🥇 P0-1: 갤러리 티어 v3 + 글로벌 인지도 피처

### 출처
- **Q2** (2026-04-26 17:28): 협력자 갤러리/기관 티어 리스트 v3 공유
- **Q10** (2026-04-24 14:38): 갤러리 유형 분류 / 서울 가중치 / 해외 갤러리

### 현황 (v3-filtered-tuned)
- 갤러리 피처군 6개 (`gallery_tier`, `has_seoul`, `gallery_type` 등) 합계 **2.5%** 중요도
- `gallery_tier`는 도시 수·평균가·작품 수 휴리스틱 (외부 입력 미반영)
- `has_seoul`은 단순 도시명 매칭 (지역 강한 갤러리 미반영)
- `has_international`은 해외/지방 구분 없음 (가고시안 vs 부산 갤러리 같은 처리)

### 액션
1. **`data/art_gallery_tier_list_v3.csv` 룩업 도입**
   - 89개 항목 + 미등재 fallback (Tier E)
2. **신규 피처**:
   - `gallery_tier_v3`: A~E (5단계, 협력자 리스트 직접)
   - `gallery_class`: 갤러리/기관/비영리/대안공간
   - `has_frieze_main`: Frieze 메인 섹션 참가
   - `has_artbasel_main`: Art Basel 본페어 참가
   - `is_global_megagallery`: 가고시안/페로탕/하우저 등
3. **기존 피처 정리**:
   - `has_seoul`: 제거 또는 보조 시그널로 강등
   - `gallery_tier` (휴리스틱): 보조 시그널로 유지
4. **데이터 재생성 + 재학습** (`prepare_primary_market_dataset.py` 갱신)
5. **calibrate_grade_margins.py 재실행** → 새 MdAPE 측정

### 예상 효과
- 갤러리 피처군 중요도 2.5% → 5~7%
- 전체 MdAPE A 12.2% → **10.5~11%** (1~2%p 개선)
- B 26.6% → **22~24%** (효과 더 클 수 있음, B는 갤러리 의존도 큼)

### 작업량
**2~3일** — 데이터 룩업 + 피처 빌더 수정 + 재학습 + ablation

### PR 이름
`feature/gallery-tier-v3`
