2. 목적과 방법론

2.1 본 cycle 의 의도

본 cycle 의 의도는 점진 표본 확대 기반 탐색 평가 — 작은 샘플 (작품 200건 / 작가 20명) 에서 빠르게 feature 및 모델 로직 후보를 좁히고, 단계적으로 더 큰 샘플로 확장하면서 유효한 후보만 통과시키는 방식. 트랙 2 의 cold-start (신규 작가) 가격예측 운영 baseline 에 대해 새 feature 후보군을 발굴하려는 시도.

2.2 방법론 (사후가설 회피 변형)

해당 ML 표준 방법론 명칭은 progressive sampling (점진 표본 확대) / multi-fidelity exploratory cycle (다단계 충실도 탐색) / pilot-then-confirmatory study (예비 후 확증). 본 트랙의 사전등록 및 재현 가능성 원칙에 맞춰 다음 변형을 적용:

  • 3분할 구성: 탐색 (Stage 1-3) → 개발 → 봉인된 확증용 holdout
  • 가설군 사전등록 (5개 군, 군별 변형 수 사전 고정)
  • 각 단계 통과 기준 사전 고정 (결과 본 후 임계 변경 금지)
  • 단계 간 진행 = 후보 탈락만 (모델 클래스·하이퍼파라미터·평가 규칙 변경 금지)
  • 탐색 결과 ≠ 확증 결과 명확 분리
방법론 거버넌스 / 검토 통제: - 사전 freeze (Phase 0 사전등록) — 6항목 (지표 / holdout / 가설군 명세 / 단계 규칙 / 파이프라인 / 결정 영향 분리)
- 봉인된 holdout — Phase 0 시점에 봉인, SHA-16 해시 기록, 마지막 단계 1회만 접근 권한
- 독립 체크포인트 검수 — 사전 freeze 자문 + 사후 체크포인트 검수 (주요 체크포인트, 양방향)
- 종료 기준 = 통과 기준 미달 시 단계 중단 / 결과 본 후 추론 변경 회피

통과 기준 (Stage 1, 탐색 단계 임계): Overall Δ ≤ -0.3%p AND Low Δ ≤ +0.2%p (baseline 대비). 통과 시 가설군별 best 1 (동률시 2) 선택 후 Stage 2 (작품 500건 / 작가 50명) 진입.

5. 해석

두 갈래의 신호가 일관됩니다.

  • 내부 feature 확장의 한계 신호: 본 cycle 직전 별도로 진행한 표본 크기 민감도 분석에서, 큐레이트된 작은 샘플 (작품 200-1,378건) 의 baseline MdAPE 24-27% 와 운영 분포 (작품 8,495건) 의 38.03% 사이 격차가 표본 크기보다 분포 조성 (composition) 차이 로 설명됨이 확인됐습니다. 즉 추가 표본 확대보다 정보축 자체의 부재가 1차 병목.
  • 본 cycle 의 통과 0건 결과: 평가 가능한 14개 변형 중 어느 가설군도 의사결정에 의미 있는 개선을 보이지 않음 — 대부분 변형이 악화 또는 0 부근 정체. 작은 샘플 noise 의 일반 패턴이지만, 동시에 현 정보 조건 내에서 추가 feature 재배열의 한계 정황도 됩니다.

따라서 내부 feature 추가 (Axis A continuation) 보다 외부 합법적 데이터 source 확보 (Axis B / license 우선) 가 정보 병목에 대한 더 직접적 대응이라는 동일한 의사결정 논리에서 본 cycle 종결 + Axis B 우선 진입을 결정합니다.
