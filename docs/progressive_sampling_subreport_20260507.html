2. Objective and Method

2.1 Why this cycle

본 cycle 의 의도는 점진 표본 확대 기반 탐색 평가 (progressive sampling exploratory evaluation) — 작은 샘플 (200x20) 에서 빠르게 feature/logic 후보를 좁히고, 단계적으로 더 큰 샘플로 확장하면서 유효한 후보만 통과시키는 방식. 트랙 2 의 cold-start 가격예측 baseline 에 대한 새 feature family 발굴 시도.

2.2 Method (HARK-safe variant)

표준 ML 방법론 명칭은 progressive sampling / multi-fidelity exploratory cycle / pilot-then-confirmatory study. 본 트랙의 사전등록 / 재현 가능성 기준에 맞춰 다음 변형 적용:

  • 3-way split: exploration (Stage 1-3) → development → locked confirmatory holdout
  • Pre-registered hypothesis families (5 families, variant cap 사전 고정)
  • Stage-별 retain rule 사전 고정 (post-hoc threshold 변경 금지)
  • Sequential = pruning only (단계 통과는 후보 탈락 / 모델 클래스·하이퍼파라미터·평가 규칙 변경 X)
  • Confirmatory language ≠ exploratory language 분리
Method governance / Review controls: - 사전 freeze (Phase 0 mini-prereg) — 6 항목 (KPI / holdout / family roster / stage rule / pipeline / decision-binding)
- Sealed holdout — Phase 0 시점 봉인, SHA-16 hash 기록, Phase 4 final 1회만 access 권한
- Independent post-run review — cycle 단계마다 외부 자문 검수 (사전 + 사후 양방향)
- Stop logic = retain rule 미달 시 단계 중단 / 결과 본 후 reasoning drift 회피

3.2 Stage 1 — 200 artworks / 20 artists

5 hypothesis families × 18 variants (4 variants SKIP — Stage 1 schema 부재):

  • Family A — Geometry variants: aspect ratio polynomial / aspect × is_3d / depth spline / max dim / full geometry
  • Family B — Temporal engineering: year × birth / career age / decade / age × area
  • Family C — Cross-artist categorical interactions: gallery × category / city × medium / attribution × 3D
  • Family D — Artist-level statistical features (negative control prereg): popularity / for-sale ratio / median proxy
  • Family E — Missingness / measurement-quality flags: year-made missing / depth missing / non-KRW proxy

Evaluation: 100-seed cold-start LAO (artist 20% holdout per seed). Baseline = F4 + spline + Huber regression (운영 채택 모델).

Retain rule (Stage 1, exploratory threshold): Overall Δ ≤ -0.3%p AND Low Δ ≤ +0.2%p (vs baseline). 통과 시 family 별 best 1 (tied 2) 선택 후 Stage 2 (500x50) 진입.

5. Interpretation

두 갈래 신호가 일관됩니다.

  • Internal feature ladder 의 한계 신호: 본 cycle 직전 별도 sample-size sensitivity 분석에서, 큐레이트된 작은 샘플 (200-1378 rows) 의 baseline MdAPE 24-27% vs 운영 분포 (8,495 rows) 의 38.03% 격차가 표본 크기보다 분포 조성 (composition) 차이로 설명됨이 확인됐습니다. 즉 추가 표본 확대보다 정보축 자체의 부재가 1차 병목.
  • 본 cycle 의 retain 0 결과: 5 family 모두 작은 샘플에서조차 추가 features 의 net effect 가 음 (개선) 이 아닌 양 (악화) 방향. 작은 샘플 noise 의 일반 패턴이지만, 동시에 현 정보 조건 내에서 추가 feature 재배열의 한계 정황도 됩니다.

따라서 Axis A continuation (내부 feature 추가) 보다 Axis B (외부 lawful source 확보) 가 information bottleneck 에 대한 더 직접적 대응이라는 동일 의사결정 logic 으로 본 cycle 종결 + Axis B 우선 진입을 결정합니다.
