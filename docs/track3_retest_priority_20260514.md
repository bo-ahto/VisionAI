# Track 3 재실험 우선순위 기록

- 날짜: 2026-05-14
- 목적: 기존 실험 중 다시 검증해야 하는 항목을 분리하고, 재실험 순서를 고정
- 기준: 기존 결과를 덮어쓰지 않고 새 실험 ID로 재검증

## 1. 재실험 판단 기준

- 기준 모델이 바뀐 경우
- 과거 실험이 현재 최적 후보와 비교되지 않은 경우
- 전체 성능은 좋아졌지만 특정 slice에서 악화가 큰 경우
- 탐색 실험 결과가 좋아 보이나 운영 가능성 또는 leakage 점검이 부족한 경우
- 데이터 컬럼 부족으로 당시 검증이 보류된 경우

## 2. 즉시 재실험 대상

| 재실험 ID | 연결 가설 | 재실험 이유 | 실행 방향 | 상태 |
|---|---|---|---|---|
| H31 | H17, H19-H22 | H19-H22 호수/크기 피처 실험은 Warm 기준값이 H17 최적 후보보다 약함 | H17 Warm champion에 호수/3D 피처를 추가해 다시 비교 | 완료 |

## 3. 후속 재실험 대상

| 대상 | 재실험 이유 | 현재 판단 |
|---|---|---|
| PR7 Warm 최고 기록 | `0.1031` Warm median APE는 가장 좋은 탐색 기록이나 release split / 운영 가능 피처 기준 재확인이 필요 | H33에서 재확인 완료, 최종 후보 대체 실패 |

| H18 interval calibration | 최종 모델 후보가 바뀌면 예측 구간도 다시 보정해야 함 | 최종 Warm/Cold 후보 확정 후 재실험 |
| H15 결측 패턴 | 현재 release split은 핵심 결측이 거의 없어 실제 결측 대응 검증이 약함 | 운영 입력 결측 샘플 또는 masking 정책 확정 후 재실험 |

## 4. 실행 순서

- 1순위: H31
- Warm 최적 후보 기준에서 호수/크기 파생 피처가 실제 추가 개선을 주는지 확인
- 결과: `0.1147 -> 0.1090`으로 개선
- 2순위: H32
- Cold 3D 개선을 전체 Cold 모델 교체가 아니라 조건부 적용으로 살릴 수 있는지 확인
- 결과: `0.3163 -> 0.2786`으로 개선, 2D 성능 유지
- 3순위: PR7 confirm
- 과거 최고 Warm 기록이 현재 문서 체계와 운영 가능 피처 기준에서도 유효한지 확인
- 결과: 운영 가능 PR7 피처 최고 `0.2251`, H31 `0.1090`보다 낮음
- 4순위: H18 재보정
- 최종 후보 모델 기준으로 가격 범위와 신뢰도 출력 정책 재계산

## 5. 기록 원칙

- 모든 재실험은 새 스크립트, 새 결과 JSON, 새 실험 기록 문서로 남김
- 기존 실험 결과는 보존
- 재실험 문서에는 반드시 아래 내용을 포함
- 재실험 이유
- 사용 피처
- 비교 기준
- Warm / Cold 결과
- slice 결과가 필요한 경우 slice별 결과
- 결론과 다음 작업
