## 1. 프로젝트 컨텍스트

### 1.1 전체 시스템에서의 위치

VisionAI 플랫폼은 4개 핵심 모듈로 구성되며, 가격 예측 AI는 모든 모듈의 핵심 데이터 파이프라인 역할을 담당한다.

| 모듈 | 기능 | 가격 예측 AI 연동 |
|------|------|-------------------|
| M1 시세 가이드 | 작가·호수별 시세 범위 제공 | 예측 모델의 가격 구간이 직접 노출됨 |
| M2 작가 성장 | 작가 활동·관심도·가격 추이 | 가격 추이 차트에 예측값 반영 |
| M3 작품 추천 | 취향 기반 작품 추천 | 시세 맥락 코멘트에 예측 가격 활용 |
| M4 경매 최적화 | 리스팅 전략·시작가 권장 | 권장 시작가/기대 낙찰 구간 산출의 핵심 |

### 1.2 목업 분석 요약

현재 구현된 목업(frontend/index.html)을 분석한 결과, 가격 예측 AI의 결과가 사용되는 주요 UI 지점은 다음과 같다.

**M1 시세 가이드 (3개 페이지)**
- m1-main: 작가/호수 선택 → 시세 조회 입력 UI
- m1-result: 대표 가격대 구간(200~300만원), 호당 시세 감각, 데이터 신뢰도 표시
- m1-input: 내 작품 정보 입력 후 시세 범위 내 위치 추정(예: 180~300만 원 범위에서 250만 원 위치)

**M2 작가 성장 (가격 관련 부분)**
- m2-profile: 20호 기준 예측 가격 구간(200~300만) 요약
- m2-activity: 분기별 가격 추이 차트(bar chart), 관심도와 가격 동시 시각화

**M3 작품 추천 (가격 관련 부분)**
- m3-detail: 비슷한 작품군 가격대, 최근 거래 동향(+10% 상승 추세)
- m3-insight: 시장 기준 가격 범위 대비 포지셔닝, 유사 작품 비교

**M4 경매 최적화 (핵심 의존)**
- m4-dashboard: 추천 시작가 구간, 리스팅 현황 테이블
- m4-strategy: 권장 시작가 구간(220~240만), 기대 낙찰 구간(230~280만)
- m4-analysis: 권장 구간 대비 실적 위치 분석

### 1.3 목업에서 도출된 예측 모델 요구사항

목업 UI에서 필요로 하는 예측 출력값을 정리하면 다음과 같다.

| 출력값 | 사용처 | 설명 |
|--------|--------|------|
| 가격 구간 (min~max) | M1 결과, M2 프로필 | 작가+호수 기준 대표 가격대 |
| 호당가 | M1 결과 | 호수 단위 가격 감각 |
| 가격 추이 (시계열) | M2 활동 흐름 | 분기별 예측 가격 변화 |
| 유사 작품 가격 비교 | M3 인사이트 | 유사 조건 작품 대비 위치 |
| 권장 시작가 구간 | M4 전략 | 경매 시작가 최적 구간 |
| 기대 낙찰 구간 | M4 전략 | 기대 거래 완료 가격 |
| 신뢰도 등급 | M1, M2 | 데이터 충분성 기반 신뢰도 |
| 시세 내 포지셔닝 (%) | M3 인사이트 | 시세 범위 내 상대 위치 |

## 2. 개발 일정 산정서 기반 태스크 분해

기능 명세서 및 도메인 개발 일정 산정서를 기반으로, 가격 예측 AI의 세부 태스크를 5개 Phase로 재구성한다.

### Phase 1: 데이터 수집 및 구축 (약 40일)

| 태스크 | AI SP | BE SP | 총 일수 | 산출물 |
|--------|-------|-------|---------|--------|
| 데이터 수집 설계 | 40 | 0 | 40 | 수집 스키마, 데이터 소스 목록 |
| 데이터 크롤러 개발 | 0 | 80 | 80 | 경매 데이터 크롤러 |
| 수집 데이터 전처리 및 정제 | 40 | 20 | 60 | 정제된 학습 데이터셋 |
| 가격 영향 요인 수집 및 데이터 구축 | 40 | 40 | 80 | 피처 데이터베이스 |

**핵심 데이터 소스 (예상)**
- 공개 경매 낙찰 데이터 (경매사 API/크롤링)
- 거래 제안 데이터 (플랫폼 내부)
- 작가 활동 데이터 (전시, 언론, 수상 이력)
- 작품 메타데이터 (크기, 재료, 제작연도, 장르)
- 플랫폼 관심도 지표 (조회, 저장, 문의)

**주요 피처 후보**
- 작가 피처: 경력 연수, 전시 횟수, 수상 이력, 학력, 소속 갤러리
- 작품 피처: 호수, 재료, 장르, 제작연도, 시리즈 여부
- 시장 피처: 최근 거래가, 거래 빈도, 관심도 지표, 시즌 정보
- 비교 피처: 동세대 작가 평균 호당가, 동장르 평균가

### Phase 2: 탐색적 분석 및 가설 검증 (약 30일)

| 태스크 | AI SP | BE SP | 총 일수 | 산출물 |
|--------|-------|-------|---------|--------|
| 가격 영향 요인 가설 수립 | 80 | 0 | 80 | 가설 문서, 피처 중요도 분석 |
| 상관관계 분석 | 80 | 0 | 80 | 상관관계 리포트, 피처 선정 |

**수행 내용**
- EDA(탐색적 데이터 분석): 가격 분포, 이상치 탐지, 결측치 패턴 확인
- 가설 수립: "작가의 전시 횟수 증가 → 호당가 상승" 등 구체적 가설 리스트
- 피처 상관관계 분석: Pearson/Spearman 상관계수, 다중공선성 검토(VIF)
- 시계열 패턴 분석: 분기별/연도별 가격 변동 추세, 계절성 확인
- 피처 중요도 평가: Permutation importance, SHAP value 기반 피처 랭킹

### Phase 3: 모델 설계 및 학습 (약 30일)

| 태스크 | AI SP | BE SP | 총 일수 | 산출물 |
|--------|-------|-------|---------|--------|
| 가격 예측 모델 설계 | 80 | 0 | 80 | 모델 아키텍처 문서 |
| 가격 예측 모델 학습 및 튜닝 | 120 | 0 | 120 | 학습된 모델, 실험 로그 |

**모델링 전략**

목업에서 요구하는 출력 형태를 고려한 모델 설계 방향:

**(A) 베이스라인 모델**
- Linear Regression / Ridge / Lasso → 기본 가격 예측
- 목적: 빠른 성능 확인, 피처 중요도 해석

**(B) 고도화 모델 (기능 명세서 명시)**
- GBM (Gradient Boosting Machine) / CatBoost / LightGBM
- 목적: 비선형 관계 포착, 카테고리 피처 처리 우수
- CatBoost는 카테고리 변수(작가명, 장르, 재료 등)가 많은 본 도메인에 적합

**(C) 구간 예측 모델 (목업 요구사항 반영)**
- Quantile Regression → 가격 구간(하위~상위) 예측
- 목업의 "200~300만원대" 같은 구간 출력에 필수
- 10th, 25th, 50th, 75th, 90th percentile 예측

**(D) 시계열 가격 추이 모델**
- 분기별 가격 추세 예측 (M2 활동 흐름 차트용)
- 시계열 split 기반 학습/검증 (기능 명세서 명시)

**평가 지표**
- MAPE (주 성과지표, 기능 명세서 명시)
- MAE, RMSE (보조 지표)
- Coverage Rate (예측 구간 내 실제값 포함률)
- 목표: MAPE 15% 이하 (신진작가 데이터 특성상 도전적 목표)

**실험 관리**
- Weights & Biases 활용 (Tech Stack 명시)
- 실험 버전 관리, 하이퍼파라미터 로깅, 성능 비교 대시보드

### Phase 4: API 구축 (약 10일)

| 태스크 | AI SP | BE SP | 총 일수 | 산출물 |

| 예측 결과 API 개발 | 0 | 40 | 40 | REST API, API 문서 |

**API 엔드포인트 설계 (목업 기반)**

```
# 시세 가이드 조회 (M1)
POST /api/v1/price/estimate
Request: { artist_id, ho_size }
Response: {
  price_range: { min, max, median },
  price_per_ho: { min, max },
  confidence_level: "high" | "medium" | "low",
  data_count: int,
  similar_artists_comparison: { ... }
}

# 가격 추이 조회 (M2)
GET /api/v1/price/trend?artist_id={}&ho_size={}&period={}
Response: {
  quarterly_prices: [{ quarter, predicted_price, interest_score }],
  trend_direction: "up" | "stable" | "down"
}

# 작품 시세 포지셔닝 (M3)
POST /api/v1/price/position
Request: { artist_id, artwork_info: { size, material, year } }
Response: {
  market_range: { min, max },
  estimated_position: float,
  percentile: int,
  similar_artworks_avg: float
}

# 경매 시작가 권장 (M4)
POST /api/v1/price/auction-recommend
Request: { artist_id, artwork_info, auction_type }
Response: {
  recommended_start_range: { min, max },
  expected_final_range: { min, max },
  timing_suggestion: string,
  confidence_level: string
}
```

## 6. 리스크 및 대응 방안

| 리스크 | 영향도 | 대응 방안 |
|--------|--------|-----------|
| 신진작가 거래 데이터 부족 | 높음 | 유사 작가 클러스터링으로 데이터 보강, 신뢰도 등급으로 불확실성 명시 |
| 가격 분포 편향 (저가 집중) | 중간 | 로그 변환, 가격대별 층화 샘플링 적용 |
| 비공개 거래 미반영 | 중간 | 공개 데이터 기반 한계 명시, 플랫폼 내부 데이터 보완 |
| MAPE 목표 미달성 | 높음 | 단계적 목표 설정(25%→20%→15%), 앙상블로 점진 개선 |
| 모델 드리프트 | 중간 | 정기 재학습 파이프라인, 드리프트 모니터링 셋업 |
| Inference 시간 초과 | 낮음 | ONNX 변환, 캐시/배치 사전계산(기능 명세서 명시) |
