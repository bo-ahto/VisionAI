## 4. 핵심 원칙

- 원본값은 보존함
- 표준화값은 별도 컬럼으로 생성함
- 파생 피처는 표준화값 검증 후 생성함
- row 삭제보다 flag와 제외 사유를 우선함
- 모든 클렌징 규칙은 원본 row로 추적 가능해야 함

## 5. 클렌징 우선순위

- 1순위: 가격
- 2순위: 크기
- 3순위: 작가명
- 4순위: 재료/지지체
- 5순위: 중복
- 6순위: 갤러리/출처 메타

## 6. 클렌징 가설

- T4-C1: 가격 정합성
- T4-C2: 크기 정합성
- T4-C3: 재료/지지체 정합성
- T4-C4: 작가명 정합성
- T4-C5: 중복 정합성
- T4-C6: 출처 편향 점검
- source는 모델 입력 피처로 사용하지 않고 품질관리/원본추적 용도로만 사용
- T4-C7: 갤러리 메타데이터
