# T4-E027 2D/3D slice 및 depth 피처 실험

- 실험 ID: `T4-E027`
- 연결 가설: `T4-H8`, `T4-H16`, `T4-H27`
- 날짜: 2026-05-17
- 상태: 완료

## 1. 실험 목적

- 3D/depth 관련 피처가 가격 예측에 도움이 되는지 확인함
- depth/volume 피처를 전체 작품에 일괄 적용해도 되는지 확인함
- 3D 작품에만 별도 모델을 적용하는 조건부 fallback이 효과적인지 확인함

## 2. 확인하려는 질문

- 3D 작품은 2D 작품보다 오차가 큰가
- depth/volume/longest edge 피처를 전체에 넣으면 성능이 개선되는가
- 3D 후보에만 depth 피처 모델을 적용하면 Cold 성능이 개선되는가
- 3D 조건부 fallback이 큰 오차 위험까지 줄이는가

- 학습 데이터: `data/track4_split/track4_train.csv`

## 4. 사용 모델

- Warm 모델
- `Ridge`
- 구조 피처 + 작가 key + 작가 이력 + support 사용
- Cold 모델
- `QuantileRegressor`
- 작가 피처 제외
- support는 제외

## 5. 비교 전략

- `base_no_depth`
- `log_area`, `aspect_ratio` 중심의 기본 크기 피처
- `global_depth_features`
- `depth_cm_filled`, `log_volume`, `longest_edge_cm`를 전체 작품에 일괄 추가
- `conditional_3d_fallback`
- 2D는 기본 모델 사용
- 3D는 depth 피처 포함 모델 사용

## 9. Cold 결과

| 전략 | 전체 median APE | 전체 p95 APE | 2D median APE | 2D p95 APE | 3D median APE | 3D p95 APE |
|---|---:|---:|---:|---:|---:|---:|
| base_no_depth | 0.3642 | 1.1421 | 0.3529 | 1.1421 | 0.8286 | 1.4093 |
| global_depth_features | 0.3635 | 1.1255 | 0.3516 | 1.1222 | 0.8348 | 1.5980 |
| conditional_3d_fallback | 0.3545 | 1.1015 | 0.3464 | 1.0948 | 0.6106 | 6.7154 |

## 10. 해석

- Cold 3D는 기본 모델에서 median APE `0.8286`으로 2D `0.3529`보다 훨씬 어려움
- depth 피처를 전체에 일괄 적용해도 Cold 전체 median APE 개선은 매우 작음
- 조건부 3D fallback은 Cold 전체 median APE를 `0.3642`에서 `0.3545`로 개선함
- 조건부 3D fallback은 Cold 3D median APE를 `0.8286`에서 `0.6106`으로 개선함
- 하지만 조건부 3D fallback은 Cold 3D p95 APE를 `1.4093`에서 `6.7154`로 크게 악화시킴
- 즉, 일부 3D 작품에는 도움이 되지만 큰 오차 위험을 키우는 문제가 있음

## 11. 결론

- 채택 / 보류 / 중단: 보류
- 판단:
- `T4-H8`: 3D 작품은 별도 관리가 필요하다는 점은 지지됨
- `T4-H16`: depth 피처 전체 일괄 적용은 강하게 지지되지 않음
- `T4-H27`: 조건부 3D fallback은 median APE 개선 신호가 있지만 tail risk 악화로 바로 채택 불가
- 운영 후보:
- 3D 여부는 위험 flag로 유지
- 3D 전용 모델은 큰 오차 방지 조건을 추가한 뒤 재검증
