# T4-E052 피처 실험 누락 최종 감사

- 날짜: 2026-05-17
- 관련 가설: T4-H39
- 상태: 완료
- 목적: Track 4 피처 선정 과정에서 빠진 실험이 있는지 최종 점검

## 1. 감사 기준

- 제안한 피처가 실제 모델 실험까지 연결되었는가
- Warm / Cold를 분리해서 확인했는가
- validation에서 좋아 보인 결과를 test에서도 확인했는가
- 최종 모델 기준으로 다시 확인했는가
- 운영에서 만들 수 없는 피처는 제외했는가

## 2. 피처 실험 감사표

| 피처 영역 | 확인한 실험 | 현재 상태 | 판단 |
|---|---|---|---|
| 기본 작품 구조 피처 | T4-E023 | 완료 | 구조-only baseline 확인 |
| 작가 key / 작가 이력 | T4-E024, T4-E037, T4-E044 | 완료 | Warm 핵심 피처로 유지 |
| 작가 train 가격 통계 | T4-E044, T4-E045, T4-E049 | 완료 | 조건부 허용, Warm 최종 유지 |
| 지지체 피처 / unknown 처리 | T4-E026 | 완료 | Warm은 유지, Cold는 직접 입력보다 위험 신호로 해석 |
| 크기 피처 축소/확장 | T4-E033 | 완료 | Warm은 대표 조합, Cold는 full-size 유지 |
| 재료 세분화 | T4-E032 | 완료 | 개선 폭 작아 최종 미채택 |
| 재료-크기 조합 피처 | T4-E035, T4-E051 | 보완 완료 | 최종 모델 기준 test 개선 없어 미채택 |
| 3D/depth/volume 후보 | T4-E027 | 완료 | 전체 적용은 보류, 위험 구간 관리로 사용 |
| Warm/Cold 라우팅 threshold | T4-E029 | 완료 | 작가 존재 여부 기준 유지 |
| 가격 범위/신뢰도 피처 | T4-E031, T4-E039, T4-E040, T4-E041, T4-E042 | 완료 | Warm 범위 가능, Cold는 low_risk 제한 |
| 금지 피처/source/gallery 검사 | T4-E034, T4-E036 | 완료 | 모델 입력 제외 원칙 유지 |
| Warm 최종 피처셋 모델 비교 | T4-E047, T4-E049 | 보완 완료 | RandomForest로 교체 |
| Cold 최종 피처셋 모델 비교 | T4-E050 | 보완 완료 | Quantile 유지 |

## 3. 생성 피처 조합 확인

- 생성 피처 조합 실험은 있었다.
- 기존 실험:
  - T4-E035
  - Warm Ridge, Cold Huber 기준
- 보완 실험:
  - T4-E051
  - Warm RandomForest, Cold Quantile 기준
- 최종 판단:
  - 생성 조합 피처는 최종 모델 기준 test median APE를 개선하지 못했다.
  - 최종 입력 피처에는 추가하지 않는다.
  - 분석용 보조 피처로만 남긴다.

## 4. 현재 기준 누락 여부

- 최종 모델 확정에 필요한 핵심 피처 실험 누락은 현재 기준으로 없다.
- Warm 비선형 모델 비교 누락은 T4-E047/T4-E049로 보완했다.
- Cold 최종 피처셋 모델 비교 누락은 T4-E050으로 보완했다.
- 생성 피처 조합 최종 모델 재검증 누락은 T4-E051로 보완했다.

## 5. 후속 아이디어이지만 현재 누락은 아닌 항목

- 작가 DB가 추가되면 전시/수상/소장 이력 기반 피처를 새 가설로 추가할 수 있다.
- 같은 재료 안에서 상대적 크기 순위 피처를 추가로 검토할 수 있다.
- 정보 완성도 점수를 모델 입력으로 직접 넣는 실험은 후속으로 가능하다.
- Cold 가격 범위 폭을 줄이려면 현재 작품 구조 피처보다 외부 작가 정보가 더 중요할 가능성이 높다.

## 6. 결론

- 피처 선정 과정에서 확인 가능한 주요 누락은 보완되었다.
- 최종 피처는 성능, 운영 가능성, 재현 가능성을 기준으로 현재 구성을 유지한다.
- 추가 피처 실험은 “현재 누락 보완”이 아니라 “성능 추가 개선” 목적의 후속 가설로 분리하는 것이 맞다.
