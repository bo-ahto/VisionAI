트랙 2 (해석 가능 모델) — 임원 1페이지 요약

작성일: 2026-05-06 · 대상: 대표 보고용 · 상세 보고서: docs/트랙2_최종보고서_20260506.md

핵심 결과 한 줄
3개 변수만으로 V3 운영 모델의 신규 작가 약점 (28-48%) 을 24-27% 까지 개선. 단계적 운영 도입 가능 수준 도달.

1. 무엇을 했나

  • 해석 가능한 hedonic 회귀 모델 개발 — 변수별 가격 기여 설명 가능
  • 현재 V3 운영 모델 (32 features GBM 블랙박스) 의 신규 작가 약점 보완 목적
  • Stage 1 (200) → Stage 2 (500) → Stage 3 (1,378) 단계 검증 완료

2. 모델 (3개 변수)

가격 = f(작품 크기, 작가 세대, 작가 생산성) + 작가별 고유 효과
변수의미가격 영향
작품 면적작품의 크기면적 1% ↑ → 가격 +0.78%
작가 출생년작가의 세대 (시장 위상)1년 늦을수록 -5%
작가 총작품수활동량 / 시장 안정성2배 ↑ → +5%

3. 운영 모델 (V3) 대비 비교

시나리오 V3 (32 features GBM) 트랙 2 (3 features) 판정
학습량 충분 작가 (≥ 10건) 12-18% 21-22% V3 유지
신규 작가 (학습량 부족) 28-48% 24-27% 트랙 2 우수 ⭐
이원 전략 통합 (시뮬레이션) — 22.30 ~ 25.18% 도입 가능

※ 30-seed LAO holdout / Bootstrap 95% CI [24.21, 28.45]. 단위는 MdAPE (예측 오차 중앙값 %).

4. 운영 도입 권고 — 이원 전략

입력 작품
  ↓
작가가 학습 데이터에 충분히 있나? (≥ 10건)
  ├─ YES (기존 작가) → V3 유지       (정확도 12-18%)
  └─ NO  (신규 작가)  → 트랙 2 도입  (정확도 ~27%, V3 대비 -1 ~ -21%p ↓)

전면 교체 아닌 보완 도입. V3 의 강점 (기존 작가 정확도) 유지 + 트랙 2 의 강점 (신규 작가 정확도 + 해석성) 추가.

5. 가치 / 한계

✅ 가치
  • 신규 작가 가격 예측 정확도 -4 ~ -20%p 개선
  • 가격 결정 요인 3축으로 명확하게 설명 가능
  • 변수 부호 일관성 100% (재현성 ↑)
  • 해석 가능 모델 → 의사결정 / 보고 용이
⚠️ 한계 / 가드레일 필요
  • 저가 작품 (< 5M원): 35.96% (편향 큼)
  • 먹/잉크 매체: 32.94% (표본 적음)
  • 중간 등급 갤러리: 28.12% (변동 큼)
  • → 위 segment 는 별도 보정 / 사람 검토 필요
