4.3 변경 패턴 해석

HP 변경 시그니처:
- ✅ 더 깊은 tree (depth 7→9) + 큰 step (lr 3.1×) + 빠른 종료 (boost 0.32×): aggressive learning
- ✅ min_child_weight 11×: leaf 수준에서 강한 sample-size 제약 (overfitting 방지) — depth↑ 보완
- ✅ L1/L2 reg 약화: 모델 capacity 증가 (data가 충분 → reg 적게 필요)
→ 종합: warm slice (n=27,062 / artist 가격 분포 학습됨)에서 tree depth + leaf regularization 위주로 capacity 재조정.

7.2 활성화 절차 (Stage 3)

  1. shadow logging activate: PR2B-prereq.1 dual-logging 인프라 위에 MODEL_VARIANT_SHADOW=v3_filtered_tuned_b_warm 설정 (또는 dual-prediction config flag)
  2. predict_logs DDL: variant 컬럼에 b_warm prediction 동시 기록
  3. 일별 metric report:
    • per-day median Δ_warm (b_warm − default)
    • per-source Δ_warm (artsy_gallery / artsy_online / saatchi_online)
    • error rate / latency comparison
  4. 7-day sign-off 기준:
    • ✅ 7-day aggregate Δ_warm ≤ -0.8pp
    • ✅ 5/7 daily medians Δ_warm ≤ -0.5pp
    • ✅ no day Δ_warm > +0.3pp
    • ✅ no latency degradation (>+5%) / no error rate spike

7.3 Canary (Stage 4)

Cohort key: artist_slug hash (artist 단위 일관 split / R1 amendment 정합) / fallback request_id.

  1. 10% canary / 24시간 / metric OK 확인
  2. 50% canary / 24시간 / metric OK 확인
  3. 100% canary / 24시간 / metric OK 확인

Sign-off: canary ≤ control + 0.3pp / latency ≤ +5% / 만족 시 Stage 5 진입.

7.4 Full migration (Stage 5)

  1. DEFAULT_VARIANT = "v3_filtered_tuned_b_warm" 변경 → 100% user 영향 시작
  2. 1주 안정 모니터링
  3. fallback artifact 보존 결정 (integrated_v3_filtered_tuned_* / rollback path)
  4. (선택) warm_factors 재추정 cycle

7.5 Rollback path

모든 단계 reversible:
1. MODEL_VARIANT 또는 DEFAULT_VARIANT 을 v3_filtered_tuned로 revert
2. Process restart / reload — predictor cached model swap 보장
3. Smoke check: predictor.variant == "v3_filtered_tuned" 확인
4. artifact retention: 모든 b_warm artifact 파일 삭제 X (rollback 가능 상태 유지)
5. DB schema (predict_logs.variant 컬럼) 변경 X / metrics schema 변경 X
