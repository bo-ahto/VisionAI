1. 한 문단 요약

warm slice에 포함된 작가 30명 (양쪽 학습·Artsy만·Saatchi만 각 10명)을 대상으로, 같은 작품의 다른 모든 입력은 그대로 두고 출처 라벨만 Artsy ↔ Saatchi로 플립하여 가격 예측 차이를 측정한 결과 — 30명 모두 변화율이 ±1.5% 이내였고 24명(80%)이 ±0.5% 이내였습니다. 평균 변화는 코호트별로 −0.33% ~ +0.02% 수준으로, 측정 노이즈에 가깝습니다. 학습 작품 수 50점 이상 작가는 변화율 최대가 0.27%로 사실상 라벨에 무관했고, 5~9점 경계선 작가에서만 1% 안팎 변화가 관찰되었습니다. 결론: 학습량이 충분한 작가에 대해서는 출처가 가격 예측의 주요 단서로 작용하지 않습니다.

2. 왜 이 실험을 했나

1차 시장 모델(integrated_v3_filtered_tuned)은 두 출처에서 가져온 데이터로 학습합니다.

출처설명학습 건수
Artsy갤러리 기반 미술품 정보 사이트7,640
Saatchi작가 직판 온라인 마켓 (전량 online)21,721
합계29,361

모델은 학습 시점에 각 작품의 source ∈ {artsy, saatchi} 라벨을 categorical 피처로 함께 봅니다. 추가로 cold path 예측에는 source × target_market 셀별 후처리 보정(median-ratio cell calibration)을 곱합니다.

이 구조에서 자연스러운 의문이 발생합니다.

❓ 콜론30 의문 (2026-04-29)

"데이터 출처별 차이가 생기는 게 아닌지 궁금합니다. 작가 10명 정도만 다른 건 다 동일하게 하고 출처(Artsy랑 Saatchi만 바꿔서) 결과를 볼 수 있을까요?"

의문의 핵심: 같은 작품에 대해 출처 라벨만 바꿔도 예측이 달라진다면, 모델이 출처에 따라 편향된 판단을 한다는 의미. 달라지지 않는다면, 작품 자체 특성으로 가격을 결정하고 있다는 의미입니다.

3. 실험 설계 — 어떻게 측정했나

3.1 작가를 3개 코호트로 분류

학습 데이터에서 작가가 어느 출처에 등장했는지 (작가 이름 정규화 매칭 기준) 에 따라 3개 그룹으로 나눴습니다.

코호트의미후보 풀선정 인원
A. 양쪽 학습Artsy와 Saatchi 양쪽 모두 충분히(warm) 학습된 작가10명10명
B. Artsy만 warmArtsy에서만 충분히 학습. Saatchi 측 작품이 없거나 1~2점만 있어 warm 미달380명10명
C. Saatchi만 warmSaatchi에서만 충분히 학습. Artsy 측 작품 없음506명10명

※ "충분히 학습됨(warm)"의 기준: 학습 시점 해당 작가의 artist_slug가 warm slice (≥5건)에 포함되어 정밀 모델(XGBoost)에 들어간 경우. 한 작가가 양쪽에 작품이 있어도 한쪽이 1~2점이면 그쪽은 cold로 분류되어 본 실험 코호트는 한쪽 warm만 인정합니다.

3.2 작품 선정 — 작가별 대표 1점

각 작가의 작품 중 ln_price 중앙값에 가장 가까운 1점을 대표로 선정했습니다. 극단가(아주 비싸거나 싼 작품)를 피해 그 작가의 일반적인 가격대를 측정하기 위함입니다.

3.3 출처 라벨만 바꿔 두 번 예측

작품의 모든 features (크기·재료·작가 신상·갤러리·발견자 통계 등 32개)를 그대로 고정한 채, 모델 입력의 source 항목 하나만 변경하여 두 번 예측을 돌렸습니다.

1차 예측: features + source = "artsy"   → price_artsy
2차 예측: features + source = "saatchi" → price_saatchi

변화율(delta%) = (price_saatchi − price_artsy) / price_artsy × 100
ratio          = price_saatchi / price_artsy

0%·1.0이면 라벨 무관, +값은 saatchi 라벨이 더 높게, −값은 saatchi 라벨이 더 낮게 예측한다는 뜻입니다.

5. 핵심 발견 3가지

발견 1 — 출처 라벨의 영향은 사실상 없습니다 (warm 한정)

warm 작가 30명 모두 변화율이 ±1.5% 이내였고, 24명(80%)은 ±0.5% 이내였습니다. 이는 모델 출력의 일반적인 측정 노이즈 수준입니다.

발견 2 — 학습량이 많을수록 영향이 더 작아집니다

총 학습량 (Artsy + Saatchi 합산, 이름 기준) 구간별로 |변화율| 통계를 보면 명확합니다.

총 학습량 (a + s) 인원 평균 |변화율| 최대 |변화율|
50작품 이상60.14%0.27%
20~49작품70.48%1.29%
10~19작품90.25%0.79%
5~9작품80.52%1.48%

50작품 이상 학습된 작가는 평균 0.14% / 최대 0.27%로 사실상 라벨 무관합니다. 5~9작품 경계선 작가에서만 1% 안팎 변화가 관찰됩니다.

발견 3 — 변화 방향이 무작위 → 모델은 출처를 직접 신호로 쓰지 않음

"Artsy에서 학습된 작가는 artsy 라벨일 때 더 높게, Saatchi에서 학습된 작가는 saatchi 라벨일 때 더 높게 나오지 않을까" 라는 직관과 다르게, 부호 분포가 일관되지 않습니다.

  • 코호트 A (양쪽 warm): saatchi 라벨로 낮아짐 7명, 높아짐 2명, 동일 1명
  • 코호트 B (Artsy만 warm): saatchi 라벨로 낮아짐 5명, 높아짐 2명, 동일 3명
  • 코호트 C (Saatchi만 warm): saatchi 라벨로 낮아짐 4명, 높아짐 4명, 동일 2명 (4:4 분할)

이는 모델 내부의 출처 categorical 임베딩이 작가별 특징(career_stage, ln_followers, artist_total_works 등)에 비해 주변적 신호로 작용함을 시사합니다.

6. 참고 — cold 작가에서는 영향이 더 큽니다

본 보고서의 메인 결론(±1.5% 이내)은 warm 작가에 한정됩니다. 학습량이 부족한 cold 작가에 대해 별도로 동일 실험을 진행했을 때, 결과는 크게 달라집니다.

7. 결과 해석 시 주의사항

  • 표본 크기: 코호트당 10명, 총 30명. 통계적 강도를 위해선 코호트당 30~50명 이상이 권장되지만, 관찰된 효과 크기가 매우 작아(±1.5% 이내) 표본을 늘려도 결론 방향이 바뀔 가능성은 낮습니다.
  • 측정 대상은 "모델 출력의 차이": 두 라벨 중 어느 쪽이 정답에 더 가까운지(정밀도)를 측정한 것은 아닙니다. 모델이 라벨에 따라 다른 답을 내는지 여부만 확인했습니다. 정밀도 평가는 별도 실측 비교가 필요합니다.
  • WARM_ONLY 필터: 메인 결론은 warm slice에 포함된 작가에 한합니다. cold 작가에 대해서는 §6 참조.
  • target_market='online' 고정: Saatchi 학습이 100% online이라는 데이터 제약 때문입니다. gallery 시장 작품은 별도 분석이 필요하며, 현재로선 Artsy 학습 분포 내에서만 비교 가능합니다.

8. 콜론30 전달용 결론 한 페이지

Q. 데이터 출처별 차이가 생기는 게 아닌지 궁금합니다.

A. 학습량이 충분한 작가(warm)에 대해서는 출처 라벨(Artsy/Saatchi)을 바꿔도 예측가가 사실상 동일합니다.

warm 작가 30명 (양쪽 학습 10명 + Artsy만 warm 10명 + Saatchi만 warm 10명) 을 대상으로, 같은 작품의 다른 모든 입력은 그대로 두고 출처 라벨만 바꿔 예측한 결과:

  • 30명 모두 변화율이 ±1.5% 이내
  • 30명 중 24명(80%)이 ±0.5% 이내
  • 학습량 50작품 이상 작가는 ±0.3% 이내
  • 변화 방향(높아짐/낮아짐)도 작가별로 무작위 → 모델이 출처를 가격의 직접 신호로 사용하지 않음

다만 학습량이 매우 적은 cold 작가에서는 영향이 −8 ~ −16%까지 커질 수 있습니다. 이는 모델이 본인 신호 부족 시 출처 라벨을 보조 단서로 활용하기 때문이며, 후처리 cell calibration으로 일부 완화하고 있으나 완전 제거는 아닙니다 (알려진 잔여 한계).

9. 용어 풀이

용어풀어 쓰면본 문서에서의 의미
코호트 (cohort)—비슷한 조건으로 묶은 작가 그룹. 본 실험에선 학습 데이터 출처 등장 패턴별 3그룹.
warm / cold—warm = 학습 시 ≥5건 작품이 있던 작가 (정밀 모델 XGBoost 라우팅), cold = 신규 작가 또는 학습 부족 (CatBoost 라우팅).
학습량 (a / s)—"작가 이름 매칭 기준 Artsy 학습 작품 수 / Saatchi 학습 작품 수". 예: 10 / 16 = Artsy 10작품, Saatchi 16작품.
변화율 (delta%)—(price_saatchi − price_artsy) / price_artsy × 100. +값 = saatchi 라벨이 더 높음, −값 = 더 낮음.
ratio—price_saatchi / price_artsy. 1.0이면 동일.
p10/p25/p50/p75/p90quantile (분위수)값을 정렬했을 때 하위 X% 위치 값. p50 = 중앙값.
cell calibration(source × target_market) cell-based calibrationcold path 모델 출력 후, 출처와 시장 조합별로 학습된 평균 편향을 곱셈으로 보정. PR #21에서 도입.
target_market—그 작품이 어떤 시장에서 팔리는지: online 또는 gallery. 본 실험은 online 고정.
OODOut-Of-Distribution학습 데이터에 없는 분포. saatchi_gallery 셀이 OOD.
