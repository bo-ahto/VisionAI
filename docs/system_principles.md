## 1. 개요

### 한 문장 요약

> **이 시스템은 경매사가 매기는 "추정가" 없이, 작품의 객관적 속성(작가, 크기, 재료, 과거 거래 이력 등)만으로 미술품의 낙찰 가격 범위를 예측한다.**

### 핵심 질문

미술품 경매에는 항상 경매사가 제시하는 **추정가**(Estimate)가 있다. 추정가는 전문가의 경험, 유사 작품 거래, 시장 분위기를 압축한 강력한 정보다. 추정가를 입력으로 넣으면 예측 정확도가 R² = 0.93(거의 완벽)에 달한다.

그런데 **추정가가 아직 정해지지 않은 상황**에서 가격을 알고 싶다면? 예를 들어:
- 위탁 전에 "이 작품이 얼마에 팔릴까?" 미리 알고 싶을 때
- 경매사의 추정가가 합리적인지 검증하고 싶을 때
- 새로운 작가의 작품 가치를 빠르게 가늠하고 싶을 때

이 시스템은 바로 그 문제를 풀기 위해 만들어졌다.

### 전체 파이프라인

```
                        입력: 작가명, 크기, 재료, 경매 타입
                                    |
                    +---------------v----------------+
                    |      49개 피처 생성기            |
                    |  (작가 이력, 물리 속성, 시장 등)   |
                    +---------------+----------------+
                                    |
               +--------------------+--------------------+
               |                                         |
      +--------v---------+                    +----------v----------+
      |    Model-A        |                    |     Model-B          |
      | (가격 범위 예측)    |                    |  (추정가 재현)        |
      | q25 / q50 / q75   |                    | low / mid / high     |
      +--------+----------+                    +----------+-----------+
               |                                          |
      +--------v---------+                                |
      |   CQR 보정기      |                                |
      | (구간 넓이 조정)   |                                |
      +--------+----------+                                |
               |                                          |
      +--------v------------------------------------------v---+
      |              신뢰도 등급 부여 (A/B/C/D)                 |
      +--------------------------------------------------------+
               |
               v
       최종 출력: 가격 범위 + 추정가 + 신뢰 등급 + 경고
```

## 2. 핵심 이론: Hedonic Pricing Model

### Hedonic Price란?

1974년 경제학자 Sherwin Rosen은 **"상품의 가격은 그 속성들의 함수"**라는 이론을 제시했다. 이것이 **헤도닉 가격 모델**(Hedonic Pricing Model)이다.

쉽게 말해:

> **어떤 물건의 가격은, 그 물건을 구성하는 특성들의 조합으로 설명할 수 있다.**

예를 들어, 아파트 가격은 면적, 층수, 역세권 여부, 학군 등의 특성으로 상당 부분 설명된다. 마찬가지로 미술품 가격도 작가의 명성, 작품 크기, 재료, 경매 타입 등의 특성으로 설명할 수 있다.

### 미술품에 적용

```
미술품 가격 = f(작가 명성, 작품 크기, 재료, 경매 타입, 시장 분위기, ...)
```

논문(Fedderke & Carugno, 2024)에서 남아공 43,000건 경매 데이터로 이 접근이 유효함을 확인했고, 우리 시스템도 K-Auction 43,866건에 같은 원리를 적용한다.

### 추정가가 빠지면 어떤 정보가 사라지는가?

추정가는 단순한 숫자가 아니다. 그 안에는:
- 전문가가 조사한 **유사 작품 거래가**
- 최근 **시장 분위기**와 수요 전망
- 작가의 **최근 평판 변화**
- 경매사의 **전략적 판단** (낮게 잡아 경쟁 유도 등)

이 모든 정보가 압축되어 있다. 추정가를 제거하면 R²가 0.93에서 Validation 기준 0.59, Test 기준 0.31로 급락하는 이유가 바로 이것이다.

### 비유: 부동산 시세 예측

> 공인중개사의 시세평가 없이 집값을 예측한다고 상상해보자.
> 면적, 층수, 역세권, 학군, 건축연도만으로도 대략적인 가격 범위는 나온다.
> 하지만 "최근 이 동네 분위기가 좋다", "옆집이 비싸게 팔렸다" 같은
> 현장 전문가의 감각까지 반영하기는 어렵다.
>
> 우리 시스템이 하는 일이 정확히 이것이다:
> **전문가의 직관 없이, 객관적 데이터만으로 최선의 가격 범위를 제시하는 것.**

## 3. 49개 피처 (입력 데이터)

시스템은 작품 하나에 대해 **49개의 특성값(피처)**을 계산한다. "피처"란 모델이 가격을 예측하기 위해 참고하는 숫자화된 정보다.

### 3.1 기본 속성 피처 (15개)

작품 자체에서 바로 알 수 있는 정보.

| 구분 | 피처 | 왜 중요한가 |
|------|------|----------|
| **작가** | artist_clean | 작가가 누구인지는 가격의 가장 큰 결정 요인 |
| **재료** | medium_category, support_category | 유화 > 판화 > 드로잉 순으로 가격 차이 |
| | is_3d | 조각 등 3D 작품은 별도 가격 구조 |
| **크기** | height_cm, width_cm, surface_area | 일반적으로 큰 작품이 비쌈 |
| | aspect_ratio | 정방형/횡방향/종방향에 따른 가격 차이 |
| | is_size_imputed | 크기 정보가 없어서 추정한 경우 (불확실성 표시) |
| **제목** | is_untitled | "무제" 작품은 통계적으로 가격 패턴이 다름 |
| **작가 이력** | artist_avg_price | 이 작가의 과거 평균 낙찰가 |
| | artist_max_price | 이 작가의 역대 최고가 (명성 지표) |
| | artist_total_sold | 총 거래 횟수 (시장 검증 정도) |
| | is_new_artist | K-Auction에 처음 나오는 작가인지 |
| **시간** | 회차 | 경매 회차 (시간 흐름, 시장 사이클 반영) |

### 3.2 고급 작가/시장 피처 — Phase 3 (8개)

과거 거래 패턴에서 추출하는 심화 정보.

| 피처 | 의미 | 비유 |
|------|------|------|
| artist_median_price | 작가 중간 가격 | 평균보다 이상치에 강건 |
| artist_price_trend | 가격 추세 (상승/하락) | "주가 이동평균선" |
| medium_avg_price | 이 재료 카테고리의 평균가 | "유화 시장 전체 시세" |
| size_ho | 호수 (한국 미술계 표준 크기 단위) | "20호짜리 그림" |

### 중요한 제약: 시간 누수 방지

모든 피처는 **해당 경매 시점 이전의 데이터만** 사용하여 계산된다. 미래 정보가 섞이면 현실에서 사용할 수 없는 "가짜 정확도"가 나오기 때문이다. 예를 들어, 300회차 경매의 가격을 예측할 때 299회차까지의 거래만 참조한다.

## 4. 2-Model 파이프라인

시스템은 두 개의 모델이 역할을 분담한다.

### Model-A: 가격 범위 예측 (MultiQuantile)

**역할**: "이 작품은 최소 이 정도, 아마 이 정도, 최대 이 정도에 팔릴 것이다"

Model-A는 세 가지 가격을 동시에 예측한다:
- **q25 (하위 25%)**: 이 이하로 팔릴 확률이 25%
- **q50 (중앙값)**: 가장 가능성 높은 가격
- **q75 (상위 75%)**: 이 이상으로 팔릴 확률이 25%

```
                가격 범위 예측
    ─────────────────────────────────
    |         |         |           |
    q25       q50       q75
    (하한)    (적정가)   (상한)

    "이 가격   "아마     "비싸게
     이하는     이쯤"     팔리면
     어려워"              이쯤"
```

#### 비유: 세 명의 전문가

> 세 명의 미술품 감정사에게 가격을 물었다고 상상해보자.
> - **신중한 감정사**: "최소 3천만 원은 받아야 합니다" (q25)
> - **균형 잡힌 감정사**: "5천만 원 정도가 적당합니다" (q50)
> - **낙관적 감정사**: "좋은 날이면 8천만 원도 가능합니다" (q75)
>
> Model-A가 하는 일이 바로 이것이다.

### Model-B: 추정가 재현

**역할**: "경매사가 매기는 추정가를 AI가 대신 생성"

경매사는 보통 추정가를 "최저 ~ 최고" 범위로 제시한다. Model-B는 같은 입력으로 이 추정가를 재현한다. 이 추정가를 다시 Model-A에 넣으면(v2 모드) 더 정확한 가격 예측이 가능하다.

### 왜 CatBoost인가?

두 모델 모두 **CatBoost**라는 알고리즘을 사용한다. CatBoost를 선택한 이유:

1. **범주형 데이터 자동 처리**: 미술품 데이터에는 "작가명", "재료", "경매 타입" 같은 범주형(카테고리) 변수가 많다. 다른 알고리즘은 이를 숫자로 변환해야 하지만, CatBoost는 자동으로 처리한다.

2. **Gradient Boosting**: 많은 작은 결정 트리를 순서대로 학습시키되, 앞선 트리가 틀린 부분을 다음 트리가 보완하는 방식이다.

3. **과적합 방지**: 내장된 정규화 기법으로 "학습 데이터에만 맞추고 새 데이터에서 틀리는" 문제를 줄인다.

```
비유: Gradient Boosting은 시험공부와 비슷하다.

[1차 트리] → "대략적인 패턴 학습" → 오답 정리
     ↓
[2차 트리] → "1차에서 틀린 문제 집중 학습" → 오답 정리
     ↓
[3차 트리] → "2차에서도 틀린 어려운 문제 학습"
     ↓
  ... 2000번 반복 ...
     ↓
[최종 예측] = 모든 트리의 예측을 합산
```

### 수학적 처리: 로그 변환

가격은 직접 예측하지 않고, **자연로그(ln)**를 취한 값을 예측한 뒤 역변환한다.

왜? 미술품 가격은 10만 원부터 10억 원까지 분포하는데, 이런 극단적 범위에서는 로그 스케일이 더 안정적으로 학습된다.

```
예시:
- 입력 가격: 50,000,000원 (5천만)
- 로그 변환: ln(50,000,000) = 17.73
- 모델 예측: 17.73 (로그 스케일)
- 역변환:   exp(17.73) = 50,000,000원
```

## 5. 보정 (Calibration)

### 왜 보정이 필요한가?

모델의 예측은 완벽하지 않다. Model-A가 "q25 = 3천만, q75 = 8천만"이라고 했을 때, 실제로 그 구간 안에 가격이 들어오는 비율이 기대만큼 되지 않을 수 있다. 이 차이를 보정하는 것이 **CQR(Conformalized Quantile Regression)**이다.

### CQR의 원리

CQR는 Romano et al. (2019, NeurIPS)이 제안한 방법으로, 아이디어는 단순하다:

1. **보정 데이터**에서 모델이 얼마나 틀리는지 측정한다.
2. 그 **틀림의 크기(Q)**를 계산한다.
3. 새로운 예측을 할 때, 구간을 **Q만큼 늘려서** 실제 가격이 포함될 확률을 높인다.

```
보정 전:  [────── q25 ─────── q75 ──────]
                  좁은 구간 (많이 빗나감)

보정 후:  [── q25 - Q ─────────── q75 + Q ──]
                  넓어진 구간 (더 많이 포함)
```

구체적으로:
```
1. 보정 데이터 각 건에 대해 "오차 점수" 계산:
   E_i = max(하한 예측 - 실제가, 실제가 - 상한 예측)
   (구간을 벗어난 정도; 구간 안이면 음수)

2. 오차 점수들의 (1-alpha) 분위수를 Q로 설정

3. 새 예측의 구간:
   [하한 - Q,  상한 + Q]
```

### Coverage 개념

**Coverage**란 "예측 구간 안에 실제 가격이 들어오는 비율"이다.

현재 시스템은 **두 가지 보정 경로**가 공존한다:

| 경로 | 방식 | alpha | Coverage |
|------|------|-------|---------|
| **API 서빙** | Additive Shift (QuantileCalibrator) | — | ~55% |
| **오프라인 평가** | CQR (ConformalQuantileCalibrator) | 0.38 | 56.1% |

API에서는 기존 additive shift 보정이 적용되고, 오프라인 학습/평가에서는 CQR(alpha=0.38)로 측정한다. 향후 API에도 CQR를 적용하면 Coverage가 개선된다.

#### 비유: 일기예보

> 일기예보에서 "내일 최고기온 20~25도"라고 했을 때,
> 실제로 그 범위 안에 들어오는 날이 전체의 몇 %인지가 Coverage다.
>
> Coverage 55%는 "100번 예측하면 55번은 맞는 범위를 제시한다"는 뜻이다.
> 나머지 45번은 구간을 벗어나지만, 그래도 크게 벗어나는 경우는 드물다.

### 시계열 주의사항

CQR는 원래 "데이터가 서로 교환 가능하다(exchangeable)"는 가정 하에 동작한다. 그러나 경매 데이터는 시간 순서가 있어서, 최근 시장 상황이 과거와 다를 수 있다. 이를 위해 시스템은 **최근 3개 시간 윈도우**에서 Coverage를 별도로 검증한다.

## 6. Cold Start 해결

### 문제: "처음 보는 작가"

K-Auction 데이터에서 **45.9%의 작가가 단 1건만 거래**되었다. 이 작가들의 가격을 예측하려면 참고할 과거 데이터가 거의 없다. 이를 **Cold Start(콜드 스타트)** 문제라고 한다.

Cold Start 작가의 오차율은 **48.70% (MdAPE)**로, 충분한 거래 이력이 있는 Warm 작가(35.03%)보다 훨씬 높다.

### 5-Tier Fallback 계층

시스템은 5단계의 점진적 대안(Fallback)을 통해 Cold Start를 처리한다. 정보가 풍부한 상위 Tier부터 시도하고, 불가능하면 다음 Tier로 넘어간다.

```
Tier 0: K-Auction 거래 5건 이상 → 자체 이력 사용
  ↓ (부족하면)
Tier 1: 해외/타 경매사 데이터 3건 이상 → 외부 가격 참고
  ↓ (없으면)
Tier 2: K-NN 유사 작가 3명 이상 → 비슷한 작가 가격 참고
  ↓ (못 찾으면)
Tier 3: 같은 재료 x 경매타입 그룹 평균 (Bayesian shrinkage)
  ↓ (그룹이 너무 작으면)
Tier 4: 같은 재료 전체 또는 전체 평균 (Bayesian shrinkage)
```

### Bayesian Shrinkage: "적은 데이터는 전체 쪽으로 당긴다"

Tier 3, 4에서 사용하는 기법이다. 핵심 아이디어:

> **소규모 그룹의 평균은 불안정하므로, 전체 평균 쪽으로 적절히 끌어당긴다.**

```
보정된 평균 = (n x 그룹 평균 + m x 전체 평균) / (n + m)

n = 그룹 내 데이터 수
m = 수축 강도 (현재 10으로 설정)
```

예시:
- "캔버스에 유채 + 프리미엄 경매" 그룹에 5건만 있고, 평균이 1억이라면
- 전체 평균이 3천만이라면
- 보정된 평균 = (5 x 1억 + 10 x 3천만) / (5 + 10) = **5,333만 원**

5건만으로는 "이 그룹은 반드시 1억"이라고 확신할 수 없으므로, 전체 평균 쪽으로 끌어내려 극단적인 예측을 방지한다.

### Artist Similarity: "비슷한 작가를 찾아 참고"

Tier 2에서 사용하는 기법이다. 처음 보는 작가라도, 비슷한 특성의 기존 작가를 찾아 가격을 추정할 수 있다.

**유사 작가 탐색 과정 (K-NN)**:

1. **후보 생성**: 같은 재료(유화, 판화 등)를 주로 사용하는 작가 필터링
2. **가격대 필터**: 비슷한 가격 범위(상하 1단계)의 작가만 남김
3. **거리 계산**: 평균 작품 크기, 평균 가격, 활동 기간 등으로 유사도 측정
4. **가중 평균**: 가까운 작가에 더 높은 가중치를 부여

```
가중치 = 1 / (1 + 거리²)

거리가 0.5인 작가: 가중치 = 1 / (1 + 0.25) = 0.80
거리가 2.0인 작가: 가중치 = 1 / (1 + 4.00) = 0.20
→ 가까운 작가의 가격이 훨씬 더 많이 반영됨
```

#### 비유: 새 식당의 예상 평점

> 새로 오픈한 식당의 평점을 예측한다면?
> 리뷰가 아직 없으니, 비슷한 유형(같은 음식, 비슷한 가격대, 비슷한 위치)의
> 기존 식당 평점을 참고하는 것이 합리적이다.
> 특히 더 비슷한 식당의 평점에 가중치를 더 주는 것이 K-NN의 원리다.

## 7. 신뢰도 등급 (A/B/C/D)

모든 예측에는 **"이 예측을 얼마나 믿어도 되는가"**를 나타내는 등급이 부여된다.

| 등급 | 의미 | 기준 | 기대 정확도 |
|------|------|------|-----------|
| **A** | 높은 신뢰도 | 거래 20건 이상 + Tier 0 | 가장 정확 |
| **B** | 보통 신뢰도 | 거래 5~19건 | 참고 가치 높음 |
| **C** | 낮은 신뢰도 | 거래 1~4건 또는 미낙찰률 50% 초과 | 대략적 범위 |
| **D** | 최소 신뢰도 | 신규 작가 또는 Cold Start Tier 2 이상 | 방향성 참고만 |

### 등급 결정 로직

```
신규 작가이거나 Cold Start Tier ≥ 2  →  D등급
  ↓ 아니면
미낙찰률 > 50% 또는 거래 < 5건       →  C등급
  ↓ 아니면
거래 < 20건                          →  B등급
  ↓ 아니면
거래 ≥ 20건 + Tier 0                →  A등급
```

### 주의: A등급이라도 100% 정확하지 않다

> **모든 예측에는 불확실성이 존재한다.**
>
> A등급은 "데이터가 충분하여 비교적 안정적인 예측"이라는 뜻이지,
> "반드시 이 가격에 낙찰된다"는 보장이 아니다.
> 경매 당일의 참여자 수, 분위기, 경쟁 상황에 따라 결과는 크게 달라질 수 있다.

## 8. 성능 지표 해석

### MdAPE (Median Absolute Percentage Error)

> **"예측 오차의 중간값 — 절반의 예측이 이 수준 이내"**

현재 전체 MdAPE는 약 **35.54%**이다.

이것은 "예측값과 실제 가격의 차이가, 절반의 경우에 35.54% 이내"라는 뜻이다.

```
예시: 예측가 5,000만 원, MdAPE 35%이면
- 절반의 경우: 실제가가 3,250만 ~ 6,750만 원 사이
- 나머지 절반은 이 범위를 벗어남
```

왜 "중간값"을 쓰는가? 미술품은 가끔 예측의 10배에 팔리는 이상치가 있다. 평균(MAPE)은 이런 이상치에 크게 흔들리지만, 중간값(MdAPE)은 견고하다.

### 실제로 어느 정도 맞추는가? (체감 정확도)

MdAPE는 "오차율"이지 "정확도"가 아니다. **뒤집어서 이해**하면:

| 오차 범위 | 예측 중 비율 | 체감 | 근거 |
|----------|------------|------|------|
| **±30% 이내** | **~43%** (10건 중 4건) | "가격대 맞음" | **실측** (test_within_30=43.4%) |
| **±20% 이내** | ~35% (3건 중 1건) | "꽤 정확하네" | 추정 (별도 산출 필요) |
| **±50% 이내** | ~65% (3건 중 2건) | "대략 맞음" | 추정 (별도 산출 필요) |
| **±100% 이상** | ~10% (10건 중 1건) | "크게 빗나감" | 추정 (이상치 비율) |

> ※ ±30% 이내 43.4%만 실측값이며, 나머지는 MdAPE 35% 기반 대략적 추정치입니다.

#### 금액으로 보면

예측가 5,000만 원인 작품의 실제 낙찰가 분포:

```
±20% (4,000만~6,000만):  ████████░░░░░░░░░░  ~35% → 3건 중 1건
±30% (3,500만~6,500만):  ██████████░░░░░░░░  ~43% → 10건 중 4건
±50% (2,500만~7,500만):  ████████████████░░  ~65% → 3건 중 2건
그 이상 벗어남:           ██████████████████  ~35%
```

> **해석**: 예측가 5,000만 원이면, 3건 중 2건은 2,500만~7,500만 사이에서 낙찰된다.
> 3건 중 1건은 4,000만~6,000만으로 꽤 정확하고, 10건 중 1건 정도는 크게 빗나간다.

#### 등급별 체감 정확도 (예시)

> ※ 아래 금액 범위는 MdAPE와 등급 기준을 조합한 **대략적 예시**이며, 등급별 실측 분포는 별도 calibration 산출이 필요합니다.

| 등급 | 예측가 5,000만일 때 예상 범위 (예시) | 체감 |
|------|----------------------------------|------|
| **A등급** (거래 20건+) | 4,000만~6,500만 | **"꽤 맞네"** |
| **B등급** (거래 5~19건) | 3,000만~7,500만 | "가격대는 맞음" |
| **C등급** (거래 1~4건) | 2,500만~1억 | "대략적 수준" |
| **D등급** (신규 작가) | 2,000만~1.5억 | "감만 잡는 수준" |

#### 경매 타입별

| 경매 타입 | Test MdAPE | 체감 |
|----------|-----------|------|
| **위클리** | ~30% | **가장 정확** — 저가, 데이터 풍부 |
| **프리미엄** | ~37% | 중간 — 가격대 다양 |
| **메이저** | ~39% | 상대적 부정확 — 고가, 변동 큼 |

> ※ 위 수치는 Test set (gap_diagnosis.json) 기준. Validation에서는 프리미엄이 ~27%로 가장 정확하나, Test에서는 시장 변화로 역전됨.

#### 다른 분야와 비교

| 분야 | 예측 오차(MdAPE) | 비교 |
|------|----------------|------|
| 부동산 시세 | 5~15% | 표준화된 속성, 거래 빈번 |
| 주식 가격 (단기) | 20~40% | 변동성 높음 |
| 미술품 (추정가 포함) | ~20% | 전문가 판단 반영 |
| **미술품 (추정가 없이 — 우리)** | **~35%** | **논문 대비 경쟁력 있음** |

#### 이 시스템으로 할 수 있는 것 / 없는 것

**할 수 있는 것**:
- "이 작품이 대략 3,000만~8,000만 원 사이" → **가격대 감잡기** ✅
- "이 작가의 최근 1년 가격이 상승세" → **트렌드 파악** ✅
- "AI 추정가 5,000만인데 경매사가 8,000만" → **괴리 감지** ✅
- Cold Start 작가의 **첫 가격대 설정** 참고 ✅

**할 수 없는 것**:
- "정확히 4,723만 원에 낙찰될 것이다" → ❌ 점 예측 부정확
- "반드시 추정가 이상에 낙찰" → ❌ 보장 불가
- 시장 급변(코로나, 버블) 시 예측 → ❌ 과거 패턴 기반

> **한 줄 결론**: "10건 예측하면 4건은 ±30% 이내로 맞추고, 6~7건은 가격대(±50%)를 맞추며, 1건 정도는 크게 빗나간다."

### R² (결정계수)

> **"모델이 가격 변동의 몇 %를 설명하는가"**

- R² = 1.0: 완벽한 예측 (100% 설명)
- R² = 0.6: 가격 변동의 60%를 설명 (나머지 40%는 모델이 모르는 요인)
- R² = 0.0: 아무것도 설명 못 함 (평균만 찍는 것과 동일)

현재 시스템:
- 추정가 포함 시: R² = **0.93** (거의 완벽)
- 추정가 없이: R² = **0.31** (테스트 세트 기준)

#### 비유

> 학교 성적이 "공부 시간 + IQ + 수면 시간"으로 60% 설명된다면, R² = 0.60이다.
> 나머지 40%는 컨디션, 운, 시험 유형 등 우리가 측정하지 못한 요인이다.
>
> R² = 0.31(테스트)은 "작가, 크기, 재료 등으로 가격 변동의 31%를 설명"한다는 뜻이다.
> 이는 추정가라는 강력한 정보 없이 예측하는 난이도를 보여준다.

### Coverage (구간 포함률)

> **"예측한 가격 범위 안에 실제 가격이 들어가는 비율"**

현재 Coverage는 약 **56%** (CQR alpha=0.38 기준)이다.

| 지표 | 현재 값 | 의미 |
|------|--------|------|
| Coverage | ~56% | 절반 이상의 경우 예측 구간에 실제가 포함 |
| Within 30% | ~43~50% | 중앙 예측의 ±30% 이내에 실제가 있는 비율 |
| Monotonicity | 1.00 | q25 < q50 < q75 순서가 항상 지켜짐 |

## 9. 한계와 주의사항

### 9.1 구조적 한계: 추정가 없는 예측

추정가는 전문가의 종합 판단이 압축된 변수다. 이를 제거하면 R²가 0.93에서 0.31(테스트)로 떨어진다. 이 갭은 미술시장 연구의 근본적 한계이며, 최신 논문(Mei et al., 2025)에서도 추정가 없는 fresh-to-market 예측의 R²는 0.54~0.65 수준이다.

### 9.2 시장 급변

- **코로나 같은 외부 충격**: 경매 시장 전체가 급변하면 과거 패턴이 무효화됨
- **트렌드 변화**: 특정 작가나 장르의 갑작스러운 인기 변동은 모델이 즉시 반영하기 어려움
- **Val-Test Gap**: Validation MdAPE 31.6% vs Test MdAPE 35.5% → **MdAPE 기준 약 4%p** 차이. R² 기준으로는 Validation 0.59 vs Test 0.31로 더 큰 격차. 시간에 따른 시장 변화(drift)가 주요 원인

### 9.3 가격대별 정확도 차이

- **고가 작품** (메이저 경매): Test MdAPE ~39%, 편차가 큼. 고가 작품은 소수 컬렉터의 의지에 따라 변동
- **중가 작품** (프리미엄 경매): Test MdAPE ~37%. Validation에서는 ~27%로 가장 정확했으나 Test에서 시장 변화 영향
- **저가 작품** (위클리 경매): Test MdAPE ~30%, 가장 안정적. 데이터가 풍부하고 가격 범위가 좁음

### 9.4 Cold Start 작가의 한계

거래 이력이 없는 작가의 예측 오차(MdAPE 48.70%)는 기존 작가(35.03%)의 거의 2배다. Tier 2 이하의 예측은 "대략적인 가격대"로만 참고해야 한다.

### 9.5 근본 원칙

> **AI 예측은 의사결정의 참고 자료이며, 최종 판단은 반드시 전문가가 내려야 한다.**
>
> 이 시스템은 전문가의 직관을 대체하는 것이 아니라,
> 객관적 데이터 기반의 "두 번째 의견(Second Opinion)"을 제공하는 것이다.

## 10. 자주 묻는 질문

### Q1: "왜 추정가를 넣으면 더 정확한가요?"

추정가는 단순한 숫자가 아니라, 경매 전문가가 수행한 비교 분석의 결과물이다. 그 안에는 유사 작품 시세, 작가 최근 평판, 시장 분위기 등 AI가 직접 관측하기 어려운 "질적 정보"가 압축되어 있다. 추정가를 입력하면 R²가 0.31에서 0.93으로 올라가는데, 이 차이(0.62)가 바로 전문가 지식의 가치를 보여준다.

시스템은 v2 모드를 통해 "AI가 생성한 추정가"를 다시 입력으로 활용하는 2단계 예측도 지원한다.

### Q2: "새로운 작가도 예측이 되나요?"

된다. 다만 정확도가 떨어진다. Cold Start 5-tier 시스템을 통해:
- 해외 경매 데이터가 있으면 참조 (Tier 1)
- 비슷한 작가를 K-NN으로 찾아 참고 (Tier 2)
- 같은 재료/경매타입 평균을 활용 (Tier 3~4)

예측에는 반드시 **D등급**(최소 신뢰도)이 부여되므로, 결과를 방향성 참고로만 사용해야 한다.

### Q3: "어떤 작가의 예측이 가장 정확한가요?"

거래 이력이 **20건 이상**이고, 가격이 **안정적인** 작가의 예측이 가장 정확하다. 구체적으로:
- A등급 작가: 가격 변동성이 낮고 충분한 데이터
- 프리미엄 경매: 중간 가격대로 가장 안정적
- 미낙찰률이 낮은 작가: 시장 수요가 꾸준

반대로, 가격이 들쭉날쭉하거나, 거래가 드물거나, 고가 작품 위주인 작가는 예측이 어렵다.

### Q4: "모델이 학습하지 못한 상황은?"

다음 상황은 모델의 예측 범위 밖이다:
- **K-Auction에 한 번도 출품되지 않은 작가**가 갑자기 고가에 낙찰되는 경우
- **경매 시장 전체의 급격한 변화** (예: 팬데믹, 금융위기)
- **위작 논란, 작가 사망** 등 가격에 극적 영향을 미치는 이벤트
- **새로운 매체나 형식**의 작품 (NFT, 디지털 아트 등)
- **극단적 고가 작품** (수십억 이상): 소수 컬렉터의 의사결정으로 가격이 결정

이러한 경우에는 시스템의 예측보다 전문가의 판단이 우선되어야 한다.
