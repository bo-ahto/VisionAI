## 0. Executive Summary

### 핵심 결과

**Hedonic mixed-effects 회귀 (3 features) 로 V3 운영 모델의 cold-start 약점 해결**

| 시나리오 | V3 (32 features GBM) | 트랙 2 (3 features) | 평가 |
|---|---|---|---|
| Warm 작가 (학습 충분) | **12-18%** ✓ | 21.74% | V3 우위 |
| **Cold 작가 (신규)** | 28-48% ⚠️ | **24-27%** ⭐ | **트랙 2 우위** |
| 통합 (시뮬레이션) | — | 22.30~25.18% | V3 + 트랙 2 보완 도입 |

### 핵심 모델

```
Stage 2 freeze (F4):
  log_price ~ log_area + birth_year_centered + log_artist_total_works

Stage 3 ME 추가:
  log_price ~ F4 + (1 | artist_slug)
```

**3 features 만으로 V3 (32 features) 의 cold-start 정확도 -4 ~ -20%p 개선.**

### 운영 도입 권고 (단계적)

| 입력 작품 | 적용 모델 | 예상 정확도 |
|---|---|---|
| 학습 데이터에 작가 ≥ 10건 | V3 유지 | MdAPE 12-18% |
| 학습 데이터에 작가 < 10건 (cold) | **트랙 2 OLS (F4) 도입** | MdAPE ~27% |

→ **이원 전략 단계적 운영 도입 권고** (전면 교체 X)

## 3. Feature Selection

### 3.1 검증 과정 (요약)

| 단계 | 결과 |
|---|---|
| Core 5 (초기) | log_area + year + career_stage + medium + tier (8 feat) → MdAPE 28.75% |
| Forward selection | log_area + birth_year + total_works + career_stage 자동 선택 |
| Elastic Net 채택률 | log_area / birth_year 100%, career_stage <50% (자동 제거) |
| **F4 (winner)** | **log_area + birth_year + total_works** (3 feat) → **MdAPE 24.59%** |

### 3.2 F4 변수 정의

| 변수 | 정의 | β (full) | 부호 일관성 |
|---|---|---|---|
| `log_area` | log(작품 면적 cm²) | +0.78 | 100% |
| `birth_year_centered` | (작가 출생년 - 평균) | -0.05 | 100% |
| `log_artist_total_works` | log(1 + 작가 총 작품 수) | +0.07 | 100% |

### 3.3 경제적 해석

```
log_price = 8.6 + 0.78 × log_area - 0.05 × birth_year_centered + 0.07 × log_artist_total_works
```

- **작품 크기**: 면적 1% 증가 → 가격 +0.78% (size elasticity)
- **작가 세대**: 출생년 1년 늦을수록 가격 -5% (시장 위상 effect)
- **작가 생산성**: 작품 수 2배 증가 → 가격 +5%

**한국 미술시장 가격 결정 = 작품 크기 + 작가 세대 + 작가 생산성**

### 4.1 Stage 2 OLS Hedonic (500/50)

| Set | k | MdAPE (30-seed LAO) | R² | VIF |
|---|---|---|---|---|
| Core 5 (초기) | 8 | 28.75±6.39% | 0.840 | 1.5 |

| **F4** ⭐ | **3** | **24.59±5.96%** | **0.869** | **1.2** |

### 4.2 Stage 3 ME Random Intercept (1378/100)

#### LAO (cold-start) — ME 효과 미미
| 지표 | OLS | ME | 차이 |
|---|---|---|---|
| MdAPE | 25.49% | 25.54% | +0.05%p |

→ Cold-start 에서 random intercept 가 0 으로 수축 → ME 효과 무력화

#### Warm-start (시간 기준) — ME 효과 강함

| Train | warm 비율 | OLS | **ME** | 차이 |
|---|---|---|---|---|
| ≤2020 | 29.6% | 33.46% | 28.59% | -4.87%p |
| ≤2022 | 54.1% | 26.50% | **22.26%** | -4.25%p |
| ≤2023 | 73.5% | 25.45% | **21.74%** | -3.71%p |

### 4.3 Variance Decomposition

| Component | 분산 | 비중 |
|---|---|---|
| Artist RE | 0.130 | **54.1%** |
| Residual | 0.110 | 45.9% |
| **ICC** | — | **0.541** |

**ICC 0.541** → 가격 분산의 54% 가 작가 단위 차이 (warm-start ME 효과 정당화)

## 7. V3 vs 트랙 2 비교 (운영 관점)

```
입력 작품
  ↓
작가 학습 데이터 ≥ 10건?
  ├─ YES (warm) → V3 유지 (검증된 정확도 12-18%)
  └─ NO  (cold) → 트랙 2 OLS F4 (~27%, V3 cold 28-48% 보다 우수)
```

### 7.1 트랙 2 도입의 가치

| 항목 | V3 단독 | V3 + 트랙 2 보완 |
|---|---|---|
| Warm 정확도 | 12-18% | 12-18% (변화 없음) |
| **Cold 정확도** | 28-48% | **~27%** (-1 ~ -21%p ↓) |
| 해석 가능 | 32 feat (어려움) | 3 feat (명확) |
| 운영 복잡도 | 낮음 | 약간 증가 (라우터 추가) |

### 7.2 비선정 모델 활용

트랙 2 가 운영 도입되어도 V3 는 warm 전용으로 유지:
- V3: warm 작가 메인 모델
- 트랙 2: cold 작가 보완 모델
- **비선정** = 별도로 없음 (역할 분리)

## 8. 운영 도입 권고

### 8.1 단계적 도입 안

```
Phase A (Week 4 ~ 1주차) — Shadow
  - 트랙 2 (cold-only) shadow 배치
  - 실제 트래픽 0% 입력만 비교
  - V3 와 cold 작가 예측 차이 monitoring

Phase B (1-2주차) — Cold-only Soft Launch  
  - cold 작가 대상으로만 트랙 2 적용
  - 1% → 5% → 10% 점진 확대
  - 운영 monitoring (latency / drift / fallback)

Phase C (2-4주차) — Full Cold Routing
  - cold 작가 100% 트랙 2 적용
  - 결과 정량 보고
  - 가드레일 (저가/ink/tier3) 별도 처리

Phase D (4주+) — 안정화
  - Calibration table 월 단위 재학습
  - V3 와 트랙 2 단계적 통합 (warm-cold 라우터)
```

### 8.2 Rollback 조건

- Cold 작가 MdAPE > V3 baseline (28-48%)
- 가드레일 segment (저가/ink) MdAPE > 50%
- Latency p99 > 임계
- Drift 알람 발생

## 12. 결론

**3 features hedonic mixed-effects 모델 (F4) 로 V3 운영 모델의 cold-start 약점 해결 가능.**

- **트랙 2 통합 MdAPE 22.30 ~ 25.18%** (V3 cold 28-48% 대비 **-3 ~ -20%p 우수**)
- **이원 전략 (warm = V3 / cold = 트랙 2) 단계적 도입 권고**
- **해석 가능**: 면적 / 작가 세대 / 작가 생산성 3축으로 가격 결정 설명
- **가드레일 필요**: 저가 / ink / tier 3 segment 별도 처리

**운영 도입 가능 단계**: Shadow (Week 4) → Cold-only soft launch (1-2주차) → Full cold routing (2-4주차) → 안정화 (4주+).
