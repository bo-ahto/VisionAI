## 0. Executive Summary

### 핵심 결과

**Hedonic 회귀 (3 features + log_area spline + Huber loss) 로 V3 운영 모델의 cold-start 약점 해결**

| 시나리오 | V3 (32 features GBM) | 트랙 2 (3 features) | 평가 |
|---|---|---|---|
| Warm 작가 (학습 충분) | **12-18%** ✓ | 21.74% | V3 우위 |
| **Cold 작가 (신규, 100-seed)** | 28-48% ⚠️ | **24.07% (Huber)** ⭐ | **트랙 2 우위** |
| 통합 (시뮬레이션) | — | 22.30~25.18% | V3 + 트랙 2 보완 도입 |

### 핵심 모델 — 최종 권고 (Huber 채택 후)

```
log_price ~ β₀ + β₁·log_area + β₂·birth_year_centered + β₃·log_artist_total_works
                + β₄·spline₁(log_area) + ε
                
손실함수: Huber (eps=1.35)
```

> **참고**: warm-start 시나리오 확장 모델로 `+ (1 | artist_slug)` random intercept 도 검토했으나, cold-start LAO 환경에서 무력화 → **운영 채택 모델은 위 fixed-effects only 형태**.

**3 features (+spline) 만으로 V3 (32 features) 의 cold-start 정확도 -4 ~ -24%p 개선.**

### 누적 개선 (Stage 3, 100-seed LAO holdout)

| 모델 단계 | MdAPE | 개선 |
|---|---|---|
| F4 OLS (baseline) | 26.46±4.69% | (기준) |
| + log_area spline | 25.22±4.36% | -1.24%p |
| **+ Huber regression** ⭐ | **24.07±4.18%** | **-2.39%p 누적** |

### 운영 도입 권고 (단계적)

| 입력 작품 | 적용 모델 | 예상 정확도 |
|---|---|---|
| 학습 데이터에 작가 ≥ 10건 | V3 유지 | MdAPE 12-18% |
| 학습 데이터에 작가 < 10건 (cold) | **트랙 2 (F4 + spline + Huber)** | **MdAPE ~24% (100-seed)** |

→ **이원 전략 단계적 운영 도입 권고** (전면 교체 X)

### Huber 채택 핵심 근거 — 취약 segment 방어력

평균 개선 (-2.39%p) 보다 **취약 segment 의 구조적 오차 감소** 가 운영상 더 중요한 가치:

| Segment | OLS | **Huber** | 개선 |
|---|---|---|---|
| 저가 (가격 <20%) | 34.27% | **28.46%** | **+5.81%p** ⭐⭐⭐ |
| 고가 (가격 >80%) | 31.87% | **28.22%** | **+3.65%p** ⭐⭐ |
| Tier 3 (worst) | 26.74% | 24.56% | +2.18%p |
| Bootstrap 95% CI | [22.75, 25.91] | **[21.68, 25.08]** | 거의 분리 |

→ 가장 위험한 운영 가드레일 segment 모두 개선 (저가/고가/worst tier)

## 3. Feature Selection

### 3.1 검증 과정 (요약)

| 단계 | 결과 |
|---|---|
| Core 5 (초기) | log_area + year + career_stage + medium + tier (8 feat) → MdAPE 28.75% |
| Forward selection | log_area + birth_year + total_works + career_stage 자동 선택 |
| Elastic Net 채택률 | log_area / birth_year 100%, career_stage <50% (자동 제거) |
| **F4 (winner)** | **log_area + birth_year + total_works** (3 feat) → **MdAPE 24.59%** |

### 3.2 F4 변수 정의

| 변수 | 정의 | β (full) | 부호 일관성 |
|---|---|---|---|
| `log_area` | log(작품 면적 cm²) | +0.78 | 100% |
| `birth_year_centered` | (작가 출생년 - 평균) | -0.05 | 100% |
| `log_artist_total_works` | log(1 + 작가 총 작품 수) | +0.07 | 100% |

### 3.3 경제적 해석

```
log_price = 8.6 + 0.78 × log_area - 0.05 × birth_year_centered + 0.07 × log_artist_total_works
```

- **작품 크기**: 면적 1% 증가 → 가격 +0.78% (size elasticity)
- **작가 세대**: 출생년 1년 늦을수록 가격 -5% (시장 위상 effect)
- **작가 생산성**: 작품 수 2배 증가 → 가격 +5%

**한국 미술시장 가격 결정 = 작품 크기 + 작가 세대 + 작가 생산성**

### 6.3.1 분석 방법론 한계 (코덱스 권고 반영, 정직 보고)

본 §1-§11 의 모든 결과는 **Phase 1 (curated exploratory)** 단계 산출물. 다음 한계들이 본 결과의 신뢰도를 제한한다 — 운영 채택은 **Phase 2 (full confirmatory)** 후 결정.

1. **Test set reuse (data snooping / "garden of forking paths")**
   - Stage 3 의 같은 test set 으로 P1 / P2 / P3 / feature 재탐색 / robustness 모두 평가
   - 6+ 모델 비교 후 최적 선택 → **winner's curse / test overfitting** 위험
   - 누적 multiple testing → reported CI 가 실제 불확실성 underestimate

2. **Train / Validation / Test 3-way split 부재**
   - Stage 3 = train + test 만 → hyperparameter 와 model selection 이 같은 test 에서 진행됨
   - Stage 4 부터 3-way 분리 적용 (`docs/stage4_데이터수집계획_20260507.md` §4.1)

3. **다중비교 보정 부재 (Stage 3)**
   - 6+ 모델 동시 비교에 Bonferroni / Holm 미적용 → 보고된 CI 가 family-wise α 통제 X
   - **Holm 보정 후 재계산 결과** (`stage3_warm_holm_adjusted.json`): warm path 비교에서 어떤 모델도 보정 후 통계적 유의성 미달 (FE only raw p=0.30, n=44 한계)
   - → 운영 채택은 **Phase 2 표본 확장 후 사전 등록 단일 비교**로 진행

4. **Pre-registered analysis plan 부재 (Stage 1-3)**
   - 가설 / metric / 임계 / 다중비교 보정 사전 등록 X — 결과 본 후 분석 추가
   - Stage 4 부터 사전등록 적용 (`docs/stage4_데이터수집계획_20260507.md` §6.0)

5. **External validity 미검증**
   - Stage 3 = curated subset (모집단 7,289 → 1,378, cleansing rule 통과)
   - production traffic 분포와 다를 수 있음 — Phase 2 (full data) 에서 분포 차이 분석 protocol 강제

6. **Calibration / OOD / drift 미평가**
   - 점추정 + CI 만 — 예측 분포 calibration curve / OOD detection / time drift 별도 평가 X
   - Phase 2 부터 필수 산출물 (`docs/트랙2_methodology_pipeline_20260507.md` §7)

> **결론**: Phase 1 결과는 **"기각되지 않은 유망 신호"** — 채택 근거가 아닌 **확인 필요 근거**. 본 보고서의 cold rollout 권고 (§5.2 / §8) 는 V3 fallback 안전장치 + Shadow / Canary 단계적 도입으로 false positive 비용을 통제하는 구조이며, warm-only path (§12 부록) 는 명시적으로 Phase 2 까지 보류.

### 6.3.2 외부 자문 (Ridge 헤도닉) 검증 결과 (2026-05-07 addendum)

> 외부 자문 (Ridge 기반 헤도닉 가격 예측 모델 + gallery/material 통계 피처 + 작가 차등 처리) 권고를 Stage 3 데이터로 검증. 상세는 `docs/stage3_exploratory_addendum_20260507.md`.

| 후보 family | 검증 항목 | 100-seed LAO 결과 | 결정 |
|---|---|---|---|
| C | gallery / material out-of-fold target encoding (shrinkage k=10) | +0.03 ~ +0.79%p | ✗ 미채택 |
| A | Ridge alone | +1.09%p (악화) | ✗ 미채택 |
| A | Huber + L2 (alpha 1e-4 ~ 10) | ±0.00%p (동등) | ≈ L2 무가치 확정 |
| A | F1 + F2 결합 | +0.77 ~ +2.23%p (악화) | ✗ 미채택 |
| E | artist_median_te / sales_count / dispersion / combined | +0.13 ~ +30.96%p | ✗ LAO 구조상 무력 |

> **artist 통계 피처는 LAO (test 작가 100% unseen) 평가에서 구조적으로 warm-only 가치만 가짐** — fillna(0) 비중 100% 로 train-eval 분포가 본질적으로 어긋남.

**핵심 결론**: 외부 자문 선형/통계 피처 계열 모든 후보 합격 기준 (-1.0%p) 미달 → **기존 운영 모델 (F4 + spline + Huber, eps=1.35, alpha=1e-4) 유지** + 외부 대안 비채택 근거 추가.

외부 자문 권고는 다음 영역에 한정 재해석:
- **Warm-start 전용 후보**: artist 통계 피처 + shrinkage (별도 cycle, Stage 4 secondary 후보 검토)
- **가격 범위 산출**: Quantile Regression q25/q50/q75 (별도 cycle, 운영 band 가치 큼)
- **Phase 2 (full data) confirmatory**: gallery/material TE 재검증 가치 (분포 차이 가능성)

### 6.4 가드레일 운영 권고

- **저가 (<5M원)**: prediction band 확대 ±50%
- **Ink 매체**: human review 권장
- **Tier 3 갤러리**: 별도 보정 규칙 검토
- **Cal table**: 월 단위 재학습 필수

## 7. V3 vs 트랙 2 비교 (운영 관점)

```
입력 작품
  ↓
작가 학습 데이터 ≥ 10건?
  ├─ YES (warm) → V3 유지 (검증된 정확도 12-18%)
  └─ NO  (cold) → 트랙 2 (F4 + spline + Huber, 24.07% Stage 3 100-seed)
```

### 7.1 트랙 2 도입의 가치

| 항목 | V3 단독 | V3 + 트랙 2 보완 |
|---|---|---|
| Warm 정확도 | 12-18% | 12-18% (변화 없음) |
| **Cold 정확도** | 28-48% | **~24%** (Huber 채택 후) |
| 해석 가능 | 32 feat (어려움) | 3 feat + spline (명확) |
| 운영 복잡도 | 낮음 | 약간 증가 (라우터 + Huber loss) |

> **표본 차이 caveat**: V3 28K 전체 vs 트랙 2 1.3K curated. 동일 프로토콜 직접 비교 X. Stage 3 100-seed Bootstrap CI [21.68, 25.08] 에서 우수 신호 일관 확인.

### 7.2 비선정 모델 활용

트랙 2 가 운영 도입되어도 V3 는 warm 전용으로 유지:
- V3: warm 작가 메인 모델
- 트랙 2: cold 작가 보완 모델
- **비선정** = 별도로 없음 (역할 분리)

## 8. 운영 도입 권고

### 8.1 단계적 도입 안

```
Phase A (Week 4 ~ 1주차) — Shadow
  - 트랙 2 (cold-only) shadow 배치
  - 실제 트래픽 0% 입력만 비교
  - V3 와 cold 작가 예측 차이 monitoring

Phase B (1-2주차) — Cold-only Soft Launch  
  - cold 작가 대상으로만 트랙 2 적용
  - **5% → 10% → 25% 점진 확대** (production spec §0.2 와 일치)
  - 운영 monitoring (latency / drift / fallback)

Phase C (2-4주차) — Full Cold Routing
  - cold 작가 100% 트랙 2 적용
  - 결과 정량 보고
  - 가드레일 (저가/ink/tier3) 별도 처리

Phase D (4주+) — 안정화
  - Calibration table 월 단위 재학습
  - V3 와 트랙 2 단계적 통합 (warm-cold 라우터)
```

### 8.2 Rollback 조건

- Cold 작가 MdAPE > V3 baseline (28-48%)
- 가드레일 segment (저가/ink) MdAPE > 50%
- Latency p99 > 임계
- Drift 알람 발생

## 12. 부록 — Warm-only Track 2 path 후보 (Stage 4 보류)

> **운영 결정 라벨**: 본 부록은 **연구 후보 / 운영 미승인 / Stage 4 후 재평가**.  
> §1-§11 의 운영 권고 (warm = V3 / cold = Track 2, §5.2) 는 **변경 X**.  
> 본 부록 목적: warm-start 에서도 Track 2 활용 가능성 탐색 결과 + Stage 4 의사결정 근거 기록

### 12.1 동기
V3 의 warm-start (artist 학습량 ≥ 10) MdAPE 12-18% 대비 Track 2 baseline (cold 운영 모델, F4 + spline + Huber) 의 warm-start 성능을 시간 기준 split 으로 측정. Artist Fixed Effects (FE) 등을 추가해 V3 warm 범위 진입 가능한지 확인.

### 12.2 P2 검증 (Combined 후보)
- **모델**: baseline + Artist FE + time weight (half-life 2y) + artist history (train avg log_price)
- **결과**: 23.15% → 16.79% (-6.36%p 점추정, n_test=44, ≤2023 split)
- **Bootstrap 95% CI**: [-11.52%p, +6.59%p], P(<0) = 79.3% — **0 포함**
- **Bucket 분해**: 저가 +3.36%p **악화**, 중가 -6.87%p, 고가 -0.93%p — 편중 개선
- **Leakage**: 0건 (artist history 의 train cutoff 분리 정상)

### 12.3 P3 검증 (코덱스 권고)
4-model rolling time-split (cutoff 2022 / 2023 / 2024):

| cutoff | n_test | baseline | **FE only** | Combined | Combined-shrunk (EB) |
|---|---|---|---|---|---|
| 2022 | 19 | 17.50% | **10.24%** | 16.79% | 16.67% |
| 2023 | 44 | 23.15% | **19.18%** | 16.49% | 16.51% |
| 2024 | 62 | 26.13% | **21.90%** | 23.98% | 23.83% |
| Δ vs baseline | — | — | **-7.26 / -3.97 / -4.23%p** | -0.71 / -6.66 / -2.15%p | 거의 동일 |

> **cutoff 2022 caveat**: n_test_artists=5 의 exploratory signal — 방향성 강건성 평가용이며 채택 결정의 주 근거는 아니다. 주 근거는 cutoff 2023 (n=13) / 2024 (n=21) + robustness 30 실험 (§12.4.2).

- **Artist-cluster bootstrap (n=500, ≤2023)**: FE only -2.68%p [-14.33, +8.54], P(<0)=72%
- **EB shrinkage 효과 미미**: σ_b² (1.046) > σ_w² (0.639) → 작가 간 분산 우세, shrinkage 약함
- **Depth bin 분해 불가**: 모든 warm test 가 10-14 depth 에 집중 (Stage 3 데이터 한계)
- **2024 composition shift**: warm artists 21 → 57 (신규 +36) — Combined 효과 약화 원인

### 12.4 결론
- **FE only** 가 3 cutoff 모두 일관 개선 (강건성 확인) → warm-only path **Stage 4 leading candidate 진입 (확정 X)** (코덱스)
- **Combined / Combined-shrunk** 는 cutoff 2024 둔화 + 저가 악화 → 운영 후보 격하 (연구 브랜치)
- **Cluster bootstrap CI 0 포함**: 표본 한계 (n=44, 13 artist) 가 본질적 — Stage 4 확장 필요
- **즉시 도입 X**: 본 보고서 §5.2 (warm = V3, cold = Track 2) 운영 권고 그대로 유지

#### 12.4.1 Feature 재탐색 결과 (코덱스 권고 후 추가 검증)
운영 채택 baseline (F4 + spline + Huber) 위에 추가 feature 검증:

| 모델 | cutoff 2022 | cutoff 2023 | cutoff 2024 | 결론 |
|---|---|---|---|---|
| **fe_only** | **10.17%** ↓7.33 | **19.17%** ↓3.98 | **21.87%** ↓4.26 | ✓ 3/3 일관 개선 |
| + gallery_tier | 15.28% | 24.72% **↑1.57** | 26.85% **↑0.72** | ✗ 악화 |
| + interaction (log_area × log_works) | 17.43% | 23.06% | 27.35% **↑1.22** | ✗ cutoff 2024 악화 |
| fe + gallery_tier | 9.96% | 17.53% | 27.05% **↑0.92** | ✗ cutoff 2024 역전 (강건성 부족) |
| fe + interaction | 11.34% | 19.88% | 22.06% | ≈ FE only ≈ |

- **gallery_tier / interaction 추가 가치 없음** — Stage 4 본실험에서 제외 (부록 sentinel 만 유지)
- **fe + gallery_tier**: cutoff 2022/2023 은 FE only 와 거의 동등하나 cutoff 2024 에서 baseline 보다 악화 — 전 cutoff 일관 우위 없음, 복잡도 증가 대비 강건성 부족
- Huber `eps` 1.35 유지 (1.5 와 -0.14%p 차이는 noise 수준)
- **단순함 = 강건함** 증거 — FE 가 이미 주요 신호 흡수, 추가 feature 는 분산만 증가

#### 12.4.2 FE only Robustness (추가 검증)
- Bootstrap n=2000 (cutoff 2024): diff -3.38%p, CI [-17.40, +9.36], P<0=72.3%
- Seed 안정성 (10 seed × cutoff 2024): mean -3.42%p (**std 0.316**), P<0 72.9% (std 0.024)
- **3 cutoff × 10 seed = 30 실험 모두 음수 방향** (방향 일관성 매우 강함)
