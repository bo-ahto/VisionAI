## 1. 배경

### 1.1 Stage 3 P3 결과 한계
- FE only 가 3 cutoff (2022 / 2023 / 2024) 모두 일관 개선 (-7.26 / -3.97 / -4.23%p)
- Artist-cluster bootstrap (n=500): mean -2.68%p, **95% CI [-14.33, +8.54]** → 0 포함
- Warm test n=44, **artist 13명 한정** (cutoff 2023 기준)
- Depth bin 분해 불가: 모든 warm test 가 10-14 depth 에 집중

### 1.2 Stage 4 목적
> **row 수가 아니라 warm artist cluster 수를 늘리는 것이 핵심** (코덱스 권고).
- 표본 확대로 cluster bootstrap CI 의 폭 좁히기
- depth bin 별 효과 분리 가능하도록 15+ depth 작가 확보
- 2024 composition shift 영향 분리 가능하도록 신규 / 기존 warm 분리 평가

## 2. 정량 목표

### 2.1 Warm artist cluster 수

> **두 축 분리** (코덱스 P1): warm artist cluster 는 **train 집계 (학습량 ≥ 10)** 와 **test 평가 가능 (n ≥ 3 / 작가)** 두 모수가 다르다. 본 계획은 두 축 모두 목표를 잡는다.

| 항목 | Stage 3 (현재, ≤2023 split) | Stage 4 (목표) | 증분 |
|---|---|---|---|
| 전체 작가 (모집단) | 100 | 200+ | +100 |
| **Warm artists** (train ≥ 10 작품) | 21 | **40+** | +19 |
| **Test 평가 가능 warm artists** (test 구간 n ≥ 3) | 13 | **25+** | +12 |
| Warm test rows | 44 | **120+** | +76 |

> 핵심 합격 모수는 **Test 평가 가능 warm artists** (cluster bootstrap resample 단위). Warm artists train 모수는 모델 fit 의 dummy 차원 확보용.

### 2.2 Depth bin 균형
| Depth bin | Stage 3 (≤2023) | Stage 4 (목표) | Test rows / bin |
|---|---|---|---|
| 10-14 | 16 작가 | 20 작가 | ≥ 30 |
| 15-24 | 5 작가 | **15 작가** | **≥ 30** |
| 25+ | 0 작가 | **5+ 작가** | **≥ 15** |

> Depth bin 별 test rows ≥ 30 이 cluster bootstrap 평가 최소 조건. 25+ depth 는 ≥ 15 도 허용 (해석용).

### 2.3 Cluster bootstrap CI 합격 기준
- FE only vs baseline mean 음수
- 95% CI 상한 ≤ 0 (즉, 통계적 유의성 확보)
- 또는 P(diff < 0) ≥ 95% (분포 기준)

## 3. 데이터 수집 전략

### 3.1 Warm artist 선정 우선순위
| 우선순위 | 조건 | 이유 |
|---|---|---|
| 1 | 기존 21명 + 작품 수 보강 (15+ 도달) | depth bin 균형 즉시 개선 |
| 2 | Stage 3 모집단 100명 중 8-9 작품 작가 (10 도달 가능) | 작가 풀 즉시 활용 |
| 3 | 신규 작가 발굴 (Saatchi / Artsy 추가 크롤) | cluster 수 확장 |
| 4 | 25+ depth 후보 작가 별도 식별 | 해석 분석용 |

### 3.2 데이터 수집 채널
- **Artsy**: 추가 크롤 — 활동 작가 페이지 / 갤러리 representation 페이지
- **Saatchi**: 작가별 작품 목록 추가 수집 (현재 21,087 → 추가 가능 풀 미정)
- **Auction archives** (별도 검토): 신뢰도 낮으면 Stage 4 에서 제외
- **갤러리 직접 제공** (가능 시): 라벨 신뢰도 최상

### 3.3 우선 cleansing rule (Stage 3 동일)
- `area_cm2 > 0`, `artist_birth_year ∈ [1850, 2010]`, `year_made ∈ [1900, 2026]`
- 가격 단위 / 통화 표준화 (KRW 기준일 환율)
- 중복 제거: `(artist_id, title, year_made, width, height, medium)` 동일 1건
- title 비-숫자 글자 포함 / medium 텍스트 비-수치성 / required text fields 비결측
- year_made 결측은 Saatchi 100% 결측 패턴 — Stage 4 도 동일 처리 (해당 작품 제외)

## 4. 분할 / 평가 protocol

### 4.1 Split 정책 — 3-way (curated 내부)

> **Stage 3 와 차이**: Stage 3 는 train/test 2-way → test reuse 발생. Stage 4 는 train/val/test 3-way 로 분리해 hyperparameter / model selection 은 val 에서, 최종 평가는 test 에서.

| Split | 정의 | 용도 |
|---|---|---|
| **Train** | year_made ≤ 2023 | 모델 fit |
| **Val** | year_made == 2024 | hyperparameter / model selection (Holm primary 외 secondary 분석) |
| **Test** | year_made == 2025 | 최종 평가 (primary hypothesis 만 사용) |
| **Rolling sensitivity** | cutoff 2022 / 2023 / 2024 multiple | 강건성 확인 (test 와 별도) |

- **Warm threshold**: train 시점 작가별 작품 수 ≥ 10 (= `WARM_ROUTING_MIN_WORKS`)
- **Stratification**: depth bin 별 stratified test (각 bin n ≥ 30 보장)
- **Test set freeze**: Phase 1 Stage 3 종료 시점에 test (year 2025) 분리, val 분리, 이후 변경 X

### 4.2 Bootstrap 정책
- **기본 단위**: artist cluster (Stage 3 의 row bootstrap 폐기)
- **반복**: n_boot = 1000 (FE only champion ≥ 2000)
- **평가 모델**: baseline / **FE only (champion, 코덱스 권고)** / Combined (참고) / Combined-shrunk (참고)
- **분리 리포트**: 신규 warm (Stage 3 학습에 없던 작가) vs 기존 warm
- **Seed 안정성**: champion 모델은 10 seed × n_boot=500 std 검증 추가 (Stage 3 robustness 결과 std 0.316)

### 4.2.1 본실험 제외 모델 (Stage 3 재탐색 결과)
- **+ gallery_tier dummy**: cutoff 2023/2024 baseline 보다 악화 (`+1.57 / +0.72%p`)
- **+ log_area × log_works interaction**: cutoff 2024 `+1.22%p` 악화
- **fe + tier / fe + interaction**: FE only 보다 약함 (cutoff 2024 `+0.92%p`)
- → Stage 4 본실험에서는 제외, 부록 재현 표만 1회 (sentinel)
- → `medium_category`, 다중 interaction, Core 5 조합 도 동일 보류 (`experiments/structural_v1/stage3_warm_feature_exploration.py` 참조)

### 4.3 Composition-shift 리포트 (필수)
- Test set 의 신규 warm 비율 추적
- 신규 warm vs 기존 warm 의 MdAPE 분리
- 가격 분포 (median / IQR) Stage 3 vs Stage 4 비교
- depth 분포 비교

### 4.4 Sample Size Justification (사전 power 계산)

| 항목 | Stage 3 (실측) | Stage 4 (사전 요구) |
|---|---|---|
| Detectable minimum effect | ~3.4%p (실측) | **2.5%p** (Stage 3 점추정의 73%) |
| Required artist cluster (test) | 13 | **25+** (≥ 1.9× Stage 3) |
| Required test rows (warm) | 44 | **120+** (≥ 2.7× Stage 3) |
| α | 0.05 (1-sided) | 0.05 (1-sided) |
| Target power | — | **0.80** |
| Bootstrap iterations | 500 | **2,000** (champion) |
| Seed 안정성 | 10 seed std=0.316 | std ≤ 0.5 요구 |

> Power 계산은 cluster bootstrap 기반 simulation 으로 수행 (`experiments/structural_v1/stage4_power_simulation.py` 신규 작성 예정).

### 6.0 Pre-registered Analysis Plan (Stage 4 시작 전 freeze)

| 항목 | 사전 고정 값 |
|---|---|
| **Primary hypothesis** | H₀: MdAPE(FE only) ≥ MdAPE(baseline) / H₁: MdAPE(FE only) < MdAPE(baseline) |
| **Primary metric** | warm-only MdAPE (artist-cluster bootstrap, n=2000) |
| **Primary test** | 1-sided 95% CI, 단일 비교 (다중비교 보정 부담 최소) |
| **Practical significance** | MdAPE 차이 ≤ -0.8%p (상한, 코덱스 권고) |
| **Secondary hypotheses** (Holm m=4) | Combined / Combined-shrunk / FE only by depth bin (10-14 / 15-24 / 25+) |
| **Sample 분할** | Time-split 다중 cutoff (2022 / 2023 / 2024 / 2025) |
| **Stratification** | warm artist depth bin (10-14 / 15-24 / 25+) |
| **Bootstrap unit** | artist cluster |
| **Seed 안정성** | 10 seed 평균 + std (std ≤ 0.5%p 요구) |
| **본실험 제외 모델** | + gallery_tier / + interaction / + medium_category / Core 5 (Stage 3 재탐색 결과 기준) |

### 6.1 합격 (Stage 4 exploratory champion 확정)
- **Primary**: FE only vs baseline 단일 비교
  - cluster bootstrap CI 상한 ≤ 0 (또는 P<0 ≥ 95%)
  - **MdAPE 차이 점추정 ≤ -0.8%p** (practical significance)
- **Secondary** (Holm m=4 보정 후):
  - depth bin 별 모두 baseline 대비 개선 (악화 bin 0건) — Holm 보정 후
  - 신규 warm vs 기존 warm 모두 개선 또는 동등
- **Segment harm budget** (어느 하나도 초과 X):
  - 가격 저가/중가/고가: +1.0 / +0.5 / +1.0%p
  - source Artsy / Saatchi: +1.0 / +1.0%p
  - depth bin 10-14 / 15-24 / 25+: +1.5 / +1.0 / +0.5%p
- → Phase 2 (Confirmatory Run 1) 진입 자격
- → spec §17 W-S 진입은 Phase 2 합격 후 (즉시 X)

### 6.2 보류 (Stage 5 추가 데이터 필요)
- Primary CI 상한 ∈ (0, +1%p] (부분 유의)
- Practical significance 미달 (점추정 ∈ (-0.8, 0]%p)
- Segment harm 1-2 개 임계 초과
- depth bin 1개 악화

### 6.3 폐기 (warm-only path 후보 제거)
- Primary 점추정 양수 또는 ±0%p 근처
- depth bin 2개 이상 악화
- Segment harm 3개 이상 임계 초과
- 신규 warm 일관 악화

### 6.4 Deviation Rule
- 사전등록 vs 실제 차이 발생 시 별도 deviation log (`docs/methodology_deviation_log.md`) 기록
- Major deviation (가설 / metric / 임계 변경) → 새 exploratory cycle 분리, 본 결과는 폐기
