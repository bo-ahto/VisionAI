# Stage 4 데이터 수집 계획 — Warm Path 재검증

> **작성일**: 2026-05-07
> **목적**: Warm-only Track 2 path (FE only) 의 cluster bootstrap CI 가 0 위에 위치하도록 표본 확장
> **연계**: `docs/트랙2_최종보고서_20260506.md` §12 부록 / `docs/트랙2_production_통합_spec_20260507.md` §17

## 1. 배경

### 1.1 Stage 3 P3 결과 한계
- FE only 가 3 cutoff (2022 / 2023 / 2024) 모두 일관 개선 (-7.26 / -3.97 / -4.23%p)
- Artist-cluster bootstrap (n=500): mean -2.68%p, **95% CI [-14.33, +8.54]** → 0 포함
- Warm test n=44, **artist 13명 한정** (cutoff 2023 기준)
- Depth bin 분해 불가: 모든 warm test 가 10-14 depth 에 집중

### 1.2 Stage 4 목적
> **row 수가 아니라 warm artist cluster 수를 늘리는 것이 핵심** (코덱스 권고).
- 표본 확대로 cluster bootstrap CI 의 폭 좁히기
- depth bin 별 효과 분리 가능하도록 15+ depth 작가 확보
- 2024 composition shift 영향 분리 가능하도록 신규 / 기존 warm 분리 평가

## 2. 정량 목표

### 2.1 Warm artist cluster 수

> **두 축 분리** (코덱스 P1): warm artist cluster 는 **train 집계 (학습량 ≥ 10)** 와 **test 평가 가능 (n ≥ 3 / 작가)** 두 모수가 다르다. 본 계획은 두 축 모두 목표를 잡는다.

| 항목 | Stage 3 (현재, ≤2023 split) | Stage 4 (목표) | 증분 |
|---|---|---|---|
| 전체 작가 (모집단) | 100 | 200+ | +100 |
| **Warm artists** (train ≥ 10 작품) | 21 | **40+** | +19 |
| **Test 평가 가능 warm artists** (test 구간 n ≥ 3) | 13 | **25+** | +12 |
| Warm test rows | 44 | **120+** | +76 |

> 핵심 합격 모수는 **Test 평가 가능 warm artists** (cluster bootstrap resample 단위). Warm artists train 모수는 모델 fit 의 dummy 차원 확보용.

### 2.2 Depth bin 균형
| Depth bin | Stage 3 (≤2023) | Stage 4 (목표) | Test rows / bin |
|---|---|---|---|
| 10-14 | 16 작가 | 20 작가 | ≥ 30 |
| 15-24 | 5 작가 | **15 작가** | **≥ 30** |
| 25+ | 0 작가 | **5+ 작가** | **≥ 15** |

> Depth bin 별 test rows ≥ 30 이 cluster bootstrap 평가 최소 조건. 25+ depth 는 ≥ 15 도 허용 (해석용).

### 2.3 Cluster bootstrap CI 합격 기준
- FE only vs baseline mean 음수
- 95% CI 상한 ≤ 0 (즉, 통계적 유의성 확보)
- 또는 P(diff < 0) ≥ 95% (분포 기준)

## 3. 데이터 수집 전략

### 3.1 Warm artist 선정 우선순위
| 우선순위 | 조건 | 이유 |
|---|---|---|
| 1 | 기존 21명 + 작품 수 보강 (15+ 도달) | depth bin 균형 즉시 개선 |
| 2 | Stage 3 모집단 100명 중 8-9 작품 작가 (10 도달 가능) | 작가 풀 즉시 활용 |
| 3 | 신규 작가 발굴 (Saatchi / Artsy 추가 크롤) | cluster 수 확장 |
| 4 | 25+ depth 후보 작가 별도 식별 | 해석 분석용 |

### 3.2 데이터 수집 채널
- **Artsy**: 추가 크롤 — 활동 작가 페이지 / 갤러리 representation 페이지
- **Saatchi**: 작가별 작품 목록 추가 수집 (현재 21,087 → 추가 가능 풀 미정)
- **Auction archives** (별도 검토): 신뢰도 낮으면 Stage 4 에서 제외
- **갤러리 직접 제공** (가능 시): 라벨 신뢰도 최상

### 3.3 우선 cleansing rule (Stage 3 동일)
- `area_cm2 > 0`, `artist_birth_year ∈ [1850, 2010]`, `year_made ∈ [1900, 2026]`
- 가격 단위 / 통화 표준화 (KRW 기준일 환율)
- 중복 제거: `(artist_id, title, year_made, width, height, medium)` 동일 1건
- title 비-숫자 글자 포함 / medium 텍스트 비-수치성 / required text fields 비결측
- year_made 결측은 Saatchi 100% 결측 패턴 — Stage 4 도 동일 처리 (해당 작품 제외)

## 4. 분할 / 평가 protocol

### 4.1 Split 정책 (Stage 3 와 동일)
- **Time-split**: train ≤ 2023 (또는 2024 / 2025 rolling), test > cutoff
- **Warm threshold**: train 시점 작가별 작품 수 ≥ 10
- **추가**: depth bin 별 stratified test (각 bin n ≥ 30 보장)

### 4.2 Bootstrap 정책
- **기본 단위**: artist cluster (Stage 3 의 row bootstrap 폐기)
- **반복**: n_boot = 1000 (FE only champion ≥ 2000)
- **평가 모델**: baseline / **FE only (champion, 코덱스 권고)** / Combined (참고) / Combined-shrunk (참고)
- **분리 리포트**: 신규 warm (Stage 3 학습에 없던 작가) vs 기존 warm
- **Seed 안정성**: champion 모델은 10 seed × n_boot=500 std 검증 추가 (Stage 3 robustness 결과 std 0.316)

### 4.2.1 본실험 제외 모델 (Stage 3 재탐색 결과)
- **+ gallery_tier dummy**: cutoff 2023/2024 baseline 보다 악화 (`+1.57 / +0.72%p`)
- **+ log_area × log_works interaction**: cutoff 2024 `+1.22%p` 악화
- **fe + tier / fe + interaction**: FE only 보다 약함 (cutoff 2024 `+0.92%p`)
- → Stage 4 본실험에서는 제외, 부록 재현 표만 1회 (sentinel)
- → `medium_category`, 다중 interaction, Core 5 조합 도 동일 보류 (`experiments/structural_v1/stage3_warm_feature_exploration.py` 참조)

### 4.3 Composition-shift 리포트 (필수)
- Test set 의 신규 warm 비율 추적
- 신규 warm vs 기존 warm 의 MdAPE 분리
- 가격 분포 (median / IQR) Stage 3 vs Stage 4 비교
- depth 분포 비교

## 6. 합격 / 보류 / 폐기 결정 기준

### 6.1 합격 (FE only warm-only path 도입 결정)
- Cluster bootstrap CI 상한 ≤ 0 (또는 P<0 ≥ 95%)
- depth bin 별 모두 baseline 대비 개선 (악화 bin 0건)
- 신규 warm vs 기존 warm 모두 baseline 대비 개선 (또는 동등)
- → Production spec §17 W-S (Shadow) 단계 진입

### 6.2 보류 (Stage 5 추가 데이터 필요)
- CI 상한 ∈ (0, +1%p] (부분 유의)
- depth bin 1개 악화 (예: 10-14 만 악화) → 정책 게이트 추가 후 재평가

### 6.3 폐기 (warm-only path 후보 제거)
- 평균 차이 점추정 양수 또는 ±0%p 근처
- depth bin 2개 이상 악화
- 신규 warm 에서 일관 악화 → 운영 risk 너무 큼
