크기 2배 → 가격 1.76배 (체감 증가). 국내 갤러리(KRW) β=0.749는 Shin(2010)의 0.74와 거의 일치.

7. 향후 계획

1

작가 프로필 자동 보강

Artue에서 작품이 판매될 때마다 자동으로 학습 데이터에 추가한다. Cold Start 작가(MdAPE 33.0%)도 1~2건의 판매 이력만 쌓이면 XGBoost 경로(MdAPE 14.2%)로 전환.

판매 발생 → 학습 데이터 추가 → 모델 재학습 → Cold Start 탈출 현재: 362명 중 46명만 XGBoost (13%) 1건 판매 후: XGBoost 비율 → 50%+ 3건 판매 후: XGBoost 비율 → 80%+
2

이미지 피처 도입

작품 이미지에서 스타일/색감/구도 정보를 추출하여 가격 예측에 활용한다.

작품 이미지 → CLIP/ResNet embedding (512~2048차원) → PCA 압축 (32~64차원) → XGBoost 피처로 추가 기대 효과: - 같은 크기/같은 작가라도 "작품의 질"에 따른 가격 차이 학습 - Cold Start 작가도 이미지 스타일로 유사 작가 매칭 가능

Artsy에서 이미지 URL을 99% 수집했으므로, embedding 추출만 추가하면 된다. 딥러닝 직접 학습이 아니라 embedding을 트리 모델의 피처로 넣는 하이브리드 방식.

3

가격 구간 예측 (Quantile Regression)

단일 가격(점 예측) 대신 가격 구간을 제공하여 신뢰감 향상.

현재: "예측 가격: 350만원" 개선: "예측 가격: 280만~420만원 (80% 신뢰구간), 중앙 350만원"

활용:
• 갤러리: "이 작품은 280~420만원 사이가 적정합니다"
• 작가: "비슷한 작가 대비 상위 20% 가격대입니다"

4

다른 갤러리 데이터 통합

Artue 통합으로 MdAPE가 41.6% → 14.2%로 개선된 것처럼, 추가 갤러리 데이터가 곧 정확도 향상.

8. 모델 설명 방법

8.1 왜 트리 모델인가

모델기존 작가 MdAPE특징
헤도닉 회귀40.5%공식 있음, 비선형 학습 불가
헤도닉 + 인터랙션30.5%강화해도 20.7%p 격차
XGBoost11.6%비선형+인터랙션 자동 학습

헤도닉은 ln(Price) = β₀ + β₁×ln(Ho) + ... 형태의 공식을 제공하지만, 비선형 관계와 조건부 인터랙션을 학습할 수 없다. 트리 모델은 공식이 없지만, SHAP으로 개별 예측을 %로 분해하여 설명 가능.

8.2 딥러닝을 쓰지 않는 이유

10,307건은 딥러닝에 부족한 데이터이며, 예측 근거 설명이 불가능하다. 향후 이미지 피처 추가 시 딥러닝으로 embedding만 추출하고, 트리 모델에 투입하는 하이브리드 방식이 현실적.

9. 용어 설명

MdAPE
Median Absolute Percentage Error. 예측 오차의 중앙값. MdAPE 14.2%는 전체 작품 중 절반이 이 오차보다 정확하다는 의미.
W30
예측 오차가 30% 이내인 작품의 비율. W30=69.7%이면 10건 중 7건이 실제 가격 대비 30% 이내.
예측/실제 비율
1.0x = 정확, 1.5x = 50% 과대 예측. 1.00x는 체계적 편향이 없다는 의미.
Cold Start
학습 시 본 적 없는 작가의 가격을 예측하는 상황. 판매 이력이 쌓이면 자동으로 해소.
SHAP
SHapley Additive exPlanations. 기준가(전체 평균)에서 출발하여 각 피처가 가격을 올리고 내리는 정도를 %로 분해하는 설명 방법.
XGBoost / CatBoost
Gradient Boosted Tree 계열 모델. XGBoost는 기존 작가(MdAPE 14.2%), CatBoost는 Cold Start(MdAPE 33.0%)에서 사용.
호당 가격제
한국 갤러리의 가격 관행. Price = α × Ho^β. β = 0.817. 크기 2배이면 가격 1.76배.
헤도닉 회귀
ln(Price) = β₀ + β₁×ln(크기) + ... 형태의 선형 모델. 트리 모델 대비 20%p+ 부정확.
