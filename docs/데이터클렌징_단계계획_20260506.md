# 데이터 클렌징 단계 계획

> **작성일**: 2026-05-06
> **목적**: 트랙 2 (Hedonic Mixed-Effects) 학습용 신뢰 데이터셋 단계적 구축
> **연계**: `docs/1개월_병행일정_V5_Structural.html` 트랙 2 Week 1-2 (후보 정의 → freeze)

## 1. 배경

### 현재 데이터 풀
- Artsy: 7,289건
- Saatchi: 21,087건
- 통합: ~28,376건 (필터링 전)

### 문제 인식
- 현재 운영 모델 신규 작가 MdAPE 28-48% (정확도 한계)
- 트랙 2 within-artist 식별을 위해 작가당 충분한 표본 필요
- 전체 데이터에 결측 / 이상치 / 표준화 불가 데이터 다수 혼재

### 단계적 접근 이유
- 작은 규모부터 cleansing pipeline 검증
- 단계별 모델 안정성 / 계수 부호 / 운영 적합성 점검
- 큰 데이터셋에서 발견되기 어려운 규칙 위반을 작은 셋에서 사전 검출

## 2. 단계별 데이터셋 구성

### Stage 1 — 데이터 규칙 검증
- **규모**: 200 records / 20 artists (작가당 평균 10작품)
- **목적**: cleansing pipeline 확정 + 포함/제외 규칙 검증
- **모델 학습**: ❌ (rules verification only)
- **출력**: cleansing 규칙 문서 + 제외 사유 로그

### Stage 2 — 1차 성능 평가
- **규모**: 500 records / 50 artists (작가당 평균 10작품)
- **목적**: OLS hedonic 1차 fit + 계수 부호·크기 확인
- **모델 학습**: ✅ (탐색적)
  - OLS hedonic
  - Mixed-effects: random intercept 중심 (random slope X — 표본 부족)
- **출력**: 계수 표 + 안정성 점검 + literature 일치 여부

### Stage 3 — 운영 적합성 판단
- **규모 (계획)**: 1,000 records / 100 artists (작가당 평균 10작품)
- **규모 (실제)**: 1,378 records / 100 artists (cleansing rule 통과 후, 모집단 2,903)
- **목적**: 최종 freeze 후보 + within-artist 식별
- **모델 학습**: ✅ (final candidate)
  - OLS hedonic + ME random intercept
  - **Random slope 점검은 조건부**: Stage 3 셋에서 작가당 작품 수 ≥ 15 인 sub-sample 으로만 시도
  - Within-artist FE 비교
- **출력**: 트랙 2 final freeze set + 해석 보고서 초안

## 3. "확실한 데이터" 선정 기준

### 필수 변수 완전성

| 카테고리 | 필수 변수 | 결측/오류 시 처리 |
|---|---|---|
| 식별 | `artist_id`, `source` | 결측 → 제외 |
| 가격 | `price`, `currency` | 표준화 불가 → 제외 |
| 작품 | `width × height`, `medium`, `year_made` | 결측률 ≤ 10% |
| 품질 | 중복 / 이상치 / medium 텍스트 불명확 | 제외 |

### 작품 단위 제외 사유 (예시)
- 가격 단위 / 통화 표준화 불가
- 면적 = 0 또는 비현실적 큰 수치
- year_made = 미래 또는 작가 사망 후
- medium 텍스트가 "mixed media unspecified" 등 모호
- price 가 동일 작가 평균의 100배 초과 등

### 구현 명시 사항 (필수)
- **FX 환율 기준일**: snapshot 일자 (수요일 마이그레이션 기준) 의 KRW 환율로 통일
- **중복 판정 키**: (`artist_id`, `title`, `year_made`, `width`, `height`, `medium`) 동일 시 1건만 유지
- **artist_id canonicalization**: slug 정규화 (대소문자 / 공백 / 특수문자 일관)
- **Holdout 분할 단위**: 작가 단위 (artist-level holdout, LAO split) — 작품 단위 분할 금지

### 작가 단위 포함 기준
- 작품 수 ≥ 10건 (Stage 1-3 공통 하한, Stage 3 의 slope 점검은 ≥ 15)
- 핵심 변수 완전성 ≥ 90%
- 가격 분포가 한 점에 collapse 되지 않음 (variance > 0)

## 4. Stratified Selection (균형 차원)

### 우선순위

| 순위 | 차원 | 이유 |
|---|---|---|
| 1 | `source` (Artsy / Saatchi) | 한쪽 쏠림 = artist effect 와 confound |
| 2 | `medium` (oil/acrylic/paper/...) | 매체 분포 균형 필요 |
| 3 | `gallery_tier` 또는 `price band` | 가격대 균형 (cold-start 일반화) |
| 4 (여유 시) | `career stage` | early/mid/late 균형 |

### Strata Quota 원칙
- 각 strata cell 최소 n ≥ 5
- Source 비율: Stage 별로 사전 결정 (예: Artsy 60% / Saatchi 40%)
- Medium: oil 30% / acrylic 25% / paper 20% / other 25% (예시)

## 6. 위험 요인 및 대응

| 위험 | 대응 |
|---|---|
| 작가당 10작품으로 random slope 불안정 | random intercept 중심 / Stage 3 의 작가당 ≥ 15 sub-sample 만 slope 점검 |
| Strata 균형 미충족 (source 쏠림) | quota 사전 고정 + 부족 시 작가 추가 선정 |
| Stage 1 결과만으로 모델 일반화 시도 | rules 검증 only / 모델 학습 금지 명시 |
| 핵심 변수 결측률 높음 | 결측 허용치 사전 결정 + missingness flag 변수 추가 |
| 이상치 정의 모호 | Cook's distance > 4/n + 작가 평균 100배 등 명시 규칙 |
| **Selection bias** (curated 셋이 모집단 대표성 X) | 모집단 분포와 strata 일치 검증 + sensitivity 보고 |
| **Source 별 가격 정책 차이** (Artsy vs Saatchi 동일 작품 가격 다름 가능) | source dummy + 분리 모델 sensitivity check |
| **Survivorship bias** (현재 활동 작가만 샘플링) | 작가 활동 종료 / 사망 케이스 별도 표기 |
| **Time drift** (year_made vs 판매 시점 불일치) | year_made + sale_year 둘 다 보유 / vintage 효과 별도 모델 |
