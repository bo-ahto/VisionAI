본 연구는 한국 미술 1차 시장 작품의 거래 가격을 예측하는 기계학습 모델을 개발한다. 1. 연구 배경 및 목적

1.1 문제 정의

한국 미술 시장에서 작품 가격은 작가 인지도, 작품 크기, 재료, 갤러리 판매처, 제작 연도 등 다수 요인에 의해 결정된다. 그러나 시장 호가는 일반에 공개되지 않거나 거래마다 큰 분산을 보이며, 신진 작가의 경우 적정 가격 산정 자체가 어려워 갤러리·작가·구매자 간의 정보 비대칭이 크다. 본 연구는 이러한 정보 비대칭을 줄이기 위해 작품 정보 입력만으로 1차 시장 가격을 추정하는 기계학습 모델을 구축한다.

1.2 연구 목표

  1. 한국 작가의 1차 시장 작품 가격을 오차 중앙값(MdAPE) 8% 이내로 예측하는 모델 (warm Artsy slice 기준)
  2. 학습량 부족 작가(cold start) 영역의 예측 정확도를 40% 이내로 안정화하고 보정 메커니즘 도입
  3. 예측 신뢰도를 등급별로 분류(A/B/C/D)하여 사용자가 결과를 적절히 활용할 수 있도록 하는 운영 인터페이스 제공
  4. 학습 데이터 출처(Artsy / Saatchi) 간 분포 차이로 인한 편향을 정량 분석하고 후처리 보정으로 통제

1.3 1차 시장 vs 2차 시장

본 연구는 1차 시장(Primary Market)을 대상으로 한다. 미술 시장은 거래 단계에 따라 두 시장으로 구분된다.

표 1.1. 1차 시장과 2차 시장의 구분
구분의미본 연구 범위
1차 시장 작가가 처음 작품을 시장에 출품하는 단계의 갤러리·온라인 마켓 호가 ✓ 본 모델 (모델 A)

3. 모델 아키텍처

3.1 전체 구조

본 모델은 작가 학습량에 따라 두 가지 Gradient Boosting Decision Tree (GBDT) 모델로 분기하는 2-way routing 구조를 채택한다.

입력 작품 (32 피처)
   │
   ├─ 작가 매칭 + warm artist 판정
   │   ├─ 작가 slug ∈ warm_artist_slugs (≥5건 학습) ?
   │   │   ├─ Yes → XGBoost (정밀 모델)
   │   │   └─ No  → CatBoost (일반화 모델)
   │
   ├─ 모델 예측 → ln(P_raw)
   │
   ├─ 후처리 1: Cell calibration (cold path만)
   │   └─ P_corrected = exp(ln(P_raw)) × factor[source × target_market]
   │
   ├─ 후처리 2: 신뢰도 등급 부여 (A/B/C/D) + 마진 산출
   │   └─ price_low = price × (1 − m) / price_high = price × (1 + m)
   │
   └─ 출력: { price_krw, price_low, price_high, grade, margin, model_type }

3.2 라우팅 의사결정의 근거

두 모델을 분리한 이유는 두 데이터 분포에서 기대되는 패턴이 다르기 때문이다.

표 3.1. warm/cold 모델 선택 근거
특성Warm 영역 (≥5건)Cold 영역 (1~4건 / 신규)
작가별 가격 분포 충분한 표본으로 평균·분산 안정 표본 부족, 분산 추정 불안정

4. 핵심 수식 및 알고리즘

4.1 학습 목표 — log-price 회귀

가격은 right-skewed 분포 (소수의 고가 작품이 평균을 왜곡)를 가지므로, 자연로그 변환된 가격을 예측 목표로 사용한다.

학습 목표 (Loss) — squared-error objective on log-price (MSE)
$$ \mathcal{L} = \frac{1}{N}\sum_{i=1}^{N}\left( \ln(P_{i, \text{actual}}) - \hat{f}(\mathbf{x}_i) \right)^2 $$
$\hat{f}(\mathbf{x}_i)$ : 모델이 작품 $i$의 입력 $\mathbf{x}_i$에 대해 추정한 $\ln(P)$ 값. 학습 목적함수는 log-price 공간의 평균 제곱 오차(MSE). CatBoost는 RMSE loss option(내부적으로 동일 minimum 갖는 squared-error objective)을 사용. 평가 지표는 별도로 MdAPE (정의는 §6 참조).

4.2 라우팅 함수

모델 라우팅
$$ \text{model}(\mathbf{x}) = \begin{cases} \text{XGBoost} & \text{if } s(\mathbf{x}) \in \mathcal{W} \\ \text{CatBoost} & \text{otherwise} \end{cases} $$
$s(\mathbf{x})$ : 입력 작품의 작가 식별자 (artist_slug)
$\mathcal{W}$ : warm artist set. 학습 시점에 ≥5건 학습 작품을 가진 작가 930명 집합. 학습 후 JSON으로 동결되어 서빙 시 권위적으로 lookup된다.

4.3 GBDT 모델의 예측

두 모델 모두 K개의 회귀 트리 ensemble로 표현된다.

GBDT 예측 함수
$$ \hat{f}(\mathbf{x}) = \sum_{k=1}^{K} \eta \cdot t_k(\mathbf{x}) $$
$t_k(\mathbf{x})$ : $k$번째 회귀 트리의 출력 (해당 leaf의 weight)
$\eta$ : learning rate (실제 tuned 값: CatBoost 0.0953, XGBoost 0.0401 — §5.1 표 참조)
$K$ : 트리 수 (Optuna 탐색 결과: CatBoost 1,000, XGBoost 3,000)

4.4 후처리 1 — Cell-based Calibration (Cold path)

cold 영역(CatBoost)에는 학습 데이터 출처별 분포 편향을 후처리로 보정한다.

4.4.1 셀 정의

$$ \text{cell}(\mathbf{x}) = (\text{source}(\mathbf{x}), \text{target\_market}(\mathbf{x})) $$
source ∈ {artsy, saatchi}
target_market ∈ {gallery, online} — 학습/오프라인 평가: 데이터 행의 is_krw == 1이면 'gallery', 아니면 'online'으로 도출하여 셀 키 산출 (scripts/calibrate_source_bias.py, scripts/calibrate_grade_margins.py). 서빙: predictor는 caller(API 요청)가 직접 전달한 target_market 값을 그대로 셀 키 산출에 사용 (primary_predictor.py:306, 371) — is_krw 자동 추론이나 일치 검증은 하지 않으며, parity 보장은 upstream caller 계약에 의존.
가능한 셀: artsy_gallery (n=868), artsy_online (n=6,421), saatchi_online (n=21,087), saatchi_gallery (n=0, OOD)

4.4.2 Factor 산출

셀별 보정 계수 (factor)
$$ \text{factor}[c] = \text{median}_{i \in c} \left( \frac{P_{i, \text{actual}}}{\hat{P}_{i, \text{predicted}}} \right) $$
$c$ : 셀 식별자 (예: artsy_online)
중앙값 사용 이유: right-skewed 가격 분포에서 평균 대비 robust한 추정
factor 해석: factor < 1 ⇒ 모델 과대예측 (실제 < 예측) ⇒ 곱셈으로 깎아 보정 / factor > 1 ⇒ 모델 과소예측 ⇒ 곱셈으로 올려 보정

4.4.3 5-fold Cross-fit OOF + Per-cell guard

self-reference (자기 자신의 데이터로 추정·평가)에 의한 leakage를 방지하기 위해 5-fold cross-fit OOF (Out-of-Fold) 방식을 사용한다.

Cross-fit factor 산출 절차 (구현: scripts/calibrate_source_bias.py)
1. Cold 학습 데이터를 5-fold로 분할 (GroupKFold by artist_slug)
2. for each fold k ∈ {1..5}:
   a. CatBoost를 다른 4개 fold로 학습 → 모델 m_k
   b. fold k에 대해 OOF 예측 ŷ_k 산출
   c. for each cell c:
        per_fold_factor[k, c] = median(P_actual / m_k(x) | x ∈ fold k AND cell == c)
   d. fold k의 OOF 예측에 per_fold_factor[k, c]를 적용하여 calibrated_OOF_k 산출
3. for each cell c (production factor):
   a. proposed_factor[c] = median(P_actual / OOF_predicted | cell == c)
   b. baseline_MdAPE[c]   = MdAPE(without calibration | cell == c)
   c. calibrated_MdAPE[c] = MdAPE(per-fold cross-fit calibrated | cell == c)
   d. if calibrated_MdAPE[c] > baseline_MdAPE[c]:
        applied_factor[c] = 1.0  ← regression guard
      else:
        applied_factor[c] = proposed_factor[c]
핵심: held-out fold 평가 시 그 fold의 모델·factor 모두 다른 4개 fold로부터 추정 → self-reference leakage 방지. production에 동결되는 factor는 전체 데이터에서 산출하지만, MdAPE 평가는 per-fold 추정값으로 한다.

4.5 후처리 2 — 신뢰도 등급 및 마진 산출

신뢰도 등급 함수 (구현: primary_predictor.py:52-89)
$$ G(\mathbf{x}) = \begin{cases} \text{A} & \text{if matched} \land\, s(\mathbf{x}) \in \mathcal{W} \\ \text{B} & \text{if matched} \land\, s(\mathbf{x}) \notin \mathcal{W} \land\, n_{\text{train}}(\mathbf{x}) \geq 1 \\ \text{C} & \text{if has\_birth\_year} \lor\, \text{has\_manual\_profile} \\ \text{D} & \text{otherwise} \end{cases} $$
matched: 작가 매칭 시스템이 작가를 식별한 경우
$\mathcal{W}$ : warm artist set (≥5건, 930명) — JSON으로 동결되어 권위적 lookup
$n_{\text{train}}(\mathbf{x})$ : 작가의 학습 작품 수 (training_count) — B 등급은 매칭 + warm slice 외부 + 학습 1건 이상 필요
가격 범위 산출
$$ P_{\text{low}} = \hat{P} \cdot (1 - m_G), \quad P_{\text{high}} = \hat{P} \cdot (1 + m_G) $$
$m_G$ : 등급별 마진. production-time 80% 커버리지 산출 결과 (grade_margin_calibration.json):
$m_A = 0.286$ (현재 적용 0.20), $m_B = 0.609$ (현재 0.30), $m_C = 0.896$ (현재 0.50), $m_D = 0.827$ (현재 0.70)

5.3 학습/서빙 정합 (train/serve consistency)

6. 평가 방법 및 지표

6.1 교차 검증 설계

두 가지 교차 검증을 병행하여 서로 다른 일반화 시나리오를 평가한다.

표 6.1. 교차 검증 방식
방식분할 단위평가하는 일반화적용 영역
KFold (5-fold) 작품 단위 "이미 본 작가의 새 작품" warm 영역
GroupKFold (5-fold) 작가 단위 (artist_slug groups) "한 번도 본 적 없는 작가" (cold-start 시뮬레이션) cold 영역

6.2 평가 지표

MdAPE (Median Absolute Percentage Error)
$$ \text{MdAPE} = \text{median}_i\left( \frac{|P_{i, \text{actual}} - \hat{P}_i|}{P_{i, \text{actual}}} \right) \times 100 $$
오차 비율의 중앙값. 작을수록 정확. right-skewed 분포에서 평균(MAPE)보다 robust.
예: MdAPE 9.7% ⇒ "절반의 작품을 ±9.7% 이내로 맞춤"
W30 (Within 30% Error Rate)
$$ W_{30} = \frac{1}{N} \sum_{i=1}^{N} \mathbb{1}\left[ \frac{|P_{i, \text{actual}} - \hat{P}_i|}{P_{i, \text{actual}}} \leq 0.3 \right] \times 100 $$
예측이 실제값의 ±30% 안에 들어간 비율. 클수록 좋음.
예: W30 = 82.8% ⇒ "82.8%의 작품을 ±30% 안에서 맞춤"

6.3 메트릭 선택의 정당성

한국 미술 시장 가격은 다음 특성을 가진다.

  • Right-skewed 분포 — 소수의 초고가 작품(억 원대)이 존재
  • 대수정규(log-normal) 가격 ⇒ ln(P) 공간에서 학습이 자연스러움
  • 가격 단위가 작품마다 다름 (50만 원 ~ 5억 원) ⇒ 절대 오차보다 상대 오차가 의미 있음

이러한 특성에서 평균 기반 지표(MAPE, MAE)는 극단 케이스에 흔들리므로, 중앙값 기반 MdAPE를 주요 지표로 채택하였다.

7.5 정직한 caveat

위 메트릭에는 다음 한계가 있음을 명시한다.

  • Cross-fit calibration의 post-hoc selection bias: factor 추정은 OOF지만, "어느 셀이 회귀하는지" guard 결정이 같은 OOF 결과를 보고 결정되어 잔존 bias가 있다. nested CV (outer fold guard 결정, inner fold factor 추정)는 계산 비용으로 미시행.
  • Production-time MdAPE: 모델 OOF 예측 + full-data routing/calibration artifact 결합 평가이므로 순수 OOF 아님.
  • 결론: 38.3% / 9.7%는 보수적 추정치. 실제 production은 그 이상일 가능성도 있음.

8. 연구 과정에서 발견한 핵심 인사이트

8.1 Train/Serve Drift가 정확도보다 큰 병목

본 연구에서 가장 중요한 발견은 피처 추가보다 학습/서빙 정합이 더 큰 정확도 병목이라는 점이다. v1 모델 분석 시 발견한 5개 drift 피처(§5.3)를 제거하니 cold MdAPE가 40.6 → 39.4로 개선되었다. 이는 다음을 의미한다:

  • 학습 데이터에 분포가 있지만 서빙 시점에는 항상 동일 값(주로 0)이 입력되는 피처는 모델 입장에서 silent noise가 된다.
  • 이러한 drift는 정확도 그래프에 직접 잡히지 않아 발견이 어렵다.
  • 발견 방법론: 학습 데이터 분포 + 서빙 코드 동시 검토 + feature importance와 production 행동 대조.

8.2 출처별 편향과 셀 단위 보정

v1에서는 단일 상수 보정 $c = -0.075$ (online인 경우, ln 공간 additive)을 사용했다. 본 연구에서 이 방식이 다음 한계를 가짐을 정량 분석하였다.

  1. Artsy/Saatchi 두 출처에 동일한 보정값 적용 ⇒ 한쪽 과보정·한쪽 부족보정
  2. Saatchi 학습 데이터가 100% 온라인이라 source 효과와 target_market 효과가 entangle
  3. OOD 셀(saatchi_gallery)에 잘못된 보정 적용 위험

해결책으로 (source × target_market) 셀별 multiplicative factor를 도입하고, cross-fit OOF로 factor를 추정하며 회귀 셀에 대해 가드를 적용하였다 (§4.4).

8.4 cold-start의 본질적 한계

Cold MdAPE 38.3%는 현재 학습 데이터 제약 하에서 모델 구조 변경만으로 더 줄이기 어려운 plateau에 가깝다고 판단되며, 그 근거를 다음과 같이 분석하였다:

  • 생년 결측 72% — 작가 경력 추정이 어려움
  • 고가 작품 1,678건(5.7%)이 분포 꼬리에 위치 — 표본 부족
  • 신규 작가 외부 정보 수집의 정확도 한계

해결책은 모델 구조 변경보다 데이터 수집 강화 + 갤러리 정보 정합에 의존한다. §9 후속 계획에서 구체화한다.

10. 기대 효과 및 활용 방안

10.1 학술적 기여

  • 한국 미술 시장의 비공개·소규모·right-skewed 거래 데이터에 적합한 GBDT + cell calibration 방법론을 제시
  • Train/serve drift 진단 및 제거가 피처 추가보다 더 큰 정확도 개선을 가져옴을 정량 입증
  • 출처 라벨 효과의 통제 실험 방법론을 제안 (n=30, 3 코호트, source flip)

10.2 산업적 활용

  • 갤러리 운영: 작품 가격 책정 시 객관적 참고가 제공 (warm Artsy 8.3% MdAPE)
  • 컬렉터·구매자: 적정 가격 검토를 통한 정보 비대칭 완화
  • 플랫폼 운영자(콜론30): 작가·작품 등록 단계의 가격 추정 자동화. 신뢰도 등급(A/B/C/D)으로 사용자에게 적절한 정보량 제시
  • 금융·법무: 미술품 담보·상속·분할 시 객관적 가격 추정 (등급 기반 신뢰도 보고)

10.3 정책적 기여

  • 한국 미술 시장 가격 형성 메커니즘의 정량 분석 (출처별·갤러리별·작가 경력별 분포)
  • 1차/2차 시장 분리 모델로 미술품 가격 정보의 투명성 향상
  • 미술품 가치 평가 표준화 프레임워크의 기초 제공
