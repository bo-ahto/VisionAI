# OP-V01-CAL-07 Warm 작가 메타 보정 운영 재검증 계획

## 1. 목적

- PP-AMW6에서 반복 재검증 후보로 올린 Warm 작가 메타 잔차 보정을 v0.1 운영 산출물 기준으로 다시 확인한다.
- 0604 신규 라벨 데이터는 학습에 쓰지 않고, 운영 입력이 들어왔을 때 후보 보정이 실제 출력에 어떤 영향을 주는지만 확인한다.
- 운영 기본 모델을 바로 바꾸지 않고, 추가 적용 가능 후보로만 평가한다.

## 2. 기준 모델

- 기준 A: `service_primary`
  - 현재 v0.1 운영 출력 기본값.
  - 내부 컬럼: `pp_v8_compact_blend_mape_guarded_pred_log`.
- 기준 B: `report_70_30`
  - 중간 리포트에서 Warm 1순위로 설명했던 70:30 결합 후보.
  - 내부 컬럼: `v01_operational_pred_log`.

## 3. 후보 보정

- 작가 메타 계수 보정
  - 작가 생년, 작품 수, 판매 작품 수, 팔로워 수, 작가 메타 완성도 등을 사용한다.
  - 기존 validation 데이터에서 `실제 로그 가격 - 기준 예측 로그 가격`을 학습한다.
  - Huber 회귀로 과도한 이상치 영향을 줄이고, 보정 폭은 로그 가격 기준 `±0.05`로 제한한다.

- 생년대 구간 보정
  - 작가 생년을 세대 구간으로 나눈다.
  - 같은 세대 구간에서 반복적으로 남는 오차의 중앙값을 보정값으로 사용한다.
  - 보정 폭은 로그 가격 기준 `±0.03`으로 제한한다.

## 4. 검증 방식

- 보정식 학습: 기존 Warm validation split만 사용한다.
- 0604 데이터: 학습에는 사용하지 않고 외부 확인용으로만 평가한다.
- 비교 지표: MdAPE, MAPE, p95_APE, RMSE_log, 3배 이상 과대/과소 예측 건수.
- 주요 판단 기준: 50달러 미만 라벨을 제외한 0604 지표를 별도 확인한다.

## 5. 채택 판단

- 이 실험만으로 v0.1 운영 기본값을 교체하지 않는다.
- 기존 split 반복 검증과 0604 외부 확인에서 같은 방향으로 개선될 때 다음 후보로 승격한다.
- MdAPE만 개선되고 MAPE 또는 p95_APE가 악화되면 운영 기본값 반영은 보류한다.
