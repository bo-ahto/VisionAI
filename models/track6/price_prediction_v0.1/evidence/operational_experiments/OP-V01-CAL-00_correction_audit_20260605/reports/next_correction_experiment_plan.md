# v0.1 후속 보정 실험 계획

## 1. 진행 원칙

- 현재 v0.1 운영 예측값은 기준선으로 고정한다.
- 보정 후보는 기준선 예측값을 대체하는 것이 아니라, 기준선 대비 개선 여부를 검증하는 실험으로 둔다.
- 0604 신규 데이터는 라벨 검수 전까지 보정값 학습에 사용하지 않는다.
- 기존 학습/검증/test split에서 보정 후보를 만든 뒤, 반복 split과 작가 단위 재학습 검증으로 확인한다.
- 실제 서비스 적용은 점가격 보정, 가격 범위 보정, 신뢰도 보정을 분리해서 판단한다.
- 검증 통과 후보라도 v0.1 기본 운영 정책에 바로 반영하지 않는다.
- 별도 API/프론트 테스트 후보로 분리한 뒤 반영 여부를 결정한다.

## 3. OP-V01-CAL-01 라벨 검수 기준을 반영한 평가 분리

- 실행 상태: 완료
- 실행 위치: `models/track6/price_prediction_v0.1/evidence/operational_experiments/OP-V01-CAL-01_label_qc_eval_split`
- 핵심 결과:
  - 전체 숫자 라벨 837건 기준 MAPE는 `14.2852`
  - 50달러 미만 8건 제외 후 MAPE는 `0.3359`
  - 50달러 이상 10만 달러 미만 핵심 구간 MAPE는 `0.3308`
  - 50달러 미만 라벨은 보정 학습보다 라벨 검수를 먼저 적용
  - 10만 달러 이상 고가 꼬리는 점가격 보정보다 가격 범위/신뢰도 보정부터 검토
- 기준 모델: v0.1 운영 예측값
- 사용 데이터: 0604 신규 라벨 데이터
- 보정 방식: 모델 예측값은 바꾸지 않고 평가 그룹만 분리
- 분리 기준:
  - 실제 가격 50달러 미만
  - 실제 가격 10만 달러 이상
  - 원화/달러 단위 변환 의심
  - 작품명, 작가명, 가격 라벨 누락 또는 비정상
- 결과물:
  - 전체 지표
  - 검수 필요 라벨 제외 지표
  - 저가/고가/단위 의심 그룹별 지표
  - 검수 대상 샘플 목록
- 판단 기준:
  - 검수 제외 후 MAPE가 안정되면 모델 보정보다 데이터 검수 프로세스를 먼저 적용한다.
  - 검수 제외 후에도 특정 구간 오차가 크면 다음 보정 실험으로 넘긴다.

## 4. OP-V01-CAL-02 저가/소형 작품 과대 예측 방어

- 실행 상태: 완료
- 실행 위치: `models/track6/price_prediction_v0.1/evidence/operational_experiments/OP-V01-CAL-02_low_small_overprediction_guard`
- 핵심 결과:
  - test 기준선 MdAPE `0.1632`, MAPE `0.2816`, p95_APE `0.9311`
  - 전역 하향 보정 후보 MdAPE `0.1618`, MAPE `0.2803`, p95_APE `0.9281`
  - over 3x 건수는 `6건`으로 줄지 않음
  - 기본 점가격 보정 채택은 보류
  - 저가/소형 과대 예측은 단순 하향 보정보다 라벨 검수와 위험도 표시가 우선
- 기준 모델: v0.1 운영 예측값
- 대상 문제: 실제 가격이 낮은 작품에서 예측값이 3배 이상 높게 나오는 경우
- 사용 가능한 조건:
  - 작품 면적
  - 예측 가격
  - 유사 작품 기반 표본 수
  - 유사 작품 기반 가격 범위 폭
  - 재료/지지체 묶음
  - 작가 가격 기준선
- 사용하지 않는 조건:
  - 실제 정답 가격
  - 0604 라벨에서만 알 수 있는 사후 정보
- 보정 후보:
  - 낮은 예측 가격 구간의 중앙값 보정
  - 소형 작품 구간의 보수적 하향 보정
  - 표본 수 부족 구간의 하향 상한 제한
- 판단 기준:
  - over 3x 건수 감소
  - MAPE 개선
  - MdAPE와 p95_APE 악화 제한

## 5. OP-V01-CAL-03 고가 작품 과소 예측 방어

- 실행 상태: 완료
- 실행 위치: `models/track6/price_prediction_v0.1/evidence/operational_experiments/OP-V01-CAL-03_high_value_underprediction_guard`
- 핵심 결과:
  - test 기준선 MdAPE `0.1632`, MAPE `0.2816`, p95_APE `0.9311`
  - 최선 후보는 under 1/3x를 `7건`에서 `6건`으로 줄임
  - 하지만 MAPE `0.2853`, p95_APE `0.9332`로 악화

  - 점가격 상향 보정은 채택 보류

- 기준 모델: v0.1 운영 예측값
- 대상 문제: 실제 고가 작품에서 예측값이 실제의 1/3 미만으로 낮게 나오는 경우
- 사용 가능한 조건:
  - 작가 가격 기준선
  - 작가 과거 고가 거래 여부
  - 유사 작품 기반 가격 범위 상단
  - 검색/전시/갤러리/미술관 신호
  - 작품 면적과 재료/지지체
- 보정 후보:
  - 고가 가능성 구간의 상단 범위 확장
  - 점가격은 제한적으로만 상향
  - 신뢰도 문구를 보수적으로 변경
- 판단 기준:
  - under 1/3x 건수 감소
  - p95_APE 개선
  - 전체 MAPE 악화 제한

## 6. OP-V01-CAL-04 위험도 기반 가격 범위 보정

- 실행 상태: 완료
- 실행 위치: `models/track6/price_prediction_v0.1/evidence/operational_experiments/OP-V01-CAL-04_risk_adjusted_range_confidence`
- 핵심 결과:
  - 기준 범위 포함률 `0.9226`
  - `fixed_125_width` 범위 포함률 `0.9588`
  - 기준 median range ratio `4.0492`
  - `fixed_125_width` median range ratio `5.7440`
  - `fixed_150_width`는 포함률이 `0.9753`으로 더 높지만 범위가 과도하게 넓어 서비스 기본 후보에서는 제외
  - 점가격은 유지하고 가격 범위/신뢰도 보정 후보로 검토 가능
  - v0.1 기본 운영 정책에는 아직 미반영
- 기준 모델: v0.1 운영 예측값
- 목적: 틀릴 가능성이 큰 예측을 화면에서 더 조심스럽게 표현
- 위험 신호:
  - 유사 작품 표본 수 부족
  - 유사 작품 가격 범위가 지나치게 넓음
  - 작가 가격 이력 부족
  - 검색 품질 낮음
  - 예측 불확실성 폭이 넓음
- 보정 방식:
  - 점가격은 유지
  - 하한/상한 범위를 넓힘
  - 신뢰도를 낮춤
  - 검수 필요 플래그를 표시
- 판단 기준:
  - 실제 가격이 범위 안에 들어오는 비율 개선
  - 범위가 과도하게 넓어지는 비율 제한
  - 서비스 화면에서 설명 가능한 규칙 유지

## 7. OP-V01-CAL-05 반복 split 및 작가 단위 재학습 검증

- 실행 상태: 범위 정책 반복 검증 완료
- 실행 위치: `models/track6/price_prediction_v0.1/evidence/operational_experiments/OP-V01-CAL-05_range_policy_revalidation`
- 핵심 결과:
  - 검증 대상은 점가격 보정이 아니라 `fixed_125_width` 범위 정책
  - validation 범위 포함률 `0.9480 -> 0.9595`
  - test 범위 포함률 `0.9226 -> 0.9588`
  - row bootstrap 양수 개선 비율 `1.0000`
  - artist bootstrap 양수 개선 비율 `1.0000`
  - 범위/신뢰도 보정 후보로 유지 가능
  - v0.1 기본 운영 정책에는 아직 미반영
  - 이 검증은 모델 재학습 검증이 아니라 범위 표시 정책 검증임
- 기준 모델: v0.1 운영 예측 재현 스크립트
- 목적: 보정 후보가 우연히 한 split에서만 좋아진 것인지 확인
- 검증 순서:
  - 기존 validation/test split 검증
  - row 단위 반복 split 검증
  - artist 단위 반복 split 검증
  - 모델 재학습 포함 artist-level 검증
- 채택 기준:
  - Warm은 MdAPE와 MAPE가 함께 좋아져야 한다.
  - Cold는 artist-level 검증에서 개선이 유지되어야 한다.
  - p95_APE가 나빠지는 후보는 점가격 보정으로 채택하지 않는다.
  - 점가격 개선은 약하지만 범위 포함률이 좋아지는 후보는 범위 보정 후보로만 둔다.

## 8. 운영 반영 전 테스트 순서

1. OP-V01-CAL-01로 평가 데이터의 라벨 검수 기준을 먼저 고정한다.
2. OP-V01-CAL-02와 OP-V01-CAL-03으로 과대/과소 예측을 따로 줄인다.
3. OP-V01-CAL-04로 서비스 화면에 들어갈 가격 범위와 신뢰도 보정을 만든다.
4. OP-V01-CAL-05로 채택 후보만 반복 검증한다.
5. OP-V01-CAL-06으로 점가격 결합 비율 후보가 historical test와 0604 외부 확인에서 동시에 안정적인지 확인한다.
6. 통과한 후보는 v0.1 기본값이 아니라 별도 후보 출력 필드로 API 테스트한다.
7. 프론트 테스트에서 기존 범위와 후보 범위를 함께 비교한다.
8. 라벨 검수 완료된 0604 데이터로 후보 범위와 점가격 후보가 과도하게 흔들리지 않는지 확인한다.
9. 안정적이면 `v0.1.1` 또는 `v0.1-range-policy-test`로 별도 승격한다.

## 9. OP-V01-CAL-06 유사 작품 기반 예측값 결합 비율 재검증

- 실행 상태: 완료
- 실행 위치: `models/track6/price_prediction_v0.1/evidence/operational_experiments/OP-V01-CAL-06_adaptive_blend_reweighting`
- 결과 보고서: `models/track6/price_prediction_v0.1/evidence/operational_experiments/OP-V01-CAL-06_adaptive_blend_reweighting/reports/result_report.md`
- 핵심 결과:
  - historical test 기준 PP-V8 MAPE `0.2816`, MdAPE `0.1632`, p95_APE `0.9311`
  - historical test에서 `svc 60% + PP-V8 40%` 후보는 MAPE `0.2717`, MdAPE `0.1362`, p95_APE `0.8329`
  - 0604 50달러 미만 제외 기준 PP-V8 MAPE `0.3359`, MdAPE `0.2298`, p95_APE `0.9273`
  - 0604 50달러 미만 제외에서 `svc 20% + PP-V8 80%` 후보는 MAPE `0.3330`, MdAPE `0.2385`, p95_APE `0.9122`
  - 0604에서는 강한 svc 결합이 MdAPE와 MAPE를 악화시킴
- 판단:
  - 기존 split만 보면 유사 작품 기반 예측값 결합으로 성능 개선 여지가 있다.
  - 0604 외부 확인에서는 PP-V8 단독 또는 낮은 svc 결합 비율만 비교 가치가 있다.
  - v0.1 기본 점가격은 즉시 변경하지 않는다.
  - 다음 후보는 전역 결합이 아니라 `svc 10~20% + PP-V8 80~90%` 또는 조건부 결합으로 제한해 API 후보 필드에서 비교한다.
