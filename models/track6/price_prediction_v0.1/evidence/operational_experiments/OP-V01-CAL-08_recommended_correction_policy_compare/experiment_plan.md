# OP-V01-CAL-08 추천 보정 후보 통합 비교 계획

## 1. 목적

- 지금까지의 보정 실험에서 유망했던 후보를 한 평가표에 올려 비교한다.
- v0.1 운영 기본값을 바로 바꾸지 않고, 다음 반영 후보의 우선순위를 정한다.
- 0604 신규 라벨은 후보 선택 학습에는 쓰지 않고 외부 확인용 성능 비교에만 사용한다.

## 2. 비교 기준

- 기준 예측값: `service_primary_ppv8`
  - 현재 v0.1 운영 기본 점가격.
  - 내부 컬럼: `pp_v8_compact_blend_mape_guarded_pred_log`.

## 3. 추천 후보

- 작가 메타 계수 보정
  - 작가 생년, 작품 수, 판매 작품 수, 팔로워 수 등으로 남은 오차를 약하게 보정한다.
  - 목적: MdAPE와 MAPE 동시 개선.

- 생년대 구간 보정
  - 작가 생년대를 기준으로 반복 오차 중앙값을 보정한다.
  - 목적: 큰 오차와 p95_APE 방어.

- 유사 작품 기반 가격 피처 저비중 결합
  - 유사 작품 기반 예측값을 `5~20%`만 섞는다.
  - 목적: MAPE/p95 개선 가능성 확인.
  - 0604에서 고비중 결합은 악화됐으므로 낮은 비중 중심으로만 비교한다.

- 조합 후보
  - `작가 메타 + 생년대`
  - `작가 메타 + 유사 작품 저비중`
  - `생년대 + 유사 작품 저비중`
  - `작가 메타 + 생년대 + 유사 작품 저비중`

## 4. 평가 기준

- 핵심 평가 범위: 50달러 미만 라벨 제외.
- 보조 평가 범위: 전체 숫자 라벨, 50~100,000달러 핵심 구간.
- 지표: MdAPE, MAPE, p95_APE, RMSE_log, 3배 이상 과대/과소 예측 건수.

## 5. 채택 판단

- MdAPE, MAPE, p95_APE 중 2개 이상 개선되어야 한다.
- MAPE만 좋아지고 MdAPE가 크게 나빠지는 후보는 보류한다.
- p95_APE 개선 후보는 점가격 기본값보다 큰 오차 방어 후보로 별도 유지할 수 있다.
- 이번 실험은 추천 후보 비교이며, 운영 기본값 교체는 반복 split 또는 추가 신규 데이터 확인 후 결정한다.
