# OP-V01-CAL-06 유사 작품 기반 예측값 결합 비율 재검증

## 1. 목적

- v0.1 Warm 점가격 성능을 높일 수 있는 추가 보정 후보가 있는지 확인한다.
- 기존 `PP-V8` 운영 후보를 바로 교체하지 않고, 유사 작품 기반 예측값과의 결합 비율을 다시 검증한다.
- 전체 데이터에 같은 보정을 적용하지 않고, 작가 표본 수와 유사 작품 묶음 품질에 따라 결합을 제한하는 방식도 함께 확인한다.

## 2. 배경

- 기존 historical test에서는 유사 작품 기반 예측값과 `PP-V8`을 섞은 후보가 `PP-V8` 단독보다 좋았다.
- 반대로 0604 신규 라벨에서는 `PP-V8` 단독이 더 안정적이었다.
- 따라서 추가 보정은 전역 결합이 아니라, 조건부 결합이 효과적인지 확인해야 한다.

## 3. 기준 모델

- 기준 후보: `PP-V8 compact_blend_mape_guarded`
- 비교 후보: `svc_numeric_seed_mean`
- 결합 방식: 로그 가격 기준 선형 결합

```text
corrected_pred_log = weight * svc_pred_log + (1 - weight) * ppv8_pred_log
corrected_pred_price = exp(corrected_pred_log)
```

## 4. 실험 후보

| 후보군 | 설명 |
| --- | --- |
| 전역 결합 | 모든 샘플에 같은 결합 비율 적용 |
| 표본 수 조건 결합 | 작가 또는 유사 작품 표본 수가 충분한 경우에만 결합 적용 |
| coverage 조건 결합 | 유사 작품 묶음 품질이 낮지 않은 경우에만 결합 적용 |
| 점가격 유지 후보 | 조건을 만족하지 않으면 기존 `PP-V8` 예측값 유지 |

## 5. 검증 기준

- historical validation에서 후보를 고른다.
- historical test에서 선택 후보가 유지되는지 확인한다.
- 0604 신규 라벨은 학습이나 선택에 쓰지 않고 외부 확인용으로만 본다.
- 0604 전체 MAPE는 50달러 미만 라벨에 크게 왜곡되므로, 50달러 미만 제외 지표를 함께 본다.

## 6. 채택 기준

- historical test에서 MdAPE, MAPE, p95_APE가 기준선 대비 개선되어야 한다.
- 0604 50달러 미만 제외 지표에서 PP-V8보다 크게 나빠지면 v0.1 점가격 보정 후보로 채택하지 않는다.
- 성능 개선이 historical test에만 나타나고 0604에서 재현되지 않으면 후보 유지 또는 추가 검증으로 둔다.
