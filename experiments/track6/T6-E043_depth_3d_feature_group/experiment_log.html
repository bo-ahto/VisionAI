T6-E043 깊이/3D 정보 추가 실험

  • 상위 일지: T6-E038 작품 변수 선정 실험 일지
  • 목적: 작품 관련 피처의 채택 여부를 가설 단위로 검증
  • 상태: 실험 계획 작성 완료, 실행 전

1. 실험 일지

  • 가설: 깊이/3D 정보는 2D와 3D 작품을 구분해 예측하는 데 도움이 된다.
  • 유의미함 기준: 3D slice의 median APE 또는 p95 APE가 개선되면 후보 유지
  • 테스트 모델: Warm: Huber / Linear Regression / Ridge
    Cold: Huber / Quantile-LAD / LightGBM
  • 확인할 작품 피처: depth_cm, has_depth, is_3d_candidate

2. 초기 실험 데이터

  • 기준 원천 파일: data/track6/track6_feature_candidates_name_corrected.csv
  • 학습 입력과 정답 가격은 분리해서 생성한다.
  • 정답 가격은 train_labels.csv, test_warm_labels.csv, test_cold_labels.csv에만 둔다.
  • Warm 학습 피처에는 artist_name_ko를 둘 수 있지만, 이 실험의 판단 대상은 작품 피처다.
  • Cold 테스트에는 작가명을 사용하지 않는다.

3. 초기 실험 테스트: Warm

  • Warm 목적: 기존 작가 작품에서 깊이/3D 정보가 2D와 3D 작품의 가격 차이를 설명하는지 확인한다.
  • Warm 기준 모델 학습 피처: artist_name_ko + ln_estimated_ho
  • Warm 깊이/3D 추가 모델 학습 피처: artist_name_ko + ln_estimated_ho + depth_cm + has_depth + is_3d_candidate
  • Warm 테스트 데이터: data/test_warm_features.csv + data/test_warm_labels.csv
  • 비교 방식: 전체 Warm 성능과 2D/3D slice 성능을 함께 비교한다.
  • 추가 확인: has_depth=1, is_3d_candidate=1, depth_cm 결측 구간의 오차를 따로 확인한다.
  • 판단 기준: 전체 성능이 비슷해도 3D slice의 p95 APE가 줄면 약점 보완 후보로 유지한다.

4. 초기 실험 테스트: Cold

  • Cold 목적: 신규 작가 작품 중 3D 또는 깊이 정보가 있는 작품의 큰 오차를 줄일 수 있는지 확인한다.
  • Cold 기준 모델 학습 피처: ln_estimated_ho
  • Cold 깊이/3D 추가 모델 학습 피처: ln_estimated_ho + depth_cm + has_depth + is_3d_candidate
  • Cold 테스트 데이터: data/test_cold_features.csv + data/test_cold_labels.csv
  • 제외 피처: artist_name_ko
  • 비교 방식: Cold 전체 성능보다 3D slice와 tail risk 개선 여부를 우선 확인한다.
  • 추가 확인: 2D 작품에 깊이/3D 피처를 일괄 적용했을 때 성능이 나빠지는지 확인한다.
  • 판단 기준: Cold 3D slice는 개선되지만 2D가 악화되면 전체 적용이 아니라 조건부 피처/분기 후보로 둔다.

6. 판단 기준

  • Warm과 Cold의 median APE를 각각 확인한다.
  • p95 APE가 줄어드는지 확인해 큰 오차가 줄었는지 본다.
  • Warm에서만 개선되면 Warm 전용 후보로 둔다.
  • Cold에서만 개선되면 Cold 전용 후보로 둔다.
  • 운영에서 입력하기 어려운 변수는 성능이 좋아도 최종 후보에서 제외하거나 보류한다.
