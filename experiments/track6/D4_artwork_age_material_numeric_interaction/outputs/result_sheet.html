구분내용
실험 목적오래된 유화, 오래된 수묵처럼 작품 연한과 재료가 함께 작용할 때 가격 예측이 개선되는지 확인한다.
실험군Group D: 작품 변수끼리의 교차항
기준선artwork_age + nant_material_idx + nant_tool
학습 피처기준선과 artwork_age x NANT 재료 교차항
테스트 피처학습 피처와 동일
사용 모델Warm: Huber / Linear Regression / Ridge, Cold: Huber / Quantile-LAD / LightGBM
구현 방식artwork_age는 숫자형으로 유지하고, 상위 재료 카테고리별 표시값과 곱한 숫자형 교차항을 생성한다.
주의제작연도 출처와 결측 여부 flag는 사용하지 않는다.
해석 기준교차항 추가 후 MdAPE 또는 RMSE(log)가 낮아지고 p95 APE가 악화되지 않으면 재료별 연한 효과가 있다고 본다.
purpose작품 연한에 따라 재료별 가격 효과가 달라지는지 확인
summaryWarm 최고는 D4 교차항: 연한 x 난트 도구명 + Huber(MdAPE 0.7311), Cold 최고는 D4 기준: 연한 + 난트 재료 + LightGBM(MdAPE 0.7015)이다.
