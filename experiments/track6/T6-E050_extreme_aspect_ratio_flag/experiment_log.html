예정작품 피처 추가 가설H12

T6-E050 극단 가로세로 비율 플래그 실험

  • 상위 일지: T6-E038 작품 변수 선정 실험 일지
  • 목적: 그림 관련 추가 피처의 채택 여부를 가설 단위로 검증
  • 상태: 실험 계획 작성 완료, 실행 전

1. 실험 일지

  • 가설: 극단적인 가로세로 비율 작품은 일반 작품과 가격 예측 오차 패턴이 다를 수 있다.
  • 유의미함 기준: 극단 비율 slice의 p95 APE가 감소하면 후보 유지
  • 테스트 모델: Warm: Huber / Linear Regression / Ridge
    Cold: Huber / Quantile-LAD / LightGBM
  • 확인할 작품 피처: aspect_ratio, is_extreme_aspect_ratio

2. 초기 실험 데이터

  • 기준 원천 파일: data/track6/track6_feature_candidates_name_corrected.csv
  • 학습 입력과 정답 가격은 분리해서 생성한다.
  • 정답 가격은 train_labels.csv, test_warm_labels.csv, test_cold_labels.csv에만 둔다.
  • Cold 테스트에는 작가명을 사용하지 않는다.
구분파일/피처
생성 파일data/train_features.csv, data/train_labels.csv, data/test_warm_features.csv, data/test_warm_labels.csv, data/test_cold_features.csv, data/test_cold_labels.csv
기준 피처Warm 기준: artist_name_ko + ln_estimated_ho + aspect_ratio
Cold 기준: ln_estimated_ho + aspect_ratio
추가 피처Warm/Cold 추가: is_extreme_aspect_ratio
테스트에 사용된 피처학습 피처와 동일한 컬럼 구성 사용

3. 초기 실험 테스트: Warm

  • Warm 정의: 학습 데이터에 같은 작가가 있는 작품을 예측하는 상황
  • Warm 학습 X Warm Test: 학습 데이터에 등장한 작가의 미사용 작품으로 평가한다.
  • Warm 학습 X Cold Test: Warm 방식 모델을 신규 작가 작품에 적용했을 때 성능이 무너지는지 확인한다.
  • 주의: Warm과 Cold는 같은 평가 지표를 쓰지만 결과는 합치지 않는다.
  • Warm 학습 데이터: data/train_features.csv + data/train_labels.csv
  • Warm 테스트 데이터: data/test_warm_features.csv + data/test_warm_labels.csv
  • 작품 연결 키: _track6_row_id
  • Warm 기준 모델 학습 피처: artist_name_ko + ln_estimated_ho + aspect_ratio
  • Warm 추가 모델 학습 피처: artist_name_ko + ln_estimated_ho + aspect_ratio + is_extreme_aspect_ratio
  • 비교 방식: 비율 원값만 쓴 모델 대비 극단 비율 여부가 Warm의 큰 오차를 줄이는지 비교한다.
  • 기록 지표: median APE, p95 APE, Within-30, Within-50

4. 초기 실험 테스트: Cold

  • Cold 정의: 학습 데이터에 한 번도 등장하지 않은 작가의 작품을 예측하는 상황
  • Cold 학습 X Cold Test: 학습 데이터에 없는 작가들의 작품만 평가한다.
  • Cold 학습 X Warm Test: Cold 방식 모델을 기존 작가 작품에 적용해 Warm 모델과 비교한다.
  • Cold 모델은 작가명을 쓰지 않는다.
  • Cold 모델은 호수, 로그 호수, 이후 추가될 작품 자체 변수만 사용한다.
  • Cold 학습 데이터: data/train_features.csv + data/train_labels.csv
  • Cold 테스트 데이터: data/test_cold_features.csv + data/test_cold_labels.csv
  • 작품 연결 키: _track6_row_id
  • Cold 기준 모델 학습 피처: ln_estimated_ho + aspect_ratio
  • Cold 추가 모델 학습 피처: ln_estimated_ho + aspect_ratio + is_extreme_aspect_ratio
  • 제외 피처: artist_name_ko
  • 비교 방식: 신규 작가 작품에서 극단 비율 여부가 큰 오차를 줄이는지 비교한다.
  • 기록 지표: median APE, p95 APE, Within-30, Within-50

5. 결과에 대한 기록

  • 결과 파일: outputs/metrics.csv
  • 예측 비교 파일: outputs/predictions.csv
  • 구간별 오차 파일: outputs/slice_metrics.csv
  • 요약 파일: outputs/summary.md
  • 실행 로그: logs/run.log
  • 결론 표기: 채택 / 보류 / 중단

6. 판단 기준

  • Warm과 Cold의 median APE를 각각 확인한다.
  • p95 APE가 줄어드는지 확인해 큰 오차가 줄었는지 본다.
  • 특정 slice 개선 여부를 함께 확인한다.
  • 운영에서 입력하기 어려운 변수는 성능이 좋아도 최종 후보에서 제외하거나 보류한다.
