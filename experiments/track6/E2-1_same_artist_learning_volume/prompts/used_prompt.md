# E2-1 같은 작가 학습량 비교 실험 지시문

- 목적: 같은 작가의 학습 작품 수가 늘어날수록 Warm 예측이 안정적인지 확인한다.
- 기존 E2와의 차이:
  - 기존 E2는 `artist_works_log` 단독 피처의 영향 확인이다.
  - E2-1은 같은 작가의 학습 작품 수를 5개, 10개, 20개, 30개로 제한해 직접 비교한다.

## 실험 기준

- 대상 작가:
  - train에 최소 30개 이상 작품이 있는 작가
  - Warm test에도 작품이 있는 작가
- 테스트 데이터:
  - 모든 학습량 조건에서 동일한 Warm test 작품을 사용한다.
  - 테스트 작품은 학습에 사용하지 않는다.
- 학습 데이터:
  - 동일 작가 집합에서 작가당 학습 작품 수만 바꾼다.
  - 비교 조건: 작가당 5개, 10개, 20개, 30개 학습
- 사용 피처:
  - `artist_name_ko`
  - `width_cm`
  - `height_cm`
  - `log_area`
  - `aspect_ratio`
- 제외 피처:
  - `artist_works_log`
  - 이유: 이번 실험은 학습량 자체를 바꿔 보는 실험이므로, 학습량 값을 모델 입력으로 직접 넣지 않는다.

## 모델

- Warm 모델:
  - Huber
  - Linear Regression
  - Ridge

## 평가 지표

- MdAPE
- p95_APE
- Within_30
- Within_50
- RMSE_log
- R2

## 판단 기준

- 작가당 학습 작품 수가 늘어날수록 MdAPE가 낮아지면 학습량 증가가 예측 안정성에 도움 된다고 판단한다.
- p95_APE가 낮아지면 큰 오차 위험도 줄었다고 본다.
- Within_30이 높아지면 실제 가격 대비 30% 이내로 맞춘 비율이 좋아졌다고 본다.
- 학습량 증가에도 성능이 좋아지지 않으면 `artist_works_log`는 예측 피처보다 신뢰도/라우팅 기준으로 쓰는 것이 적절하다.
