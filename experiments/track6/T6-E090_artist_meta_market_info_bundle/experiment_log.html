예정Group E

T6-E090 작가 시장 노출+정보량 메타 조합 실험

  • 실험군: Group E
  • 피처 라벨: B6 + B7 + 정보량
  • 상태: 실험 일지 생성 완료, 실행 전

1. 실험 일지

  • 가설: 활동량/인지도 정보와 정보량 피처를 함께 쓰면 신뢰도 판단에 도움이 될 수 있다.
  • 유의미함 기준: 같은 split과 같은 모델군에서 median APE 또는 p95 APE가 낮아지면 개선 후보로 본다.
  • 테스트 모델: Warm Huber / Linear Regression / Ridge, Cold Huber / Quantile-LAD / LightGBM

2. 초기 실험 데이터

  • 기준 원천 파일: data/track6/track6_feature_candidates_name_corrected.csv
  • 학습 입력과 정답 가격은 분리해서 생성한다.
  • 정답 가격은 train_labels.csv, test_warm_labels.csv, test_cold_labels.csv에만 둔다.
  • 입력 피처와 정답 라벨은 _track6_row_id로 연결한다.
구분내용
학습 피처artist_meta_total_works, artist_meta_for_sale_works, artist_meta_followers, artist_meta_is_p1, artist_meta_missing_flags, artist_meta_completeness_score
테스트 피처학습 피처와 같은 컬럼을 사용한다. Cold 실험에서는 artist_name_ko를 제외한다.
확인 목적시장 노출+정보량 조합 확인

3. Warm 테스트

  • Warm 정의: 학습 데이터에 같은 작가가 있는 작품을 예측하는 상황
  • Warm 학습 데이터: data/train_features.csv + data/train_labels.csv
  • Warm 테스트 데이터: data/test_warm_features.csv + data/test_warm_labels.csv
  • Warm과 Cold 결과는 합치지 않고 따로 기록한다.

4. Cold 테스트

  • Cold 정의: 학습 데이터에 한 번도 등장하지 않은 작가의 작품을 예측하는 상황
  • Cold 학습 데이터: data/train_features.csv + data/train_labels.csv
  • Cold 테스트 데이터: data/test_cold_features.csv + data/test_cold_labels.csv
  • Cold 모델은 작가명 자체를 사용하지 않는다.

5. 결과 기록

  • 결과 파일: outputs/metrics.csv
  • 예측 비교 파일: outputs/predictions.csv
  • 구간별 오차 파일: outputs/slice_metrics.csv
  • 요약 파일: outputs/summary.md
  • 실행 로그: logs/run.log
