Warm v0.1 네 가지 예측 축의 학습 방식과 조합 수식

작성일 2026-06-08 대상 Warm 작가 가격 예측 최종 기준 blend_svcnum_ppv8_wsvc_0.70 단위 로그 KRW
핵심 결론

Warm v0.1은 네 가지 후보 예측 축을 만든다. 이 HTML은 후보 1, 2, 3, 4가 각각 어떤 피쳐와 어떤 순서로 예측 로그가격을 만드는지 먼저 설명하고, 마지막에 네 후보를 비교한 뒤 최종 70:30 선택식을 정리한다.

후보별 문서 구성

후보 축자체 예측을 만드는 방식비교 단계에서의 역할
유사작품통계 Huber seed 평균유사작품 숫자 통계를 넣은 Huber 모델 10개 seed 평균유사작품계열 후보
유사작품통계+신뢰피쳐 Huber seed 평균숫자 통계에 그룹 수준/신뢰도 범주까지 넣은 Huber 모델 10개 seed 평균유사작품계열 비교 후보
PPV6 다중후보 안정 블렌드여러 Warm 후보 예측값을 validation 기준으로 가중 결합PP계열 비교 후보
PPV8 compact 안정 블렌드V2 방어형 후보와 L10 생성버킷 후보를 75:25로 결합PP계열 후보
1단계: 네 후보가 각각 자기 방식으로 예측 로그가격을 만든다. 후보1 = 유사작품통계_Huber_seed평균_로그가격 후보2 = 유사작품통계_신뢰피쳐포함_Huber_seed평균_로그가격 후보3 = PPV6_다중후보_안정블렌드_로그가격 후보4 = PPV8_안정블렌드_로그가격 2단계: 마지막 비교 섹션에서 네 후보를 성능 기준으로 비교하고 최종 조합을 선택한다.

전체 흐름

1. Warm 라우팅
작가가 학습 registry에 있으면 Warm 경로로 보낸다.
2. 작품 피쳐 생성
크기, 면적, 형태, 재료, 지지체, 작가 키, 크기 버킷을 만든다.
3. 유사작품 통계
같은 작가/재료/크기 순서로 가장 신뢰 가능한 비교군 통계를 찾는다.
4. 네 후보 예측
SVC numeric, SVC full, PPV6, PPV8 네 축의 로그가격을 만든다.
5. 최종 70:30
검증에서 선택된 조합으로 최종 로그가격과 KRW 가격을 계산한다.

후보 1: 유사작품통계 Huber seed 평균

svc_numeric_seed_mean이다. 기본 Warm 피쳐에 유사작품 숫자 통계를 추가하고, HuberRegressor를 seed 10개로 반복 학습한 뒤 예측 로그가격을 평균한다.

구분사용 피쳐
기본 작품/작가 피쳐width_cm, height_cm, depth_cm, area_cm2, log_area, aspect_ratio, has_depth, is_3d_candidate, is_extreme_aspect_ratio, medium_category, support_category, medium_support_bucket, artist_key
유사작품 숫자 통계svc_group_log_price_median, svc_group_log_price_q25, svc_group_log_price_q75, svc_group_log_price_iqr, svc_group_log_unit_area_median, svc_group_log_unit_area_iqr, svc_group_n_log
1. Crossfit 통계
train 내부 비교군 통계를 자기 fold 제외 방식으로 계산한다.
2. 피쳐 전처리
숫자는 median impute와 표준화, 범주는 missing 처리와 one-hot encoding.
3. Huber 학습
target은 log(price_krw), epsilon 1.35, alpha 0.0001.
4. Seed 반복
seed 10개로 fold 구성을 바꿔 반복 학습한다.
5. 평균 예측
10개 seed 예측 로그가격을 평균한다.
유사작품통계_Huber_seed평균_로그가격 = average(Huber_seed별_예측로그가격_s)

Test: MdAPE 0.1520, MAPE 0.2942, p95 0.9381. 최종 조합의 70% 축으로 선택됐다.

후보 2: 유사작품통계+신뢰피쳐 Huber seed 평균

svc_full_seed_mean이다. 후보 1의 숫자 통계에 유사작품그룹 수준과 신뢰도 범주를 추가한다.

구분사용 피쳐
후보 1 전체 피쳐기본 작품/작가 피쳐 + 유사작품 숫자 통계
유사작품 신뢰 범주svc_group_level, svc_coverage_tier, svc_has_artist_level
1. Crossfit 통계
숫자 통계와 신뢰 범주를 누수 없이 계산한다.
2. 신뢰피쳐 추가
그룹 수준, 표본수 tier, 작가수준 여부를 범주 피쳐로 넣는다.
3. Huber 학습
후보 1과 같은 Huber 설정으로 학습한다.
4. Seed 반복
seed 10개를 반복한다.
5. 평균 예측
10개 seed 예측 로그가격을 평균한다.
유사작품통계_신뢰피쳐포함_Huber_seed평균_로그가격 = average(신뢰피쳐포함_Huber_seed별_예측로그가격_s)

Test: MdAPE 0.1533, MAPE 0.2956, p95 0.9190. 최종식에는 들어가지 않고 비교 후보로 사용됐다.

후보 3: PPV6 다중후보 안정 블렌드

pp_v6_fine_blend_mape_guarded이다. 원본 작품 피쳐를 직접 쓰는 모델이 아니라, 이미 만들어진 여러 Warm 후보의 예측 로그가격을 입력으로 쓰는 블렌드다.

입력 예측값역할
L9_Huber_Quantile_Residual_로그가격Huber, quantile, residual 보정을 순차 적용한 후보
작가이력_라우팅_로그가격작가 이력 구간에 따라 후보를 라우팅한 예측값
유사작품_Fallback_로그가격유사작품 기반 fallback 후보
L10_작가메타_외부검색_순차보정_로그가격작가 메타/외부 검색 피쳐 반영 후보
L10_생성버킷_순차보정_로그가격생성 버킷 피쳐 반영 후보
1. 후보 예측 병합
하위 후보 예측값을 같은 작품 row 기준으로 맞춘다.
2. Weight 탐색
validation에서 0.10 단위 weight grid를 탐색한다.
3. MdAPE guard
최저 단일 MdAPE의 1.08배 이내 조합만 허용한다.
4. MAPE 선택
허용 조합 중 MAPE가 가장 낮은 조합을 선택한다.
5. Test 적용
선택된 weight를 그대로 test에 적용한다.
PPV6_다중후보_안정블렌드_로그가격 = 0.10 * L9_Huber_Quantile_Residual + 0.30 * 작가이력_라우팅 + 0.20 * 유사작품_Fallback + 0.20 * L10_작가메타_외부검색 + 0.20 * L10_생성버킷

Test: MdAPE 0.1613, MAPE 0.2889, p95 0.9314. 최종식에는 들어가지 않고 비교 후보로 사용됐다.

후보 4: PPV8 compact 안정 블렌드

pp_v8_compact_blend_mape_guarded이다. 후보 3보다 배포 구조를 단순화하기 위해 네 개 하위 후보만 비교하고, 최종적으로 두 후보를 75:25로 섞는다.

입력 예측값역할
V1_대표후보_로그가격대표 단일 후보
V2_방어형후보_로그가격평균오차 방어 성격이 강한 후보
L10_생성버킷_순차보정_로그가격생성 버킷 피쳐 반영 후보
L10_작가메타_외부검색_순차보정_로그가격작가 메타/외부 검색 피쳐 반영 후보

V2 방어형 후보 내부 구조

V2_방어형후보_로그가격은 PP-V2의 huber_component_range_clipped 후보이다. 여러 기존 Warm 후보의 예측 로그가격을 다시 입력으로 넣고, Huber meta-model로 한 번 더 안정화한 값이다.

V2 입력의미
기존 Warm 후보 예측 로그가격들기본 Huber, L8/L9 순차 후보, D4 블렌드, R5 p95/MAPE 방어 후보, 작가이력 라우팅, 유사작품 fallback, U1 확장 후보 등
예측값 요약 피쳐하위 후보 예측값의 평균, 표준편차, 범위
기준후보와의 차이각 하위 후보 예측값 minus 기준 후보 예측값
불확실성 폭routing_width
V2_raw_로그가격 = HuberMetaModel(하위후보_예측로그가격들, 예측값_평균, 예측값_표준편차, 예측값_범위, 기준후보와의_차이들, routing_width) V2_방어형후보_로그가격 = clip(V2_raw_로그가격, 하위후보_최소값 - 0.03, 하위후보_최대값 + 0.03)

L10 생성버킷 순차보정 후보 내부 구조

L10_생성버킷_순차보정_로그가격은 PP-L10의 l8_seq__full_plus_generated_buckets 후보이다. 가격대 불확실성을 먼저 추정하고, Huber 중심선과 CatBoost 잔차 보정을 순서대로 적용한다.

L10 피쳐 묶음사용 피쳐
Warm 기본 피쳐width_cm, height_cm, depth_cm, area_cm2, log_area, aspect_ratio, medium_category, support_category, medium_support_bucket, artist_key 등
작가 학습량artist_works_log, artist_works_count_train
생성 bucketsize_bucket, shape_bucket, support_size_bucket, medium_shape_bucket, is_large_2d, is_large_3d
Quantile 피쳐q10_log, q50_log, q90_log, quantile_width, price_range_ratio
q10_log, q50_log, q90_log = CatBoostQuantile(작품피쳐, 생성bucket피쳐) quantile_width = q90_log - q10_log price_range_ratio = exp(clip(quantile_width, -10, 10)) L10_Huber_중심선_로그가격 = Huber(작품피쳐, 생성bucket피쳐, quantile피쳐들) CatBoost_잔차보정 = CatBoostRegressor(실제_로그가격 - L10_Huber_OOF_중심선_로그가격) L10_생성버킷_순차보정_로그가격 = L10_Huber_중심선_로그가격 + CatBoost_잔차보정
1. 후보 예측 병합
네 하위 후보 예측값을 같은 작품 row 기준으로 맞춘다.
2. Weight 탐색
validation에서 0.25 단위 weight grid를 탐색한다.
3. MdAPE guard
최저 단일 MdAPE의 1.08배 이내 조합만 허용한다.
4. MAPE 선택
허용 조합 중 MAPE가 가장 낮은 조합을 선택한다.
5. Test 적용
선택된 weight를 그대로 test와 최종 비교에 적용한다.
하위 후보최종 PPV8 weight
V1_대표후보_로그가격0.00
V2_방어형후보_로그가격0.75
L10_생성버킷_순차보정_로그가격0.25
L10_작가메타_외부검색_순차보정_로그가격0.00
PPV8_안정블렌드_로그가격 = 0.75 * V2_방어형후보_로그가격 + 0.25 * L10_생성버킷_순차보정_로그가격

Test: MdAPE 0.1632, MAPE 0.2816, p95 0.9311. 최종 조합의 30% 축으로 선택됐다.
