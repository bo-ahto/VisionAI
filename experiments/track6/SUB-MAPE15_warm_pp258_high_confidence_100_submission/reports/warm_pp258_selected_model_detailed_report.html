Warm 가격 예측 최종 운영 모델 상세 리포트

작성일: 2026-06-10 · 대상 모델: 최종 운영 예측가격
현재 선택된 Warm 운영 예측가격은 단일 회귀 모델이 아니라, 미세 보정 전 기준 로그가격 위에 잔차 방향을 한 번 더 확인한 뒤 매우 작은 보정값을 더하는 미세 보정 모델이다.

2. 모델 성격

이 모델은 가격을 크게 새로 산출하는 모델이 아니라 보수적인 로그가격 보정층이다. 가격을 원 단위에서 직접 보정하지 않고 로그가격에서 보정하며, 잔차 방향이 맞고 확신이 있을 때만 움직인다.

최종 운영 예측가격의 마지막 미세 보정 단계에서 사용하는 양수 방향 기본 상한은 로그가격 기준 0.00005다. 이 값은 전체 Warm 기준 예측가격을 처음 만들 때의 상한이 아니라, 이미 만들어진 미세보정전_기준로그가격 위에 마지막으로 한 번 더 적용하는 추가 보정 상한이다.

구분사용 상한확인 위치

최종 운영 예측가격의 마지막 미세 보정상향 기본 상한 0.00005, 하향 기본 상한 0.000035최종 운영 예측가격 산출, 보정 상한 계산 단계

최종 추가 보정 상한 0.00005는 가격 비율로 약 exp(0.00005) - 1, 즉 약 0.005% 수준이다.

2.1 단계별 사용 모델과 적용 위치

이 Warm 운영 예측가격은 여러 모델을 한 번에 섞어 직접 예측하는 구조가 아니다. 선행 예측가격을 만든 뒤, 그 예측가격 위에 방향 확인, 잔차 보정, 불확실성 기반 상한 제한을 순차적으로 적용한다.

순서단계사용 모델 또는 방법적용 방식최종 운영 예측가격에서의 역할
1안정 기준 로그가격 생성Huber 계수 기반 안정 기준 모델작품/유사작품 기반 피처로 안정적인 기준 로그가격 hcoef_stable 생성가격대 구간, 구성 예측 분산, 신뢰도 판단의 출발점
2예측 불확실성 생성선행 quantile 예측상위 분위 로그가격과 하위 분위 로그가격의 차이로 quantile_width 생성최종 가격을 직접 만들지는 않고, 보정 강도와 상한을 줄이는 위험 신호로 사용
3미세 보정 전 기준 예측가격 생성히스토그램 기반 그래디언트 부스팅 방향 분류기 + Huber 잔차 회귀 + p95 보조 예측가격 이동선행 균형 기준 예측가격 위에 방향이 맞는 잔차 보정과 p95 방어/개선 이동분을 아주 작게 더함최종 운영 예측가격의 직접 기준값 생성
4최종 운영 예측가격 생성히스토그램 기반 그래디언트 부스팅 방향 분류기 + Huber 잔차 회귀미세 보정 전 기준 예측가격 대비 상향확률과 잔차를 다시 계산하고, 방향이 일치할 때만 0.025 * 잔차 수준으로 추가 보정최종 선택된 운영 예측가격 산출
5보정 상한 제한quantile width 순위 + row 위험도quantile_width가 크거나 row 위험도가 높으면 보정 상한을 줄임p95 악화 방지 및 불안정 row 방어
6비교 실험 후보CatBoost, LightGBM, XGBoost, Ridge, 추가 Huber 계열이전 실험군에서 방향 분류 또는 잔차 보정 후보로 테스트최종 선택 경로에는 CatBoost/LightGBM/XGBoost가 직접 들어가지 않음

정리하면, 현재 선택된 최종 운영 예측가격의 직접 산식에 들어간 핵심 모델은 히스토그램 기반 그래디언트 부스팅 방향 분류기와 Huber 잔차 회귀다. quantile은 가격을 직접 예측하는 마지막 모델이 아니라, 예측 구간 폭을 통해 보정 상한을 줄이는 불확실성 제어 장치로 쓰인다. CatBoost는 이전 후보군에서 테스트됐지만 아래 이유로 최종 선택된 계산 경로에는 포함하지 않았다.

CatBoost를 최종 경로에서 제외한 이유

CatBoost는 시도하지 않은 모델이 아니다. 이전 후보군에서 다음 두 방식으로 테스트했다.

테스트 방식설명
방향 분류 후보CatBoost 분류기로 기준 예측가격이 실제보다 낮게 잡혔는지, 높게 잡혔는지의 방향 확률을 계산한 뒤 방향이 맞을 때만 보정
잔차 보정 후보CatBoost 회귀기로 기준 로그가격 대비 잔차를 예측한 뒤 불확실성 상한 안에서 보정

최종 선택에서 CatBoost를 제외한 이유는 성능이 전혀 나빠서가 아니라, 최종 운영 조건인 MAPE, p95 APE, 반복 안정성, replacement score를 동시에 가장 잘 만족하지 못했기 때문이다. 아래 비교에서 replacement score는 낮을수록 기존 최고 기준 예측가격을 대체하기에 유리한 내부 점수다.

비교 후보fixed test MAPEfixed test p95 APEreplacement/recommendation score판단

CatBoost 방향 분류 후보 중 MAPE 우수 후보0.2698890.807326-0.001387MAPE는 거의 같지만 p95 APE와 대체 점수가 약함

따라서 CatBoost는 특정 지표나 특정 구간에서는 장점이 있었지만, 최종 운영 후보가 요구한 “평균 오차를 유지하면서 큰 오차 구간도 방어하는 보수적 미세 보정층”에는 선택된 히스토그램 기반 방향 분류 + Huber 잔차 조합보다 적합하지 않았다. 최종 경로는 성능이 가장 크게 튀는 후보가 아니라, 기존 Warm 최고 기준 예측가격을 안정적으로 대체할 수 있는 후보를 선택한 결과다.

4. 직접 입력 피처

최종 미세 보정층이 직접 사용하는 피처는 작품 원본 메타데이터 전체가 아니다. 실제 입력은 원천 row 값에서 기존 Warm 예측가격 로그가격과 불확실성 요약값을 만든 뒤, 이를 다시 가격대/신뢰도/가격 차이/row 위험도 피처로 변환한 값이다.

원천 row 값
  -> 기존 Warm 예측가격 로그가격과 불확실성 요약값 생성
  -> 가격대, 신뢰도, 구간 파생 피처 생성
  -> 미세 보정 전 기준 예측가격과 보조 예측가격 간 차이 및 row 위험도 생성
  -> 방향 분류 모델과 Huber 잔차 모델의 입력 피처로 사용
최종 미세 보정층에는 artist_key, 작가 생년, 갤러리명 같은 원본 작가 메타 컬럼이 직접 들어가지 않는다. 이 정보들은 상위의 기존 Warm 예측가격 생성 과정에서 이미 반영되었을 수 있고, 최종 미세 보정층은 그 결과로 만들어진 기준 로그가격과 불확실성 요약값을 받아 미세 보정한다.

4.4 미세 보정 전 기준 예측가격과 보조 예측가격의 차이 피처

최종 미세 보정층은 미세 보정 전 기준 예측가격 위에서 보정한다. 따라서 최종 보정층의 핵심 피처는 미세 보정 전 기준 예측가격이 안정성 우선 보조 예측가격, p95 방어형 보조 예측가격, p95 개선형 보조 예측가격과 얼마나 다른가다.

미세보정전_기준로그가격 = 미세 보정 전 기준 예측가격의 로그가격

안정성우선_이동폭 = abs(안정성 우선 보조 예측가격의 로그가격 - 미세보정전_기준로그가격)
p95방어형_이동폭 = abs(p95 방어형 보조 예측가격의 로그가격 - 미세보정전_기준로그가격)
p95개선형_이동폭 = abs(p95 개선형 보조 예측가격의 로그가격 - 미세보정전_기준로그가격)
p95강화방어형_이동폭 = abs(p95 강화 방어형 보조 예측가격의 로그가격 - 미세보정전_기준로그가격)
선행기준대비_이동폭 = abs(미세 보정 전 기준 예측가격의 로그가격 - 선행 균형 기준 예측가격의 로그가격)

이 값들이 큰 row는 내부 예측가격들이 서로 다른 판단을 내린 row다. 이런 row는 보정이 도움이 될 수도 있지만, 잘못 움직이면 p95 오차를 키울 위험도 있다. 그래서 방향 분류 모델에는 이 차이값을 넣고, 최종 보정 상한 계산에는 row 위험도를 함께 사용한다.

5. 학습 대상

모델은 기준 로그가격이 실제 가격보다 낮은지 높은지의 방향과 기준 로그가격에 아직 남아 있는 잔차의 크기를 학습한다.

실제_로그가격 = log(실제_가격)
잔차 = 실제_로그가격 - 기준_로그가격

방향라벨 = 1  if 잔차 > 0
방향라벨 = 0  if 잔차 <= 0

6. 미세 보정 전 기준 로그가격 생성

최종 미세 보정의 직접 기준값은 미세 보정 전 기준 예측가격의 로그가격이다. 이 기준 예측가격은 선행 균형 기준 예측가격 위에 방향 조건부 잔차 보정과 p95 방어형/개선형 보조 예측가격의 이동분을 결합해 만든다.

선행기준_방향확신도 = abs(선행기준_상향확률 - 0.5) * 2

선행기준_적용확신도
  = clip((선행기준_방향확신도 - 0.14) / (1 - 0.14), 0, 1)

미세보정전_원시보정
  = 0.05 * 선행기준_잔차예측 * 선행기준_잔차방향일치 * 선행기준_적용확신도
  + 0.04 * 선행기준_p95방어형이동 * 선행기준_p95방어형방향일치 * 선행기준_적용확신도
  + 0.02 * 선행기준_p95개선형이동 * 선행기준_p95개선형방향일치 * 선행기준_적용확신도

미세보정전_방향별기본상한
  = 0.00010   if 미세보정전_원시보정 >= 0
  = 0.00007   if 미세보정전_원시보정 < 0

미세보정전_적용상한
  = clip(
      미세보정전_방향별기본상한
      * (1 - 0.50 * 불확실성순위)
      * (1 - 0.75 * row위험도),
      0.000006,
      미세보정전_방향별기본상한
    )

미세보정전_적용보정 = clip(미세보정전_원시보정, -미세보정전_적용상한, +미세보정전_적용상한)

미세보정전_기준로그가격 = 선행_균형기준로그가격 + 미세보정전_적용보정

7. 최종 운영 예측가격 산출

최종 운영 예측가격은 미세 보정 전 기준 로그가격에서 다시 시작한다. 선택된 설정에서는 안정성 우선 보조 예측가격으로 이동하는 강도가 0.000이므로 실질 보정은 Huber 잔차 기반 연속 미세 보정 하나다.

최종 운영 예측가격의 계산 순서도는 다음과 같다.

미세 보정 전 기준미세보정전_기준로그가격을 직접 기준값으로 사용한다.
↓
방향 신호 계산방향 분류 모델로 미세보정전_상향확률과 적용확신도를 만든다.
↓
잔차 신호 계산Huber 잔차 모델로 미세보정전_잔차예측을 만든다.
↓
방향 일치 확인상향/하향 방향과 잔차 방향이 같은 row만 보정 대상으로 둔다.
↓
원시 보정값0.025 * 잔차예측 * 방향일치 * 적용확신도로 계산한다.
↓
상한 적용불확실성순위와 row위험도로 보정 상한을 줄인다.
↓
최종 가격 환산최종로그가격 = 미세보정전_기준로그가격 + 최종보정_적용값, 최종가격 = exp(최종로그가격)
항목값
방향 확신도 임계값0.12
Huber 잔차 보정 강도0.025
안정성 우선 보조 예측가격 이동 강도0.000
양수 방향 기본 상한0.00005
음수 방향 기본 상한0.000035
불확실성 축소 강도0.55
row 위험도 축소 강도0.80
최소 적용 상한0.000006
 
최종보정_방향확신도 = abs(미세보정전_상향확률 - 0.5) * 2

최종보정_적용확신도
  = clip((최종보정_방향확신도 - 0.12) / (1 - 0.12), 0, 1)

최종보정_예상방향 = +1  if 미세보정전_상향확률 >= 0.5
최종보정_예상방향 = -1  if 미세보정전_상향확률 < 0.5

최종보정_잔차방향일치 = 1  if sign(미세보정전_잔차예측) == 최종보정_예상방향
최종보정_잔차방향일치 = 0  otherwise

최종보정_원시값
  = 0.025
    * 미세보정전_잔차예측
    * 최종보정_잔차방향일치
    * 최종보정_적용확신도

8. 보정 상한 계산

최종보정_방향별기본상한
  = 0.00005   if 최종보정_원시값 >= 0
  = 0.000035  if 최종보정_원시값 < 0

불확실성순위 = rank01(quantile_width)

최종보정_적용상한
  = clip(
      최종보정_방향별기본상한
      * (1 - 0.55 * 불확실성순위)
      * (1 - 0.80 * row위험도),
      0.000006,
      최종보정_방향별기본상한
    )

최종보정_적용값 = clip(최종보정_원시값, -최종보정_적용상한, +최종보정_적용상한)

최종 Warm 로그가격 = 미세보정전_기준로그가격 + 최종보정_적용값

최종 Warm 가격 = exp(최종 Warm 로그가격)

9. 최종 운영 예측가격 계산 절차

절차 표기 기준
  • 실제 실행 코드 원문: 아님
  • 표기 방식: 문서용 변수명 사용
  • 목적: 최종 운영 예측가격의 계산 순서와 산식 설명
1. 기준 로그가격 준비

   기준로그가격 = 미세보정전_기준로그가격

2. 방향 분류 모델 기반 상향확률 계산

   미세보정전_상향확률
     = 방향분류모델(미세보정전_기준가격_파생피처)

3. 상향확률을 방향확신도로 변환

   최종보정_방향확신도 = abs(미세보정전_상향확률 - 0.5) * 2

   최종보정_적용확신도
     = clip((최종보정_방향확신도 - 0.12) / (1 - 0.12), 0, 1)

4. Huber 잔차 모델 기반 잔여 오차 예측

   미세보정전_잔차예측
     = Huber잔차모델(미세보정전_기준가격_파생피처)

5. 방향 분류 모델과 잔차 모델의 방향 일치 여부 확인

   최종보정_예상방향 = +1  if 미세보정전_상향확률 >= 0.5
   최종보정_예상방향 = -1  if 미세보정전_상향확률 < 0.5

   최종보정_잔차방향일치 = 1  if sign(미세보정전_잔차예측) == 최종보정_예상방향
   최종보정_잔차방향일치 = 0  otherwise

6. 방향 일치 및 확신도 존재 시 원시 보정값 생성

   최종보정_원시값
     = 0.025
       * 미세보정전_잔차예측
       * 최종보정_잔차방향일치
       * 최종보정_적용확신도

7. 보정 방향별 기본 상한 설정

   최종보정_방향별기본상한
     = 0.00005   if 최종보정_원시값 >= 0
     = 0.000035  if 최종보정_원시값 < 0

8. 예측 불확실성과 row 위험도 기반 상한 축소

   최종보정_적용상한
     = clip(
         최종보정_방향별기본상한
         * (1 - 0.55 * 불확실성순위)
         * (1 - 0.80 * row위험도),
         0.000006,
         최종보정_방향별기본상한
       )

9. 원시 보정값 상한 제한

   최종보정_적용값
     = clip(최종보정_원시값, -최종보정_적용상한, +최종보정_적용상한)

10. 기준 로그가격에 최종 보정값 가산

    최종로그가격 = 미세보정전_기준로그가격 + 최종보정_적용값

11. 로그가격을 원 가격 단위로 환산

    최종가격 = exp(최종로그가격)
