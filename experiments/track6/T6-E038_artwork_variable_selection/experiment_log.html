예정 작품 변수 선정 T6-G5 운영 가능 피처 선정

T6-E038 작품 변수 선정 실험 일지

  • 목적: 작품 관련 피처가 가격 예측에 유의미한지 검증
  • 형식: 실험별 폴더 기준 일지
  • 상태: 실험 계획 작성 완료, 실행 전

1. 실험 목적과 판단 기준

  • 목적 1: 작품 변수 후보가 가격 예측에 도움이 되는지 확인
  • 목적 2: 원값과 ln 변환값 중 어떤 표현이 더 안정적인지 확인
  • 목적 3: Warm / Cold에서 사용할 작품 피처 조합을 따로 정해야 하는지 확인
  • 유의미함 기준 1: 같은 피처셋 안에서 median APE가 낮아짐
  • 유의미함 기준 2: 같은 피처셋 안에서 p95 APE가 낮아짐
  • 유의미함 기준 3: Within-30, Within-50이 높아짐
  • 가설 관리는 아래 작품 변수 선정 가설 목록 표에서 통합 관리

1-1. 작품 변수 선정 가설 목록

가설 ID 가설 확인할 변수 실험 방법 판단 기준
H1 호수는 작가명 없이도 가격대 구분에 도움이 된다. ln_estimated_ho 중앙값 기준 모델과 호수 only 모델 비교 호수 only 모델의 median APE가 더 낮으면 유지
H2 실제 크기 정보는 호수만 사용할 때보다 가격 예측을 개선한다. width_cm, height_cm, log_area, aspect_ratio 기준 모델에 실제 크기 묶음 추가 Warm / Cold 중 하나 이상에서 median APE 하락
H3 재료 정보는 기준 모델보다 가격 예측을 개선한다. nant_material_idx, nant_tool 기준 모델에 재료 묶음 추가 median APE 또는 p95 APE 개선
H4 지지체 정보는 기준 모델 + 재료 피처보다 가격 예측을 개선한다. support_category, nant_support 기준 모델 + 재료 피처에 지지체 묶음 추가 성능 개선 시 유지
H5 깊이/3D 정보는 2D와 3D 작품을 구분해 예측하는 데 도움이 된다. depth_cm, has_depth, is_3d_candidate 깊이/3D 피처 추가 전후를 비교하고 2D/3D slice별 오차 확인 3D slice의 median APE 또는 p95 APE 개선
H6 재료와 크기 조합 피처는 재료와 크기를 따로 넣는 것보다 가격 예측을 개선한다. nant_material_support_bucket, nant_material_idx_x_ho_bucket, 재료 x 호수 구간 단독 피처 모델과 조합 피처 모델 비교 조합 피처 모델의 성능이 더 좋으면 유지
H7 단계적 피처 선택 방식은 전체 조합 탐색 없이도 기준 모델보다 좋은 피처 조합을 찾을 수 있다. 전체 작품 피처 후보 단일 추가 → 그룹 추가 → 제거 실험으로 후보 축소 최종 선택 조합이 기준 모델보다 성능 개선
H8 Warm과 Cold는 동일한 작품 피처 조합보다 각각 다른 피처 조합을 사용할 때 성능이 좋아질 수 있다. Warm / Cold 후보 피처 조합 같은 피처 조합 모델과 Warm / Cold 분리 피처 모델 비교 분리 피처 모델의 각 성능이 더 좋으면 채택
H9 크기 대표값 중심 피처는 전체 크기 피처를 모두 쓰는 방식보다 예측 오차를 줄일 수 있다. ln_estimated_ho vs width_cm, height_cm, log_area, aspect_ratio 대표 크기 피처 모델과 전체 크기 피처 모델 비교 대표값 모델이 성능 유지 또는 p95 APE 개선
H10 원본 재료 문구에는 표준 재료 분류가 담지 못한 가격 차이 설명 정보가 있을 수 있다. collected_material_raw, nant_material_idx, nant_tool 표준 재료 피처 모델과 원본 재료 키워드 추가 모델 비교 원본 키워드 추가 시 median APE 또는 특정 재료 slice 오차 개선
H11 작품 제목에는 에디션, 세트, 포스터 등 가격 차이를 설명하는 정보가 있을 수 있다. title_raw 제목 키워드 flag 생성 후 비교 전체 성능 또는 해당 키워드 slice 오차 개선
H12 극단적인 가로세로 비율 작품은 일반 작품과 가격 예측 오차 패턴이 다를 수 있다. aspect_ratio, is_extreme_aspect_ratio 비율 원값 모델과 극단 비율 flag 추가 모델 비교 극단 비율 slice의 p95 APE 감소
H13 0에 가까운 깊이와 실제 3D에 가까운 깊이는 가격 차이를 다르게 설명할 수 있다. depth_cm, has_depth, is_3d_candidate, depth_bucket has_depth만 사용한 모델과 depth 구간화 모델 비교 3D/depth slice 오차 개선
H14 난트 재료 분류 번호가 너무 세분화되어 있으면 그룹화했을 때 더 안정적인 가격 예측이 가능할 수 있다. nant_material_idx, nant_support, nant_tool, nant_material_group 원본 idx 모델과 상위 그룹화 모델 비교 Cold p95 APE 감소 또는 성능 유지
H15 가격 예측에는 면적보다 긴 변 또는 짧은 변 정보가 더 도움이 될 수 있다. width_cm, height_cm, log_area, max_side_cm, min_side_cm 면적 중심 모델과 긴 변/짧은 변 모델 비교 전체 또는 대형 작품 slice 오차 개선

2. 실험 방법

  • 기준 모델은 T6-E017의 같은 피처셋 기준 결과를 바탕으로 압축한다.
  • Warm 기준 모델: Huber, Linear Regression, Ridge
  • Cold 기준 모델: Huber, Quantile / LAD, LightGBM
  • Warm과 Cold는 난이도와 사용 가능한 피처가 다르므로 후보 모델군을 분리한다.
  • 각 모델은 같은 데이터와 같은 피처셋 기준으로 반복 적용한다.
  • Warm 기준 모델은 artist_name_ko + ln_estimated_ho를 고정 조건으로 둔다.
  • Cold 기준 모델은 ln_estimated_ho를 고정 조건으로 둔다.
  • artist_name_ko는 작품 피처 실험 대상이 아니라 Warm 기준 조건이다.
  • 재료, 지지체, 크기 파생값, 3D 피처는 가설별 실험 일지에서 하나씩 검증한다.

3. 가설별 실행 공통 규칙

  • 기준 원천 파일: data/track6/track6_feature_candidates_name_corrected.csv
  • 학습 입력과 가격 라벨은 분리해서 저장한다.
  • 가격 라벨은 학습과 평가 단계에서만 결합한다.
  • Warm 평가와 Cold 평가는 합치지 않고 따로 기록한다.
  • Warm의 artist_name_ko는 기준 조건이며, 작품 피처 채택 판단 대상은 아니다.
  • Cold에서는 작가명 없이 작품 피처의 효과를 확인한다.
