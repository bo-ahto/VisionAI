실험 목적작가명만으로 설명되는 가격 효과를 기준으로 두고, 작품 유형 정보가 추가 예측력을 주는지 확인한다.
실험군Group C: 작가명 + 작품 변수
기준선B1 기준: artist_name_ko only
학습 피처artist_name_ko에 artwork_type_final, artwork_type_final_major3을 하나씩 또는 묶음으로 추가
테스트 피처학습 피처와 동일
사용 모델Warm: Huber / Linear Regression / Ridge, Cold: Huber / Quantile-LAD / LightGBM
해석 중심C5는 작가명이 학습에 있는 Warm 상황에서 의미가 크므로 Warm 결과를 중심으로 판단한다.
Cold 해석 주의Cold는 신규 작가명이라 artist_name_ko가 학습에 없는 카테고리로 처리되므로 참고값으로만 본다.
평가 지표R2, RMSE(log), MdAPE, p95 APE, Within-30, Within-50, MAPE를 확인한다.
결론 기준B1 기준선보다 Warm MdAPE 또는 RMSE(log)가 낮아지고 p95 APE가 악화되지 않으면 작품 유형 정보의 추가 설명력이 있다고 판단한다.
purpose작가명을 넣은 뒤에도 작품 유형 정보가 가격 예측 성능을 추가로 개선하는지 확인
summaryWarm 최고는 작가명 + 작품 유형 3대 구분 + Huber(MdAPE 0.4263), Cold 최고는 작가명 + 작품 유형 전체 + 3대 구분 + LightGBM(MdAPE 0.6758)이다.
