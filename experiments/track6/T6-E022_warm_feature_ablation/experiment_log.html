예정 실험 후속 실험 T6-G5 운영 가능 피처 선정

T6-E022 Warm 피처 제거 ablation

이 문서는 실행 전 실험 일지 템플릿입니다. 실행 후 결과 지표와 해석을 같은 파일에 갱신합니다.

실험 단계: 후속 실험

단계 설명: 이 실험은 기본 피처 정의 이후의 모델/피처 조합/운영 정책 검증입니다.

1. 가설

  • Warm 후보 피처 중 일부는 중복되거나 성능 기여가 작을 수 있다.

2. 이 실험이 기본 피처 정의에 필요한 이유

  • 이 실험은 기본 피처 정의 이후의 모델/피처 조합/운영 정책 검증입니다.
  • 이 단계에서는 최고 성능 모델을 찾기보다, 어떤 피처를 기본 입력값으로 유지할지 판단합니다.
  • 판단 결과는 이후 기본 피처로 후보 모델 비교 단계의 입력 피처셋으로 넘어갑니다.

3. 실험 방법

항목내용
테스트 모델Warm: Huber / Linear Regression / Ridge, Cold: Huber / Quantile-LAD / LightGBM
학습에 사용된 피처Warm 후보 전체 피처에서 하나씩 제거
테스트에 사용된 피처동일 제거 피처셋
학습 정답값ln_price_krw
비교 기준전체 피처 vs one-drop 피처
유의미함 기준최종 Warm 필수 피처와 제외 피처 구분

4. 사용 모델 상세

항목내용
실험 모델군Warm: Huber / Linear Regression / Ridge, Cold: Huber / Quantile-LAD / LightGBM
모델 역할피처 효과를 검증하기 위한 기본 비교 모델군
기본 입력 처리범주형 피처는 인코딩, 수치형 피처는 필요 시 스케일링 또는 로그 변환
목표값 처리ln_price_krw를 학습 정답값으로 사용
비교 방식전체 피처 vs one-drop 피처
모델 선택 기준median APE, p95 APE, Within-30/50, Warm/Cold 분리 성능, 운영 가능성

5. 생성할 데이터 파일

  • data/train_features.csv: 학습에 사용된 피처
  • data/train_labels.csv: 학습 정답값
  • data/test_warm_features.csv: Warm 테스트 입력 피처
  • data/test_warm_labels.csv: Warm 테스트 정답값
  • data/test_cold_features.csv: Cold 테스트 입력 피처
  • data/test_cold_labels.csv: Cold 테스트 정답값

6. 결과 기록 위치

  • outputs/metrics.csv: 전체 지표
  • outputs/predictions.csv: 예측값과 실제값 비교
  • outputs/slice_metrics.csv: 구간별 오차
  • outputs/summary.md: 결과 해석 요약
  • logs/run.log: 실행 로그

7. 실행 후 채워야 할 결론

  • Warm median APE / p95 APE
  • Cold median APE / p95 APE
  • Within-30 / Within-50
  • baseline 대비 개선 여부
  • 채택 / 보류 / 중단 판단
  • 다음 실험으로 넘길 피처 또는 모델 후보
