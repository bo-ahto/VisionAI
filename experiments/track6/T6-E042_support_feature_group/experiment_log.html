T6-E042 지지체 정보 추가 실험

  • 상위 일지: T6-E038 작품 변수 선정 실험 일지
  • 목적: 작품 관련 피처의 채택 여부를 가설 단위로 검증
  • 상태: 실험 계획 작성 완료, 실행 전

1. 실험 일지

  • 가설: 지지체 정보는 기준 모델 + 재료 피처보다 가격 예측을 개선한다.
  • 유의미함 기준: 성능 개선 시 후보 유지
  • 테스트 모델: Warm: Huber / Linear Regression / Ridge
    Cold: Huber / Quantile-LAD / LightGBM
  • 확인할 작품 피처: support_category, nant_support
  • 피처 비교 원칙: 기본 지지체와 난트 지지체를 비교하되, 중복값이므로 최종 기준선에는 nant_support만 사용한다.

2. 초기 실험 데이터

  • 기준 원천 파일: data/track6/track6_feature_candidates_name_corrected.csv
  • 학습 입력과 정답 가격은 분리해서 생성한다.
  • 정답 가격은 train_labels.csv, test_warm_labels.csv, test_cold_labels.csv에만 둔다.
  • Warm 학습 피처에는 artist_name_ko를 둘 수 있지만, 이 실험의 판단 대상은 작품 피처다.
  • Cold 테스트에는 작가명을 사용하지 않는다.
  • 기준 피처: Warm artist_name_ko + ln_estimated_ho, Cold ln_estimated_ho
  • 재료 묶음: nant_material_idx + nant_tool
  • 최종 지지체 후보: nant_support

3. 초기 실험 테스트: Warm

  • Warm 목적: 재료 정보를 이미 사용한 상태에서 지지체 정보가 추가 설명력을 주는지 확인한다.
  • Warm 비교 기준 모델 학습 피처: artist_name_ko + ln_estimated_ho + nant_material_idx + nant_tool
  • Warm 지지체 추가 모델 학습 피처: 재료 기준 모델에 support_category only, nant_support only, 둘 다 사용한 모델을 비교한다.
  • Warm 테스트 데이터: data/test_warm_features.csv + data/test_warm_labels.csv
  • 비교 방식: 재료 포함 모델과 지지체 추가 모델을 비교한다.
  • 추가 확인: 캔버스/종이/패널 등 support_category 구간별로 오차가 줄어드는지 본다.
  • 판단 기준: 재료 모델 대비 개선되면 지지체를 독립 피처로 유지한다. 재료와 중복되어 개선이 없으면 조합 피처 실험으로만 넘긴다.

4. 초기 실험 테스트: Cold

  • Cold 목적: 신규 작가 상황에서 재료 정보만으로 부족한 부분을 지지체 정보가 보완하는지 확인한다.
  • Cold 비교 기준 모델 학습 피처: ln_estimated_ho + nant_material_idx + nant_tool
  • Cold 지지체 추가 모델 학습 피처: 재료 기준 모델에 support_category only, nant_support only, 둘 다 사용한 모델을 비교한다.
  • Cold 테스트 데이터: data/test_cold_features.csv + data/test_cold_labels.csv
  • 제외 피처: artist_name_ko
  • 비교 방식: 재료 포함 Cold 모델과 지지체 추가 Cold 모델을 비교한다.
  • 추가 확인: 지지체 값이 없는 작품, 종이/캔버스/패널 구간별 p95 APE를 확인한다.
  • 판단 기준: Cold median APE와 p95 APE가 함께 개선되면 지지체를 Cold 후보 피처로 유지한다.

  • 예측 비교 파일: outputs/predictions.csv
  • 구간별 오차 파일: outputs/slice_metrics.csv
  • 요약 파일: outputs/summary.md
  • 실행 로그: logs/run.log
  • 결론 표기: 채택 / 보류 / 중단

6. 판단 기준

  • Warm과 Cold의 median APE를 각각 확인한다.
  • p95 APE가 줄어드는지 확인해 큰 오차가 줄었는지 본다.
  • Warm에서만 개선되면 Warm 전용 후보로 둔다.
  • Cold에서만 개선되면 Cold 전용 후보로 둔다.
  • 운영에서 입력하기 어려운 변수는 성능이 좋아도 최종 후보에서 제외하거나 보류한다.
