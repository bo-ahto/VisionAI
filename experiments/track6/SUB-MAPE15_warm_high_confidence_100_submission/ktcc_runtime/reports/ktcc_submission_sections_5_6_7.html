7. 시험구성 1

구분내용
시험항목 명가격 예측 모델 성능
시험목적: 고신뢰 Warm 가격예측 구간의 작품 100건에 대해 AI 가격예측 모델이 산출한 예측 가격의 MAPE가 15% 이하인지 확인하고자 한다.
개발목표MAPE 15% 이하

의뢰자가 제시한 스크립트 1 ~ 2
시험절차 및 방법 1. 시험용 PC에서 제출 폴더 ktcc_runtime을 연다.
2. Python 3.9 이상 환경을 준비하고, 필요 시 pip install -r requirements.txt를 실행한다.
3. 실행 전 테스트 입력, label, 모델 artifact 파일이 존재하는지 확인한다.
4. 터미널 또는 VS Code에서 python scripts/ktcc_price_mape_test.py를 실행한다.
5. 스크립트가 모델 artifact를 로드하고 테스트 입력 100건에 대해 final_price를 산출한다.
6. 스크립트가 label 파일과 예측 결과를 _track6_row_id 기준으로 조인한다.
7. 각 row의 absolute_percentage_error = abs(final_price - actual_price) / actual_price를 계산한다.
8. 100건의 평균 절대비율오차인 MAPE를 계산한다.
9. outputs/ktcc_price_mape_metrics.csv와 콘솔 출력에서 MAPE가 15% 이하인지 확인한다.
10. 본 제출 패키지 기준 실행 결과는 MAPE 12.60%로 목표 기준을 만족한다.
