# PP-OPT8 결과 해석 및 후속 개선 계획

- 작성일: 2026-06-09
- 기준 데이터: 제출용 제외, Warm validation OOF 519건 + fixed test 607건
- 기준 운영 후보: PP-OPT7 Warm final operational candidate
- 목적: 20개 추가 실험 결과를 성능 개선 관점으로 해석하고, 다음 실험 우선순위를 정한다.

## 1. 결론

PP-OPT8에서 현재 운영 후보를 바로 대체할 후보는 없었다. 그러나 실험이 실패했다는 뜻은 아니다. 결과는 다음 개선 방향을 명확히 보여준다.

1. 평균 오차를 낮추는 보정과 p95 큰 오차를 낮추는 보정이 서로 다른 역할을 한다.
2. CatBoost/작가 메타 계열은 MAPE를 낮추지만 p95를 악화시키는 경향이 있다.
3. XGBoost gap routing, tail guard, LightGBM tail guard는 p95를 낮추지만 MAPE를 악화시키는 경향이 있다.
4. 퀀타일 폭 기반 보정 강도 조절은 test에서 MAPE와 p95를 동시에 소폭 개선했지만 반복 검증 안정성이 부족하다.

따라서 다음 단계는 단일 보정 모델을 더 강하게 만드는 것이 아니라, row별로 보정 사용 여부와 보정 강도를 결정하는 게이트형 조합 모델을 만드는 것이다.

## 3. 성능 개선을 위한 핵심 가설

현재 후보들은 각각 장점이 분리되어 있다.

- 평균 오차 개선 후보: 작가 메타 CatBoost, CatBoost price band/cap
- p95 방어 후보: XGBoost gap routing, tail guard, LightGBM tail guard
- 공통 안정화 후보: 퀀타일 폭 기반 보정 강도 조절

따라서 후속 모델은 아래 구조가 되어야 한다.

```text
최종 예측 로그가격
  = 운영 후보 로그가격
  + 안전 구간 평균오차 개선 보정값
  - 위험 구간 큰오차 방어 보정값

안전 구간 평균오차 개선 보정값
  = CatBoost/작가메타 보정값
  * 안전구간확률
  * 퀀타일폭기반보정강도
  * 구간별보정상한

위험 구간 큰오차 방어 보정값
  = TailGuard보정값
  * 큰오차위험확률
  * 모델간예측차이기반강도
```

중요한 점은 CatBoost 보정과 tail guard를 동시에 강하게 적용하지 않는 것이다. 평균 오차 보정은 안전 구간에서만 켜고, 큰 오차 방어는 위험 구간에서만 켜야 한다.

## 4. 후속 실험 우선순위

### 1순위: PP-OPT9 게이트형 하이브리드 보정

목표는 현재 운영 후보를 유지하면서 다음 세 가지 신호를 조합하는 것이다.

- 평균오차 개선 신호: 작가 메타 CatBoost 보정
- 큰오차 방어 신호: XGBoost gap routing 또는 tail guard
- 공통 안정화 신호: 퀀타일 폭 기반 보정 강도

실험식:

```text
최종보정값
  = 평균오차개선보정값 * 평균오차개선게이트
  + 큰오차방어보정값 * 큰오차위험게이트

평균오차개선게이트
  = 1 if 예측불확실성폭이 낮고, 유사작품수가 충분하고, 모델간예측차이가 작음
  = 0 or 약한 값 otherwise

큰오차위험게이트
  = 1 if 예측불확실성폭이 높거나, 모델간예측차이가 크거나, tail-risk 모델 확률이 높음
  = 0 or 약한 값 otherwise
```

성공 기준:

- fixed test MAPE가 운영 후보보다 낮을 것
- fixed test p95가 운영 후보보다 `0.001` 이상 악화되지 않을 것
- 반복 검증에서 MAPE 개선율과 p95 방어율이 동시에 개선될 것

### 2순위: 작가 메타 CatBoost 보정의 안전 구간 탐색

작가 메타 보정은 MAPE 개선력이 가장 강하지만 p95를 악화시킨다. 따라서 전체 적용이 아니라 어느 row에서 안전한지를 학습해야 한다.

실험 방법:

```text
작가메타보정이득
  = abs(운영후보오차) - abs(작가메타보정후오차)

안전라벨
  = 1 if 작가메타보정이득 > 0 and 보정후오차가 p95 위험 구간에 들어가지 않음
  = 0 otherwise
```

이 안전라벨을 LightGBM 또는 Logistic 모델로 학습해, 작가 메타 보정을 켤 row만 선택한다.

### 3순위: p95 방어 전용 라우터 재설계

XGBoost gap routing은 p95 개선폭이 가장 컸다. 다만 MAPE가 소폭 악화되므로 큰 오차 위험 row에만 적용해야 한다.

실험 방법:

```text
큰오차위험라벨
  = 1 if 운영후보의 절대퍼센트오차가 상위 5% 또는 상위 10%에 포함
  = 0 otherwise

큰오차위험확률
  = LightGBMClassifier(퀀타일폭, 모델간예측차이, 유사작품수, 가격대, 신뢰도)

방어보정값
  = XGBoost라우팅보정값 * 큰오차위험확률
```

### 4순위: 다목적 cap/strength 최적화

현재 cap과 strength는 후보 조합으로 비교했지만, 목적함수가 명시적으로 `MAPE + p95 + 안정성`을 동시에 최적화하지는 않았다.

다음 실험에서는 아래 목적함수로 탐색한다.

```text
목적함수
  = test_like_validation_MAPE
  + 0.50 * max(0, p95악화량)
  + 0.25 * 반복검증불안정성
```

탐색 대상:

- CatBoost 보정 cap
- 작가 메타 보정 weight
- 퀀타일 폭별 shrinkage
- tail guard 적용 threshold
- gap routing threshold

### 5순위: 작품 피쳐 보정 재설계

작품 피쳐 조합 보정은 현재 방식으로는 성능이 악화됐다. 원인은 크기, 재료, 지지체, 제작연도 조합이 희소해서 row별 보정이 과하게 흔들리기 때문이다.

재시도 방식:

```text
작품피쳐보정값
  = shrinkage_mean(작품피쳐그룹잔차)

shrinkage_mean
  = (그룹표본수 * 그룹잔차평균 + prior_strength * 전체잔차평균)
    / (그룹표본수 + prior_strength)
```

즉, 작품 피쳐는 직접 모델 보정이 아니라 표본 수 기반 shrinkage 보정으로 재설계한다.

## 5. 실행 순서

1. PP-OPT9: 기존 후보를 조합한 게이트형 하이브리드 보정 실험
2. PP-OPT10: 작가 메타 CatBoost 보정 안전 구간 분류 실험
3. PP-OPT11: XGBoost/LightGBM 기반 tail-risk 라우터 실험
4. PP-OPT12: 다목적 cap/strength 자동 탐색 실험
5. PP-OPT13: 작품 피쳐 shrinkage 보정 재실험
6. 최종 비교: PP-OPT7 운영 후보 대비 fixed test, validation OOF, 반복 검증 안정성 동시 비교

## 6. 현재 판단

현재 운영 후보를 유지하면서 개선 가능성이 가장 높은 방향은 다음 조합이다.

```text
PP-OPT7 운영 후보
+ 안전 구간에서만 작동하는 작가 메타 CatBoost 보정
+ 퀀타일 폭 기반 보정 강도 축소
+ 큰 오차 위험 구간에서만 작동하는 XGBoost/tail guard 방어
```

이 방향은 PP-OPT8 결과에서 발견된 장점을 모두 사용하고, 각 방법의 단점을 gate로 제한하는 구조다.
