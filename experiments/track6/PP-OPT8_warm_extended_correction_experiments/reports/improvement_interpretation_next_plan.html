PP-OPT8 결과 해석 및 후속 개선 계획

작성일: 2026-06-09 · 기준 데이터: 제출용 제외 Warm validation OOF 519건 + fixed test 607건 · 기준 운영 후보: PP-OPT7 Warm final operational candidate
현재 운영 후보를 바로 대체할 후보는 없었다. 하지만 평균 오차를 낮추는 보정과 p95 큰 오차를 낮추는 보정이 분리되어 나타났기 때문에, 다음 단계는 단일 모델 교체가 아니라 row별 gate를 이용한 하이브리드 보정이다.

1. 핵심 해석

평균 오차 개선 신호 작가 메타 CatBoost, CatBoost price band/cap은 MAPE를 낮추지만 p95를 악화시키는 경향이 있다.
큰 오차 방어 신호 XGBoost gap routing, tail guard, LightGBM tail guard는 p95를 낮추지만 MAPE를 악화시키는 경향이 있다.
공통 안정화 신호 퀀타일 폭 기반 보정 강도 조절은 test에서 MAPE와 p95를 동시에 소폭 개선했지만 반복 검증 안정성이 약하다.

2. 실험별 결과 해석

방향 관찰 결과 해석 다음 사용 방식
퀀타일 폭 기반 보정 강도 test MAPE -0.000556, p95 -0.000422 불확실성 폭으로 보정 강도를 줄이는 방식은 유효하다. 후속 후보의 공통 governor로 사용하고 반복 검증 기준으로 재튜닝
작가 메타 + CatBoost 보정 test MAPE 최대 -0.003423, p95 +0.005569 평균 오차 개선 신호는 가장 강하지만 tail risk가 커진다. 안전 구간에서만 켜는 평균오차 개선 보정으로 사용
CatBoost price band/cap test MAPE -0.001384, p95 +0.000767 가격대별 cap은 효과가 있으나 p95 여유가 작다. 작가 메타 보정의 cap 보조 정책으로 사용
XGBoost gap routing p95 -0.007305, MAPE +0.000152 큰 오차 방어에는 가장 강하지만 전체 적용은 평균 오차를 밀어낸다. tail-risk가 높은 row에서만 작동하는 방어 라우터로 사용
LightGBM residual p95 +0.017512 직접 잔차 보정 모델로 쓰기에는 위험하다. 보정값 생성보다 위험도 분류/gate 모델로 제한
작품 피쳐 조합 보정 MAPE +0.003016, p95 +0.026467 희소 조합을 직접 보정하면 과적합 위험이 크다. min support와 shrinkage 기반으로 재설계

4. 후속 실험 우선순위

1순위: PP-OPT9 게이트형 하이브리드 보정

작가 메타 CatBoost 보정, XGBoost gap routing, 퀀타일 폭 governor를 하나의 row별 gate 구조로 결합한다.

2순위: 작가 메타 CatBoost 보정 안전 구간 탐색

작가 메타 보정이 실제로 이득을 주는 row를 라벨링하고, LightGBM 또는 Logistic 모델로 보정 사용 여부를 학습한다.

3순위: p95 방어 전용 라우터 재설계

큰 오차 위험 확률이 높은 row에서만 XGBoost routing 또는 tail guard를 적용한다.

4순위: 다목적 cap/strength 최적화

MAPE, p95, 반복 검증 불안정성을 함께 벌점으로 두고 cap, strength, threshold를 자동 탐색한다.

5순위: 작품 피쳐 shrinkage 보정

작품 피쳐 조합은 직접 모델 보정이 아니라 표본 수 기반 shrinkage 평균으로 다시 구성한다.
