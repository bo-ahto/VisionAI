Group G

T6-E099 기본 프로필 x 재료 교차항 실험

  • 실험 라벨: G6
  • 피처 구성: E3 x A8
  • 상태: 일지 생성 완료, 실행 전

1. 실험 일지

  • 가설: 작가 기본 프로필에 따라 재료 효과가 다르게 나타날 수 있다.
  • 목적: 기본 프로필별 재료 프리미엄 확인
  • 유의미함 기준: 교차항 추가 모델의 median APE 또는 p95 APE가 기준 모델보다 낮아지면 개선 후보로 본다.
  • 테스트 모델: Warm Huber / Linear Regression / Ridge, Cold Huber / Quantile-LAD / LightGBM

2. 초기 실험 데이터

  • 기준 원천 파일: data/track6/track6_feature_candidates_name_corrected.csv
  • 학습 입력과 정답 가격은 분리해서 생성한다.
  • 입력 피처와 라벨은 _track6_row_id로 연결한다.
구분피처
작품 기본 피처 묶음ln_estimated_ho + nant_material_idx/nant_tool + nant_support
작가 메타 기준 피처artist_meta_birth_year, artist_meta_career_stage, artist_meta_nationality
추가 교차항artist_meta_career_stage x nant_material_idx, artist_meta_nationality x nant_material_idx

3. Warm / Cold 테스트

  • Warm: 작가명 사용 여부를 따로 기록해 작가명 효과와 메타 교차항 효과를 구분한다.
  • Cold: 작가명은 제외하고 기본 프로필 메타와 재료 교차항만 사용한다.
  • 결과는 Warm과 Cold를 합치지 않고 따로 기록한다.

4. 결과 기록

  • 결과 파일: outputs/metrics.csv
  • 예측 비교 파일: outputs/predictions.csv
  • 구간별 오차 파일: outputs/slice_metrics.csv
  • 실행 로그: logs/run.log
