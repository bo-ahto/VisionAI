# T6-E037 가격 범위 / 신뢰도 표시 정책 실험

- 상태: 예정
- 실험 단계: 후속 실험
- 단계 설명: 기본 피처 정의 이후 진행할 후속 실험
- 세부 목표: T6-G7 신뢰도/가격 범위 정책
- 가설: 단일 가격 예측보다 가격 범위와 신뢰도 경고를 함께 제공하는 것이 실무적으로 더 안전하다.
- 테스트 모델: 최종 Warm/Cold 후보
- 학습에 사용된 피처: `최종 후보 피처셋`
- 테스트에 사용된 피처: `최종 후보 피처셋`
- 학습 정답값: `ln_price_krw`
- 비교 기준: 단일 예측 vs 가격 범위 coverage
- 유의미함 기준: 서비스 출력 정책 후보 확정
- HTML 일지: `experiment_log.html`

## 폴더 구조

- `data/`: 실험 전용 학습/테스트 데이터
- `scripts/`: 실험 실행 코드
- `outputs/`: 결과 지표와 예측값
- `logs/`: 실행 로그
