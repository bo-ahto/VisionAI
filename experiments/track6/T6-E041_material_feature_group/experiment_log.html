T6-E041 재료 정보 추가 실험

  • 상위 일지: T6-E038 작품 변수 선정 실험 일지
  • 목적: 작품 관련 피처의 채택 여부를 가설 단위로 검증
  • 상태: 실험 계획 작성 완료, 실행 전

1. 실험 일지

  • 가설: 재료 정보는 기준 모델보다 가격 예측을 개선한다.
  • 유의미함 기준: median APE 또는 p95 APE 개선 시 후보 유지
  • 테스트 모델: Warm: Huber / Linear Regression / Ridge
    Cold: Huber / Quantile-LAD / LightGBM
  • 확인할 작품 피처: nant_material_idx, nant_tool
  • 피처 비교 원칙: nant_material_idx + nant_tool only, 둘 다 사용한 모델을 비교한다. 최종 후보는 난트 피처를 우선한다.

2. 초기 실험 데이터

  • 기준 원천 파일: data/track6/track6_feature_candidates_name_corrected.csv
  • 학습 입력과 정답 가격은 분리해서 생성한다.
  • 정답 가격은 train_labels.csv, test_warm_labels.csv, test_cold_labels.csv에만 둔다.
  • Warm 학습 피처에는 artist_name_ko를 둘 수 있지만, 이 실험의 판단 대상은 작품 피처다.
  • Cold 테스트에는 작가명을 사용하지 않는다.

3. 초기 실험 테스트: Warm

  • Warm 목적: 이미 학습 데이터에 있는 작가의 작품에서 재료 정보가 호수+작가명 기준 모델보다 가격 예측을 개선하는지 확인한다.
  • Warm 기준 모델 학습 피처: artist_name_ko + ln_estimated_ho
  • Warm 재료 추가 모델 학습 피처: artist_name_ko + ln_estimated_ho + nant_material_idx + nant_tool, artist_name_ko + ln_estimated_ho + nant_material_idx + nant_tool, artist_name_ko + ln_estimated_ho + nant_material_idx + nant_tool를 비교한다.
  • Warm 테스트 데이터: data/test_warm_features.csv + data/test_warm_labels.csv
  • 테스트 피처: 학습 피처와 동일한 컬럼을 사용한다.
  • 비교 방식: 기준 모델과 재료 추가 모델의 median APE, p95 APE를 비교한다.
  • 추가 확인: nant_material_idx 있음/없음 구간별 성능을 따로 확인한다.
  • 판단 기준: Warm에서 개선되면 재료 정보는 Warm 후보 피처로 유지한다. 개선이 재료값이 있는 구간에만 집중되면 결측 보완 필요성을 별도 기록한다.

4. 초기 실험 테스트: Cold

  • Cold 목적: 학습 데이터에 없는 신규 작가 작품에서 작가명 없이 재료 정보만으로 가격 예측이 개선되는지 확인한다.
  • Cold 기준 모델 학습 피처: ln_estimated_ho
  • Cold 재료 추가 모델 학습 피처: ln_estimated_ho + nant_material_idx + nant_tool, ln_estimated_ho + nant_material_idx + nant_tool, ln_estimated_ho + nant_material_idx + nant_tool를 비교한다.
  • Cold 테스트 데이터: data/test_cold_features.csv + data/test_cold_labels.csv
  • 제외 피처: artist_name_ko
  • 비교 방식: 호수 only 기준 모델과 재료 추가 모델을 같은 Cold split에서 비교한다.
  • 추가 확인: 재료가 unknown이거나 난트 재료 번호가 없는 작품에서 오차가 커지는지 확인한다.
  • 판단 기준: Cold에서 개선되면 신규 작가 예측용 작품 자체 피처로 유지한다. p95 APE가 커지면 재료 세분화가 오히려 불안정한지 검토한다.

  • 결과 파일: outputs/metrics.csv
  • 예측 비교 파일: outputs/predictions.csv
  • 구간별 오차 파일: outputs/slice_metrics.csv
  • 요약 파일: outputs/summary.md
  • 실행 로그: logs/run.log
  • 결론 표기: 채택 / 보류 / 중단

6. 판단 기준

  • Warm과 Cold의 median APE를 각각 확인한다.
  • p95 APE가 줄어드는지 확인해 큰 오차가 줄었는지 본다.
  • Warm에서만 개선되면 Warm 전용 후보로 둔다.
  • Cold에서만 개선되면 Cold 전용 후보로 둔다.
  • 운영에서 입력하기 어려운 변수는 성능이 좋아도 최종 후보에서 제외하거나 보류한다.
