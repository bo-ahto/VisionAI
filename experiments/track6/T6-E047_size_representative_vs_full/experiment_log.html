T6-E047 크기 대표값 vs 전체 크기 피처 실험

  • 상위 일지: T6-E038 작품 변수 선정 실험 일지
  • 목적: 작품 관련 피처의 채택 여부를 가설 단위로 검증
  • 상태: 실험 계획 작성 완료, 실행 전

1. 실험 일지

  • 가설: 크기 대표값 중심 피처는 전체 크기 피처를 모두 쓰는 방식보다 예측 오차를 줄일 수 있다.
  • 유의미함 기준: 대표값 모델이 성능 유지 또는 p95 APE 개선 시 채택
  • 테스트 모델: Warm: Huber / Linear Regression / Ridge
    Cold: Huber / Quantile-LAD / LightGBM
  • 확인할 작품 피처: ln_estimated_ho vs width_cm, height_cm, log_area, aspect_ratio

2. 초기 실험 데이터

  • 기준 원천 파일: data/track6/track6_feature_candidates_name_corrected.csv
  • 학습 입력과 정답 가격은 분리해서 생성한다.
  • 정답 가격은 train_labels.csv, test_warm_labels.csv, test_cold_labels.csv에만 둔다.
  • Warm 학습 피처에는 artist_name_ko를 둘 수 있지만, 이 실험의 판단 대상은 작품 피처다.
  • Cold 테스트에는 작가명을 사용하지 않는다.

3. 초기 실험 테스트: Warm

  • Warm 목적: 기존 작가 작품에서 크기를 대표값만 사용할지, 전체 크기 피처를 함께 사용할지 결정한다.
  • Warm 대표 크기 모델 학습 피처: artist_name_ko + ln_estimated_ho
  • Warm 전체 크기 모델 학습 피처: artist_name_ko + ln_estimated_ho + width_cm + height_cm + log_area + aspect_ratio
  • Warm 테스트 데이터: data/test_warm_features.csv + data/test_warm_labels.csv
  • 비교 방식: 대표 크기 모델과 전체 크기 모델을 비교한다.
  • 추가 확인: 전체 크기 피처가 median APE를 낮추는지, 또는 p95 APE를 악화시키는지 함께 본다.
  • 판단 기준: 전체 크기 피처의 개선 폭이 작거나 p95가 나빠지면 대표값 중심 피처를 우선한다.

4. 초기 실험 테스트: Cold

  • Cold 목적: 신규 작가 예측에서 크기 대표값만으로 충분한지, 가로/세로/면적/비율을 모두 넣어야 하는지 확인한다.
  • Cold 대표 크기 모델 학습 피처: ln_estimated_ho
  • Cold 전체 크기 모델 학습 피처: ln_estimated_ho + width_cm + height_cm + log_area + aspect_ratio
  • Cold 테스트 데이터: data/test_cold_features.csv + data/test_cold_labels.csv
  • 제외 피처: artist_name_ko
  • 비교 방식: 같은 Cold split에서 대표 크기 모델과 전체 크기 모델을 비교한다.
  • 추가 확인: 대형 작품, 극단 비율 작품, 크기 결측 작품의 오차를 따로 확인한다.
  • 판단 기준: 전체 크기 피처가 Cold에서 불안정하면 대표값 중심으로 유지하고, 약점 구간은 별도 파생 피처 실험으로 넘긴다.

6. 판단 기준

  • Warm과 Cold의 median APE를 각각 확인한다.
  • p95 APE가 줄어드는지 확인해 큰 오차가 줄었는지 본다.
  • Warm에서만 개선되면 Warm 전용 후보로 둔다.
  • Cold에서만 개선되면 Cold 전용 후보로 둔다.
  • 운영에서 입력하기 어려운 변수는 성능이 좋아도 최종 후보에서 제외하거나 보류한다.
