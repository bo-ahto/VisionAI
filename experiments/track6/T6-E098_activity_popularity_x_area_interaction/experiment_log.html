T6-E098 활동량/인지도 x 면적 교차항 실험

  • 실험 라벨: G5
  • 피처 구성: E2 x A6
  • 상태: 일지 생성 완료, 실행 전

1. 실험 일지

  • 가설: 작가의 활동량/인지도에 따라 면적 효과가 다르게 나타날 수 있다.
  • 목적: 활동량/인지도별 대형작 프리미엄 확인
  • 유의미함 기준: 교차항 추가 모델의 median APE 또는 p95 APE가 기준 모델보다 낮아지면 개선 후보로 본다.
  • 테스트 모델: Warm Huber / Linear Regression / Ridge, Cold Huber / Quantile-LAD / LightGBM

2. 초기 실험 데이터

  • 기준 원천 파일: data/track6/track6_feature_candidates_name_corrected.csv
  • 학습 입력과 정답 가격은 분리해서 생성한다.
  • 입력 피처와 라벨은 _track6_row_id로 연결한다.
구분피처
작품 기본 피처 묶음ln_estimated_ho + nant_material_idx/nant_tool + nant_support
작가 메타 기준 피처artist_meta_total_works, artist_meta_followers, artist_meta_is_p1
추가 교차항artist_meta_total_works x log_area, artist_meta_followers x log_area

3. Warm / Cold 테스트

  • Warm: 활동량/인지도 높은 작가의 대형작 효과를 확인한다.
  • Cold: 작가명은 제외하고 활동량/인지도 메타와 면적 교차항만 사용한다.
  • 결과는 Warm과 Cold를 합치지 않고 따로 기록한다.

4. 결과 기록

  • 결과 파일: outputs/metrics.csv
  • 예측 비교 파일: outputs/predictions.csv
  • 구간별 오차 파일: outputs/slice_metrics.csv
  • 실행 로그: logs/run.log
