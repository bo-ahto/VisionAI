실험 코멘트

항목내용
실험 목적작가명 한글을 그대로 범주형으로 넣는 방식과 숫자형으로 요약해 넣는 방식을 비교한다.
실험군Group B: 작가 변수만
비교 기준B1 one-hot 결과를 기준으로 frequency, target mean, smoothed target mean을 비교한다.
학습 피처artist_name_ko 또는 작가명에서 train 내부 기준으로 만든 encoding 값 1개
테스트 피처학습 피처와 같은 encoding 방식으로 만든 값 1개
사용 모델Warm: Huber / Linear Regression / Ridge, Cold: Huber / Quantile-LAD / LightGBM
누수 방지target mean 계열 encoding은 train label만으로 계산하고, warm/cold test label은 성능 계산에만 사용한다.
해석 주의Cold는 신규 작가명이므로 artist_name 기반 encoding이 대부분 전체 평균 또는 미학습값 처리로 들어가며, 최종 Cold 모델 판단에는 쓰지 않는다.
평가 지표R2, RMSE(log), MdAPE, p95 APE, Within-30, Within-50, MAPE를 확인한다.
결론 기준Warm에서 B1 one-hot보다 MdAPE 또는 RMSE(log)가 개선되면 해당 encoding 방식을 후속 Warm 후보로 둔다.
