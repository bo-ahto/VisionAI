# T6-E036 Warm/Cold 라우팅 기준 실험

- 상태: 예정
- 실험 단계: 후속 실험
- 단계 설명: 기본 피처 정의 이후 진행할 후속 실험
- 세부 목표: T6-G8 최종 운영 후보 확정
- 가설: 학습 데이터 내 작가 존재 여부와 작품 수 기준을 함께 쓰면 모델 선택 안정성이 높아진다.
- 테스트 모델: Warm 최종 후보 / Cold 최종 후보
- 학습에 사용된 피처: `최종 후보 피처셋`
- 테스트에 사용된 피처: `최종 후보 피처셋`
- 학습 정답값: `ln_price_krw`
- 비교 기준: 작가 존재 여부 only vs 작품 수 threshold
- 유의미함 기준: 서비스 모델 선택 규칙 확정
- HTML 일지: `experiment_log.html`

## 폴더 구조

- `data/`: 실험 전용 학습/테스트 데이터
- `scripts/`: 실험 실행 코드
- `outputs/`: 결과 지표와 예측값
- `logs/`: 실행 로그
