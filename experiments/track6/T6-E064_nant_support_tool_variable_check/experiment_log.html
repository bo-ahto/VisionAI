예정 개별 변수 확인

T6-E064 난트 지지체 변수 영향 확인

  • 상위 흐름: 기본 피처 정의 단계
  • 목적: 변수 하나 또는 변수 묶음 하나가 가격 예측에 영향을 미치는지 독립적으로 확인
  • 상태: 실험 일지 생성 완료, 실행 전

1. 실험 일지

  • 가설: 난트 지지체 변수는 표준 지지체 분류보다 추가적인 가격 설명 정보를 제공한다.
  • 확인 변수: nant_support
  • 유의미함 기준: 같은 모델과 같은 split에서 median APE 또는 p95 APE가 낮아지면 가격 예측에 영향을 주는 후보로 본다.
  • 테스트 모델: Warm Huber / Linear Regression / Ridge, Cold Huber / Quantile-LAD / LightGBM

2. 초기 실험 데이터

  • 기준 원천 파일: data/track6/track6_feature_candidates_name_corrected.csv
  • 학습 입력과 정답 가격은 분리해서 생성한다.
  • 정답 가격은 train_labels.csv, test_warm_labels.csv, test_cold_labels.csv에만 둔다.
  • 입력 피처와 정답 라벨은 _track6_row_id로 연결한다.
  • Warm 학습 피처에는 artist_name_ko를 둘 수 있지만, 이 실험의 판단 대상은 nant_support다.
  • Cold 테스트에는 작가명을 사용하지 않는다.
  • 난트 분류는 운영 입력값이 아니라 정제 파이프라인에서 생성되는 표준화 값이다.

3. 초기 실험 테스트: Warm

  • Warm 정의: 학습 데이터에 같은 작가가 있는 작품을 예측하는 상황
  • Warm 학습 X Warm Test: 학습 데이터에 등장한 작가의 미사용 작품으로 평가한다.
  • Warm 학습 X Cold Test: Warm 방식 모델을 신규 작가 작품에 적용했을 때 성능이 무너지는지 확인한다.
  • 주의: Warm과 Cold는 같은 평가 지표를 쓰지만 결과는 합치지 않는다.
  • Warm 학습 데이터: data/train_features.csv + data/train_labels.csv
  • Warm 테스트 데이터: data/test_warm_features.csv + data/test_warm_labels.csv
  • 작품 연결 키: _track6_row_id
  • 기준 모델 학습 피처: artist_name_ko + ln_estimated_ho + nant_material_idx + nant_tool
  • 변수 추가 모델 학습 피처: artist_name_ko + ln_estimated_ho + nant_material_idx + nant_tool + nant_support
  • 테스트 피처: 학습 피처와 같은 컬럼을 data/test_warm_features.csv에서 사용한다.
  • 비교 방식: artist_name_ko + ln_estimated_ho + nant_material_idx + nant_tool 모델과 artist_name_ko + ln_estimated_ho + nant_material_idx + nant_tool + nant_support 모델을 비교한다.

4. 초기 실험 테스트: Cold

  • Cold 정의: 학습 데이터에 한 번도 등장하지 않은 작가의 작품을 예측하는 상황
  • Cold 학습 X Cold Test: 학습 데이터에 없는 작가들의 작품만 평가한다.
  • Cold 학습 X Warm Test: Cold 방식 모델을 기존 작가 작품에 적용해 Warm 모델과 비교한다.
  • Cold 모델은 작가명을 쓰지 않는다.
  • Cold 모델은 호수, 로그 호수, 이후 추가될 작품 자체 변수만 사용한다.
  • Cold 학습 데이터: data/train_features.csv + data/train_labels.csv
  • Cold 테스트 데이터: data/test_cold_features.csv + data/test_cold_labels.csv
  • 작품 연결 키: _track6_row_id
  • 제외 피처: artist_name_ko
  • 기준 모델 학습 피처: ln_estimated_ho + nant_material_idx + nant_tool
  • 변수 추가 모델 학습 피처: ln_estimated_ho + nant_material_idx + nant_tool + nant_support
  • 테스트 피처: 학습 피처와 같은 컬럼을 data/test_cold_features.csv에서 사용한다.
  • 비교 방식: ln_estimated_ho + nant_material_idx + nant_tool 모델과 ln_estimated_ho + nant_material_idx + nant_tool + nant_support 모델을 비교한다.

  • 예측 비교 파일: outputs/predictions.csv
  • 구간별 오차 파일: outputs/slice_metrics.csv
  • 요약 파일: outputs/summary.md
  • 실행 로그: logs/run.log

6. 판단 기준

  • Warm과 Cold의 median APE를 각각 확인한다.
  • p95 APE가 줄어드는지 확인해 큰 오차가 줄었는지 본다.
  • Warm에서만 개선되면 Warm 전용 후보로 둔다.
  • Cold에서만 개선되면 Cold 전용 후보로 둔다.
  • 운영에서 입력하기 어렵거나 재현하기 어려운 변수는 성능이 좋아도 보류한다.
  • 결론 표기: 채택 / 보류 / 중단
