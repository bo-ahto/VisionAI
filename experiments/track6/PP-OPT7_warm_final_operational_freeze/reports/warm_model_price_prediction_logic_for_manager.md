# Warm 가격예측 모델 계산 로직 요약

이 문서는 Warm 가격예측 모델이 작품 가격을 어떤 순서와 계산식으로 예측하는지 설명하기 위한 공유용 문서다. 내부 실험명과 축약어 대신, 문서만 보고도 의미를 알 수 있도록 기능 중심 이름을 사용했다.

## 1. 모델의 한 줄 요약

Warm 가격예측 모델은 먼저 안정적인 기준가격을 만든 뒤, 작품 정보와 작가 메타 정보에서 나온 작은 보정값을 더해 최종 가격을 계산한다.

중요한 점은 가격을 원화 단위에서 바로 더하는 것이 아니라, **로그가격 공간에서 더한 뒤 다시 원화가격으로 변환한다**는 점이다.

```text
최종예측_로그가격 = 기준_로그가격 + 최종적용_보정로그값

최종예측_원화가격 = exp(최종예측_로그가격)
```

원화가격 기준으로 보면 같은 식은 아래처럼 해석된다.

```text
기준_원화가격 = exp(기준_로그가격)
보정배율 = exp(최종적용_보정로그값)

최종예측_원화가격 = 기준_원화가격 * 보정배율
```

따라서 이 모델의 보정값은 원화 금액을 직접 더하는 값이 아니라, 기준가격을 조금 올리거나 내리는 **배율 보정값**이다.

## 2. 전체 계산 흐름

```text
입력 작품 정보와 작가 정보
        |
        v
[1] 유사 작품 통계와 보조 가격 후보를 이용해 기존 Warm 기준 로그가격 계산
        |
        v
[2] Huber 잔차 보정으로 안정 기준 로그가격 생성
        |
        v
[3] CatBoost 모델로 작품 및 신뢰도 기반 보정값 계산
        |
        v
[4] Huber 모델로 작가 생년과 세대 기반 보정값 계산
        |
        v
[5] 두 보정값을 합산하되, 전체 이동 폭을 제한
        |
        v
[6] 예측 불확실성이 큰 구간에서는 보정 강도를 축소
        |
        v
[7] 기준 로그가격에 최종 보정 로그값을 더함
        |
        v
[8] 지수함수로 원화가격 변환
```

## 3. 기준가격 생성 방식

최종 모델은 기준가격을 처음부터 새로 만드는 모델이 아니다. 기존 Warm 계열에서 가장 안정적이었던 기준 로그가격을 중심값으로 사용한다.

기준 로그가격은 아래 계층으로 만들어진다.

```text
기준_로그가격
  = 기존Warm기준_로그가격 + Huber잔차보정_로그값
```

기존 Warm 기준 로그가격은 두 가격 후보의 가중 평균이다.

```text
기존Warm기준_로그가격
  = 0.70 * 유사작품통계_기반_로그가격
  + 0.30 * 안정형보조후보_로그가격
```

여기서 `0.70`과 `0.30`은 최종가격에서 "기준가격 70%, 보정값 30%"를 뜻하지 않는다. 이 비율은 **기준가격을 만들 때 두 후보 가격을 섞는 내부 비율**이다.

안정형 보조 후보 가격은 다시 두 보조 후보를 섞어 만든다.

```text
안정형보조후보_로그가격
  = 0.75 * 방어형보조후보_로그가격
  + 0.25 * 생성버킷순차보정_로그가격
```

각 구성요소의 의미는 다음과 같다.

| 구성요소 | 의미 |
| --- | --- |
| 유사작품통계_기반_로그가격 | 작가, 크기, 재료, 유사 작품 가격 통계를 이용해 만든 기준 가격 후보 |
| 방어형보조후보_로그가격 | 가격이 과하게 흔들리지 않도록 보수적으로 만든 보조 가격 후보 |
| 생성버킷순차보정_로그가격 | 가격대와 작품 특성 구간을 순차적으로 보정한 보조 가격 후보 |
| 안정형보조후보_로그가격 | 방어형 보조 후보와 순차 보정 후보를 섞은 보조 기준 가격 |
| 기존Warm기준_로그가격 | 유사 작품 통계 후보 70%와 안정형 보조 후보 30%를 섞은 기존 기준 가격 |

## 4. Huber 잔차 보정으로 기준가격 안정화

기존 Warm 기준 로그가격을 만든 뒤, Huber 모델이 작은 잔차 보정을 더해 안정 기준 로그가격을 만든다.

Huber 모델은 실제 가격 자체를 바로 맞히는 것이 아니라, 기존 기준가격이 실제 가격에서 얼마나 벗어났는지를 학습한다.

```text
Huber잔차보정_학습목표
  = 실제_로그가격 - 기존Warm기준_로그가격
```

Huber 모델이 사용하는 주요 입력은 다음과 같다.

| 입력 정보 | 의미 |
| --- | --- |
| 보조 가격 후보들 | 서로 다른 방식으로 계산된 가격 후보 |
| 후보 간 가격 차이 | 기준 후보들이 서로 얼마나 다르게 예측했는지 |
| 작품 면적 | 작품 크기의 로그값 |
| 유사 작품 표본 수 | 비교 가능한 유사 작품이 얼마나 많은지 |
| 유사 작품 가격 분산 | 유사 작품 가격이 얼마나 넓게 퍼져 있는지 |

Huber 잔차 보정의 최종 적용식은 다음과 같다.

```text
Huber잔차보정_로그값
  = 값제한(Huber모델_예측잔차, -0.05, +0.05) * 0.50

기준_로그가격
  = 기존Warm기준_로그가격 + Huber잔차보정_로그값
```

`값제한(값, 하한, 상한)`은 값이 하한보다 작으면 하한으로, 상한보다 크면 상한으로 자르는 함수다. 즉 Huber 모델이 큰 보정값을 내더라도, 이 단계에서는 최대 `±0.05` 로그 안으로 자른 뒤 절반만 반영한다.

## 5. 최종 보정값 생성 방식

기준 로그가격이 정해진 뒤 최종 모델은 두 종류의 보정값을 만든다.

1. 작품 및 예측 신뢰도 기반 CatBoost 보정값
2. 작가 생년과 세대 기반 Huber 보정값

두 보정값은 모두 다음 잔차를 맞히는 방향으로 학습된다.

```text
보정모델_학습목표
  = 실제_로그가격 - 기준_로그가격
```

즉, 기준가격이 실제가격보다 낮게 예측되는 경향이 있는 구간에서는 양수 보정값을 만들고, 높게 예측되는 경향이 있는 구간에서는 음수 보정값을 만든다.

## 6. 작품 및 신뢰도 기반 CatBoost 보정

CatBoost 보정은 작품 특성, 가격 후보 간 차이, 예측 불확실성, 유사 작품 표본 수를 이용해 기준가격의 잔차를 보정한다.

주요 입력은 다음과 같다.

| 입력 정보 | 의미 |
| --- | --- |
| 기준 로그가격 | 현재 모델이 중심값으로 보는 가격 |
| 기존 Warm 기준 로그가격 | Huber 보정 전의 기존 기준 가격 |
| 유사 작품 통계 기반 로그가격 | 비교군 통계에서 나온 가격 후보 |
| 안정형 보조 후보 로그가격 | 보조 모델을 섞어 만든 가격 후보 |
| 생성 버킷 순차 보정 로그가격 | 가격대와 작품 특성 구간을 반영한 보조 후보 |
| 가격 후보 간 표준편차 | 여러 후보가 서로 얼마나 다르게 예측했는지 |
| 가격 후보 간 범위 | 후보 가격의 최대값과 최소값 차이 |
| 예측 불확실성 폭 | 가격 예측 구간의 상단과 하단 차이 |
| 가격 범위 비율 | 보조 후보 가격 범위가 중앙가격 대비 얼마나 넓은지 |
| 유사 작품 표본 수 | 비교 가능한 유사 작품 개수 |
| 작품 면적 | 작품 크기 정보 |
| 신뢰도 구간 | 예측을 높게 신뢰할 수 있는지, 중간인지, 낮은지 |

CatBoost 모델의 원시 보정값은 그대로 사용하지 않고, 예측 불확실성 폭에 따라 상한을 다르게 둔다.

```text
CatBoost동적상한
  = 0.02  if 예측불확실성폭 <= 1.60
  = 0.01  if 예측불확실성폭 > 1.60

CatBoost보정_로그값
  = 값제한(CatBoost원시보정_로그값, -CatBoost동적상한, +CatBoost동적상한)
```

의미는 단순하다. 예측 불확실성이 큰 작품은 CatBoost가 강하게 보정하지 못하도록 보정 폭을 절반으로 줄인다.

## 7. 작가 생년과 세대 기반 Huber 보정

작가 보정은 작가 메타 정보 중 생년과 세대 구간을 이용한다. 작가 고유 식별자를 강하게 외우는 방식이 아니라, 생년과 세대 구간에서 나타나는 잔차 경향을 약하게 반영한다.

세대 구간은 작가 생년을 숫자로 바꾼 뒤 아래 기준으로 나눈다.

```text
작가생년숫자값 = 숫자로_변환(작가생년)

작가세대구간 =
  "생년없음"     if 작가생년숫자값 is missing
  "1940년이전"  if 작가생년숫자값 <= 1940
  "1940년대"    if 1940 < 작가생년숫자값 <= 1950
  "1950년대"    if 1950 < 작가생년숫자값 <= 1960
  "1960년대"    if 1960 < 작가생년숫자값 <= 1970
  "1970년대"    if 1970 < 작가생년숫자값 <= 1980
  "1980년대"    if 1980 < 작가생년숫자값 <= 1990
  "1990년이후"  if 1990 < 작가생년숫자값
```

작가 생년이 없으면 평균값으로만 대체하지 않고, `생년없음`이라는 별도 구간으로 처리한다. 그래서 생년 정보가 없는 작가의 잔차 경향도 별도로 반영할 수 있다.

작가 보정값은 다음 식으로 적용된다.

```text
작가세대_원시보정_로그값
  = Huber모델(작가생년숫자값, 작가세대구간)

작가보정_로그값
  = 값제한(작가세대_원시보정_로그값, -0.03, +0.03) * 0.75
```

즉 작가 생년과 세대가 강한 보정 신호를 내더라도 `±0.03` 로그 안으로 자르고, 그중 75%만 사용한다.

## 8. 두 보정값의 합산

CatBoost 보정은 주 보정으로 사용하고, 작가 보정은 보조 신호로 사용한다.

```text
1차보정_로그값
  = 값제한(
      1.00 * CatBoost보정_로그값
    + 0.50 * 작가보정_로그값,
    -0.025,
    +0.025
    )
```

이 식의 의미는 다음과 같다.

| 항목 | 의미 |
| --- | --- |
| `1.00 * CatBoost보정_로그값` | 작품 특성과 신뢰도에서 나온 보정은 전부 반영 |
| `0.50 * 작가보정_로그값` | 작가 생년/세대 신호는 절반만 반영 |
| `-0.025 ~ +0.025` 제한 | 두 보정이 같은 방향으로 커져도 전체 이동 폭을 제한 |

## 9. 위험 구간별 보정 강도 축소

모델은 예측이 불안정한 구간에서 보정값을 더 약하게 적용한다. 위험 구간은 아래 조건으로 판단한다.

고위험 구간은 다음 조건 중 하나라도 만족하면 적용한다.

| 조건 | 기준 |
| --- | --- |
| 신뢰도 구간 | 낮은 신뢰도 |
| 예측 불확실성 폭 | 1.65 이상 |
| 가격 후보 간 표준편차 | 0.13 이상 |
| 기존 기준가격과 안정 기준가격 차이 | 0.05 이상 |
| 유사 작품 표본 수 | 4개 미만 |

중위험 구간은 고위험은 아니지만 다음 조건 중 하나라도 만족하면 적용한다.

| 조건 | 기준 |
| --- | --- |
| 신뢰도 구간 | 중간 신뢰도 |
| 예측 불확실성 폭 | 1.28 이상 |
| 가격 후보 간 표준편차 | 0.08 이상 |
| 기존 기준가격과 안정 기준가격 차이 | 0.025 이상 |
| 유사 작품 표본 수 | 8개 미만 |

위험 구간별 보정 강도는 다음과 같다.

```text
위험계수
  = 0.15  if 고위험 구간
  = 0.55  if 중위험 구간
  = 0.90  otherwise
```

최종 보정값은 위험계수를 곱한 뒤 한 번 더 제한한다.

```text
최종적용_보정로그값
  = 값제한(1차보정_로그값 * 위험계수, -0.020, +0.020)
```

최종적으로 기준 로그가격에서 `±0.020` 로그 이상 움직이지 못하도록 제한한다.

## 10. 최종 가격 산출

모든 계산을 합치면 최종 가격 산식은 다음과 같다.

```text
기존Warm기준_로그가격
  = 0.70 * 유사작품통계_기반_로그가격
  + 0.30 * 안정형보조후보_로그가격

안정형보조후보_로그가격
  = 0.75 * 방어형보조후보_로그가격
  + 0.25 * 생성버킷순차보정_로그가격

Huber잔차보정_로그값
  = 값제한(Huber모델_예측잔차, -0.05, +0.05) * 0.50

기준_로그가격
  = 기존Warm기준_로그가격 + Huber잔차보정_로그값

CatBoost보정_로그값
  = 값제한(CatBoost원시보정_로그값, -CatBoost동적상한, +CatBoost동적상한)

작가보정_로그값
  = 값제한(작가세대_원시보정_로그값, -0.03, +0.03) * 0.75

1차보정_로그값
  = 값제한(
      1.00 * CatBoost보정_로그값
    + 0.50 * 작가보정_로그값,
    -0.025,
    +0.025
    )

최종적용_보정로그값
  = 값제한(1차보정_로그값 * 위험계수, -0.020, +0.020)

최종예측_로그가격
  = 기준_로그가격 + 최종적용_보정로그값

최종예측_원화가격
  = exp(최종예측_로그가격)
```

## 11. 계산 예시

아래 예시는 보정값이 어떻게 줄어드는지 보여주기 위한 단순 예시다.

```text
CatBoost보정_로그값 = +0.018
작가보정_로그값 = +0.012

1차보정_로그값
  = 1.00 * 0.018 + 0.50 * 0.012
  = 0.018 + 0.006
  = +0.024
```

이 작품이 정상 구간이라면 위험계수는 0.90이다.

```text
최종적용_보정로그값
  = 값제한(+0.024 * 0.90, -0.020, +0.020)
  = 값제한(+0.0216, -0.020, +0.020)
  = +0.020
```

이 작품이 중위험 구간이라면 위험계수는 0.55다.

```text
최종적용_보정로그값
  = 값제한(+0.024 * 0.55, -0.020, +0.020)
  = +0.0132
```

이 작품이 고위험 구간이라면 위험계수는 0.15다.

```text
최종적용_보정로그값
  = 값제한(+0.024 * 0.15, -0.020, +0.020)
  = +0.0036
```

같은 보정 신호가 나오더라도, 불확실성이 높은 작품은 최종 가격 이동이 작아진다.
