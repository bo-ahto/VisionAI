Warm 가격예측 모델 계산 로직 요약

상사 공유용 문서다. 내부 실험명과 축약어 대신 기능 중심 이름을 사용했고, 가격 계산 흐름을 기준가격 생성과 보정값 적용으로 나누어 설명한다.

1. 모델의 한 줄 요약

Warm 가격예측 모델은 먼저 안정적인 기준가격을 만든 뒤, 작품 정보와 작가 메타 정보에서 나온 작은 보정값을 더해 최종 가격을 계산한다.

중요한 점은 가격을 원화 단위에서 바로 더하는 것이 아니라, 로그가격 공간에서 더한 뒤 다시 원화가격으로 변환한다는 점이다.

최종예측_로그가격 = 기준_로그가격 + 최종적용_보정로그값
최종예측_원화가격 = exp(최종예측_로그가격)
기준_원화가격 = exp(기준_로그가격)
보정배율 = exp(최종적용_보정로그값)
최종예측_원화가격 = 기준_원화가격 * 보정배율

2. 전체 계산 흐름

입력 작품 정보와 작가 정보
  -> 유사 작품 통계와 보조 가격 후보를 이용해 기존 Warm 기준 로그가격 계산
  -> Huber 잔차 보정으로 안정 기준 로그가격 생성
  -> CatBoost 모델로 작품 및 신뢰도 기반 보정값 계산
  -> Huber 모델로 작가 생년과 세대 기반 보정값 계산
  -> 두 보정값을 합산하되, 전체 이동 폭을 제한
  -> 예측 불확실성이 큰 구간에서는 보정 강도를 축소
  -> 기준 로그가격에 최종 보정 로그값을 더함
  -> 지수함수로 원화가격 변환

3. 기준가격 생성 방식

기준_로그가격
  = 기존Warm기준_로그가격 + Huber잔차보정_로그값

기존Warm기준_로그가격
  = 0.70 * 유사작품통계_기반_로그가격
  + 0.30 * 안정형보조후보_로그가격

안정형보조후보_로그가격
  = 0.75 * 방어형보조후보_로그가격
  + 0.25 * 생성버킷순차보정_로그가격

주의: 0.70과 0.30은 최종가격에서 "기준가격 70%, 보정값 30%"를 뜻하지 않는다. 이 비율은 기준가격을 만들 때 두 후보 가격을 섞는 내부 비율이다.

구성요소의미
유사작품통계_기반_로그가격작가, 크기, 재료, 유사 작품 가격 통계를 이용해 만든 기준 가격 후보
방어형보조후보_로그가격가격이 과하게 흔들리지 않도록 보수적으로 만든 보조 가격 후보
생성버킷순차보정_로그가격가격대와 작품 특성 구간을 순차적으로 보정한 보조 가격 후보
안정형보조후보_로그가격방어형 보조 후보와 순차 보정 후보를 섞은 보조 기준 가격
기존Warm기준_로그가격유사 작품 통계 후보 70%와 안정형 보조 후보 30%를 섞은 기존 기준 가격

4. Huber 잔차 보정으로 기준가격 안정화

Huber 모델은 실제 가격 자체를 바로 맞히는 것이 아니라, 기존 기준가격이 실제 가격에서 얼마나 벗어났는지를 학습한다.

Huber잔차보정_학습목표
  = 실제_로그가격 - 기존Warm기준_로그가격

Huber잔차보정_로그값
  = 값제한(Huber모델_예측잔차, -0.05, +0.05) * 0.50

기준_로그가격
  = 기존Warm기준_로그가격 + Huber잔차보정_로그값
입력 정보의미
보조 가격 후보들서로 다른 방식으로 계산된 가격 후보
후보 간 가격 차이기준 후보들이 서로 얼마나 다르게 예측했는지
작품 면적작품 크기의 로그값
유사 작품 표본 수비교 가능한 유사 작품이 얼마나 많은지
유사 작품 가격 분산유사 작품 가격이 얼마나 넓게 퍼져 있는지

5. 최종 보정값 생성 방식

기준 로그가격이 정해진 뒤 최종 모델은 작품 및 예측 신뢰도 기반 CatBoost 보정값과 작가 생년/세대 기반 Huber 보정값을 만든다.

보정모델_학습목표
  = 실제_로그가격 - 기준_로그가격

5.1 작품 및 신뢰도 기반 CatBoost 보정

입력 정보의미
기준 로그가격현재 모델이 중심값으로 보는 가격
여러 가격 후보유사 작품 통계, 안정형 보조 후보, 순차 보정 후보 등
가격 후보 간 표준편차와 범위여러 후보가 서로 얼마나 다르게 예측했는지
예측 불확실성 폭예측 가격 구간의 상단과 하단 차이
유사 작품 표본 수비교 가능한 유사 작품 개수
작품 면적과 신뢰도 구간작품 크기와 예측 신뢰도
 
CatBoost동적상한
  = 0.02  if 예측불확실성폭 <= 1.60
  = 0.01  if 예측불확실성폭 > 1.60

CatBoost보정_로그값
  = 값제한(CatBoost원시보정_로그값, -CatBoost동적상한, +CatBoost동적상한)

5.2 작가 생년과 세대 기반 Huber 보정

작가세대구간 =
  "생년없음"     if 작가생년숫자값 is missing
  "1940년이전"  if 작가생년숫자값 <= 1940
  "1940년대"    if 1940 < 작가생년숫자값 <= 1950
  "1950년대"    if 1950 < 작가생년숫자값 <= 1960
  "1960년대"    if 1960 < 작가생년숫자값 <= 1970
  "1970년대"    if 1970 < 작가생년숫자값 <= 1980
  "1980년대"    if 1980 < 작가생년숫자값 <= 1990
  "1990년이후"  if 1990 < 작가생년숫자값

작가보정_로그값
  = 값제한(Huber모델(작가생년숫자값, 작가세대구간), -0.03, +0.03) * 0.75

6. 보정값 합산과 위험 구간 축소

1차보정_로그값
  = 값제한(
      1.00 * CatBoost보정_로그값
    + 0.50 * 작가보정_로그값,
    -0.025,
    +0.025
    )
위험 구간판정 조건위험계수
고위험낮은 신뢰도, 예측 불확실성 폭 1.65 이상, 후보 간 표준편차 0.13 이상, 기준가격 차이 0.05 이상, 유사 작품 4개 미만 중 하나라도 해당0.15
중위험중간 신뢰도, 예측 불확실성 폭 1.28 이상, 후보 간 표준편차 0.08 이상, 기준가격 차이 0.025 이상, 유사 작품 8개 미만 중 하나라도 해당0.55
정상 구간고위험과 중위험에 해당하지 않음0.90
 
최종적용_보정로그값
  = 값제한(1차보정_로그값 * 위험계수, -0.020, +0.020)

7. 최종 가격 산출식

최종예측_로그가격
  = 기준_로그가격 + 최종적용_보정로그값

최종예측_원화가격
  = exp(최종예측_로그가격)

원화가격 관점에서는 최종적용_보정로그값이 기준가격에 곱해지는 배율로 작동한다.

8. 계산 예시

CatBoost보정_로그값 = +0.018
작가보정_로그값 = +0.012

1차보정_로그값
  = 1.00 * 0.018 + 0.50 * 0.012
  = +0.024

정상 구간:
최종적용_보정로그값
  = 값제한(+0.024 * 0.90, -0.020, +0.020)
  = +0.020

중위험 구간:
최종적용_보정로그값
  = 값제한(+0.024 * 0.55, -0.020, +0.020)
  = +0.0132

고위험 구간:
최종적용_보정로그값
  = 값제한(+0.024 * 0.15, -0.020, +0.020)
  = +0.0036
