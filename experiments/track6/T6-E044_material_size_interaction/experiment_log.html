T6-E044 재료 x 크기 조합 피처 실험

  • 상위 일지: T6-E038 작품 변수 선정 실험 일지
  • 목적: 작품 관련 피처의 채택 여부를 가설 단위로 검증
  • 상태: 실험 계획 작성 완료, 실행 전

1. 실험 일지

  • 가설: 재료와 크기 조합 피처는 재료와 크기를 따로 넣는 것보다 가격 예측을 개선한다.
  • 유의미함 기준: 조합 피처 모델이 단독 피처 모델보다 성능이 좋으면 유지
  • 테스트 모델: Warm: Huber / Linear Regression / Ridge
    Cold: Huber / Quantile-LAD / LightGBM
  • 확인할 작품 피처: nant_material_support_bucket, nant_material_idx_x_ho_bucket

2. 초기 실험 데이터

  • 기준 원천 파일: data/track6/track6_feature_candidates_name_corrected.csv
  • 학습 입력과 정답 가격은 분리해서 생성한다.
  • 정답 가격은 train_labels.csv, test_warm_labels.csv, test_cold_labels.csv에만 둔다.
  • Warm 학습 피처에는 artist_name_ko를 둘 수 있지만, 이 실험의 판단 대상은 작품 피처다.
  • Cold 테스트에는 작가명을 사용하지 않는다.
  • 기준 피처: Warm artist_name_ko + ln_estimated_ho, Cold ln_estimated_ho
  • 단독 재료 피처: nant_material_idx + nant_tool
  • 단독 크기 피처: width_cm + height_cm + log_area + aspect_ratio + ln_estimated_ho
  • 조합 피처: nant_material_idx_x_ho_bucket

3. 초기 실험 테스트: Warm

  • Warm 목적: 기존 작가 작품에서 재료와 크기를 따로 넣는 것보다 조합 피처가 더 나은지 확인한다.
  • Warm 단독 모델 학습 피처: artist_name_ko + ln_estimated_ho + nant_material_idx + nant_tool + width_cm + height_cm + log_area + aspect_ratio
  • Warm 조합 모델 학습 피처: artist_name_ko + ln_estimated_ho + nant_material_idx_x_ho_bucket
  • Warm 테스트 데이터: data/test_warm_features.csv + data/test_warm_labels.csv
  • 비교 방식: 단독 피처 모델과 조합 피처 모델을 같은 Warm split에서 비교한다.
  • 추가 확인: 조합 bucket의 희소 구간, 값이 적은 bucket에서 p95 APE가 커지는지 확인한다.
  • 판단 기준: median APE가 개선되어도 p95 APE가 커지면 과도한 조합 피처로 보고 보류한다.

4. 초기 실험 테스트: Cold

  • Cold 목적: 신규 작가 상황에서 재료 x 크기 조합이 작품 자체 정보만으로 가격대를 더 잘 나누는지 확인한다.
  • Cold 단독 모델 학습 피처: ln_estimated_ho + nant_material_idx + nant_tool + width_cm + height_cm + log_area + aspect_ratio
  • Cold 조합 모델 학습 피처: ln_estimated_ho + nant_material_idx_x_ho_bucket
  • Cold 테스트 데이터: data/test_cold_features.csv + data/test_cold_labels.csv
  • 제외 피처: artist_name_ko
  • 비교 방식: 단독 피처와 조합 피처를 같은 Cold split에서 비교한다.
  • 추가 확인: Cold에서 처음 보는 조합 bucket이 많은지, unknown bucket 비율이 높은지 확인한다.
  • 판단 기준: Cold p95 APE가 악화되면 조합 피처를 전체 Cold 모델에 넣지 않고 약점 slice 전용 후보로 둔다.

5. 결과에 대한 기록

  • 결과 파일: outputs/metrics.csv
  • 예측 비교 파일: outputs/predictions.csv
  • 구간별 오차 파일: outputs/slice_metrics.csv
  • 요약 파일: outputs/summary.md
  • 실행 로그: logs/run.log
  • 결론 표기: 채택 / 보류 / 중단

6. 판단 기준

  • Warm과 Cold의 median APE를 각각 확인한다.
  • p95 APE가 줄어드는지 확인해 큰 오차가 줄었는지 본다.
  • Warm에서만 개선되면 Warm 전용 후보로 둔다.
  • Cold에서만 개선되면 Cold 전용 후보로 둔다.
  • 운영에서 입력하기 어려운 변수는 성능이 좋아도 최종 후보에서 제외하거나 보류한다.
